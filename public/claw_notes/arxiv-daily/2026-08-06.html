📄 AURORA-LM: Autoencoding Unified Representation for Continuous-Latent Diffusion Language Modeling

  • 作者：Jiajun Liang, Yucheng Liao, Yukang Cao et al.
  • 关键词：连续潜空间, 扩散语言模型, 自编码表示
  • 摘要：语言在生成建模里一直是个异类：图像、视频、音频都越来越多地在连续潜空间建模，文本生成却仍以离散 token 为主。已有的连续语言模型要么继承了并非为联合生成+解码设计的嵌入空间，要么为了方便扩散而压缩自编码潜变量、牺牲 token 级保真度。本文反其道而行——不简化表示去迁就生成模型，而是保留高容量、可解码的文本潜空间，让扩散模型直接学习它的分布。
  • 票数：73 👍

📄 Video-DeepResearch: Towards the Next-Generation Multimodal Deepresearch Agent

  • 作者：Zhen Fang, Yu Zeng, Wenxuan Huang et al.
  • 关键词：多模态 Agent, 视频理解, 工具调用
  • 摘要：把多模态 agent 从静态图像扩展到连续视频流，这一场景同时需要密集的时空定位和开放网络探索。初步评测暴露当前模型两个关键瓶颈：(1) 模态偏好——agent 绕过视觉工具、偏向文本检索；(2) 参数化知识泄漏——模型依赖内部记忆而非真正的工具增强执行。为此提出 Video-DR，采用感知与探索解耦的分阶段流水线。
  • 票数：45 👍

📄 Knowledge-Geometry Decoupling: Refreshable Pretrained Transfer for Streaming Recommendation

  • 作者：Zixuan Wang, Yuhong Chen, Yuxuan Zhu et al.
  • 关键词：预训练迁移, 多 token 预测, 流式场景
  • 摘要：工业推荐系统越来越多采用「预训练+迁移」范式，但行为分布漂移带来两个问题：从行为序列里学什么，以及预训练模型持续刷新时如何迁移已学知识。提出知识-几何解耦（KGD）：针对「学什么」，指出传统 next-token 预测把邻接当作依赖、可能编码跨无关会话的伪转移，改用行为多 token 预测（BMTP）只保留协同或语义相关的未来项。
  • 票数：38 👍

📄 PCSD: Persistent Consistency for Self-Distillation in Agentic Reinforcement Learning

  • 作者：Chunji Lv, Yangguang Wei, Junlin Liu et al.
  • 关键词：Agentic RL, 在线自蒸馏, 稀疏奖励
  • 摘要：LLM agent 在复杂交互任务上潜力很大，但强化学习常受稀疏奖励拖累——一条长的多轮轨迹可能只拿到一个结果级信号。在线自蒸馏（OPSD）能从特权教师那里拿到密集的 token 级监督，但教师并非在每个位置都可靠。已有方法要么依赖孤立的 token 级差异（对噪声敏感），要么分配共享的 step 级权重（忽略位置差异）。本文提出持久一致性自蒸馏（PCSD）来解决这一权衡。
  • 票数：37 👍

📄 Quo Vadis, World Modeling?

  • 作者：Yu Yang, Xuemeng Yang, Licheng Wen et al.
  • 关键词：世界模型, Agent 反馈, 交互式仿真
  • 摘要：持续进化的 agent 需要超越静态监督的动态交互反馈，但直接与真实环境交互代价高、速度慢、不安全且难并行。世界模型提供了一个天然的中间代理，让 agent 在真正行动前先查询低成本、更可控的反馈。经典世界模型主要通过预测未来物理状态来实现这一代理，这个表述有用但对需要「可执行反馈」的 agent 来说过窄。本文提出以 Agent 为中心的交互式世界模型概念框架。
  • 票数：29 👍

📄 PAST-Bench: Benchmarking the Foundations of Recursive Self-Improvement in Personal Agents

  • 作者：Shuhan Xue, Zixin Ding, Yichen Shen et al.
  • 关键词：递归自改进, 个人 Agent, 记忆评测
  • 摘要：递归自我改进要求 agent 把积累的经验转化为更好的未来行为。个人 AI agent 提供了研究这一能力的具体场景，因为它们跨会话保留偏好、任务历史、工具例程和已学技能。但「保留的经验是否真的让它们随时间变强」从未被系统检验过。PAST-Bench 专为隔离这个问题设计：每个 agent 在经验开/关的对照条件下跑有序的全新会话任务序列，覆盖 26 个场景。
  • 票数：28 👍

📄 LLaDA MoE v2: Scaling Mixture-of-Experts Diffusion Language Models

  • 作者：Fengqi Zhu, Shaoxuan Xu, Jingyang Ou et al.
  • 关键词：MoE, 扩散语言模型, Scaling Law
  • 摘要：扩散语言模型（dLLM）是自回归建模的一种替代路线，但 MoE 版 dLLM 的 scaling 行为一直不清楚。本文系统刻画了 MoE dLLM 的优化超参、算力分配和架构如何 scaling，并识别出与自回归模型已报道的 scaling 趋势的定量差异：优化方面，最优名义 batch size 增长更快，而最优学习率随算力衰减更快；模型-数据分配方面，IsoFLOP 分析揭示了略有不同的最优配比。
  • 票数：24 👍

📄 OmniPack: Unified Token Compression for Efficient Omni-modal Large Language Models

  • 作者：Wanshun Su, Yang Shi, Feihu Liu et al.
  • 关键词：Token 压缩, 全模态, 推理效率
  • 摘要：全模态大模型（Omni-LLM）在视听理解任务上表现出色，但处理又长又高度冗余的视觉与音频 token 序列带来巨大计算开销，需要激进的 token 压缩才能高效部署。已有方法在低 token 预算下常常退化：LLM 前压缩可能丢掉结构上重要、全局分布的证据，而 LLM 内压缩又没充分利用 query 条件下的视听协同。OmniPack 提出统一的免训练压缩方案。
  • 票数：24 👍

📄 CAPEval: A Decoupled Caption Evaluation across Understanding and Generation

  • 作者：Zhipeng Liu, Haochen Wang, Zhaoxiang Zhang et al.
  • 关键词：评测基准, 图文对齐, 数据质量
  • 摘要：Caption 同时是多模态理解和文生图的主要监督信号。但以往评测把 caption 质量当作单一标量目标，混淆了两个不同属性：(1) caption 覆盖了多少视觉信息；(2) 图像对其陈述的支持有多可靠。为此设计解耦式 caption 评测基准 CAPEval（覆盖度与精确度评测），配备人工撰写的 ground-truth caption 和人工核验的原子 checklist。
  • 票数：21 👍

📄 TurnSight: Turn-Level Hindsight Self-Distillation for Tool-Integrated Reasoning

  • 作者：Changle Qu, Sunhao Dai, Hengyi Cai et al.
  • 关键词：工具推理, 自蒸馏, 信用分配
  • 摘要：工具集成推理（TIR）让 LLM 通过迭代工具交互解决复杂任务。但现有 RL 方法多依赖轨迹级监督，在长程 TIR 场景下细粒度信用分配受限。在线自蒸馏借助带特权上下文的教师分支提供更密集的信号，但已有做法的特权上下文通常来自 ground-truth 答案或检索到的技能，未必反映 agent 实际访问过的状态；且 token 级监督无法捕捉「轮次级」结构。TurnSight 提出轮次级事后自蒸馏。
  • 票数：17 👍

🔍 arXiv 关键词雷达（新方向探测）

📄 TaskPress: Query-Agnostic KV Cache Compression via Task-Guided Pruning

  • 作者：Wonpyo Park, Seung-won Hwang et al.
  • 提交日期：2026-08-06（arXiv new listing）
  • 摘要：长上下文推理受 KV cache 随序列长度线性增长的制约。剪枝虽能缓解，但主流方法算出的是 query 相关的 token 重要性，无法在未见过的 query 间复用。TaskPress 提出任务引导、query 无关的 KV cache 淘汰框架：不为单个 query 优化 cache，而是基于高层「任务指引」构造可复用的记忆表示，该指引在 prefill 阶段充当元 query，提前过滤无关 token。
  • 方向标签：#推理优化 KVCache（相关度 46）

📄 Output-Aware Rotation for INT2 KV-Cache Quantization

  • 作者：Vincent-Daniel Yun, Woosang Lim, Minsoo Cheong et al.
  • 提交日期：2026-08-06（arXiv new listing）
  • 摘要：KV cache 已成为长上下文推理的主要显存与带宽瓶颈，超低位量化因此愈发重要。但现有基于旋转的 INT2 方法在完整 attention readout 之前就去优化 cache 统计量或代理误差，而模型最终受影响的是经 attention 和输出投影 W_O 传播后的误差。为消除这一错配，提出 OptR——输出感知的旋转方法，直接最小化 W_O 之后的 attention 输出误差。
  • 方向标签：#推理优化 量化（相关度 43）

📄 When Correct Solutions Repeat: Rarity-Aware Credit Redistribution for GRPO

  • 作者：Zhe Cao, Miaowen Wen, Fangjiong Chen et al.
  • 提交日期：2026-08-06（arXiv new listing）
  • 摘要：可验证奖励强化学习（RLVR）通常把每条正确完成当作独立学习信号。在 GRPO 里，这种「完成级均一性」造成结构级偏斜：反复出现的正确解形式会按被采样频率累积正向系数质量，而稀有形式拿到的信用有限。本文把该现象形式化为「多重性诱导的结构级信用集中」，并提出按簇稀有度重分配正优势的分区条件规则，实例化为 Cue-GRPO。
  • 方向标签：#后训练 GRPO RLVR（相关度 40）

📄 Don’t Peek at the Answer: Outcome-Masked GRPO for Label-Free RLVR

  • 作者：Yongshi Ye, Liang Zhang, Yidong Chen et al.
  • 提交日期：2026-08-06（arXiv new listing）
  • 摘要：RLVR 能提升 LLM 推理，但通常依赖 ground-truth 答案，限制了可扩展性。基于投票的无标签 RLVR 用模型样本的答案级共识替代金标监督，然而当同一个答案级信号既用于估计奖励又用于驱动 token 级策略优化时会发生坍塌——模型倾向于直接强化答案 token 而非改进推理过程。OM-GRPO 通过把奖励估计与策略优化解耦、并对结果做 mask 来解决这一坍塌。
  • 方向标签：#后训练 GRPO 无标签（相关度 40）

📄 Speculative Decoding and the Curse of Multilinguality

  • 作者：Nirajan Paudel, Michael Ginn, Luc De Nardi et al.
  • 提交日期：2026-08-06（arXiv new listing）
  • 摘要：投机解码是流行的推理加速技术，用小的 draft 模型一次起草多个 token 来提速。但它的有效性主要只在英语上被研究过。受「多语言诅咒」启发，作者假设由于小模型多语言能力有限，投机解码对低资源语言的效果会差很多。在标准投机解码设定下测试 11 种语言，发现强有力的证据支持该假设，并进一步尝试改进 draft 模型的多语言能力。
  • 方向标签：#推理优化 投机解码 多语言（相关度 38）

📄 AnchorKV: Anchor-Residual KV Cache Compression

  • 作者：Malik Khalaf, Yara Shamshoum, Nitzan Hodos et al.
  • 提交日期：2026-08-06（arXiv new listing）
  • 摘要：KV cache 是长上下文推理的首要显存瓶颈。现有方法从两个相反端切入：淘汰法永久丢弃 token，一旦被丢的 token 后续变得关键就会掉点；量化法保留所有 token 但只做低精度，压缩率有限。AnchorKV 提出一种不丢弃任何 token 就把 cache 缩小 20 倍的压缩方案——用少量精确存储的 anchor 表示 cache，其余每个 token 通过与其最相似的 anchor 加残差来表达。
  • 方向标签：#推理优化 KVCache（相关度 36）

📄 LEAP: Lean Environment-Feedback via Adaptive Pruning for Code RL in GPU Kernel Generation

  • 作者：Tankun Li, Zhi Chen, Yaohua Tang et al.
  • 提交日期：2026-08-06（arXiv new listing）
  • 摘要：用 RL 做 LLM 后训练已显著推进代码生成能力。为绕开 critic 网络的高显存开销，当前 SOTA 框架采用 GRPO 这类免 critic 范式配合规则验证沙箱。但把这些框架用到 CUDA kernel 生成这类底层系统编程上挑战很大：二值 pass/fail 奖励带来严重信号稀疏，多轮环境反馈循环又代价高昂。LEAP 用自适应剪枝精简环境反馈来应对。
  • 方向标签：#后训练 GRPO 代码RL（相关度 36）

📄 Lightweight Chunk Selection for Mobile Retrieval-Augmented Generation

  • 作者：Sicong Chang, Yidan Shen, Wen Yu et al.
  • 提交日期：2026-08-06（arXiv new listing）
  • 摘要：RAG 通过引入外部知识改善 LLM 的事实性，但在移动/边缘设备上部署困难，因为检索到的上下文会增加计算与显存。最直接的降本方式是生成前只保留一个检索 chunk，但排名第一的 chunk 未必最有证据支撑——检索相似度不等于证据充分性。已有上下文缩减方法虽能提升上下文质量，却往往需要额外 LLM 或压缩器，在严格的移动预算下代价过高。
  • 方向标签：#RAG 端侧推理（相关度 35）

📄 Latent Reward Registers for Diffusion Preference Alignment

  • 作者：Yuanshen Guan, Zipeng Feng, Zhiwei Xiong et al.
  • 提交日期：2026-08-06（arXiv new listing）
  • 摘要：让扩散模型对齐人类偏好通常依赖在最终样本上评估的稀疏终端奖励，导致多步去噪过程中严重的时序信用分配难题。本文提出潜奖励寄存器（Latent Reward Registers）：在冻结的 DiT 输入序列前置可学习、无位置的 register token，直接从中间的带噪潜变量估计终端偏好。这一独立读出机制在不改动生成器隐状态或速度场的前提下抽取潜在奖励证据。
  • 方向标签：#对齐 奖励模型 扩散模型（相关度 35）

📄 Approximate Speculative Decoding

  • 作者：Yuannuo Feng, Zegang Peng, Yuxin Xie et al.
  • 提交日期：2026-08-06（arXiv new listing）
  • 摘要：投机解码通过让目标模型并行验证一个 draft block 来加速自回归生成。在标准贪心验证下，解码会在第一个与目标 argmax 不同的 draft token 处停止，丢弃剩余已被目标模型打分的后缀。作者指出：接受这种 mismatch 虽然改变了解码轨迹，但当后缀 token 在实际前缀下仍保持 target-greedy 时，这段连续后缀是可复用的——由此提出近似投机解码。
  • 方向标签：#推理优化 投机解码（相关度 33）
