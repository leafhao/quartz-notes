📄 LongHorizon-Harness: Advancing Long-Horizon Agents for Real-World Tasks

  • 作者：Ziyu Ma et al.
  • 关键词：long-horizon agent, 状态管理, 工具调用, 自我评估
  • 摘要：LLM 智能体越来越多地承担长周期任务，需要跨多个相互依赖的步骤持续推理、调用工具并自我修正。但现有 agent harness 把任务执行、任务状态和完成度评估全塞进一个不断膨胀的上下文里，导致状态难以追踪，错误的自我评估会一路传播污染后续决策。本文提出 LongHorizon-Harness，把状态管理与评估从上下文中解耦出来，显著提升真实世界长周期任务的可靠性。
  • 票数：126 👍

📄 DAPD: Dual-Anchored Policy Distillation

  • 作者：Jianyu Wu et al.
  • 关键词：后训练, on-policy 蒸馏, 特权幻觉, DAPD
  • 摘要：On-policy 自蒸馏（OPSD）在语言模型后训练中越来越流行：给教师模型喂特权信息可以增强教师，但会诱发”特权幻觉”——学生学到的是依赖特权信息的行为模式，而推理时它拿不到这些信息，却仍然假装信息还在，最终反而掉性能。本文提出 DAPD（双锚定策略蒸馏），用双锚机制约束蒸馏目标，消除特权幻觉。
  • 票数：54 👍

📄 Progressive Agent Skill Generation via Reinforcement Learning

  • 作者：Junhao Shen et al.
  • 关键词：agent skill, 强化学习, 技能生成, 渐进式训练
  • 摘要：现有 skill 生成方法大多依赖启发式规则或流水线式归并，针对不同证据源都得单独设计。基于学习的方法能统一建模异构来源的技能生成，但难点在于技能本身缺乏天然的监督信号。本文用强化学习做渐进式 agent 技能生成，让模型自己从执行反馈中学会抽取和沉淀可复用技能。
  • 票数：49 👍

📄 UEmbed: Unified Sparse and Dense Multimodal Embeddings

  • 作者：Tingyu Song et al.
  • 关键词：稀疏检索, 多模态嵌入, LSR, RAG
  • 摘要：稀疏检索是现代搜索系统（从 web search 到 RAG）的基石。已有工作用 Learned Sparse Retrieval（LSR）超越精确词面匹配走向语义匹配，但 LSR 一直绑死在 encoder 式双向架构上，扩展到多模态还严重依赖额外的跨模态模块。UEmbed 提出统一的稀疏+稠密多模态嵌入框架，一个模型同时产出两种表示。
  • 票数：41 👍

📄 CADENA: Stepwise CAD Reverse Engineering

  • 作者：Soslan Kabisov et al.
  • 关键词：CAD 逆向工程, 逐步生成, 中间状态验证
  • 摘要：CAD 是现代工程的基础，但把已有形状转成可编辑模型仍需大量专家人力。多数 AI 系统一次性吐出整个 CAD 程序，从不检查中间几何；而人类工程师是一个特征一个特征地搭，每步操作后都检查还剩什么要建。CADENA 采用逐步式 CAD 逆向工程，模仿人类的增量验证流程。
  • 票数：30 👍

📄 WorldExam: Benchmarking World Models from Apparent Appearance to Inherent Reactivity

  • 作者：Yuxue Yang et al.
  • 关键词：世界模型, 视频生成, 反应性评测, benchmark
  • 摘要：可控视频生成模型正被越来越多地当作世界模型开发。相应地，评估它们就不能只看生成视频的表观质量，还要看它们所描绘世界的内在反应性——能否从场景状态推断世界应当如何反应，并生成输入里没有明说的合理后果。WorldExam 构建了从”表观外貌”到”内在反应性”的世界模型评测基准。
  • 票数：30 👍

📄 SKT: Skill-Use Training at Scale via Verified Synthetic Data Generation

  • 作者：Zelin Tan et al.
  • 关键词：合成数据, 技能使用训练, 可验证数据合成, agent
  • 摘要：Agent skill 已成为给语言模型智能体注入可复用流程知识的重要机制。但光提供技能并不保证当前模型能有效识别、应用和协调这些技能。SKT 提出一条经过验证的数据合成流水线，构造 skill-grounded 任务和可执行轨迹，规模化训练模型的技能使用能力。
  • 票数：27 👍

📄 SWE-Touch: Benchmarking Coding Agents When Users Touch the Code

  • 作者：Yuqiao Tan et al.
  • 关键词：coding agent, 共享工作区, benchmark, 人机协同
  • 摘要：真实软件开发中，coding agent 要在共享工作区里干活——用户可能在任务进行中查看甚至修改代码。但现有仓库级 benchmark 通常只评估 agent 单干，或把用户参与限制在发消息。SWE-Touch 专门评测”用户中途动代码”时 coding agent 的理解与响应能力。
  • 票数：22 👍

📄 GradCuit: Credit-Assigned Gradient Flow Enables Robust and Interpretable Test-Time Latent Reasoning

  • 作者：Zhaoxin Yu et al.
  • 关键词：测试时推理, 隐空间优化, 信用分配, 可解释性
  • 摘要：基于优化的隐空间推理在测试时优化实例专属的连续状态、冻结模型参数，从而改进 LLM 输出。但现有方法通常通过解码出的 token 把这些状态连回推理轨迹，导致序列级信用分配很间接，也看不清隐状态更新如何塑造后续推理。GradCuit 引入带信用分配的梯度流，让测试时隐空间推理更鲁棒、更可解释。
  • 票数：21 👍

📄 Motion Beyond Morphology: Bootstrapping Cross-Category Motion Transfer from Abstract Motion Representations

  • 作者：Zhixue Fang et al.
  • 关键词：动作迁移, 视频生成, 跨类别泛化
  • 摘要：视频动作迁移的目标是用参考视频的动态去驱动目标物体。现有方法大多依赖固定的结构对应关系，一旦参考物与目标物在形态、关节结构或形变机制上差异很大，这种对应就失效了。本文提出跨类别动作迁移视角，从抽象动作表征出发绕开固定结构绑定。
  • 票数：20 👍

📄 DeepVoyager-VL: Incentivizing Vision-in-the-Loop Search for Long-Horizon Multimodal Agents

  • 作者：Huanyao Zhang et al.
  • 关键词：多模态 agent, 深度搜索, 长周期, 视觉在环
  • 摘要：多模态大模型（MLLM）在视觉理解和推理上已有长进，但其静态参数化知识限制了处理知识密集、动态演化的开放世界问题的能力。多模态深度搜索因此成为关键方向，从单轮事实检索演进到长周期多轮搜索。DeepVoyager-VL 用”视觉在环”搜索激励机制训练长周期多模态智能体。
  • 票数：15 👍

📄 3DZip: Spatial-Aware Feature Diversity-Guided Token Compression for 3D Question Answering

  • 作者：Changwoo Baek et al.
  • 关键词：token 压缩, 3D VLM, 推理效率, 空间推理
  • 摘要：3D 视觉语言模型（3D VLM）通过把 2D 视觉特征投影到世界坐标来构建几何感知 token，从而支持 3D 问答等空间推理任务。但这种设计每个场景生成上千 token，计算和显存开销巨大。2D VLM 的 token 压缩已被充分研究，但 3D 场景下的方案仍缺失。3DZip 提出空间感知的特征多样性引导 token 压缩。
  • 票数：14 👍

📄 Verifier-Induced Support Reshaping in On-Policy Optimization

  • 作者：Shaohang Wei et al.
  • 分类：Machine Learning (cs.LG)
  • 公告日期：2026-08-05
  • 关键词：RLVR, on-policy 优化, 支撑集重塑, 探索坍缩
  • 摘要：作者证明：带可验证奖励的 on-policy 强化学习（RLVR）在优化当前目标的同时，会让”对后续目标有用的成功行为”变得过于稀有、采样不到、也就无法被强化。他们把这一现象命名为 verifier-induced support reshaping（验证器诱导的支撑集重塑），并定义”有效可奖励支撑集”为固定 rollout 预算内可达的成功轨迹集合。在两个模型族上通过重复验证器打分采样和双向训练验证了该效应。这对理解 RLVR 的长期能力天花板很关键。
  • 方向标签：#RLHF/后训练

📄 Distill Where You Fail: Recovering Learning Signals of Negative RL-Groups from Adaptive Teacher Guidance

  • 作者：Zhuowen Han et al.
  • 分类：Computation and Language (cs.CL)
  • 公告日期：2026-08-05
  • 关键词：GRPO, RLVR, on-policy 蒸馏, 负例组
  • 摘要：RLVR 已成为 LLM 后训练的标准范式，其中 GRPO 被广泛采用，但它有个硬伤：奖励信号稀疏，一旦组内所有回答拿到相同奖励，梯度就完全消失。On-policy 蒸馏（OPD）能提供稠密的 token 级教师监督，是天然的补救手段，但简单地把 GRPO 和 OPD 拼起来反而会退化。本文提出”在失败处蒸馏”——只对负例组（全错的 group）用自适应教师引导来回收学习信号，兼顾 GRPO 的探索性和 OPD 的稠密监督。
  • 方向标签：#RLHF/后训练

📄 Distill What the Student Can See: Fisher-Projected On-Policy Distillation for Vision-Language Models

  • 作者：Leyan Xue et al.
  • 分类：Machine Learning (cs.LG)
  • 公告日期：2026-08-05
  • 关键词：on-policy 蒸馏, Fisher 投影, VLM, 师生对齐
  • 摘要：On-policy 蒸馏（OPD）从当前学生策略采轨迹，在这些轨迹的前缀上最小化师生 next-token 分布的 token 级散度，好处是蒸馏状态与学生自己的生成分布对齐。但它隐含假设：完整的教师分布在任何学生能力水平下都是合适的目标。在视觉-语言推理中，教师的纠正可能依赖学生根本看不见的视觉区分。本文用 Fisher 投影把教师信号投到学生”能看见”的子空间，只蒸馏学生可学的部分。
  • 方向标签：#推理优化

📄 Practical Online KV Cache Compaction for LLM Agents: An Empirical Study

  • 作者：Yujian Liu et al.
  • 分类：Computation and Language (cs.CL)
  • 公告日期：2026-08-05
  • 关键词：KV cache 压缩, 在线压缩, agent 推理, 长轨迹
  • 摘要：LLM 智能体会积累很长的轨迹（推理步骤、工具调用、环境反馈），KV cache 成为推理的主要瓶颈。KV cache 压缩能降本，但多数已有方法假设上下文是静态的、未来查询已知或可离线近似。智能体场景要求在线压缩：新信息必须在未来相关性未知时就被压掉，且代理查询要足够便宜以放进推理路径。本文是一篇针对 agent 场景在线 KV cache 压缩的系统实证研究。
  • 方向标签：#推理优化

📄 PROGRESS: Coverage-guided RL to Train Search-augmented LLM Agent

  • 作者：Sudipta Paul et al.
  • 分类：Artificial Intelligence (cs.AI)
  • 公告日期：2026-08-05
  • 关键词：搜索增强 agent, 覆盖度奖励, 过程监督, 查询分解
  • 摘要：现有搜索增强 LLM 智能体多用强化学习提升推理能力，但主要依赖结果级奖励，对搜索行为本身几乎没有监督，也忽略了智能体拆解复杂查询的能力。PROGRESS 用教师引导的覆盖度奖励显式地塑造策略模型的子查询生成：训练时冻结的教师模型给出查询分解的覆盖参考，以此提供过程级奖励信号。
  • 方向标签：#长上下文/检索

📄 Curriculum-Guided Layer Scaling for Language Model Pretraining

  • 作者：Karanpartap Singh et al.
  • 分类：Computation and Language (cs.CL)
  • 公告日期：2026-08-05 （arXiv ID 归属 2025-06，本次为新版本/交叉列表公告）
  • 关键词：预训练效率, 课程学习, 层堆叠, 模型生长
  • 摘要：随着 LLM 预训练成本上升，提升这一核心阶段学习效率的策略持续受关注。受人类认知发育启发（大脑逐渐成熟、知识逐步累积），作者提出 Curriculum-Guided Layer Scaling（CGLS）：通过渐进式层堆叠（训练过程中逐步加层）让模型规模增长与数据难度提升同步，实现计算高效的预训练。
  • 方向标签：#数据工程

📄 From Profiling to Synthesis: Benchmarking Implicit Behavioral Alignment in Personalized LLM Agents

  • 作者：Jiajia Song et al.
  • 分类：Artificial Intelligence (cs.AI)
  • 公告日期：2026-08-05
  • 关键词：个性化 agent, 行为对齐, 偏好演化, benchmark
  • 摘要：LLM 已能支撑越来越强的自主智能体，但个性化仍是实用化的关键。近期 benchmark 开始评测智能体个性化，却大多依赖静态偏好快照、固定交互日志，或对预定义用户画像做问答。这类设计无法刻画用户偏好的演化，也忽略了”偏好条件下的任务执行”。本文提出从画像到合成的评测框架，衡量个性化智能体的隐式行为对齐。
  • 方向标签：#Agent

📄 Adversarial Attacks in Multi-Agent LLM Pipelines: Unveiling Structural Vulnerabilities in Agentic AI Architectures

  • 作者：Faisal Haque Bappy et al.
  • 分类：Cryptography and Security (cs.CR)
  • 公告日期：2026-08-05
  • 关键词：多智能体安全, 对抗攻击, 边界验证, agentic 架构
  • 摘要：多智能体 LLM 流水线把多个专用智能体编排成结构化工作流，中间输出在智能体间传递。这带来单智能体场景下不存在的安全缺口：一旦某个智能体接受了对抗性内容，它就会作为”可信输入”在整条流水线里传播。作者认为该漏洞源于缺失”边界验证”这一安全原语——即对跨智能体传递的数据做显式校验。文章系统揭示了 agentic AI 架构的结构性脆弱性。
  • 方向标签：#新架构/Scaling

今日观察

  • On-policy 蒸馏（OPD）成为最密集的战场：HF 热榜的 DAPD 与 arXiv 雷达的两篇（Distill Where You Fail、Fisher-Projected OPD）都在攻同一个问题——教师分布对学生并非天然合适的目标。DAPD 指出”特权幻觉”，Fisher 投影版指出”学生看不见的视觉区分”，GRPO+OPD 版指出”负例组的梯度回收”。三条路径互补，值得连起来读。
  • RLVR 的隐性代价被正面拆解：Verifier-Induced Support Reshaping 提出优化当前目标会挤掉后续目标所需行为的可采样性，这是对 RLVR 长期能力天花板的机制性解释，比单纯刷分的工作更有信息量。
  • Agent 工程化转向”状态与技能”：LongHorizon-Harness（状态解耦）、SKT（技能使用的合成数据训练）、Progressive Agent Skill Generation（RL 生成技能）、在线 KV cache 压缩（长轨迹推理成本）四篇合起来看，长周期 agent 的瓶颈已从”能不能调工具”移到”状态怎么管、技能怎么沉淀、上下文怎么压”。
