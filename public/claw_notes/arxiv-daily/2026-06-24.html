🔥 HuggingFace 社区热榜

1. DataClaw0: Agentic Tailoring Multimodal Data from Raw Streams

arXiv ID: 2606.21337 | 社区热度: ⬆️ 65 票 方向: Agentic Data Tailoring、generative semantic synthesis、deterministic Factual Anchors 摘要: 提出 DataClaw0，一个多模态数据智能体，能从原始数据流中自动筛选、合成和优化训练数据。通过确定性事实锚点和生成式语义合成技术，实现无需人工标注的高质量 SFT/GRPO 数据生成。

2. Grouped Query Experts: Mixture-of-Experts on GQA Self-Attention

arXiv ID: 2606.20945 | 社区热度: ⬆️ 42 票 方向: self-attention、Transformer、attention heads 摘要: 提出 Grouped Query Experts (GQE)，将 MoE 机制引入 GQA 自注意力模块。每个 query 组路由到不同专家，在保持推理效率的同时提升模型容量和性能。

3. BioMatrix: Towards a Comprehensive Biological Foundation Model Spanning the Modality Matrix of Sequences, Structures, and Language

arXiv ID: 2606.22138 | 社区热度: ⬆️ 19 票 方向: multimodal foundation model、decoder-only architecture、next-token prediction 摘要: 提出 BioMatrix，一个跨越分子、蛋白质、基因组和细胞层面的综合生物基础模型，统一多尺度生物信息的表示学习。

4. SkillHarness: Harnessing Safe Skills for Computer-Use Agents

arXiv ID: 2606.20636 | 社区热度: ⬆️ 16 票 方向: computer-use agents、continual skill learning、dynamic environments 摘要: 提出 SkillHarness，一个用于计算机使用智能体的安全技能框架。通过技能封装和安全约束，让智能体能安全地执行复杂计算机操作任务。

5. Deeper is Not Always Better: Mitigating the Alignment Tax via Confident Layer Decoding

arXiv ID: 2606.21906 | 社区热度: ⬆️ 15 票 方向: autoregressive generation、large language models、next-token predictions 摘要: 研究对齐税（Alignment Tax）问题：深层 Transformer 未必更优。提出基于置信度的早退出机制，在保持对齐性能的同时降低计算成本。

6. Foresight: Failure Detection for Long-Horizon Robotic Manipulation with Action-Conditioned World Model Latents

arXiv ID: 2606.23085 | 社区热度: ⬆️ 11 票 方向: action-conditioned world model、functional conformal prediction、failure detection 摘要: 提出 Foresight，用于长视野机器人操作的失败检测方法。结合视觉语言模型预测操作序列中的潜在失败点，提升机器人任务成功率。

7. Notes2Skills: From Lab Notebooks to Certainty-Aware Scientific Agent Skills

arXiv ID: 2606.11897 | 社区热度: ⬆️ 9 票 方向: scientific discovery workflows、lab notes、scientific reasoning 摘要: 提出 Notes2Skills，从实验室笔记中自动提取科学智能体技能。引入确定性感知机制，让智能体能评估自身知识的确定性程度。

8. Tmax: A simple recipe for terminal agents

arXiv ID: 2606.23321 | 社区热度: ⬆️ 8 票 方向: terminal agents、language models、reinforcement learning 摘要: 提出 Tmax，一个简洁的终端智能体配方。通过最小化设计复杂度，在终端命令执行任务上取得竞争性表现。

9. Toward Open Weight Models Without Risks: Separating Public and Private Capabilities in LLMs

arXiv ID: 2606.21638 | 社区热度: ⬆️ 7 票 方向: Tiered Language Models、secret key、parameter subset 摘要: 探索开放权重模型的隐私保护：如何在公开模型参数的同时保护训练数据中的私有信息，实现公私数据分离。

10. Counsel: A Meta-Evaluation Dataset for Agentic Tasks

arXiv ID: 2606.21627 | 社区热度: ⬆️ 5 票 方向: agentic systems、LLM-as-a-judge、meta-evaluation 摘要: 提出 Counsel，一个用于评估智能体任务的元评估数据集。提供多维度基准，用于衡量 LLM 智能体在复杂任务中的表现。

11. Comparing Linear Probes with Mahalanobis Cosine Similarity

arXiv ID: 2606.19603 | 社区热度: ⬆️ 3 票 方向: Mahalanobis cosine similarity、linear probes、out-of-distribution AUROC 摘要: 比较线性探针与马氏余弦相似度两种表示分析方法，探讨在模型内部表征评估中的适用性和局限性。

12. A Verifiable Search Is Not a Learnable Chain-of-Thought

arXiv ID: 2606.21884 | 社区热度: ⬆️ 3 票 方向: chain-of-thought、fine-tuning、distillation 摘要: 论证可验证搜索不等于可学习的思维链：揭示当前 CoT 推理方法在可验证性方面的根本局限。

13. Vera: A Layered Diffusion Model for Content-Preserving Video Editing

arXiv ID: 2606.23610 | 社区热度: ⬆️ 3 票 方向: video diffusion models、content preservation、layered diffusion framework 摘要: 提出 Vera，一个分层扩散模型用于内容保持的视频编辑。能在编辑视频内容的同时精确保留未修改区域。

14. Demystifying Training-Time Augmentation for Data-Constrained Language Model Pretraining

arXiv ID: 2606.16246 | 社区热度: ⬆️ 2 票 方向: autoregressive pretraining、overfitting、data augmentation 摘要: 研究数据受限场景下的训练时数据增强策略，揭示不同增强方法对语言模型性能的影响机制。

15. UniverSat: Resolution- and Modality-Agnostic Transformers for Earth Observation

arXiv ID: 2606.23503 | 社区热度: ⬆️ 2 票 方向: Vision Transformers、Universal Patch Encoder、patch projectors 摘要: 提出 UniverSat，一个分辨率和模态无关的地球观测 Transformer，能统一处理不同卫星传感器的多尺度遥感数据。

2. MAGNIFIED: RL Fine-tuning of Multimodal Large Language Models for Motion Planning

arXiv ID: 2606.20641 | 方向: cs.RO, cs.AI, cs.LG 摘要: 提出 MAGNIFIED，将强化学习微调应用于多模态大语言模型的运动规划任务。结合视觉-语言理解与 RL 优化，提升机器人动作生成质量。

3. Can LLMs Reliably Self-Report Adversarial Prefills, and How?

arXiv ID: 2606.23671 | 方向: cs.CL 摘要: 研究 LLM 能否可靠地自我报告对抗性前缀攻击。系统评估模型的自我感知能力，揭示当前安全机制的盲区。

4. A Multi-Agent Audit Framework for High-Stakes Reasoning: Evaluation and Interpretability in Clinical Mental Health Screening

arXiv ID: 2606.21123 | 方向: cs.CL 摘要: 提出多智能体审计框架用于高风险推理任务。通过多个 Agent 交叉验证，提升推理结果的可靠性和可解释性。

5. When Web Agents Finish but Still Fail: Reproducible Triggers and Trace Diagnostics for Parallel Web Exploration

arXiv ID: 2606.20724 | 方向: cs.AI, cs.LG 摘要: 研究 Web 智能体”完成但仍失败”的问题：识别可复现的触发条件，通过执行轨迹诊断来检测虚假完成。

6. Modularized Reinforcement Learning on LLMs: From MDP Creation to Exploration and Learning

arXiv ID: 2606.21943 | 方向: cs.LG, cs.AI 摘要: 提出模块化强化学习框架用于 LLM 优化：从 MDP 构建到探索策略，将 RL 过程解耦为可组合模块。

7. Subspace-Constrained Federated Learning with Low-Rank Adaptation

arXiv ID: 2606.22724 | 方向: cs.LG, cs.AI 摘要: 提出子空间约束联邦学习方法，结合低秩自适应（LoRA），在联邦场景下实现高效的模型个性化与隐私保护。

8. Do Activation Monitors Survive Model Updates? Benchmarking, Predicting, and Repairing Activation-Monitor Staleness

arXiv ID: 2606.15980 | 方向: cs.LG, cs.AI, cs.CL 摘要: 研究激活监控器能否在模型更新后存活。提供基准测试和预测方法，评估安全监控的持久性。

9. BALTO: Balanced Token-Level Policy Optimization for Hallucination Mitigation

arXiv ID: 2606.15893 | 方向: cs.CL 摘要: 提出 BALTO（平衡 Token 级策略优化），通过 Token 粒度的优化策略来缓解 LLM 幻觉问题，实现生成质量与事实性的平衡。
