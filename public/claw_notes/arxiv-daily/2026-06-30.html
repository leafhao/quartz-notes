1. PhysisForcing: Physics Reinforced World Simulator for Robotic Manipulation

arXiv ID: 2606.28128 | 社区热度: ⬆️ 39 票
方向: video generation models, embodied world simulation
摘要: PhysisForcing 通过像素级轨迹对齐损失和语义级关系对齐损失，增强具身视频生成的物理一致性。该方法利用 DiT 特征进行视频理解编码，在 R-Bench 和 PAI-Bench 上显著提升了机器人操作任务的模拟真实度。

2. Formalizing Latent Thoughts: Four Axioms of Thought Representation in LLMs

arXiv ID: 2606.27378 | 社区热度: ⬆️ 36 票
方向: axiomatic evaluation framework, latent thought representations
摘要: 提出了一个公理化评估框架，揭示了 LLM 潜在思维表征中的系统性缺陷。通过四个功能公理（忠实性、因果性、组合性和可传递性），定量分析了 LLM 在推理过程中思维链表征的质量和局限性。

3. Translation as a Bridging Action: Transferring Manipulation Skills from Humans to Robots

arXiv ID: 2606.28133 | 社区热度: ⬆️ 33 票
方向: bi-manual manipulation, vision-language-action model
摘要: 提出一种”桥接动作”表征方法，将人类操作技能更高效地迁移到机器人。通过交错动作标记和视觉-语言-动作模型，实现了从人类灵巧手到平行夹爪的双手操作技能迁移，无需额外机器人演示数据。

4. Qwen-Image-2.0-RL Technical Report

arXiv ID: 2606.27608 | 社区热度: ⬆️ 27 票
方向: reinforcement learning from human feedback, on-policy distillation
摘要: 通过强化学习和在策略蒸馏方法，提升视觉-语言模型的图像生成质量和指令遵循能力。采用逐点评分范式进行 RLHF，结合在策略数据蒸馏，在视觉生成任务上取得了显著进步。

5. MultiHashFormer: Hash-based Generative Language Models

arXiv ID: 2606.28057 | 社区热度: ⬆️ 16 票
方向: language models, embedding matrices, parameter efficiency
摘要: MultiHashFormer 通过将 token 表示为哈希码组合，实现了基于哈希的自回归语言模型。该方法消除了传统大规模嵌入矩阵的需求，在保持生成质量的同时显著降低了参数量和词表规模对模型大小的约束。

6. SingGuard: A Policy-Adaptive Multimodal LLM Guardrail with Dynamic Reasoning

arXiv ID: 2606.22873 | 社区热度: ⬆️ 11 票
方向: vision-language models, multimodal guardrail, safety
摘要: SingGuard 是一个策略自适应的多模态安全护栏系统，能在实时对话中动态推理和评估安全风险。系统根据不同部署场景的安全策略自动调整判断标准，在多模态内容安全评估中表现优异。

7. The Tatoxa System for Text Detoxification in Low-Resource Languages

arXiv ID: 2606.26015 | 社区热度: ⬆️ 9 票
方向: text detoxification, low resource languages
摘要: Tatoxa 是面向鞑靼语的文本去毒化系统，展示了在低资源语言场景下的优越性能。通过对比实验验证了多种去毒化策略在非英语低资源环境中的效果，为多语言安全内容生成提供了实践参考。

8. GBC: Gradient-Based Connections for Optimizing Multi-Agent Systems

arXiv ID: 2606.28187 | 社区热度: ⬆️ 8 票
方向: multi-agent systems, large language models, credit assignment
摘要: 基于梯度连接（GBC）方法实现了多 Agent 系统中的细粒度归因和优化。通过构建计算图追踪 Agent 间的信息传递和决策贡献，解决了多智能体协作中长期存在的信用分配问题。

9. ProMSA: Progressive Multimodal Search Agents for Knowledge-Based VQA

arXiv ID: 2606.27974 | 社区热度: ⬆️ 7 票
方向: multimodal search agent, retrieve-then-generate pipeline
摘要: 渐进式多模态搜索 Agent 用于知识增强的视觉问答任务，自适应地管理工具调用预算。相比传统检索-生成流水线，该方法通过逐步细化搜索策略，在保持效率的同时提高了知识获取的精准度。

10. SimFoundry: Modular and Automated Scene Generation for Policy Learning

arXiv ID: 2606.28276 | 社区热度: ⬆️ 6 票
方向: real-to-sim, digital twins, zero-shot transfer
摘要: SimFoundry 通过自动化模拟场景构建实现零样本真实世界机器人策略训练。采用模块化方法从真实场景自动生成数字孪生仿真环境，支持机器人在完全合成数据上学习可迁移策略。

11. Vesta: A Generalist Embodied Reasoning Model

arXiv ID: 2606.20905 | 社区热度: ⬆️ 4 票
方向: embodied generalist, foundation model, spatial grounding
摘要: Vesta 是一个统一的具身通才模型，集成了定位、空间推理、导航和操作能力。作为具身基础模型，它在单一架构内实现了多种空间理解任务的协同，为通用具身智能提供了新范式。

12. Parallel Rollout Approximation for Pixel-Space Autoregressive Image Generation

arXiv ID: 2606.27978 | 社区热度: ⬆️ 4 票
方向: autoregressive generation, pixel-space
摘要: 并行展开近似（PRA）解决了像素空间自回归图像生成中的效率瓶颈。通过在连续 token 空间中实现并行解码，显著加速了高分辨率图像的自回归生成过程，同时保持了生成质量。

arXiv ID: 2606.27632 | 发布时间: 2026-06-30
方向: cs.CL

2. From Detection to Action: Using LLM Agents for Fault-Tolerant Control

arXiv ID: 2606.28011 | 发布时间: 2026-06-30
方向: eess.SY

3. Internalizing the Future: A Unified Agentic Training Paradigm for World Model Planning

arXiv ID: 2606.27483 | 发布时间: 2026-06-30
方向: cs.AI

4. LLawCo: Learning Laws of Cooperation for Modeling Embodied Multi-Agent Behavior

arXiv ID: 2606.28182 | 发布时间: 2026-06-30
方向: cs.LG
摘要: 学习合作法则以建模具身多智能体行为。在去中心化和部分可观测环境中，提出从观察数据中自动发现协作规则的方法，使多智能体系统能自主发展出高效的合作策略。

5. HPRO: Hierarchical Progressive Reward Optimization via Preference Extraction

arXiv ID: 2606.28249 | 发布时间: 2026-06-30
方向: eess.AS
摘要: 通过偏好提取实现分层渐进式奖励优化。将该方法应用于基于 LLM 的文本转语音模型，通过多层次的偏好学习逐步优化生成质量，在自然度和表达力上取得了显著提升。

6. Enhancing Numerical Prediction in LLMs via Smooth MMD Alignment

arXiv ID: 2606.27731 | 发布时间: 2026-06-30
方向: cs.CL
摘要: 通过平滑 MMD 对齐增强 LLM 的数值预测能力。尽管 LLM 具有强大的通用能力，但在数值推理任务中仍不可靠。本文提出的对齐方法通过最大均值差异优化，显著提升了模型在数值预测任务上的准确性。

7. Learning to Reason with Curriculum II: Compositional Generalization

arXiv ID: 2606.27721 | 发布时间: 2026-06-30
方向: cs.LG
摘要: 课程学习推理系列第二篇：组合泛化。研究模型通过组合简单问题的解来解决复杂问题的能力，提出了针对组合推理的课程训练策略，在推理链的组合性泛化上取得了突破性进展。

8. Cognitive Episodes in LLM Reasoning Traces Enable Interpretable Hallucination Detection

arXiv ID: 2606.28186 | 发布时间: 2026-06-30
方向: cs.CL
摘要: 利用 LLM 推理痕迹中的认知片段实现可解释的幻觉检测。通过分析推理过程中的认知状态转变模式，识别出导致幻觉生成的关键节点，为 LLM 可信度评估提供了新的可解释方法。
