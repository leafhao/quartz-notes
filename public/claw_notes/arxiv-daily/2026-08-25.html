arXiv 论文日报 | 2026-08-25

今日主线：RLVR 奖励噪声诊断 + SFT 事实性退化修复 + 推理加速（自投机 / CoT 记忆压缩） + 压缩后模型愈合。Agent 侧记忆管理与 RAG 归因也集中出现。

🔥 HuggingFace 热榜（社区策展）

📄 Let’s Scale Step by Step: Compute-Efficient Hyperparameter Transfer for Large-Scale Mixture-of-Experts

  • 作者：Nayeon Kim, Hojin Lee, Yunju Bak et al.
  • 关键词：MoE, 超参迁移, 学习率, scaling
  • 摘要：MoE 架构能在算力不成比例增长的前提下大幅扩容，但在极端模型规模与 token 预算下用网格搜索调学习率的成本不可承受。本文提出两阶段、算力友好的超参迁移框架：先跨模型宽度迁移最优学习率，再外推到万亿级 token 预算，从而无需大规模 sweep 即可预测大 MoE 的最优 LR。
  • 票数：32 👍
  • 方向标签：#预训练 MoE ScalingLaw

📄 Graph Engineering in the Era of LLM Agents: From Individual Intelligence to System Intelligence

  • 作者：Yuyuan Feng, Zhishang Xiang, Chaobin Yang et al.
  • 关键词：LLM agent, 多智能体, 图工程, 系统智能
  • 摘要：LLM 已从语言生成器演化为能完成长程复杂任务的自主智能体，围绕它形成了 Prompt / Context / Harness / Loop 四类工程范式。但单体智能有天花板：异构专长、相互依赖的子任务、并行执行都难以由单个 agent 承担。本文提出用「图工程」把 agent 系统显式建模为图结构，从个体智能走向系统智能。
  • 票数：30 👍
  • 方向标签：#Agent 系统架构

📄 OmniAssistBench: Assistant-style Interaction Benchmark for Omni-LLMs

  • 作者：Xianyun Sun, Chaoyou Fu, Zhengye Zhang et al.
  • 关键词：Omni-LLM, 交互式评测, benchmark
  • 摘要：全模态大模型有潜力做实时助手：持续感知环境并引导用户达成目标。这与被动视频理解不同，需要主动结合视觉状态、用户目标与先验知识。难点在于评测——模型的回应会改变用户后续动作，静态离线数据集无法容纳这种动态。本文构建了可交互的助手式评测基准填补这一空白。
  • 票数：26 👍
  • 方向标签：#评测 多模态

📄 AgentMercury: Your Agent Can Synthesize Verifiable Environments for Business Scenarios at Scale

  • 作者：Minbyul Jeong, Chanwoong Yoon
  • 关键词：环境合成, 可验证奖励, agent 训练
  • 摘要：Agent 通过与环境交互学习，但训练环境多为人工构造或围绕既有 benchmark 合成，这种「任务中心」范式难以扩展到真实、持续演化的工作流。AgentMercury 反过来做：从高层业务场景合成可执行环境，让多样任务从这个「世界」里自然涌现，而非为单一任务定制环境。
  • 票数：6 👍
  • 方向标签：#数据工程 Agent 可验证奖励

📄 Llama-Mobile: Efficient 2.7-Bit Quantization of VLMs

  • 作者：Luka Ribar, Jeevan Bhoot, Douglas Orr et al.
  • 关键词：量化, 2.7-bit, 端侧推理, Arm CPU
  • 摘要：VLM 上移动端受内存与算力限制。本文的量化流水线用模型自身生成校准数据、不需要访问原训练配置，并提出一种每参数 2.7 bit 的新格式，可在 Arm CPU 上高效执行。将 Llama 3.2 11B Vision Instruct 压到 3.7 GB 验证了可行性。
  • 票数：5 👍
  • 方向标签：#推理优化 量化

📄 CLEAR: Continuous Latent Adapter Routing for Utility-Preserving LLM Safety Alignment

  • 作者：Chengxiao Wang, Enyi Jiang, Xiaojing Liao et al.
  • 关键词：安全对齐, LoRA 路由, 效用保持
  • 摘要：提升安全性常牺牲通用能力，因为全局安全微调会同时改变模型对有害和无害输入的响应。CLEAR 用一个轻量的隐状态门控连续调节安全 LoRA 适配器的激活强度，只在需要时介入，从而在压低有害回答的同时尽量不动冻结主干、不伤无害提问上的表现。
  • 票数：2 👍
  • 方向标签：#对齐与安全 参数高效

🔍 arXiv 关键词雷达（新方向探测）

📄 Multilingual Verifier Bias in RLVR: Benchmark, Rollout Diagnosis, and the Cross-Lingual Selection Bottleneck

  • 作者：Chenyu Zhou, Qiliang Jiang, Xu Zhou et al.
  • 提交日期：2026-08-25 (cs.CL)
  • 摘要：RLVR 已是训练数学推理的标准配方，其中答案验证器被当成「与语言无关」的奖励函数。本文指出这个假设在多语言场景下失效：精确匹配验证器会把格式与文字系统差异转化成依赖语言的假阴性奖励噪声。作者给出一套可复用的多语言 RLVR 奖励审计协议——验证器鲁棒性测试集、rollout 诊断流程、语言条件化的奖励误差指标，并揭示跨语言选择瓶颈。
  • 方向标签：#RLHF RLVR 后训练优化

📄 Knowing but Not Saying: Preventing Factual Access Failures in LLM SFT via Recall-Anchored Distillation

  • 作者：Haodong Chen, Yadong Wang, Shengtao Wen et al.
  • 提交日期：2026-08-25 (cs.AI)
  • 摘要：领域 SFT 会损伤目标域外的事实性表现，通常被归因为灾难性遗忘。但本文识别出更具体的现象——「事实可达性失效」：SFT 后模型在受限评测（选择题/排序）中仍能认出正确答案，却在闭卷开放生成中说不出来。也就是知识没被擦除，只是取不到。作者据此提出召回锚定蒸馏来恢复这条通路。
  • 方向标签：#SFT 灾难性遗忘 蒸馏

📄 Memory Augmentation Unlocks Efficient Chain-of-Thought Reasoning

  • 作者：Simeng Zhang, Yilong Chen, Wenyuan Zhang et al.
  • 提交日期：2026-08-25 (cs.CL)
  • 摘要：CoT 提升复杂任务表现，但冗长的推理轨迹带来可观推理开销；激进压缩又会破坏逻辑连贯性。本文把这个权衡形式化为「上下文-生成替代律」：显式推理上下文可以替代一部分解码期生成。基于此提出免训练的记忆增强压缩框架，用构造好的记忆承载被压掉的推理步骤。
  • 方向标签：#推理优化 CoT压缩

📄 Self-Speculation for Faster Reasoning Models

  • 作者：Ravisri Valluri, Tung Nguyen, Aditya Grover et al.
  • 提交日期：2026-08-25 (cs.CL)
  • 摘要：长推理轨迹对语音助手、编码 agent 这类延迟敏感场景很不友好。现有加速方法多停留在 token 级，没利用推理工作流本身的结构。本文提出 SSR（Self-Speculation for Reasoning），在推理流程层面做自投机，用模型自身的粗粒度轨迹预测来跳步加速。
  • 方向标签：#推理优化 投机解码

📄 Quantization-Aware Healing: A Practical Recipe for Recovering Compressed, 4-Bit LLMs

  • 作者：Bakbergen Ryskulov, Iker García-Ferrero, David Montero et al.
  • 提交日期：2026-08-25 (cs.CL)
  • 摘要：低成本服务往往意味着模型既被结构化剪枝到一小部分参数、又量化到 4 bit，两步叠加会明显损伤推理、数学、代码与长上下文能力，部署前需要「愈合」阶段。默认做法 QAT 用硬标签重拟合，作者实测收敛慢且过峰后崩塌；改用 QAH（量化感知愈合）后表现更稳，给出了可落地的配方。
  • 方向标签：#推理优化 量化 剪枝

📄 Weighted Memory Tree: Remembering What Matters for Long-Horizon LLM Agents

  • 作者：Quang Dao, Purvi Kathalkar, Kenneth Eaton et al.
  • 提交日期：2026-08-25 (cs.AI)
  • 摘要：长程 agent 的执行历史不断膨胀，既抬高推理成本，也让过时、无关、误导性信息污染推理。已有记忆方案侧重组织或压缩历史，但缺少「哪些记忆该保持激活」的判定机制。本文提出加权记忆树，把执行过程按任务/子任务分层组织并加权，显式决定记忆的激活与淘汰。
  • 方向标签：#Agent 长上下文 记忆管理

📄 TRACE-Memory: Public-Conditioned Retrieval and Utility-Aware Evidence Admission for Personalized Generation

  • 作者：Jing Wang, Zhu Wang, Yifan Guo et al.
  • 提交日期：2026-08 (cs.AI，本次新交叉挂载)
  • 摘要：个性化生成系统按「请求-记忆相关性」检索用户历史注入上下文，但相关的历史可能指向错误的偏好维度、重复公共信息，或支撑不足。作者主张：只有当个人记忆带来超出「纯公共信息回答」的增益时才应使用。TRACE-Memory 分两阶段——先定位请求与公共上下文中缺失的用户特定信息，再做覆盖导向的候选检索与效用感知的证据准入。
  • 方向标签：#RAG 个性化 记忆管理

📄 DFM Mimir v1: An Open HRM Delivering Frontier Performance at 1B Parameters Using Only Permissible Post-Training Data

  • 作者：Peter Schneider-Kamp, Jacob Nielsen, Gianluca Barmina et al.
  • 提交日期：2026-08 (cs.CL，本次新交叉挂载)
  • 摘要：当前大模型研发依赖海量且常常授权不清的数据，对坚持开源与合规数据的研究者构成高门槛。Mimir v1 是基于 HRM（分层推理模型）架构从零训练的 10 亿参数模型，仅用授权合规的后训练数据（161 个数据集混合），英文表现有竞争力、丹麦语创下新 SOTA，超过原始 HRM-Text 基线。
  • 方向标签：#后训练 数据工程 小模型

📄 Truth Lies Deep: Countering Semantic Camouflage via Latent Intent Verification

  • 作者：Md. Hasib Ur Rahman
  • 提交日期：2026-08-25 (cs.CL)
  • 摘要：LLM 的安全对齐常是「表层」的：拒答机制只在生成末段触发，并未消除预训练期获得的有害概念知识。这种架构性脱节使模型易被「语义伪装」攻破——把有害意图包裹进无害叙事（如创意写作）绕过输入输出护栏。作者分析潜层激活轨迹，提出在潜空间做意图验证而非只看输出。
  • 方向标签：#对齐与安全 越狱防御

📄 Why2Speak: Faithful Reasoning for Abstaining Action Policies

  • 作者：Shreya Mendi, Brinnae Bent
  • 提交日期：2026-08-25 (cs.AI)
  • 摘要：许多 agent 系统需反复在「行动」与「弃权」间选择，此时忠实推理对可监督性至关重要——解释只有反映真实产生动作的计算过程才有用。作者以多方对话中的插话时机为研究场景（助手决定是否发言），暴露类别不平衡、动作代价不对称，以及「暴露推理本身会改变被审计策略」的问题，在 Qwen3-8B 上对比了带/不带 CoT 解码。
  • 方向标签：#Agent 可解释性 对齐

📄 When Failures Propagate: Causal Failure Attribution in Agentic Retrieval-Augmented Generation

  • 作者：Lauren Pothuru
  • 提交日期：2026-08-25 (cs.CL)
  • 摘要：Agentic RAG 把检索、推理、生成交织成多跳流程，第 1 跳的检索错误可能只在第 3 跳表现为答案错误，而后续检索也可能修复轨迹。本文提出 AgenticRAG-FP 干预式基准：在指定跳注入认证故障、重跑下游轨迹，再用已知干预去检验各类归因诊断器是否找得对。
  • 方向标签：#RAG 可靠性 归因分析

📄 EnSI-RAG: Entity-Structure-Indexed Retrieval-Augmented Generation for Long-Document Question Answering

  • 作者：Xuanyu Meng, Jiashuo Sun, Jash Rajesh Parekh et al.
  • 提交日期：2026-08-25 (cs.CL)
  • 摘要：长文档 QA 的证据往往横跨多个实体及其关系。常规 RAG 把文档切成原始 chunk 靠 embedding 相似度召回，一旦 chunk 边界把实体与支撑证据切开，或问题需要多跳推理，效果就下滑。EnSI-RAG 构建实体-结构索引替代纯 chunk 索引来缓解这两个问题。
  • 方向标签：#RAG 长上下文
