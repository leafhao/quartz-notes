1. DiSCTT: 基于共识引导的自适应测试时优化框架

标签: LLM Reasoning RLHF RAG

arXiv ID: 2603.05357

作者: Mohammad Mahdi Moradi, Sudhir Mudur

摘要: 提出了一种难度感知、共识引导的自课程框架 DiSCTT，用于大语言模型的测试时适应。该方法通过采样推理轨迹的一致性来估计实例级认知不确定性，动态分配优化策略：高共识输入使用监督微调，低共识输入使用带共识正则化的强化学习。在数学和通用推理基准上，DiSCTT 在准确率、方差和计算效率上均优于现有方法。

亮点:

  • 显式建模实例难度和不确定性
  • 结合监督学习和强化学习的混合优化策略
  • 显著降低计算成本和训练时间

2. 无检索的 LLM 事实核查

标签: LLM Agent RAG

arXiv ID: 2603.05471

作者: Artem Vazhentsev, Maria Marina, Daniil Moskovskiy 等

摘要: 提出了无需外部检索的事实核查任务，专注于利用 LLM 的内在参数知识进行事实验证。引入了 INTRA 方法，通过利用内部表示之间的交互实现 SOTA 性能。在 9 个数据集上的实验表明，基于 logit 的方法通常不如利用内部模型表示的方法。

亮点:

  • 摆脱对外部检索的依赖
  • 可作为训练时的奖励信号或生成过程的组件
  • 在长尾知识、多语言、长文本生成等场景下表现出色

3. 分布式部分信息拼图：认知不对称下的共同基础构建

标签: LLM Multimodal Reasoning

arXiv ID: 2603.05450

作者: Yifan Zhu, Mariah Bradford, Kenneth Lai 等

摘要: 引入了分布式部分信息拼图（DPIP）任务，用于研究认知不对称条件下的多模态协作。提供了一个跨语音、手势和动作模态的时序对齐数据集。评估了两种建模范式：SOTA LLM 和基于动态认知逻辑（DEL）的公理化管道。结果表明现代 LLM 在追踪任务进展和信念状态方面仍面临挑战。

亮点:

  • 多模态、多方协作场景
  • 认知不对称下的共同基础构建
  • 结合符号推理和神经方法

4. InfoFlow KV: 信息流感知的长上下文 KV 重计算

标签: LLM RAG Transformer

arXiv ID: 2603.05353

作者: Xin Teng, Canyu Zhang, Shaoyi Zheng 等

摘要: 将选择性 KV 重计算问题建模为信息流问题，提出了一种基于注意力范数的信号来识别语义相关且结构上能够传播信息的 token。引入了信息流引导的 chunk 重排序策略。在 LLM 和 VLM 基准上，在相当的效率预算下实现了一致的性能提升。

亮点:

  • 解决长上下文 RAG 的推理瓶颈
  • 信息流建模而非启发式方法
  • 适用于 LLM 和 VLM

5. SAIL: 弱监督密集视频描述的相似性感知引导学习

标签: LLM Multimodal

arXiv ID: 2603.05437

作者: Ye-Chan Kim, SeungJu Cha, Si-Woo Kim 等

摘要: 提出 SAIL 框架，通过跨模态对齐构建语义感知的掩码。引入基于 LLM 的增强策略生成合成字幕，提供额外的对齐信号。在 ActivityNet Captions 和 YouCook2 上实现了 SOTA 性能。

亮点:

  • LLM 辅助数据增强
  • 语义感知的时序定位

6. FlashAttention-4: 针对 Blackwell GPU 的算法与内核协同设计

标签: LLM Transformer

arXiv ID: 2603.05451

作者: Ted Zadouri, Markus Hoehnerbach, Jay Shah 等

摘要: 针对 Blackwell GPU（B200/GB200）的非对称硬件扩展特性，开发了 FlashAttention-4。通过重新设计的流水线、软件模拟的指数运算和条件 softmax 重缩放，以及利用 tensor memory 和 2-CTA MMA 模式，实现了相比 cuDNN 9.13 最高 1.3 倍、相比 Triton 最高 2.7 倍的加速，在 B200 GPU 上达到 1613 TFLOPs/s（71% 利用率）。

亮点:

  • 针对最新 Blackwell 架构优化
  • 使用 CuTe-DSL 实现，编译速度提升 20-30 倍
  • 显著的性能提升

7. 低参数 LLM 的词义消歧推理框架

标签: LLM Reasoning

arXiv ID: 2603.05400

作者: Deshan Sumanathilaka, Nicholas Micallef, Julian Hough

摘要: 研究低参数 LLM（<4B 参数）是否能通过推理驱动的微调策略在词义消歧（WSD）任务上达到高参数模型的性能。使用增强的 FEWS 数据集微调 8 个小规模开源 LLM。结果表明，基于 CoT 的推理结合邻近词分析可以达到 GPT-4-Turbo 零样本性能。Gemma-3-4B 和 Qwen-3-4B 在 FEWS 上超越所有中等参数基线和 SOTA 模型。

亮点:

  • 小模型通过推理增强达到大模型性能
  • 显著降低计算和能源需求
  • 强跨域泛化能力

8. Judge Reliability Harness: LLM 评判者可靠性压力测试

标签: LLM Agent

arXiv ID: 2603.05399

作者: Sunishchal Dev, Andrew Sloan, Joshua Kavner 等

摘要: 提出了 Judge Reliability Harness，一个用于构建验证套件以测试 LLM 评判者可靠性的开源库。在 4 个基准上评估了 4 个 SOTA 评判者，发现在不同模型和扰动类型下性能存在显著差异。初步实验揭示了由于简单文本格式变化、改写、冗余度变化和标签翻转导致的一致性问题。

亮点:

  • 系统化的 LLM 评判者可靠性测试
  • 开源工具库
  • 揭示现有评判者的脆弱性

9. Progressive Residual Warmup: 语言模型预训练的渐进式残差预热

标签: LLM Transformer

arXiv ID: 2603.05369

作者: Tianhao Chen, Xin Xu, Lu Yin 等

摘要: 提出 Progressive Residual Warmup (ProRes)，实现”早期层先学习”的理念。通过将每层的残差乘以一个从 0 到 1 逐渐预热的标量，深层需要更长的预热步数。在多种模型规模、归一化和初始化方案下的预训练实验表明，ProRes 不仅稳定了预训练，还引入了独特的优化轨迹，带来更快的收敛、更强的泛化和更好的下游性能。

亮点:

  • 基于层级依赖的训练策略
  • 提升训练稳定性和收敛速度
  • 适用于多种架构配置
