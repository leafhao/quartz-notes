📰 arXiv 论文推送 | 2026-05-19

时间窗口：最近 7 天（2026-05-12 ~ 2026-05-19） 来源：arXiv cs.AI 新提交（browser fallback，因 API 持续 429） 共筛选 12 篇，主要方向：多智能体系统、RLHF/自我批评、Agent Skills 编译、自演化代码生成、可验证 Agent 治理

🌟 亮点速览

  1. ICRL — 学习内化自我批评的强化学习（13 May） 首个把 critique-induced 改进通过 RL 内化到模型自身能力的框架，Qwen3-8B critic 媲美 32B critic。代理任务 +6.4 / 数学推理 +7.0。

  2. SkillSmith — 把 Agent 技能编译成边界化运行时接口（12 May） 提出 boundary-first compiler-runtime，通过离线编译技能包，把 token 消耗降 57%、思考迭代降 43%、求解时间降 50%。

  3. Solvita — Agentic 进化框架（14 May） 不更新权重的持续学习，4 个专门 agent + 可训练图状知识网络。在 CodeContests / APPS / Codeforces 实测达 SOTA，单次基线翻倍。

📚 论文列表（按提交时间倒序）

1. Belief Engine: Configurable and Inspectable Stance Dynamics in Multi-Agent LLM Deliberation

  • arXiv ID: 2605.15343 · PDF
  • 作者: Joshua C. Yang, Maurice Flechtner, Damian Dailisan, Michiel A. Bakker
  • 提交日期: 2026-05-14
  • 摘要: 提出可审计的 belief-update 层 BE，把”信念”建模为命题的证据状态，通过 log-odds 规则（evidence uptake u + prior anchoring a）暴露 scalar stance。在 DEBATE 数据集上能区分证据驱动的立场变化与锚定/角色漂移。

2. Zero-Shot Goal Recognition with Large Language Models

  • arXiv ID: 2605.15333 · PDF
  • 作者: Kin Max Piamolini Gusmão, Nathan Gavenski, Nir Oren, Felipe Meneguzzi
  • 提交日期: 2026-05-14
  • 摘要: 首次系统评估前沿 LLM 作为零样本目标识别器在经典 PDDL 基准上的表现。发现 LLM 在目标识别上能力差异巨大：部分模型能随证据扩展接近 landmark-based 精度，部分则始终被先验世界知识锚定。

3. Context Pruning for Coding Agents via Multi-Rubric Latent Reasoning

  • arXiv ID: 2605.15315 · PDF
  • 作者: Jingjing Wang, Xiwen Chen, Wenhui Zhu, Huayu Li, Zhengxiao He, Feiyang Cai 等
  • 提交日期: 2026-05-14
  • 摘要: 把代码相关性分解为”语义证据”和”依赖支撑”两个维度，每个用独立 CRF 建模 + MoE gating 融合。SWE-Bench Verified 等 4 个基准上 12/16 头对头胜出，多轮任务多省 31% token，单轮 EM +3.5。

4. SMCEvolve: Principled Scientific Discovery via Sequential Monte Carlo Evolution

  • arXiv ID: 2605.15308 · PDF
  • 作者: Jiachen Jiang, Huminhao Zhu, Zhihui Zhu
  • 提交日期: 2026-05-14
  • 摘要: 把程序进化重构为对 reward-tilted 目标分布的采样，用 SMC 采样器逼近，给出有限样本复杂度分析。在数学、算法、符号回归与端到端 ML 研究基准上以更少 LLM 调用超越 SOTA。

5. ⭐ Solvita: Enhancing LLMs for Competitive Programming via Agentic Evolution

  • arXiv ID: 2605.15301 · PDF
  • 作者: Han Li, Jinyu Tian, Rili Feng, Yuqiao Du, Chong Zheng, Chenyu Wang 等
  • 提交日期: 2026-05-14
  • 摘要: Planner / Solver / Oracle / Hacker 四个 agent + 可训练的图结构知识网络，通过 pass/fail 把执行结果转化为 RL 更新（不动 LLM 权重）。CodeContests、APPS、AetherCode、Codeforces 实测达 code-generation agent SOTA。

6. Verifiable Agentic Infrastructure: Proof-Derived Authorization for Sovereign AI Systems

  • arXiv ID: 2605.15228 · PDF
  • 作者: Jun He, Deying Yu
  • 提交日期: 2026-05-13
  • 摘要: 针对自主 Agent 在云/政务等高风险场景下的授权问题，提出 Distributed Trust Framework：用 Justification Proof + 共识评估 + 临时执行身份 + Evidence Chain，把权限从”长期身份”转成”按证授予”。

7. NIMO Controller: a Self-Driving Laboratory Orchestrator based on MCP

  • arXiv ID: 2605.15227 · PDF
  • 作者: Naruki Yoshikawa, Ryo Tamura
  • 提交日期: 2026-05-13
  • 摘要: 把所有自驱实验室能力都暴露为 MCP server，提供基于 MCP tool discovery 自动生成的可视化编排界面，AI agent 与人类共享同一后端。color-matching 案例验证可用性。

8. ⭐ ICRL: Learning to Internalize Self-Critique with Reinforcement Learning

  • arXiv ID: 2605.15224 · PDF
  • 作者: Jianbo Lin, Xiaomin Yu, Yi Xin, Yifu Guo, Zhuosong Jiang, Zhongqi Yue 等
  • 提交日期: 2026-05-13
  • 摘要: 共享 backbone 联合训练 solver 与 critic，critic 奖励来自 solver 后续不带 critique 时的能力提升；用 distribution-calibration re-weighting 解决无 critique 与有 critique 的分布漂移。Qwen3-8B critic 性能逼近 32B。

9. NOVA: Fundamental Limits of Knowledge Discovery Through AI

  • arXiv ID: 2605.15219 · PDF
  • 作者: Salman Avestimehr, Ken Duffy, Muriel Médard
  • 提交日期: 2026-05-12
  • 摘要: 把”生成-验证-累积-再训练”循环建模为知识空间上的自适应采样，证明在 Zipf 尾部假设下累计生成成本 R_cum(D)=Θ(c_gen·D^α)，并指出 contamination trap：随简单知识耗尽，假阳性率即使很低也会污染知识库。

10. CAX-Agent: A Lightweight Agent Harness for Reliable APDL Automation

  • arXiv ID: 2605.15218 · PDF
  • 作者: Chenying Lin, Yichen Hai, Yi He, Ran Wang, Haiyan Qiang, Liang Yu
  • 提交日期: 2026-05-12
  • 摘要: 面向 MAPDL 有限元仿真的 Agent Harness，三层架构（LLM service / agent harness / solver）+ 三档 recovery ladder。50 个标准结构基准 × 3 次重复，model-only recovery 完成率 92.67%、零干预率 84%。

11. Fair Outputs, Biased Internals: Causal Potency and Asymmetry of Latent Bias in LLMs

  • arXiv ID: 2605.15217 · PDF
  • 作者: Jagdish Tripathy, Marcus Buckmann
  • 提交日期: 2026-05-12
  • 摘要: 在 mortgage underwriting 任务上发现：模型输出层无种族偏见，但内部表征仍编码并放大人口学信息。通过激活 steering + 跨层干预，仅注入受抑制信息即可使决策几乎完全反转，且偏置不对称。提示仅靠 output 审计不够。

12. ⭐ SkillSmith: Compiling Agent Skills into Boundary-Guided Runtime Interfaces

  • arXiv ID: 2605.15215 · PDF
  • 作者: Duling Xu, Zheng Chen, Zaifeng Pan, Jiawei Guan, Dong Dong, Jialin Li, Bangzheng Pu
  • 提交日期: 2026-05-12
  • 摘要: 指出现有 skill 注入式 agent 的两类冗余：无关上下文注入、重复 skill 推理。boundary-first 编译器把技能离线编译为最小可执行接口，运行时只动态访问相关组件。SkillsBench 上 token -57.44%、思考迭代 -42.99%、求解时间 -50.57%（2.02× 加速）。
