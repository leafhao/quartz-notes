🔍 arXiv 关键词雷达（新方向探测）

📄 SPADE: Speculative Decoding for Precise and Low Cost Distributed Edge Cloud Inference

  • 作者：Divya Jyoti Bajpai et al.
  • arXiv ID：2608.13076
  • 摘要：把投机解码拆到边缘-云两端：边缘跑轻量 draft 模型批量产候选 token，云端大模型只做并行验证。既避免小模型直接部署掉精度，又避免大模型逐 token 计费的高成本，在保持大模型输出分布无损的前提下降低分布式推理开销。
  • 方向标签：#推理优化

📄 PAIR: Pairwise-Aware Inclusion Reweighting for Adaptive Rollout Allocation in RLVR

  • 作者：Pixel Nomand et al.
  • arXiv ID：2608.11368
  • 摘要：指出 RLVR 算力分配的统计学错配：未裁剪的 leave-one-out 组相对梯度不是各 rollout 独立贡献之和，而是 rollout 两两配对上的二阶 U 统计量。因此完成一条 rollout 会揭示其它 rollout 的信息，逐点式难度/效用预算分配天然次优。PAIR 改用成对感知的纳入重加权做自适应 rollout 预算分配。
  • 方向标签：#RLHF RLVR

📄 DARTree: Speculative Diffusion Decoding with Autoregressive Draft Trees

  • 作者：Tianyi Li et al.
  • arXiv ID：2608.13524
  • 摘要：扩散式 drafter 能并行预测整块 token，但它给出的是逐位置边缘分布，没有沿着 draft 路径条件化。已有的循环修正只沿单条链补因果信息，而扩散式建树虽扩宽候选覆盖却带不进链上信息。DARTree 用自回归 draft 树把两者结合，兼顾候选覆盖广度与路径条件性。
  • 方向标签：#推理优化

📄 Thought-Aware KV Cache Compaction for Reasoning via Adaptive Attention Matching

  • 作者：Yang Liu et al.
  • arXiv ID：2608.12331
  • 摘要：推理模型的长 CoT 让 KV cache 线性膨胀成解码期显存瓶颈。现有压缩把推理轨迹当扁平 token 序列做均匀压缩，忽略了 CoT 的层次结构——不同思考步的重要性差异极大。TAM 通过思维段切分 + 自适应注意力匹配做「思维感知」的差异化压缩。
  • 方向标签：#推理优化 长上下文

📄 Teach the Magnitude, Not the Direction: Verifier-Bounded Credit Assignment for Multi-Turn Multi-step LLM Agents

  • 作者：Zechuan Wang et al.
  • arXiv ID：2608.13179
  • 摘要：多轮工具调用 Agent 的 RLVR 只有轨迹级奖励，把各轮异质结果糅成单一信号；而 on-policy 蒸馏虽有逐 token 密集监督，却受教师上限约束或出现梯度集中坍缩。CrEST 提出分层信用分配：保留 RL 的 verifier 上限，同时引入密集监督的幅度信息而非方向。
  • 方向标签：#RLHF Agent

📄 CROP: Task Relevance via Counterfactuals for Selective On-Policy Distillation

  • 作者：Enhan Li et al.
  • arXiv ID：2608.13387
  • 摘要：On-policy 蒸馏对学生自采样轨迹上的所有 token 给同等权重，但这些 token 的监督价值差异很大。CROP 用反事实方法度量每个 token 的任务相关性，做选择性 OPD，把蒸馏梯度集中到真正影响任务成败的位置。
  • 方向标签：#后训练 蒸馏

📄 Dual-Flow Transformers: Decoupling the Primary Prefill Path from Additional Decode Computation

  • 作者：Liming Liu et al.
  • arXiv ID：2608.12385
  • 摘要：推理两阶段对硬件压力完全不同：prefill 并行、算力受限；decode 串行、显存带宽受限。常规加宽/加深会同时抬高两者成本，因为每加一层都要在两个阶段都算一遍。本文让额外的层只参与 decode 路径，把主 prefill 路径与增量 decode 计算解耦。
  • 方向标签：#新架构 推理优化

📄 vToken: Token-Level Virtualization for Reclaimable KV Caches

  • 作者：Yuanhang Gao et al.
  • arXiv ID：2608.13263
  • 摘要：PagedAttention 用固定块降低分配器级碎片，但新一代 KV 淘汰算法工作在比块更细的 token 粒度，粒度错配导致块内碎片——大量已分配 KV 显存无法回收。vToken 加了一层轻量 token 级虚拟化，让 KV 显存真正可回收。
  • 方向标签：#推理优化

📄 MARCH: Scaling Recurrent Memory with Content-Routed State Anchors

  • 作者：Ming Zhang et al.
  • arXiv ID：2608.12435
  • 摘要：Transformer 的长上下文检索能力来自随长度增长的 token 级记忆，代价是训练二次复杂度 + 推理期线性膨胀的 KV cache；循环模型压成固定状态解码高效，但召回密集任务上偏弱。MARCH 用内容路由的状态锚点扩展循环记忆容量，试图兼顾两者。
  • 方向标签：#新架构 长上下文

📄 LittleLearner: Language Models Under Pedagogically Controlled Knowledge Exposure

  • 作者：Fanfei Li et al.
  • arXiv ID：2608.13545
  • 摘要：Web 级混杂语料让「模型如何习得知识与技能」难以研究，因为无法刻画先验暴露。作者构建 LITTLECURRICULUM——88B token 的美国小学教材级语料，显式剔除五年级以上的概念、事实与词汇，并从零训练 5B 模型，做受控的知识暴露实验。
  • 方向标签：#数据工程 预训练

📄 When Your Agent Opens the Chat App: Agent-Controlled Search over Raw Chat Logs Rivals Structured Memory

  • 作者：Ruizhe Li et al.
  • arXiv ID：2608.12888
  • 摘要：Agent 记忆系统普遍在提问前就把原始对话转成摘要/向量/树/知识图谱。本文追问：收益到底来自结构本身，还是来自对原始历史的高质量检索？ReFind 完全不建语义结构，只做词法索引 + Agent 自主搜索，效果与结构化记忆相当。
  • 方向标签：#Agent 记忆

📄 DFM Mimir v1: An Open HRM Delivering Frontier Performance at 1B Parameters Using Only Permissible Post-Training Data

  • 作者：Peter Schneider-Kamp et al.
  • arXiv ID：2608.13517
  • 摘要：基于 Hierarchical Reasoning Model 架构从零训练的 10 亿参数模型，全程只用许可授权的后训练数据。英语上具竞争力，丹麦语刷新 SOTA，为坚持开源与合规数据来源的研究者提供了可复现的低门槛路径。
  • 方向标签：#后训练 开源

📄 Reasoning Jury: Multi-Model Consensus for Evaluating Reasoning Traces

  • 作者：Congchao Wang et al.
  • arXiv ID：2608.12585
  • 摘要：改进推理模型需要能判断长推理轨迹质量——用于推理数据策展、RL 训练信号、以及理解推理行为。但长轨迹判别很难，单模型裁判不可靠。本文用多模型共识组成「推理陪审团」，并能定位模型犯错的具体位置以支持运行时反馈。
  • 方向标签：#评测 数据工程

📄 DAPD: Dual-Anchored Policy Distillation

  • 作者：Jianyu Wu et al.
  • arXiv ID：2608.01735
  • 摘要：On-policy 自蒸馏（OPSD）常给教师加特权信息，但会诱发「特权幻觉」：学生学到依赖特权的行为，推理时却拿不到该信息，仍按有特权时的方式行动，最终掉性能。本文把根因定位为推理期教师-学生的信息不对称，提出双锚定策略蒸馏。
  • 方向标签：#后训练 蒸馏

📄 Unifying Depth and Width Pruning for LLMs via Binary Knapsack Optimization

  • 作者：Palaash Goel et al.
  • arXiv ID：2608.12953
  • 摘要：结构化剪枝现有方法依赖贪心启发式，决策短视且常无法精确命中目标压缩预算。SNIPER 两阶段：先在粗粒度组件上解背包优化，得到给定重要性估计下条件最优的参数分配；再做细粒度剪枝以严格满足预算。
  • 方向标签：#量化剪枝

观察

今日最集中的信号是 on-policy 蒸馏（OPD/OPSD）的问题诊断潮：CROP 指出 token 信用等权不合理、DAPD 指出特权教师引发「特权幻觉」、CrEST 指出 OPD 受教师上限约束且会梯度坍缩。三篇独立工作从不同角度指向同一结论——OPD 的密集监督优势要靠精细的信用分配才能兑现。

另一条主线是 KV cache 的粒度错配：TAM（CoT 层次结构 vs 均匀压缩）与 vToken（token 级淘汰 vs 块级管理）都在说同一件事——上层算法已经细到 token/思维步粒度，底层内存管理还停在块级，中间的错配就是可回收的性能空间。
