🔥 HuggingFace 热榜（社区策展）

📄 ReferTrack: Referring Then Tracking for Embodied Visual Tracking

  • 作者：Hanjing Ye, Tianle Zeng, Jiazhao Zhang et al.
  • 热度：11 💬
  • 摘要：具身视觉跟踪(EVT)要求移动智能体根据自然语言描述，仅依靠机载视觉持续跟踪特定目标。ReferTrack将目标识别与轨迹规划解耦，先用视觉-语言模型精确定位目标，再用独立策略实现鲁棒跟踪，在多个EVT基准上显著优于端到端VLA方法。

📄 AREX: Towards a Recursively Self-Improving Agent for Deep Research

  • 作者：Shuqi Lu, Chaofan Li, Kun Luo et al.
  • 热度：2 💬
  • 摘要：深度研究需要智能体找到同时满足多个约束的答案。AREX利用发现-验证不对称性，通过递归自我改进机制让研究智能体反复生成、验证和优化答案。该方法将验证分解为可处理的逐约束检查，在复杂研究任务上大幅提升了答案质量。

📄 GraphVid: Interactive Graph-Controllable Video Generation

  • 作者：Vedant Shah, Onkar Susladkar, Tushar Prakash et al.
  • 热度：2 💬
  • 摘要：GraphVid提出基于图的交互式可控视频生成方法。用户通过场景图指定多对象交互关系，而非传统的文本提示或运动轨迹输入，实现了更精确的多对象场景控制。该方法有效解决了复杂多对象视频生成中的精确控制难题。

📄 ICAE-Bench: Evaluating Coding Agents as Interactive Project Builders

  • 作者：Zhongyuan Peng, Dan Huang, Chuyu Zhang et al.
  • 热度：2 💬
  • 摘要：ICAE-Bench评估编码智能体作为交互式项目构建者的能力。随着vibe-coding工作流兴起，编码智能体不再仅完成精确指令下的代码补全，而是要将不完整的产品意图转化为可工作的软件。该基准涵盖了从需求理解到完整项目交付的全链路评估。

📄 Robostral Navigate

  • 作者：Arjun Majumdar, Avinash Sooriyarachchi, Benjamin Tibi et al.
  • 热度：1 💬
  • 摘要：Robostral Navigate提出一种最小化传感器假设、跨机器人形态泛化且训练高效的导航系统。不依赖深度传感器、多摄像头阵列或预建地图，仅用单目视觉实现端到端导航，大幅降低了部署门槛。

📄 Tencent WorkBuddy Bench: A Multi-Domain Coding-Agent Benchmark with Contamination-Resistant Task Construction

  • 作者：Tencent WorkBuddy Bench Team, Siqi Cai, Shaopeng Chen et al.
  • 热度：1 💬
  • 摘要：腾讯WorkBuddy Bench是一个多领域编码智能体评估套件，采用抗污染的任务构造方法。核心是统一评估框架，通过分布感知方式构造和运行编码智能体任务，确保评估结果反映真实能力而非数据泄漏。

📄 NVIDIA-labs OO Agents: Native Python Object-Oriented Agents

  • 作者：Paul Furgale, Severin Klingler, James Nolan et al.
  • 热度：1 💬
  • 摘要：NVIDIA NOOA提出面向对象的Python原生智能体框架。将智能体定义为Python对象，其方法即工具，属性即状态，实现了模型无关的可靠AI智能体构建，统一了传统分散在提示模板、工具模式、回调代码和工作流图中的开发流程。

📄 TableVerse: A Large-scale Tabletop Dataset with Real-world Grounded Layouts for Generalizable Manipulation

  • 作者：Boyuan Wang, Yue Zhang, Xutao Xue et al.
  • 热度：1 💬
  • 摘要：TableVerse提供大规模桌面数据集，包含真实世界中的物体布局，用于训练泛化的机器人操作策略。相比基于文本到布局幻觉或简化程序化生成的方法，该数据集提供了高保真度的真实场景数据。

📄 Streaming Multi-Agent Autoregressive Diffusion Model with World State Registers

  • 作者：Sicheng Mo, Yuheng Li, Ziyang Leng et al.
  • 热度：1 💬
  • 摘要：提出流式多智能体自回归扩散模型，引入世界状态寄存器(World State Registers)维护跨智能体持久存在且跨视角演化的世界状态。解决了现有自回归视频扩散管道仅传递观察历史、缺乏共享状态表示的问题。

  • 方向标签：#对齐优化 / 推理 / 训练

  • 方向标签：#对齐优化 / 推理 / RAG

📄 Teaching LLMs String Matching, Backtracking, and Error Recovery to Deduce Bases and Truth Tables for the Combinatorially Exploding Bit Manipulation Puzzles

📄 X3-OPD: Distilling Reasoning into Large Audio-Language Models via On-Policy Alignment

  • 方向标签：#对齐优化 / 推理 / 推理优化

  • 方向标签：#推理 / 智能体 / RAG

📄 Learning to Detect UI Principle Violations via Reinforcement Learning

  • 方向标签：#对齐优化 / 推理 / 智能体

📄 Silent Failures in Quantized LLM Reasoning: A Taxonomy-Based Analysis of Hollow Convergence and Failure Mode Shifts

  • 作者：Renuka Oladri, Mohan Vamsi Varadaraju Priya, Jerry Wu
  • 相关度：25 分
  • 摘要：研究揭示训练后量化会在保持任务精度的情况下静默改变LLM推理方式。通过六类失败分类法分析30000条思维链输出，发现量化引起的’空洞收敛’和失败模式转移现象。
  • 方向标签：#推理 / 推理优化 / 评估

📄 MIRROR: Learning from the Other View for Multi-Modal Reasoning

  • 方向标签：#推理 / 多模态 / 评估

📄 Demonstrating GenDB: Instance-Optimized and Customized Query Processing Code Generation via LLM Agents

  • 相关度：24 分

  • 方向标签：#对齐优化 / 智能体 / 推理优化

📄 DynamicMCPBench: A Trace-Grounded, Effect-Scored Benchmark for LLM Agents over Live MCP Servers

  • 摘要：DynamicMCPBench提出基于执行轨迹和效果评分的LLM智能体基准，评估智能体在实时MCP服务器上的工具调用能力，解决了现有基准在动态有状态环境下评估脆弱的问题。
  • 方向标签：#智能体 / RAG / 评估

  • 方向标签：#推理 / 智能体 / RAG

📄 ImplicitBBQ: Benchmarking Implicit Bias in Large Language Models through Characteristic Based Cues

  • 作者：Bhaskara Hanuma Vedula, Darshan Anghan, Ishita Goyal et al.

  • 摘要：ImplicitBBQ通过基于特征的隐含线索评估LLM中的隐性偏见。发现即使LLM在显式人口统计描述下能抑制偏见输出，通过间接线索传达身份时仍可能表现出隐性偏见。
  • 方向标签：#对齐优化 / 推理 / 评估

📄 Overcoming the Communication-Performance Tradeoff in LLM Pretraining

  • 摘要：研究克服LLM预训练中的通信-性能权衡。针对DiLoCo等通信高效分布式训练算法在带宽受限环境下的局限性，提出新方法在保持通信效率的同时消除性能差距。
  • 方向标签：#RAG / 推理优化 / 训练

📄 EvoSQL: Memory-Augmented Critic-Generator Co-Evolution for Text-to-SQL

  • 相关度：22 分
  • 摘要：EvoSQL提出记忆增强的批评者-生成器协同进化框架用于Text-to-SQL。通过多步分解、执行诊断和定向修正，将SQL合成形式化为协同进化过程。
  • 方向标签：#对齐优化 / 推理 / 推理优化

📄 WaveformQA: Benchmarking LLM Temporal Reasoning on Digital Waveforms

  • 作者：Yichuan Liu, Daniel Cummings, Nick Vadlamudi
  • 相关度：22 分
  • 摘要：WaveformQA评估LLM在数字波形上的时序推理能力。尽管LLM在代码生成和推理方面表现强劲，但在设计验证关键的波形时序推理上仍待探索。
  • 方向标签：#对齐优化 / 推理 / 评估

📄 Enhancing Explainable Cardiac Diagnosis with Guide-Grounded Multimodal LLMs

  • 作者：Hai-Nam Duy Vuong, Duy-Anh Bui, Trong-Nghia Nguyen et al.
  • 相关度：22 分
  • 摘要：提出指南锚定的多模态LLM增强可解释心脏诊断。解决了深度学习心电图模型可解释性不足和LLM幻觉风险的双重挑战，通过CNN+Grad-CAM+多模态LLM框架生成可靠的ECG报告。
  • 方向标签：#对齐优化 / RAG / 多模态

📄 V-DEAL: Diagnosing Video Safety De-Calibration as an Understanding-Refusal Coupling Failure

  • 作者：Zhetong Zhang, Honghao Fu, Miao Xu et al.
  • 相关度：22 分
  • 摘要：V-DEAL诊断视频安全去校准问题，将其归因为理解-拒绝耦合失败。发现有害视频配良性查询比配显式有害查询获得更高攻击成功率，揭示了视频LLM安全对齐的深层缺陷。
  • 方向标签：#对齐优化 / RAG / 训练
