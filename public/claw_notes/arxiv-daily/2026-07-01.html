1. Beyond IID: How General Are Tabular Foundation Models, Really?

arXiv ID: 2606.30410 | 社区热度: ⬆️ 2 票
摘要: 提出 BeyondArena 基准，首个针对表格数据的统一全面评测框架，支持多种任务类型（IID、时间序列、分组）和特征类型。在 11 个模型和 142 个数据集上的评测显示，现有表格基础模型在小到中等规模的 IID 数据上表现优异，但在非 IID、大规模和高维数据集上，传统树模型和深度学习模型仍占主导地位。

2. SWE-Together: Evaluating Coding Agents in Interactive User Sessions

arXiv ID: 2606.29957 | 社区热度: ⬆️ 1 票
摘要: 推出 SWE-Together，一个从真实用户-智能体编码会话中重建的多轮交互基准。从 11,260 个会话中精选 109 个仓库级任务，构建了一个响应式的 LLM 用户模拟器来重放交互。评估指标包括最终代码正确性和所需纠正反馈轮次，实验表明更强的智能体在达到更高成功率的同时需要更少的干预，用户体验更好。

3. One-Step Gradient Delay is Not a Barrier for Large-Scale Asynchronous Pipeline Parallel LLM Pretraining

arXiv ID: 2606.30634 | 社区热度: ⬆️ 1 票
摘要: 研究大规模 LLM 预训练中的异步流水线并行（PipeDream-2BW）。挑战了传统观点，证明性能下降主要取决于优化器选择而非固有限制。发现 AdamW 在延迟下表现不佳，而 Muon 等新方法表现出强鲁棒性。引入误差反馈启发的修正方法，在最大 10B 参数模型上的评估证实该策略可弥合与同步训练的性能差距。

4. Illuminating Unified Multimodal Model for Free-form Interleaved Text-Image Generation

arXiv ID: 2606.30054 | 社区热度: ⬆️ 1 票
摘要: 推出 ILLUME-X，一个高级统一多模态范式，通过改进多模态数据效率和稳定训练过程，实现高质量的自由形式交错文本-图像生成。包括三个关键组件：扩展的交错文本-图像训练数据管道、针对自由长度多模态序列的渐进式训练策略、全面的评估方法 ILScore。在风格迁移、图像分解和故事讲述等多个任务上优于先前的统一模型。

5. Beyond Drug Discovery: The Nanotechnology Molecular Optimization (NMO) Benchmark

arXiv ID: 2606.30170 | 社区热度: ⬆️ 1 票
摘要: 推出纳米技术分子优化（NMO）基准，连接机器学习与量子材料科学。用量子模拟替代代理预言机，引入严格协议以优先考虑科学实用性而非排行榜过拟合。基于物理的 NMO 任务施加硬结构约束和崎岖适应度景观，对生成模型提出全新要求。开发新的基线方法，包括用于建模结构约束的新表示和消除药物数据集偏差的领域无关预训练策略，结果超越最先进物理性质并揭示先前未知的结构基序。

6. The Surprising Effectiveness of Video Diffusion Models for Hand Motion Reconstruction

arXiv ID: 2606.30308 | 社区热度: ⬆️ 1 票
摘要: 提出 ViDiHand，利用预训练视频扩散模型的表示来重建 4D 双手姿态。通过手部覆盖渲染目标使其特征专门化用于手部，同时保留其世界先验。解码器从适配特征中恢复度量尺度姿态。整个流程直接在完整帧上运行，无需检测器、填充器或测试时优化。在 ARCTIC、HOT3D 和 HOI4D 上大幅优于先前方法，确立视频扩散模型作为手部运动重建的强大新基础。

7. DreamForge-World 0.1 Preview: A Low-Compute Real-Time Controllable World Model

arXiv ID: 2606.30292 | 社区热度: ⬆️ 1 票
摘要: 推出 DreamForge-World 0.1 Preview，一个用于实时交互式世界模拟的预览基础世界模型。该系统适配 LongLive 1 自回归视频堆栈（源自 Wan2.1-T2V-1.3B），并受 Matrix-Game 系列启发引入残差动作路径。专注于低计算适配、消费级 GPU 运行时和广泛交互能力覆盖。支持实时键盘鼠标控制、多模态初始化、中途重新提示、双视图操作，以及在单个 RTX 4090 上以原生 480p 分辨率达到 14-15 FPS 的分钟级交互展开。

1. VLK: Learning Humanoid Loco-Manipulation from Synthetic Interactions in Reconstructed Scenes

arXiv ID: 2606.30645 | 发布时间: 2026-06-29 | 方向: cs.RO
摘要: 提出 VLK（视觉-语言-运动学）方法，通过在重建场景中合成交互来学习人形机器人感知驱动的移动操作。利用 3D 高斯点云重建室内环境，合成导航和物体交互轨迹，渲染配对的自我中心观测。生成 48,000 条配对轨迹，训练预测短期全身运动学轨迹的 VLK 策略。在物理 Unitree G1 上评估导航和单物体运输任务，证明重建场景中的合成交互为 sim-to-real 提供有效监督。

2. LeVo 2: Stable and Melodious Song Generation via Hierarchical Representation Modeling and Progressive Post-Training

arXiv ID: 2606.30642 | 发布时间: 2026-06-29 | 方向: cs.SD
摘要: 推出 LeVo 2，一个用于可控全长歌曲生成的混合 LLM-Diffusion 框架。采用分层建模：LeLM 首先预测混合 token 用于语义规划，然后并行预测人声和伴奏 token 用于轨道特定细化，扩散式音乐编解码器重建全长波形。核心贡献是美学引导的训练计划：预训练期间使用自动音乐美学评估框架分配音乐性层级条件，渐进式后训练应用 SFT、大规模离线 DPO 和闭环半在线 DPO 分别改进生成质量、可控性和音乐性。

3. Self-Evolving World Models for LLM Agent Planning

arXiv ID: 2606.30639 | 发布时间: 2026-06-29 | 方向: cs.AI
摘要: 推出 WorldEvolver，一个自演化世界模型框架，在保持下游智能体和所有模型参数冻结的情况下修订其部署时上下文。整合三个模块：情景记忆（通过基于检索的模拟利用真实动作转换）、语义记忆（从预测-观察不匹配中提取持久启发式规则）、选择性预见（在整合到智能体推理上下文之前过滤低置信度预测）。在 ALFWorld 和 ScienceWorld 上评估，WorldEvolver 在三个骨干网络上达到最高预测精度，在下游智能体成功率上领先其他世界模型基线。

4. GROW²: Grounding Which and Where for Robot Tool Use

arXiv ID: 2606.30632 | 发布时间: 2026-06-29 | 方向: cs.RO
摘要: 提出 GROW²（GROunding Which and Where），解决开放世界功能可供性定位问题：选择开放类别物体作为工具并定位其特定动作区域。利用物体部件作为自然抽象，将定位过程分层为语义和几何层级，避免数据密集的端到端训练。语义层面利用视觉-语言模型的常识推理解析任务指令、选择工具物体、识别任务相关部件；几何层面使用视觉基础模型从单张 RGB-D 图像将部件定位到精确 3D 区域。在功能可供性预测基准和机器人工具使用实验中实现零样本泛化。

5. Pessimism’s Paradox: Conservative Offline Training Amplifies Reward Hacking During Online Adaptation in Reasoning Models

arXiv ID: 2606.30627 | 发布时间: 2026-06-29 | 方向: cs.LG
摘要: 实证和机制性地挑战保守离线训练作为后续在线适应的安全基础这一直觉。在三个保守水平下训练 Qwen3-14B 策略，然后针对学习的奖励集成进行在线适应，同时测量 GSM8K 精确答案准确性的真实性能。发现更高的离线保守性单调增加奖励黑客损害，Spearman ρ=1.0。机制分析揭示三链因果链：高 β DPO 压缩策略熵 → 低熵策略生成多样性降低的响应 → 尽管接近训练分布，集成分歧（认知不确定性）随 β 增加并在在线优化期间被更快利用。

6. DOPD: Dual On-policy Distillation

arXiv ID: 2606.30626 | 发布时间: 2026-06-29 | 方向: cs.AI
摘要: 提出 DOPD（双在线策略蒸馏），一种优势感知的双蒸馏范式，根据优势差距和相对概率在特权教师和特权学生策略之间动态路由 token 级监督。每个 token 从教师或学生本身接收不同强度、目标和策略的监督，在转移可信能力的同时接收辅助信号，以缓解特权幻觉。在大语言模型和视觉-语言模型设置上的广泛实验表明，DOPD 始终优于 Vanilla OPD 和其他对手。稳定性、鲁棒性、持续学习和分布外任务的进一步结果验证其优越性。

7. Optimization Dynamics Imprint Semantic Specificity in Contrastive Embedding Norms

arXiv ID: 2606.30625 | 发布时间: 2026-06-29 | 方向: stat.ML
摘要: 提供形式理论框架解释对比嵌入模型中被丢弃的范数如何与语义属性（概念特异性、token 频率、人类不确定性）相关。通过分析优化动力学，推导出解析公式，证明嵌入长度自然编码此信息作为训练过程的副产品。还展示这如何产生可在特定模型和检索任务中用作免费校准工具的信号，为先前的启发式观察提供基础解释。

8. Scaling the Horizon, Not the Parameters: Reaching Trillion-Parameter Performance with a 35B Agent

arXiv ID: 2606.30616 | 发布时间: 2026-06-29 | 方向: cs.CL
摘要: 推出 Agents-A1，一个 35B 混合专家智能体模型，通过扩展智能体视野达到万亿参数级性能。从两个角度研究智能体视野扩展：扩展长视野轨迹和扩展异构智能体能力。构建连接外部知识、动作、观察和验证器结果的长视野知识-动作基础设施，产生平均长度 45K token 的智能体轨迹。采用三阶段训练：全域监督微调、领域级教师模型训练、多教师领域路由在线策略蒸馏。在 SEAL-0、IFBench、HiPhO、FrontierScience-Olympiad 和 MolBench-Bind 上达到领先结果。

9. C²R: Cross-sample Consistency Regularization Mitigates Feature Splitting and Absorption in Sparse Autoencoders

arXiv ID: 2606.30609 | 发布时间: 2026-06-29 | 方向: cs.LG
摘要: 稀疏自编码器（SAE）通过将激活分解为稀疏、人类可理解的特征来解释大语言模型，但扩展到大字典暴露基本挑战。系统研究揭示普遍的特征分裂（将连贯概念碎片化为非原子潜变量）和广泛的特征吸收（在一般特征中创建任意异常）。引入 C²R（跨样本一致性正则化），通过惩罚方向相似潜变量的共同激活，明确鼓励每个语义特征在批次中由统一潜变量一致表示。综合评估表明 C²R 有效缓解分裂和吸收，同时保持重建保真度。

10. MESA: Prioritizing Vulnerable Communication Channels for Securing Multi-Agent Systems

arXiv ID: 2606.30602 | 发布时间: 2026-06-29 | 方向: cs.CR
摘要: 多智能体系统（MAS）越来越多地用于自动化复杂的分布式工作流，但其智能体间通信通道引入新的攻击面。提出 Mesa，一个无标签框架，用于主动排名哪些 MAS 边缘最关键——即最有可能在受损时影响系统决策。Mesa 结合六个图论指标和两个动态探针（消融和掩蔽），无需攻击跟踪。在三个不同 MAS 场景、八个网络拓扑和五个开源 LLM 上评估，Mesa 排名与经验单边攻击成功率强相关，平均 Spearman ρ=+0.60（峰值 +0.73）。

11. Wireless Backdoor Attack and Defense for Semantic Communications over Multiple Access Channel

arXiv ID: 2606.30595 | 发布时间: 2026-06-29 | 方向: cs.NI
摘要: 语义通信（SemCom）旨在在无线信道上保留语义含义和面向任务的信息，超越传统的消息恢复。共享访问无线网络中采用 SemCom 引入了多用户语义推理的新漏洞。考虑两个发射器通过多址信道与公共接收器通信的 SemCom 系统。每个发射器将源信息映射为潜在语义表示，而接收器联合重建和分类两个发射器的语义信息。提出选择性空中后门（木马）攻击，对手在训练期间通过空中传输低功率触发波形并注入到共享接收信号中。通过在测试期间再次传输触发，这种隐蔽的低功率攻击选择性操纵一个发射器的语义推理，同时最小程度影响另一个发射器的推理。开发触发感知防御机制以在触发污染的无线观测下保留正确的语义标签。

12. Words Speak Louder Than Code: Investigating Cognitive Heuristics in LLM-Based Code Vulnerability Detection

arXiv ID: 2606.30587 | 发布时间: 2026-06-29 | 方向: cs.CR
摘要: 首次系统探索 LLM 驱动代码漏洞检测中的认知启发式。引入控制框架，保持代码固定，仅改变周围上下文以触发三种认知启发式：通过作者归属的光环效应、通过任务目标和后果的框架效应、通过先前分析结果的锚定效应。在三种编程语言上评估八个 LLM，发现所有模型都易受这些启发式影响。跨模型平均敏感性在框架效应最高（33.2%），其次是锚定（23.5%）和光环（18.4%）。演示概念验证黑盒认知攻击，可抑制高达 97% 的先前检测到的漏洞。

13. A Hybrid Framework For Crypto-Ransomware Detection In Enterprise Shared Storage

arXiv ID: 2606.30586 | 发布时间: 2026-06-29 | 方向: cs.CR
摘要: 大多数企业工作场所环境强制实施限制在客户端端点存储敏感数据的策略和技术控制。因此，勒索软件运营商已演变出将攻击面从本地系统扩展到网络驱动器和共享存储资源的变体。由于传统端点检测机制主要关注本地系统行为，受损客户端可以影响远程文件服务器（如加密共享数据），而不会直接触发服务器本身的行为变化。提出用于检测集成文件服务器和客户端环境中加密勒索软件入侵的混合检测框架。该框架基于称为兴趣区域（RoI）的新技术来分析网络流量并提取妥协指标（IoC）。机器学习模块实现 99.64% 的检测精度，假阴性率为 0%，假阳性率极低。此外，该方法能够早期检测，在发生重大损害之前识别勒索软件入侵，准确率为 99.44%。
