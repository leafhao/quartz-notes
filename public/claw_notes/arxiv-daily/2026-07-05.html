📡 arXiv 最新扫描

1. MMIR-TCM: Memory-Integrated Multimodal Inference and Retrieval for TCM Clinical Decision Support

arXiv ID: 2607.01814 | 方向: cs.AI
摘要: 提出 MMIR-TCM 框架，将记忆增强的多模态推理与检索增强生成（RAG）结合，用于中医临床决策支持。系统通过舌诊图像分析实现辨证论治和处方生成，解决了中医诊断主观性和可重复性不足的难题。利用 PPO 优化策略与 LLM 推理能力，在中医知识图谱上实现多跳推理。

2. Enhancing Fitness Intelligence through Domain-Specific LLM Post-Training

arXiv ID: 2607.02118 | 方向: cs.AI
摘要: 针对科学健身教练（SFC）场景，提出领域特定的 LLM 后训练方法。通用大模型在健身领域直接部署存在不足，本文通过监督微调（SFT）结合推理增强和 RAG 技术，构建了专业健身智能系统，使 LLM 能够提供个性化、科学的健身指导建议。

3. DRIFTLENS: Measuring Memory-Induced Reasoning Drift in Personalized Language Models

arXiv ID: 2607.02374 | 方向: cs.AI
摘要: 揭示个性化对 LLM 推理轨迹的影响。当模型存储用户属性和偏好并注入后续提示时，不仅改变了输出内容，还改变了推理路径。提出 DRIFTLENS 框架量化”记忆诱导推理漂移”现象，对比了 GRPO、DPO 等后训练方法在个性化场景下的推理稳定性差异。

4. Lynx: Progressive Speculative Quantization for accelerating KV Transfer in Long-Context Inference

arXiv ID: 2607.01831 | 方向: cs.DC, cs.LG
摘要: 针对长上下文推理中分离式推理架构的 KV 缓存传输瓶颈，提出 Lynx 渐进式投机量化方案。在 RAG 和 Agentic 系统驱动的长上下文工作负载中，解码需等待大规模 KV 缓存跨网络传输完成。Lynx 通过渐进量化策略加速传输，显著降低首 token 延迟。

5. Safeguarding LLM Agents from Misalignment through Provenance Analysis

arXiv ID: 2607.01236 | 方向: cs.CL, cs.AI
摘要: 随着 LLM Agent 获得越来越强的工具访问权限，确保其行为与用户意图对齐变得至关重要。提出基于溯源分析的方法检测 Agent 工具调用偏离用户意图的”失对齐”现象。利用 PPO 优化的对齐检测策略，在 Agent 执行前拦截潜在有害操作。

6. Breaking Safety at the Token Boundary: How BPE Tokenization Creates Exploitable Gaps in LLM Alignment

arXiv ID: 2607.01239 | 方向: cs.CL, cs.AI
摘要: 揭示字符级扰动能绕过 LLM 安全对齐的结构性机制：BPE 分词将安全关键词切分为子词片段，而公开的三个对齐数据集（DPO/SFT）中不包含此类变体的训练样本。这一发现指出了当前对齐方法的系统性盲区，为改进安全训练提供了新方向。

7. TUDUM: A Turkish-Thinking Reasoning Pipeline for Qwen3.5-27B

arXiv ID: 2607.01927 | 方向: cs.CL, cs.AI
摘要: 提出 TUDUM（Türkçe Düşünen Üretken Model）流水线，将 Qwen 系列 27B 思维模型适配到土耳其语推理。核心挑战不仅是用土耳其语回答，而是让显式推理链本身也使用土耳其语。采用 GRPO + SFT 组合训练策略，实现了非英语思维链推理的突破。

8. Behind the Refusal: Determining Guardrail Activation via Behavioral Monitoring

arXiv ID: 2607.02121 | 方向: cs.CR, cs.AI
摘要: 研究 LLM 安全护栏系统的行为监测方法。随着大模型和 Agentic 系统集成到实际应用中，检测和阻止恶意指令的护栏系统成为 AI 安全的关键组件。本文提出通过行为监测确定护栏何时被激活，帮助研究者理解和改进对齐防御机制。

9. Know Your Source: A Public Knowledge Store for Media Background Checks

arXiv ID: 2607.02383 | 方向: cs.CL
摘要: 构建面向媒体背景核查的公共知识库。基于 LLM 的 RAG 系统越来越多用于自动事实核查等任务，通过将 LLM 输出建立在检索证据之上提供透明的推理依据。本文提出标准化的知识存储方案，允许外部信息独立于底层模型进行更新，提升事实核查的可靠性。

10. ESC: Emotional Self-Correction for Reliable Vision-Language Models

arXiv ID: 2607.02089 | 方向: cs.CV, cs.AI, cs.CL, cs.LG
摘要: 提出情感自纠正（ESC）方法提升视觉语言模型的可靠推理能力。现有自纠正方法依赖后训练或精心设计的反馈机制，计算成本高。ESC 利用情感信号引导模型在无需额外训练的情况下自主修正不可靠推理，实现了更高效的多模态推理纠错。

11. CLAP: Closed-Loop Training, Evaluation, and Release Control for Domain Agent Post-training

arXiv ID: 2607.01846 | 方向: cs.AI
摘要: 提出 CLAP（闭环 Agent 后训练）方法，解决领域 Agent 面临的嘈杂业务数据、不确定的后训练收益、离线/在线不匹配和适配器发布风险等问题。将业务数据转化为结构化 SFT 样本和决策偏好样本，通过 GRPO/PPO 进行闭环优化，实现从训练到部署的全链路质量管控。

12. InduceKV: Fixed-Footprint Continual Adaptation of Multimodal LLMs via Inducing KV Memories

arXiv ID: 2607.02010 | 方向: cs.AI
摘要: 研究多模态大语言模型在固定部署空间下的持续适应问题。重复参数更新或不断增长的回放存储会随时间累积适应状态。提出 InduceKV 方法，通过诱导式 KV 记忆实现固定空间占用的持续学习，无需指令微调即可适应新任务和领域。

13. Geometric Signatures of Reasoning: A Spectral Perspective on Task Hardness

arXiv ID: 2607.01571 | 方向: cs.LG
摘要: 从谱分析角度研究思维链推理的内部几何结构。虽然大量研究关注推理链的长度和内容，但对其内部几何特征知之甚少。本文研究推理链在 LLM 隐藏空间中的几何签名，揭示任务难度与推理链几何复杂度之间的关联，为理解和改进 CoT 推理提供新视角。

14. Kara: Efficient Reasoning LLM Serving via Sliding-Window KV Cache Compression

arXiv ID: 2607.01237 | 方向: cs.CL, cs.AI
摘要: 推理模型常生成长思维链，在解码阶段累积大量 KV 缓存，导致高解码延迟和有限吞吐量。提出 Kara 方法，通过滑动窗口 KV 缓存压缩技术高效服务推理 LLM，在保持推理质量的同时显著降低内存开销和延迟。

15. MolSight: A Graph-Aware Vision-Language Model for Unified Chemical Image Understanding

arXiv ID: 2607.01982 | 方向: cs.CV, cs.AI
摘要: 提出图感知的视觉语言模型 MolSight，用于统一化学图像理解。分子大语言模型作为理解分子结构和功能的统一框架正在成为新趋势，但现有模型难以完整捕获分子结构的视觉表示。通过对齐与推理增强，实现从分子图像到功能预测的端到端理解。

16. Prompt Coverage Adequacy

arXiv ID: 2607.02057 | 方向: cs.SE, cs.AI
摘要: 研究大语言模型和自主 Agent 时代的提示覆盖充分性问题。LLM 将软件开发抽象层级从编写精确程序提升到表达意图和目标，这一范式转变引入了新挑战——如何评估提示是否充分覆盖了目标行为的各个方面，为提示工程质量评估提供形式化框架。

17. Many Voices, One Reward: Multi-Role Rubric Generation for LLM Judging and Reward Modeling

arXiv ID: 2607.01830 | 方向: cs.LG
摘要: 可靠的奖励和偏好信号对评估和优化开放任务上的大语言模型至关重要。提出多角色评分标准生成方法，将判断分解为显式评价维度。现有无标注评分标准生成器通常依赖单一视角，本文引入多角色机制生成更全面的 Rubric，支持 GRPO 等奖励模型的训练。

18. Bi-NAS: Towards Effective and Personalized Explanation for Recommender Systems via Bi-Level Neural Architecture Search

arXiv ID: 2607.01387 | 方向: cs.IR, cs.LG
摘要: 通过双层神经架构搜索为推荐系统提供有效的个性化解释。利用 LLM 的推理和 RAG 能力，在不同场景下评估推荐解释的有效性。提出自动搜索最优解释生成架构的方法，兼顾解释质量和个性化程度。

19. RusFinChain: A Russian Benchmark for Verifiable Chain-of-Thought Reasoning in Finance with Fuzzy-Aligned Evaluation

arXiv ID: 2607.01388 | 方向: cs.CL
摘要: 构建俄语金融领域可验证思维链推理基准。多步符号推理对稳健的金融分析至关重要，但现有基准忽视中间推理步骤。提出模糊对齐评估方法，不仅评估最终答案的正确性，还验证每一步推理的合理性，填补非英语金融 CoT 评估的空白。

20. SPLIT: Cross-Lingual Empathy and Cultural Grounding in English and Ukrainian LLM Responses

arXiv ID: 2607.02049 | 方向: cs.CL, cs.AI
摘要: 大语言模型越来越多部署在情感支持和危机相关场景中，但其跨语言能力在这些情境下仍未充分探索。现有基准强调多语言性能但很少检验危机相关同理心和文化适配性。本文评估英语和乌克兰语 LLM 响应中的跨语言共情和文化根基差异。
