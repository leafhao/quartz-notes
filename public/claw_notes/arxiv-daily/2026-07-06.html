📡 arXiv 最新扫描

1. ThreadWeaver: Adaptive Threading for Efficient Parallel Reasoning in Language Models

arXiv ID: 2512.07843 | 方向: cs.LG, cs.AI, cs.CL 摘要: 提出 ThreadWeaver，一种自适应线程化方法，用于高效并行推理。通过扩展推理时计算，LLM 在推理任务上表现强劲，但其固有的顺序解码带来了大量延迟。现有并行推理方法存在分配不均和冗余计算等问题，ThreadWeaver 通过动态调整线程粒度来提升并行效率。

2. LearNAT: Learning NL2SQL with AST-guided Task Decomposition for Large Language Models

arXiv ID: 2504.02327 | 方向: cs.CL 摘要: 提出 LearNAT，一种基于 AST 引导的任务分解框架，用于自然语言到 SQL 的翻译。相比依赖 GPT-4 等大规模私有模型的方案，LearNAT 通过抽象语法树分解复杂查询，使开源模型也能达到较优的 NL2SQL 效果。

3. Scaling Latent Reasoning via Looped Language Models

arXiv ID: 2510.25741 | 方向: cs.CL 摘要: 提出并开源 Ouro（取名自循环蛇 Ouroboros），一种循环语言模型家族。现代 LLM 主要通过显式文本生成（如 CoT）来”思考”，这将推理推迟到后训练阶段且未充分利用预训练数据。Ouro 通过循环结构在潜空间中实现可扩展推理。

4. Beyond Next-Token Prediction: An RLVR Proof of Concept for Tool-Use Agents on Atlassian Workflows

arXiv ID: 2607.01465 | 方向: cs.AI 摘要: LLM 被训练预测下一个 token，而非在特定 API 中执行操作。在企业 SaaS 场景中，成功意味着以正确顺序调用正确的端点和参数。本文提出基于强化学习验证推理（RLVR）的概念验证，使工具使用 Agent 能在 Atlassian 工作流中可靠执行复杂操作序列。

5. Leveraging Metamemory Agent for Enhanced Data-Free Code Generation in Large Language Models

arXiv ID: 2501.07892 | 方向: cs.SE, cs.AI 摘要: 提出元记忆 Agent 框架，用于增强无数据场景下的代码生成。少样本方法依赖精心挑选的参考示例，限制了其在无数据场景的适用性。元记忆 Agent 通过模拟人类元认知记忆来自动管理代码范例，提升 LLM 代码生成质量。

6. Who Gets the Reward & Who Gets the Blame? Evaluation-Aligned Training Signals for Multi-LLM Agents

arXiv ID: 2511.10687 | 方向: cs.MA, cs.AI, cs.CL 摘要: 提出统一理论框架，将合作博弈论归因与 LLM 训练信号结合，解决多 Agent 系统中”谁获奖、谁担责”的问题。现有训练方法缺乏将系统级评价与 Agent/消息级学习连接的机制，本框架通过 Shapley 值等方法实现评估对齐的训练信号分配。

7. Optimizing RAG Rerankers with LLM Feedback via Reinforcement Learning

arXiv ID: 2604.02091 | 方向: cs.CL, cs.AI, cs.IR 摘要: 提出通过强化学习优化 RAG 重排序器。重排序器在 RAG 系统中扮演关键角色，但当前模型通常使用与最终生成目标脱节的监督信号训练。本文利用 LLM 反馈作为奖励信号，通过 RL 使重排序器的优化目标与下游生成质量直接对齐。

8. Purified OPSD: On-Policy Self-Distillation Without Losing How to Think

arXiv ID: 2607.02234 | 方向: cs.CL, cs.AI 摘要: 在策略自蒸馏（OPSD）已成为提升 LLM 推理的有前景范式，但通常会让模型丢失”如何思考”的能力。本文提出 Purified OPSD，在从有特权教师（可访问参考答案）进行蒸馏的同时，保留模型自身的推理过程，防止能力退化。

9. Atomic Task Graph: A Unified Framework for Agentic Planning and Execution

arXiv ID: 2607.01942 | 方向: cs.AI, cs.CL 摘要: 提出原子任务图（ATG），一个统一的 Agent 规划和执行框架。基于 LLM 的 Agent 在复杂多步任务中展现强大潜力，但现有方法通常要么通过扩展推理、要么通过结构化工具使用来提升性能。ATG 将规划与执行统一到图结构中，实现更高效的任务分解和并行执行。

10. StatEval: A Comprehensive Benchmark for Large Language Models in Statistics

arXiv ID: 2510.09517 | 方向: cs.CL, cs.AI 摘要: 提出 StatEval，首个全面评估 LLM 统计推理能力的基准测试。尽管 LLM 快速发展，统计推理在现有基准中仍严重不足，现有测试通常无法涵盖概率建模、假设检验、贝叶斯推断等核心统计能力。

11. GR2 Technical Report

arXiv ID: 2606.31984 | 方向: cs.IR, cs.AI, cs.LG 摘要: GR2 技术报告。工业推荐系统通过多阶段漏斗（召回、粗排、精排）服务数十亿用户。本文提出使用生成式检索结合强化学习训练的推荐框架，可在不同阶段统一建模用户兴趣。

12. QTALE: Quantization-Robust Token-Adaptive Layer Execution for LLMs

arXiv ID: 2602.10431 | 方向: cs.LG, cs.CL 摘要: 提出 QTALE，一种对量化鲁棒的 Token 自适应层执行方法。LLM 对计算和内存资源的巨大需求是高效部署的挑战，QTALE 结合量化和自适应层跳跃两种互补技术，根据 token 难度动态决定执行哪些层。

13. A Hippocampus for Linear Attention: An Exact Memory for What the Recurrent State Forgets

arXiv ID: 2607.02303 | 方向: cs.LG, cs.CL 摘要: 为线性注意力机制设计”海马体”模块。线性注意力和状态空间模型将前缀压缩到固定大小的循环状态，以 O(1) 内存为代价牺牲了精确检索能力。本文提出精确记忆机制，补偿循环状态遗忘的信息。

14. From Actions to Understanding: Conformal Interpretability of Temporal Concepts in LLM Agents

arXiv ID: 2604.19775 | 方向: cs.AI, cs.ET, cs.MA 摘要: 提出基于共形预测的时间概念可解释性框架。LLM Agent 日益被部署为能在交互环境中推理、规划和行动的自主系统，但其内部引导序列行为的机制仍不透明。本框架通过分析动态推理轨迹来理解 Agent 行为。

15. Search for Truth from Reasoning: A Dynamic Representation Editing Framework for Steering LLM Trajectories

arXiv ID: 2606.28589 | 方向: cs.AI 摘要: 提出动态表示编辑框架（RepE），引导 LLM 推理轨迹走向真理。现有方法如 CoT 和”等一下”提示主要鼓励模型多思考，但往往无法引导其走向正确答案。本框架在动态推理过程中实时编辑模型的内部表示，实现推理方向的精准控制。

16. MedRepBench: A Comprehensive Benchmark for Medical Report Interpretation

arXiv ID: 2508.16674 | 方向: cs.CV, cs.AI, cs.CL 摘要: 提出 MedRepBench，首个全面的医学报告理解基准。从真实文档图像中理解医学报告对于生成面向患者的解释和实现临床信息的结构化交换至关重要。现有 VLM 和 LLM 在文档理解方面表现优异，但对医学报告的结构化理解仍存在挑战。

17. AgenticRAGTracer: A Hop-Aware Benchmark for Diagnosing Multi-Step Retrieval Reasoning in Agentic RAG

arXiv ID: 2602.19127 | 方向: cs.CL 摘要: 提出 AgenticRAGTracer，一个跳跃感知的基准，用于诊断 Agentic RAG 中的多步检索推理。随着 Agent 方法快速发展，Agentic RAG 已成为重要研究方向。多跳推理要求模型进行深思熟虑和多步交互，是评估此类能力的关键测试场景。

18. Polite on the Surface, Broken in Practice: A Curated Dataset for Fixing Generation and Register Failures in Low-Resource Bangla Text Generation

arXiv ID: 2605.22487 | 方向: cs.CL 摘要: 构建精选数据集，修复低资源孟加拉语文本生成中的语体失误。多语言 LLM 近年大幅提升了跨语言对话能力，但建模文化敏感和上下文依赖的交流仍是瓶颈。现有模型在孟加拉语敬语系统和语体切换方面存在严重的语用失败。

19. Bringing Agentic Search to Earth Observation Data Discovery

arXiv ID: 2607.02387 | 方向: cs.IR, cs.LG 摘要: 将 Agent 搜索引入地球观测数据发现。NASA 及其数据中心拥有数千个地球科学数据集和工具，即使领域专家也难以找到合适的资源。本文提出 Agent 搜索系统，作为地球科学社区的公共服务，通过多步推理和工具调用简化数据发现流程。

20. MMBench-Live: A Continuously Evolving Benchmark for Multimodal Models

arXiv ID: 2607.01813 | 方向: cs.CV, cs.AI 摘要: 提出 MMBench-Live，一个持续演化的多模态模型基准。现有评测基准大多是静态的，容易受到时效性衰退、数据污染和高维护成本的影响。MMBench-Live 通过多方协作构建持续更新的评测集，解决传统基准的固化问题。
