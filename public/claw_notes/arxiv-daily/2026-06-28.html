🔥 HuggingFace 社区热榜

1. Information-Aware KV Cache Compression for Long Reasoning

arXiv ID: 2606.26875 | 社区热度: ⬆️ 9 票
方向: KV cache、long-context reasoning
摘要: InfoKV 是一个基于熵感知的 KV 缓存压缩框架，通过引入信息论信号（前向影响力和预测不确定性）来增强 LLM 的长上下文推理能力。现有方法仅依赖注意力权重来评估 token 重要性，而 InfoKV 结合了信息论度量，在 prefilling 和 decoding 阶段都能有效压缩 KV 缓存，同时保持推理质量。

2. PhysiFormer: Learning to Simulate Mechanics in World Space

arXiv ID: 2606.27364 | 社区热度: ⬆️ 9 票
方向: diffusion transformer、3D meshes
摘要: PhysiFormer 使用坐标空间扩散生成物理上合理的 3D 物体运动，无需显式归纳偏置。与在视角相关像素空间中操作的视频世界模型不同，PhysiFormer 将物体表示为 3D 网格并在世界坐标中预测顶点轨迹，支持多物体推理和复杂材料泛化。

3. Hallucination in World Models is Predictable and Preventable

arXiv ID: 2606.27326 | 社区热度: ⬆️ 8 票
方向: world models、hallucination
摘要: 世界模型在状态-动作空间的低数据区域会产生幻觉，表现为视觉流畅但偏离真实动力学。研究发现这种幻觉可通过数据中心信号检测，并通过覆盖感知采样和好奇心奖励等技术有效缓解，实现数据高效的微调。

4. Neglected Free Lunch from Post-training: Progress Advantage for LLM Agents

arXiv ID: 2606.26080 | 社区热度: ⬆️ 7 票
方向: reinforcement learning、reward models、agentic settings
摘要: 强化学习后训练能为语言模型实现有效的步级评分，无需训练专用奖励模型。提出”进展优势”（Progress Advantage）概念——从 RL 后训练模型中推导出隐式优势函数，利用对数概率比实现测试时缩放和不确定性量化，解决了 Agent 场景中过程奖励模型难以构建的问题。

5. COrigami: An AI Pipeline for Co-Designing Flat-Foldable Visually Recognisable Origami

arXiv ID: 2606.26299 | 社区热度: ⬆️ 4 票
方向: computational origami、reinforcement learning
摘要: 一个计算折纸系统，使用自然语言输入通过 AI 驱动的优化和审美评估生成折痕图案。结合几何约束满足和视觉美学评价，实现人机协作的数学约束设计。

6. ABACUS: Adapting Unified Foundation Model for Bridging Image Count Understanding and Generation

arXiv ID: 2606.23835 | 社区热度: ⬆️ 3 票
方向: vision-language model、GRPO
摘要: ABACUS 是一个统一的视觉-语言模型，通过创新的空间定位、边界感知计数策略和自我批判学习（使用 GRPO）来处理物体计数、人群计数、指代表达计数和计数保真图像生成，无需任何基准特定训练。

7. When Does Combining Language Models Help? A Co-Failure Ceiling on Routing, Voting, and Mixture-of-Agents Across 67 Frontier Models

arXiv ID: 2606.27288 | 社区热度: ⬆️ 3 票
方向: multi-model LLM systems、routing、voting
摘要: 多模型系统（路由、投票、级联、融合、混合代理）面临由所有模型同时失败的概率决定的基本精度上限。研究覆盖 67 个前沿模型，证明无论集成策略或模型间相关性如何，共同失败率是这类系统增益的天花板。

8. How Post-Training Shapes Biological Reasoning Models

arXiv ID: 2606.16517 | 社区热度: ⬆️ 3 票
方向: post-training、reinforcement learning
摘要: 研究生物推理模型中后训练各阶段对泛化能力的不同影响：持续预训练使模型与生物语言对齐，监督微调提升域内性能但降低域外泛化，强化学习则能恢复域外泛化能力。揭示了后训练管道中各阶段的互补作用。

9. OpenBioRQ: Unsolved Biomedical Research Questions for Agents

arXiv ID: 2606.21959 | 社区热度: ⬆️ 3 票
方向: agentic models、retrieval-grounded benchmark
摘要: 一个新的生物医学基准，通过测试无标准答案的未解研究问题来评估 Agent 模型验证来源和避免虚假引用的能力。发现当前 Agent 模型很少捏造引用（超过 99% 可解析），但引用的论文往往并不支持其声明。

10. GridVQA-X: A Framework for Evaluating Multimodal Explainability Methods

arXiv ID: 2606.14740 | 社区热度: ⬆️ 3 票
方向: Vision-Language Models、Multimodal Explainable AI
摘要: GridVQA-X 引入了一个诊断框架，通过区分真正的空间-关系推理和跨模态捷径来评估多模态模型的跨模态可解释性，为 VLM 的可信赖性提供更严格的评估工具。

11. EO-WM: A Physically Informed World Model for Probabilistic Earth Observation Forecasting

arXiv ID: 2606.27277 | 社区热度: ⬆️ 2 票
方向: video diffusion transformer、multispectral forecasting
摘要: EO-WM 是一个视频扩散 Transformer，用于多光谱地球观测预测。通过物理信息条件框架融入气象强迫和气候基线，更好地捕捉天气驱动的不确定性，实现高质量的地表动态概率预报。

12. Physics Question Scene Graph: Fine-grained Evaluation of Physical Plausibility in Text-to-Video Generation

arXiv ID: 2606.25306 | 社区热度: ⬆️ 1 票
方向: video generation models、vision-language model
摘要: 基于 VLM 的分层问题图框架，评估视频生成模型对物理定律的遵循程度。支持细粒度违规检测并与人类判断高度相关，测试了 Sora 2、Veo 3、Wan 2.1 等最新模型。

13. Do Thinking Tokens Help with Safety?

arXiv ID: 2606.25013 | 社区热度: ⬆️ 1 票
方向: alignment、safety、reasoning models
摘要: 研究推理模型的安全性：思考 token 是否真正帮助安全决策？发现安全结果可从早期隐藏表示预测，推理过程虽然出现但实际上并未显著影响最终响应。当前安全干预措施会无意中抑制真正的推理信号，揭示了推理与安全之间的张力。

14. Forecasting Future Behavior as a Learning Task

arXiv ID: 2606.11445 | 社区热度: ⬆️ 1 票
方向: large reasoning models、behavior forecasting
摘要: “行为预测器”从单个推理轨迹学习预测大型推理模型的输出，性能超过 LLM 同时所需计算成本显著降低。为理解和信任 AI 系统提供了一种新的低成本分析路径。

15. Plans Don’t Persist: Why Context Management Is Load Bearing for LLM Agents

arXiv ID: 2606.22953 | 社区热度: ⬆️ 1 票
方向: context management、token eviction
摘要: 标准 LLM Agent 依赖计划内容保留在上下文中而非作为持久状态维护。通过重放配对诊断和压缩压力测试证明：上下文管理（压缩、摘要、驱逐旧 token）对长期任务至关重要，丢弃信息的安全性取决于计划信号是否仍被需要。

📡 arXiv 最新扫描

1. NebulaExp-8B: An Empirical Post-Training Pipeline via Full-Scale Ablation Research

arXiv ID: 2606.26671 | 方向: cs.AI
摘要: 开源后训练对齐全流程消融研究。公开详细的数据构建、过滤规则和训练配方，解决现有工作不公开细节导致的社区复现困难。覆盖 SFT 和 RLHF 阶段的完整消融实验，为轻量级模型优化提供参考。

2. AIGP: An LLM-Based Framework for Long-Term Value Alignment in E-Commerce Pricing

arXiv ID: 2606.26787 | 方向: cs.LG, cs.AI, cs.CL
摘要: 基于 LLM 的电商定价框架，解决传统动态定价模型可解释性差、非结构化信息利用不足以及与长期商业目标（累计 GMV、ROI、里程碑达成）对齐困难的问题，实现价值对齐的智能定价。

3. Paved with True Intents: Intent-Aware Training Improves LLM Safety Classification Across Training Regimes

arXiv ID: 2606.27210 | 方向: cs.CL
摘要: 提出安全分类器应将用户意图建模为提示和最终标签之间的显式信号。引入 AIMS 数据集（1,724 个困难安全提示，配对意图描述和危害标签），证明意图感知训练在多种训练机制下都能提升 LLM 安全分类性能。

4. Staying VIGILant: Mitigating Visual Laziness via Counterfactual Visual Alignment in MLLMs

arXiv ID: 2606.26387 | 方向: cs.CV, cs.CL, cs.LG
摘要: 多模态大语言模型容易产生与视觉输入矛盾的幻觉。提出反事实视觉对齐方法缓解”视觉惰性”——模型倾向于依赖语言先验而忽略图像内容的问题，从机制层面提升视觉感知的忠实度。

5. OI-Bench: An Option Injection Benchmark for Evaluating LLM Susceptibility to Directive Interference

arXiv ID: 2601.13300 | 方向: cs.CL
摘要: 评估 LLM 对指令干扰的敏感性。除界面伪影外，研究表明 LLM 的决策可被社会暗示、框架效应和指令等指令性信号影响。提出选项注入基准来系统测量这种脆弱性。

6. How Do Tool-Augmented LLM Agents Perform on Real-World Energy Analytics Tasks?

arXiv ID: 2606.26346 | 方向: cs.AI
摘要: 首个能源领域 Agent 基准。现有评估仅限于静态知识回忆，而能源领域需要实时数据检索、专业工具使用和多步推理。系统评估工具增强 LLM Agent 在真实能源分析任务上的表现。

7. Helpfulness Hurts: Domain-Dependent Degradation of Mid-Trained Compassion Values Under Post-Training

arXiv ID: 2606.26102 | 方向: cs.CL, cs.AI
摘要: 标准后训练流程（SFT + RL）使模型更有用，但可能无意间退化预训练阶段植入的价值观。研究后训练数据的领域如何差异化地影响模型的同理心等价值，揭示”有用性”与”价值保持”之间的张力。

8. Improving General Role-Playing Agents via Psychology-Grounded Reasoning and Role-Aware Policy Optimization

arXiv ID: 2606.27025 | 方向: cs.CL
摘要: 通用角色扮演 Agent 的改进方法。主流的监督微调鼓励行为模仿但缺乏深层类人内部思考，导致域外泛化差。提出心理学驱动推理和角色感知策略优化，实现更忠实的角色刻画。

9. GEOALIGN: Geometric Rollout Curation for Robust LLM Reinforcement Learning

arXiv ID: 2606.26917 | 方向: cs.LG, cs.AI
摘要: 在线强化学习广泛用于 LLM 与奖励信号对齐，但在噪声或错误指定的奖励下训练不稳定。识别了”方向不一致”失败模式——批次内少量高奖励 rollout 导致表示空间不稳定——并提出几何 rollout 筛选方法实现鲁棒 RL 训练。

10. OpenRCA 2.0: From Outcome Labels to Causal Process Supervision

arXiv ID: 2606.27154 | 方向: cs.AI
摘要: 根因分析对 LLM Agent 能力的全面测试（长上下文理解、多步推理、工具使用）。现有数据集仅标注根因而非因果传播路径，本工作从结果标签升级为因果过程监督，弥补这一根本缺口。
