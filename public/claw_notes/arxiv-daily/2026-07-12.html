📡 arXiv 最新扫描（/new 2026-07-12）

1. When Implausible Tokens Get Reinforced: Tail-Aware Credit Calibration for LLM Reinforcement Learning

arXiv ID: 2607.07976 | 方向: cs.CL | GRPO/PPO/RL优化 摘要: 强化学习在增强 LLM 推理能力方面取得了显著成功，但无 critic 的 RL 方法依赖均匀信用分配，对所有 token 广播相同的 advantage。本文识别出一种”尾部强化”问题——不合理 token 获得过高奖励，并提出尾部感知信用校准方法，在 GRPO/PPO 框架下实现更精确的 token 级信用分配，提升推理质量。

2. Wasserstein Distributionally Robust Regret Optimization for Reinforcement Learning from Human Feedback

arXiv ID: 2605.00155 | 方向: cs.CL | RLHF/后训练优化 摘要: RLHF 是 LLM 对齐的核心后训练工具，但训练奖励仅为人类真实效用的学习代理。本文提出基于 Wasserstein 分布鲁棒后悔优化的 RLHF 框架，解决目标错配下的决策问题——在估计奖励的不确定性下优化策略，确保在最坏情况分布偏移下仍能最小化后悔值。

3. Curriculum Learning for Efficient Chain-of-Thought Distillation via Structure-Aware Masking and GRPO

arXiv ID: 2602.17686 | 方向: cs.LG | GRPO/CoT蒸馏 摘要: 将大模型的 CoT 推理蒸馏到小模型面临根本挑战：教师推理往往过于冗长。本文提出结构感知掩码 + GRPO 的课程学习方法，通过渐进式难度调度和结构化推理压缩，让小模型高效学习 CoT 能力，同时保留多步推理的可解释性。

4. DeepSearch-World: Self-Distillation for Deep Search Agents in a Verifiable Environment

arXiv ID: 2607.07820 | 方向: cs.CL | Agent自蒸馏/工具使用 摘要: 训练工具使用 Agent 从自身经验中改进仍具挑战性：SFT 依赖固定教师轨迹，稀疏奖励 RL 对长视野交互提供弱监督。本文提出 DeepSearch-Evolve 自蒸馏框架，在可验证环境中让搜索 Agent 通过自身成功轨迹迭代进化，无需外部教师模型即可持续提升搜索策略质量。

5. Hallucination Self-Play: Bootstrapping Reinforced Detector via Evolved Generator

arXiv ID: 2607.07993 | 方向: cs.CL | 幻觉检测/奖励模型 摘要: LLM 输出中的忠实性幻觉检测因高质量标注数据稀缺而困难。本文提出幻觉自对弈框架：生成器和检测器协同进化——生成器学习产生越来越难以检测的幻觉，检测器通过强化学习变得越来越敏锐，形成对抗式自举循环，无需依赖高级 LLM 合成训练数据。

6. Reinforcing the Generation Order of Multimodal Masked Diffusion Models

arXiv ID: 2607.08056 | 方向: cs.LG | GRPO/扩散语言模型 摘要: 扩散语言模型（DLM）在文本生成中取得进展。本文研究自适应 token 生成顺序对数学推理和代码合成的提升效果，将 GRPO 引入多模态掩码扩散模型，强化最优生成顺序的学习，在保持并行解码效率的同时显著提升推理任务表现。

7. Distill Where the Student Goes: Teacher-Regularized RL for English-Evidence Cross-Lingual RAG

arXiv ID: 2607.02966 | 方向: cs.CL | 后训练/跨语言RAG 摘要: 跨语言 RAG 中”英文证据”模式下，即使基础模型强大，生成仍可能失败——英文证据引发语言漂移。本文提出教师正则化 RL 方法，在学生模型实际生成路径上进行蒸馏，而非固定教师轨迹，有效解决跨语言生成中的语言混杂问题。

8. Jet-Long: Efficient Long-Context Extension with Dynamic Bifocal RoPE

arXiv ID: 2607.07740 | 方向: cs.LG | 长上下文扩展 摘要: 现代 LLM 在 RAG、仓库级编码和 Agent 工作流中频繁遇到远超预训练窗口的输入。本文提出动态双焦 RoPE（Bifocal RoPE），实现高效的零样本上下文窗口扩展，无需额外训练即可处理超长输入，同时保持对局部和全局信息的注意力精度。

9. What to Keep, What to Forget: A Rate-Distortion View of Memory Compaction in LLMs and Agents

arXiv ID: 2607.08032 | 方向: cs.LG | KV缓存/记忆压缩 摘要: LLM 及其 Agent 将越来越多计算和内存用于”记忆”：缓存 KV、携带长 prompt、维护循环状态、存储历史对话。本文从率失真理论视角统一分析记忆压缩问题，为 KV 缓存淘汰、prompt 压缩和会话记忆管理提供信息论最优框架。

10. When Does Continual Learning Require Learning

arXiv ID: 2607.07847 | 方向: cs.LG | 持续学习/灾难遗忘 摘要: 随着 LLM 能力增强，如何实现持续学习成为关键问题。当前领域主要将其框架化为上下文管理和遗忘缓解问题。本文论证这一框架不完整：持续学习根本上是何时需要真正的参数更新（而非仅靠上下文）的问题，提出判断准则和新的研究方向。

11. Persuasion Attacks Can Decrease Effectiveness of CoT Monitoring

arXiv ID: 2607.08066 | 方向: cs.LG | CoT安全/对齐 摘要: CoT 监控是 AI Agent 的重要安全机制——通过可见推理轨迹发现不对齐或欺骗行为。本文揭示说服攻击可以显著降低 CoT 监控的有效性：LLM 在受到精心设计的说服后，其推理轨迹可能隐藏真实意图，对基于 CoT 的安全监控提出严峻挑战。

12. Diffusion-GR2: Diffusion Generative Reasoning Re-ranker

arXiv ID: 2607.01170 | 方向: cs.AI | 推理加速/蒸馏 摘要: 生成式推理重排序器通过发射 CoT 再重排序候选列表获得高准确率，但推理缓慢——自回归解码器每个推理 token 需一次前向传播。本文提出扩散式推理重排序器，用并行扩散解码替代自回归生成，在保持推理质量的同时大幅加速推理过程。

13. Rethinking Small VLM Quantization: From Component-Wise Analysis to Hardware-Aware Edge Deployment

arXiv ID: 2607.08029 | 方向: cs.LG | 量化/边缘部署 摘要: 小于 30 亿参数的视觉语言模型加速了设备端多模态智能落地，但组件级量化的深入理解仍是瓶颈。本文系统评估 VLM 各组件（视觉编码器、连接器、语言模型）对不同量化策略的敏感度，提出硬件感知的最优量化配置方案。

14. Understanding Axes of Difficulty For Long Context Tasks Via PredicateLongBench

arXiv ID: 2607.08284 | 方向: cs.AI | 长上下文评估 摘要: LLM 的长上下文能力快速提升，但现有评估——从大海捞针到多跳推理——主要测量”整体能力”。本文提出 PredicateLongBench，系统化拆解长上下文任务的难度轴（信息散布模式、推理深度、干扰密度等），实现对长上下文能力的精细诊断。

15. PolyWorkBench: Benchmarking Multilingual Long-Horizon LLM Agents

arXiv ID: 2607.06008 | 方向: cs.CL | 多语言Agent评估 摘要: LLM Agent 在需要规划、工具使用和环境交互的长视野任务中表现出色，但现有基准隐式假设单语设置。本文构建多语言长视野 Agent 基准 PolyWorkBench，评估推理、工具调用和执行全流程在多语言场景下的表现差异。

16. Cognitive-structured Multimodal Agent for Multimodal Understanding, Generation, and Editing

arXiv ID: 2607.08497 | 方向: cs.CL | 多模态Agent/上下文优化 摘要: 统一多模态模型可同时进行视觉/语言理解和图像生成/编辑，但反复将所有历史视觉和文本输入馈入共享上下文窗口，限制了长视野多模态对话。本文提出认知结构化多模态 Agent，通过分层记忆和选择性注意机制突破上下文窗口限制。

17. DeepTutor: Towards Agentic Personalized Tutoring

arXiv ID: 2604.26962 | 方向: cs.CL | Agent/个性化RAG 摘要: 教育是 LLM 最有前景的应用之一，但当前 LLM 依赖静态预训练知识、缺乏对个体学习者的适应，现有 RAG 系统也不能提供个性化引导反馈。本文提出 DeepTutor——一个具有主动适应能力的 Agent 教学系统，通过动态知识图谱和个性化对话策略实现自适应教学。

18. DR-Arena: an Automated Evaluation Framework for Deep Research Agents

arXiv ID: 2601.10504 | 方向: cs.CL | 深度研究Agent评估 摘要: 随着 LLM 越来越多地作为深度研究 Agent 执行自主调查和信息综合，其任务性能的可靠评估成为关键瓶颈。本文提出 DR-Arena 自动化评估框架，解决静态数据集无法反映 Agent 在开放式研究任务中实际能力的问题。

19. Narration-of-Thought: Inference-Time Scaffolding for Defeasible Ethical Reasoning in Large Language Models

arXiv ID: 2606.26366 | 方向: cs.CL | CoT改进/推理脚手架 摘要: 标准 CoT 在道德困境上呈现两种失败模式：利益相关方坍缩（推理中只提到一方）和不确定性压制（没有明确不确定因素就做出判断）。本文提出叙事思维（Narration-of-Thought），一种推理时脚手架方法，强制 LLM 在多角度叙事后再做判断，显著提升可废止推理质量。

20. IMProofBench: Benchmarking AI on Research-Level Mathematical Proof Generation

arXiv ID: 2509.26076 | 方向: cs.CL | 数学推理评估 摘要: 随着 LLM 数学能力提升，评估其在前沿数学知识边界上的表现日益重要。现有基准仅关注最终答案或高中级别问题。本文构建研究级数学证明生成基准 IMProofBench，要求模型在形式化证明助手中生成完整证明，测试真正的研究级数学推理能力。
