1. RolloutPipe: Overlapping Pipelined Rollout and Training in Disaggregated On-Policy LLM Reinforcement Learning

arXiv ID: 2606.26997 | 方向: cs.DC, cs.LG
摘要: 提出 RolloutPipe 框架，解决大语言模型强化学习（RLVR）中训练资源分配和异构训练支持的问题。针对 LLM 后训练中基于可验证奖励的强化学习日益依赖数学、逻辑和科学任务的地面真值反馈这一趋势，该方法通过流水线重叠的 rollout 和训练阶段实现灵活资源分配，显著提升在线策略 RL 训练效率。

2. HiLSVA: Design and Evaluation of a Human-in-the-Loop Agentic System for Scientific Visualization

arXiv ID: 2606.26614 | 方向: cs.HC, cs.AI
摘要: 提出 HiLSVA，一个面向科学可视化的人机协作智能体系统。现有 LLM 智能体系统过度强调自主性而忽略人类分析控制，限制了透明性和人类监督。HiLSVA 将人类保留在决策环路中，使自然语言交互与人类分析需求相结合，为高风险科学分析提供可控的智能辅助。

3. MKG-RAG-Bench: Benchmarking Retrieval in Multimodal Knowledge Graph-Augmented Generation

arXiv ID: 2606.26458 | 方向: cs.AI
摘要: 针对多模态知识图谱增强生成（MKG-RAG）中检索环节被忽视的问题，提出专门的检索基准测试。知识图谱上的检索增强生成已成为 LLM 接地的有效方法，但现有基准主要忽略了多模态场景中检索的挑战——检索本身是关键瓶颈，多模态知识的复杂性使精确检索更加困难。

4. EvoOptiGraph: Weakness-Driven Coevolution via Graph-Based Structural Generation for Optimization Modeling

arXiv ID: 2606.26578 | 方向: cs.AI
摘要: 解决从自然语言自动建模优化问题的两大挑战：训练语料缺乏结构多样性，数据生成流程与模型学习脱节。EvoOptiGraph 提出弱点驱动的协同进化方法，通过图结构生成实现数据和模型的联合优化，显著提升 LLM 在优化建模任务上的表现。

5. TOPS: First-Principles Visual Token Pruning via Constructing Token Optimal Preservation Sets for Efficient MLLM Inference

arXiv ID: 2606.27161 | 方向: cs.AI
摘要: 提出基于第一性原理的视觉 token 剪枝方法 TOPS，通过构建最优保留集实现多模态大语言模型（MLLM）高效推理。大量视觉 token 带来巨大计算开销，现有剪枝方法缺乏理论指导。TOPS 从信息论角度出发，确保在减少 token 数量的同时最大保留有效信息。

6. Perception, Verdict, and Evolution: Hindsight-Driven Self-Refining Forensics Agent for AI-Generated Image Detection

arXiv ID: 2606.26552 | 方向: cs.CV, cs.AI
摘要: 提出基于事后驱动的自我改进取证智能体，用于 AI 生成图像检测。面对生成模型快速进化带来的挑战，传统深度伪造检测方法力不从心。该方法利用多模态大语言模型的潜力，通过感知-判决-进化三阶段实现自主改进，克服现有方法在诊断幻觉方面的不足。

7. Comparing BERT Sentence-Pair Classification and Few-Shot LLM Prompting for Detecting Threat and Solution Framing in German Climate News

arXiv ID: 2606.26489 | 方向: cs.CL
摘要: 比较 BERT 句对分类和少样本 LLM 提示在德语气候新闻框架检测中的效果。新闻媒体对气候变化的报道方式（强调威胁或解决方案）影响公众参与度和政策支持，自动检测这些框架模式可帮助研究者大规模分析媒体话语。

8. Learning from the Self-future: On-policy Self-distillation for dLLMs

arXiv ID: 2606.18195 | 方向: cs.CL
摘要: 首次将在线策略自蒸馏（OPSD）应用于扩散语言模型（dLLMs）的后训练。现有 OPSD 方法本质上以自回归为中心，通过左到右前缀条件注入特权信息。本文提出适配 dLLM 并行生成特性的自蒸馏方法，让模型从自身未来预测中学习，有效提升扩散 LLM 的生成质量。

9. OpenFinGym: A Verifiable Multi-Task Gym Environment for Evaluating Quant Agents

arXiv ID: 2606.26350 | 方向: cs.AI, cs.LG
摘要: 提出 OpenFinGym，一个可验证的多任务 Gym 环境，用于评估量化金融智能体。虽然 LLM 智能体在量化金融工作流中的应用日益增多，但评估仍然碎片化——分散在孤立任务中，基准任务的金融相关性常被忽视。该环境覆盖金融工作流的多阶段特性，提供统一评估框架。

10. LCAi: Life Cycle Assessment with big data fusion and retrieval-augmented generation-assisted interpretation

arXiv ID: 2606.26857 | 方向: cs.AI
摘要: 将大数据融合和检索增强生成引入生命周期评估（LCA）的解释阶段。传统 LCA 的解释阶段缺乏将量化改进机会转化为可执行战略路径的结构化机制，该方法利用 RAG 技术在技术、社会和政策不确定性下提供环境热点改进建议。

11. TAVR-VLM: Risk-Conditioned Causal Grounding for Hallucination-Resistant Report Generation

arXiv ID: 2606.26874 | 方向: cs.AI
摘要: 针对经导管主动脉瓣置换术（TAVR）规划的高风险场景，提出风险条件因果接地方法，解决多模态大语言模型中的诊断幻觉问题。生成文本缺乏解剖学接地是将 MLLM 应用于医学领域的核心障碍，TAVR-VLM 通过因果推理确保报告生成的可靠性。

12. Joint Reward Modeling: Internalizing Chain-of-Thought for Efficient Visual Reward Models

arXiv ID: 2602.07533 | 方向: cs.AI
摘要: 提出联合奖励建模方法，将思维链内化到视觉奖励模型中。奖励模型对 RLHF 至关重要，决定了生成模型的对齐质量和可靠性。对于图像编辑等复杂任务，奖励模型需要捕捉全局语义一致性和隐含逻辑约束，联合建模方法在保持效率的同时提升了对齐能力。

13. Reasoning Quality Emerges Early: Data Curation for Reasoning Models

arXiv ID: 2606.26797 | 方向: cs.LG
摘要: 发现推理质量在训练早期就已涌现，据此提出推理模型的数据筛选方法。在小规模高质量长推理链数据上进行 SFT 是激发 LLM 强推理能力的有效途径，但现有方法严重依赖强推理模型来过滤样本。本文提出无需强模型辅助的数据质量早期评估方法。

14. Cliff Tokens: Identifying Single-Token Failure Triggers in LLM Mathematical Reasoning

arXiv ID: 2606.25524 | 方向: cs.AI, cs.CL
摘要: 识别 LLM 数学推理中的”悬崖 token”——触发推理失败的单个 token。LLM 在数学推理中准确率较高，但对同一问题的不同推理轨迹差异巨大。先前工作在步骤、块或句子层面分析失败，本文深入到 token 粒度，找到导致推理链崩溃的临界触发点。

15. BrepCoder: A Unified Multimodal Large Language Model for Multi-task B-rep Reasoning

arXiv ID: 2602.22284 | 方向: cs.LG
摘要: 提出统一的多模态大语言模型 BrepCoder，用于 CAD 领域的多任务 B-rep 推理。现有方法依赖任务特定模型，需要为新任务做结构性修改，且主要关注点云或图像。BrepCoder 直接处理边界表示（B-rep），在统一架构下完成多种 CAD 推理任务。

16. Embarrassingly Simple Self-Distillation Improves Code Generation

arXiv ID: 2604.01193 | 方向: cs.CL
摘要: 证明简单自蒸馏（SSD）即可改善 LLM 代码生成能力——无需验证器、教师模型或强化学习。只需从模型自身采样解决方案（特定温度和截断配置），再用于微调，就能持续提升代码生成质量。方法简洁有效，挑战了代码生成必须依赖复杂训练流程的观念。

17. ReasonCLIP-58M: Visually Grounded Commonsense Reasoning Supervision for CLIP

arXiv ID: 2606.26794 | 方向: cs.CV, cs.AI
摘要: 为 CLIP 引入视觉接地的常识推理监督信号。CLIP 及其变体的预训练仍以描述性图像-文本对齐为主，但下游应用越来越需要视觉接地的常识推理和组合性推理能力。ReasonCLIP-58M 提供 5800 万条推理监督数据，增强视觉骨干的推理能力。

18. Just how sure are you? Improving Verbalized Uncertainty Calibration in Medical VQA

arXiv ID: 2606.27023 | 方向: cs.LG, cs.CL, cs.CV
摘要: 改善多模态大语言模型在医学视觉问答中的口头化不确定性校准。MLLM 应用于医学 VQA 时，无论实际正确与否都倾向产生过度自信的输出。现有校准方法主要针对纯文本 LLM 开发，未考虑多模态特性，本文提出适配多模态场景的校准方法。

19. Soft Token Alignment for Cross-Lingual Reasoning

arXiv ID: 2606.26466 | 方向: cs.CL
摘要: 提出软 token 对齐方法解决跨语言推理一致性问题。多语言大语言模型对不同语言的语义等价提示常产生不一致的推理和答案。研究发现中间表示可以相对语言无关，但生成过程随层深入变得越来越语言特定，软对齐方法在保持多语言能力的同时提升一致性。

20. GenRecal: Generation after Recalibration from Large to Small Vision-Language Models

arXiv ID: 2506.15681 | 方向: cs.CL
摘要: 提出从大到小视觉语言模型的重校准生成方法 GenRecal。大型 VLM 虽然性能接近 GPT-4V 等闭源系统，但在资源受限设备上部署仍具挑战。GenRecal 通过大模型校准小模型的方式，在保持性能的前提下实现高效部署。

📈 技术趋势

本期论文集中体现三大趋势：(1) LLM 强化学习训练基础设施持续优化（RolloutPipe 流水线并行、Joint Reward Modeling）；(2) 推理能力提升的多路径探索——从数据筛选（Reasoning Quality Emerges Early）到失败分析（Cliff Tokens）再到自蒸馏（Self-Distillation）；(3) 多模态 LLM 效率优化成为热点（TOPS token 剪枝、GenRecal 模型蒸馏、不确定性校准）。
