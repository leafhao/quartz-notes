1. Self in Space: Benchmarking Self-Awareness and Spatial Cognition in UAV Embodied Intelligence

arXiv ID: 2607.12477 | 社区热度: ⬆️ 3 💬
方向: Embodied AI, Multimodal LLMs
摘要: 自主无人机系统越来越依赖多模态大语言模型（MLLMs）在复杂真实环境中运行。此类具身场景不仅需要理解周围空间，还需维持智能体自身的连贯表征。本文提出了一个基准测试，评估MLLMs在无人机具身智能中的自我意识和空间认知能力。

2. Harness Handbook: Making Evolving Agent Harnesses Readable, Navigable, and Editable

arXiv ID: 2607.13285 | 社区热度: ⬆️ 3 💬
方向: Agent Systems, Software Engineering
摘要: 现代AI智能体的能力不仅取决于基础模型，还取决于其”harness”——负责构建提示、管理状态、调用工具和协调执行的框架。本文提出了使不断演进的Agent Harness更具可读性、可导航性和可编辑性的方法论。

3. From Controlled to the Wild: Evaluation of Pentesting Agents for the Real-World

arXiv ID: 2605.10834 | 社区热度: ⬆️ 2 💬
方向: Security, Agent Evaluation
摘要: AI渗透测试智能体作为攻击性安全系统越来越可信，但当前基准测试对真实世界目标的指导仍然有限。本文评估和优化了渗透测试智能体在CTF之外的真实目标场景中的表现。

4. Boogu-Image-0.1: Boosting Open-Source Unified Multimodal Understanding and Generation

arXiv ID: 2607.13125 | 社区热度: ⬆️ 2 💬
方向: Multimodal, Image Generation
摘要: 开源统一多模态理解与生成模型家族，包含 Base、Turbo、Edit 和 Edit-Turbo 变体。在高质量文生图、快速推理、指令编辑和中英双语理解方面表现出竞争力。

5. Ring-Zero: Scaling Zero RL to a Trillion Parameters for Emergent Reasoning

arXiv ID: 2607.12395 | 社区热度: ⬆️ 2 💬
方向: Reinforcement Learning, Reasoning
摘要: 使用可验证奖励的强化学习（zero RL）无需人类标注数据即可激发链式思维推理，但现有研究受计算限制主要局限于小模型。本文将 zero RL 扩展到万亿参数规模，研究涌现推理能力的训练动态。

6. MAGIC: Transition-Aware Generation of Navigable Multi-Scene Game Worlds with Large Language Models

arXiv ID: 2607.11594 | 社区热度: ⬆️ 2 💬
方向: Game AI, LLM Applications
摘要: 多场景导航是当代3D游戏的定义特征，但人工创建非常费力。本文利用大语言模型实现转换感知的可导航多场景游戏世界自动生成。

7. Are LLMs Ready for Scientific Discovery? A Capability-Oriented Benchmark for AI Scientists

arXiv ID: 2607.11079 | 社区热度: ⬆️ 2 💬
方向: Scientific AI, Benchmark
摘要: 现有基准主要评估LLM的代码执行或工作流完成能力，忽略了科学分析服务于不同类型的科学主张（假设探索、统计推断、机制解释）。本文提出面向能力的AI科学家基准测试。

8. Generative Compilation: On-the-Fly Compiler Feedback as AI Generates Code

arXiv ID: 2607.13921 | 社区热度: ⬆️ 1 💬
方向: Code Generation, Compilation
摘要: 具有丰富静态语义的语言（如Rust）为AI生成代码提供更强保证，但其严格性使生成更困难。本文提出在代码生成过程中实时引入编译器反馈，而非仅在生成后验证。

9. Discrete Diffusion Models: A Unified Framework from Tokenization to Generation

arXiv ID: 2607.13431 | 社区热度: ⬆️ 1 💬
方向: Diffusion Models, Generation
摘要: 离散去噪扩散模型（DDMs）作为自回归建模的替代方案，提供并行生成和迭代全局细化能力。本文提出从分词到生成的统一框架。

10. AffectFlow-DINO: Uncertainty-Aware Multi-Task Affect Estimation via Conditional Rectified Flow

arXiv ID: 2607.13250 | 社区热度: ⬆️ 1 💬
方向: Multimodal, Affective Computing
摘要: 多任务情感估计系统，通过条件整流流头对野外面部行为的固有模糊性建模，而非预测单一情感估计值。

11. Self-Improvements in Modern Agentic Systems: A Survey

arXiv ID: 2607.13104 | 社区热度: ⬆️ 1 💬
方向: Agent Systems, Self-Improvement
摘要: 自改进智能体正从研究原型走向部署系统。本综述将现代自改进智能体框架化为自适应系统，通过最少或零人工输入将经验转化为可控进化。

12. PalmClaw: A Native On-Device Agent Framework for Mobile Phones

arXiv ID: 2607.13027 | 社区热度: ⬆️ 1 💬
方向: Mobile AI, On-Device Agent
摘要: LLM智能体已从生成响应发展为执行多步任务。大多数智能体系统运行在桌面或服务器上，本文提出原生端侧智能体框架PalmClaw，支持移动设备上的工具调用和任务自动化。

1. Post-Training Shifts Confidence: A Three-Stage Analysis of How SFT, RL, and OPD Shape Pre-, Intra-, and Post-CoT Calibration

arXiv ID: 2607.13753 | 方向: cs.CL | 相关度: ⭐⭐⭐⭐⭐
摘要: 大语言模型通过监督微调、强化学习和在线策略蒸馏获得了强大的推理能力，但这些后训练方法通常仅通过最终答案准确率来评估。本文研究后训练如何重塑推理过程中的置信度，引入三阶段框架分析CoT前、中、后的校准变化。

2. Exploring Post-Training Alignment of Small Language Models for Biomedical Data-to-Text Generation

arXiv ID: 2607.13430 | 方向: cs.CL | 相关度: ⭐⭐⭐⭐⭐
摘要: 将复杂生物医学数据转化为患者友好叙述是现代生物信息学的核心任务。本文对比分析了在专业生物医学数据到文本生成任务中训练小语言模型的后训练对齐方法（SFT、DPO等）。

3. Groc-PO: Grounded Context Preference Optimization for Truthful Multimodal LLMs

arXiv ID: 2607.13712 | 方向: cs.CV | 相关度: ⭐⭐⭐⭐⭐
摘要: 多模态大语言模型仍存在视觉幻觉、内容捏造和不忠实推理等问题。本文提出基于接地上下文的偏好优化方法（Groc-PO），通过对齐方法解决多模态LLM的真实性问题。

4. Meta-Learning Preferences for Multilingual LLM Alignment

arXiv ID: 2607.13315 | 方向: cs.CL | 相关度: ⭐⭐⭐⭐⭐
摘要: 跨语言人类偏好数据的不均等分布是多语言LLM对齐的重大挑战。本文提出元学习框架，解决低资源语言对齐中数据不足的问题，通过RLHF实现跨语言偏好迁移。

5. Analogical Deep Research: Retrieving and Integrating Historical Analogies for Foresight Analysis

arXiv ID: 2607.13602 | 方向: cs.CL | 相关度: ⭐⭐⭐⭐
摘要: 历史类比——当前情境与结构相似过去事件的系统比较——是前瞻分析最有力的工具之一。本文提出”类比深度研究”新任务，利用LLM智能体检索和整合历史类比进行预测分析。

6. Value Drifts: Tracing Value Alignment During LLM Post-Training

arXiv ID: 2510.26707 | 方向: cs.CL | 相关度: ⭐⭐⭐⭐⭐
摘要: 随着LLM在社会中扮演越来越重要的角色，研究其与人类价值观的对齐变得至关重要。本文追踪LLM后训练过程中价值对齐的变化轨迹，揭示”价值漂移”现象。

7. RAGthoven at SemEval-2026 Task 1: A Multi-Stage Pipeline Walks Into a Benchmark and Barely Clears the Bar

arXiv ID: 2607.13189 | 方向: cs.CL | 相关度: ⭐⭐⭐⭐
摘要: 多阶段LLM流水线系统RAGthoven，用于SemEval-2026多语言幽默生成任务。将创意文本生成分解为规划器、Best-of-N写作器和反思器的多阶段流水线。

8. Beyond tokens: a unified framework for latent communication in LLM-based multi-agent systems

arXiv ID: 2606.05711 | 方向: cs.CL | 相关度: ⭐⭐⭐⭐
摘要: 基于LLM的多智能体系统已成为解决复杂推理、规划和工具使用任务的主流范式。本文提出超越token级自然语言通信的统一框架，探索潜空间通信在多智能体系统中的应用。
