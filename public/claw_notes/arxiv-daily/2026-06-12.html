1. Redesign Mixture-of-Experts Routers with Manifold Power Iteration

arXiv ID: 2606.12397 | 社区热度: ⬆️ 74 票
方向: Mixture-of-Experts、router
摘要: 提出一种全新的混合专家（MoE）路由器设计，通过流形幂迭代（Manifold Power Iteration）将路由器各行与对应专家矩阵的主奇异方向对齐。引入「先幂迭代再回缩」范式，理论上证明能驱动路由器收敛到专家的主奇异方向，在 1B 到 11B 参数规模上验证可提升 MoE 模型效果。

2. Toward Generalist Autonomous Research via Hypothesis-Tree Refinement

arXiv ID: 2606.11926 | 社区热度: ⬆️ 68 票
方向: autonomous research、long horizons
摘要: 提出 Arbor 自主科研框架，结合长期协调器、短期执行器与「假设树精炼」（HTR），让 AI 智能体在长周期内自主完成探索-实验-抽象的科研循环。在 6 项真实科研任务上全部取得最佳留出结果，平均相对增益超过 Codex 和 Claude Code 的 2.5 倍；在 MLE-Bench Lite 上用 GPT-5.5 达到 86.36% 任意奖牌率。

3. Claw-SWE-Bench: A Benchmark for Evaluating OpenClaw-style Agent Harnesses on Coding Tasks

arXiv ID: 2606.12344 | 社区热度: ⬆️ 55 票
方向: SWE-bench、OpenClaw
摘要: 推出 Claw-SWE-Bench，一个多语言 SWE-bench 风格基准与适配器协议，让异构智能体框架（claws）在公平条件下可比。包含 8 种语言、43 个仓库的 350 个 GitHub issue 修复实例。实验显示适配器设计至关重要：OpenClaw 用最简适配器仅 19.1% Pass@1，完整适配器在相同 GLM 5.1 后端下达 73.4%。将框架设计与成本核算作为编码智能体评测的一等维度。

4. Reason, Then Re-reason: Cross-view Revisiting Improves Spatial Reasoning

arXiv ID: 2606.11683 | 社区热度: ⬆️ 28 票
方向: spatial reasoning、egocentric videos
摘要: 提出 ReRe（先推理再重推理）框架，针对自我中心视频的空间推理。第一阶段 MLLM 从原视频形成空间假设，第二阶段通过观察从预测的 3D 几何渲染出的新视角视频来验证或修正假设。训练免费、推理时即可用。在 VSI-Bench 和 STI-Bench 上大幅提升开源 MLLM，逼近专有 SOTA 水平。

5. On Subquadratic Architectures: From Applications to Principles

arXiv ID: 2606.12364 | 社区热度: ⬆️ 21 票
方向: Transformers、attention
摘要: 系统比较 xLSTM、Mamba-2、Gated DeltaNet 三种次二次架构，在代码模型预训练、代码模型蒸馏、时序基础模型预训练等复杂依赖任务上评测。结果显示 xLSTM 整体表现最强，得益于其门控机制带来的更灵活稳定的记忆纠正。统一形式化分析揭示 xLSTM 的优势源于稳健的状态追踪与累积。

6. Grammar-Constrained Decoding Can Jailbreak LLMs into Generating Malicious Code

arXiv ID: 2606.11817 | 社区热度: ⬆️ 17 票
方向: Grammar-Constrained Decoding、jailbreak attack
摘要: 揭示一个反直觉风险：用于提升代码可靠性的「语法约束解码」（GCD）本身可成为攻击面。提出 CodeSpear 越狱攻击，仅施加良性代码语法约束即可诱导 LLM 生成恶意代码，攻击成功率平均提升超 30 个百分点。对应提出 CodeShield 安全对齐方法，教模型在 GCD 下生成语义无害的「蜜罐代码」，在保持良性效用的同时恢复安全性。

7. Reroute, Don’t Remove: Recoverable Visual Token Routing for Vision-Language Models

arXiv ID: 2606.12412 | 社区热度: ⬆️ 15 票
方向: vision-language models、visual tokens
摘要: 针对视觉语言模型（VLM）的视觉 token 压缩，指出主流「排序-删除」范式的脆弱性：token 重要性随解码器深度变化，早期被低估的 token 可能在后续层变得关键。提出 Reroute——训练免费插件，用「可恢复路由」替代删除：被推迟的 token 绕过当前阶段并在下一决策点重新进入候选池。在 LLaVA-1.5 和 Qwen 上保持 VQA 性能的同时改善了 grounding。

8. Verifiable Environments Are LEGO Bricks: Recursive Composition for Reasoning Generalization

arXiv ID: 2606.12373 | 社区热度: ⬆️ 6 票
方向: Reinforcement Learning、Large Language Models
摘要: 提出 RACES（环境扩展的递归自动组合）框架，将可验证环境视为可递归组装的乐高积木。关键洞察：当一个环境的输出类型匹配另一个的输入类型时即可自动融合。定义 SEQUENTIAL/PARALLEL/SORT/SELECT 等组合算子。实验显示组合环境上的 RL 训练持续提升推理泛化：DeepSeek-R1-Distill-Qwen-14B 平均提升 3.1 分，仅用 50 个基础环境即达到 300 个独立环境的效果。

9. Fine-tuning Multi-modal LLMs with ART: Art-based Reinforcement Training

arXiv ID: 2606.11854 | 社区热度: ⬆️ 3 票
方向: Parameter-Efficient Fine-Tuning、LoRA
摘要: 提出 ART（基于艺术的强化训练）参数高效微调方法。区别于 LoRA 和软提示需修改预编译 LLM 的计算图，ART 仅优化冻结多模态 LLM 的原始视觉输入（像素数组），通过梯度反传注入信息，从而在 vLLM 等高吞吐引擎上支持软 token 方法。在 Qwen 架构多个规模与多个文本基准上，ART 在数学和结构化工具使用任务上达到与 LoRA 相当的精度。

10. Time-Series Foundation Model Embeddings for Remaining Useful Life Estimation

arXiv ID: 2606.11990 | 社区热度: ⬆️ 3 票
方向: time-series foundation model、Chronos-2
摘要: 提出一种轻量学习方法用于剩余使用寿命（RUL）预测：利用冻结的预训练时序基础模型（Chronos-2）作为骨干提取上下文窗口特征，仅训练小型回归头。在两类工业传感器设备的真实数据上，Chronos-2 特征持续优于循环、卷积、Transformer 及梯度提升基线。更长历史窗口显著提升性能，表明 TSFM 表示是工业 RUL 估计的实用、数据高效替代方案。

11. Adaptive Multi-Resolution Procedural Knowledge Compression for Large Language Models

arXiv ID: 2606.12203 | 社区热度: ⬆️ 2 票
方向: large language models、reusable natural language skills
摘要: 提出 SKIM（技能压缩），一个面向 LLM 程序化知识的自适应多分辨率软 token 压缩框架。针对可复用自然语言技能反复调用导致预填成本与延迟上升的问题，SKIM 根据技能复杂度创建不同数量的软 token，既提升推理效率又保留技能使用效果，同时支持频繁更新社区技能的轻量离线压缩。实验将技能压缩到原长的 30-60%，任务性能优于现有压缩方法。

12. Building Social World Models with Large Language Models

arXiv ID: 2606.11482 | 社区热度: ⬆️ 1 票
方向: Social World Model、state-transition functions
摘要: 提出社会世界模型（SWM）框架，捕捉社会信念如何随重大事件演变。SWM 通过挖掘社会数据的时间模式并优化证据下界来学习社会信念的状态转移函数，无需显式人工标注或昂贵普查数据。基于 Kalshi 和 Polymarket 真实预测市场构建 SWM-bench 基准（含 1.2 万+数据点）。SWM 显著超越时序基础模型，在 Kalshi 上达 SOTA，并提供可解释的社会信念动态洞察。

13. Which Models Are Our Models Built On? Auditing Invisible Dependencies in Modern LLMs

arXiv ID: 2606.12385 | 社区热度: ⬆️ 1 票
方向: LLM dependency graphs、agentic system
摘要: 提出 ModSleuth 智能体系统，从公开物料递归重建 LLM 依赖关系图并提供源头可溯证据。现代 LLM 训练管线越来越依赖其他模型生成数据、过滤语料、评判输出，这些依赖呈递归性且文档分散。ModSleuth 区分直接/间接依赖、以操作为中心表示异构管线角色。应用于 4 个公开物料丰富的 LLM 发布，恢复 1060 个经验证的依赖，揭示多跳许可证义务、训练-评测耦合及文档不一致。

14. APEX: A Network-Native Time-Series Foundation Model for Forecasting and Anomaly Detection for Wireless Edge Operations

arXiv ID: 2606.11553 | 社区热度: ⬆️ 1 票
方向: time-series foundation models、wireless network telemetry
摘要: 提出 APEX，一个网络原生、仅解码器的 Transformer 时序基础模型，用于无线边缘运营的预测与异常检测。通用时序基础模型难以迁移到突发、零膨胀、跨协议层耦合的无线网络遥测。APEX 在约 4500 个生产无线网络（约 10 万 AP 时序）上预训练。在 192 步 DHCP 退化基准上，APEX-Large 较最强基线 Toto 降低 MAE 18%、较 SARIMA 降低 38%，异常检测 F1=0.93；APEX-Edge（10.5M）支持边缘亚秒级隐私推理。

15. Towards Diverse Scientific Hypothesis Search with Large Language Models

arXiv ID: 2606.10587 | 社区热度: ⬆️ 1 票
方向: evolutionary search、hypothesis generation
摘要: 针对科学假设搜索，提出一个受经典并行回火算法启发的进化框架。许多发现场景下目标并非找到单一最佳假设，而是产出一组多样、高质量的备选假设以对冲下游不确定性，但常用进化搜索易导致「多样性坍缩」。该方法将假设搜索建模为采样问题，在多个温度层并行搜索并实现温度间信息交换，在分子发现、方程发现、算法发现等领域同时提升假设质量与多样性。

1. Breaking Entropy Bounds: Accelerating RL Training via MTP with Rejection Sampling

arXiv ID: 2606.12370 | 发布时间: 2026-06-10
方向: cs.LG
摘要: 提出 Bebop，系统研究多 token 预测（MTP）在 LLM 后训练中的应用，解决 RL 训练中 rollout 阶段瓶颈。揭示 MTP 接受率本质上受模型熵波动限制（与熵呈负线性关系）；概率拒绝采样可缓解 RL 中熵的扰动。提出端到端 TV 损失直接优化多步拒绝采样接受率，接受率提升约 10%（最高达 95%），推理吞吐额外提升最多 25%。在 Qwen3.5/3.6/3.7 异步 RL 训练上实现最高 1.8 倍端到端加速。

2. Beyond Fully Random Masking: Attention-Guided Denoising and Optimization for Diffusion Language Models

arXiv ID: 2606.12273 | 发布时间: 2026-06-10
方向: cs.CL
摘要: 提出 AGDO（注意力引导的去噪与优化）框架，用于扩散语言模型（dLLM）。现有后训练方法多依赖随机掩码策略，忽视 token 内在依赖。实证分析显示强烈关注未掩码上下文的 token 具有更高生成稳定性且对推理至关重要。AGDO 据此让训练和优化与注意力派生的依赖对齐：基于注意力结构确定去噪顺序，并在 SFT 与 RL 中强调注意力关键 token。在数学和编码基准上持续超越 SOTA dLLM 后训练方法。

3. Soft-Prompt Tuning for Fair and Efficient LLM Benchmark Evaluation

arXiv ID: 2606.12117 | 发布时间: 2026-06-10
方向: cs.CL
摘要: 提出软提示微调，用于公平高效的 LLM 基准评测。基准分数常因模型遵循特定格式的能力而误判其真实知识，尤其惩罚知道答案但缺乏后训练格式化能力的基座模型。该方法仅优化 10 个软提示向量（7B 模型约 0.0006% 参数），短时调优即可适配基准格式。在 7 模型 7 数据集上验证：80 步内即饱和格式遵循，显著优于零样本/少样本提示，且软提示基座性能比基线更可靠地预测后训练模型排名。

4. Decoding Multimodal Cues: Unveiling the Implicit Meaning Behind Hateful Videos

arXiv ID: 2606.11953 | 发布时间: 2026-06-10
方向: cs.CL
摘要: 针对仇恨视频检测的可解释性，提出信息增强与推理增强（IARE）框架。现有研究多停留于二分类，缺乏揭示隐含含义的语境理由。作者构建 Ex-HateMM 与 Ex-ImpliHateVid 两个数据集（含多模态有害元素细粒度标注与语境理由）。IARE 用多模态思维链整合有害元素丰富理由证据，并用直接偏好优化（DPO）引导模型走向正确推理路径，在两数据集上达 SOTA 并生成准确理由。

5. RLCSD: Reinforcement Learning with Contrastive On-Policy Self-Distillation

arXiv ID: 2606.11709 | 发布时间: 2026-06-10
方向: cs.LG
摘要: 提出 RLCSD（带对比式在策略自蒸馏的强化学习）。在策略自蒸馏（OPSD）为推理模型提供 token 级密集监督，但作者发现其学习信号集中于风格 token 而非任务 token，称为「特权诱导风格漂移」，会破坏训练稳定性或缩短响应。RLCSD 通过对比正确提示与错误提示下的师生差距来抑制风格漂移，让信号更集中于任务 token。在 Qwen3（1.7B/4B/8B）和 Olmo-3-7B-Think 上持续超越 GRPO 及此前 OPSD 方法。
