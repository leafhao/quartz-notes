1. RAG-Star: Enhancing Deliberative Reasoning with Retrieval Augmented Verification and Refinement

关键词： RAG, Reasoning, Monte Carlo Tree Search

摘要： 提出 RAG-Star，一种新颖的 RAG 方法，将检索信息整合到基于树的深思熟虑推理过程中。通过蒙特卡洛树搜索（MCTS），迭代规划中间子查询和答案。提出检索增强验证，利用查询和答案感知的奖励建模为 LLM 内在推理提供反馈。在 Llama-3.1-8B 和 GPT-4o 上的实验表明，RAG-Star 显著优于之前的 RAG 和推理方法。

亮点： 结合外部知识与内在推理，MCTS + RAG 的新范式

2. RAG-Gym: Systematic Optimization of Language Agents for Retrieval-Augmented Generation

关键词： RAG, Agent Optimization, DPO

摘要： 引入 RAG-Gym 平台，系统性探索三个优化维度：(1) 提示工程，(2) Actor 微调，(3) Critic 训练。提出 Re²Search 代理，引入推理反思，显著优于标准提示。发现直接偏好优化（DPO）是最有效的后训练算法。优化后的 Re²Search++ 代理在平均 F1 上比 Search-R1 提升 3.2%-11.6%。

亮点： 系统性优化框架，DPO + Critic 训练的最佳实践

3. Vendi-RAG: Adaptively Trading-Off Diversity And Quality Significantly Improves RAG With LLMs

关键词： RAG, Diversity, Multi-hop Reasoning

摘要： 提出 Vendi-RAG 框架，联合优化检索多样性和答案质量。利用 Vendi Score（VS）促进文档检索中的语义多样性，使用 LLM 评委评估候选答案。在 HotpotQA、MuSiQue 和 2WikiMultiHopQA 数据集上，相比 Adaptive-RAG 提升 +4.2%、+4.1% 和 +1.3%。

亮点： 多样性与质量的平衡优化，多跳推理显著提升

4. T-RAG: Lessons from the LLM Trenches

关键词： RAG, Enterprise QA, Fine-tuning

摘要： 分享构建和部署企业私有文档问答 LLM 应用的经验。系统 T-RAG（Tree-RAG）结合 RAG 与微调的开源 LLM，使用树结构表示组织内实体层级，生成文本描述增强上下文。Needle in a Haystack 测试表明，该组合优于简单 RAG 或微调实现。

亮点： 企业级 RAG 实践经验，树结构实体层级增强

5. TEAL: Tokenize and Embed ALL for Multi-modal Large Language Models

关键词： Multi-modal, Tokenization, Joint Embedding

摘要： 提出 TEAL 方法，将任何模态输入视为 token 序列，学习所有模态的联合嵌入空间。使用现成的 tokenizer 离散化输入，通过可学习的嵌入矩阵嵌入到联合空间。MM-LLMs 只需自回归预测多模态 token。冻结 LLM 即可执行理解和生成任务。实验显示多模态理解的显著提升。

亮点： 统一多模态 token 序列化，冻结 LLM 也能生成多模态输出

6. Deep Mamba Multi-modal Learning (DMML)

关键词： Mamba, Multi-modal, Hashing

摘要： 受 Mamba 网络启发，提出 Deep Mamba Multi-modal Learning (DMML) 用于多模态特征融合。应用于多媒体检索领域，提出 Deep Mamba Multi-modal Hashing (DMMH) 方法，结合算法准确性和推理速度。在三个公开数据集上达到 SOTA 结果。

亮点： Mamba 架构应用于多模态学习，高效检索

7. Synergy-CLIP: Extending CLIP with Multi-modal Integration

关键词： CLIP, Multi-modal, Audio-Visual-Text

摘要： 提出 Synergy-CLIP 框架，扩展 CLIP 架构以整合视觉、文本和音频三种模态。引入 VGG-sound+ 三模态数据集，提供等尺度表示。在零样本分类等下游任务上优于现有基线。引入缺失模态重建任务，展示 Synergy-CLIP 在实际场景中提取模态协同的能力。

亮点： 三模态统一学习，等尺度数据集 VGG-sound+

8. FOCAL: A Novel Benchmarking Technique for Multi-modal Agents

关键词： Agent Benchmark, Voice Agent, Error Analysis

摘要： 提出 FOCAL 框架，用于端到端推理、组件级错误传播和多模态代理（语音到语音+文本输入）的错误分析。提出两个新指标：Reasoning Score 和 Semantic Score，用于评估代理在语音模式下进行有意义对话的效果。

亮点： 语音代理基准测试框架，新的评估指标

9. Focus Agent: LLM-Powered Virtual Focus Group

关键词： Agent, HCI, Focus Group

摘要： 提出 Focus Agent 框架，LLM 驱动模拟焦点小组（数据收集）并作为人类参与者焦点小组讨论的主持人。通过 5 次焦点小组会议（23 名人类参与者）评估，定量分析表明 Focus Agent 能生成与人类参与者相似的意见。

亮点： LLM 作为焦点小组主持人和参与者，HCI 应用

10. Diagnosing and Resolving Cloud Platform Instability with Multi-modal RAG LLMs

关键词： RAG, Cloud Platform, Multi-modal

摘要： 提出 ARCA 系统，多模态 RAG LLM，结合现代 AI 工具的模式匹配能力与自然多模态 RAG LLM 界面，简化问题识别和解决。逐步评估显示 ARCA 优于现有 SOTA 替代方案。

亮点： 云平台故障诊断，多模态 RAG 实际应用
