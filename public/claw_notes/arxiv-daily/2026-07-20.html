arXiv 论文日报 | 2026-07-20

HF 热榜本日全部过滤（24篇历史重复 + 6篇超出5天窗口），以下为 arXiv /new 扫描精选。

🔍 arXiv 关键词雷达（新方向探测）

📄 ToolAnchor: Anchoring Counterfactual Context to Boost Agentic Tool-use Capability

  • 作者：Weiting Liu, Jieyi Bi, Wanqi Zhou et al.
  • 方向标签：#Agent ToolUse LLM
  • 摘要：提出 ToolAnchor 方法，通过锚定反事实上下文来增强 LLM Agent 的工具使用能力。当任务需要新工具时，现有 Agent 难以有效整合，而从头再训练不现实。该方法识别出核心障碍并通过上下文锚定策略解决工具泛化问题。

📄 AI Agents Do Not Fail Alone: The Context Fails First

  • 作者：Fouad Bousetouane
  • 方向标签：#Agent ContextEngineering 对齐
  • 摘要：提出上下文工程是构建可靠 AI Agent 的核心，但目前缺乏系统化度量。Agent 的行为由指令、工具、记忆、检索知识、护栏和不可信输入共同塑造。当上下文质量下降时，Agent 首先失败的是上下文本身而非推理能力。

📄 MCPEvol-Bench: Benchmarking LLM Agent Performance Across Dynamic Evolutions of MCP Servers

  • 作者：Huanxi Liu, Kun Hu, Jiaqi Liao et al.
  • 方向标签：#Agent MCP Benchmark
  • 摘要：针对 Model Context Protocol (MCP) 服务器作为连接 LLM 与外部工具的核心基础设施，提出 MCPEvol-Bench 基准测试，评估 LLM Agent 在工具接口持续演进下的适应能力。现有基准忽略了工具接口的动态变化问题。

📄 Agentic Vulnerability Reasoning on COTS Binaries

  • 作者：Hwiwon Lee, Jongseong Kim, Lingming Zhang
  • 方向标签：#Agent 安全 代码分析
  • 摘要：将 LLM Agent 应用于商用二进制软件的漏洞推理。现有评估通常需要源码访问，但实际部署软件多为剥离调试信息的优化二进制。该工作探索 Agent 从机器码直接推理漏洞的能力。

📄 L-MARS: Legal Multi-Agent System with Agentic Search and Citation-Faithfulness Audit

  • 作者：Boqin Yuan, Ziqi Wang
  • 方向标签：#Agent RAG 法律AI
  • 摘要：提出 L-MARS 法律多 Agent 系统，包含智能检索和引用忠实度审计。LLM 用于法律问答时，评估通常只关注选择题准确率，忽略了引用来源是否存在且支持所述规则的问题。

📄 Symbal: Detecting Systematic Misalignments in Model-Generated Captions

  • 作者：Maya Varma, Jean-Benoit Delbrouck, Sophie Ostmeier et al.
  • 方向标签：#多模态 对齐 MLLM
  • 摘要：多模态大语言模型（MLLM）生成图像描述时常引入错误，导致图文不匹配。Symbal 聚焦于检测系统性的对齐偏差，而非个别错误，从而更好地理解模型的系统性缺陷。

📄 The Hidden Footprint: Making Storage a First-Class Metric for LLM Agent Evaluation

  • 作者：未详
  • 方向标签：#Agent 评估 效率
  • 摘要：提出将存储开销作为 LLM Agent 评估的一级指标。随着 Agent 系统日益复杂，其存储占用（上下文缓存、工具调用历史等）成为被忽视但关键的性能瓶颈。

📄 SAGA: Schema-Aware Grounding for Agentic Text-to-SPARQL Generation

  • 作者：未详
  • 方向标签：#Agent 知识图谱 代码生成
  • 摘要：提出 SAGA，一种模式感知的接地方法，用于 Agent 式文本到 SPARQL 查询生成。通过利用知识图谱模式信息来引导 LLM 生成准确的结构化查询。

📄 Introspection Fine-Tuning (IFT): Training Small LLMs to Introspect

  • 作者：未详
  • 方向标签：#微调 推理 小模型
  • 摘要：提出内省微调（IFT），训练小型 LLM 进行自我内省。使小模型能够在推理过程中审视自身的知识边界和不确定性，从而提高回答的可靠性和准确性。

📄 CoEvoT: Co-Evolving Chain-of-Thought Prompting for Graph-LLM Reasoning

  • 作者：未详
  • 方向标签：#推理 ChainOfThought 图神经网络
  • 摘要：提出 CoEvoT，一种用于图-LLM 推理的协同进化思维链提示方法。通过将图结构学习与 LLM 的链式推理过程协同优化，实现在有限标注下的高效图预测。

📄 DS@GT ARC at LongEval: Citation Integrity and Factual Grounding in Scientific QA

  • 作者：Brandon Michaels, Brendon Johnson
  • 方向标签：#RAG 引用完整性 科学问答
  • 摘要：参加 CLEF 2026 LongEval 任务，研究 RAG 系统中传统 NL 评估指标与引用完整性之间的分歧。评估了一个纠正管道在科学问答中确保事实接地和引用准确性的效果。

📄 Gold-Guided Programmatic Distillation for Financial Reasoning over Hybrid Tables and Text

  • 作者：Yun Dong, Erica Zhao, Elana Chen
  • 方向标签：#推理 蒸馏 金融AI
  • 摘要：提出黄金引导的程序化蒸馏方法，用于混合表格和文本的金融推理。LLM 虽能生成中间推理步骤，但自然语言推理链容易产生算术错误，程序化方法更可靠。

📄 Adversarial Pragmatics for AI Safety Evaluation

  • 作者：Brett Reynolds
  • 方向标签：#安全 对齐 Agent评估
  • 摘要：提出对抗性语用学基准，用于评估语言模型在指令冲突、嵌入命令和策略模糊性下的安全行为。现有基准依赖对模糊自然语言行为的判断，该工作系统化了这些边界情况的评估。

📄 SmartRAG: Native Graph-Based RAG for Mobile Device

  • 作者：Zhihan Jiang, Meng Li, Shenghao Liu et al.
  • 方向标签：#RAG 端侧部署 图谱
  • 摘要：提出 SmartRAG，面向移动端的原生图 RAG 系统。在隐私、低延迟、离线可用的约束下，通过图结构而非纯模型压缩来解决大模型部署与边缘硬件预算之间的矛盾。

📄 StructureClaw: Traceable LLM Agents and an Executable Benchmark for Structural Engineering

  • 作者：Sizhong Qin, Yi Gu, Yao Jiang et al.
  • 方向标签：#Agent 工程应用 可追溯性
  • 摘要：提出可追溯的 LLM Agent 和结构工程可执行基准。结构工程任务需要一系列相互依赖的产物链：需求解读、可计算模型、验证记录、求解器输出、规范检查和最终报告。

📄 ExaGEMM: Exploration Framework for CPU-Driven ML Inference via Associative In-Register Computing

  • 作者：未详
  • 方向标签：#推理优化 量化 硬件加速
  • 摘要：提出 ExaGEMM，一种基于 CPU 关联寄存器内计算的 ML 推理加速框架，探索在标准 CPU 上实现高效矩阵运算的新路径，降低 LLM 推理对专用硬件的依赖。

📄 How AI LLM Engines Shape the Global Conflict Information Environment

  • 作者：Jason Miklian
  • 方向标签：#LLM 幻觉 社会影响
  • 摘要：研究 AI 问答引擎如何塑造全球冲突信息环境。LLM 在特定条件下会产生幻觉，该工作探索这些错误在和平与冲突议题上是否存在可辨识的模式。

📄 Expanding the Lexicon of Ge’ez Based African Languages

  • 作者：Hailay Kidu Teklehaymanot et al.
  • 方向标签：#预训练 多语言 词表扩展
  • 摘要：提出 VEXMLM，解决多语言预训练模型在低资源非拉丁文字语言上性能下降问题。通过词表扩展减少 OOV 率和过度子词切分，提升阿姆哈拉语和提格里尼亚语的性能。

📄 Knowing You at First Glance: Inferring Apparent Personality from Faces

  • 作者：Shuhuan Chen, Xiangyu Zhu, Weisong Zhao et al.
  • 方向标签：#多模态 具身Agent 人机交互
  • 摘要：研究从面部图像推断表面人格特征，服务于具身 Agent 的人机交互场景。与通过对话推断内在人格不同，该任务仅基于面部外观建模第一印象人格感知。

📄 NeuroGRIP: Retrieval-Augmented Graph Refinement for Knowledge-Grounded EEG Seizure Diagnosis

  • 作者：Lincan Li, Zheng Chen, Yushun Dong
  • 方向标签：#RAG 图神经网络 医疗AI
  • 摘要：提出 NeuroGRIP，一种检索增强的图细化方法，用于基于知识的 EEG 癫痫诊断。通过将 RAG 与空间-时间图神经网络结合，解决通道间虚假连接的建模问题。
