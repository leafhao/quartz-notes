📡 arXiv 最新扫描（2026-07-10 /new）

1. WCog-VLA: A Dual-Level World-Cognitive Vision-Language-Action Model for End-to-End Autonomous Driving

arXiv ID: 2607.08375 | 方向: cs.AI 摘要: 提出 WCog-VLA，一种具备双层世界认知能力的视觉-语言-动作模型，用于端到端自动驾驶。现有 VLA 方法要么缺乏全面的世界认知，要么世界预见能力碎片化，导致模型局限于被动驾驶。该方法通过世界认知层实现主动驾驶决策，结合视觉语言理解和动作生成。

2. Dual-Difficulty Curriculum Learning for Direct Preference Optimization

arXiv ID: 2504.07856 | 方向: cs.AI 摘要: 提出双维度难度课程学习方法改进直接偏好优化（DPO）。现有课程学习方法仅从单维度衡量难度，本文将对齐难度重构为由提示复杂度（PC）和配对区分度构成的二维空间，实现更精细的训练样本排序，提升 LLM 对齐效果。

3. UltraX: Refining Pre-Training Data at Scale with Adaptive Programmatic Editing

arXiv ID: 2607.08646 | 方向: cs.CL 摘要: 随着可用训练数据接近物理上限，Scaling Laws 的收益递减。本文提出 UltraX，一种自适应程序化编辑方法，在大规模语料库中提升数据质量而非扩展数据量，通过规模化的精炼操作改善 LLM 预训练效果。

4. MAVEN: A Multi-stage Agentic Annotation Pipeline for Video Reasoning Tasks

arXiv ID: 2605.21917 | 方向: cs.AI 摘要: 提出 MAVEN 多阶段智能体标注流水线，用于视频推理任务。训练视觉语言模型（VLM）进行视频事件推理需要高质量的结构化标注，MAVEN 通过多阶段 agent 协作实现大规模自动标注，捕获事件的时间、地点、原因和后果。

5. MASTE: A Multi-Agent Pipeline for Zero-Shot Aspect Sentiment Triplet Extraction

arXiv ID: 2607.08080 | 方向: cs.CL 摘要: 提出 MASTE 多智能体流水线，实现零样本的方面-观点-情感三元组提取。虽然 LLM 在许多 NLP 基准上表现出色，但在 ASTE 任务上效果有限。MASTE 通过多个 agent 协作分步生成，突破了单次推理的瓶颈。

6. Peer-Predictive Self-Training for Language Model Reasoning

arXiv ID: 2604.13356 | 方向: cs.CL 摘要: 提出同伴预测自训练（PST），一种无标签微调框架。多个语言模型通过跨模型聚合响应协作改进，实现无需外部监督的持续自我提升，为语言模型推理能力的自增强提供新范式。

7. Where do LLMs Fall Short in CBT-Guided Affective Reasoning?

arXiv ID: 2607.02885 | 方向: cs.CL 摘要: 研究 LLM 在认知行为疗法（CBT）引导的情感推理中的不足。现成 LLM 虽然回复流畅且有同理心，但会退化为机械式的验证与反思，无视不同 CBT 框架要求。揭示了 LLM 在结构化心理推理方面的系统性缺陷。

8. MentalHospital: A Virtual Environment for Evaluating Psychiatric Clinical Encounters

arXiv ID: 2607.08257 | 方向: cs.CL 摘要: 提出 MentalHospital 虚拟环境，用于评估 LLM 在精神科临床会诊中的表现。该基准测试覆盖多种精神疾病场景，评估模型的诊断推理、沟通技巧和临床判断能力。

9. When RLHF Fails: A Mechanistic Taxonomy of Reward Hacking, Collapse, and Gaming

arXiv ID: 2606.03238 | 方向: cs.CL 摘要: 提出 RLHF 失败的机制分类学，系统梳理奖励黑客攻击、奖励崩溃和奖励博弈等现象。为理解偏好对齐训练中的病态行为提供了统一框架，对改进 RLHF/DPO/GRPO 等后训练方法具有指导意义。

10. Diarization-Guided Qwen-ASR Adaptation for Multilingual Two-Speaker Conversational ASR

arXiv ID: 2607.08208 | 方向: cs.CL 摘要: 提出说话人分割引导的 Qwen-ASR 适配方法，用于多语言双说话人对话语音识别。通过 diarization 信息引导大型语言模型适配对话场景，解决多说话人场景下的语音转录问题。

11. FSD-VLN: Fast-Slow Dual-System Modeling for Aerial Long-Horizon Vision-Language Navigation

arXiv ID: 2607.08359 | 方向: cs.AI 摘要: 提出快慢双系统建模的视觉-语言导航方法，用于无人机长程导航。受认知心理学双系统理论启发，实现快速直觉反应与慢速深思熟虑的结合，提升空中长距离导航的规划能力。

12. ICDAR 2026 HIPE-OCRepair Competition on LLM-Assisted OCR Post-Correction

arXiv ID: 2607.08143 | 方向: cs.CL 摘要: ICDAR 2026 竞赛报告：LLM 辅助的 OCR 后校正。展示了大语言模型在历史文档 OCR 错误修复中的最新进展，涵盖多种语言和历史时期的文档处理挑战。

13. SQuaD-SQL: Efficient Text-to-SQL with Small Language Models via LLM-Guided Distillation

arXiv ID: 2607.08161 | 方向: cs.CL 摘要: 提出 SQuaD-SQL，通过 LLM 引导的知识蒸馏实现小语言模型的高效 Text-to-SQL。在保持大模型性能水平的同时，大幅降低部署成本和推理延迟，解决了 LLM 在生产环境中的部署瓶颈。

14. An Online Reference-Free Evaluation Framework for Flowchart Image-to-Code Generation

arXiv ID: 2602.13376 | 方向: cs.CL 摘要: 提出无参考在线评估框架，用于流程图图像到代码的生成评估。针对视觉-语言模型在文档处理中将流程图转换为结构化代码（如 Mermaid）的场景，解决生产环境中无 ground-truth 时的质量评估难题。

15. EasyLens: A Training-Free Plug-and-Play Subtle-Lesion Representation Amplifier for Medical Vision-Language Models

arXiv ID: 2606.06379 | 方向: cs.AI 摘要: 提出 EasyLens，一种无需训练的即插即用模块，增强医学视觉-语言模型对微小病变的敏感性。解决了 VLM 在临床图像解读中对细微病变检测不足的实际问题，可直接插入现有模型。

16. Selective Left-Shift: Turning Test-Time Compute and Difficulty-based Curation into Training Data for Low-Resource Code Generation

arXiv ID: 2607.07748 | 方向: cs.LG 摘要: 提出选择性左移方法，将测试时计算和基于难度的数据筛选转化为低资源编程语言的训练数据。解决小语言模型在 Julia 等低资源语言上性能骤降的问题，通过 SFT+DPO+难度课程学习实现突破。

17. When Synthetic Speech Is All You Have: Better Call GRPO

arXiv ID: 2607.08409 | 方向: cs.CL 摘要: 研究仅有合成语音时的 LLM-based ASR 适配问题。在银行等监管领域，真实语音采集成本高且受法律约束，合成语音成为替代方案。本文提出使用 GRPO 强化学习方法弥合合成-真实语音的声学差异。

18. When Structured Sparse Autoencoders Learn Consistent Concepts Across Modalities

arXiv ID: 2607.08605 | 方向: cs.LG 摘要: 研究结构化稀疏自编码器如何在跨模态中学习一致的概念。针对视觉-语言模型中传统 SAE 难以学习模态一致特征的问题，提出结构化方法实现跨模态概念的统一表示，推进机制可解释性研究。

19. What LLM Forecasters Know but Don’t Say: Probing Internal Representations for Calibration and Faithfulness

arXiv ID: 2607.08046 | 方向: cs.CL 摘要: 探究 LLM 预测器内部表示的校准度和忠实性。微调后的 LLM 预测器虽然准确但校准差，其思维链推理可能不忠实反映预测依据。研究发现内部表示提供了比外部输出更直接的窗口来理解模型判断。

20. Retrieval-Augmented Generation Must Move Beyond Factual Grounding to Represent Diverse Opinions

arXiv ID: 2604.12138 | 方向: cs.CL 摘要: 立场论文：RAG 系统必须超越事实性 grounding，学会表达多元观点。现有 RAG 系统存在”事实偏见”，优化认识论不确定性的同时忽视了观点内容中固有的偶然不确定性，需要范式转变来处理多元意见。
