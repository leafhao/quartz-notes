🔥 HuggingFace 社区热榜

1. RoboTALES: Learning Reasoning-Guided Robot Policies via Task-Aligned Simulated Futures

arXiv ID: 2607.06018 | 社区热度: ⬆️ 1 票
方向: Embodied AI, Video Generation for Control
摘要: 预训练视频生成模型是视觉运动控制的有力骨架，但其想象的未来轨迹常偏离任务意图且不可靠地与动作条件化。本文提出 RoboTALES，通过任务对齐的模拟未来来引导推理驱动的机器人策略学习，解决规划和策略提取中的漂移问题。

2. Token-Based Dual-view Fusion and Adaptation of Large Vision Models for Breast Cancer Classification

arXiv ID: 2607.06309 | 社区热度: ⬆️ 1 票
方向: Medical AI, Vision Model Adaptation
摘要: 乳腺癌分类需要有效融合 CC 和 MLO 两种视角的互补信息。本文提出基于 Token 的双视角融合方法，适配大型视觉模型用于乳腺X光分类，克服现有多视角学习方法的局限性。

3. AgentLens: Production-Assessed Trajectory Reviews for Coding Agent Evaluation

arXiv ID: 2607.06624 | 社区热度: ⬆️ 1 票
方向: Code Agent, Evaluation Benchmark
摘要: 多数代码 Agent 基准将运行简化为单一通过/失败位，但实际使用者体验的是整条轨迹：Agent 如何遵循指令、使用工具、验证结果。AgentLens 提出基于生产环境评估的轨迹审查基准，对交互式代码 Agent 进行全面评估。

4. Single-Rollout Asynchronous Optimization for Agentic Reinforcement Learning

arXiv ID: 2607.07508 | 社区热度: ⬆️ 1 票
方向: Agentic RL, LLM Post-training
摘要: 强化学习在 LLM 后训练中日益重要。之前的 RL pipeline 多为同步批交替式，对长时域 Agent 任务效率低下。本文提出单 rollout 异步优化方法，作为更高效的 Agentic RL 框架，适用于长时域任务的 LLM 训练。

5. Sparse Delta Memory: Scaling the State of Linear RNNs through Sparsity

arXiv ID: 2607.07386 | 社区热度: ⬆️ 1 票
方向: Efficient Architecture, Linear Attention
摘要: 线性注意力模型虽有固定状态大小和每 token 固定计算量的优势，但在长上下文召回方面落后于 softmax 注意力 Transformer。本文提出稀疏增量记忆机制，通过稀疏性扩展线性 RNN 的状态容量，缩小与 Transformer 的差距。

6. Imagined Rollouts are Kinematic, Not Dynamic: A Diagnosis of Long-Horizon World-Model Failure

arXiv ID: 2607.05966 | 社区热度: ⬆️ 1 票
方向: World Model, Long-horizon Planning
摘要: 世界模型的长时域失败通常归因于累积误差，但这一笼统框架未区分误差类型。本文提出”运动学 vs 动力学”重构：世界模型倾向于进行运动学而非动力学想象。文章将此操作化为可量化指标，诊断长时域世界模型失败的根本原因。

7. Accurate, Interdisciplinary and Transparent Structure-property Understanding with Deep Native Structural Reasoning

arXiv ID: 2607.07708 | 社区热度: ⬆️ 1 票
方向: Scientific AI, Structure-property Reasoning
摘要: 结构-性质关系是生物、化学和材料科学的基础。本文提出深度原生结构推理方法，通过解释空间、化学和周期性组织中的结构证据来机械性地解释这些关系，实现跨学科的准确、透明理解。

8. Teaching LLMs a Low-Resource Language: Enhancing Code Completion in Pharo

arXiv ID: 2607.04939 | 社区热度: ⬆️ 1 票
方向: LLM Code Generation, Low-Resource Language
摘要: LLM 在自动代码编写方面开辟了新可能性，但在训练数据稀缺的低资源语言中表现不佳。本文探索如何教会 LLM 低资源编程语言 Pharo，增强其代码补全能力，为低资源编程语言的 LLM 适配提供方法论。

9. RoboDojo: A Unified Sim-and-Real Benchmark for Comprehensive Evaluation of Generalist Robot Manipulation Policies

arXiv ID: 2607.04434 | 社区热度: ⬆️ 1 票
方向: Robotics, Generalist Policy Evaluation
摘要: 通用机器人操作策略进展迅速，但现有基准在系统评估方面仍有局限：任务简单、时域短、技能覆盖窄。RoboDojo 提供统一的仿真+真机基准，对通用机器人操作策略进行全面评估。

10. Dual Latent Memory in Vision-Language-Action Models for Robotic Manipulation

arXiv ID: 2607.07608 | 社区热度: ⬆️ 1 票
方向: VLA Model, Robotic Manipulation
摘要: 主流 VLA 模型在马尔可夫假设下仅从当前观察预测动作，难以处理长时域时序依赖任务。本文提出双潜在记忆机制，增强 VLA 模型的时序建模能力，有效应对长时域机器人操作任务。

11. HunyuanOCR-1.5: Making Lightweight OCR VLMs Faster and Better

arXiv ID: 2607.04884 | 社区热度: ⬆️ 1 票
方向: OCR, Lightweight VLM
摘要: HunyuanOCR-1.5 是轻量级端到端 OCR 专用视觉语言模型，统一了文档解析、文本检测、信息提取、图文翻译和多图文档理解。在轻量架构基础上实现更快速度和更好效果。

12. Where to cut, how deep: BPE and Unigram-LM on chemistry SMILES

arXiv ID: 2607.05691 | 社区热度: ⬆️ 1 票
方向: Tokenization, Chemistry LM
摘要: 每个读取 SMILES 的化学语言模型都始于分词器，但该领域从自然语言继承了 BPE 却少有审视。本文系统比较 BPE 和 Unigram-LM 在化学 SMILES 上的表现差异，揭示不同分词策略对化学语言建模的影响。

13. WildCity: A Real-World City-Scale Testbed for Rendering, Simulation, and Spatial Intelligence

arXiv ID: 2607.06838 | 社区热度: ⬆️ 0 票
方向: Spatial Intelligence, 3D Reconstruction
摘要: 人类可以在陌生城市导航并逐渐形成跨越数十平方公里的连贯空间心理地图。AI 能否构建同等规模的空间表征？WildCity 提供真实世界城市尺度测试平台，用于渲染、仿真和空间智能研究。

14. Infinite Worlds with Versatile Interactions

arXiv ID: 2607.07534 | 社区热度: ⬆️ 0 票
方向: World Model, Interactive Generation
摘要: LingBot-World 2.0 实现无界交互时域并保持输出质量一致性，得益于精心设计的因果预训练方案。支持多种交互模式，在无限长度的世界生成中保持稳定质量。

15. Scaling Mixture-of-Experts Video Pretraining for Embodied Intelligence

arXiv ID: 2607.07675 | 社区热度: ⬆️ 0 票
方向: MoE, Video Pretraining, Embodied AI
摘要: 视频生成模型在机器人控制方面展现前景，但因主要关注内容创作而存在域偏差——优先视觉保真度和创意而非计算效率和物理真实性。本文提出 MoE 视频预训练扩展方案，弥合内容创作与具身智能之间的鸿沟。

📡 arXiv 最新扫描（LLM 优化方向）

1. UP: Unbounded Positive Asymmetric Optimization for Breaking the Exploration-Stability Dilemma

arXiv ID: 2607.06987 | 相关度: ⭐⭐⭐
方向: GRPO/DAPO 改进, RL for Reasoning
摘要: 强化学习已成为增强 LLM 复杂推理能力的标准范式。现代 RL 框架依赖重要性采样实现样本效率，但面临探索-稳定性两难困境。本文提出 UP（无界正向非对称优化），打破 GRPO/DAPO 等方法中的探索与稳定性矛盾，实现更高效的 LLM 推理训练。

2. DiaLLM: An Investigation into the Robustness-Generation Gap in English Dialect Adaptation

arXiv ID: 2607.07669 | 相关度: ⭐⭐⭐
方向: Post-training, Dialect Alignment
摘要: LLM 虽能日益理解方言英语，但仍只能生成标准的美式英语，方言生成这一更难的问题基本未被解决。DiaLLM 通过持续预训练三个开放权重 LLM，研究鲁棒性与生成能力之间的差距，探索后训练方言适配方法。

3. Geometric Self-Distillation for Reasoning Generalization

arXiv ID: 2607.06855 | 相关度: ⭐⭐⭐
方向: Post-training, Reasoning Distillation
摘要: 在策略蒸馏是 LLM 的实用后训练方法，在学生自身轨迹上提供密集的教师监督。在特权上下文自蒸馏中，教师和学生是同一模型但教师可见提示信息。本文提出几何自蒸馏方法，改善推理泛化能力。

4. LLM-Guided Task-Semantic Field Factorization for Industrial Process Forecasting

arXiv ID: 2607.06623 | 相关度: ⭐⭐
方向: LLM for Industrial AI, Time-series
摘要: 过程工业依赖时序预测和软测量来估计难以在线测量的质量变量。标注数据稀缺，工况频繁变化。本文提出 LLM 引导的任务语义场分解方法，利用 LLM 的对齐能力解决工业过程预测中的多场景适配问题。

5. LEMUR 2: Unlocking Neural Network Diversity for AI

arXiv ID: 2607.06839 | 相关度: ⭐⭐
方向: NAS Benchmark, Architecture Design
摘要: 现有 NAS 基准仅覆盖架构设计空间的狭窄区域，缺少跨域或部署感知评估。LEMUR 2 引入大规模可扩展框架，统一生成式、评估式和部署流水线，释放神经网络多样性潜力。

6. Online Data Selection Is Implicit Alignment

arXiv ID: 2607.07023 | 相关度: ⭐⭐⭐
方向: Alignment Theory, Data Selection
摘要: SFT 通常被视为能力适配步骤，对齐归因于后续偏好优化或 RL。但当样本在微调过程中被在线评分和筛选时，“选什么数据训练”本身就隐式地执行了对齐。本文证明在线数据选择等价于隐式对齐，统一了 SFT 与对齐的理论边界。

7. Entropy Pacing Policy Optimization for Multi-Task Agentic Reinforcement Learning

arXiv ID: 2607.07178 | 相关度: ⭐⭐⭐
方向: Multi-task Agentic RL, GRPO/PPO 改进
摘要: RL 在复杂 Agent LLM 任务中展现潜力，但现有工作多聚焦单任务。本文提出熵节奏策略优化（Entropy Pacing），解决多任务 Agent RL 中的泛化问题——在 GRPO/PPO 基础上引入熵调度机制，训练能解决多种任务的通用 Agent。

8. Constrained Decoding for Diffusion Language Models via Efficient Inference over Finite Automata

arXiv ID: 2607.07026 | 相关度: ⭐⭐
方向: Structured Generation, Diffusion LM
摘要: 约束解码对 LLM 服务至关重要，确保生成输出遵循特定结构（如 JSON Schema 格式的函数调用）。现有系统专为自回归模型设计，假设从左到右生成。本文首次为扩散语言模型设计基于有限自动机的高效约束解码方法。

9. Healthier LLMs: Retrieval-Augmented Generation for Public Health Question Answering

arXiv ID: 2607.06641 | 相关度: ⭐⭐
方向: RAG, Public Health QA
摘要: LLM 在医学问答基准上表现优异，但幻觉和官方指南快速演变限制了其在公共卫生领域的应用。RAG 通过将回答锚定在显式知识库中来缓解这些风险。本文系统评估 RAG 在公共卫生问答中的有效性。

10. LLM-powered reasoning in agent-based modeling

arXiv ID: 2607.06757 | 相关度: ⭐⭐
方向: LLM Agent, Agent-based Modeling
摘要: Agent 基建模（ABM）可模拟数百万个体及其交互，对政策制定很有用。但 ABM 传统依赖静态先验，无法适应实时变化。本文提出 LLM 驱动的推理方法注入 ABM，使 Agent 能基于 LLM 推理做出自适应决策。
