🔥 HuggingFace 热榜（社区策展）

📄 SAF-OPD: Stable Advantage Fusion for On-Policy Distillation

  • 作者：Yifan Ding et al.
  • 方向：后训练 · RL融合
  • 摘要（中文）：RLVR 把单一回复级奖励广播给所有 token，而 on-policy 蒸馏(OPD)用更强教师给每个 token 打稠密优势分，但性能被教师上限锁死、也抑制超越教师的探索。两者互补，可固定系数融合两种优势会导致训练不稳。本文提出 SAF-OPD（稳定优势融合），动态调和 RLVR 与 OPD 的优势信号，在保留稠密监督的同时不牺牲探索空间。
  • 一句点评：对做 GRPO/DAPO 后训练的人是当天最值得读的一篇：把蒸馏的稠密信号和 RLVR 的探索性放进同一个优势函数里。
  • 热度：23 👍 / 1 💬

📄 Scaling Properties of Text Conditioning in Visual Generation

  • 作者：Zilong Chen et al.
  • 方向：Scaling Law · 文本条件
  • 摘要（中文）：研究视觉生成中文本条件的经验 scaling 规律。以往难以测量，因为扩散损失不随自然语言 prompt 的 token 数缩放。作者发现收敛后的扩散损失实际随 prompt 中「结构化语言」的量而缩放，并用两种互补指标（白盒似然类 + 另一类）量化结构化语言程度。
  • 一句点评：把 scaling law 的视角从模型/数据搬到「条件信息的结构性」上，对做多模态数据工程有直接启发。
  • 热度：23 👍 / 1 💬

📄 ExtractBench: A Benchmark for Schema-Guided Enterprise Document Extraction

  • 作者：Boyang Zhang et al.
  • 方向：Agent 评测 · 结构化抽取
  • 摘要（中文）：企业流程越来越依赖 agent 做 schema 引导的抽取：给定文档和用户自定义 schema，agent 需忠实遵循 schema 输出正确结果并附带溯源证据。ExtractBench 是该任务的首个基准，同时评估取值准确率、大规模下的记录完整性、grounding 质量与实测成本。
  • 一句点评：少见地把「成本」纳入 agent 评测维度，对落地型 agent 系统的选型很实用。
  • 热度：15 👍 / 0 💬

📄 Evaluation-Verification Reward for Consistent Multi-Reference Image Editing

  • 作者：Yingmao Miao et al.
  • 方向：奖励模型 · 多参考编辑
  • 摘要（中文）：多参考图像编辑仍难以在多个参考间保持视觉一致性与整体协调。RL 在文生图和单图编辑上很有效，但扩展到多参考编辑受阻于缺少能捕捉这类一致性的奖励模型。本文提出「评估-验证」双阶段奖励，专门刻画多参考一致性。
  • 一句点评：奖励设计思路可迁移：当单一标量奖励表达力不够时，拆成评估+验证两段。
  • 热度：11 👍 / 0 💬

📄 EMBL AI Librarian: Life-Sciences Knowledge Layer for AI Agents

  • 作者：Luigi Sigillo et al.
  • 方向：Agent 基础设施 · 检索层
  • 摘要（中文）：网络正越来越多被 AI agent 而非人类访问。生命科学领域的 agentic 流水线增长迅速，而 Europe PMC（4000 万+ 索引记录）这类资源是为人设计的——只接受关键词和复杂语法，返回的也是人读的结果。EMBL AI Librarian 在其上构建了面向 agent 的知识层。
  • 一句点评：「为 agent 重做检索接口」这个方向值得关注，是 RAG 之后的基础设施层。
  • 热度：4 👍 / 1 💬

🔍 arXiv 关键词雷达（新方向探测）

📄 Are the Financial Reasoning from LLMs Credible? A Real World Test over Long-Horizon Statements

  • 作者：Xinke Tong et al.
  • 分类：Computation and Language (cs.CL)　相关度评分：39
  • 摘要（中文）：LLM 是否具备真正的结构化推理，还是仅依赖表层模式匹配？金融领域要求数值精确 + 长上下文多步逻辑，是理想试验场。现有基准多为选择题或裁剪表格上的单跳 QA，忽略了真实工业级的跨表跨期复杂度。作者构建了基于长周期真实财报的测试集，系统检验 LLM 财务推理的可信度。
  • 一句点评：对评估「推理是真能力还是刷分」很有参考价值，长上下文 + 数值精度是当前最容易露馅的组合。
  • 方向标签：#推理评测 / 长上下文

📄 Learning Latent Reasoning Traces for Scalar Reward Models End-to-End

  • 作者：Sanwoo Lee et al.
  • 分类：Computation and Language (cs.CL)　相关度评分：33
  • 摘要（中文）：奖励模型是 RL 对齐 LLM 的核心。传统标量 RM 高效且概率化，但依赖表层线索，在复杂或分布外任务上泛化差；生成式 RM 靠大量推理提升鲁棒性，但推理开销大。本文让标量 RM 端到端地学习「隐式推理轨迹」，兼得两者：保持标量 RM 的效率，同时获得生成式 RM 的鲁棒性。
  • 一句点评：如果你在训 RM，这是一条明确可试的路径——不用把 RM 变成生成模型也能拿到推理带来的鲁棒性。
  • 方向标签：#后训练 / 奖励模型

📄 DRIFT: Difficulty Routing Self-DIstillation with Rhythm-Gated Exploration and Success BuFfer Training

  • 作者：Haoning Wang et al.
  • 分类：Machine Learning (cs.LG)　相关度评分：30
  • 摘要（中文）：让 LLM 在无外部专家监督下稳定自我提升，是复杂推理的核心难题。现有自蒸馏和 RL 方法缺乏对「题目级学习进度」的显式跟踪与自适应优化机制，导致训练过度优化简单题、难题监督信号弱。DRIFT 引入难度路由 + 节奏门控探索 + 成功缓冲区训练三个组件来解决。
  • 一句点评：难度路由 + 成功缓冲区，本质是给 RL 训练加课程调度，是 GRPO 类方法很实际的稳定化补丁。
  • 方向标签：#后训练 / 自蒸馏 / 数据工程

📄 Role-Agent: Bootstrapping LLM Agents via Dual-Role Evolution

  • 作者：Xucong Wang et al.
  • 分类：Artificial Intelligence (cs.AI)　相关度评分：30
  • 摘要（中文）：LLM agent 在复杂任务上表现强，但学习常受限于低效的交互反馈和静态训练环境，阻碍泛化。Role-Agent 让单个 LLM 同时扮演 agent 和环境两个角色，通过双角色协同演化自举，边生成任务边解任务，摆脱对固定环境的依赖。
  • 一句点评：self-play 在 agent 训练上的一个干净实现，不需要外部环境即可生成训练信号。
  • 方向标签：#Agent / 自演化

📄 OpenClaw and Ollama in Agentic AI: Toward Fully Autonomous and Scalable AI Agent Systems

  • 作者：Konstantinos I. Roumeliotis et al.
  • 分类：Artificial Intelligence (cs.AI)　相关度评分：28
  • 摘要（中文）：从被动响应的 LLM 到持久化、可执行动作的系统，这一转变暴露了 agentic AI 架构理解上的关键空白，尤其是推理层、编排层、执行层的分离问题。本文以 OpenClaw + Ollama 为载体，给出全栈 agentic 系统的设计与评估统一框架。
  • 一句点评：对自建 agent 系统（含 Hermes 这类）有直接参考：三层分离是可扩展性的关键。
  • 方向标签：#Agent / 系统架构

📄 TransMem: Transforming Hidden States into Memory for Large Language Models

  • 作者：Haodong Lei et al.
  • 分类：Multiagent Systems (cs.MA)　相关度评分：27
  • 摘要（中文）：LLM agent 越来越在长交互历史上运行，有效推理需要识别并利用分散在过往观察与动作中的相关证据。但此前已计算好的表示里蕴含的有用信息在后续生成中常被浪费。TransMem 提出一个轻量的推理时参数化方法，把隐状态直接转化为可复用的记忆。
  • 一句点评：不改训练、只在推理时把 hidden states 变成记忆，工程成本极低，值得实测。
  • 方向标签：#长上下文 / 推理优化 / 新架构

📄 AMTFV: Agentic Mathematical Tool-Flow Verification for LLM Self-Correction

  • 作者：Rui Zou et al.
  • 分类：Artificial Intelligence (cs.AI)　相关度评分：26
  • 摘要（中文）：LLM 数学能力强，但可靠验证候选答案仍难。现有方法要么靠自然语言反思修正（无法支持精确计算），要么直接生成验证程序（过早把数学推理与代码耦合）。AMTFV 提出 agentic 数学工具流验证：把验证拆解成工具调用流，解耦推理与执行。
  • 一句点评：自校正类工作常年不 work 的原因就是验证不可靠；用工具流做验证是绕开这个坑的正解。
  • 方向标签：#推理能力 / 自校正 / Agent

📄 RTLCurator: Label-Efficient Data Curation for RTL Generation

  • 作者：Siyang Cai et al.
  • 分类：Hardware Architecture (cs.AR)　相关度评分：25
  • 摘要（中文）：训 LLM 写 RTL 需要大量「规格-代码」配对语料，这类数据稀缺到多数公开语料已靠合成。合成能给规模但给不了正确性——两个广泛使用的 RTL 数据集里只有 24.4% 和 53.5% 的配对能通过生成的功能测试。RTLCurator 研究在标注预算极低的条件下该保留多少语料、如何筛。
  • 一句点评：把「合成数据正确率只有 24%」这个数字摆出来就很有价值。标注高效的数据策展方法论可直接迁移到其他代码/推理数据集。
  • 方向标签：#数据工程 / 合成数据

📄 LightningRL: Breaking the Accuracy-Parallelism Trade-off of Block-wise dLLMs via Reinforcement Learning

  • 作者：Yanzhe Hu et al.
  • 分类：Machine Learning (cs.LG)　相关度评分：25
  • 摘要（中文）：扩散式 LLM（dLLM）作为并行 token 生成的新范式受到关注，分块变体尤其活跃。但现有 dLLM 存在刚性的「准确率-并行度」权衡：通过激进并行解码提高每次前向的 token 数（TPF）常导致性能下降和生成质量退化。LightningRL 用强化学习打破这一权衡。
  • 一句点评：dLLM 是自回归之外少数还在推进的路线，用 RL 解决并行度-质量权衡是个新角度。
  • 方向标签：#后训练 / 新架构

📄 Self-Boosting Vision-Language Models with Noisy Student On-Policy Self-Distillation

  • 作者：Shuai Wang et al.
  • 分类：Machine Learning (cs.LG)　相关度评分：25
  • 摘要（中文）：后训练让 VLM 理解人类指令并完成下游任务。当前后训练方法通常依赖人工标注数据、外部模型蒸馏或强化学习，成本高。本文提出「噪声学生 on-policy 自蒸馏」，让模型自我提升，无需外部教师或人工标注。
  • 一句点评：noisy student 这套老方法在 on-policy 设定下复活，对没有更强教师模型时的后训练很实用。
  • 方向标签：#后训练 / 自蒸馏 / 多模态

📄 BLADE: Boundary-Expanded and Layer-Adaptive Dynamic Exit for Efficient LLM Reasoning

  • 作者：Keshu Fu et al.
  • 分类：Computation and Language (cs.CL)　相关度评分：25
  • 摘要（中文）：LLM 常靠生成长推理链提升表现，但算力大量浪费在冗余的验证和修改上。现有基于探针的早退方法主要检查显式语义信号，粒度粗。BLADE 提出边界扩展 + 层自适应的动态退出，在推理链层面细粒度地决定何时停止思考。
  • 一句点评：推理成本优化里最实用的一类——不改模型权重，只在解码阶段省算力。
  • 方向标签：#推理优化 / 动态退出

📄 When Iterative RAG Beats Ideal Evidence: A Diagnostic Study in Scientific Multi-hop Question Answering

  • 作者：Mahdi Astaraki et al.
  • 分类：Computation and Language (cs.CL)　相关度评分：25
  • 摘要（中文）：RAG 让 LLM 突破参数化知识，但迭代式「检索-推理」循环究竟何时真正优于静态 RAG 并不清楚，尤其在需要多跳的科学领域。本文做了诊断性研究：在给定「理想证据」的对照条件下，迭代 RAG 反而有时更强，并分析其原因。
  • 一句点评：「迭代 RAG 打败理想证据」这个反直觉结论说明检索循环带来的不只是证据，还有推理结构化，值得细读。
  • 方向标签：#RAG / 诊断研究

📄 NeSyFS: A Neuro-symbolic Fast-Slow Thinking Framework for LLM Agent under Partial Observability

  • 作者：Duo Xu et al.
  • 分类：Artificial Intelligence (cs.AI)　相关度评分：25
  • 摘要（中文）：LLM 越来越被部署为自主 agent（自反思、RAG、科学发现等）。这些场景中 agent 必须在有限观察下行动（部分可观测）。NeSyFS 提出神经符号的快慢思考框架：快系统用 LLM 直觉响应，慢系统用符号推理在部分可观测下做规划。
  • 一句点评：部分可观测是真实 agent 环境的常态，用符号层补 LLM 的规划短板是合理分工。
  • 方向标签：#Agent / 神经符号

📄 Don’t Mix Rewards, Mix Policies: Policy Decomposition and Optimization for Multi-Reward RL

  • 作者：Ruiming Liang et al.
  • 分类：Artificial Intelligence (cs.AI)　相关度评分：25
  • 摘要（中文）：现代 LLM 不仅要答对，还要适配不同的人类价值观和使用场景，因此多奖励 RL 越来越重要。本文主张「不要混奖励，要混策略」：不把多个奖励加权成单一标量，而是做策略分解与优化，为每个奖励维度学独立策略再组合。
  • 一句点评：多目标对齐里加权求和一直是权宜之计，策略级分解是更干净的形式化。做多维度偏好对齐的可以直接借。
  • 方向标签：#后训练 / 多目标RL

📄 Mixture-of-Translators: Translating KV Caches Across Heterogeneous Large Language Models

  • 作者：Jin-woo Lee et al.
  • 分类：Computation and Language (cs.CL)　相关度评分：23
  • 摘要（中文）：异构 LLM 系统越来越依赖共享上下文、检索证据和多 agent 对话历史，但各模型的 KV cache 是模型专属的，无法跨架构复用。Mixture-of-Translators 学习一组「翻译器」，把 KV cache 在异构 LLM 之间转换，实现跨模型缓存复用。
  • 一句点评：多模型协同系统里重复 prefill 是明显浪费；跨架构翻译 KV cache 这个想法很大胆，若可行收益巨大。
  • 方向标签：#推理优化 / KVCache
