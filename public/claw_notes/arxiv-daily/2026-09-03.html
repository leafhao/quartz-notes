arXiv 论文日报 | 2026-09-03

今日聚焦知识蒸馏、GRPO/DPO、奖励黑客、推测解码、量化、MoE、SFT 配方与安全对齐。所有英文摘要均已翻译并压缩为中文概述。

🔥 HuggingFace 热榜（社区策展）

📄 Knowledge Distillation During Mid-Training Favors Reasoning over Factual Recall

  • 作者：Jacqueline He et al.
  • 关键词：知识蒸馏、中期训练、推理能力、事实记忆
  • 摘要：研究发现，标准前向 KL 蒸馏在中期训练阶段会继续增强推理，却减慢事实记忆获取。作者提出 Switch Distillation：教师高置信时蒸馏，否则回退到交叉熵训练，从而兼顾推理、常识和事实召回，并使收益延续到后训练阶段。
  • 社区热度：1（HF API numComments 代理）

📄 Token-Efficient Data Reasoning Agents via Adaptive Structuring of Unstructured Data

  • 作者：Milad Rezaei Hajidehi et al.
  • 关键词：智能体、数据工程、RAG、Token 效率
  • 摘要：提出 agentic data cracking：智能体回答问题时，复用已加载上下文，由分支智能体顺手抽取未来查询可能复用的结构化信息。随着结构化存储积累，更多问题可绕过长文档读取；在 FanOutQA 扩展实验中成本下降 53%，准确率基本保持。
  • 社区热度：1（HF API numComments 代理）

📄 Adapting Without Gradients: Affine Statistics Transport and What Its Certificate Can Tell You

  • 作者：Salim Khazem et al.
  • 关键词：测试时适配、无梯度、部署效率
  • 摘要：提出 CASTER，在冻结模型上用目标批次统计估计仿射变换并迁移源类别分布，无需反向传播、优化器状态或源特征库。作者还设计“残差—间隔”证书判断迁移是否可靠，门控后将无条件迁移的平均负收益转为正收益。
  • 社区热度：1（HF API numComments 代理）

📄 Learning Where Outcomes Change: Credit-Addressable Reasoning for Multimodal Geometry

  • 作者：Jiani Guo et al.
  • 关键词：多模态推理、GRPO、信用分配、结构化 CoT
  • 摘要：提出可寻址信用分配：用 Code-CoT 把视觉关系写成可执行、带行号的事件，再由 CE-GRPO 在事件边界采样后续并局部归因奖励。九个几何基准平均准确率达到 76.04%，较轨迹级 GRPO 提升 3.43 个百分点。
  • 社区热度：1（HF API numComments 代理）

📄 From Production Traffic to Post-Training: Building a Self-Hosted LLM That Covers the Corporate Request Mix

  • 作者：Olga Tsymboi et al.
  • 关键词：后训练、GRPO、模型合并、生产流量
  • 摘要：从 200 多个内部应用的真实流量出发，分别针对指令遵循、函数调用和内部任务训练 GRPO 专家，再通过两阶段 SLERP 合并，避免多目标联合训练的奖励干扰。最终单模型承接约一半平台流量，并暴露了语义坍缩、过度调用和冗长奖励黑客等典型问题。
  • 社区热度：2（HF API numComments 代理）

📄 Agents in the Large: Perception-Centered Architecture for Persistent Agents

  • 作者：Shihan Dou et al.
  • 关键词：持久智能体、记忆、感知、系统架构
  • 摘要：提出面向长期服务的感知中心架构 Pera。它持续感知任务执行、内部上下文和环境变化，将信号转化为生命周期任务，以驱动服务流程的持续运行与适配，试图把智能体从一次性任务执行器推进到长期自适应系统。
  • 社区热度：1（HF API numComments 代理）

📄 Safin-1: Safety from Within through Memory-Native State Evolution

  • 作者：Ming Zhang et al.
  • 关键词：安全对齐、长上下文、记忆路由、状态演化
  • 摘要：Safin-1 将安全能力表示为模型原生状态，而非仅依靠外部护栏或事后 SFT。其 MARCH 架构维护结构化记忆并按内容路由历史信息，可在不反复修改主干参数的情况下，于测试时更新持久能力状态，在安全、长上下文、检索和效率评测上均获得提升。
  • 社区热度：1（HF API numComments 代理）

📄 SMELT: Scaling Laws for Compute-Matched MoE Looped Transformers

  • 作者：Shaowen Wang et al.
  • 关键词：MoE、循环 Transformer、Scaling Law、训练效率
  • 摘要：SMELT 在严格匹配单 Token FLOPs、非嵌入参数量和 KV Cache 的前提下，让 MoE Transformer 的中间半数层循环两次。扩展至 54B 参数后，其计算最优前沿可节省 6.8%–18.0% 训练 FLOPs，且下游增益高于验证损失所能解释的水平。
  • 社区热度：1（HF API numComments 代理）

📄 Harness-of-Harness: Multi-Day Autonomous Software Development with Continual Improvement

  • 作者：Haoyang Yan et al.
  • 关键词：代码智能体、持续改进、长程任务、自动评测
  • 摘要：提出 HoH，在现有代码智能体 Harness 之上组织规划—编码—测试迭代，通过小步可验证增量、独立评测和版本化历史实现持续改进。三个 Harness—模型组合平均相对提升 52.25%，并完成了 70 多轮、多日自主开发实验。
  • 社区热度：0（HF API numComments 代理）

📄 StudentSim: Training LLM-based Student Simulators

  • 作者：Ke Yang et al.
  • 关键词：个体化模拟、奖励模型、强化学习
  • 摘要：StudentSim 通过群体训练后再按个体专门化，把稀疏学生数据转为可响应指导的个性化模拟器。统一评测覆盖棋类、英语写作和数学；将模拟器用作导师强化学习的奖励模型后，人工评审认为所得导师优于无 RL 和 GPT-5.4 模拟器奖励基线。
  • 社区热度：2（HF API numComments 代理）

🔍 arXiv 关键词雷达（新方向探测）

📄 Instella-MoE Technical Report

  • 作者：Jiang Liu et al.
  • 提交日期：2026-09-01
  • 摘要：发布完全开放的 16B/2.8B 激活参数 MoE 模型 Instella-MoE，结合 Gated MLA 与 FarSkip-Collective，并公开预训练、中期训练、长上下文扩展、反馈数据筛选、DPO 及多教师在线策略蒸馏的完整流程。模型在同激活规模开放模型中表现有竞争力。
  • 方向标签：#MoE 新架构 后训练 数据工程

📄 Uncovering and Mitigating Aggregation-Induced Reward Hacking in Multi-Reward Reinforcement Learning

  • 作者：Yu Yuan et al.
  • 提交日期：2026-08-31
  • 摘要：指出多奖励 RL 中的固定标量化会把不同奖励轮廓压成同一分数，诱导策略偏向更易获取的维度并形成奖励黑客。AMRP 根据相对短板、波动和近期进展在线重分配权重，在 GRPO、GDPO 与 PPO 上均改善奖励平衡和下游表现。
  • 方向标签：#RLHF GRPO PPO 奖励模型

📄 Context-Grounding Gains Are Mediated by Pre-existing Machinery: Auditing GRPO, SFT, and DPO

  • 作者：Prakhar Gupta et al.
  • 提交日期：2026-09-01
  • 摘要：系统比较 GRPO、SFT 与 DPO 对“遵循上下文证据而非记忆知识”的影响。实验中五种 GRPO 的增益较小，冲突 SFT 中等，而 DPO 在匹配分布上接近满分；因果分析表明，提升主要放大了初始模型已有的注意力头与表征方向。
  • 方向标签：#GRPO DPO SFT 对齐

📄 From Rollouts to Recipes: Self-Contained Post-Training for LLMs

  • 作者：Yifei Li et al.
  • 提交日期：2026-09-01
  • 摘要：提出 Self-Routing，根据样本 rollout 的正确率和置信度，将其动态路由到 GRPO、在线自蒸馏、正则化或跳过，无需外部教师、额外标注和额外采样。在 Qwen3/Qwen3.5 数学推理实验中持续优于统一 GRPO、统一 OPSD 和固定混合策略。
  • 方向标签：#后训练 GRPO 在线蒸馏 推理优化

📄 SFAD: Speculative Factuality-Aware Decoding

  • 作者：Guanqiao Chen et al.
  • 提交日期：2026-09-01
  • 摘要：SFAD 用 DPO 训练上下文忠实的草稿模型，并在推测解码中以“认识摩擦”检测潜在幻觉；高风险时执行非对称 Logit 引导，否则保持标准推测流程。该方法在提升事实忠实度的同时实现 2.48 倍解码加速。
  • 方向标签：#推测解码 DPO 事实性 推理优化

📄 REAL-Q: E2E LLM Quantization via Dynamic Gradient Descent

  • 作者：Qian Zhang et al.
  • 提交日期：2026-08-30
  • 摘要：REAL-Q 针对逐层 PTQ 中固定 Hessian 与损失地形变化错位的问题，优化端到端对齐的代理损失，并在每个列块后执行动态块级梯度修正，配合滑动窗口平滑跨层误差。在 LLaMA-3.1 和 Qwen3 的 W4A16 设置下，端到端 KL 散度最多降低约 49%。
  • 方向标签：#量化 PTQ 推理优化

📄 Post-Training Science for Supervised Fine-Tuning

  • 作者：Charles O’Neill et al.
  • 提交日期：2026-09-01
  • 摘要：用统一实验框架系统扫描 SFT 的学习率、批量大小、LoRA/全量微调、秩与缩放、训练轮数、数据量和优化器，覆盖 Qwen3、Llama、稠密及 MoE 模型，最高达 235B 参数。工作旨在给出可迁移的选择规则，并为每条建议量化不确定性。
  • 方向标签：#SFT LoRA 后训练 ScalingLaw

📄 When Safety Routing Breaks: Understanding Alignment Fragility under Benign Fine-Tuning

  • 作者：Yitong Guo et al.
  • 提交日期：2026-09-01
  • 摘要：从 Fisher 几何解释良性微调为何破坏安全对齐：安全 Fisher 呈低秩，少量微调会重新锐化输出侧 MLP 的安全路由通道，使拒答能力快速坍塌而通用能力变化较小。LoRA 和 ASAM 能缓解早期坍塌，但数据规模增大后保护减弱。
  • 方向标签：#安全对齐 SFT LoRA

📄 CARE: Contrastive Anchor-based Rubric Evolution for Large Language Model Post-Training

  • 作者：Siyuan Li et al.
  • 提交日期：2026-09-01
  • 摘要：针对开放式任务中静态评分细则会被策略逐渐“刷分”的问题，CARE 用前沿模型生成的高质量锚点回答约束评分细则演化，并以自适应修复与主动追赶两条分支维护高奖励区域的判别力。其在 300 步训练中持续提高相对 GPT-4.1 锚点的胜率。
  • 方向标签：#后训练 奖励模型 奖励黑客 对齐

📄 Scaling Near-Optimal SFT-RL Annotation Budget Allocation from Small to Large LLMs

  • 作者：Jingtan Wang et al.
  • 提交日期：2026-09-01
  • 摘要：研究固定标注预算如何在 SFT 与 RL 数据之间分配。结果显示，与其寻找单一最优比例，不如确定性能接近峰值的宽“近优区域”；该区域会随模型规模扩大，并可从小代理模型稳定迁移到大模型，从而避免昂贵的大规模穷举搜索。
  • 方向标签：#SFT RLHF 数据工程 ScalingLaw
