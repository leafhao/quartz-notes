📌 今日亮点

🛡️ ClawGuard: Tool-Augmented LLM Agent 安全框架

ClawGuard: A Runtime Security Framework for Tool-Augmented LLM Agents Against Indirect Prompt Injection

  • 作者: Wei Zhao, Zhe Li, Peixin Zhang, Jun Sun
  • 方向: Agent 安全
  • 亮点: 提出确定性工具调用边界强制机制，防御间接提示注入攻击，无需模型微调或架构修改。

🔍 Meerkat: Agent 轨迹安全审计

Detecting Safety Violations Across Many Agent Traces

  • 作者: Adam Stein, Davis Brown, Hamed Hassani, Mayur Naik, Eric Wong
  • 方向: Agent 安全审计
  • 亮点: 结合聚类与智能搜索发现安全违规，在 CyBench 上发现的 reward hacking 案例比之前审计多近 4 倍。

📚 论文列表

1. Who Handles Orientation? Investigating Invariance in Feature Matching

  • arXiv: 2604.11809
  • 作者: David Nordström, Johan Edstedt, Fredrik Kahl, Georg Bökman
  • 分类: cs.CV
  • 摘要: 研究现代稀疏匹配管道中旋转不变性应融入的阶段。发现在描述子中融入旋转不变性与在匹配器中处理效果相似，但前者能更快实现。发布了两个对平面旋转鲁棒的匹配器，在多模态、极端图像匹配等任务上达到 SOTA。

2. Pair2Scene: Learning Local Object Relations for Procedural Scene Generation

  • arXiv: 2604.11808
  • 作者: Xingjian Ran, Shujie Zhang, Weipeng Zhong, Li Luo, Bo Dai
  • 分类: cs.CV
  • 摘要: 提出新的程序化场景生成框架，通过学习局部规则（支撑关系和功能关系）与场景层次结构和物理算法结合，生成超出训练分布的复杂场景。

3. Detecting Safety Violations Across Many Agent Traces

  • arXiv: 2604.11806
  • 作者: Adam Stein, Davis Brown, Hamed Hassani, Mayur Naik, Eric Wong
  • 分类: cs.AI, cs.CL
  • 摘要: 提出 Meerkat，结合聚类与智能搜索发现 Agent 安全违规。在误用、对齐偏差和任务博弈设置中显著提升违规检测能力，发现 AgentDojo 上广泛的开发者作弊行为。

4. Solving Physics Olympiad via Reinforcement Learning on Physics Simulators

  • arXiv: 2604.11805
  • 作者: Mihir Prabhudesai, Aryan Satpathy, Yangmin Li, et al.
  • 分类: cs.LG, cs.AI, cs.CV, cs.RO
  • 摘要: 利用物理模拟器生成合成问答对，通过强化学习训练 LLM 物理推理能力。仅使用模拟数据训练，在 IPhO（国际物理奥林匹克）问题上性能提升 5-10 个百分点。

5. Psychological Concept Neurons: Can Neural Control Bias Probing and Shift Generation in LLMs?

  • arXiv: 2604.11802
  • 作者: Yuto Harada, Hiro Taiyo Hamada
  • 分类: cs.CL
  • 摘要: 研究大五人格特质在 LLM 中的表示和干预。发现人格信息在早期层即可解码，概念选择性神经元主要分布在中层。干预这些神经元可影响探测读数，但对生成标签的影响较弱且存在跨特质溢出。

6. CLSGen: A Dual-Head Fine-Tuning Framework for Joint Probabilistic Classification and Verbalized Explanation

  • arXiv: 2604.11801
  • 作者: WonJin Yoon, Kangyu Zhu, Ian Bulovic, et al.
  • 分类: cs.CL
  • 摘要: 提出新框架解决 LLM 分类任务中的概率估计问题，避免灾难性遗忘和语言崩溃。在 AUROC 和 F1 指标上超越现有方法，同时保持解释生成能力。

7. C-ReD: A Comprehensive Chinese Benchmark for AI-Generated Text Detection Derived from Real-World Prompts

  • arXiv: 2604.11796
  • 作者: Chenxi Qing, Junxi Wu, Zheng Liu, et al.
  • 分类: cs.CL, cs.AI
  • 摘要: 提出全面的中文 AI 生成文本检测基准，解决模型多样性和数据同质性问题。支持域内检测和泛化到未见 LLM 及外部中文数据集。

8. Disentangled Point Diffusion for Precise Object Placement

  • arXiv: 2604.11793
  • 作者: Lyuxing He, Eric Cai, Shobhit Aggarwal, Jianjun Wang, David Held
  • 分类: cs.RO
  • 摘要: 提出分层解耦点扩散框架 TAX-DPD，用于精确物体放置。通过 Dense GMM 建模全局放置先验，点云扩散模块分别建模物体几何和放置框架，在仿真和真实工业插入任务中达到 SOTA。

9. A Mechanistic Analysis of Looped Reasoning Language Models

  • arXiv: 2604.11791
  • 作者: Hugh Blayney, Álvaro Arroyo, Johan Obando-Ceron, et al.
  • 分类: cs.LG, cs.AI
  • 摘要: 对循环推理语言模型的潜在状态进行机制分析。发现循环块学习到的推理阶段与前馈模型相似，并在每次迭代中重复这些阶段。

10. ClawGuard: A Runtime Security Framework for Tool-Augmented LLM Agents Against Indirect Prompt Injection

  • arXiv: 2604.11790
  • 作者: Wei Zhao, Zhe Li, Peixin Zhang, Jun Sun
  • 分类: cs.CR, cs.AI
  • 摘要: 提出 ClawGuard 运行时安全框架，在每次工具调用边界强制执行用户确认的规则集，防御间接提示注入。无需模型修改或基础设施变更，在 AgentDojo、SkillInject、MCPSafeBench 上验证了有效性。
