1. ExpRL: Exploratory RL for LLM Mid-Training

arXiv ID: 2606.17024 | 社区热度: ⬆️ 0 票
方向: 强化学习、推理优化
摘要: 稀疏奖励强化学习已成为提升 LLM 推理能力的标准工具，但其成功严重依赖基础模型的覆盖度。ExpRL 提出了一种更自动化的方法：使用大规模人类问答数据进行基于 RL 的中期训练。该方法将参考解决方案作为奖励脚手架，而非模仿目标——参考答案对策略隐藏，仅用于构建问题特定的评分标准来评判策略生成的推理轨迹。ExpRL 在数学推理任务上的表现优于 SFT、稀疏奖励 GRPO 和自蒸馏，并为后续稀疏奖励 RL 提供了更好的初始化。

2. Human Universal Grasping

arXiv ID: 2606.17054 | 社区热度: ⬆️ 0 票
方向: 机器人、抓取
摘要: 人类能够轻松抓取物体，而多指机器人远未达到这种通用性。HUG 提出了一个流匹配模型，可为用户指定的任何物体生成多样的人类抓取姿态。通过智能眼镜，研究团队收集了 1M-HUGs 数据集，包含 100 万帧（27.8 小时）的第一人称抓取数据，覆盖 6707 个物体实例和 41 栋建筑。预测的抓取姿态可以重定向到各种机器人手，实现日常场景中的零样本抓取。在 30 个真实物体的测试集上，HUG 比最先进的抓取基线高出 +23% 和 +34%。

3. EgoPhys: Learning Generalizable Physics Models of Deformable Objects from Egocentric Video

arXiv ID: 2606.16202 | 社区热度: ⬆️ 0 票
方向: 物理模拟、可变形体
摘要: 人类通过日常交互自然理解物体物理，但准确预测复杂的可变形动力学（如弹性材料和织物）仍是计算机视觉和机器人学的重大挑战。EgoPhys 提出了一个框架，可从第一人称纯 RGB 视频中构建可变形物体的物理数字孪生。通过将逐物体的逆物理解决方案蒸馏到紧凑的码本中，EgoPhys 能够为未见物体预测密集的弹簧刚度场，无需逐弹簧的测试时优化。在真实 xArm6 机器人上部署后，从单个第一人称人类游戏视频初始化的数字孪生可作为内部世界表示，辅助可变形物体规划。

4. LaWAM: Latent World Action Models for Efficient Dynamics-Aware Robot Policies

arXiv ID: 2606.15768 | 社区热度: ⬆️ 0 票
方向: 机器人控制、世界模型
摘要: 视觉-语言-动作模型（VLA）利用大规模视觉-语言预训练实现语义机器人控制，但通常缺乏对机器人动作如何改变场景的显式预见能力。LaWAM 是一个潜在世界动作模型，通过紧凑的潜在视觉子目标而非重建的未来视频，向机器人策略暴露预测动力学。LaWAM 在 LIBERO（98.6% 成功率）、RoboTwin（91.22% 成功率）和真实世界操作任务上达到了最先进或竞争性的成功率，同时保持低延迟推理（每个动作块预测 187 毫秒，比像素空间 WAM 低 24 倍的墙钟延迟）。

5. The Ghosts of Polymarket: When Off-Chain Matches Meet On-Chain Reverts

arXiv ID: 2606.16852 | 社区热度: ⬆️ 0 票
方向: DeFi、安全
摘要: Polymarket 作为 DeFi 中增长最快的预测市场平台，采用链下匹配但链上结算的混合架构。这种设计产生了一个一致性间隙，称为”幽灵填充”（Ghost Fills）：链下成功匹配的订单可能在链上结算时失败。研究团队通过构建 GHOSTHUNTER 工具，从链上追踪中重建失败的结算并归因于具体攻击模式。在 1,952,440 笔撤销的匹配订单交易中，发现攻击者利用匹配与结算之间的时间间隙，在已匹配订单最终确认前使其失效。识别出四种攻击向量：nonce bump、余额耗尽、授权撤销和代理陷阱，通过 35 种演变变体实现。这些攻击允许选择性撤销 980,133 笔已填充订单，实现至少 149 万美元的利润，影响 17.8 亿美元资金和 217 万 POL（约 21.2 万美元）。

6. Hierarchical Advantage Weighting for Online RL Fine-Tuning of VLAs from Sparse Episode Outcomes

arXiv ID: 2606.17043 | 社区热度: ⬆️ 0 票
方向: 强化学习、机器人
摘要: 当预训练的 VLA 策略通过在线 RL 进行微调时，每个回合仅产生一个二元结果（成功或失败），但 actor 更新需要逐转移的监督。现有方法通常将这种稀疏结果简化为单个标量奖励或优势信号，这混淆了不同形式的转移级反馈，并在基本任务成功可达后提供有限的指导。HABC 提出了分层优势加权行为克隆，为可行性和效率这两个目标训练独立的 critic 头，并通过状态自适应平衡组合它们的输出。在三个接触丰富的双臂任务的真实机器人实验中，HABC 将监督微调基线的成功率从 36%、44% 和 12% 提升到 92%、88% 和 38%。

7. SP^3: Spherical Priors for Plug-and-Play Restoration

arXiv ID: 2606.16396 | 社区热度: ⬆️ 0 票
方向: 图像恢复、扩散模型
摘要: SP^3 是一种新颖的即插即用算法，通过将去噪器替换为球形编码器（SE）作为生成先验，加速最大后验图像恢复。SP^3 利用 SE 紧密结构化的潜在空间作为对自然图像流形的鲁棒投影，近似难以处理的近端先验步骤。通过半二次分裂，将此投影与闭式数据一致性步骤交替，实现稳定收敛，无需在推理期间计算梯度。这种独特的公式解锁了”随时”恢复能力，从第一次迭代就能产生清晰、合理的图像。在各种图像恢复任务的评估中，SP^3 达到了与最先进的零样本扩散和流方法相当的感知质量，同时快 3-630 倍。

8. GD^2PO: Mitigating Multi-Reward Conflicts via Group-Dynamic reward-Decoupled Policy Optimization

arXiv ID: 2606.16771 | 社区热度: ⬆️ 0 票
方向: 强化学习、多目标优化
摘要: 随着 LLM 的发展，训练后强化学习越来越依赖多维奖励来培养全面能力。这种转变需要能够同时优化多样且可能竞争的目标的新算法。GD^2PO 提出了群组动态奖励解耦策略优化，采用冲突感知过滤机制屏蔽遭受严重奖励分歧的回合。通过防止冲突信号相互抵消，这种屏蔽策略保留并增强了有效 RL 优势的幅度，从而显著加速学习效率。此外，引入查询级重新加权，根据整体奖励共识动态调整每个查询的更新强度。在工具调用和人类偏好对齐等各种多奖励场景的实验表明，GD^2PO 持续且显著优于现有基线。

9. MMDiff: Extending Diffusion Transformers for Multi-Modal Generation

arXiv ID: 2606.16673 | 社区热度: ⬆️ 0 票
方向: 扩散模型、多模态
摘要: 扩散 transformer 展示了卓越的生成能力，但在内容渲染后，其去噪轨迹中计算的丰富感知表示被丢弃。MMDiff 提出了一个框架，将冻结的扩散 transformer 转换为多模态生成系统，使用轻量级解码器头联合生成图像及任意密集感知模态组合。核心发现是感知信息沿去噪轨迹在时间上分布，多时间步特征融合与空间变化的聚合权重至关重要，比单时间步提取在语义分割上提升高达 28.7% mIoU。通过仅在冻结主干上训练轻量级解码器头，在语义分割、显著物体检测和深度估计中实现了强劲性能，并证明该框架能够大规模有效生成合成数据。

10. DreamX-World 1.0: A General-Purpose Interactive World Model

arXiv ID: 2606.16993 | 社区热度: ⬆️ 0 票
方向: 世界模型、视频生成
摘要: DreamX-World 1.0 是一个通用交互式文本/图像到视频世界模型，用于可控的长时序生成。它支持相机导航、重访先前观察区域以及跨逼真、游戏风格和风格化领域的可提示事件。数据引擎结合了相机精确的虚幻引擎渲染、动作丰富的游戏录制和具有恢复相机几何的真实世界视频。通过因果强制、DMD 风格蒸馏和长回合训练，将双向视频生成器转换为少步自回归世界模型。在自生成的长时序上下文上训练使模型暴露于自己生成的历史，减少跨自回归块累积的风格和颜色漂移。在 5 秒基础评估中，DreamX-World 1.0 达到 73.75 的相机控制得分和 84.76 的总分，超越 HY-WorldPlay 1.5 和 LingBot-World。

11. PermaVid: Consistent Video Generation Across Edits via Disentangled Context Memory

arXiv ID: 2606.16449 | 社区热度: ⬆️ 0 票
方向: 视频生成、一致性
摘要: 在编辑操作下的一致视频生成需要持久性：当编辑修改场景外观或布局时，后续生成应在时间和视点上保持连贯。然而，现有记忆设计在此类修改后难以维持长期一致性，因为存储的上下文可能变得过时或无效。PermaVid 提出了一个新框架，建立在多模态上下文记忆之上，将空间上下文解耦为语义外观和几何结构，并配合编辑感知的记忆更新和检索策略，使记忆演化与后续观察保持一致。实验表明，该方法在编辑后保持强大的长期语义和结构一致性，显著优于最先进方法。

12. Geometric Action Model for Robot Policy Learning

arXiv ID: 2606.17046 | 社区热度: ⬆️ 0 票
方向: 机器人、几何推理
摘要: 通用机器人策略必须遵循用户指令，同时推理物体、相机和机器人动作在 3D 物理世界中的交互。最近的视觉-语言-动作模型（VLA）和视频世界-动作模型（WAM）从大规模基础模型继承了强大的语义或时间先验，但它们主要在 2D 图像帧或 2D 派生的潜在空间上操作，将接触丰富操作所需的 3D 几何隐式化。GAM 提出了几何动作模型，这是一种语言条件操作策略，直接重新利用预训练的几何基础模型（GFM）作为感知、时间预测和动作解码的共享基底。在广泛的仿真和真实机器人操作基准测试中，GAM 比当前基础模型规模的基线更准确、更鲁棒、更快且更轻。

13. Implicit Reasoning for Large Language Model-based Generative Recommendation

arXiv ID: 2606.14142 | 社区热度: ⬆️ 0 票
方向: 推荐系统、推理
摘要: 大型语言模型（LLM）越来越多地被采用作为生成式推荐（GR）的主干，有望访问预训练的世界知识。然而，可靠地调用这些知识用于 GR 仍然知之甚少。关键障碍在于基于 LLM 的 GR 通常使用语义 ID（SID）表示项目，破坏了 LLM 的自然语言推理接口，因为这些 token 在预训练期间未被 LLM 见过。PauseRec 提出了一个轻量级隐式推理范式，专为 GR 量身定制。PauseRec 异常实用，避免了昂贵的推理轨迹获取和推理对齐训练，带来诸多好处：(1) 比标准显式 CoT 方法高出 6.22%，(2) 减少高达 65% 的 GPU 小时训练成本，(3) 加速推理高达 71.3%。

14. Tangram: Unlocking Non-Uniform KV Cache Compression for Efficient Multi-turn LLM Serving

arXiv ID: 2606.06302 | 社区热度: ⬆️ 0 票
方向: LLM 服务、KV 缓存
摘要: 多轮 LLM 服务累积对话历史，其键值（KV）缓存随每轮和每个用户增长，迅速超过模型权重本身，使内存而非计算成为吞吐量的约束。非均匀 KV 压缩在注意力头之间分配异构预算，比均匀方案更好地保留准确性，但仍不实用：现代服务栈假设头之间的 KV 长度相同，因此异构性将释放的内存困在页面碎片中，在预填充时间中花费高达 25% 回收分散的页面，并使 GPU 工作负载偏斜，将解码延迟膨胀高达 1.7 倍或在每个解码步骤中消耗 15-20% 用于重新规划。Tangram 观察到这种异构性无需在运行时发现：头部保留遵循两级结构规律性——输入不变的头排名与窄界的每头比率——可以从少至 50 个样本离线校准。基于此洞察，Tangram 静态解决先前系统动态处理的内容。在 vLLM 上实现后，Tangram 作为现有非均匀压缩方法的即插即用基底，匹配其准确性，同时相对完整 KV 基线提升端到端吞吐量高达 2.6 倍。
