本期主线：国产模型涨价潮 + 开源 Agent Harness 混战

两条最硬的叙事同时在国产阵营发生。DeepSeek 于 8/17 零点启用分时定价，高峰段输出价格拉到 27 元/百万 tokens（此前 4.5 倍），缓存未命中升至 9 元/百万；V4-Flash 从 0.28跳到1.32，V4-Pro 从 0.87跳到3.96。同一时间它把 Harness v0.1 以 MIT 协议开源，直接对标 Claude Code。「便宜换量」的阶段结束了，转向「先把 agent 生态占住，再按算力真实成本收钱」。

海外这一侧，开源 agent harness 在一周内冒出两个新玩家（TrueForge、Nutanix MCP server），同时 The Hacker News 披露 MCP server 会泄露企业密钥——工具层刚热起来，安全债已经浮出水面。

两条结构性信号：

  • Physical AI 成为下一波主场：Crunchbase 统计 H1 2026 机器人 / 航天等实体 AI 吸金数十亿美元。国内同步印证——宇树科技科创板上市首日涨超 600%，市值 3640 亿元。
  • VC 内部开始自我警告：Thrive Capital 的 Joshua Kushner 公开批评硅谷 VC 的 AI 狂热（8/14, TechCrunch）。另有报告称先进芯片封装因 AI 需求走到 $1000 亿量级的拐点。

四、政策与治理

  • EU Digital Omnibus on AI 已生效；EDPB 就生成式 AI 的网络爬取开启指南咨询；英国设立法律服务 AI Growth Lab
  • 越南禁止涉密文件上传 AI 平台（8/14 报道）：东南亚首个强制执行性指令。越南也是该区域唯一在议会层面通过约束性 AI 立法的国家，与 ASEAN 自愿性指南形成对照
  • NYC Bar 呼吁全国统一 AI 规则框架（8/13）：结论是 AI 工具「可辅助法律工作，但不能替代专业法律判断」
  • 俄克拉荷马州考虑规制 AI 竞选广告：30+ 州已立法，主流做法是强制可见披露而非禁止（避免诉讼风险）
  • IAB 广告 AI 透明度与披露框架 V2（8/18）
  • 中国以 WAICO 推进全球 AI 治理议程，叠加 2023 全球 AI 治理倡议、2025 十三点行动计划与能力建设行动计划

值得跟进的三条

  1. 国产模型定价从「补贴」转「按成本收钱」：DeepSeek 涨价 4.5 倍、智谱 GLM-5.1 曾提价 10%，同时 Coding/Agent 能力全线上推。国产 API 的性价比优势正在收窄，用国产 API 做重度 agent 编排的成本模型需要重算。
  2. Agent harness 层进入开源混战：DeepSeek Harness、TrueForge、Codex CLI、Claude Code 各占一路。谁定义 harness 的插件协议，谁就拿到 agent 生态的分发位。
  3. MCP 的安全债：企业级 MCP 实现一周内新增两家，凭证泄露披露同期出现。自建 MCP server 前先把凭证隔离和最小权限做掉。
