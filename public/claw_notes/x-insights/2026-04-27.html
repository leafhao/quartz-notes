💰 AI 投资与估值动态

Anthropic 万亿估值风暴

二级市场突破 $1T

  • 4 月 17 日，Anthropic 在 Caplight/Ventuals 等二级交易平台隐含估值短暂突破 $1 trillion
  • 年化收入从 2025 年末 9B飙升至30B（4 个月增长 233%）
  • 官方估值仍为 380B（SeriesG，30B 融资后）

争议焦点

  • OpenAI 指控 Anthropic 通过 gross accounting 夸大收入 $80B
  • 盈利预计 2027 年才能实现
  • 多家 VC 已报价 $800B+，Anthropic 未接受

投资逻辑转向

  • 华尔街重新评估：“安全优先”投资逻辑被验证
  • 企业客户重视可靠性+护栏，监管重视问责
  • Anthropic 构建两者，万亿估值是”市场的收据”

DeepSeek 首轮融资

  • 3 年来首次寻求外部融资，目标 300M+，估值超10B
  • 创始人梁文峰此前坚持独立研发，芯片短缺比资金更关键
  • 新融资解决人才保留与商业化转型

OpenAI $110B 融资

  • 全球史上最大 VC 交易，估值 $840B
  • 2026 年 2 月全球 VC 融资创纪录 $189B，AI 三巨头占 83%

🤖 AI Agent 与编码工具演进

自主 Agent 时代

从建议到执行

  • 2026 年最大转变：从单次提示响应 → 多步骤规划执行循环
  • Agent 可拆解任务、调用终端/API、运行测试、迭代修正

主流 Agent 工具排名

工具定位关键特性

MCP 协议崛起

  • Model Context Protocol 成为 Agent 连接外部数据/API 的统一标准
  • 几乎所有主流编码 Agent 支持 MCP

Agent Teams 架构

未来趋势：专业化 Agent 协作

Planner → Architect → Implementer → Tester → Reviewer
  • 类似真实工程团队分工
  • 提升复杂任务可靠性
  • Google DeepMind/Anthropic 实验室已验证可行性

  • 强调”可持续推理”与”跨系统协作”能力

📈 趋势洞察

1. AI-native 架构成刚需

  • 2026 年产品设计必须围绕多模型编排、Agent workflow、无缝 AI 集成
  • 不再是”把 AI 挂到现有系统”，AI 本身就是架构

2. 企业战场转向编码

  • Claude Code 收入占比超半，企业订阅爆发
  • 编码 Agent 成为 AI 公司收入核心引擎

3. 投资忠诚度消亡

  • 至少 12 家 OpenAI VC 同时投资 Anthropic
  • Founders Fund、Iconiq、Insight、Sequoia 双边下注

4. 上下文窗口竞争白热化

  • Claude：1M tokens（Opus 4.6 Beta）
  • Gemini：1M tokens（3 Pro）
  • GPT：约 250K（Enterprise）
  • 长文档/代码库分析成为关键战场
