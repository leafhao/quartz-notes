2. 学术与研究

「Mind Viruses」：Agent 之间的自传播观念（08-21，本期最值得读） 论文 Mind Viruses: Self-Propagating Ideas in Multi-Agent LLM Systems，作者为 Anthropic Fellows Program 的 Vassilis Papadopoulos、McNair Shah，联合 Anthropic 研究员 Sam Zimmerman、Jack Lindsey，已投 arXiv。 核心发现：AI Agent 可以说服彼此采纳目标与信念，且这些观念会继续向下传播——有时能在接收方 Agent 记忆被完整重置后依然存活。 → https://www.linkedin.com/pulse/new-paper-shows-how-self-propagating-ideas-spread-between-borish-oapte 💡 对多 Agent 系统设计的直接含义：单点记忆清理不构成有效隔离边界，需要在协议/编排层做约束。

SemiAnalysis：CUDA 护城河在 Agentic 推理下还成立吗（08-21 数据分界） 实测结论有明确时间分界：2026-08-21 之前，AMD MI355X + SGLang 在 e2e 性价比上已追平 B200 + vLLM（但 B300 vLLM 和 B200 SGLang 仍领先）；08-21 之后，因 Inferact 与 Nvidia 对 vLLM 的优化落地，B200 的每美元性能反超 MI355X。 → https://newsletter.semianalysis.com/p/agentx-inferencexv3-does-cuda-moat 💡 这是「软件栈优化速度决定硬件竞争格局」的教科书案例——硬件没换，一次 vLLM 优化就把性价比曲线翻转了。

LLM 能出人格测验，还能预测答案（08-22） 希伯来大学（HUJI）医学神经科学系博后 Monsa 为一作。核心论点：人格特质本身反映在语言中，LLM 在训练过程中把人类人格结构当作副产品学到了——没有专门教心理学，结构已经嵌在语言里。 → https://www.jpost.com/science/article-906137

AI 评审偏好 AI 生成内容，且「论文洗稿」可轻易套利（08-23，Forbes） 组织越来越多用 LLM 评估书面材料（简历、论文投稿）。Lance Eliot 指出：AI 评审分数可通过「paper laundering」（让 LLM 重写一遍）显著提升，机制上是可套利的。 → https://www.forbes.com/sites/lanceeliot/2026/08/23/ai-prefers-ai-generated-content-so-game-those-ubiquitous-ai-assessments-by-having-ai-write-your-materials-if-you-dare/

从模型到 Agent：分子发现的下一阶段（08-21，GEN） Agentic AI 平台（如 Vecura）进入药物-靶点交互建模场景，配了较完整的文献引用。生物医药方向的 agent 化综述。 → https://www.genengnews.com/topics/artificial-intelligence/from-models-to-agents-the-next-phase-of-ai-adoption-in-molecular-discovery/

本周判读

1. Agent 安全从理论问题变成责任问题。 三条线在同一周汇合：Mind Viruses 论文证明观念可跨 Agent 传播且抗记忆重置（技术层）、Guidelight 记分卡显示没有实验室达标遏制实践（治理层）、Bloomberg Law 报道 rogue agent 已造成实际入侵和责任真空（法律层）。做多 Agent 系统的人现在有了具体的失败模式可以设计防御，而不只是抽象担忧。

2. 软件栈优化的杠杆比想象中大。 SemiAnalysis 那条 08-21 的分界线值得记住：硬件一颗没换，vLLM 的一轮优化就把 B200 vs MI355X 的性价比曲线翻转了。评估推理硬件选型时，「当前性价比」的半衰期可能只有几周。

3. 硬件融资进入「客户即投资人」阶段。 Etched 的 7亿轮由JaneStreet领投，逻辑是先买硬件跑起来、再投钱——这种信号质量远高于纯财务轮。同时Nvidia一手涨价15300 亿），供应链关系在被重新定价。

4. 全球 AI 立法进入「中等国家批量落子」期。 印尼、土耳其、韩国在一周内各自出框架，共同点是都在明确处理 agentic AI（自主发起交易、与外部系统交互）。这说明监管语言已经从「生成式 AI」升级到「代理式 AI」，比欧美主流讨论的节奏并不慢。

5. AI 内容治理正在被现实打败。 华盛顿邮报论证检测工具原理上不可持续，同一周 Teachers Pay Teachers 被 AI 教案冲垮。加上 Forbes 报道的「AI 评审偏好 AI 内容、洗稿可套利」，指向同一结论：靠检测守门的路线走不通，需要转向来源验证和责任归属机制。
