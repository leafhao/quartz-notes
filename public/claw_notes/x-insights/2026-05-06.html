🔥 热门话题

1. 前沿模型发布动态

OpenAI

  • GPT-5.4（3月5日发布）：首个真正统一的前沿模型，1M token 上下文窗口，83% GDPVal 分数，在桌面任务测试中达到75%成功率
  • GPT-5.5（传闻）：OpenAI 进行了全架构重新训练，成为新的基准标杆
  • Workspace Agents：OpenAI 宣布团队可共享的工作空间代理，超越个人生产力场景

Anthropic

  • Claude Opus 4.6（2月5日）和 Claude Sonnet 4.6（2月17日）：1M token 上下文窗口（beta），改进编码能力，部署到 Microsoft PowerPoint 和 Excel
  • Claude Mythos 5：Anthropic 最前沿模型，通过 Project Glasswing 项目向 AWS、Apple、Cisco、Google、JPMorgan Chase、Microsoft 等机构提供访问权限，用于发现和修复关键软件漏洞
  • Memory 功能：3月初向所有 Claude 用户推出，支持跨对话保持上下文和偏好

Google DeepMind

  • Gemini 3.1 Pro（2月19日）：13/16 基准测试领先，77.1% ARC-AGI-2 分数（是 Gemini 3 Pro 的两倍）
  • Gemini 3.1 Flash-Lite（3月）：大幅降价，推理成本优化

xAI

  • Grok 4.20 Beta 2（3月3日）：最适合实时数据访问和多代理工作流
  • Grok Imagine 1.0（2月2日）

Meta

  • Muse Spark：Meta 重构的 AI 实验室发布的首个模型，专为 Meta 产品集成的多模态模型

2. 国内 AI 厂商动态

DeepSeek（深度求索）

  • DeepSeek V3.2（2025年12月发布，仍在主力）：推理优先的 MoE 模型，专为 Agent 构建
  • DeepSeek V4 Preview：大型模型（超 1T 参数），性能接近前沿模型，运行成本极低，SWE-Bench 预期分数超过80%，定价 0.30−0.50/百万 tokens

Moonshot AI（月之暗面）

  • Kimi K2.5（1月开源）：万亿参数模型，支持多模态代理工作流，Agent Swarm 功能可同时调度100个并行子代理，SWE-Bench Verified 71.3%
  • Kimi K2.6：持续迭代
  • Kimi Coding Tool：与 Claude Code 直接竞争的编码工具，兼容 OpenAI API 协议

Alibaba（阿里云通义）

  • Qwen 3.6 Plus：效率突破型模型，性能接近 Claude Opus 4.5，规模不到 Kimi K2.5 的一半，1M token 上下文窗口
  • Qwen3-Coder-Next：专为代理编码设计的高效编码模型

3. 开源模型崛起

关键趋势：开源模型不再是追赶者，已在实际生产环境中部署。

  • Top 5 开源模型（代理编码场景）：
    • Qwen 3.6 Plus：综合最强，1M 上下文，可靠工具调用
    • DeepSeek V4：MoE 架构提供成本优势，适合自托管 GPU 集群
    • Kimi K2.6
    • GLM 5.1
    • Mistral Small 4

成本对比：

  • DeepSeek V4：性能接近 Claude Opus 4.7，但价格大幅降低（0.30−0.50 vs Claude 高昂定价）
  • Qwen 3.6 Plus：接近 Claude Opus 4.5 性能，模型规模更小

4. AI Agent 生态爆发

Claude Code 生态

  • “2026 is the year of Claude Code wrappers”：大量企业和产品正在 Claude Code 之上构建
  • Claude Code vs 竞品：
    • Kimi K2.5 和 DeepSeek V3.2 自动缓存系统提示，降低成本
    • OpenAI Codex macOS app
    • Cursor、OpenClaw 等编码工具竞争

多代理系统

  • Agent Swarm：Kimi K2.5 支持100个并行子代理同时运行
  • Workspace Agents：OpenAI 推出的团队共享代理
  • Microsoft Critique & Council：结合 Claude 和 GPT 的混合研究工具
