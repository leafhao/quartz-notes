AI 总结

本日监控的 AI 领域热点主要集中在以下几个方向：

  1. AI 模型竞争格局：GPT-5.4、Claude 4.6、Gemini 3.1 成为主流选择，各有优势领域
  2. 融资动态：OpenAI 122B、Anthropic30B、DeepSeek $300M 融资轮引发市场关注
  3. 开源模型崛起：GLM-5、MiniMax M2.5 等开源模型在性能上逼近闭源竞争对手
  4. Agent 评测体系：Terminal-Bench、τ²-Bench 等新基准测试推动 Agent 能力评估标准化

3. Agent 评测基准演进

新兴评测基准

  • Terminal-Bench Hard：测试终端操作、系统管理、多步命令执行
  • τ²-Bench Telecom：企业场景 API 集成、数据库查询、多系统编排
  • IFBench：指令遵循、函数调用、参数提取精度
  • PolyMATH：多模态数学推理基准
  • ARC-AGI-3：抽象推理与通用智能测试

Agent 排名（2026年1月）

  1. GLM-4.7 (Thinking) - Terminal-Bench 30%，τ²-Bench 96%
  2. Gemini 3 Flash - 多场景平衡
  3. DeepSeek V3.2 - 开源最佳选择
  4. GPT-5.2 - 工具调用能力强

4. AI 学术研究前沿

关键论文方向

  • 推理模型训练：DeepSeek-R1、Nemotron 采用大规模 RL 训练
  • 多模态理解：BABYVISION 基准测试视觉推理能力
  • Agent 架构：Titans 模块支持 2M+ token 长期记忆
  • 地理空间推理：SocioReasoner 框架处理卫星图像语义分割

OpenAI 融资详情

来源: https://openai.com/index/accelerating-the-next-phase-ai/

OpenAI 完成史上最大私募融资 122B，估值852B。首次向个人投资者开放渠道（银行渠道募集 3B），并纳入ARKInvestETF。公司年化收入24B，但市场对其高估值存在分歧。

Anthropic 融资详情

来源: https://www.anthropic.com/news/anthropic-raises-30-billion-series-g-funding-380-billion-post-money-valuation

Anthropic Series G 融资 30B，估值380B。Claude Code 企业订阅增长 4 倍，年化收入从 9B增至30B，可能已超越 OpenAI。Opus 4.6 在 GDPval-AA 测试中领先，可处理财务、法律等知识工作。

DeepSeek V4 发布

来源: https://fortune.com/2026/04/24/deepseek-v4-ai-model-price-performance-china-open-source/

DeepSeek 发布 V4 模型，定价极具竞争力：V4-Pro 3.48/MtokensvsOpenAI30/M。同时寻求首次外部融资 300M，估值10B。V3 和 R1 模型引发中国 AI 投资热潮，MiniMax、Knowledge Atlas IPO 后涨幅 370%-700%。

LLM Benchmarks 2026 状态

来源: https://benchlm.ai/blog/posts/state-of-llm-benchmarks-2026

Claude Mythos Preview 排名榜首 (99 分)，但主流前沿模型差距缩小：Gemini 3.1 Pro 和 GPT-5.4 同为 94 分。开源模型 GLM-5 (85)、Qwen3.5 397B (81) 进入前列。Agentic 基准测试成为实际应用能力的重要指标。

Agent 评测工具推荐
