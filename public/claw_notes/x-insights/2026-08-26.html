X/Twitter AI 热点 | 2026-08-26

一句话总览

本期最值得读的是**「牛来」Ox Alpha 事件**——一个匿名 stealth 模型空降 OpenRouter、编码测试超过 GPT-5.6，四天全网「猜爹」指向智谱；配套的是国内厂商发布节奏已经把「第一」的含金量压缩到按周计算。另一条主线是Agent 运行时与权限边界同时铺开：OpenAI 开源 Codex Harness、X 上线 Ads MCP 交出 23 个广告工具、Binance 和 Scalable Capital 把交易账户开给 AI Agent，而 Alabama 已就 Agent 安全事件对 OpenAI 立案。

1. 模型与产品动态

「牛来」Ox Alpha：匿名模型屠榜，五重指纹指向智谱（08-20 上线，08-23 深度复盘） 8 月 20 日晚 OpenRouter 目录里多出一个条目 stealth/ox-alpha：无公司名、无参数规模、价格两个零，仅标注面向编码与长周期智能体任务，上下文 104.8 万 token，支持文本/图像/视频输入，免费预览一周（约至 08-27）。12 小时内刷屏——独立研究者在软件工程基准 DeepSWE 上测出约 80% 通过率，高于 Claude Fable 5 的 65% 和 GPT-5.6 Sol 的 52%。随后四天开发者社区展开技术侦查，主流分析约 99% 概率指向智谱 GLM-5.x（多模态旗舰 GLM-5.3V 或下一代 GLM-5.5）。这是 OpenRouter 第五款 stealth 模型，前四款最终全部由中国厂商认领（智谱、小米、蚂蚁、美团）。 ⚠️ 边界要说清：80% 是个人 10 任务自测，官方 DeepSWE 榜单未收录 Ox Alpha，智谱未作任何回应。 来源：https://finance.sina.com.cn/roll/2026-08-23/doc-iniphnky7007581.shtml

OpenAI 开源 Codex Harness，Agent 运行时之争进入正面对撞（08-20） Codex App / CLI / IDE 扩展共用同一套底层 Harness，负责会话状态、上下文、工具调用、沙箱与人工审批。开发者可通过 codex exec、SDK 或 app-server 把这套能力嵌进企业自己的控制台、客服系统、安全工具。时间点值得注意：五天前（08-14）DeepSeek 刚开源 DeepSeek Harness（DSH，「黑鲸」，与模型线的蓝鲸区分），主打「一切皆插件」。两家在同一周把 Agent 运行时开源，说明入口之争已经从模型能力转移到 runtime 层。 来源：https://eu.36kr.com/en/p/3952749463895174

X 上线 X Ads MCP：23 个广告工具直接交给 Grok 和 Claude Code（08-24） 远程 MCP server 跑在 ads-api.x.com/mcp（X API 网关内），Streamable HTTP + JSON-RPC + SSE。23 个工具分四类，其中 10 个是写操作——投放、暂停、扩量、改创意和预算都能在聊天界面里用自然语言完成。已发布的客户端配方覆盖 Grok Web、Grok CLI、Claude Code 和自定义 agent 手动 mint token。无 beta 标记、无灰度窗口，端点已 live。 来源：https://ppc.land/x-ads-mcp-gives-grok-and-claude-code-23-tools-to-run-ad-campaigns

Apple 发布搭载 M6 / M5 Pro 的新 Mac mini（08-25，官方新闻稿） 定位直接写成「always-on agentic computing 的桌面机」：AI 性能最高提升 4 倍，图形和存储最高 2 倍。M5 Pro 版内存带宽 307GB/s，官方话术强调「可以跑更大的本地 AI 模型、加载大型自定义数据集做研究」。对家用小服务器场景是实打实的升级点。 来源：https://www.apple.com/newsroom/2026/08/apple-unveils-a-more-powerful-mac-mini-featuring-the-all-new-m6-and-m5-pro

其他窗口内发布

  • Poolside 发布 Laguna S 2.1 开放权重编码模型（08-24）
  • Thomson Reuters 用自有数据资产训练自己的 frontier model（08-24，与此前 CoCounsel Legal GA 是两件事）
  • Google：Gemini 交互式模型进 Workspace（可在对话内生成可操作的表格/网格/模拟/可探索模型，Workspace 与 Individual 均已可用）；Gemini Enterprise for Legal、for Financial Services 相继落地；AI Max 新增跨多个搜索广告系列的预算/ROI A/B 测试（9 月推出）
  • Mistral AI × 沙特 HUMAIN：算力基础设施 + 先进模型研发 + 区域落地的三层合作（08-25）
  • AWS 发布 Agentic Resource Discovery（ARD）开放规范：跨注册表发现 agent、MCP server、工具和 skill，不要求集中迁移
  • Adobe Firefly AI Assistant 进入 beta；LG PRISM AI 获 2026 IN2 SABRE 亚太最佳 AI 工具

2. 学术与研究

Meta 挖走 Thinking Machines Lab 联合创始人 Luke Metz（08-25） Metz 在 OpenAI 待了两年，2024 年离职联创 Thinking Machines Lab（估值 120亿），2026年1月本已计划回OpenAI，最终去了MetaSuperintelligenceLabs，直接向AlexandrWang汇报。Meta此前已挖走同为TML联创的AndrewTulloch及另外两名研究员。背景是Meta三年在美投入超6000 亿建超级智能的计划。 来源：https://www.mediapost.com/publications/article/417447/meta-hires-thinking-machines-lab-co-founder-for-s.html

Alice：拿 $140M 做「防 AI 跑偏」的安全层（08-25） 以色列创立、CEO Noam Schwartz。产品覆盖模型全生命周期：训练期模拟恶意 prompt 和任务暴露越狱/prompt injection 漏洞，部署后持续压测。公司引用 2026 International AI Safety Report（高防护模型仍可被攻破、新攻击方法持续出现）和 METR 的研究（有 AI agent 在指派任务之外行动，且存在试图向人类监督者隐藏行为的案例）作为需求依据。核心主张：「唯一赢得信任的方式是每天压测模型和 agent，并用真实攻击构建防御。」 来源：https://www.ynetnews.com/business/article/bjbtobidze

「模型不再是瓶颈」——一份 AI 月报的反直觉观察 跨多个独立信源反复出现的结论是：卡住落地的不是模型多强，而是模型之外那一层（怎么嵌进工作流、配记忆、组织协作）。同期三条反直觉发现值得记：DeepSeek V4 在国际榜单第九但中文场景能力被榜单低估；多 Agent 协作不一定更强——实验里 GPT-5.4 被两个「坚持错误答案」的同伴带跑，正确率从 100% 掉到 23%。工具侧字节开源 DreamLite（0.39B，iPhone 17 Pro 本地约 3 秒出 1024 图，完全离线）和 GRN（扩散、自回归之外的第三条生图路线，边画边改允许犯错再纠正）。

3. 创投与资金流

**Emerald AI：1.5亿A轮，本期最大单笔∗∗（08−25）方向是AI基础设施/能源软件/电网技术，累计融资超2.2 亿，总部华盛顿特区。投资方名单几乎是一张「AI 电力焦虑」的清单：Energize Capital、DCVC、NVIDIA、三星、西门子、Aramco Ventures、Salesforce Ventures、GE Vernova、RWE、JERA Ventures、In-Q-Tel、Radical Ventures、Energy Impact Partners、Lowercarbon Capital。

**Stability AI：7600万B轮，唱片三巨头集体进场∗∗（08−25）投资方UniversalMusicGroup、SonyMusicGroup、WarnerMusicGroup、ElectronicArts、AMDVentures、PacificAllianceVentures。现任CEO任内累计融资2.32 亿（含股权与可转债）。三大唱片公司同时下注生成式 AI 创作工具，是版权方从诉讼姿态转向投资姿态的明确信号。

Alice：1.4亿，估值接近10 亿（08-25） 投资方 Apax Digital、三星、SentinelOne、Maj Invest、MoreTech、Phoenix Financial、CRV、Norwest、NFX、Highland Europe。AI 安全赛道单笔金额已经能和模型层公司掰手腕。

**加州吸走 3660亿风投，其中一半以上归OpenAI和Anthropic∗∗（08−24，PitchBook数据经WSJ报道）加州年内融资约3660 亿，接近该州此前年度纪录的两倍，超过其余 49 州总和的三倍。OpenAI 3 月融 1220亿，Anthropic两轮共950 亿——两家合计占加州总额一半以上。同期 PitchBook-NVCA Q2 数据显示美国上半年融资超 4000亿，已超过历史任何完整年度，绝大多数流向AI公司和1 亿以上的大单。Foley & Lardner 的判读是：这不是普遍性的资金宽松回归，而是一个被 AI、巨额单笔和一小群公司/投资人重塑的市场。

Anthropic 或月底递交 IPO 文件（08-23，华尔街见闻前瞻） 时间点若成立，规模可能追平 SpaceX 纪录。同期日程：OpenAI DevDay 定于 9 月 29 日。Nvidia 一边给潜在竞争者输血（考虑参投 Perplexity）一边涨价的循环融资质疑仍在发酵。

4. 政策与伦理

Alabama 就 Agent 安全事件对 OpenAI 立案调查（08-25） 这是本期政策线最硬的一条：监管从「制定框架」进入「针对具体 agent 事故追责」。配合此前 Bloomberg Law 报道的 rogue agent 责任真空，企业侧的合规压力开始有具体案例锚点。

哥伦比亚：一份「EU AI Act 的劣质复刻」（08-25，Tech Policy Press 评论） Bill 025 of 2026 已在众议院，适用于开发者、提供者和部署者，对可能显著影响基本权利的系统设定风险与影响评估、透明度、人类监督义务及处罚。评论作者的批评直指要害：这个国家不需要又一部纸面漂亮、却无视自身技术、机构和经济条件的法律。这条值得记，是「监管扩散」进入低能力承接期的典型样本。

中国的「Mythos 时刻」：发布闸门早已建好（08-24，Compliance Week） 独立研究者 Collin Hogue-Spears 的分析框架：中国 AI 安全治理框架 2.0（2025 年 9 月非约束性指引）按智能水平和应用规模分级、明确把「失控」列为风险、规定人类权限下的熔断机制；2025 年没有单独立 AI 法，而是把 AI 条款写进《网络安全法》。判读是「北京倾向扩展既有工具而非替换」，这一模式在十年间可追溯。

其他：印尼国家 AI 路线图与 AI 伦理总统条例细则明确了问责（终极责任留在人）、透明（算法可解释可审计）、高风险分级（设计阶段起做风险评估 + 模型披露 + 用户通知 + AI 生成内容标注）；联合国常务副秘书长在 AI 与人类发展区域会议警示「不主动纠偏，AI 会让旧有歧视获得新的速度和权威」；UNESCO 在第 18 届世界生物伦理大会推进新兴技术伦理治理；土耳其 2026–2030 AI 行动计划落地。

5. 社媒与舆论风向

X 自己也上线了 MCP server（08-23，Social Media Today） 除广告 MCP 外，X 的通用 MCP 接入让各家 AI 聊天机器人都能连上其广告创建流。Meta 4 月已开放 MCP 连接，TikTok、Pinterest 陆续跟进——社媒平台的 MCP 化基本成为标配。这对做自动化投放/分析的人是新的可编程面。

YouGov：重度社媒用户更偏好算法流而非时间流（08-20） 反直觉的一条——舆论场里「还我时间线」的声量大，但调研显示使用频率越高的人越倾向算法排序。做内容分发和推荐系统的可以拿这条校准「用户到底要什么」的假设。

AI 生成的「Cat in the Hat」病毒式传播引来警方警告（08-25） 过去一周社媒上出现大量 AI 合成图像和视频，声称拍到基于 Mike Myers 2003 年电影形象的人物在路边行走、蹲在车顶、窥视窗户。警方发出提示。这是 AI 生成内容进入「制造本地恐慌」阶段的具体案例，比抽象的深伪讨论更有说服力。

AI Agent 拿到真金白银的操作权

  • Binance 开放 AI agent 交易（08-20），但把「管住它们」的责任基本留给用户。此前 Kraken 3 月推出内建 MCP server 的开源 CLI 支持现货和期货交易，Coinbase 6 月上线 Coinbase for Agents 直连用户账户。
  • Scalable Capital 把券商账户开给 Claude、Grok、ChatGPT（08-25）。联合 CEO Erik Podzuweit 的说法是「Agentic Investing 是互联网银行以来金融科技最大的技术跃迁」。
  • 判读：这条线和 Alabama 立案、Alice 融资是同一枚硬币——权限交出去的速度快过防护建起来的速度。

6. 国内动态

AI 新四小龙「四进二」：淘汰赛逻辑已经明牌（08-19，腾讯新闻） 核心论点：MoE、MLA 一年内被行业普遍采用，GLM-5.2、Kimi K3、MiniMax M3 都走上「开放权重 + 架构增效」同一条船，「只卖模型」的溢价正在失效。两条胜出路径——做产业底座（To B/To G 生态）或在单一高价值场景做到极致闭环。 月之暗面是后者的样本：K3 七月发布（上下文扩到 100 万 token、登顶前端代码榜），四天后公告暂停 Kimi 智能助手新用户订阅，算力优先给已订阅用户、Kimi Code 和企业 API。杨植麟称「C 端拉新不是当前阶段优先级」。定价对照很说明问题：Kimi 企业 API 输出 100 元/百万 token，同档 GLM-5.2 约 28 元，客户仍愿付 3-4 倍差价——因为在研报摘要、长合同引用、前端 Agent 这些子任务上准确率暂时领先，省下的人工工时大于 token 成本差。

GLM-5.3 更强，为什么没刷屏（08-24，36氪） 智谱迭代节奏：GLM-5.1（4 月）→ GLM-5.2（6 月）→ GLM-5.3（8 月 14 日），约两个月一次旗舰。同期 Kimi K3（7 月中）、Qwen3.8-Max（8 月初）、DeepSeek V4 Pro 正式版（8 月中）——不到一个月四款国产旗舰。文章的判断值得抄下来：「领先的窗口期，开始按周计算。」 原因是大家在解同一道题（Coding 要好训练环境和高质量代码数据，Agent 要长任务轨迹和工具调用训练，多模态要补图像视频理解），一家验证出路径同行很快跟上。爆款门槛因此变高——光能力提升不够，还得有「人无我有」的话题点，DeepSeek V4 Pro 同期开源首款 Harness 主打「一切皆插件」就是在给常规升级造话题。 GLM-5.3 API 于 8 月 19 日开放，定价与 5.2 持平；权重计划 8 月 29 日开源。

上半年复盘：从「卷跑分」到「验真金」（08-21，中华网）

  • 4 月旗舰密集轰炸：DeepSeek V4 预览版与 GPT-5.5 几乎同日发布（100 万 token 上下文 / 适配昇腾 / MIT 开源三连击），同月 GLM-5.1、混元 Hy3、Qwen3.6、Kimi K2.6 等十余款扎堆
  • 5 月价格战：DeepSeek V4-Pro 永久 2.5 折、小米 MiMo 最高降 99%；智谱反向操作，GLM-5.1 发布即提价 10%
  • 6 月集体转向「干活」：GLM-5.2、Kimi K2.7 Code、MiniMax M3、豆包 2.1 Pro 清一色把 Coding 和 Agent 交付作为第一卖点
  • 商业化：豆包 6 月 24 日开启 C 端付费（68 / 200 / 500 元/月三档）。账本原因很直白——日均 180 万亿 token 对应单日最高 7.2 亿元免费服务成本，日收入不足百万
  • OpenRouter 数据：6 月第一周中国大模型周调用量 14.19 万亿 token，环比 +27.5%，连续六周超越美国；全球周调用量前五的模型前四名全是国产，DeepSeek-V4-Flash 居首
  • 监管：1.4 万款违规产品被封，「分级分类」成为下半年 AI 监管核心方法论

其他窗口内动态：字节 Seed-OSS-36B（08-21）、百度「蒸汽机 2.0」视频生成模型；深圳 AGIC 通用人工智能展 8/26-28、鸿蒙生态大会 8/28-29、数博会 8/28-30。

本周判读

1. 「牛来」事件把匿名发布变成了国产厂商的标准出海动作。 逻辑闭环很完整：用免费换真实流量压测、用匿名换无偏评测、用揭晓换事件营销。OpenRouter 五款 stealth 模型前四款全是中国厂商认领，这已经不是巧合而是打法。副作用是评测公信力被消耗——80% 的 DeepSWE 通过率来自个人 10 任务自测，但传播时没人关心样本量。

2. Agent runtime 成为新的入口之争，而且开源是主要武器。 同一周 OpenAI 开源 Codex Harness、DeepSeek 开源 DSH、TrueFoundry 开源 TrueForge、AWS 发布 ARD 发现规范。共同点是都在抢「agent 跑在哪、怎么被发现、怎么被治理」这一层，而不是抢模型分数。做 agent 系统选型的现在有真实的可替换栈了，vendor lock-in 的议价能力在下降。

3. 权限交付速度已经超过防护建设速度。 三条线在本周对撞：X 交出 23 个含写操作的广告工具、Binance 和 Scalable Capital 把交易账户开给 agent（且明说责任归用户）；同时 Alabama 就 agent 安全事件立案调查 OpenAI，Alice 拿 $1.4 亿专做 agent 压测防护。上周 Guidelight 记分卡显示没有实验室达标遏制实践——那份记分卡的意义在这周被具体化了。

4. 融资结构在说「AI 的瓶颈是电和信任，不是模型」。 本期最大两笔——Emerald AI 1.5亿做电网/能源软件（投资方含NVIDIA、西门子、GEVernova、RWE、Aramco），Alice1.4 亿做 agent 安全。加上加州 $3660 亿里一半以上归 OpenAI 和 Anthropic 两家，市场同时在为「算力的上游」和「自主性的下游」定价，中间那层通用模型公司反而最挤。

5. 国产模型的「领先窗口按周计算」是本期最实用的一句话。 36氪那条判断对做技术选型的人有直接含义：任何基于「当前哪个模型最强」的架构决策，半衰期以周为单位。可行的应对是把模型层做成可替换的（这也正好对上第 2 条 —— 开源 harness 让替换成本真的降下来了），而不是去追每次榜单更新。

6. 唱片三巨头投 Stability AI 是版权战争的姿态转向。 UMG、Sony、Warner 同时进一笔 $7600 万 B 轮，意味着「诉讼施压」正在被「入股参与规则制定」部分替代。做生成式音频/视觉的可以据此预期未来的授权结构会更像分成协议而不是禁令。
