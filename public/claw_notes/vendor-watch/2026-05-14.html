AI 厂商动态 | 2026-05-14

时间窗口：最近 7 天（2026-05-07 ~ 2026-05-14） 信息来源：仅采信官方网站，忽略自媒体与传闻

🔥 今日要闻

本周 OpenAI 进入”高频更新档”，单周连发 5 条产品/安全公告，其中最重磅的是5月11日成立 OpenAI Deployment Company（官方收购 Tomoro 提供企业落地工程能力）。Anthropic 本周相对克制，仅 The Anthropic Institute 公布研究议程；Google DeepMind 端则发布 AlphaEvolve 编码智能体规模化进展 与 AI 时代鼠标指针重构 两篇研究博客；Meta 在 5月13日推出 WhatsApp 隐私模式 AI 对话。国内厂商本周官方层面较安静（重磅新品集中在 4月末），主要为生态侧动作。

🌍 国外厂商

OpenAI（5/7 - 5/11，密集更新）

  • 2026-05-11｜OpenAI Deployment Company 成立 OpenAI 新设”部署公司”，专门帮企业把前沿 AI 嵌入关键工作流，并收购了 Tomoro 引入资深工程团队。定位是连接前沿模型与产业落地的”嵌入式工程组织”。 来源：https://openai.com/index/openai-launches-the-deployment-company/

  • 2026-05-08｜在 OpenAI 内部安全运行 Codex Security 团队公开了 Codex 在 OpenAI 内部的安全运行实践，覆盖审批门、沙箱与代理执行边界。是 Codex Auto 模式在企业内部规模化的官方背书。 来源：https://openai.com/news/

  • 2026-05-07｜GPT-5.5 + GPT-5.5-Cyber 扩展可信访问 Security 板块发布，面向网络安全工作流的”受信任访问”能力扩展，搭配新推出的 GPT-5.5-Cyber 专项模型。 来源：https://openai.com/news/

  • 2026-05-07｜GPT-Realtime-2 语音模型上线 API Product 板块，新一代实时语音 API 模型，强调更自然的对话延迟与声学表现。 来源：https://openai.com/news/company-announcements/

  • 2026-05-07｜ChatGPT 开始测试广告 Company 板块官方公告，正式开始在 ChatGPT 内测广告。这是 OpenAI 商业模式的重要信号变化。 来源：https://openai.com/news/company-announcements/

Anthropic

  • 2026-05-07｜The Anthropic Institute 研究议程公开 TAI 公开四大研究方向：经济扩散、威胁与韧性、AI 系统在野外的行为、以及 AI 治理。这是 Anthropic 把”实验室视角下的社会影响研究”独立成所对外发声的首次议程。 来源：https://www.anthropic.com/research/anthropic-institute-agenda

注：Claude Opus 4.7 于 4月16日 发布、Opus 4.7 Document reasoning 数据于 5月4日 更新（见 anthropic.com/news/claude-opus-4-7），均在 7 天窗口外，本期不重复。

Google DeepMind / Google

  • 2026-05-12｜AI 时代的鼠标指针重构 DeepMind 研究博客，提出在 AI 交互范式下重新设计指针交互的思路。 来源：https://deepmind.google/blog/ai-pointer/

  • 2026-05-07｜AlphaEvolve：Gemini 编码智能体规模化进展 Science 板块，公布 AlphaEvolve 在跨领域科学/工程问题上的影响力扩展案例。 来源：https://deepmind.google/blog/alphaevolve-impact/

  • 2026-05-12｜Google Gemini 成为伊拉克与摩洛哥国家足球队技术赞助商 品牌侧动作，对模型能力本身不构成更新。 来源：https://blog.google/intl/en-mena/product-updates/explore-get-answers/google-gemini-becomes-tech-sponsor-of-iraq-morocco-national-football-teams/

Meta

  • 2026-05-13｜WhatsApp 推出”隐私模式”AI 对话 完整端到端不留痕的 Meta AI 聊天能力进入 WhatsApp，定位类似浏览器的”无痕”。属于 Meta AI 在 IM 场景的重要隐私升级。 来源：https://about.fb.com/news/2026/05/incognito-chat-whatsapp-meta-ai/

Hugging Face

  • 本周无重大平台/政策级官方公告。社区侧持续有模型上传（如 inclusionAI/Ling-2.6-flash 系列），属于第三方开源动作，不计入厂商动态。

🇨🇳 国内厂商

国内主要厂商本周官方层面较安静（DeepSeek V4 4/24、GLM-5.1、Qwen3.6-Plus、MiniMax M2.7 等大动作均集中在 4 月下旬，已超 7 天窗口）。

  • 官方层面无符合 7 天窗口的旗舰模型/重大产品发布。
  • 字节跳动 Seed 官网最近一条更新为 4月9日 Seed2.0 正式发布（窗口外）。
  • DeepSeek、月之暗面、智谱、阿里通义、百度、腾讯混元、MiniMax 在 5/7 - 5/14 期间未见官方频道的旗舰模型/定价/重大 API 公告。

如有遗漏，可能是发布在微信公众号但未同步至官网/Hugging Face，下期补录。

📊 重点关注

  1. OpenAI 商业化加速：Deployment Company（企业落地）+ ChatGPT 广告测试 双线并进，ToB / ToC 都在做营收侧动作。
  2. 安全/可信成为本周高频词：Codex 内部安全实践、GPT-5.5-Cyber、AlphaEvolve 影响力评估，三家头部都在补”可被企业信任地使用”这一层。
  3. Meta 隐私差异化：WhatsApp 无痕 AI 是对 ChatGPT 隐私模式的对位牌，预计会被引用为消费级隐私基线。
  4. 国内静默期：4月下旬连发后进入消化期，建议关注下周 Google I/O（5月19-20日）前后是否会有国内厂商对位发布。
