AI 厂商动态 | 2026-08-25

本周窗口重点（8/18 - 8/25 严格 7 天内）

以下条目的发布/披露日期确认落在本次 7 天窗口内：

  • Anthropic — Claude Platform 新增合规性 API 端点（8/18）；Claude 加速蛋白质设计与分析化学研究（8/18）
  • OpenAI — Codex iOS 更新：Codex Remote 启动项、标准 MCP 表单、任务可靠性（8/18）；AI Futures 博客上线，首篇由 Dean Ball 谈权力集中与治理（8/20）；o3 与 GPT-4.5 从 ChatGPT 退役生效（8/26，已进入倒计时）
  • Meta — Muse Glimmer 30B 开源智能体模型进入外部报道视野（8/19，Apache 2.0，单卡可跑）
  • 行业 — Raymond James 8月 Token Observer：头尾模型定价差距扩大（8/21）；Guidelight 报告称五大实验室安全系统落后于模型能力（8/20）；Stripe 约 7.5B收购OpenRouter（8/21）；Higgsfield400M 融资、估值 $5.4B（8/21）；Thomson Reuters 推出自研前沿模型（8/24）；Gemini 3.7 Flash 智能体基准以半价胜出竞品的横评报道（8/24）

下文各厂商小节保留了完整的 8 月上下文（含 8/18 之前的发布，如 Claude Sonnet 5、GPT-5.6 Sol、Gemini 3.7 Flash 等），便于回溯本月完整脉络；这些条目已超出 7 天窗口，标注日期以便区分。

Anthropic

Claude Sonnet 5（8月10日发布）

  • 价格：2/Minputtokens，10/M output tokens
  • 能力：提升了 Chat、Cowork、Claude Code 和 API 的速率限制，以支持更高的 token 吞吐量
  • 来源：Introducing Claude Sonnet 5

Claude Opus 5 发布

  • 定位：接近 frontier intelligence 的思考型和主动型模型，价格是 Fable 5 的一半
  • 性能：在编码和知识工作评估中达到新的 SOTA
  • 来源：Introducing Claude Opus 5

Project Glasswing（八月）

  • 发布方式：仅向受邀客户开放的新模型，通过 Project Glasswing 计划部署
  • 描述：Anthropic 对外部署的最强模型，内部广泛用于研究和工程
  • 来源：Redacted Risk Report August 2026

文本水印技术（8月2日）

  • 功能：为符合 EU AI Act 要求，Claude 输出添加不可见水印
  • 覆盖范围：2026年8月2日后发布的模型立即支持，旧模型将在未来几个月逐步推出
  • 来源：How Claude’s text watermarking works

企业安全功能（8月6日）

  • Beta 功能：企业计划现可开启技能和插件安全扫描，自动检测第三方技能和插件中的恶意内容
  • 来源：Release notes | Claude Apps

API 合规性端点（8月11日、8月18日）

  • 新增多个合规性 API 端点：
    • GET /v1/compliance/apps/sessions/local
    • GET /v1/compliance/apps/sessions/local/{session_id}
    • GET /v1/compliance/apps/sessions/local/{session_id}/messages
  • 新增权限范围：read:compliance_user_data
  • 来源：Claude Platform release notes

科学研究应用（8月18日）

  • 案例：Claude 加速蛋白质设计和分析化学研究
  • 来源：How Claude is accelerating protein design and analytical chemistry

OpenAI

GPT-5.6 Sol（8月11日）

  • 特性：超低延迟推理，基于 Cerebras 合作提供 Ultrafast 模式
  • 定位：OpenAI 最智能模型的超高速推理版本
  • 来源：OpenAI Release Notes - August 2026

GPT-5.6 Luna（8月中旬）

  • 用户范围：替代 GPT-5.5 成为免费和 Go 用户的默认模型
  • 新功能：提供新特性支持
  • 来源：Best AI Chatbots 2026

Codex 升级（8月13日、8月18日）

  • 改进方向：更快、更可靠，深度集成到现有工具中
  • iOS 更新（8月18日）：
    • 新增 Codex Remote 启动时自动打开设置
    • 支持标准 MCP 表单和可编辑消息任务可靠性提升
  • 来源：Introducing upgrades to Codex | Release Notes

模型退役（5月28日公告，8月26日生效）

  • 退役模型：OpenAI o3 和 GPT-4.5 将于8月26日从 ChatGPT 退役
  • 原因：聚焦更强大的新模型，淘汰使用率较低的旧模型
  • 来源：ChatGPT Release Notes

ChatGPT Business 高级席位（8月10日）

  • 产品更新：推出 Premium seats 席位模式
  • 来源：OpenAI News

网络安全能力声明（8月7日）

  • 主题：响应下一代关键网络能力前沿
  • 来源：OpenAI News

Codex 扩展为通用生产力工具（8月17日）

  • 定位转变：Codex 不再仅限于编码，开始面向知识工作者推广
  • 来源：Codex is becoming a productivity tool for everyone

AI Futures 博客（8月20日）

  • 主题：探讨 AI 权力集中风险、治理原则和自由
  • 首篇文章：由 Dean Ball 撰写
  • 来源：OpenAI launches AI Futures blog

Codex CLI 更新（8月5日）

  • 版本：0.146.1
  • 改进：对具备网络能力的模型应用更安全的自动审查默认设置，并在终端中解释权限变更
  • 来源：ChatGPT & Codex changelog

Google

Gemini 3.7 Flash（8月13日）

  • 定位：最智能的工作模型，专为编码和智能体设计
  • 性能：在多项基准测试中超越 Anthropic Claude Sonnet 5 和 Meta GPT-5.6 Terra，且价格更低
  • 价格优势：引入价持续到2026年12月31日
  • 来源：Introducing Gemini 3.7 Flash | Gemini 3.7 Flash Model Card

Gemini 3.6 Flash 和 3.5 Flash-Lite（7月21日）

  • 更新：模型卡片在7月更新
  • 来源：Model cards

Gemini Robotics 2（7月30日）

  • 能力：从脚到指尖的全身智能控制、精细灵巧性和团队协作
  • 来源：Gemini Robotics 2 brings whole body intelligence to robots

Gemini 连接应用扩展（8月12日）

  • 更新：新的连接应用和服务即将加入 Gemini
  • 来源：New connected apps are coming to Gemini

Gemini Omni 建设者案例（8月7日）

  • 内容：展示5位建设者使用 Gemini Omni 的实际应用
  • 来源：See what 5 builders are making with Gemini Omni

Genie 3 世界模型

  • 定位：世界模型的新前沿
  • 发布方式：作为限量研究版本公布
  • 来源：Genie 3: A new frontier for world models

Meta / Hugging Face

Muse Glimmer 30B（8月发布）

  • 参数：30B 参数因果语言模型
  • 用途：专为自主智能体任务设计
  • 许可：Apache 2.0 开源
  • 部署：足够小，可在单台消费级 GPU 上运行
  • 来源：unsloth/Muse-Glimmer-30B-GGUF | Manifold Market betting

Llama 衍生模型增长

  • 数据：Hugging Face 上 Llama 衍生模型超过 85,000 个，比去年增长超过 5 倍
  • 来源：The future of AI: Built with Llama

GGML / llama.cpp 加入 Hugging Face（2月）

  • 合作：GGML 团队加入 Hugging Face，项目保持完全开源和社区治理
  • 影响：本地推理最重要的项目现在拥有持久的资源支持
  • 来源：State of Open Models: Summer 2026

行业动态

Token 定价趋势（Raymond James 报告，8月21日）

  • 观察：顶级和底部 AI 模型之间的 token 定价差距扩大
  • 驱动因素：新的网络安全模型推出
  • 来源：Raymond James sees token pricing gap widen

Anthropic 营收增长

  • 数据：Anthropic 的 ARR 增长超过 OpenAI，但增速开始放缓
  • 来源：Anthropic: The Economics of an AI Pioneer

OpenAI 现金消耗和 Token 价格

  • 趋势：Token 价格暴跌，OpenAI 每月烧钱数十亿美元
  • 时间节点：Token 定价指数在 OpenAI 和 Anthropic 宣布保密 IPO 申请（6月初）的几天前达到峰值
  • 来源：OpenAI Is Burning Billions as Token Prices Plunge

AI 安全系统落后（8月20日）

  • 报告来源：Guidelight（前 OpenAI 安全主管 Steven Adler 创立的非营利组织）
  • 结论：审查 Anthropic、Google、Meta、OpenAI 和 xAI 的公开披露后，发现这些公司的安全系统跟不上模型能力的发展
  • 来源：AI lab’s safety systems are falling behind

xAI Grok 4.6（8月12日）

  • 发布：xAI 推出 Grok 4.6
  • 来源：Manifold Market betting

Stripe 收购 OpenRouter（8月）

  • 交易：Stripe 以约 $7.5B 收购 AI 模型路由器 OpenRouter
  • 来源：Politics hits data centers, OpenAI falls behind Anthropic

Higgsfield 融资（8月）

  • 金额：400M，估值5.4B
  • 用途：扩展视频和图像生成平台
  • 来源：Politics hits data centers

Thomson Reuters 推出前沿模型（8月24日）

  • 内容：利用其世界级数据资产推出前沿模型
  • 来源：Thomson Reuters Leverages Its World-Class Data Assets

AI 投资趋势（2026上半年）

  • 数据：AI 初创公司在2026年前六个月筹集约 $399B，全年有望突破新高
  • 流向：最大融资流向前沿模型实验室和智能体 AI 基础设施供应商
  • 来源：Latest AI developments 2026

总结

本周 AI 厂商发布密集，主要看点：

  1. Anthropic：Sonnet 5 和 Opus 5 双发布，Project Glasswing 限量推出最强模型，文本水印技术响应 EU 监管
  2. OpenAI：GPT-5.6 Sol/Luna 双版本，Codex 从编码工具扩展为通用生产力平台，模型退役加速迭代
  3. Google：Gemini 3.7 Flash 在性能和价格上击败竞品，机器人和世界模型持续推进
  4. Meta：开源 Muse Glimmer 30B，可在消费级硬件运行的智能体模型
  5. 国内厂商：本周窗口内无重大官方发布
  6. 行业：Token 价格战加剧，Anthropic 营收增长超越 OpenAI，AI 安全问题凸显，大规模融资持续
