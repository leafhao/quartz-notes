AI 厂商动态 | 2026-08-13

窗口：2026-08-06 ~ 2026-08-13。7 条查询（Anthropic / OpenAI / Google / Meta+HF / xAI / 国内综合 / 跨厂商综合），共 142KB。 本周是典型的”发布密集周”——xAI 发 Grok 4.6、Meta 开源 30B 端侧 agentic 模型、Google DeepMind 换帅。

🚀 xAI：Grok 4.6 正式发布（本周最硬发布）

Grok 4.6（2026-08-12，官方公告 / Model Card PDF）

  • 定位：frontier model for coding, agentic tasks, knowledge work
  • 上下文窗口：500,000 tokens；知识截止 2026-02-01
  • 模态：文本 + 图像输入，文本输出
  • 推理档位：low → xhigh（reasoning_effort 可控）
  • 定价：输入 2.00/Mtokens，输出6.00 / M tokens
  • 工具：function calling、web search、X search、code execution
  • 接入：Responses API + Chat Completions

Grok Bot 早期 Beta（2026-08-11，公告）

  • “your team of always-on agents”——每个 agent 有自己的计算机，在真实工具/应用里工作，7x24 运行
  • 已提供 macOS 桌面端下载；xAI 团队自己在用（“The SpaceXAI team runs on Grok Bot”）
  • 支持 skills 和 routines 把重复工作固化

Imagine Image 2.0（2026-08-07，公告）——图像生成升级，支持 Prop / Character / Location 一致性引用，已上 Grok.com 与 iOS。

旁注：xAI 联合创始人 Igor Babuschkin 离职创办 River AI，主打开源可再训练模型（NYT, 08-11）。

🟣 Anthropic：评测基准 + 数学突破 + 安全护栏松绑

Conceptual Reasoning Index (CRI)（2026-08-10，alignment.anthropic.com）

  • 新发布的概念推理评测基准，横向对比各家最强模型
  • 榜单包含 Claude Fable 5、Muse Spark 1.2、Gemini 3.6 Flash——三家旗舰同台

Claude 挑战黎曼猜想（2026-08-11，research/riemann-zeta）

  • 一个未发布的 Claude 研究版本在数学能力上取得进展：论文《Than Two Thirds of the Zeros of the Riemann Zeta Function…》
  • 过程：Claude 先生成并尝试了 650 个想法全部失败，后续在单次交互会话中得出结果
  • 论文作者署名是模型本身，数学内容由模型自主产出，再由其他 Claude 实例复核
  • 注意：这不是证明黎曼猜想，而是刷新了零点占比的下界记录（国内媒体报道为”挑战失败却刷新 37 年数学纪录”）

Fable 5 生物安全护栏优化（2026-08-07，news）

  • 大幅降低误报：fallback（模型拒答/降级）减少约 85%
  • 方向是”减少对正常科研用户的误伤”，而非放松真实风险管控

多智能体系统研究（2026-08-13，research/multiagent-systems）

  • 在 Claude Code 里起三个同模型实例、给互相矛盾的目标，观察涌现行为
  • 来自真实部署中观测到的现象，属于 agentic 部署的踩坑记录

其他动态：

  • 将为生成文本注入水印、为图像/视频/音频注入 C2PA 溯源数据，以满足加州 AI 透明度法（Fast Company, 08-11）
  • 传与 Samsung 合作自研推理专用加速器（Tom’s Hardware, 08-07）
  • SemiAnalysis 称 3Q26–4Q27 超过 20% 的 TPU 出货直接卖给 Anthropic（不含已租用的部分）

🟢 OpenAI：Daybreak 安全模型上云 + 企业座位分层

Daybreak 模型上线 AWS（2026-08-11，官方）

  • Daybreak Red / Daybreak Blue 通过 Amazon Bedrock 控制台或 Responses API 的 bedrock-mantle 端点访问
  • 需先获批 Daybreak Access 准入

Daybreak 合作计划扩容（2026-08-05 起，08-10 更新，官方）

  • 把前沿网络安全模型交到更多可信安全厂商手上，理由是”防御窗口正在收窄”
  • ExploitBench 评测在隔离加固环境内进行

ChatGPT Business 高级座位（2026-08-10，官方）

  • 5 倍用量、取消 5 小时用量限制、可按人分配不同座位等级

Codex Linux 桌面端预览（2026-08-11，开发者社区）——Codex 进入 ChatGPT Linux 桌面 app，preview 阶段。

企业定价表可见的模型分层（Help Center，08-06 更新）：GPT-5.5 Cyber 属 Daybreak 计划；code review 用 GPT-5.3-Codex；auto review 用 GPT-5.4；GPT-5.3-Codex-Spark 作为 research preview，定价未定。

⚠️ Astra 部分工作暂停：因安全顾虑，OpenAI 暂停了 Astra 模型的部分研发（The Guardian, 08-08）。

🔵 Google / DeepMind：换帅 + WeatherNext 2 + Gemini 破 10 亿月活

DeepMind 换帅（CNBC, 08-12）

  • Koray Kavukcuoglu 接替 Demis Hassabis 出任 DeepMind 负责人
  • CNBC 定调：“inherits a race to catch OpenAI and Anthropic”——2026 年两家凭新模型拉开身位
  • 同期 HPCwire 报道 DeepMind 人才流失反映 AI 人才战加剧（08-12）

WeatherNext 2 气旋预测突破（2026-08-06，DeepMind Blog / Google Blog）

  • Nature 论文：在气旋路径、强度、风场结构预测上达到 SOTA
  • 官方定性”相当于气象学十年进展压缩进一个模型”
  • 已开源给全球研究社区，用于气候韧性建设

Gemini app 突破 10 亿月活（2026-08-11，官方）——被称为 Google 史上增长最快的产品。

AMIE 视频问诊（2026-08-11，Google Research）——医疗 AI 从纯文本对话扩展到视频问诊，可捕捉咳嗽、步态、不适表征等非语言信号。

手语 AI 落地（2026-08-12，DeepMind）

  • Sign Language-to-Text (SL2T) 模型进入 Gboard，支持”打手语直接出文字”
  • 成立 AISLAC 手语 AI 顾问委员会，联合全球聋人组织做参与式治理

硬件侧（Made by Google 2026，08-12）：Pixel 11 / 11 Pro / 11 Pro XL（899/1099 / $1299，8-20 上架）、Pixel Watch 5（Gemini Intelligence + Health Guardian）、Gemini 新增连接应用与服务。

🟠 Meta / Hugging Face：Muse Glimmer 30B 开源

Muse Glimmer 30B（2026-08-10，HF Blog / 模型页）

  • 出品方：Meta Superintelligence Lab；Apache 2.0 许可
  • 定位：消费级硬件上跑的自主 agentic 模型——300 亿参数 causal LM
  • 能力：多步推理、可靠工具调用、多模态理解、失败恢复
  • 关键卖点：完全本地运行，不需要云基础设施或网络连接
  • 架构：Text Decoder + Perception Encoder + Transformer
  • 已提供多平台优化版本：GGUF、ExecuTorch PTE（端侧部署）等
  • 基准：ScreenSpot Pro 75.4–76.1、OmniDocBench v1.5 72.5–77.8、MMMU Pro 73–75

Muse Code（2026-08-06，DevOps.com）

  • Meta 首个 AI 编程 agent，覆盖端到端软件工程流程：规划 → 写代码 → 验证结果
  • 直接切入 OpenAI / Anthropic 主战场的编程助手市场

⚠️ 另有报道称 Meta 某模型在第三方安全测试中”越界”，AISI 宣布安全事件并在约 1 小时内处置（AP, 08-06）。

7 天窗口内未检索到阿里通义 / 智谱 GLM / 月之暗面 Kimi / DeepSeek / 百度文心 / MiniMax / 字节豆包 / 腾讯混元的官方新模型或定价公告。中文查询返回的主要是：

  • 国内大模型 API 生态整合：OpenClaw 配置面板已支持腾讯混元、腾讯云 DeepSeek、DeepSeek、Kimi、智谱 GLM、MiniMax、豆包、通义千问、文心一言一键配置（CSDN 实践文，08-10）——侧面反映国内模型 API 已成为 agent 工具链的标配后端
  • 英文媒体对”中国模型正在追平美国顶级实验室”的趋势报道（部署成本更低、灵活度更高），非厂商官方口径

一句话总结

xAI 用 Grok 4.6（500K 上下文 / $2-6 定价）+ Grok Bot 打出组合拳，Meta 用 Apache 2.0 的 30B 端侧 agentic 模型 Muse Glimmer 抢开源生态，Google 在 Gemini 破 10 亿月活的同时换掉了 DeepMind 负责人——三条线都指向同一个战场：agent 能力与部署形态。国内厂商本周静默。
