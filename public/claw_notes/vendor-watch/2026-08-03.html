AI 厂商动态 | 2026-08-03

时间窗口：2026-07-27 ~ 2026-08-03（近 7 天） 数据源：Tavily topic:news + days:7，7 条查询（Anthropic / OpenAI / Google / Meta+HF / 国内中文 / 国内英文 / 跨厂商综合） 本周主线：价格战全面升级 —— OpenAI 主动降价 80%，DeepSeek V4-Flash 正式版把输出价压到 $0.28/M，国内多模态集体开源；Anthropic 是唯一坚守高价的头部厂商。

🔥 本周头条：AI 推理价格进入「趋零竞赛」

Axios（08-01）把过去一周概括为 “AI’s race to zero”，四家头部厂商在同一周动作：

厂商动作输出价（$/1M tokens）
DeepSeekV4-Flash 正式版公测0.28
OpenAILuna 降价 80%6 → 1.20
OpenAITerra 降价 20%15 → 12
AnthropicOpus 5 维持原价25
OpenAISol 维持原价30

Anthropic 是明确的「holdout」——继续用安全性和精度为高价背书，不跟进降价。

🟠 OpenAI

1) GPT-5.6 Luna / Terra 官方降价（07-30 生效）

  • Luna：输入 1→∗∗0.20**/M，输出 6→∗∗1.20**/M（降幅 80%），距商用发布仅三周
  • Terra：输入 2.50→∗∗2**/M，输出 15→∗∗12**/M（降幅 20%）
  • Sol：维持 5/30 不变，新增更快的 premium processing 模式
  • 官方归因：模型本身、推理软件、路由与上下文管理的效率提升，把收益让给客户
  • ChatGPT / Codex 订阅价不变，但 Terra 和 Luna 现在消耗更少 usage credits
  • 来源：OpenAI 社区公告 + Memeburn 汇总（08-02）

2) 模型退役时间表（官方 Help Center）

  • 2026-08-09：Atlas 停止工作，需提前导出数据
  • 2026-08-26：o3 从 ChatGPT 退役（90 天日落期结束），GPT-4.5 同批退役
  • 2026-08-31：Codex 中 GPT-5.4 / 5.4 mini 退役 → 分别切到 GPT-5.6 Terra / GPT-5.6 Luna（ChatGPT 登录用户；自带 API key 的 Codex 使用另算）
  • 👉 实操提醒：本月是 OpenAI 老模型清仓月，脚本里写死 o3 / gpt-5.4 的地方要提前改

3) 研究发布

  • 08-01 发布 Ten advances in mathematics and theoretical computer science（openai.com/index/ten-advances-in-mathematics）

4) 社区负反馈

  • 开发者论坛出现多条 “Codex consistency issues since 5.6” / “Codex 更新是严重退步” 帖（07-31 起），5.5 Medium 被自动切到 5.6 Sol 引发不满，Luna 的 weekly usage 消耗速度与 API 定价不符也被投诉。降价的另一面是路由策略变动带来的体验波动。

🟣 Anthropic

1) 定价路线图：Sonnet 5 引导期即将结束

  • Opus 5：5输入/∗∗25** 输出（比 GPT-5.6 Sol 的 30输出便宜，输入同价5），官方定位为 Fable 5 之下的务实替代
  • Sonnet 5：当前 2/10 属引导价，官方计划 2026-09-01 上调至 3/15
  • 👉 实操提醒：如果有跑在 Sonnet 5 上的批量任务，9 月起成本会涨 50%，值得现在就把预算模型改过来

2) Anthropic × Blackstone 合资 Ode，规模 15 亿美元（07-31）

  • 定位为企业级 AI 落地实施公司，赌注是「企业部署能力比继续造模型更值钱」
  • 背景数据：Forbes AI 50（2026）显示 3056 亿美元私募 AI 市场里，OpenAI + Anthropic 合计占榜单总融资的 80%

3) 官网 newsroom 本窗口内无新模型发布

  • 官方站近期条目：Redeploying Claude Fable 5（07-04，出口管制解除后自 7 月 1 日重新部署，附更新的网络安全防护）、AI for Science 罕见遗传病研究资助（07-20）——均在 7 天窗口之外，此处仅作背景，不计入本周动态。
  • ⚠️ Tavily 的 answer 字段本周也确认「Anthropic 未宣布 8 月新版本」，与 results 一致。

🔵 Google / DeepMind

1) Gemini 产品面连续四天更新

  • 07-27 NOAA × Google Cloud 气象预报合作：NOAA 迁移到 Google Cloud H4D 虚拟机，成为首批把业务化数值天气预报（operational NWP）直接搬上公有云的全球主要气象中心
  • 07-29 Gemini for macOS 新增自然语言能力：口述即可生成干净转录、编辑与摘要，直接落到当前应用里
  • 07-30 Gemini Spark 接入 Chrome，同时对 Google AI Pro 订阅用户开放 160+ 个新国家/地区
  • 07-31 官方博客展示 Glanceboard：用 Gemini 3.6 Flash + Nano Banana vibe-code 出的晨间日程应用

2) 效率路线

  • Axios 归纳：Google 本轮一次性放出三款主打效率的 Gemini “flash” 模型（3.6 Flash / 3.5 Flash-Lite / 3.5 Flash Cyber），与 OpenAI 降价、DeepSeek 低价形成同向压力

3) Hassabis 提出 FINRA 式行业自律机构

  • 主张建一个类比金融业 FINRA 的独立机构：SEC 式政府监督下运行，由行业出资但人员独立，纳入独立技术专家、开源代表与政府官员，运营目标定在 2026 年底
  • Bloomberg 称白宫正在评估该模型（Treasury 部长 Bessent 参与设计）

🔷 Meta AI

1) 立场反转：Muse Spark 1.1 走闭源 + 激进定价

  • Axios（08-01）指出 Meta 在 Muse Spark 1.1 上「悄悄背离了长期拥抱开放权重的路线」，转为闭源并对开发者激进定价

2) 同时在政策层高举开源大旗（07-28）

  • 扎克伯格 WSJ 撰文：广泛分发 AI 的收益大于风险，真正的危险不是能力过强而是能力过度集中——读起来是对 “Pacing the Frontier” 联名信的正面反驳
  • Meta 联合 Nvidia、Microsoft、Palantir 发出联署信，要求监管方不要限制开放权重模型格式
  • 微妙之处：Meta 首席科学家 Shengjia Zhao 以个人身份签了 Pacing the Frontier 信，与 CEO 公开立场相左

🤗 Hugging Face

  • 安全事件后续：METR 就 Hugging Face 事件呼吁对 AI agent 越界行为建立独立的根因调查机制（08-02）。METR 于 2026-05 发布的 Frontier Risk Report 是首个跨行业的内部部署 agent 失配风险评估，Anthropic / Google / Meta / OpenAI 均提供了内部最强模型参与。Fortune（07-30）亦把 “Hugging Face hack” 与行业放缓讨论并列。
  • 托管动态：DeepSeek-V4-Flash-0731 上架 HF，仓库参数 304B（284B base + DSpark 草稿模块）
  • NVIDIA 主导的 37 成员 Open Secure AI Alliance（07-27）成立，承接 7 月 24 日那封「可下载模型让防守方获得与攻击方对等能力」的行业信

🇨🇳 国内厂商

DeepSeek —— 本周国内最强动作

V4-Flash-0731 正式版发布 + API 公测（07-31）

  • 模型卡明确写「正式版取代 preview」，架构与规模不变，性能提升全部来自重做 post-training
  • 强化方向：工具调用、任务规划、代码开发、Agent 执行
  • 附带 DSpark 投机解码模块（与 V4-Flash-DSpark 结构一致）
  • 调用方式不变，model 名设为 deepseek-v4-flash 即可
  • 定价：cache-miss 输入 0.14/M∗∗、cached输入∗∗0.0028/M、输出 0.28/M∗∗；V4−Pro输出约∗∗0.87/M
  • 能力位置：Axios 称 V4 Flash 在复杂代码与自主软件任务上接近 Claude Opus 4.8；在 Arena.ai 前端代码众包榜上首发即高位
  • 生态注脚：DeepSeek V4 与 GLM-5.2 采用 MIT、Qwen3.6 开放模型为 Apache 2.0，三家都允许无限制商用
  • 连带效应：Michael Burry 公开点评，认为 OpenAI 降价的「真新闻」是为 DeepSeek V4 做准备

MiniMax —— H3 多模态生成模型

  • 2K 视频生成 0.8 元/秒，约为同级旗舰的 1/3
  • 降本手段：高压缩 Tokenizer 减少视频生成 token 消耗 + 异构训练/任务负载均衡/GPU 利用率优化
  • 将于近期开放权重，成为 MiniMax 首个开源多模态生成模型；企业可本地部署，国产芯片厂商可围绕它做软硬协同优化

字节跳动 —— Seedance 2.5

  • 继承 Seedance 2.0 的统一音视频联合生成架构
  • 单次生成时长 15s → 30s（翻倍），且不是单镜头拉长，而是在 30 秒内组织多个逻辑关联镜头，做出起承转合

行业榜单：《2026 中国 AI 大模型竞争力 TOP20》（07-28 发布）

中国数据研究中心首次构建技术/商业/生态/潜力四维评估体系，盘点 68 家主流厂商。TOP 序列：

豆包 → 通义千问 → DeepSeek → 智谱AI → 百度文心一言 → 腾讯混元 → 月之暗面 Kimi → MiniMax → 华为盘古 → 阶跃星辰 → 小米 MiMo → 讯飞星火 → 美团 …

  • 豆包以日活破 1 亿居首，通义千问商业化能力突出，DeepSeek 领跑开源技术
  • 报告主张行业关注点已从「参数规模」转向落地与生态
  • ⚠️ 该榜单为第三方研究机构发布，非厂商官方公告，此处按行业参考收录

其他开源格局参考

  • GLM-5.2（智谱，744B MoE，6 月发布）在开放权重指数上以 51 分居首
  • Kimi K3（月之暗面，2.8T MoE / 896 experts / 16 active，07-16 发布）本周仍是舆论焦点：Zacks 以 “DeepSeek 2.0, or is this Time Different?” 为题讨论其冲击；Cline 已把 K3 以约 5 折官方折扣接入

🏛️ 监管与政策（影响厂商发布节奏）

  • 白宫 AI 审查 8 月 1 日截止：行政令本身是自愿性质，且明确不得被解读为强制许可或预审授权。但《2018 出口管制改革法》给了商务部独立权限——2026 年 6 月商务部曾在 Anthropic 两款模型发布后 90 分钟内切断其全球访问，并要求 OpenAI 限制 GPT-5.6 Sol 的推出节奏，两家均已配合。实际效果：不参与「自愿」预发布审查的实验室会承担现实风险。
  • 游说支出：OpenAI + Anthropic 2026 Q2 联邦游说合计 317 万美元，环比 +23%（CNBC 依据联邦披露）。两家在截止日前约两周向政府草案框架提交了联合修订意见——「政府起草规则、被监管企业修订、政府发布」的流程被批评为利益冲突。
  • “Pacing the Frontier” 联名信：OpenAI 与 Anthropic 正式支持「放慢会自己写代码的 AI」；Meta 阵营公开反对（见上文）。
  • 制度归属之争：OpenAI 6 月 3 日的联邦框架蓝图主张以商务部 AI 安全标准中心为主导机构（基于加州/纽约/伊利诺伊已立法），而 6 月行政令把阈值判定交给了 NSA。

📌 对飞哥的三条实操建议

  1. 9 月 1 日前重算 Sonnet 5 成本：2/10 是引导价，9 月起变 3/15（+50%）。有长期批量任务的话现在就把预算和模型选择过一遍。
  2. 8 月是 OpenAI 老模型清仓月：08-09 Atlas 停摆、08-26 o3 退役、08-31 Codex 里 5.4 系列退役。脚本/配置里写死旧模型名的地方本月内改完。
  3. 国产开源多模态值得占个坑：MiniMax H3 即将开放权重（首个开源多模态生成模型），DeepSeek V4-Flash 是 MIT 且 agent/代码能力对标 Opus 4.8、输出价 $0.28/M。信息聚合和笔记类任务里，把部分链路切到 V4-Flash 能显著降本。
