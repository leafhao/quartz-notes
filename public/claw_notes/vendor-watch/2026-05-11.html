📌 今日重点动态

OpenAI（5月5-7日密集发布）

1. GPT-5.5 Instant 发布（5月5日）

  • 定位：替代 GPT-5.3 Instant 成为 ChatGPT 默认模型
  • 特性：更智能、答案更清晰简洁、个性化响应
  • API：chat-latest 别名
  • 个人化：从历史聊天、文件、Gmail 集成增强个人化（Plus/Pro 用户优先）
  • 链接：https://openai.com/index/gpt-5-5-instant/

2. ChatGPT 广告平台扩展（5月5日）

  • 新增 CPC 竞价模式：按点击付费
  • 广告原则：答案保持独立 unbiased，对话隐私，用户控制体验
  • 链接：https://openai.com/index/new-ways-to-buy-chatgpt-ads/

3. 语音智能 API 新模型（5月7日）

  • GPT-Realtime-2：实时语音交互最强模型
  • 关键升级：
    • 上下文窗口从 32K → 128K
    • 支持 Preambles（工作提示语）
    • 并行工具调用 + 透明化
    • 更强恢复行为
  • 三种模式：实时语音、实时翻译、实时转录
  • 链接：https://openai.com/index/advancing-voice-intelligence-with-new-models-in-the-api/

4. ChatGPT 广告测试扩展（5月7日更新）

  • 新增市场：英国、墨西哥、巴西、日本、韩国
  • 此前试点：美国、加拿大、澳大利亚、新西兰
  • 链接：https://openai.com/index/testing-ads-in-chatgpt/

📈 行业趋势观察

1. OpenAI 产品节奏加速

  • 5月5-7日连续发布4项更新
  • 从模型升级到商业化（广告平台）再到多模态（语音 API）
  • 显示 OpenAI 正在从单一模型公司转向”模型+平台+生态”

2. 语音交互成为新战场

  • GPT-Realtime-2 128K 上下文支持长对话
  • 实时翻译、转录能力开放 API

3. 国内算力成本上升

  • 腾讯云率先宣布算力涨价 5%
