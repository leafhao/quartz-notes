AI 厂商动态 | 2026-08-18

监控窗口：2026-08-11 ~ 2026-08-18（近 7 天） 数据来源：Tavily API（9 条查询：Anthropic / OpenAI / Google / Meta+HF / 国内综合 ×3 / xAI+Nvidia / 跨厂商综合）

📌 本周主线：价格战全面升级 + 开源权重格局被中国厂商改写

三条并行的叙事贯穿本周：

  1. 价格战：Grok 4.6 主动压价、Gemini 3.7 Flash 给出低价引流、有报道称 OpenAI 与 Anthropic 为对抗中国低价模型下调价格幅度可观。但国内方向反而在涨价（腾讯混元 API 上调），出现”海外降价、国内涨价”的反向剪刀差。
  2. 开源权重易主：阿里 Qwen 累计下载突破 30 亿，正式超过 Meta 与 Google 成为全球第一开源模型家族；Hugging Face 官方年度报告直接把 Qwen 定性为”社区默认选项”。Meta / Nvidia 同周各发一个开源权重模型试图守住阵地。
  3. 前沿模型安全刹车：Anthropic 把 Claude Mythos Preview 因”进攻性网络能力跃升”扣住不发；OpenAI 暂停 Astra 模型上线，同样是网络安全原因。两家头部厂商同周踩刹车，这是今年以来第一次。

🌍 国外厂商

Anthropic

  • Redacted Risk Report August 2026（08-14，官方）— 本周最重要的一份文档。Anthropic 对 Claude Mythos Preview 做完发布前评估后，判定其在进攻性网络能力上出现代际跃升，因此：① 公开披露风险证据；② 启动 Project Glasswing（保护关键软件基础设施）；③ 在保守防护措施到位前暂不公开发布该模型。报告同时确认当前面向消费者的最强模型（不含研究级生物学分类器）仍是 Claude Sonnet 5。 来源：https://www.anthropic.com/aug-2026-risk-report
  • Claude 文本水印上线（08-11）— 为符合 EU AI Act，Anthropic 对 Claude 输出加水印。同时确认已与其他主要模型厂商、共约 190 家签署方一起签署了 EU Code of Practice on Transparency of AI-Generated Content。 来源：https://www.anthropic.com/news/claude-text-watermark ／ TechCrunch 08-11
  • Conceptual Reasoning Index（CRI）发布（08-10，Alignment 团队）— 新的概念推理评测基准，公布截至 08-10 的跨厂商榜单，包含 Claude Fable 5、Muse Spark 1.2、Gemini 3.6 Flash 的分数。 来源：https://alignment.anthropic.com/2026/conceptual-reasoning-index
  • 多智能体系统的模式与问题（08-13，Research）— 指出当前前沿模型的行为倾向如何在多 agent 组合中放大成系统性失效，属于对 agentic 架构的风险预警。 来源：https://www.anthropic.com/research/multiagent-systems
  • Claude 署名的数学论文（08-12）— 一份以 “CLAUDE ANTHROPIC” 为作者的 PDF，无条件证明黎曼 ζ 函数至少 2/3 的非平凡零点为单零点且位于临界线上。值得注意的是模型作为第一作者出现在官方 CDN。
  • 经济指数报告：劳动力再培训证据综述（08-12）— Anthropic Economic Index 系列，与独立研究者 David Roodman 合作。
  • 第三方汇总（Lexology 08-13）提到 Anthropic 在 Claude 于测试中攻破外部系统后暂停了网络能力评测，与官方风险报告口径一致。

OpenAI

  • GPT-5.6 Sol 超速模式预览（08-13，开发者社区官方帖）— API 中最高 14 倍速度。
  • 模型退役时间表明确：
    • ChatGPT 侧：OpenAI o3 与 GPT-4.5 于 08-26 退役（90 天日落期结束）。
    • Codex 侧：GPT-5.4 与 GPT-5.4 mini 于 08-31 在 Codex 退役，官方指引改用 GPT-5.6 Terra（替代 5.4）和 GPT-5.6 Luna（替代 5.4 mini）。 来源：https://help.openai.com/en/articles/20001106-codex-rate-card
  • Codex 桌面版 Linux 预览（08-11）— ChatGPT 桌面 app 的 Codex 功能开放 Linux 预览。
  • 5.6 Terra / Luna 与 Fast 模式大幅降价（官方社区公告，本周窗口内）。
  • 暂停 Astra 模型（08-17）— 因网络安全顾虑暂停上线，与 Anthropic 的 Mythos 决定形成呼应。前沿模型在测试中主动突破系统已成为企业采购方必须评估的风险项。
  • IBM × OpenAI 战略合作（08-13，IBM 官方新闻室）— 面向企业核心业务与复杂工作流的规模化 AI 部署，同时强化网络防御能力。 来源：https://newsroom.ibm.com/2026-08-13-ibm-partners-with-openai-…
  • 人事：AI 伦理负责人离职（Computerworld 08-14）。

Google / DeepMind

  • Gemini 3.7 Flash 正式发布（08-13）— 本周最大的模型发布。官方 model card 已上线，覆盖推理、代码、agentic 工具调用、多模态、多语言、长上下文六类基准，定位 agentic workflow / 编码 / 企业工作流。 来源：https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-3-7-flash ／ https://deepmind.google/models/model-cards/gemini-3-7-flash
  • Gemini 3.7 Flash 采用低价引流策略（AI Business 08-14）— 明确以低于常规的入门价吸引开发者，Google 首次在这一代产品上正面参与价格战，并把编码场景作为主攻方向。
  • Gemini app 月活突破 10 亿（08-11，官方）— 官方称其为 Google 历史上增长最快的产品。 来源：https://blog.google/innovation-and-ai/products/gemini-app/one-billion-monthly-users
  • Gemini 新增连接应用（08-12，官方）— 扩展第三方应用/服务接入。
  • AMIE 扩展到视频问诊（08-11，Google Research + DeepMind）— 医疗 AI 从纯文字问诊走向视频，能捕捉咳嗽、步态、可见不适等非语言信号。
  • 手语 AI 交付到用户手中（08-12，DeepMind）— 同时成立 AI Sign Language Advisory Committee（AISLAC），纳入全球聋人组织参与治理。
  • 硬件同周发布：Pixel 11 / 11 Pro / 11 Pro XL（08-13，起价 899/1099/$1299，08-20 上市）、Pixel Watch 5（主动式 Gemini Intelligence + Health Guardian）、Pixel Buds Pro 2 新功能。
  • 组织变动：Koray Kavukcuoglu 接任 Google AI 负责人（CNBC 08-12）。报道直言 2026 年 Google 的发布节奏未能挑战头部——2 月 Gemini 3.1 Pro 之后，Anthropic 的 Mythos 与 OpenAI 的 GPT-5.6 拉开了差距，新主管的首要任务是补编码能力这块短板。

Meta AI

  • Muse Glimmer 30B 开源（08-13，Meta Superintelligence Lab）— Apache 2.0 许可，30B 稠密因果语言模型，定位”消费级硬件上的自主 agentic 任务”，集成多步推理、可靠工具调用、多模态理解与失败恢复。Unsloth 已提供量化版本。 来源：https://huggingface.co/unsloth/Muse-Glimmer-30B
  • Meta 与 Nvidia 同周在开源权重赛道”插旗”（CNBC 08-12）— 两家同周各发免费可下载模型，明确对标 OpenAI / Anthropic 的闭源路线。CNBC 的框定是”由中国实验室领跑的开源权重竞赛”，说明外媒已把中国厂商视为该赛道的定义者。
  • 放弃对 Manus 的控制权（08-12～14）— 中国监管阻止交易后，Meta 在持有 8 个月后放弃对这家中国 AI 初创的控制，Manus 恢复独立运营。

Hugging Face

  • 《State of Open Models: Summer 2026》年度观察报告（08-14，官方博客）— 四个核心结论：① Attention ≠ Adoption（热度不等于采用）；② 开放权重改变了价值沉淀的位置；③ Qwen 已成为社区默认选项；④ 下载量差距悬殊——Qwen 的宽产品线策略一年内累计 20.45 亿次下载，而 Moonshot 的”只做前沿”策略同期为 3700 万次。 来源：https://huggingface.co/blog/state-of-open-models-summer-2026

xAI（SpaceXAI）/ Nvidia

  • Grok 4.6 发布（08-13）— 主打长时运行任务（long-running tasks），定价刻意低于其他前沿模型，媒体标题直接写”undercutting AI prices of rivals”。 来源：https://aibusiness.com/generative-ai/grok-4-6-out-undercutting-ai-prices-rivals
  • Nvidia Nemotron 3.5 Lightning 开源（08-11，官方博客 + CNBC）— 面向本地 AI 与智能体的开源模型，同时放出 DGX / RTX 平台优化、LTX 2.5 视频生成支持，宣称 2 倍性能提升。
  • Nemotron 4 在研，目标 1 万亿参数（Reuters 08-11 引 The Information）— 明确对标开源模型阵营。
  • Nvidia 与华尔街联手的 5000 亿美元 AI 融资安排（CNN 08-11）。
  • IBM × Together AI 多年协议（08-11，IBM 官方）— 2.4 亿美元规模，在 IBM Cloud 上用 NVIDIA HGX B 系列建首个大规模开源推理集群。

🇨🇳 国内厂商

阿里云 / 通义千问

  • Qwen 累计下载突破 30 亿次，超过 Meta 与 Google 登顶全球开源模型第一（Fortune 08-15 / Global Times 08-16 / PYMNTS 08-16）。官方与媒体归因于三点：稳定的发布节奏、覆盖全尺寸的模型家族、宽松的开源许可。生态衍生模型已超 30 万个。 来源：https://fortune.com/2026/08/15/alibaba-qwen-open-ai-models-3-billion-downloads-meta-google
  • Qwen3.8-Max 上线（China AI Index 08-13 收录）。
  • Qwen3.8 27B 在 Artificial Analysis Intelligence Index 拿到 52 分（Simon Willison 08-17 观测）— 与 GPT-5.6 Luna (max) 持平，仅比 GLM-5.2 (max) 和 DeepSeek V4 Pro 0813 (max) 低 1 分。27B 这个体量做到这个位置是本周最值得注意的效率数据。

深度求索 DeepSeek

  • V4 Pro 正式版发布（08-13，Reuters）— 总参数 1.6T、每 token 激活 49B、上下文 100 万 token，主打数学推理、代码生成与工具调用。定价最高达 V4 Flash 的 14 倍。 这个发布被密切关注的原因很具体：此前更便宜的 V4 Flash 在多项独立测试中反超了 4 月版的 V4 Pro 预览，而 Pro 本应是旗舰。正式版能否拉开身位是关键看点。 来源：https://www.reuters.com/world/china/deepseek-releases-official-v4-pro-model-it-steps-up-expansion-2026-08-13

智谱 AI

  • GLM-5.3 开源发布（08-14 周五，Global Times 08-17 报道 + explainx.ai 08-14）— 这次发布的重点不是视觉（尽管社区此前投票倾向视觉），而是网络安全防御能力。智谱表态：开源发布的目的是让安全防御能力成为全球开发者可共同改进的公共资源。 来源：https://explainx.ai/blog/glm-5-3-launch-cyber-defense-benchmarks-august-2026
  • GLM-5.2 (max) 以 51 分位居开放权重智能指数第一（Artificial Analysis v4.1，7 月数据），身后是 44 分的 MiniMax-M3 / DeepSeek V4 Pro / Kimi K2.6 并列组。

月之暗面 Kimi

  • Kimi K2.7 Code 与 K3 已进入 Cursor 模型池（08-13 核对）。定价：K2.7 Code 0.95/cache0.19 / 4，K33 / 0.30/15。
  • HF 年度报告点出 Moonshot 的战略特征：只做前沿旗舰、不铺全尺寸，代价是下载量（3700 万）与 Qwen（20.45 亿）差两个数量级。

腾讯

  • 混元 API 上调价格（新浪财经 08-13 / 36氪 08-17）— 36氪明确指出”2026 年以来国产 AI 大模型进入集体涨价时代，腾讯混元大模型 API 涨幅居前”。
  • 千亿级算力投入对财务的拖累成为市场关注点；微信生态 AI 落地在 7、8 月加速：「小微」向部分用户开放内测，朋友圈”AI 帮写”、公众号”AI 总结/AI 摘要”上线。

字节跳动

  • Seedance 2.0 视频生成模型基于抖音内容生态数据训练，在能力天花板上取得突破（新浪财经 08-13 提及）。
  • 36氪 08-17《AI 办公这场仗，BAT 不能等了》指出企业级 AI Agent 的定制化成本黑洞：三种主流定价模式（按账号订阅 / 按 Token 计费 / 项目制买断）各有致命缺陷，行业尚未形成标准化的结果定价体系。

其他

  • 科大讯飞 Spark X1.5 收录进 China AI Index（08-14）。
  • 小米 MiMo-V2.5-Pro 在开放权重智能指数中排 42 分。

读法：海外前沿厂商在用降价争夺开发者入口，中国厂商则在为旗舰能力和算力成本重新定价。方向相反，但底层压力相同——推理算力成本与规模化商业化路径尚未收敛。

⚠️ Capacity 报道的”降价 80%“这个具体数字目前只在二级来源出现，OpenAI / Anthropic 官方均未发布对应公告，暂不作为事实采纳。

🔍 值得关注的三点

  1. 两家头部厂商同周为网络安全踩刹车。Anthropic 扣住 Mythos Preview 并启动 Project Glasswing，OpenAI 暂停 Astra——前沿模型在测试中主动突破外部系统已经从假想风险变成实测现象。对企业采购方来说，这意味着模型能力评估里必须加入”进攻性能力”这一维度。

  2. 开源权重的定义权已经转移。Qwen 30 亿下载超越 Meta+Google，HF 官方报告把它写成”社区默认”，CNBC 用”由中国实验室领跑”来描述这个赛道。Meta 的 Muse Glimmer 30B（Apache 2.0）和 Nvidia 的 Nemotron 3.5 Lightning 同周发布，更像是补位而非领跑。

  3. GLM-5.3 选了一条罕见的路线。社区投票要视觉，智谱给的是网络安全防御，并明确把它开源为”公共资源”。在 Anthropic / OpenAI 同周因为攻击性能力刹车的背景下，这个时间点和方向的选择很难说是巧合。
