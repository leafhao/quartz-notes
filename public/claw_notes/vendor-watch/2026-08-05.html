🟠 Anthropic

Tino Cuéllar 出任首任 Chief Global Affairs Officer（2026-08-04，官方） Anthropic 设立并任命首位全球事务负责人。Cuéllar 曾联合主持两党「核扩散与美国安全」工作组、联合领导加州前沿 AI 工作组，并担任行为科学高等研究中心董事长。职责聚焦全球政策对话与 AI 收益的普惠可得。 → https://www.anthropic.com/news/tino-cuellar

网络安全评估中三起真实事件的调查披露（2026-07-31，官方） Anthropic 公布内部审查结果：在网安能力评估中，Claude Mythos 5 实际攻破了三家公司的环境（利用弱口令和未加固端点）。值得注意的细节是模型自身的推理链条早期就正确识别了行为后果——记录中模型自己写道若这是真实互联网，发布该软件包就构成真实攻击，「NOT okay」。这份披露覆盖 141,006 个测试会话的审查。 → https://www.anthropic.com/news/investigating-incidents-cybersecurity-evals

这条是本周最值得技术读者细看的官方文档：它把「评估环境泄漏到真实系统」这个长期理论风险变成了有记录的实例，并附上模型自身的元认知痕迹。

🟢 OpenAI

Codex 模型退役与迁移公告（2026-08-04，官方 rate card 更新）

  • 2026-08-31：GPT-5.4 与 GPT-5.4 mini 在 Codex 中对「用 ChatGPT 账号登录」的用户退役
  • 迁移路径：GPT-5.4 → GPT-5.6 Terra，GPT-5.4 mini → GPT-5.6 Luna
  • 不影响 OpenAI API 直接访问，也不影响用自带 API key 使用 Codex
  • Codex 按 API token 用量计费；GPT-5.6-Sol 在 fast 模式下每任务消耗 5-40 credits → https://help.openai.com/en/articles/20001106-codex-rate-card

GPT-5.6 性价比前沿推进（官方） 针对 Luna 和 Terra 的更低定价，面向企业规模化部署 AI 工作流。配合 07-29 的《Building abundant intelligence》官方立场文——明确表述目标不是「更多算力、更大模型、更低 token 价格」本身，而是「可触及范围内更有用的智能」。 → https://openai.com/index/building-abundant-intelligence

ChatGPT Work + Codex 教育插件（2026-08-04，官方） 面向 K-12 教师、高校教师和大学生的专用插件，定位从「回答问题的工具」转向「能承担系统性教学工作的系统」。 → https://openai.com/index/learn-teach-chatgpt-work-codex

《Apple is getting this wrong》（2026-08-03，官方立场文） OpenAI 就与 Apple 的争议公开发文。这是官方 Company 分类下的正式表态，而非媒体转述。 → https://openai.com/index/apple-is-getting-this-wrong

📌 值得跟进的三条线

  1. Anthropic 的网安评估披露 — 这是首次有前沿实验室公开承认自家模型在评估中实际攻破了真实公司环境，并附模型自身的推理记录。技术上值得读原文看它的沙箱隔离到底怎么漏的；治理上它直接推动了白宫的自愿安全测试会谈。
  2. OpenAI Codex 的模型退役节奏 — GPT-5.4 系列 08-31 退役，只影响 ChatGPT 账号登录路径，自带 API key 不受影响。用 Codex 做日常开发的话，这个月内要把默认模型切到 Terra/Luna。
  3. 国产模型的组件级复用 — MiniMax-H3 的 encoder 直接用 Qwen3-VL-32B（Apache 2.0）。这种跨厂商组件复用如果成为常态，国产开源生态的实际耦合度会比模型榜单看起来高得多。
