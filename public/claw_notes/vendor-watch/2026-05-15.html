AI 厂商动态 | 2026-05-15

监控时间窗口：2026-05-08 至 2026-05-15（最近7天）

📊 本周概览

本周 AI 厂商动态活跃，国际厂商聚焦模型能力提升和企业服务，国内厂商则在商业化和生态建设上持续发力。

国际厂商：OpenAI 发布 GPT-5.5 Instant 和语音 API 更新，Anthropic 推出 Claude Opus 4.7 并宣布多项合作 国内厂商：腾讯混元登顶 OpenRouter 榜首，阿里云发布 HappyHorse 视频生成模型

🌍 国际厂商动态

OpenAI

GPT-5.5 Instant 发布（5月5日）

  • 核心更新：更智能、更准确、更个性化的默认模型
  • 能力提升：
    • 事实准确性大幅提升，在高风险领域（医疗、法律、金融）幻觉率降低 52.5%
    • 不准确声明减少 37.3%
    • 增强记忆和个性化能力
  • 定位：成为用户工作、浏览、规划、写作的默认操作层
  • 来源：OpenAI 官方博客

语音智能 API 更新（5月7日）

  • 新模型发布：
    • GPT-Realtime-2：最智能的语音模型
    • GPT-Realtime-Translate：实时翻译
    • GPT-Realtime-Mini：轻量级语音模型
  • 应用场景：实时语音交互、语音代理、浏览器工作流
  • 来源：OpenAI API 文档

Codex 浏览器集成（5月14日）

  • 功能：Codex 可在浏览器中直接使用
  • 意义：AI 代理更加生产就绪，降低使用门槛
  • 来源：OpenAI 产品更新

Anthropic

Claude Opus 4.7 发布（5月4日）

  • 核心能力：
    • 指令遵循能力大幅提升（会严格按照指令执行，需重新调优 prompt）
    • 金融和知识工作领域达到 SOTA 水平
    • 增强的代码审查功能
  • 定价：面向 Pro、Max、Team 和 Enterprise 用户，具有竞争力
  • 来源：Anthropic 官方博客

研究更新（5月7-8日）

  • 5月8日：发布”Teaching Claude why”研究，减少代理错位
  • 5月7日：
    • 自然语言自动编码器：将 Claude 的思维转化为文本
    • 开源对齐工具捐赠
    • Anthropic Institute 重点领域发布
  • 来源：Anthropic Research

商业合作（5月13-14日）

  • 5月14日：与盖茨基金会达成 2 亿美元合作
  • 5月13日：推出 Claude for Small Business
  • 5月6日：提高 Claude 使用限制，与 SpaceX 达成算力协议
  • 5月5日：推出金融服务代理
  • 来源：Anthropic 新闻中心

Google DeepMind

Gemini 3 Deep Think（2月12日发布，持续更新）

  • 定位：专为科学、研究和工程设计的推理模式
  • 能力：解决现代科学、研究和工程挑战
  • 来源：Google AI Blog

🇨🇳 国内厂商动态

腾讯混元

混元 3.0 登顶 OpenRouter（5月7日）

  • 成绩：以 3.66 万亿 Token 调用量登顶总榜第一
  • 细分榜单：同时拿下编程和工具调用两个场景冠军
  • 意义：中国模型首次长期占据榜首，打破海外模型垄断
  • 背景：首席 AI 科学家姚顺雨接手后的第一张成绩单
  • 来源：新浪财经报道

阿里云

HappyHorse 视频生成模型（5月6日）

  • 模型系列：
    • HappyHorse-1.0-t2v：文生视频，支持有声视频生成
    • HappyHorse-1.0-i2v：图生视频（基于首帧）
    • HappyHorse-1.0-video-edit：视频编辑
  • 规格：可生成 3-15 秒、720P/1080P 视频
  • 来源：阿里云文档

字节跳动

豆包推出收费模式（5月）

  • 转变：从纯免费转向分层付费
  • 背景：中国大模型市场从”百模大战”收敛为”巨头生态领跑 + 技术新贵突围”
  • 数据：
    • 豆包大模型日均 Token 使用量已突破 120 万亿（截至3月）
    • 过去三个月增长一倍，比2024年5月增长1000倍
    • 火山引擎上累计 Token 使用量超万亿的企业从100家增至140家
  • 来源：36氪报道

Seedance 2.0 API 开放公测（4月2日）

  • 功能：企业级视频生成 API
  • 安全保障：行业领先的版权与肖像安全保障，覆盖全流程
  • 来源：澎湃新闻

月之暗面（Kimi）

Kimi K2.6 发布（4月下旬）

  • 核心能力：
    • HLE-Full（带工具）得分 54.0，超过 GPT-5.4 和 Claude Opus 4.6
    • DeepSearchQA F1 分数 92.5，准确率 83.0
    • SWE-Bench Pro 得分 58.6，SWE-Bench Verified 达到 80.2
  • 战略调整：急招 Kimi Code 平台推理工程师（本科学历，3年经验）
  • 背景：在 DeepSeek 冲击下，专注底层模型研发和工程化能力
  • 来源：钛媒体报道

智谱 AI & MiniMax

港股上市表现（截至5月9日）

  • 智谱 AI：市值突破 4000 亿港元
  • MiniMax：市值稳定在 2300 亿港元
  • 意义：成为”全球大模型第一股”，为后续厂商 IPO 铺路
  • 来源：腾讯云开发者社区

百度

职级体系改革（4月28日宣布，5月1日执行）

  • 改革内容：
    • 取消原有 T/P/E/M 字母职级体系
    • 统一调整为 5-12 级数字职级体系
    • 将 AI 工具应用、大模型落地能力、AI 业务产出纳入全员绩效考核
  • 来源：澎湃新闻

🔍 行业趋势观察

1. 模型能力持续提升

  • 国际：OpenAI 和 Anthropic 聚焦准确性、推理能力和企业服务
  • 国内：腾讯混元、月之暗面在编程和工具调用上取得突破

  • 企业服务：Anthropic 推出小企业版和金融服务代理，OpenAI 强化 API 能力

3. 多模态扩展

  • 视频生成：阿里云 HappyHorse、字节 Seedance 2.0 开放企业级 API
  • 语音智能：OpenAI 发布三款实时语音模型

4. 生态竞争白热化

  • 榜单争夺：腾讯混元登顶 OpenRouter，中国模型频繁出现在全球榜首
  • 人才争夺：月之暗面急招工程师，各大厂商加大研发投入

5. 资本市场活跃

  • 上市潮：智谱、MiniMax 成功上市，阶跃星辰 25 亿美元融资即将落地
  • 战略投资：Anthropic 获盖茨基金会 2 亿美元投资，字节 AI 预算上调至 2000 亿元
