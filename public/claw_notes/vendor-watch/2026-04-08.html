AI 厂商动态 - 2026-04-08

本笔记记录国内外 AI 大模型厂商的最新动态，包括新模型发布、API 更新、定价变化、技术突破等。

🌍 国外厂商

Anthropic Claude

重大发布：Claude 4.6 系列

  • 2026年2月5日：发布 Claude Opus 4.6 和 Sonnet 4.6
  • 2026年3月13日：1M token 上下文窗口正式可用
  • Opus 4.6 在 MRCR v2 8-needle benchmark 1M tokens 达 78.3%，Sonnet 4.6 达 65.1%
  • 显著超越 GPT-5.4 (36.6%) 和 Gemini 3.1 Pro (18.3%)

产品矩阵扩展（2月-3月）

  • Cowork（协作工作空间）
  • Agent Teams（智能体团队）
  • Computer Use（计算机操作能力）
  • Channels（消息频道）
  • Dispatch（调度系统）
  • Scheduled Tasks（定时任务）
  • Plugins（插件系统）
  • Projects（项目管理）

定价策略

  • 截至 2026年4月，Anthropic 未进行任何 Claude 模型定价变更
  • Batch API 支持 Opus 4.6 和 Sonnet 4.6 输出扩展至 300k tokens

官方来源：Claude API Docs

Google DeepMind

Gemini Deep Think 发布

  • 专注科学研究和数学推理的专门模型
  • 在 IMO-ProofBench Advanced 和 FutureMath Basic 表现优异
  • 采用 Aletheia 验证框架，多轮自我迭代推理

Gemini 3 系列

  • Gemini 3.1 Pro 作为旗舰模型
  • 支持长上下文推理和多模态理解

新产品线

  • Genie 3：生成和探索交互式世界
  • Gemini Robotics：感知、推理、工具使用和交互
  • Gemma 4：开源模型，31B 参数版本
  • Gemini Image Flash：快速图像生成
  • Veo 3：视频生成
  • WeatherNext：AI 天气预报

官方来源：DeepMind Models

Meta AI

Llama 后继模型动态

  • Llama 后继模型（内部代号 Llama 4.X/4.5）开发延迟
  • 转向闭源 AI 模型策略
  • Superintelligence Labs 团队聚焦封闭模型开发

开源策略变化

  • 报道称 Meta 正在重新评估开源策略
  • 内部重组影响 AI 实验室结构

官方来源：Digitimes 报道（非官方确认，需关注后续发布）

🇨🇳 国内厂商

智谱AI GLM

GLM-5 发布（2026年2月11日）

  • 新一代旗舰模型，代号 “Pony Alpha”
  • 参数规模：从 355B 扩至 744B，激活参数从 32B 提至 40B
  • 预训练数据：从 23T 升至更大规模
  • 上下文长度：达到 100万 token
  • 定位：Agentic Engineering 范式重构，编程与智能体能力重点提升
  • 对标：Anthropic Claude Opus 系列
  • 开源：已开源发布

官方来源：36氪、新浪财经

  • 主打 AI 代理和编程能力

产品矩阵

  • Kimi K2.5 多模态模型
  • Kimi Claw 智能体系统

估值动态

  • 估值飙升至 180亿美元，3个月翻4倍
  • Kimi 产品用户增长爆发

官方来源：什么值得买、新浪财经

  • MODEL1：GitHub 中出现新模型标识符，可能代表新架构

技术进展

  • FlashMLA 代码更新横跨114个文件

官方来源：联合早报、新浪财经

Qwen3-Max-Thinking 发布（2026年1月26日）

  • 采用全新 Test-time Scaling 机制
  • 原生 Agent 能力大幅增强，可自主调用工具

  • 100万 token 超长上下文
  • 业界领先 Agentic Coding 能力
  • 原生多模态理解（图像、视频、音频）
  • 已上线 OpenRouter 和阿里云百炼平台

Qwen3.5 系列（2026年2月）

  • 多个型号发布，除夕夜发布 Qwen3.5-Plus
  • 主打”更强智能、更广覆盖”

官方来源：中国科技网、掘金

能力提升
