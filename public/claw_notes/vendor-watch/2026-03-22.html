AI 厂商动态监控 - 2026年3月22日

本周是 2026 年 AI 历史上最爆炸的一周，多个厂商同时发布旗舰模型。

🌍 国外厂商

OpenAI

  • GPT-5.4 mini & nano 发布 (3月17日)
    • “最强大的小型模型”，比 GPT-5 mini 快 2 倍以上
    • GPT-5.4 mini 已在 GitHub Copilot 上推出
    • 免费用户可通过 Thinking 功能使用
  • GPT-5.4 Thinking (3月5日发布)
    • 高性能深度思考模型

Anthropic

  • Claude Opus 4.6 (2月发布，本月更新)
    • METR 估计任务完成时间最长的模型（50% 时间阈值 14.5 小时）
    • 默认输出 token 提升到 64k，上限 128k
  • Claude Code 重大更新 (3月)
    • Push-to-talk 语音模式
    • /loop 循环任务
    • 100 万 token 上下文窗口
    • Opus 4.6 成为默认模型

Google DeepMind

  • Gemini 3.1 Pro (2月19日发布)
    • Google 最强大的公开 AI 模型
    • 在推理、代码生成、多模态理解上显著提升
  • Gemini 3.1 Flash Lite (3月3日预览)
    • “最具性价比的模型”
    • 100 万 token 上下文窗口
    • 完整多模态支持

Meta AI

  • Llama 4 (2025年4月已发布)
    • 采用 MoE (Mixture of Experts) 架构
  • 动态：Meta 正在考虑授权 Google Gemini

🇨🇳 国内厂商

月之暗面 (Kimi) ⭐ 本周亮点

  • Kimi K2.5 发布 (1月)

    • 多模态升级，添加原生视觉能力
    • 4 亿参数的 MoonViT 视觉编码器
    • 支持图像和视频处理

  • Attention Residuals 技术报告 (3月16日) 🔥

    • 马斯克点赞的重磅技术
    • 改造几乎所有现代大模型使用的残差连接结构
    • 同样算力下效果相当于基线模型 1.25 倍算力
    • GitHub 开源：github.com/MoonshotAI/Attention-Residuals

MiniMax ⭐ 本周亮点

  • MiniMax M2.5 (2月发布)

    • 在编程、工具调用、搜索、办公等生产力场景达到 SOTA
    • SWE-Bench Verified: 80.2%
    • Multi-SWE-Bench: 51.3%
    • 比 M2.1 完成任务速度快 37%
    • 成本极低：每秒 100 token 连续工作 1 小时仅需 $1

  • MiniMax M2.7 (3月发布) 🚀

    • “自进化”模型 - 无需人类干预
    • 可自主完成 30-50% 的强化学习研究工作流
    • 在软件工程和专业办公任务上显著提升

智谱AI (GLM)

  • GLM-5 (2月11日发布)
    • 新一代旗舰模型
  • GLM-5-Turbo (3月16日发布)
    • 专为 Agent 场景优化的模型
    • 通过 Slime 训练框架具备长序列任务执行能力
    • API 价格大幅上涨：相对 GLM-4.7 上涨约 83%

深度求索 (DeepSeek)

  • DeepSeek V4 即将发布 (预计下周)
    • 市场高度期待
  • 趣闻：日本乐天”最强 AI”被发现是套壳 DeepSeek，日本网友集体破防

阿里云 (通义千问)

  • Qwen3.5 - 首个原生多模态大模型
    • 统一架构整合语言推理与视觉感知
  • qwen3-max-2026-01-23
    • 融合思考模式与非思考模式
    • 原生支持 search agent
    • 已上线 Microsoft Azure (3月)

字节跳动 (豆包)

  • 豆包大模型 2.0 系列 (2月发布)
    • 采用 MoE 稀疏架构
    • 在中文场景与实时交互上建立壁垒
    • TVBench、EgoTempo 基准上超越人类分数
    • 动态场景理解能力强（健身指导、穿搭建议等）

小米 (MiMo) ⭐ 本周热点

  • Hunter Alpha 神秘模型事件 (3月11日-18日)
    • 神秘模型突然出现在 OpenRouter 平台
    • 性能强劲，被误认为是 DeepSeek V4
    • 真相揭晓：小米 MiMo-V2-Pro 早期测试版本
    • 由前 DeepSeek 研究员罗福莉领导
    • 设计为 AI Agent 的”大脑”

腾讯 (混元)

  • 混元 3.0 大模型 (计划 4 月发布)

    • 正在内部业务场景测试
    • 马化腾：“智能水平将实现显著跃升，就像 2.5 相对于 1.0 的提升”
    • 挖走 27 岁 AI 天才姚顺雨

  • Cinema 4D 集成

    • 将集成腾讯混元 3D 引擎
    • 实现文本/参考图生成 3D 模型

📊 行业趋势

本周关键词

  • Agent 时代：GLM-5-Turbo、MiMo-V2-Pro、MiniMax M2.7 都强调 Agent 能力
  • 自进化模型：MiniMax M2.7 的”self-evolving”概念
  • 架构创新：Kimi 的 Attention Residuals 打破传统残差连接
  • 小型化趋势：GPT-5.4 mini/nano、Gemini 3.1 Flash Lite

价格动态

  • 智谱 API 价格 2026 Q1 接近翻倍
  • MiniMax 主打极致性价比

竞争格局

  • 国外：OpenAI、Anthropic、Google 形成三足鼎立
  • 国内：DeepSeek、MiniMax、Kimi、智谱、字节跳动竞争激烈
  • 新玩家：小米意外入局，MiMo-V2-Pro 性能惊艳
