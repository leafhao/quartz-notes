监控窗口：2026-08-19 ~ 2026-08-26（近 7 天） 检索方式：Tavily 9 条查询 — 4 条厂商官方域名限定（topic:general）+ 5 条综合/国内新闻（topic:news） 筛选原则：官方 changelog / release notes / 厂商公告优先；窗口外内容（如 Gemini 3.7 Flash GA 于 8-13、Meta Muse Glimmer 于 8-10）已排除或明确标注

一、国外厂商

Anthropic — 本周最活跃

1. Claude API / SDK 连续两天更新（官方 release notes，8-19 & 8-20） 来源：https://docs.anthropic.com/en/release-notes/api

  • 8-19：工具链大幅扩容
    • 新增 computer_toolset_20260801（支持 zoom 参数与 configs 配置，替代 computer_20251124）
    • 新增 browser_toolset_20260801、agent_toolset_20260401
    • Files API（/v1/files）加入分页（page / next_page / ids[]）与过期控制（expires_in_seconds / expires_at）
    • /v1/skills 端点（skills-2025-10-02），支持 container / mount_path
    • web_search / web_fetch 支持 allowed_domains / blocked_domains 白/黑名单与 max_content_tokens
    • 企业用户管理 beta：anthropic-beta: ce-user-management-2026-07-13
    • 工具级 permission_policy
  • 8-20：SDK 层面破坏性变更
    • HTTP 客户端迁移到 httpx2（DefaultHttpxClient、httpx2.alias_httpx() 兼容层）
    • 采样参数 temperature / top_p / top_k 行为调整
    • 新增 compaction_control（上下文压缩控制）
    • 原始响应接口改为 .with_raw_response + await response.parse()
    • AnthropicBedrock 支持 us-east-1

对做 Agent 的开发者影响最大的是 computer_toolset / browser_toolset / agent_toolset 三件套同日更新 + 工具级 permission_policy，Anthropic 明显在把 computer-use 往生产级权限治理推。httpx2 迁移是硬性的，升级 SDK 前要看迁移指南。

2. Claude Mythos 5 走出 Glasswing 白名单，进入 Claude Security（8-21） 来源：unite.ai（8-21）、dataconomy（8-24）、finance.biggo（8-21）

  • Mythos 5 是 Anthropic 解除网安安全分类器限制的模型，此前自 2026-04 起仅向审核过的防御方（Project Glasswing 伙伴）开放
  • 8-21 起在 Claude Security（企业版漏洞扫描服务，公测中）中承担实际漏洞扫描，按常规 token 计费
  • 同时宣布：$35M credits 开源防御基金、把 Mythos 5 接入安全伙伴产品、扩展 Cyber Verification Program 到 Mythos 级访问
  • Mythos 5 定价 10/M输入、50/M 输出；Mythos 类流量带 30 天留存要求
  • 背景：6-09 Fable 5 / Mythos 5 分叉发布，Fable 5 走 GA（网安/生物类查询路由到 Opus 4.8），Mythos 5 走白名单；8 月初重调 Fable 5 生物安全分类器，误拦下降 85%

3. Claude Sonnet 5 定价与 tokenizer 变更定档 8-31（⚠️ 信源冲突）

  • Machine Brief（8-23）称 8-31 起 Sonnet 5 从 2/10 涨到 3/15，并同步换 tokenizer，代码类文本 token 数增加 10–35%，实际成本涨幅高于标价涨幅
  • 但另有信源（tech-insider，8-24）称 Anthropic 已于 8-10 宣布 launch pricing 永久化、取消 9-01 涨价
  • 官方 docs 的 “What’s new in Claude Sonnet 5” 页确认了 tokenizer 更换和三处行为变更（adaptive thinking 默认开、手动 extended thinking 返回 400、非默认采样参数返回 400），但未在检索内容中给出定价结论
  • 结论：tokenizer 变更确定存在，定价走向两个二手信源互相矛盾，需以 Anthropic 官方 pricing 页为准，不建议按任一说法做预算

4. $5M AI wellbeing 研究基金（8-25） 来源：startuphub.ai（8-25）

二、国内厂商

智谱 AI — GLM-5.3 上线（8-19）⭐ 本周国内最硬发布

来源：InfoQ AI 周报（8-24）、智能体工场周报（8-24/25）

  • 8-19 凌晨上线新一代基座模型 GLM-5.3 API，擅长复杂编码、防御性网络安全、长程任务

  • 同日国家超算互联网上线 GLM-5.3 API 调用服务
  • 另有报道称 GLM-5.3 在 CyberGym 网安基准登顶（84.5%），开源编码榜 8-14 登顶

字节跳动 — 发布”豆包工作”（8-25）

来源：新浪财经 / 华尔街见闻（8-25）、财联社（8-25）

  • 企业办公 Agent 产品，字节正式加入”办公 Agent 四国杀”（对手：阿里千问办公、腾讯 WorkBuddy、百度库库 AI）
  • 能力：授权后直接操作浏览器和电脑，跨软件处理数据 / 收集信息 / 填表 / 比对资料；长任务可调用云电脑持续执行，本机关机不中断；支持手机远程操控电脑
  • 多 Agent 协作：“工作小队”分工（数据 / 研究 / 设计 / 金融 / 科研）
  • 核心差异是与飞书深度打通：用飞书账号登录后可在权限范围内调用聊天记录、文档、会议纪要、日程；产出内容沉淀回飞书成为企业知识资产。飞书内原豆包企业版入口已升级为豆包工作

  • 官方称已成为国内首批通过”办公智能体能力 + 云端基准测试”双认证的办公智能体

行业观察（华尔街见闻）：办公 Agent 阶段的竞争逻辑从”谁家模型更强”变成”先把不同模型放进同一工作台，让用户把真实工作交进来”—— 真实工作流数据成为核心筹码。下一个关键问题是路由：同一任务调哪个模型，几分钱的单次调用差异会随任务量放大。

三、本周主线：国产大模型”涨价潮”与大厂按兵不动

来源：21 世纪经济报道 / 新浪财经（8-20）、智能体工场周报（8-24）

摩根士丹利统计（字节、阿里、百度、腾讯、MiniMax、智谱、月之暗面、DeepSeek 官方报价）：

指标2025 Q12026 Q2涨幅
平均 API 输入价（元/百万 tokens）3.34.9+48%
平均 API 输出价（元/百万 tokens）12.221.9+80%

分化格局

  • 独立厂商涨价：智谱年内三次调价、Kimi K3 发布价较前代涨超 3 倍、MiniMax M3 发布时 API 全面翻倍 —— “六小虎”已有四家完成涨价
  • 大厂按兵不动：阿里、腾讯、字节自有算力 + 自有场景，维持免费/低价拖住价格敏感客户
  • 价格分层已成型：从混元-TurboS 输出 ¥2/百万，到 Kimi K3 输出 ¥100/百万，相差 50 倍。国内大模型不再是”一个市场”，而是分化成多个定位不同的细分市场
  • 峰谷定价可能成新标准：DeepSeek 先行，把算力供需波动直接传导到价格

涨价动因（受访者观点）：AI 推理每次调用产生真实算力成本，前期补贴价难以长期维持；长上下文、深度推理、Agent 任务显著增加推理负载，高峰算力供给仍紧张。

两种解读

  • 正方：涨价是国产模型走出价格战底部的标志，敢收钱说明客户粘性真实存在
  • 反方：大厂不动才是最狠的杀招 —— 模型间替换成本在下降，只提价不匹配新能力，用户会用脚投票
  • 检验标准：不看涨价公告，看续费率

五、值得飞哥关注的三条

  1. Anthropic 的 computer-use 工具链在往生产级权限治理走（8-19 那批更新里的 permission_policy、allowed_domains/blocked_domains、agent_toolset）。这台 Mac mini 上的 computer-use 工作流如果依赖 Claude API，SDK 升级要留意 httpx2 是硬性迁移。

  2. GLM-5.3 是本期最值得试的国产模型：同一基础模型、纯后训练把 AA Index 推到 60 分（对标 Fable 5 / GPT-5.6 Sol），价格与 GLM-5.2 一致（输入 ¥8 / 输出 ¥28 每百万 tokens），下周五开源权重。飞哥手上有 GLM 凭证，“后训练撬动前沿能力”这条路径也贴合 SFT/RL 方向。

  3. 成本结构在重排，不是能力竞赛：OpenAI 旗舰降价 20%、Anthropic 换 tokenizer（隐性涨价）、DeepSeek 周末全低谷价、国产独立厂商普涨而大厂不动。做长期 Agent 类工作流的话，峰谷时段 + 缓存命中率现在对账单的影响可能超过换模型本身。
