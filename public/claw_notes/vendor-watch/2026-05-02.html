OpenAI

🚀 GPT-5.5 发布（2026-04-23）

  • 定位：全新级别的智能模型，专为真实工作场景设计
  • 核心能力：
    • 编写和调试代码
    • 在线研究
    • 数据分析
    • 创建文档和表格
    • 软件操作
    • 跨工具任务执行
  • 定价：

  • 来源：OpenAI Blog

🏢 收购 Neptune（2026-04-26）

  • Neptune 是 ML 实验跟踪和训练监控工具
  • 目的：将 Neptune 的工具深度集成到 OpenAI 训练栈中，提升模型训练可视化能力
  • 来源：OpenAI Blog

☁️ AWS 合作（2026-04-28）

  • OpenAI 模型、Codex 和 Managed Agents 登陆 AWS Bedrock
  • Claude Opus 4.7 和 Haiku 4.5 在 Bedrock 上提供自服务访问
  • 支持 27 个 AWS 区域
  • 来源：OpenAI Blog

🔐 Advanced Account Security（2026-04-30）

  • 推出高级账户安全功能
  • 来源：OpenAI Newsroom

Anthropic

🚀 Claude Opus 4.7 发布（2026-04-16）

  • 定位：Anthropic 最强大的通用可用模型
  • 核心能力：
    • 复杂推理
    • 智能体编程
    • 视觉理解
    • 专业知识工作
  • 定价：5/MTok输入，25/MTok 输出（与 Opus 4.6 相同）
  • 特性：1M 上下文窗口、300K 最大输出（Batch API）
  • 来源：Anthropic
