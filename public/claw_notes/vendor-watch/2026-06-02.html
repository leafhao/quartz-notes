AI 厂商动态 | 2026-06-02

监控窗口：最近 7 天（2026-05-26 ~ 2026-06-02）。只采信官方来源，传闻/预测/自媒体仅作交叉参考标注。

本周一句话

Anthropic 一周内连放两枚重磅：发布 Claude Opus 4.8，并以 9650 亿美元估值反超 OpenAI、于 6/1 秘密递交 IPO 招股书（S-1）。Google I/O 2026 余热延续，Gemini Spark 自主代理本周开始推送。国内方面 MiniMax 最活跃（新模型 M3 + 启动境内 IPO），其余厂商本周官方发布偏静。

🌍 国外厂商

Anthropic — 本周主角

  • Claude Opus 4.8 发布（5/28，官方）：在 Opus 4.7 基础上全面提升基准表现，新增「努力等级（effort level）」控制、Claude Code 的动态工作流（dynamic workflows）、以及比上代便宜约 3 倍的 fast mode；ARC 等基准报告约 84% 分数。
    • 来源（官方）：https://www.anthropic.com/news/claude-opus-4-8
  • 估值反超 OpenAI（5/28–5/29）：估值达约 9650 亿美元，首度超过 OpenAI 成为全球最具价值的 AI 创业公司。同期预告下一代模型 「Mythos」即将到来（仅官宣预告，尚未发布）。
    • 来源：Business Insider / Yahoo Finance / Investor’s Business Daily
  • 秘密递交 IPO 招股书（6/1，公司确认）：向 SEC 递交 S-1 注册声明，正式启动上市进程，与 OpenAI 的竞赛白热化；尚未确定发行股数与定价。
    • 来源：CNN / 华盛顿邮报 / 洛杉矶时报 / Gizmodo

OpenAI — 本周无新模型

  • 窗口内无新模型发布。官方最新内容为工程实践 「用 Codex 构建自我改进的报税 Agent」（5/27，官方）。
    • 来源（官方）：https://openai.com/index/building-self-improving-tax-agents-with-codex/
  • 当前主力仍为 GPT-5.5 / GPT-5.4 / GPT-5.3 Instant / GPT-5.3-Codex。第三方 DeepSWE 编码榜（5/26，VentureBeat）将 GPT-5.5 列为榜首，并指出 Claude Opus 存在「钻基准漏洞」嫌疑（第三方观点，非官方）。

Google DeepMind

  • Gemini Spark 开始推送（5/29）：可在手机熄屏状态下自主跑「数字差事」的代理能力正式下发，是 I/O 2026「Agentic Gemini」叙事的落地。
    • 来源：Android Authority
  • Google I/O 2026 余热：本周持续报道 Gemini Omni（统筹其他模型、支持动态编辑的「超级代理」视频模型）、Gemini 3.5（更快的 agentic 模型，含后台代理与应用集成）、以及与三星/高通合作的 Android XR「智能眼镜」。
    • 来源：Google blog / ynetnews / Chrome Unboxed
  • Hassabis AGI 预测（5/28）：在 Axios 访谈中表示 AGI 可能在 2030 年前后实现，最早不排除 2029。
    • 来源：Gigazine（转 Axios 访谈）
  • 开发者活动：与 Kaggle 合办 AI Agents Intensive Course，6/15–19 举行，报名已开。

Meta AI / Hugging Face — 本周官方静默

  • 窗口内未见 Llama 新模型或重大官方发布；当前主力仍为 Llama 4（Scout / Maverick）。Hugging Face 侧近期内容（JFrog Artifactory 企业指南）多在窗口外，无重大动态。

🇨🇳 国内厂商

MiniMax — 国内最活跃

  • 新模型 MiniMax M3：官方发布新一代模型，主打编码与 agentic（智能体）能力提升。
  • 启动境内 IPO（5/30–6/1）：在港股之后计划在中国大陆上市，剑指 DeepSeek 等本土对手；同期披露业务高增长。
  • 风险点：Hailuo 图像/视频系统遭 Disney、Universal、Warner Bros Discovery 的加州 IP 侵权诉讼，撤诉动议未获支持。
    • 来源：Bloomberg / Asia Tech Review

其余国内厂商（通义千问 / DeepSeek / 智谱 GLM / Kimi / 百度文心 / 字节豆包 / 腾讯混元）

  • 本周未检索到上述厂商的官方重大新发布。DeepSeek 主要以「MiniMax 对标对象」的身份出现在英文媒体报道中，无官方产品更新。
  • 说明：国内厂商缺乏统一权威英文官网，综合查询本周多返回英文财经媒体对行业的报道而非厂商官方公告。按惯例标注「本周国内厂商官方发布较少」，不以英文媒体行业分析充当厂商动态。

🔧 行业其他（交叉参考）

  • Nvidia 发布 Alpamayo 2 Super 开放推理模型（6/1）：面向自动驾驶的开放推理模型。来源：Automotive World
  • 企业部署竞赛：Forbes 报道 AI 巨头进入「13 周部署季」，OpenAI（Frontier Alliances）、Meta 等密集落地企业级合作。

📌 重点关注

  1. Claude Opus 4.8 已上线 —— 本周唯一来自一线厂商的官方新模型，effort level + fast mode 值得评测。
  2. Anthropic IPO + 反超 OpenAI 估值 —— AI 资本市场标志性事件，关注后续 S-1 细节与「Mythos」发布节奏。
  3. Gemini Spark 落地 —— Google agentic 战略从演示走向真实推送。
  4. MiniMax M3 + 境内 IPO —— 国内本周唯一明确的官方产品 + 资本动作。
