AI 厂商动态 | 2026-05-18

时间窗口：2026-05-11 → 2026-05-18（最近 7 天）。仅采信官方来源（openai.com / anthropic.com / blog.google / deepmind.google / ai.meta.com / 厂商官方）。

一周看点（TL;DR）

  • OpenAI 这一周仍是节奏最快的厂商：5/11 推出 OpenAI Deployment Company（企业 AI 落地子公司），5/13–5/14 把 Codex 推到全平台（Windows 沙箱、移动端 preview、远程 SSH/Hooks），5/15 上线 ChatGPT 个人理财体验，5/16 与 Figma 联手做 Codex ↔ Figma 双向集成，并宣布与马耳他合作向全民提供 ChatGPT Plus，同步 Stargate 扩建到密歇根。
  • Anthropic 主线仍在「绑大客户 + 绑算力」：5/13 推出 Claude for Small Business（含 LISC × Workday 创业者加速计划），5/14 同日双发——与盖茨基金会成立 2 亿美金合作 + PwC 全员部署 Claude（30 万人 + 3 万人持证）。本周无新模型，旗舰仍为 Claude Opus 4.7（4-16）。
  • Google / DeepMind 进入 I/O 前夜：Google I/O 2026 定档 5/19-20（窗口外），本周仅有 5/12 Android Show: I/O Edition——Gemini Intelligence 主动式特性、Gemini in Chrome for Android（含 auto-browse Agent）等先发预热。
  • Meta / Hugging Face 本周无重大官方发布。
  • 国内主线在「火山引擎 Agent Plan + 百度文心 5.1」：5/9 百度正式发布文心大模型 5.1（多维弹性预训练，已上线千帆 + 文心一言），5/11 字节火山引擎正式发布 Agent Plan（Coding Plan 升级，整合 Doubao-Seed/Seedance/Seedream + Harness 工具）。其他厂商（阿里 Qwen、智谱 GLM、Kimi、DeepSeek、MiniMax）以 4 月密集发布的延续铺开为主，本周以渠道与定价调整为主。

OpenAI

本周官方动态非常密集，从企业落地、Codex 全平台、ChatGPT 产品化到全球基建一线推进。

OpenAI Deployment Company（5/11）

  • 「OpenAI launches the OpenAI Deployment Company to help businesses build around intelligence」（5/11）。
  • 单独成立的子公司，专门做企业 AI 落地与部署服务，配合 GPT-5.5 & Codex 在大客户的规模化部署。
  • 来源：https://openai.com/index/openai-launches-the-deployment-company/

Codex 全平台一致性（5/13–5/14）

  • 5/13 「Building a safe, effective sandbox to enable Codex on Windows」：Codex 沙箱终于支持 Windows，三大桌面平台对齐。 来源：https://openai.com/index/running-codex-safely/
  • 5/14 「Work with Codex from anywhere」：Codex iOS / Android preview 全计划开放（含 Free / Go），同时上线 Remote SSH、Hooks、Programmatic access tokens。 来源：https://openai.com/index/work-with-codex-from-anywhere/
  • 5/13 同期发布「Our response to the TanStack npm supply chain attack」复盘，对 npm 生态供应链安全有参考价值。

ChatGPT 产品化（5/14–5/15）

  • 5/14 「Helping ChatGPT better recognize context in sensitive conversations」：心理健康/危机情境上下文识别，与 GPT-5.5 Instant 默认模型联动。
  • 5/15 「A new personal finance experience in ChatGPT」：连接金融账户后，ChatGPT 可结合个人财务上下文做目标规划、消费洞察、情景模拟。 来源：https://openai.com/index/personal-finance-chatgpt/

全球基建 & 合作（5/16）

  • 「OpenAI Codex and Figma launch seamless code-to-design integrations」（5/16）：通过 Figma MCP server 实现 Codex 与 Figma 之间双向流转——既能把 Figma Design/Make/FigJam 上下文喂给 Codex，也能从 Codex 反向生成 Figma 文件。 来源：https://openai.com/index/figma-partnership/，开发者文档：https://developers.openai.com/blog/building-frontend-uis-with-codex-and-figma
  • 「OpenAI and Malta partner to bring ChatGPT Plus to all citizens」（5/16，Global Affairs）：首个把 ChatGPT Plus 全民配发的国家级合作。 来源：https://openai.com/index/malta-chatgpt-plus-partnership/
  • 「Expanding Stargate to Michigan」：在 Saline Township 增建 1GW+ 园区，作为与 Oracle 4.5GW 合作的一部分。 来源：https://openai.com/index/expanding-stargate-to-michigan/

其他

  • 5/12 「Parameter Golf 教会了我们什么」（Research）：超小模型参数效率研究，路线图意义大于直接产品。
  • 5/11 OpenAI 校园网络（Student Club）意向表上线。
  • 5/8 「Running Codex safely inside OpenAI」：内部安全实践公开，配合 Windows 沙箱发布。

上下文回顾（>7 天，仅作背景）

  • GPT-5.5（4-23）/ GPT-5.5 Instant（5-5）：默认模型切换，5.3 Instant 兼容窗口三个月。

Anthropic

本周双线推进：「中小企业 + 公益」与「超大企业」同步签下。

Claude for Small Business（5/13）

  • 推出面向 SMB 的产品线，并联合 Workday 与 LISC（Local Initiatives Support Corporation）启动 Workday Foundation Solopreneurship Accelerator——首批 15 名独立创业者获 Workday 基金会种子资金 + Anthropic 提供的 Claude credits + LISC 设计的 AI-first 创业课程。
  • 来源：https://www.anthropic.com/news/claude-for-small-business

与盖茨基金会 2 亿美金战略合作（5/14）

  • 「Anthropic forms $200 million partnership with the Gates Foundation」。覆盖三大方向：可携带的技能与认证记录、面向再就业人群的可信职业指导、链接培训项目与就业结果数据的影响评估工具。
  • 来源：https://www.anthropic.com/news/gates-foundation-partnership

PwC 全员部署 Claude（5/14）

  • 「PwC is deploying Claude to build technology, execute deals, and reinvent enterprise functions for clients」。
  • PwC 将以 Claude Code + Claude Cowork 为核心，从美国团队铺到全球，建立联合卓越中心，并对 30,000 名 PwC 顾问进行 Claude 认证培训。Dario Amodei 直接背书：「保险核保从 10 周缩短到 10 天，安全工作从小时级压缩到分钟级。」
  • 来源：https://anthropic.com/news/pwc-expanded-partnership

模型现状（背景）

  • 旗舰仍为 Claude Opus 4.7（4-16 发布，5-4 更新 OfficeQA Pro 评测图）。Mythos Preview 系统卡仍未升为正式发布。

Google / DeepMind

Google I/O 2026 定档 5/19-20（在本期窗口的次日），本周以 I/O 前哨预热为主。

Android Show: I/O Edition 2026（5/12）

  • 引入 Gemini Intelligence：Android 上的主动式 AI 体验（proactive 而非问答驱动）。
  • 「Bringing the best of Gemini in Chrome to Android」：Chrome 上的 Gemini 同步登陆 Android，包含 auto browse（agentic 网页浏览体验）。
  • 来源：https://blog.google/products-and-platforms/platforms/android/android-show-io-edition-2026/

模型现状（背景）

  • 旗舰仍为 Gemini 3.1 Pro / 3.1 Ultra；开源端为 Gemma 4（31B / 26B-A4B / E4B / E2B）。本周开发者博客延续 Gemma 4 推理加速、Gemini API File Search 多模态化等议题，未见 Pro/Ultra 级新模型。

Meta AI / Hugging Face

Meta

  • 本周无官方新模型，旗舰仍是 Muse Spark（Meta Superintelligence Labs，4-8 发布）。Llama 4 系列开源生态在下游持续分发，无新版本。

Hugging Face

  • 本周无 HF 官方主导的重大模型发布；社区端继续围绕 Gemma 4 / Qwen3.6 / GLM-5.1 / Kimi K2.6 等的部署与量化做工程化分发。

国内厂商

本周国内最重要的两条官方动态：百度文心 5.1 + 字节火山引擎 Agent Plan。

百度——文心大模型 5.1（5/9）

  • 5/9 百度正式发布文心大模型 5.1，采用「多维弹性预训练」技术，已在百度千帆模型广场、文心一言官网同步上线，面向企业用户与开发者开放体验。
  • 主打降低 AI 训练成本（多维弹性预训练）；定位是 ERNIE 5.0（2026/01 上线，2.4 万亿参数全模态）的迭代版本。
  • 来源（每经/腾讯转载）：https://news.qq.com/rain/a/20260509A05LDK00

字节跳动——火山引擎 Agent Plan（5/11）

  • 5/11 火山引擎官微正式发布 Agent Plan：在 Coding Plan 主力编程模型订阅基础上，新增更多模态模型 + Harness 工具。
  • 模型矩阵覆盖：Doubao-Seed（语言）、Doubao-Seedance（视频生成）、Doubao-Seedream（图像生成）等豆包全家桶，可在同一订阅内做编程、视频生成、语音合成、音乐创作等全模态调用。
  • 是国内”模型超市” + Agent 化订阅的重要落地节点。
  • 来源：https://view.inews.qq.com/a/20260511A06JH300

阿里 / 智谱 / Kimi / DeepSeek / MiniMax / 腾讯（背景）

  • 阿里 Qwen：4/2 Qwen3.6-Plus（编程 Agent 旗舰），4/15-16 ATH 事业群陆续发布 AI 开发工具与开放世界模型 Happy Oyster。本周无新模型，重心在百炼上下架与渠道扩展。
  • 智谱 GLM-5.1：4/8 发布开源，4/18 在 SWE-Bench Pro 刷新国产模型成绩；本周以渠道（腾讯云 TokenHub、火山引擎 Coding Plan 等）继续铺开为主。
  • Kimi K2.5 / K2.6：3 月 ARR 破 1 亿美金后，本周无新模型动作；融资侧月之暗面新一轮 140 亿元已基本敲定，估值约 1400 亿。
  • DeepSeek V4：4/24 Preview 发布（Pro/Flash 双版本，1M 上下文，开源权重，定位华为昇腾 950PR），本周已在腾讯云 / 阿里云上架完毕，价格策略保持「不到 GPT-5 1/10」的激进路线。
  • MiniMax M2.7：3/18 发布，本周通过火山引擎 Agent Plan 等渠道继续扩张。
  • 腾讯云 TokenHub（4-30）：Token Plan 企业版专业套餐已纳入 GLM-5.1 / GLM-5-Turbo / Kimi-K2.6 / MiniMax-M2.7 / DeepSeek-V4-Flash / DeepSeek-V4-Pro。

重点关注

  1. Codex 进入「随处都能写代码」阶段：Windows 沙箱 + 移动端 preview + Figma 双向集成，OpenAI 在把 Codex 从 IDE 内的代码生成工具，推向”任意终端、任意设计/开发上下游环节”的全平台 Agent。Figma MCP server 是这一周最值得拆来看的范本。
  2. Anthropic 的 5/14 双发是”客户结构”信号：盖茨基金会（公益/影响力） + PwC（30 万人级别专业服务） + 5/13 SMB 同时开启，意味着 Claude 的客户金字塔在同步加固——超大企业、政府/公益、中小企业三层一并锁住。本周仍无新模型，资源都压在合作与算力侧（前一周公布的 Google + Broadcom 5 年 2000 亿合作仍是大背景）。
  3. 5/19 Google I/O 是下周窗口的爆点：本周看到的 Android Show + Gemini Intelligence + Chrome on Android 都是预热，Gemini 3.5 / 3.2 是否在 I/O 主舞台官宣是下周报告的核心观察对象。
  4. 国内进入「Agent 订阅」期：火山引擎 Agent Plan 是国内首个把多模态模型 + 工具链打包成 Agent 化订阅的官方产品，叠加百度文心 5.1 上线，4 月的「模型大战」正在过渡到 5 月的「Agent / Plan 大战」。腾讯云 TokenHub 一次性纳入 6 家头部国产模型则代表「中立云做模型超市」的路线。
