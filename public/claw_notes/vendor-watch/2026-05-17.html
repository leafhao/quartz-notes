AI 厂商动态 | 2026-05-17

时间窗口：2026-05-10 → 2026-05-17（最近 7 天）。仅采信官方来源（openai.com / anthropic.com / blog.google / deepmind.google / ai.meta.com / 厂商官方文档）。

一周看点（TL;DR）

  • 进入 5 月，前沿模型节奏放缓，OpenAI 4 月底发完 GPT-5.5 / GPT-5.5 Instant 之后，本周主线转向 Codex 工程化（Windows 沙箱、移动端、远程 SSH/Hooks）和 ChatGPT 产品化（个人理财体验、敏感对话上下文识别）。
  • Anthropic 本周无新模型发布，重点在 算力侧：透露未来 5 年向 Google Cloud 投入约 2000 亿美元用于 TPU/云服务的合作扩展（路透 5/5 报道，本周持续发酵）。
  • Google / DeepMind 本周无大型模型发布，开发者侧 Gemini API File Search 升级为多模态 RAG，并继续推进 Gemma 4 推理加速。
  • 国内厂商本周相对安静，4 月集中发布期已过：DeepSeek V4 (Pro/Flash, 4-24)、Qwen-Image-2.0 Pro (4-22)、腾讯云 TokenHub Token Plan 新增 GLM-5.1 / Kimi-K2.6 / MiniMax-M2.7 / DeepSeek-V4 (4-30) 等已落地，本周以渠道铺开和价格策略调整为主。

OpenAI

本周更新最密集的厂商，全部围绕 Codex 与 ChatGPT 体验。

Codex on Windows（5/13）

  • 官方博客 “Building a safe, effective sandbox to enable Codex on Windows”（Engineering, 2026-05-13）。
  • 给 Windows 平台带来与 macOS 一致的安全沙箱，意味着 Codex CLI 终于在三大桌面平台对齐。
  • 来源：https://openai.com/index/running-codex-safely/

Work with Codex from anywhere（5/14）

  • “Codex in the ChatGPT mobile app is rolling out in preview on iOS and Android across all plans, including Free and Go”。
  • 同时上线 Remote SSH 和 Hooks 全计划开放，Programmatic access tokens 上线。
  • macOS Codex 应用支持手机连接（Windows 端”coming soon”）。
  • 来源：https://openai.com/index/work-with-codex-from-anywhere/

TanStack npm 供应链攻击响应（5/13）

  • “Our response to the TanStack npm supply chain attack”（Company）。
  • OpenAI 公开复盘了对 TanStack 包被劫持事件的内部排查与处置流程，对所有依赖 npm 生态的工程团队都有参考价值。
  • 来源：https://openai.com/news/

ChatGPT 敏感对话上下文识别（5/14）

  • “Helping ChatGPT better recognize context in sensitive conversations”（Safety）。
  • 强化模型在心理健康、危机情境下的上下文理解，与 GPT-5.5 Instant 默认模型结合后落地。
  • 来源：https://openai.com/news/

个人理财体验（5/15）

  • “A new personal finance experience in ChatGPT”（Product, 2026-05-15）。
  • 把 ChatGPT 推向理财助理场景，是 OpenAI 持续推进”专业垂直工作流”路线的一环。
  • 来源：https://openai.com/index/gpt-5-5-instant/（关联条目）

上下文回顾（>7 天，仅作背景）

  • GPT-5.5 (4-23) / GPT-5.5 Instant (5-5)：默认模型切换，三个月内保留 5.3 Instant 兼容窗口。Pro 计划提供 5.5 Pro，Codex 中提供 400K 上下文与 1.5x Fast 模式。

Anthropic

本周无新模型，重头戏在算力与资本侧。

与 Google + Broadcom 的算力扩展协议

  • 官方页 “Anthropic expands partnership with Google and Broadcom for multiple gigawatts of next-generation compute”。
  • 路透 5/5：Anthropic 据信将在未来 5 年向 Google Cloud 与 TPU 投入约 2000 亿美元。Google 本身向 Anthropic 投资额度承诺扩至最高 400 亿美元。
  • 这意味着 Claude 系列后续训练与推理将更深度绑定 TPU + Broadcom 网络栈，而非完全依赖 AWS Trainium。
  • 来源：https://www.anthropic.com/news/google-broadcom-partnership-compute

模型现状（背景）

  • 当前旗舰仍为 Claude Opus 4.7（4-16 发布，5-4 更新了 OfficeQA Pro 评测图）。Sonnet 4.6 / Opus 4.6 / 4.5 仍在线。
  • Mythos Preview 仍未正式发布，本周也未透露时间表。

Google / DeepMind

本周以开发者工具更新为主，无大型模型发布。

Gemini API File Search 升级为多模态 RAG（5/5，本周仍在推广窗口）

  • “Gemini API File Search is now multimodal: build efficient, verifiable RAG”。
  • 文件搜索 API 现支持图像 / 文本混合检索，并提供可验证引用，对企业 RAG 场景较实用。
  • 来源：https://blog.google/innovation-and-ai/models-and-research/gemini-models/next-generation-gemini-deep-research/（同期相关条目）

Gemma 4 推理加速

  • “Accelerating Gemma 4: faster inference with multi-token prediction”——开发者博客近期主推。
  • 多 token 预测 + 同 Gemini 3 同源架构，强调 intelligence-per-parameter；31B 模型在 Arena 开源榜位列全球第 3。

模型现状（背景）

  • 旗舰为 Gemini 3.1 Pro（2 月）/ Gemini 3.1 Ultra（3-20 发布，2M 多模态上下文）。本周无 Ultra/Pro 级别更新。

Meta AI / Hugging Face

Meta

  • 本周无新模型，旗舰仍是 Muse Spark（Meta Superintelligence Labs，4-8 发布）。
  • 同期 Llama 4 系列继续被 Red Hat AI 等下游做量化分发，本周未见新版本。

Hugging Face

  • 5-04 “AI Release Week Thread”（Presidentlin Collection）持续更新，本周收录的开源亮点包括 HuggingFaceTB/nanowhale-100m（小型 0.1B 文本生成）、google/gemma-4-31B-it-assistant 等社区分发。
  • 仅作开源生态参考，非 HF 官方模型发布。

国内厂商

本周相对安静，主要看点在渠道与定价。

腾讯云 TokenHub（4-30，本周仍在生效窗口）

  • Token Plan 企业版专业套餐新增模型：GLM-5.1、GLM-5-Turbo、Kimi-K2.6、MiniMax-M2.7、DeepSeek-V4-Flash、DeepSeek-V4-Pro。
  • 等于把六家头部国产模型一次性塞进腾讯云月度订阅，对国内 toB 多模型路由场景影响明显。
  • 来源：https://cloud.tencent.com/document/product/1823/130675

阿里云百炼模型上下架（4-23 / 4-24，背景）

  • DeepSeek-V4-Pro / V4-Flash 阿里直供。
  • Qwen-Image-2.0-Pro-2026-04-22：图像生成与编辑融合，纹理 / 光影 / 多语言文字渲染显著升级。
  • 这两条已超 7 天窗口，仅作上下文。

其他（背景，>7 天）

  • DeepSeek V4 Preview（4-24，1M 上下文 + Agent 能力 + 开源权重 + 据称首发支持华为昇腾 950PR）。
  • 月之暗面 Kimi K2.5 / K2.6 持续在阿里百炼提供推理服务，本周无新模型动作。
  • 智谱 GLM-5（含 Lite / Mini / Code 系列）、MiniMax M2.x 等已在多家云厂商铺开，本周以渠道动作为主。

重点关注

  1. Codex 全平台一致性：Windows 沙箱 + 移动端 preview + Remote SSH + Hooks，OpenAI 把 Codex 从”代码生成”推向”任意位置完成开发任务”的全平台 Agent。
  2. Anthropic 全面投靠 TPU：5 年 2000 亿美元绑定 Google Cloud + Broadcom 网络，长期看 Claude 训练与推理栈将明显从 Trainium 转向 TPU。这对国内做 Claude 兼容层 / 反代的服务也意味着 Google 侧合规风险将更显性。
  3. 国内进入”消化期”：4 月密集发布之后，5 月主线变成”渠道接入 + 定价调整”。腾讯云 TokenHub 一次性纳入 6 家头部模型，是观察国产多模型 SaaS 路由趋势的好样本。

数据来源（官方）：openai.com, anthropic.com, blog.google, deepmind.google, ai.meta.com, llama.com, help.aliyun.com, cloud.tencent.com。
