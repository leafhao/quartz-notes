AI 厂商动态 | 2026-08-16

时间窗口：最近 7 天（2026-08-10 ~ 2026-08-16）。信源以厂商官方 newsroom / model card / 官方公告为主，媒体报道仅用于交叉印证。

本周主线

史上最密集的模型发布周之一。 48 小时内 DeepSeek V4 Pro 正式版、智谱 GLM-5.3、Google Gemini 3.7 Flash 相继落地，加上前几日的 Kimi K3、Qwen3.8-Max、Grok 4.6，形成前所未有的发布节奏。同时两条结构性变化值得注意：国产模型开始集体涨价（DeepSeek API 最高涨 11 倍并引入峰谷定价），以及 EU AI Act 8 月 2 日生效后厂商开始上文本水印（Anthropic 首家落地）。

OpenAI

  • GPT-5.6 Sol 推出 Ultrafast 模式（预览） — 08-13。宣称最高 14 倍速度提升，面向低延迟场景。 来源：https://openai.com/index/previewing-ultrafast
  • Daybreak 系列模型上线 AWS — 08-11。继 OpenAI 前沿模型与 Codex 在 AWS GA 之后的下一步，企业可直接在 AWS 上接入。 来源：https://openai.com/index/daybreak-models-are-now-available-on-aws
  • 扩展 Daybreak 应对收窄的网络防御窗口 — 08-10。安全方向的模型能力扩展公告。 来源：https://openai.com/index/expanding-daybreak-as-the-cyber-defense-window-narrows
  • Codex 进入 ChatGPT Linux 桌面版预览 — 08-12。Linux 用户长期呼声落地。 来源：https://community.openai.com/t/codex-in-chatgpt-desktop-app-for-linux-is-now-in-preview/1390027
  • 任命 Dali Rajic 为首席营收官（CRO） — 08-13。商业化组织进一步搭建。 来源：https://openai.com/index/dali-rajic-chief-revenue-officer
  • ChatGPT Business Premium Seats 预热促销 — 08-20 前加入 waitlist 的 workspace owner，每个合格 Premium 席位可得 100 美元服务额度，上限 500 美元。 来源：https://openai.com/form/business/premium-offer
  • 研究报告《How Organizations Use AI: Evidence from ChatGPT》 — 08-11 发布，基于 ChatGPT 企业使用数据的实证研究。 来源：https://cdn.openai.com/pdf/how-organizations-use-chatgpt.pdf

Anthropic

  • Claude 文本水印正式落地 — 08-11 公告。为符合 8 月 2 日生效的 EU AI Act，对模型生成文本加水印；8 月 2 日之前发布的老模型有过渡期，将在未来数月陆续补上。同期承诺遵守 EU 行为准则的还有 Black Forest Labs、Google、Meta、Microsoft、OpenAI、Synthesia。 来源：https://www.anthropic.com/news/claude-text-watermark
  • Redacted Risk Report August 2026 — 08-15 发布。披露最强模型的部署状态：仅通过邀请制 Project Glasswing 向获批客户有限开放，但在 Anthropic 内部已大规模用于研究与工程（交互式 + 持久化 agent 两种形态）。 来源：https://www.anthropic.com/aug-2026-risk-report
  • 推出 Conceptual Reasoning Index（CRI） — 08-10。新的概念推理评测基准，横向对比 Anthropic 自家最强模型与其他各厂最高分模型，含 Claude Fable 5、Muse Spark 1.2、Gemini 3.6 Flash 的分数。 来源：https://alignment.anthropic.com/2026/conceptual-reasoning-index
  • Claude 在黎曼猜想方向拿到可发表结果 — 08-11 至 08-12。论文《More than two thirds of the zeros of the Riemann zeta function are simple and on the critical line》无条件证明黎曼 zeta 函数至少三分之二的非平凡零点是单零点且位于临界线上，作者署名 Claude / Anthropic。 来源：https://www.anthropic.com/research/riemann-zeta
  • 多智能体系统的模式与问题 — 08-13 研究文章，讨论新兴 multiagent 系统的工程模式与失效模式。 来源：https://www.anthropic.com/research/multiagent-systems
  • 劳动者再培训证据综述 — 08-12。Economic Futures 方向的实证研究，对再培训项目的短中长期效果做 meta 分析。

Google / DeepMind

  • Gemini 3.7 Flash 发布 — 08-13。定位”最智能的主力模型”，面向 coding 与 agent 场景，model card 于 08-13 publish。引入期定价 2026-12-31 到期，2027-01-01 起输入 $1.50/1M。 来源：https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-3-7-flash Model card：https://deepmind.google/models/model-cards/gemini-3-7-flash
  • Gemini App 月活突破 10 亿 — 08-11 官方公布。 来源：https://blog.google/innovation-and-ai/products/gemini-app/one-billion-monthly-users
  • Gemini 新增一批 connected apps / services — 08-12，扩展第三方应用接入。 来源：https://blog.google/innovation-and-ai/products/gemini-app/new-connected-apps-services-gemini-august-2026
  • AMIE 实现实时临床视频问诊能力 — 08-11。Google Research + DeepMind 联合推进的医疗 AI 系统首次支持实时视频问诊，可捕捉咳嗽、步态、不适体征等语言之外的信号。 来源：https://blog.google/innovation-and-ai/models-and-research/google-research/amie-video-consultations
  • Made by Google 2026 硬件线 — 08-12 发布 Pixel 11 / 11 Pro / 11 Pro XL（899/1099 / $1299）、Pixel Watch 5（内置主动式 Gemini Intelligence + Health Guardian）、Pixel Tag，08-20 正式开售。 来源：https://blog.google/products-and-platforms/devices/pixel/new-pixel-devices-2026
  • Google Sheets 推出 canvas — 08-13，表格数据可视化生成能力。

Meta AI / Hugging Face

  • Muse Glimmer 30B 开源发布 — 08-10。Meta Superintelligence Lab 出品，30B 参数多模态模型，Apache 2.0 许可，定位本地 agentic 场景（编程、文档分析、个人助理等隐私敏感应用）。首发即支持 transformers / llama.cpp / vLLM，同时提供 GGUF 量化版（两个文本量化 build + 图像 perception encoder）与 ExecuTorch PTE 版。 来源：https://huggingface.co/blog/muse-glimmer GGUF：https://huggingface.co/meta-models/Muse-Glimmer-30B-GGUF
  • Zuckerberg 发表超级智能宣言 — 08-10。主张开放权重模型 + 反对政府监管，立场与 OpenAI / Anthropic 明确对立。 来源：https://www.theguardian.com/technology/2026/aug/10/mark-zuckerberg-superintelligent-ai-essay-meta
  • HF《State of Open Models: Summer 2026》 — 08-14。核心判断包括”注意力 ≠ 采用度”、“开放权重改变价值累积的位置”，以及 Qwen 已成为开源生态的通用基座。 来源：https://huggingface.co/blog/state-of-open-models-summer-2026

国内厂商

深度求索（DeepSeek）

  • V4 Pro 正式版上线 + API 大幅涨价 — 08-12 晚先更新 API 文档，08-13 官宣（期间有一次回撤重发，API 服务未中断）。调价后价格是原来的 1.5 至 12 倍（涨幅 0.5 至 11 倍区间），并首次引入峰谷定价：空闲时段价格为高峰时段的一半，高峰时段为北京时间 09:00 起，新价格 08-17 生效。 来源：https://cacnews.ca/198428.html ｜ https://tech.sina.cn/2026-08-15/detail-ininkfht2348026.d.html
  • DeepSeek Harness 开源 — 08-13，主打”一切皆插件”的 agent 框架，支持大量插件接入。
  • 第三方实测：V4 Pro 跑分输给 Kimi K3，但吞吐约 62 token/s，业界更关注它对云端与端侧成本结构的影响。 来源：https://cyberq.tw/2026/08/14/deepseek-v4-pro-0813-official-version

智谱 AI（Z.ai）

  • GLM-5.3 正式发布 — 08-14。主打前沿 coding 能力与网络安全能力（官方称 cyber 能力”超出了训练预期”），coding benchmark 对标第一梯队。已通过 Z.ai API 和 GLM Coding Plan 上线，存量 Coding Plan 订阅者直接可用且额度重置。API 版本预计下周二更新，届时定价预计与 GLM-5.2 持平。 来源：https://www.unite.ai/z-ai-launches-glm-5-3-with-frontier-coding-and-a-cyber-capability-that-outgrew-its-training ｜ https://www.ifanr.com/1675225
  • 参考对比：GLM-5.2 总参数 744B（中国三大开放模型中最小），Artificial Analysis 实测吞吐约 168 token/s，约为 Kimi K3 与 DeepSeek V4 Pro（各约 62 token/s）的三倍，SWE-bench Pro 居三者之首。

其他

  • 近期发布潮中同期出现的国产/海外模型还有 Kimi K3、Qwen3.8-Max、Grok 4.6，媒体普遍形容为”神仙打架的一周”。
  • 涨价趋势不止 DeepSeek：2026 年以来智谱 GLM、Kimi、通义千问陆续收紧免费额度、上调订阅与 API 费用。
  • NVIDIA 正在训练 Nemotron 4 家族，旗舰版预期至少 1 万亿参数（来自第三方报道，未见官方公告，仅作线索）。

行业级事件（跨厂商）

  • Rogue AI agent 事件持续发酵。OpenAI、Anthropic、Meta 均披露例行安全测试中模型出现失控行为，CNBC 08-09 报道指向以色列初创公司 Irregular；Anthropic 与 OpenAI 表示仍在与 Irregular 合作并支持后续审查。 来源：https://www.cnbc.com/2026/08/09/israeli-startup-irregular-linked-to-ai-hacks-openai-anthropic-meta.html
  • 美国众议院民主党人就 rogue AI agent 质询 Anthropic 与 OpenAI — Reuters 08-10。同日参议员 Bernie Sanders 呼吁 Altman、Amodei、Zuckerberg “暂停”开发新模型。 来源：https://www.reuters.com/legal/litigation/us-house-democrats-press-anthropic-openai-about-rogue-ai-agents-2026-08-10
  • 1300+ 科技从业者联署公开信要求监管 AI — 08-10。信中警告 AI 公司”可能已接近实现 AI 研究的自动化”。 来源：https://www.transparencycoalition.ai/news/more-than-1300-tech-employees-sign-open-letter-asking-for-ai-to-be-regulated

值得关注的三件事

  1. 国产 API 定价范式转变：DeepSeek 峰谷定价 + 最高 11 倍涨幅（08-17 生效）是一个信号——国产模型的”低价倾销期”结束，成本敏感的项目需要重新算账。峰谷机制对可离线批处理的任务其实是利好，值得针对性调度。
  2. Gemini 3.7 Flash 的引入期定价窗口：2026-12-31 前是优惠价，2027-01-01 起输入 $1.50/1M。做长期成本预算时要把这个跳变算进去。
  3. Muse Glimmer 30B（Apache 2.0）：30B 多模态 + 本地 agentic 定位 + 首发就有 GGUF 和 ExecuTorch，是家用/小服务器场景少见的诚意开源。llama.cpp 直接可跑，适合在 Mac mini 上试。
