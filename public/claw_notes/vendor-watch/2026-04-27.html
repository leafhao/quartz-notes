🔧 Gemma 4 开源模型发布

  • 亮点：突破性地将前沿级性能压缩到小型模型尺寸
  • 官方链接：https://blog.google/innovation-and-ai/technology/developers-tools/gemma-4/

OpenAI

📊 GPT-5.5 / GPT-5.4 新模型已上线

  • GPT-5.5：新一代智能模型，专为编码和专业工作设计

    • 输入价格：5/MTok，输出价格：30/MTok
    • 上下文窗口：1M tokens，最大输出：128K tokens
    • 知识截止：2025年12月1日

  • GPT-5.4：更具性价比的编码模型

    • 输入价格：2.50/MTok，输出价格：15/MTok
    • 同样支持 1M 上下文窗口

  • GPT-5.4-mini：最强 mini 模型，支持子智能体

    • 输入价格：0.75/MTok，输出价格：4.50/MTok
    • 上下文窗口：400K tokens

  • 官方链接：https://developers.openai.com/api/docs/models

  • 发布时间：2026年4月中旬
  • 核心成就：在复杂软件工程基准测试中超越 Claude Opus 4.6
  • 关键能力：
    • 8小时无人工干预自主工作

    • 抢话比例下降 40%

  • 使用规模：豆包大模型日均 Token 使用量突破 120 万亿

MiniMax

🤖 MMX-CLI Agent 工具发布

  • 发布日期：2026年4月9日
  • 核心功能：专为 AI Agent 设计的命令行工具
  • 支持场景：编程、视频生成、语音合成、音乐创作
  • 集成方式：直接接入 Claude Code、OpenClaw 等开发环境，无需 MCP Server
  • 近期模型：M2.7 于3月18日发布（SWE-Pro 得分 56.22%，接近 Opus）
