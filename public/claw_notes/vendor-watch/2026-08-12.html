AI 厂商动态 | 2026-08-12

时间窗口：2026-08-05 ~ 2026-08-12。仅收录窗口内有官方/一线媒体支撑的条目，窗口外旧闻已剔除。 本期主线：Meta 高调重返开源（Muse Glimmer 30B + Muse Code 低价狙击）、OpenAI Daybreak 网安模型上 AWS、Gemini 破 10 亿 MAU、国产模型价格战把全球推理均价打到年内低点。

一、本期最值得关注

1. Meta 开源战略回归：Muse Glimmer 30B（08-10）+ Muse Code（08-05）

Meta 本期是唯一”双发布”的厂商，且两条都直指竞争对手软肋。

Muse Glimmer 30B（08-10 发布）

  • Meta Superintelligence Lab 出品，300 亿参数因果语言模型，Apache 2.0 许可
  • 定位明确：端侧 agentic——多步推理 + 可靠工具调用 + 多模态理解 + 失败恢复，本地跑，不需要云和网络
  • 由旗舰 Muse 蒸馏而来；同步放出 GGUF 与 ExecuTorch PTE 两套部署产物，社区当天就出了 unsloth / MLX / ROCm FP4 量化版
  • 基准披露（模型卡）：ScreenSpot Pro 75.4-76.1、OmniDocBench v1.5 75.8-77.8、MMMU Pro 74-75
  • 来源：HF 模型卡 · HF 官方博客 · Reuters

Muse Code（08-05 发布，beta）

  • Meta 第一个终端编码 agent，底层是 Muse Spark 1.2
  • 定价 $1.25 / 百万输入 token，明确低于 Anthropic 与 OpenAI 同档产品；另有 pay-as-you-go 档
  • 争议点：有”contributor pricing”（数据贡献换低价）档位，媒体质疑数据使用边界
  • 来源：CNBC

战略信号：Zuckerberg 同期公开呼吁美国放宽 open-weight 模型监管，明确把”对标中国开源势力”作为理由。这是 Meta 从 Muse Spark 闭源路线的一次公开转向，Reuters / aibusiness 均以”reverses course”定调。

2. OpenAI：Daybreak 网络安全模型登陆 AWS（08-11）

  • Daybreak Red / Daybreak Blue 现已可通过 Amazon Bedrock 控制台或 Responses API 的 bedrock-mantle 端点调用
  • 需要先获批 Daybreak Access 准入，不是公开开放
  • 配套动作：08-05「Putting frontier cyber models in more trusted hands」扩大 Daybreak Cyber Partner Program；08-10「Expanding Daybreak as the Cyber Defense Window Narrows」阐述防御窗口收窄的判断
  • 来源：OpenAI 官方 · Daybreak 扩展说明

其他 OpenAI 窗口内动态

  • ChatGPT Business Premium 座位（08-10 官宣即将上线）：5 倍用量、取消 5 小时用量墙、同一 workspace 可混配座位类型；08-20 前加入 waitlist 的 workspace owner 有 $100 服务额度激励
  • Codex 桌面端 Linux 版进入 preview（08-11，社区公告）
  • Codex 付费计划限额 08-09 重置，随后周一再次重置
  • 官方案例文章两篇：HSP GRUPPE 税务咨询（08-10）、AI-native 财务职能（08-06）；与美国心理学会（APA）就青少年心理健康与 AI 达成合作（08-06）

4. Anthropic：Claude 攻黎曼猜想 + Fable 5 生物安全护栏

二、跨厂商观察

1. 开源/开放权重成为主战场，且是中美同构的竞争 Meta 用 Muse Glimmer 明确回到开源，理由是对标中国开源势力；中国厂商用开源权重压价获取份额；Google 把 Gemma 9 亿下载和 WeatherNext 2 开源当作势能证明。三方逻辑不同但动作一致——开放权重从”理想主义”变成了标准竞争工具。

2. 价格战已经进入可量化阶段 不再是”某家降价”的单点新闻，而是有第三方指数（Silicon Data）给出全市场推理均价 1.16−1.18/年内低点。MetaMuseCode的1.25/百万输入 token 明确以”低于 Anthropic 和 OpenAI”为卖点。成本曲线下移会把竞争压力从模型能力转移到工程壁垒和场景落地。

3. 端侧 agentic 是新的差异化方向 Muse Glimmer 30B 的定位（本地跑、无需联网、工具调用 + 失败恢复）说明大厂开始认真做”能在笔记本上自主干活的模型”。这条路线和云端旗舰模型不是替代关系，而是新增战场。

4. 网络安全模型走向受控分发 OpenAI 的 Daybreak 系列上 AWS 但保留 Daybreak Access 准入门槛，Google 也提到”Cyber 模型已上线”。前沿网安能力正在形成”能力开放 + 客户白名单”的分发范式，与通用模型的开放策略明显分叉。

5. 模型能力叙事从基准转向可验证科学产出 Anthropic 的黎曼猜想研究、Google 的 WeatherNext 2 Nature 论文，两家本期都不靠跑分而是拿”审稿过的科学结果”说话。这比基准分数更难反驳，也更难复现。

三、本期空窗提示

  • Anthropic：无新模型、无定价调整，仅研究 + 安全公告
  • 国产厂商官方渠道：中文查询噪音极重（房产 SEO 页面大量堆砌”@DeepSeek @通义千问”等标签抢 AI 抓取流量），本期国内条目主要靠英文财经媒体 + 中关村在线/36氪/SegmentFault 交叉印证，缺少厂商官方中文公告的一手来源
  • GPT-5.6 Luna 大幅降价的说法出现在第三方技术博客，未找到 OpenAI 官方定价页支撑，本期不采纳
