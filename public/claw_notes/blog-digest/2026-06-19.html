2. Beyond LoRA: Can you beat the most popular fine-tuning technique?

  • 来源博客: Hugging Face Blog
  • 链接: https://huggingface.co/blog/peft-beyond-lora
  • 发布: 2026-06-18

HF PEFT 团队抽样 20,834 个标注 PEFT 的模型卡，发现 LoRA 占比 98.4%，几乎吞掉整个生态——但他们认为这种垄断不健康。文章系统对比了 LoRA 之外的多种 PEFT 方法（包括针对量化模型、checkpoint 体积、抗灾难性遗忘的不同维度），并给出在 PEFT 库里直接切换的 API 思路，鼓励基于具体任务做更理性的选择，而非默认 LoRA。

3. Is it agentic enough? Benchmarking open models on your own tooling

  • 来源博客: Hugging Face Blog
  • 链接: https://huggingface.co/blog/is-it-agentic-enough
  • 发布: 2026-06-18

HF 把 transformers 当作 case study，做了一套面向 agent 的基准：不只看最终答案是否正确，还测量”过程成本”——agent 走了多少步、消耗多少 token、在哪些 API 上卡住。和此前 hf CLI 的”agent 优化”工作呼应（token 用量减 1.3-1.8x，最高 6x），他们把同样思路引入 transformers，提出一个简单原则——库要让 agent 能用：API 清晰、文档可发现、有 CLI 与 Skill。这是 library design 在 agent 时代的新评价维度。

4. MosaicLeaks: Can your research agent keep a secret?

  • 来源博客: Hugging Face Blog (ServiceNow)
  • 链接: https://huggingface.co/blog/ServiceNow/mosaicleaks
  • 发布: 2026-06-18

ServiceNow 提出 deep-research agent 的隐私新攻击面：agent 把私有文档与外部 web 检索结合时，对手仅凭外部查询日志就能拼出私密信息（“mosaic effect”）。他们把泄露分为 intent / answer / full-information 三档，并提出 PA-DR (Privacy-Aware Deep Research) RL 训练方法，把严格链路成功率从 48.7% 提到 58.7%，同时把答案/全量泄露从 34.0% 压到 9.9%。给企业部署 deep research agent 提供了可量化的安全工程视角。

  • 来源博客: JVM Weekly (Hacker News >=150)
  • 链接: https://www.jvm-weekly.com/p/project-valhalla-explained-how-a
  • 发布: 2026-06-19

6 月 15 日 Oracle 确认 JEP 401（Value Classes and Objects）合入 OpenJDK 主干，目标 JDK 28——单 PR 1,816 文件、19.7 万行代码，大到主仓暂停其他大改动。这是 Valhalla 自 2014 起十年工作的”第一部分”，仍以 preview 默认关闭交付。文章从 Java “万物皆引用” 的根源讲起，把指针间接、对象头开销与 “codes like a class, works like an int” 的目标串成一条主线，是入门理解 value type 演进的最佳长读。

6. Zero-Touch OAuth for MCP (Enterprise-Managed Authorization)

  • 来源博客: Model Context Protocol Blog (Hacker News >=150)
  • 链接: https://blog.modelcontextprotocol.io/posts/enterprise-managed-auth/
  • 发布: 2026-06-18

MCP 推出 Enterprise-Managed Authorization (EMA) 扩展并稳定化，Anthropic、Microsoft、Okta 已采用。痛点：标准 MCP 授权是 user-scoped，每名员工都要逐个 server 同意一遍，安全团队没法统一审计，工作和私人账号还会混。EMA 把组织 IdP 设为权威决策方，登录时通过 ID-JAG（Identity Assertion JWT Authorization Grant）一次拿到所有 server 的访问 token，没有 per-server 同意页。MCP 走向企业级的关键拼图。

8. 何恺明组新作 MiniT2I：258M 参数文生图，去掉 VAE 与 AdaLN

  • 来源博客: 量子位
  • 链接: https://www.qbitai.com/2026/06/436518.html
  • 发布: 2026-06-18

何恺明带 5 位本科生发新论文 MiniT2I，把去年的 JiT 思路扩到文生图：直接在像素空间做扩散预测干净图像（x-prediction），删掉 VAE 与 MM-DiT 的 AdaLN 机制。结果单次前向 GFLOPs 从 1379 降到 265（降约 80%），仅 258M 参数，FID 从 18.7 → 13.7，B/16 版 GenEval 0.87 / DPG-Bench 84.2，训练只用 8 张 H100 跑 3 天。一次极简主义对工业级 SD3/FLUX.1-dev 的有力回应。

  • 链接: https://www.qbitai.com/2026/06/436813.html
