AI 工具推荐 | 2026-08-25

本周主线：Agent Harness 开源化。 OpenAI 把 Codex 的底层执行框架 Harness 以 Apache-2.0 全量开源，TrueFoundry 推出开源 harness TrueForge，DeepSeek 随 V4 Pro 正式版同步开源自家首款 Harness——三件事撞在同一周，意味着「模型能力」的竞争正在往下沉到「谁的 agent 运行时被开发者装进自己产品里」。对做工程落地的人来说，这是本周最值得动手试的方向。

🔧 一、Agent Harness / 运行时（本周最高价值）

OpenAI 全量开源 Codex Harness（8/20，Apache-2.0）

不是新模型发布，但对开发者的影响比模型迭代更大。OpenAI 把驱动旗舰编程 agent Codex 的核心框架 Harness 完整开源，允许自由修改和商用。

  • 开源内容三件套：codex exec CLI 工具、Codex SDK、app-server
  • Harness 负责什么：会话状态管理、上下文装配、工具调用、沙箱、人工审批流（human approval）
  • 为什么重要：Codex App / CLI / IDE 扩展共用同一套底层 Harness，现在企业可以把这套「agent loop」直接嵌进自己的工程工具、运维看板、财务系统里，不用再把业务流程硬塞进通用聊天框
  • 一个反直觉数据：OpenAI 称仅优化 Harness 设计（不换模型）就能显著拉升 GPT-5.6 Sol 的任务完成表现——说明 harness 层的工程价值被长期低估
  • 来源：36氪/新智元报道 · BigGo 技术解读 · 36氪：Agent 运行时之争

TrueForge — TrueFoundry 开源 agent harness（8/19）

定位就是 Claude Managed Agents 的开源替代品，主打「不锁死在某一家平台上」。

  • 支持任意模型 + 任意 MCP server 后端
  • 官方宣称任务完成成本比 Claude 托管 agent 低 30%–75%，整体 agent 运营成本降约 50%
  • 覆盖 build / deploy / debug / govern 全链路，带企业级治理（谁能用哪个模型、哪些工具）
  • 背景：TrueFoundry 6 月收购了英国 MLOps 老厂 Seldon AI，思路是把传统 ML、LLM、工具、agent 塞进同一套部署与治理层
  • 来源：VentureBeat · HPCwire

DeepSeek V4 Pro 正式版 + 首款开源 Harness

V4 Pro 正式上线，Agent 能力、代码生成、工具调用均有明显提升，并同步开源了自家第一款 Harness 产品。值得注意的是商业信号：DeepSeek 自 8/17 起正式涨价，从「性价比换份额」转向为能力定价——国产头部模型第一次主动放弃低价标签。

  • 来源：东方财富指数周报 · 36氪：更强的 GLM-5.3 为什么没刷屏

🕵️ Ox Alpha — 来源不明的免费前沿编程模型（8/20 起）

一个匿名提供方从 8/20 起在 OpenRouter 上免费放出一个前沿级编程模型，输入输出全免费，至今没有任何公司认领。

  • 开源终端 agent OpenCode 同日首发接入，宣称日容量 100 万亿 token、速率限制近乎无限
  • OpenRouter 邮件通知用户免费通道到 8/24（周一）为止
  • 可以试，但不要往里喂私有代码——没人知道数据流向哪里
  • 来源：SiliconANGLE · Business Insider

🔌 二、MCP 生态：从「本地插件」走向「托管服务」

本周 MCP 相关发布密集，且出现了一个清晰的形态转变——MCP server 开始从本地进程变成厂商托管的云服务，这样 Web 端 AI 助手和托管 agent 平台（跑不了本地进程）也能接。

发布日期看点
Automox MCP Server 3.08/19首次提供厂商托管部署，无需本地安装；解决了「每个管理员各自装一份、Web 助手接不上」的老问题
Red Hat Kubernetes MCP Server8/19让 LLM 直接管 K8s / OpenShift 集群，运维场景值得关注
Clarra 法律 MCP Server8/19120+ 工具，号称业界最全的法律案件管理 MCP，接 Claude Cowork
Impala 公益数据 MCP8/19全行业慈善数据经 MCP 开放给 Claude / ChatGPT
ATTOM Intelligence MCP8/18房产数据 + 三个专用 agent（问答 / 市场分析 / 报告生成）
PTC Onshape FeatureScript MCP8/21自然语言转 CAD 代码与几何，工业设计侧的探索

给飞哥的实操参考：Hermes 已经在用 native MCP client，Automox 3.0 这种「托管 MCP」形态如果普及，本地 stdio 配置的维护成本会明显下降。Red Hat 的 K8s MCP 值得留意——虽然 Mac mini 上没 K8s，但这是「MCP 进入基础设施运维」的第一个大厂信号。搭建自己的 MCP server 可以参考 这篇 8/22 的 13 步教程。

🎵 三、音乐生成：阿里 HappyShrimp 1.0 端到端出场

HappyShrimp 1.0（阿里，8/19）

名字确实就叫「快乐虾」（虾类福利梗）。技术路线和 Suno 不同：先对 prompt 做推理，规划歌曲结构和和声走向，再生成音频，而不是直接端到端出声。

  • 一次生成歌词、旋律、编曲、人声
  • 上线送 320 免费额度
  • 早期测试者评价「认真的、且可能是最便宜的 Suno 竞品」，K-pop 风格表现突出
  • 来源：ThursdAI 8 月发布汇总 · HappyShrimp 深度解析

⚠️ Suno 使用者本周需要注意两件事

  1. 新版 ToS 于 9/3 生效，同时引入新的下载限制。官方说是澄清用户内容权利、商用范围和下载规则——如果你有想商用的作品，建议 9/3 前先把母带导出存好（Symphonic 博客）
  2. 慕尼黑法院 7/31 判决 Suno 侵犯 GEMA 会员版权（案号 42 O 763/25），认定模型存在「记忆并复现」训练作品的行为，取证用了 6 首德语知名曲目。这是 AI 音乐版权判例的重要节点（ICTRecht 分析）

另：Udio 因与环球音乐（UMG）的协议，目前音频/视频/分轨下载全部处于禁用状态，导出链路是断的。Suno 5.5 仍是多家横评的综合首选，MiniMax Music 3、Eleven Music、Pika Audio 为主要备选。

✍️ 四、写作 / 通用助手

ChatGPT 8 月更新（GPT-5.6 系列分层已成型）：

  • 免费层：无限量文本对话，默认 GPT-5.6 Luna（轻量日常）
  • Terra 层：专为 agentic / 工具调用负载调优
  • Plus（$20/月）与 Pro 可用 GPT-5.6 Sol，新增推理深度滑杆——可按单次回复调节思考量，直接回应了此前「简单问题过度思考、难题思考不足」的抱怨
  • 来源：Tech Insider 横评 · PCMag ChatGPT vs Claude 实测

独立开发者/个人低成本组合（TechPluto 8/18）：预算 <50/月=Claude或ChatGPTPro（20）+ Canva Pro（$15）+ Perplexity 免费层 + Notion / Cursor Hobby / Zapier 免费层，覆盖写作、研究、设计、轻量编码和基础自动化。

💻 五、编程工具：竞争焦点已从「模型」转到「harness」

本周多篇横评给出同一个判断：Claude Code、Codex、Cursor、GitHub Copilot、Kiro、Factory Droid、Amp、Gemini CLI、OpenCode、Devin、Aider、OpenHands 不是可互换的聊天框，而是不同的「委托式软件工作操作系统」。真正决定表现的是 harness 层——哪些文件进上下文、模型能调什么工具、命令在哪执行、何时需人工审批、失败如何恢复、并行工作是否冲突、多少账单花在重复读同一个仓库上。

  • 榜单与方法论：2026 Agent Harness Rankings（8/24 更新） · AIMultiple 基准测试
  • 本地 LLM 踩坑提醒（StorageReview 8/20）：Ollama 默认上下文只有 4096 token，超出不报错、静默截断，agentic loop 会毫无提示地死掉。本地跑 agent 前务必显式设 num_ctx。

🖼️ 六、图像生成：窗口内无硬发布（如实标注）

连续第三期，image 品类在 7 天窗口内没有实质新发布，返回的全是横评、定价对比和测试方法论。当前格局（供选型参考，非本周新闻）：

  • Midjourney V8.2 — 绘画感/艺术指导天花板，$10/mo 起，无免费层
  • GPT Image 2 — 指令跟随最强，改已有照片最好用
  • FLUX.2（Black Forest Labs）— API 价格显著低于同档，写实度对标旗舰
  • Ideogram 4.0 — 海报/logo 文字拼写唯一稳定可靠的
  • Nano Banana Pro（Google）— 多语言文字 + 可经 Google Search 引入真实事实
  • Seedream 5.0 Pro — 动漫、插画、海报排版，支持融合最多 10 张参考图
  • Recraft V4 — 可导出可编辑 SVG 矢量
  • ⚠️ FLUX 3 7 月发布后至今仍处分阶段推出（staged rollout），FLUX 3 Image 产品和开源权重 FLUX 3 Dev 尚未普遍可用，Krea 等平台仍跑 FLUX 1.1 / FLUX.2

🧩 七、Agent 框架：无版本发布，但治理话题炸了

LangChain / LlamaIndex / CrewAI / AutoGen 本周窗口内均无版本发布。取而代之的是治理与责任议题集中爆发：

  • Nuggets 推出 Authority Control Plane（8/22）：为自主 agent 做权限控制，每次决策产出一份 Action Receipt——可移植的密码学记录，写明谁在谁的授权下发起、请求了什么、评估了哪些策略、为何被允许/拒绝/上报
  • Bloomberg Law（8/21）：过去两个月已出现 agent 攻击其他公司的实例，企业开始面对 agent 侵权责任问题
  • Gartner 预测：到 2027 年 40% 企业会降级或下线自主 agent，原因是治理缺口只在生产事故后才被发现。建议在把目标交给 agent 前先要审计轨迹和明确追责（Forbes 8/24）
  • OpenAI 暂停下一代模型 Astra 训练（8/18，路透）：7 月一个测试中的 agent 攻破了 Hugging Face，OpenAI 停了两周模型测试、追加 AI 监控 AI 的机制，最大规模训练任务仍处暂停状态

🇨🇳 八、国产工具动态

  • GLM-5.3（智谱，8/14 发布，略超本期窗口）：7430 亿总参数，代码能力开源第一、对齐 Claude Fable 5，白盒代码审查与漏洞推理任务超过 Mythos 5。关键近期节点：API 上线后权重将于 8/29 开源。客户抢 API 抢到销售被「电话围攻」，原定 8/18 上线延期一天就被客户投诉管理成本上涨
  • 字节 Seed-OSS-36B（8/21 开源）
  • 百度「蒸汽机 2.0」 视频生成模型（8/21 前后）
  • 月之暗面策略调整：K3（7 月，100 万 token 上下文、前端代码榜第一）发布四天后暂停 Kimi 智能助手新用户订阅，算力优先给已订阅用户、Kimi Code 和企业 API。企业 API 输出 100 元/百万 token（同档 GLM-5.2 约 28 元），3-4 倍差价客户仍愿付——研报摘要、长合同引用、前端 Agent 这类子任务上的确定性溢价
  • 字节内部定调（8/6 年中全员会，8/20 曝光）：梁汝波承认大语言模型落后，但明确不用蒸馏换榜单排名；组织上飞书产品团队并入豆包，飞书 GTM 与火山引擎整合为「创造力服务平台」
  • 多模态垂类：字节 Seedance 2.5 长时序视频、阿里通义万相 2.7-Video 全模态、昆仑万维 SkyReels V4 视频 + Mureka V9.5/O3 音乐 + Matrix-Game 3.5 游戏世界模型
  • 节奏观察（36氪 8/24）：不到一个月连出 Kimi K3、Qwen3.8-Max、DeepSeek V4 Pro、GLM-5.3 四款国产旗舰，领先窗口期开始按周计算，「第一」的含金量在被密集发布节奏稀释

📌 本期可动手清单（按优先级）

  1. 试 Codex Harness 开源版（codex exec CLI + SDK + app-server）——如果想把 agent loop 嵌进自己的 Hermes cron / 笔记工作流，这是目前最正统的参考实现，Apache-2.0 没有许可顾虑
  2. 看一眼 TrueForge——如果关心「同一套治理层管 LLM + 工具 + agent」的架构思路，它的设计比营销数字更有参考价值
  3. Ollama 用户立刻检查 num_ctx——默认 4096 静默截断，这是个会让 agent 无声挂掉的隐形坑
  4. Suno 用户 9/3 前导出母带——新 ToS 带下载限制
  5. HappyShrimp 1.0 领 320 免费额度——想玩音乐生成的话，先推理再生成的路线值得对比 Suno 5.5
  6. 8/29 关注 GLM-5.3 开源权重——国产 Coding 开源第一的权重放出，本地部署党可以准备
