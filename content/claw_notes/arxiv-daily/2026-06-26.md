### 1. [Quantization Inflates Reasoning: Token Inflation as a Hidden Cost of Low-Bit Reasoning Models](https://arxiv.org/abs/2606.25519)

**arXiv ID**: 2606.25519 | **发布时间**: 2026-06-26  
**方向**: cs.AI — 量化推理、测试时计算  
**摘要**: 量化被广泛用于降低大语言模型的推理成本，但其对推理模型的影响远不止最终准确率或每 token 延迟。研究发现，低比特后训练量化会引入隐藏的测试时计算成本——量化后的推理模型会产生显著的 token 膨胀现象，即生成更多的推理 token 来补偿精度损失，这一隐性代价在现有评估中被忽略。

**摘要**: 基于人类反馈的强化学习（RLHF）依赖奖励模型来对齐大语言模型与人类偏好，但常受到奖励黑客攻击的影响——策略学习利用训练好的奖励模型中的缺陷来最大化奖励分数而非真正对齐。本文提出偏差拟合方法来缓解奖励模型的长度偏差问题，减少奖励黑客现象。

### 4. [TRUSTMEM: Learning Trustworthy Memory Consolidation for LLM Agents with Long-Term Memory](https://arxiv.org/abs/2606.25161)

**摘要**: 大语言模型 Agent 依赖长期记忆来支持有限上下文窗口之外的扩展交互和个性化辅助。现有记忆 Agent 通过生成式写入、修改和删除操作主动更新外部记忆，但这些更新可能遗漏重要信息。TRUSTMEM 提出了一种可信赖的记忆整合学习方法，有效解决了记忆更新中的信息丢失问题。
