### 1. How Do AI Agents Spend Your Money? Analyzing and Predicting Token Consumption in Agentic Coding Tasks

**作者**: Longju Bai, Zhemin Huang, Xingyao Wang, Jiao Sun, Rada Mihalcea, Erik Brynjolfsson, Alex Pentland, Jiaxin Pei

**链接**: [arXiv:2604.22750](http://arxiv.org/abs/2604.22750v1) | [PDF](https://arxiv.org/pdf/2604.22750v1)

**摘要**: 本研究首次系统性地分析了 Agent 编码任务中的 token 消耗模式。研究发现：(1) Agent 任务消耗的 token 是普通代码推理的 1000 倍，且主要由输入 token 驱动；(2) token 使用高度随机，同一任务可能相差 30 倍，高 token 使用并不保证高准确率；(3) 不同模型 token 效率差异显著，Kimi-K2 和 Claude-Sonnet-4.5 比 GPT-5 多消耗超过 150 万 token；(4) 专家评估的任务难度与实际 token 成本相关性弱；(5) 前沿模型无法准确预测自身 token 使用量。

### 2. Representational Harms in LLM-Generated Narratives Against Global Majority Nationalities

**作者**: Ilana Nguyen, Harini Suresh, Thema Monroe-White, Evan Shieh

**链接**: [arXiv:2604.22749](http://arxiv.org/abs/2604.22749v1) | [PDF](https://arxiv.org/pdf/2604.22749v1)

**摘要**: 研究广泛采用的 LLM 在开放性叙事生成中如何刻画不同国籍身份。发现存在针对全球多数群体（Global Majority）的持续性表征伤害，包括有害刻板印象、抹除和单一化描绘。边缘化国籍身份在权力中立故事中被低代表性，在从属角色中被过度代表性，比例超过 50 倍。当提示中存在美国国籍线索时，伤害程度会进一步放大。

### 10. Can QPP Choose the Right Query Variant? Evaluating Query Variant Selection for RAG Pipelines

**作者**: Negar Arabzadeh, Andrew Drozdov, Michael Bendersky, Matei Zaharia

**链接**: [arXiv:2604.22661](http://arxiv.org/abs/2604.22661v1) | [PDF](https://arxiv.org/pdf/2604.22661v1)

**摘要**: 研究查询性能预测（QPP）作为查询变体选择机制的可行性。发现检索和生成目标之间存在系统性分歧：最大化 nDCG 的变体往往无法产生最佳生成答案。轻量级预检索预测器经常匹配或超越更昂贵的后检索方法，为稳健 RAG 提供了延迟高效的方案。
