### 📄 [The Teacher Is a Direction, Not a Destination: Extrapolating RL-Induced Representation Residuals in On-Policy Distillation](https://arxiv.org/abs/2609.36484)
- **作者**：Hao Li et al.
- **关键词**：on-policy distillation, representation residual, RL extrapolation, training stability
- **摘要**：OPD 让学生在自己的轨迹上对齐教师的 next-token 分布，其泛化变体可通过在输出空间外推隐式奖励让学生超越教师。但语言模型头会各向异性地衰减这种变化——教师隐状态中编码的变化只有很小一部分权重能到达 logits；而输出空间外推依赖的采样 token log-prob 比值会注入噪声并被外推放大，导致训练不稳。作者观察到 RL 真正改变的是模型内部表征，据此改为在**表示残差空间**做外推（「教师是一个方向，不是终点」），比输出空间外推更稳、更强。

### 📄 [Semifactual Credit-Augmented Policy Optimization](https://arxiv.org/abs/2609.40360)
- **作者**：Junshu Pan et al.
- **提交日期**：2026-09-30
- **摘要**：RLVR 提升了 LLM 的推理能力，但其预测仍对任务无关的提示特征敏感。作者用**保持问题与答案不变的半事实提示干预**测敏感度，发现 token 级敏感度差异巨大，且在解码时抑制高漂移 token 候选就能在不更新权重的前提下提升推理准确率。这说明 GRPO 给每个响应 token 相同的、由结果导出的优势，会连同潜在虚假依赖一起被强化。据此提出 SCAPO：把半事实稳定性纳入 token 级信用分配，对相对不稳的 token 削减优势（但稳定性本身不给额外奖励）。Qwen3-4B-Base 与 Qwen3-1.7B-Base 上 AIME 2024–2026 比 GRPO 高 **5.63 / 4.17 个百分点**，并在多数数学基准与全部 OOD 基准上最优。
- **方向标签**：#后训练 / #信用分配

### 📄 [Advancing Entropy-Level Credit Assignment in RLVR via Proximal Entropy Policy Optimization](https://arxiv.org/abs/2609.39402)
- **作者**：Yun Kim, Nojun Kwak
- **提交日期**：2026-09-30
- **摘要**：GRPO 这类无价值模型的 RLVR 方法给 rollout 内所有 token 分配相同优势，忽略了 token 贡献的不均等；近期用 token 熵作重要性代理的方法又在整个 batch 上全局计算，把重要性与**提示难度、位置趋势**混为一谈。作者主张重要性应相对每个 token 的局部上下文来衡量，提出**近邻熵**（proximal entropy）并证明它对上述两类混杂不变量。PEPO 用它加权 per-token 优势，在 Qwen3-1.7B、Qwen3-4B、Llama-3.2-3B-Instruct 的数学推理上超过 GRPO 与熵基线；该形式还可代入其他算法获益，用于单流 RL 时也成功，而全局熵则失效。
- **方向标签**：#后训练 / #信用分配 / #GRPO

### 📄 [DEdit: Iterative Draft Editing for Speculative Decoding](https://arxiv.org/abs/2609.38510)
- **作者**：Longxuan Yu et al.
- **提交日期**：2026-09-29
- **摘要**：基于扩散的草稿器能一次提出多个 token 以降低草稿延迟，但这些 token 是各自独立预测的——**早期一个错误就会让前缀验证丢掉整段草稿**，即便其中包含有用的后续预测。DEdit 除常规并行解掩码外还能迭代**编辑**草稿：靠 token-to-token 预测，让较晚的预测充当双向上下文来修复早期错误、延长被接受的前缀。为教会模型在保留正确预测的同时修复错误，作者提出 ProposalMix——训练时按首过置信度混合草稿预测与真值 token。Qwen3-4B/8B 七个基准上取得最高宏平均 token 接受率与加速（贪心解码下 5.72× / 5.97×）；编辑轮次与草稿窗口越大接受率越高，把编辑器限制为因果注意力会降低接受率，说明**未来上下文是收益的关键来源**。

### 📄 [Low-Discrepancy Dither for Quantized Recurrent State Caches](https://arxiv.org/abs/2609.39185)

### 📄 [ShamAN-Q: Shampoo Augmented NanoQuant for Sub-1-bit LLM Weights](https://arxiv.org/abs/2609.38521)

### 📄 [ID Balancing: Stable Training of Extremely Sparse MoE via PID-Based Load Control](https://arxiv.org/abs/2609.39137)
- **作者**：Peng Jin et al.
- **提交日期**：2026-09-30
- **摘要**：用 MoE 扩展 LLM 能以近乎恒定的每 token 计算量换来参数量增长，但继续扩大参数规模要求路由越来越稀疏，此时专家负载失衡更严重，既降低参数利用率与训练效率，也可能损害训练稳定性，成为可靠扩展的瓶颈。作者把两种代表性「无辅助损失」方法统一为**不完整的 PID 控制器**：DeepSeek 的无损法相当于固定步长积分项，Kimi K3 的分位均衡相当于广义比例项。据此提出 ID Balancing（积分-微分）：积分项随负载误差缩放，微分项仅在失衡**恶化**时启用，从而对大误差或恶化中的误差强纠正、接近平衡时小更新。768 专家、Top-3 下最坏骨干 MaxVio 相对最优基线降逾 **50%**，训练平均骨干 MinVio 降逾 12%；总参数从 18.9B 增到 69.9B（Top-10-of-768）时最坏 MaxVio 几乎不变，约比辅助损失基线低 89.6%。稀疏度越高优势越大。
- **方向标签**：#MoE / #训练稳定性

### 📄 [Capture the lifecycle: KV Cache management in ReAct Agents with KVTether](https://arxiv.org/abs/2609.39819)
- **作者**：Kaihua Fu et al.
- **提交日期**：2026-09-30
- **摘要**：长上下文推理-行动（ReAct）agent 的高效服务依赖 KV cache 复用来降低 prefill 延迟与成本，但 agent harness 与底层服务栈之间存在**语义鸿沟**：上下文消息经变异、工具执行与子 agent 协调后，会变成活跃使用、永久丢弃或暂时未使用，而服务栈只观察到对应 KV 的访问，这种生命周期盲区让 LRU 这类只看近期性的策略既无法及时回收死 KV，也无法保住比新条目更早会被复用的旧 KV。KVTether 通过追踪嵌入 harness 的语义原语捕获运行时生命周期语义，把消息级语义翻译成 KV 级生命周期状态来驱动状态优先的缓存管理，且不向 harness 暴露物理复杂度；回收死 KV 后，它优先保留正在等待复用的「存活但空闲」KV，减少复用前的过早驱逐。多个 agent 基准与生产负载上，端到端延迟相对 LMCache、MORI 最多降 **26.3% / 17.4%**，估算任务成本平均降 40.0% / 33.2%。
- **方向标签**：#长上下文 / #推理服务

### 📄 [Linguistic Loopholes in LLM Unlearning: From a 174-Language Benchmark to Coverage-Aware Unlearning](https://arxiv.org/abs/2609.40286)
- **作者**：Tyler Skow et al.
- **提交日期**：2026-09-30
- **摘要**：在一个语言里忘掉的事实，换语言提问、甚至只换要求作答的语言，就可能被重新取出——这是**跨语言漏洞**。最直接的解法是全语言遗忘，但它既不可扩展，又会放大对无关能力的损害。作者提出「语言预算多语言遗忘」任务：选取一个语言子集，使其对**未接受遗忘监督的语言**的擦除效果最大化。为此构建 Cross-Language Unlearning Tensor 基准（横跨 174 个语言—文字对与 25 种原子改写类型，考察遗忘何时跨语言表达泛化），并提出 COVER 依预测覆盖率选择源语言。作者发现朴素地挑「单语言效果最好的源」并不能可靠组合成好的源集合，这正是需要 COVER 的原因；部署时只需良性校准数据与冻结模型访问权。三个模型家族、两个不相交遗忘集上，COVER 相比均匀选择把留出集平均残余可达性降低 **7.8–27.3%**，且增益在低资源语言的真实新闻文档（LORELEI 语料人工翻译）上同样成立。
- **方向标签**：#安全 / #遗忘 / #多语言

### 📄 [Replay on Demand: An Emergent Curriculum for Balancing Adaptation and Forgetting in Continued Pretraining](https://arxiv.org/abs/2609.40089)
- **作者**：Lukas Thede et al.
- **提交日期**：2026-09-30
- **摘要**：持续预训练能让语言模型适配新领域与新知识，但代价是遗忘已有能力。回放可以缓解这个权衡，然而**固定回放配比**独立于模型实际的保留需求分配训练量。Replay on Demand（RoD）改为从模型自身的学习动态推导回放分配：按**剩余学习潜力**优先适配样本，按**已观测遗忘**优先回放样本，二者竞争共享的训练预算，从而形成一个决定每步训练内容的在线课程。在多个模型、规模与适配领域上，RoD 达到或超过调优过的固定回放基线与模型合并所能达到的适配—遗忘前沿，且无需预先设定回放配比；回放会集中在更易遗忘的源上，并随训练中遗忘的出现动态增配与重分配。
- **方向标签**：#数据工程 / #持续预训练
