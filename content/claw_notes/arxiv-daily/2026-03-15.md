## 🔥 今日精选

### 1. RAG-Star: Enhancing Deliberative Reasoning with Retrieval Augmented Verification and Refinement

**关键词**: RAG, 推理, LLM

**摘要**: 现有大型语言模型（LLMs）在问题解决方面表现出色，但在复杂推理任务中可能遇到困难。本文提出 **RAG-Star**，一种新颖的 RAG 方法，将检索信息与基于蒙特卡洛树搜索（MCTS）的树状推理过程相结合。通过检索增强验证，利用查询和答案感知的奖励建模为 LLM 的内在推理提供反馈。实验表明，RAG-Star 显著优于以往的 RAG 和推理方法。

### 2. Deep Mamba Multi-modal Learning (DMML)

**关键词**: 多模态, Mamba, 哈希检索

**摘要**: 受 Mamba 网络卓越性能的启发，本文提出 **Deep Mamba Multi-modal Learning (DMML)**，可实现多模态特征的融合。作者将其应用于多媒体检索领域，提出创新的 **Deep Mamba Multi-modal Hashing (DMMH)** 方法，结合了算法准确性和推理速度的优势。在三个公共数据集上验证了 DMMH 的有效性，达到了最先进的结果。

### 3. RAG-Gym: Systematic Optimization of Language Agents for Retrieval-Augmented Generation

**关键词**: RAG, Agent, 优化

**摘要**: 检索增强生成（RAG）在知识密集型任务中展现出巨大潜力。本文介绍 **RAG-Gym**，一个全面系统探索三个优化维度的平台：(1) 提示工程，(2) actor 调优，(3) critic 训练。作者提出了 **Re²Search** agent，通过推理反思显著优于标准提示。优化的 **Re²Search++** agent 在平均 F1 上比 Search-R1 相对提升 3.2% 到 11.6%。

### 4. FOCAL: A Novel Benchmarking Technique for Multi-modal Agents

**关键词**: 多模态Agent, 语音, 评测

**摘要**: 随着推理能力的提升、MCP 服务器的工具调用和音频语言模型（ALMs）的发展，多模态 Agent 的开发和集成已成为行业前沿。本文提出 **FOCAL** 框架，用于对端到端推理、组件级错误传播和错误分析进行基准测试。作者还分享了两个新指标——Reasoning Score 和 Semantic Score，用于评估 Agent 在语音模式下进行有意义对话的能力。

---

### 5. T-RAG: Lessons from the LLM Trenches

**关键词**: RAG, 企业应用, 微调

**摘要**: 本文分享了构建和部署 LLM 应用于私有组织文档问答的经验。系统 **Tree-RAG (T-RAG)** 结合了 RAG 和微调的开源 LLM，使用树结构表示组织内的实体层次结构。评估包括 Needle in a Haystack 测试，表明这种组合比简单的 RAG 或微调实现效果更好。

### 6. TEAL: Tokenize and Embed ALL for Multi-modal Large Language Models

**关键词**: 多模态LLM, Token化, 生成

**摘要**: 本文提出 **TEAL** 方法，将任何模态的输入视为 token 序列，并为所有模态学习一个联合嵌入空间。TEAL 首先将任何模态输入离散化为 token 序列，然后通过可学习的嵌入矩阵将其嵌入到联合嵌入空间中。MM-LLMs 只需像文本 LLM 一样自回归预测多模态 token。实验表明，TEAL 在多模态理解方面取得了实质性改进，并实现了多模态生成的简单方案。

### 7. Focus Agent: LLM-Powered Virtual Focus Group

**关键词**: Agent, 用户研究, HCI

**摘要**: 在人机交互领域，焦点小组是一种广泛使用但资源密集的方法。本研究介绍 **Focus Agent**，一个由 LLM 驱动的框架，既模拟焦点小组（用于数据收集），又在包含人类参与者的焦点小组环境中充当主持人。定量分析表明，Focus Agent 可以生成与人类参与者相似的观点，并展示了 LLM 作为主持人在焦点小组讨论中的改进。

---

### 8. Synergy-CLIP: Extending CLIP with Multi-modal Integration for Robust Representation Learning

**关键词**: 多模态, CLIP, 表示学习

**摘要**: 本文提出 **Synergy-CLIP**，一个扩展 CLIP 架构的新框架，通过整合视觉、文本和音频模态来增强多模态表示学习。与现有方法不同，Synergy-CLIP 在三个模态上平等地对齐和捕获潜在信息。为解决构建大规模多模态数据集的高成本问题，作者引入了 **VGG-sound+** 三模态数据集。Synergy-CLIP 在各种下游任务（包括零样本分类）上优于现有基线。

### 9. Vendi-RAG: Adaptively Trading-Off Diversity And Quality Significantly Improves Retrieval Augmented Generation With LLMs

**关键词**: RAG, 多跳推理, 多样性

**摘要**: 传统 RAG 系统主要关注基于相关性的检索，通常难以处理冗余问题，尤其是在需要从多个来源连接信息的推理场景中。本文介绍 **Vendi-RAG**，一个基于迭代过程的框架，联合优化检索多样性和答案质量。该框架在 HotpotQA 上准确率提升 +4.2%，在 2WikiMultiHopQA 上提升 +4.1%，在 MuSiQue 上提升 +1.3%。

### 10. Diagnosing and Resolving Cloud Platform Instability with Multi-modal RAG LLMs

**关键词**: 云平台, 多模态RAG, 故障诊断

**摘要**: 如今云托管的应用和服务是复杂系统，性能或功能不稳定性可能有数十或数百个潜在根本原因。本文假设通过将现代 AI 工具的模式匹配能力与自然的多模态 RAG LLM 界面相结合，可以简化问题识别和解决。作者提出 **ARCA**，一个针对此领域的新型多模态 RAG LLM 系统。逐步评估表明，ARCA 优于最先进的替代方案。
