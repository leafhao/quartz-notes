### 1. Shepherd: A Runtime Substrate Empowering Meta-Agents with a Formalized Execution Trace

- **作者**: Simon Yu, Derek Chong, Ananjan Nandi, Dilara Soylu, Jiuding Sun, Christopher D Manning, Weiyan Shi
- **链接**: [arXiv:2605.10913](https://arxiv.org/abs/2605.10913) | [PDF](https://arxiv.org/pdf/2605.10913)
- **分类**: cs.AI, cs.PL, cs.SE
- **摘要**: 提出 Shepherd，一个函数式编程模型，将 meta-agent 对目标 agent 的操作形式化为函数，核心操作在 Lean 中机械化验证。系统以 Git-like 执行轨迹记录每次 agent-环境交互，支持任意历史状态的 fork 和 replay。进程 fork 速度比 Docker 快 5 倍，replay 时 prompt-cache 复用率 >95%。在运行时干预中，supervisor 将 CooperBench 配对编程通过率从 28.8% 提升至 54.7%；在反事实元优化中，分支探索在四个基准上超越 baseline 最多 11 分，同时减少 58% 的时间。

### 2. Remember the Decision, Not the Description: A Rate-Distortion Framework for Agent Memory

- **作者**: Mingxi Zou, Zhihan Guo, Langzhang Liang, Zhuo Wang, Qifan Wang, Qingsong Wen, Irwin King, Lizhen Qu, Zenglin Xu
- **链接**: [arXiv:2605.10870](https://arxiv.org/abs/2605.10870) | [PDF](https://arxiv.org/pdf/2605.10870)
- **分类**: cs.AI
- **摘要**: 将 agent 记忆问题建模为以决策为中心的率失真问题，提出 DeMem 在线记忆学习器。核心洞察：记忆的价值不在于忠实描述过去，而在于保留支持正确决策所需的区分度。给出了精确的"可安全遗忘边界"和记忆-失真前沿，证明了近极小极大遗憾保证。

### 4. The Generalized Turing Test: A Foundation for Comparing Intelligence
- **作者**: Daniel Mitropolsky, Susan S. Hong, Riccardo Neumarker, Emanuele Rimoldi, Tomaso Poggio
- **链接**: [arXiv:2605.10851](https://arxiv.org/abs/2605.10851)
- **摘要**: 提出广义图灵测试 (GTT) 框架，通过不可区分性比较任意 agent 的能力。定义 Turing 比较器 A ≥ B：当 B 作为区分者无法可靠区分 A（模仿 B）和另一个 B 实例时成立。实验在现代模型上验证了该框架产生与现有排名一致的分层结构。
