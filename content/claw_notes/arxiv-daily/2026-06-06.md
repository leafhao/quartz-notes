### 1. HANDOFF: 人形机器人全身控制

**论文标题**: HANDOFF: Humanoid Agentic Task-Space Whole-Body Control via Distilled Complementary Teachers

**作者**: Lizhi Yang, Junheng Li 等 (Georgia Institute of Technology, Boston Dynamics AI Institute)

**核心创新**: 
- 提出紧凑、直观的人形机器人控制接口，连接任务规划与全身控制
- 通过多教师知识蒸馏方案，将运动跟踪、运动控制和跌倒恢复三个专家模块整合为单一学生控制器
- 在 Unitree G1 机器人上实现最先进的速度跟踪和最大的鲁棒操作工作空间
- 通过 VLM 驱动的智能体规划器实现自然语言驱动的任务执行

**链接**: [https://arxiv.org/abs/2606.06493v1](https://arxiv.org/abs/2606.06493v1)

### 2. TempoVLA: 可变速度的视觉-语言-动作策略

**论文标题**: TempoVLA: Learning Speed-Controllable Vision-Language-Action Policies

**作者**: Dong Jing, Jingchen Nie 等 (Peking University, UNC Chapel Hill)

**核心创新**:
- 机器人操作在低风险阶段需要快速执行，高风险阶段需要缓慢精确运动
- 提出 TempoVLA，单一 VLA 模型通过显式条件控制执行速度
- Variable-Speed Trajectory Augmentation (VSTA) 数据增强方法，在保持运动语义的同时重新调整演示速度
- 配合大型多模态模型实现动态速度控制：低风险阶段加速，高风险阶段减速

**链接**: [https://arxiv.org/abs/2606.06491v1](https://arxiv.org/abs/2606.06491v1)

### 3. Code2LoRA: 代码模型的超网络生成适配器

**论文标题**: Code2LoRA: Hypernetwork-Generated Adapters for Code Language Models under Software Evolution

**作者**: Liliana Hotsko, Yinxi Li 等

**核心创新**:
- 代码语言模型需要仓库级上下文来解析导入、API 和项目约定
- 提出 Code2LoRA，超网络框架生成仓库特定的 LoRA 适配器，零推理时 token 开销注入仓库知识
- Code2LoRA-Static：单仓库快照转适配器，适合稳定代码库
- Code2LoRA-Evo：GRU 隐藏状态支持的适配器，随代码 diff 更新，适合活跃开发的演进代码库
- 构建 RepoPeftBench 基准：604 个 Python 仓库，40K 训练和 12K 测试任务

**链接**: [https://arxiv.org/abs/2606.06492v1](https://arxiv.org/abs/2606.06492v1)

### 4. 无递归的递归网络预训练

**论文标题**: Pretraining Recurrent Networks without Recurrence

**作者**: Akarsh Kumar, Phillip Isola (MIT)

**核心创新**:
- 训练 RNN 需要跨长序列分配信用，标准 BPTT 方法并行性受限且存在梯度消失/爆炸问题
- 提出 Supervised Memory Training (SMT)，完全绕过递归信用传播，将 RNN 训练简化为单步记忆转移的监督学习
- 通过 Transformer 编码器获取记忆标签，保留预测未来所需的过去信息
- SMT 实现时间并行 RNN 训练，任意两个 token 间具有稳定的 O(1) 长度梯度路径
- 在语言建模和像素序列建模任务上优于 BPTT

**链接**: [https://arxiv.org/abs/2606.06479v1](https://arxiv.org/abs/2606.06479v1)
