## 🔥 亮点论文

### 1. CASCADE: Case-Based Continual Adaptation for Large Language Models During Deployment

**arXiv ID**: [2605.06702](https://arxiv.org/abs/2605.06702)

**作者**: Siyuan Guo, Yali Du, Hechang Chen, Yi Chang, Jun Wang

**摘要**: 大语言模型的生命周期受限于训练与部署的刚性分离，学习在部署后即停止。本文提出部署时学习（DTL）作为 LLM 生命周期的第三阶段，使 LLM Agent 能够在不修改参数的情况下从部署经验中持续改进。CASCADE 框架通过显式演进的情景记忆，将经验重用建模为上下文赌博机问题，实现原则性的探索-利用权衡。在 16 个任务（医疗诊断、法律分析、代码生成、Web 搜索、工具使用、具身交互）上，CASCADE 比零样本提示提升 20.9% 成功率。

**关键词**: `LLM Agent`, `Continual Learning`, `Episodic Memory`, `Contextual Bandit`

### 2. Towards Security-Auditable LLM Agents: A Unified Graph Representation

**arXiv ID**: [2605.06812](https://arxiv.org/abs/2605.06812)

**作者**: Chaofan Li, Lyuye Zhang, Jintao Zhai, Siyue Feng, Xichun Yang 等 (12位)

**摘要**: LLM Agent 系统的语义驱动执行范式在低级物理事件与高级执行意图之间产生了严重的语义鸿沟，使事后安全审计极为困难。本文提出 Agent-BOM，一种用于 Agent 安全审计的统一结构表示。Agent-BOM 将 Agent 系统建模为分层有向图，将静态能力基座（模型、工具、长期记忆）与动态运行语义状态（目标、推理轨迹、动作）分离。基于此，开发了用于路径级风险评估的图查询范式，并以 OWASP Agentic Top 10 进行实例化。评估显示 Agent-BOM 能重建隐蔽攻击链，包括跨会话记忆污染、工具滥用、供应链劫持等。

**关键词**: `LLM Agent`, `Security Auditing`, `OWASP Agentic Top 10`, `Attack Chain`

### 3. More Thinking, More Bias: Length-Driven Position Bias in Reasoning Models

**arXiv ID**: [2605.06672](https://arxiv.org/abs/2605.06672)

**作者**: Xiao Wang

**摘要**: CoT 推理和推理调优模型（如 DeepSeek-R1）被认为能通过仔细思考减少浅层启发式偏差。本文在多选题 QA 的位置偏差测试中发现不同结论：在任何具备推理能力的模型中，每个问题的位置偏差与推理轨迹长度成正比。在 13 种推理配置（两个 R1-distilled 7-8B 模型、两个 CoT 基础模型、671B DeepSeek-R1）上，12 种显示轨迹长度与位置偏差分数（PBS）存在正相关（0.11-0.41）。截断干预提供因果证据：从轨迹后期恢复的继续生成更倾向于位置偏好选项。

**关键词**: `Reasoning Model`, `Position Bias`, `DeepSeek-R1`, `CoT`, `Evaluation`

### GraphDC: A Divide-and-Conquer Multi-Agent System for Scalable Graph Algorithm Reasoning

**arXiv ID**: [2605.06671](https://arxiv.org/abs/2605.06671) | **PDF**: [链接](https://arxiv.org/pdf/2605.06671)

**作者**: Wenjin Li, Jiaming Cui

**摘要**: LLM 在数学问题上表现强劲，但在图算法任务上仍不理想，因为图拓扑结构复杂且需要系统性多步推理。GraphDC 提出分治多智能体框架：将输入图分解为小子图，分配给专门 Agent 进行局部推理，由主 Agent 整合局部输出与跨子图信息。分层设计降低单 Agent 推理负担，缓解计算瓶颈，提高大规模图实例的鲁棒性。

**领域**: cs.AI, cs.MA

### Hidden Coalitions in Multi-Agent AI: A Spectral Diagnostic from Internal Representations

**arXiv ID**: [2605.06696](https://arxiv.org/abs/2605.06696)

**作者**: Cameron Berg, Susan L. Schneider, Mark M. Bailey

**摘要**: AI Agent 集合可形成联盟，产生关键的涌现组织结构。本文提出从 Agent 内部神经表示检测联盟结构的方法：构建 Agent 隐藏状态的 pairwise 互信息图，应用谱分割识别联盟边界。在 MARL 环境和 LLM 中验证，成功恢复程序化层级和动态联盟结构。

**领域**: cs.AI, cs.LG, cs.MA

### When Does a Language Model Commit? A Finite-Answer Theory of Pre-Verbalization Commitment

**arXiv ID**: [2605.06723](https://arxiv.org/abs/2605.06723)

**作者**: Long Zhang, Wei-neng Chen, Feng-feng Wei, Zi-bo Qin

**摘要**: 语言模型常在给出最终答案前生成推理，但可见答案不揭示模型偏好何时稳定。本文通过有限答案偏好稳定化研究此问题：将模型继续概率投影到有限答案集。在控制延迟判决任务中，上下文有限答案投影在答案可解析前稳定，有 17-31 token 的平均领先。

**领域**: cs.AI, cs.CL, cs.LG

### Weblica: Scalable and Reproducible Training Environments for Visual Web Agents

**arXiv ID**: [2605.06761](https://arxiv.org/abs/2605.06761)

**作者**: Oğuzhan Fatih Kar, Roman Bachmann, Yuanzheng Gong, Anders Boesen Lindbo Larsen, Afshin Dehghan

**摘要**: Web 复杂开放且不断变化，使视觉 Web Agent 的训练数据扩展困难。Weblica 通过 HTTP 级缓存捕获和重放稳定视觉状态，同时保留交互行为；LLM 环境合成基于真实网站和核心 Web 导航技能。将 RL 训练扩展到数千环境，Weblica-8B 在多个基准上超越相似规模基线。

**领域**: cs.AI, cs.CV, cs.LG

### Randomness is sometimes necessary for coordination

**arXiv ID**: [2605.06825](https://arxiv.org/abs/2605.06825)

**作者**: Rohan Patil, Jai Malegaonkar, Henrik I. Christensen

**摘要**: 同质 Agent 的完全参数共享是合作 MARL 标准。但在置换对称观测下，共享确定性策略输出相同动作分布，使角色分化不可能。本文提出 Diamond Attention：每个 Agent 每步采样随机数，诱导临时排名排序。在 XOR 博弈达到 1.0 成功，确定性基线只有 0.5。

**领域**: cs.AI, cs.RO

### AGWM: Affordance-Grounded World Models for Environments with Compositional Prerequisites

**arXiv ID**: [2605.06841](https://arxiv.org/abs/2605.06841)

**作者**: Qinshi Zhang, Weipeng Deng, Zhihan Jiang, Jiaming Qu, Qianren Li, Weitao Xu, Ray LC

**摘要**: 标准世界模型学习静态转移函数，忽略动作前提条件。AGWM 学习以 DAG 表示的抽象可供性结构，显式跟踪动作的动态可执行性。实验显示更低的多步预测误差，更好的新配置泛化。

**领域**: cs.AI, cs.LG
