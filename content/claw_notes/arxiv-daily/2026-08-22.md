### 📄 [EnvHarness: Awakening Static Worlds for Agent Learning](https://arxiv.org/abs/2608.19880)
- **作者**：Chengsong Huang et al.
- **关键词**：agent learning, environment generation, RL
- **摘要**：LLM agent 靠与环境交互学习，但现有环境都是手工搭建的静态世界：看不见 agent 的弱点，agent 一变强就过时。已有的环境生成方法又依赖领域专用流水线和昂贵/不可靠的验证器。EnvHarness 提出把已有静态世界「唤醒」成可持续演化的训练环境，免去反复重建环境的工程负担。
- **票数**：235 👍

### 📄 [FACET: Preserving Source Intent and Executable State in Terminal Task Synthesis](https://arxiv.org/abs/2608.18580)
- **作者**：Kou Shi et al.
- **关键词**：terminal agent, task synthesis, executable verifier
- **摘要**：训练终端 agent 需要可规模化的「可执行监督」，但合成高质量终端任务很难：一个任务要同时耦合指令、初始化环境、参考解和可执行验证器，四者假设不一致就会产出无解或误判的任务。FACET 在多阶段合成中保持源意图与可执行状态一致，显著提升合成任务的可用率。
- **票数**：107 👍

### 📄 [SWE-bench Science: Can Coding Agents Resolve Engineering Tasks in Science?](https://arxiv.org/abs/2608.19799)
- **作者**：Zhipeng Xu et al.
- **关键词**：coding agent, benchmark, scientific software
- **摘要**：科研软件的 bug 不只影响程序行为，还会污染科学结论本身。现有 coding agent 评测只看总体成功率，说不清 agent 为什么修不好。SWE-bench Science 面向科研代码库构建评测，用于诊断失败原因而非只报分数。
- **票数**：56 👍

### 📄 [MemTrapBench: Benchmarking Cognitive Traps in LLM Memory Use](https://arxiv.org/abs/2608.20202)
- **作者**：Mengru Wang et al.
- **关键词**：memory, cognitive trap, benchmark
- **摘要**：现有记忆类评测只检查信息能否被正确抽取、存储、检索，忽略了「检索回来的记忆如何反过来扭曲模型推理」。作者提出记忆诱发的认知陷阱概念并构建评测：即使检索本身是对的，注入的记忆也可能让模型在当前任务上表现更差。
- **票数**：29 👍

### 📄 [Repo0: Design-Driven Zero-to-All Code Generation](https://arxiv.org/abs/2608.19854)
- **作者**：Silin Chen et al.
- **关键词**：code agent, repo-level generation, architecture
- **摘要**：多数代码 agent 都预设仓库架构已经存在。Repo0 处理「从零到全量」场景：直接从自然语言需求构建整个软件项目，并在整个开发过程中持续维持模块化的仓库架构，用设计驱动而非逐文件补全。
- **票数**：15 👍

### 📄 [FlashPrefill V2: Block-Sparse Prefill Attention for Long-Context LLM Serving](https://arxiv.org/abs/2608.19758)
- **作者**：Qihang Fan et al.
- **关键词**：long context, sparse attention, prefill, serving
- **摘要**：长上下文的核心瓶颈是 attention 的二次复杂度，尤其在计算密集的 prefill 阶段。V1 的即时模式发现 + max 动态阈值仍停留在算法原型阶段；V2 做成面向生产部署的块稀疏 prefill attention，把长上下文服务的首 token 延迟压下来。
- **票数**：13 👍

### 📄 [Thinking in a Low-Resource Language: What SFT Builds, What RL Fixes, What Accuracy Cannot See](https://arxiv.org/abs/2608.17744)
- **作者**：Ayoub Kirouane et al.
- **关键词**：SFT, RL, low-resource language, evaluation noise
- **摘要**：拿三个前沿 MoE 模型（3.6–4.0B 激活参数）微调成用低资源语言推理：准确率几乎不动，而且这个量级下 benchmark 本身就是噪声——只换随机种子分数就波动 7.7 分，超过所有数据和配方带来的效果差异。这个 null result 是第一个结论；真正的变化发生在准确率看不见的地方（SFT 建立什么、RL 修正什么）。
- **票数**：12 👍

### 📄 [Inject, Align, Recover: Staged Post-Training for Retrieval-Free Document Knowledge Internalization](https://arxiv.org/abs/2608.20281)
- **作者**：Qian Kou et al.
- **关键词**：post-training, knowledge internalization, retrieval-free QA
- **摘要**：推理时不检索原文档时，LLM 常常答不出封闭文档集里的问题。作者把这个设定形式化为「文档知识内化」：把固定语料转成可用的参数化知识。IAR 用注入-对齐-恢复三阶段后训练，把结构化知识注入与能力恢复分离，避免注入新知识时损伤通用能力。
- **票数**：9 👍

### 📄 [VA-Judger: Reward Modeling from Human Preference Feedback for Joint Video-Audio Generation](https://arxiv.org/abs/2608.18607)
- **作者**：Yinming Huang et al.
- **关键词**：reward model, RLHF, video-audio generation
- **摘要**：用 RL 后训练音视频联合生成模型需要奖励信号。现有做法是把音质、画质、同步性等单维指标拼起来，各维独立打分，无法捕捉 prompt/视频/音频三者之间的整体语义与时序一致性。VA-Judger 直接从人类偏好反馈学统一奖励模型。
- **票数**：9 👍

### 📄 [PEA-DPO: Perception-Enhanced Alignment Direct Preference Optimization for MLLMs Alignment](https://arxiv.org/abs/2608.19598)
- **作者**：Jiawei Feng et al.
- **提交日期**：2026-08-22（cs.CV）
- **摘要**：DPO 在纯文本对齐上已被验证有效，但多模态适配几乎空白。作者通过表征分析定位到多模态偏好优化的关键缺陷——「视觉不敏感」：模型往往分不清原图与带关键视觉扰动的图，于是偏好信号退化成纯语言先验。PEA-DPO 强化感知信号参与对齐。
- **方向标签**：#后训练优化

### 📄 [MidTool: Mid-training Data Synthesis for Agentic Tool Use](https://arxiv.org/abs/2608.20314)
- **作者**：Fengqing Jiang et al.
- **提交日期**：2026-08-22（cs.AI）
- **摘要**：中期训练（mid-training）正被认为是塑造 LLM 能力的关键阶段：已有工作证明定向 mid-training 能强化数学/科学等推理密集能力，也能提升软件工程场景的 agentic 能力。本文研究相对少被探索的平行方向——通用工具调用能力，提出面向 agentic tool use 的 mid-training 数据合成方案。
- **方向标签**：#数据工程

### 📄 [SAPO: Single-Rollout Autoregressive Policy Optimization for Agentic Reinforcement Learning](https://arxiv.org/abs/2608.19842)
- **作者**：Dayang Liang et al.
- **提交日期**：2026-08-22（cs.AI）
- **摘要**：GRPO 一类 critic-free、组相对的方法靠多条 rollout 估计优势，避开了 PPO 的显存开销，在长时序交互任务上表现很强，但近期研究揭示了它的三类问题。SAPO 改成单 rollout 的自回归策略优化，用更低的采样成本做 agentic RL。
- **方向标签**：#后训练优化

### 📄 [Learning When to Think: Adaptive Reasoning for Test-Time Compute Allocation](https://arxiv.org/abs/2608.20256)
- **作者**：Gijs Kassenaar et al.
- **提交日期**：2026-08-22（cs.AI）
- **摘要**：RL 训出来的推理模型通常在固定 token 预算下工作，导致简单题过度计算、难题算力不够。本文让模型自己分配推理预算：把响应的第一个 token 当作模式选择器，在 NoThink（直接答）等三档之间自主切换。
- **方向标签**：#推理优化

### 📄 [ReCache: Efficient KV Cache Reuse and Compression for Tool-Augmented LLM Agents](https://arxiv.org/abs/2608.19662)
- **作者**：Yichu Fang et al.
- **提交日期**：2026-08-22（cs.CL）
- **摘要**：Agent 会在不同请求中以不同组合和顺序反复编码同一批工具/技能 schema，标准前缀缓存因此无法复用它们的 KV 状态。ReCache 把资源表示独立缓存，用 resource-wise attention 去掉跨资源依赖，同时压低推理时的算力与显存开销。
- **方向标签**：#推理优化

---

### 📄 [From Retrieved Context to Runtime Control: Adaptive Compression for Edge-based RAG](https://arxiv.org/abs/2608.19535)
- **作者**：Zlatan Feric et al.
- **提交日期**：2026-08-22（cs.AI）
- **摘要**：RAG 把检索段落塞进 prompt，代价是 prefill 变重、KV cache 变大、显存带宽/延迟/能耗全部上升。上下文压缩是自然解法，但 SOTA 压缩方法通常是静态的。本文把压缩率变成运行时可控量，面向边缘部署做自适应压缩。
- **方向标签**：#推理优化

### 📄 [Beyond Imitation: Filtering On-Policy Distillation by Reasoning Progress](https://arxiv.org/abs/2608.19408)
- **作者**：Chen Yang et al.
- **提交日期**：2026-08-22（cs.AI）
- **摘要**：On-policy 蒸馏（OPD）把学生自采轨迹配上教师的稠密 token 级监督，是有效的后训练框架，但它隐含假设「教师奖励是推理进展的合适代理」，因而对所有教师反馈一视同仁。作者指出该假设常常不成立，改为按推理进展筛选教师信号。
- **方向标签**：#后训练优化

### 📄 [Learning how to Forget: Fine-tuning for Long-Context Sparse Attention](https://arxiv.org/abs/2608.19920)
- **作者**：Matthias Seeger et al.
- **提交日期**：2026-08-22（cs.CL）
- **摘要**：此前大量工作用稀疏 attention 做 KV cache 选择与压缩以支撑长上下文。本文提出一种新的稀疏 attention 微调方法：适用于任意 KV cache 策略，单张 40GB A100 即可跑，让模型在训练阶段就与「遗忘策略」协同适配，而非事后硬套。
- **方向标签**：#推理优化
