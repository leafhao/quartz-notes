### 📄 [Memadapter: Counterfactual Adaptation Against Memory-induced Sycophancy](https://arxiv.org/abs/2610.05162)
- **作者**：Ruqing Ning et al.
- **关键词**：long-term memory, memory-induced sycophancy, counterfactual adaptation
- **摘要**：长期记忆让智能体能跨会话复用信息，但也诱发谄媚：即便记忆不准、过时或与证据冲突，智能体仍过度迎合用户既有信念。已有做法假设谄媚源自记忆本身有偏，于是按阶段过滤记忆；但作者指出正确客观的记忆同样会引发谄媚，且同一条记忆在不同情境下该有多大影响并不相同。MemAdapter 不再过滤，而是按情境自适应地整合检索到的记忆，让推理保持客观可靠。
- **票数**：27 👍

### 📄 [Data Unlearning via Inverse Distillation](https://arxiv.org/abs/2609.36099)

- **摘要**：测试时训练把上下文压进在线更新的快权重作为记忆，现有设计让记忆按层私有：只随时间递归，深度只是索引 L 份独立记忆。作者主张记忆归属不必绑定深度，提出 Universal TTT：所有层读写同一份共享记忆，同时保留各层专属主干参数，于是记忆在时间与深度两个维度上递归，以 chunk 与层为单位——深层的写入可被下一个 chunk 的浅层读到。uTTT-MoE 在 124M 与 760M 上 RULER 准确率 15.5 与 27.9，同状态同激活算力下比层私有版本高 2.6 与 2.1 点。
- **方向标签**：#新架构 / #记忆

### 📄 [Can Agent Harnesses and Inference Engines Hear Each Other? The HEAR Protocol for Agentic LLM Serving](https://arxiv.org/abs/2610.06597)
- **作者**：Jiaqi Zhao et al.
- **提交日期**：2026-10-05
- **摘要**：LLM agent 执行多轮推理、工具调用与并行子智能体等复杂工作流，高效服务需要跨两层的决策，而两层信息互补：agent harness 懂工作流依赖、上下文生命周期与执行目标，推理引擎则观察请求队列、KV 缓存状态、资源压力与执行能力。现有接口没有把两种视角系统连起来。HEAR 是双向的 harness—引擎配对协议：标准化 harness 如何传达工作流意图与执行需求、引擎如何回传运行时状态、能力与结果；语义与优化策略分离，因而支持多种协同策略而不改工作流与模型语义。
- **方向标签**：#推理服务 / #智能体

### 📄 [Balancing Memory Pathways: Analyzing and Improving Memory Utilization in Hybrid LMs](https://arxiv.org/abs/2610.06750)
- **作者**：Hyunji Lee et al.
- **提交日期**：2026-10-05
- **摘要**：循环—注意力混合语言模型交错放置注意力层与循环层，以兼顾效率与性能。先前工作认为两条通路互补：注意力做早期 token 的精确回忆，循环层做长程信息的整合。作者发现「两条通路都在」不等于「被有效使用」——混合模型明显更依赖注意力而少用循环状态，标准 SFT 提升整体表现却不改善两者的协调，模型反而更依赖注意力传播的信息。为此加入一个辅助损失，限制注意力对早期 token 的访问，迫使循环通路承担更多整合，改善两条记忆通路的协调。
- **方向标签**：#长上下文 / #记忆

### 📄 [Principled Top-$k$ Selection for Language Models with Hybrid Gradients](https://arxiv.org/abs/2610.04162)
- **作者**：Xuchen Gong et al.
- **提交日期**：2026-10-03
- **摘要**：从 m 个候选里选最好的 k 个是现代 LLM 系统的关键部件，例如 RAG 的文档选择与 MoE 的专家路由，但训练这些选择模块很难：梯度信号弱、探索—利用权衡不佳，已有工作多靠启发式，缺少显式建模并求解 top-k 的原则性目标。本文提出一个可训练的选择目标，其梯度天然以混合形式给出更丰富的信号——同时含监督梯度分量与策略梯度分量；并证明选择问题随 m 增大而变难，算法以 O(1/√T) 收敛，最优上界来自偏差与方差的平衡。
- **方向标签**：#数据工程 / #RAG
