- **摘要**：超级人工智能（ASI）要求 AI 超越掌握已有知识，走向探索未知、创造新知识并把新想法转化为可验证结果。但当今 AI 的能力主要建立在学习、压缩、应用人类已有知识之上，现有基准也只测"能否基于已学知识给出正确答案"或"能否在大量人工指导下完成任务"。作者提出 ASI-Bench——首个联合评估 AI 系统「创新性探索」与「自主科研执行」能力的基准，覆盖通用研究领域。

### 📄 [Embodied-Navigator: Point, Think, Memorize, and Align for Efficient Navigation](https://arxiv.org/abs/2608.17512)
- **作者**：Hongyan Feng, Sunlai Chen, Xuanyu Liu et al.
- **关键词**：VLM, embodied navigation, visual prompting, memory
- **摘要**：视觉语言模型（VLM）推动了具身导航，但直接部署仍困难：现有方法强迫 VLM 使用与其 2D 预训练先验不匹配的非自然动作空间，加上僵化的推理调度和低效的记忆管理。作者提出 TAMP-Nav 统一框架，核心是「像素到 3D 动作表述」——VLM 只需选择 2D 像素，再投影为 3D 坐标交给底层 SLAM 控制器，从而与 VLM 的 2D 视觉先验自然对齐。
- **票数**：44 👍

### 📄 [Agent Lightning v1.0: Towards Harnessed Agentic RL](https://arxiv.org/abs/2608.17528)
- **作者**：Zhiyuan He, Siwei Zhang, Zhiwen Zhou et al.
- **关键词**：agentic RL, agent harness, post-training, RL infrastructure
- **摘要**：现代 Agent 运行在管理工具、上下文和控制流的 "harness"（承载框架）之内，harness 因此成为系统关键部分。初版 Agent Lightning 提出了通过 LLM endpoint 代理把任意 Agent 接入 RL 训练的解耦架构，后被 verl Uni-Agent、AReaL 2.0、slime、Polar 等框架采纳。作者把这一范式称为「harnessed agentic RL」——部署期的 harness 直接参与模型后训练。它与传统 agentic RL 的根本区别在于：环境交互循环由 harness 而非训练引擎拥有，训练器只观察到部分信息。

### 📄 [Data-DPO: Direct Preference Optimization for Target Model Data Selection in LLM Post-Training](https://arxiv.org/abs/2608.16926)
- **作者**：Peng Sun, Yi Yang, Antong Zhang et al.
- **提交日期**：2026-08-19 · cs.LG
- **摘要**：SFT 数据筛选的目标是从大规模候选中挑出少量有效样本，降低训练成本同时保持性能。但现有方法多把数据价值视为相对静态的属性，很少关注数据与目标模型能力分布之间的匹配度。Data-DPO 提出面向目标模型的 SFT 数据筛选：通过一步探针观察目标模型在不同样本上的局部训练反馈，把样本间的激活差异转化为成对数据偏好，再训练一个轻量奖励模型来打分。
- **方向标签**：#数据工程 #后训练 #DPO

### 📄 [Agentic ESOpt: Fine-Tuning Long-Horizon LLM Agents with Minimal GPU Requirements](https://arxiv.org/abs/2608.17310)
- **作者**：Zhi Zheng, Rongsheng Chen, Yunpeng Ba et al.
- **提交日期**：2026-08-19 · cs.LG
- **摘要**：RL 在单轮 LLM 微调上表现不错，但长程 Agent 推理带来分支交互增长和稀疏奖励，暴露出 RL 的多个局限：基于反向传播的重型训练栈让大模型微调不切实际，更长的轨迹让信用分配显著变难。作者主张演化策略（ES）是微调长程 LLM Agent 的更优选择，优势有三：模型可扩展性（仅需推理级显存即可全参数优化）、更简单的信用分配、更好的并行性。
- **方向标签**：#后训练 #RL替代 #低显存

### 📄 [GUPO: Gradient Uncertainty-aware Policy Optimization for Post-Training Large Language Models](https://arxiv.org/abs/2608.17411)
- **作者**：Peizheng Guo, Jianqi Zhang, Xingyu Zhang et al.
- **提交日期**：2026-08-19 · cs.LG
- **摘要**：GRPO 已成为 LLM 推理后训练的主流方法。GRPO 中同一 mini-batch 内不同 query 诱导的组梯度被直接平均以形成策略更新，但这些组梯度方向可能互相冲突。实证分析表明组梯度冲突往往与低效的策略更新相关，因此需要在冲突下得到可靠的聚合更新方向。标准 GRPO 把实测组梯度当作确定性贡献，未考虑其可靠性差异；GUPO 引入梯度不确定性感知的聚合。
- **方向标签**：#GRPO #后训练 #策略优化

### 📄 [Belayer: Efficient Fault Tolerance for LLM Agentic RL Training](https://arxiv.org/abs/2608.14635)
- **作者**：Jiecheng Zhou, Qinghao Hu, Peng Sun et al.
- **提交日期**：2026-08-19 · cs.DC
- **摘要**：LLM Agent 越来越多在长程沙箱环境中用 RL 训练。与传统 RL 不同，agentic RL 把 GPU 密集的 rollout 引擎与有状态环境容器耦合，后者的动作会产生可见副作用（文件编辑、命令执行、依赖安装）。单条轨迹可能横跨多轮生成与环境交互，一个组件故障就会丢弃已完成的工作，或让模型暴露在与上下文不一致的环境状态中。现有系统缺乏针对这种分布式执行模型的高效且正确的恢复机制，Belayer 补上这一环。
- **方向标签**：#训练基础设施 #agentic RL #容错

### 📄 [Palmyra x6 Technical Report: An Agentic, Tool-Use Model Post-Trained via Anchored Supervised Fine-Tuning](https://arxiv.org/abs/2608.16620)
- **作者**：Peng Du, Kiran Kamble, Rakshith Vasudev et al.
- **提交日期**：2026-08-19 · cs.CL
- **摘要**：Palmyra x6 面向企业级 Agent 任务优化，做法是在 MoE 基座上用「锚定 SFT」在一小批经验证的合成工具调用轨迹上后训练，优化器为 Muon + Adam 混合。配方刻意保守可控：626 条轨迹、单个 epoch、低学习率、对冻结基座做 KL 锚定。相比前代默认模型有显著提升，在公开基准上与多个近期模型相比表现优异，BFCL Core 得分 0.785 为最高。

### 📄 [Hierarchical Data Selection via Manifold Coverage and Sparse Feature Coverage in LLM Post-training](https://arxiv.org/abs/2608.16927)
- **作者**：Peng Sun, Yi Yang, Antong Zhang et al.
- **提交日期**：2026-08-19 · cs.LG
- **摘要**：随着 SFT 数据规模持续扩大，从大候选池中挑高价值子集对降本增效至关重要。现有方法常直接在原始 embedding 空间衡量多样性，几何度量会把主导语义方向、细粒度监督差异和局部噪声纠缠在一起。作者把数据筛选形式化为「由粗到细的覆盖问题」并提出 MASS：先用稠密自编码器学低维主流形坐标做粗粒度语义分组，再在每组内做质量感知的稀疏特征覆盖。

### 值得重点看的三篇

1. **GUPO（2608.17411）** — 直指 GRPO 组梯度冲突这个实际训练痛点，把组梯度的可靠性差异建模进聚合，属于能直接迁到现有 GRPO 流水线的改动。
