### 1. Experience as a Compass: Multi-agent RAG with Evolving Orchestration and Agent Prompts

**arXiv ID:** [2604.00901](https://arxiv.org/abs/2604.00901)
**作者:** Sha Li, Naren Ramakrishnan
**领域:** cs.AI

**摘要:**
Multi-agent Retrieval-Augmented Generation (RAG), wherein each agent takes on a specific role, supports hard queries that require multiple steps and sources, or complex reasoning. Existing approaches rely on static agent behaviors and fixed orchestration strategies, leading to brittle performance on diverse, multi-hop tasks. This paper proposes **HERA**, a hierarchical framework that jointly evolves multi-agent orchestration and role-specific agent prompts. At the global level, HERA optimizes query-specific agent topologies through reward-guided sampling and experience accumulation. At the local level, Role-Aware Prompt Evolution enables individual agents to refine their behavior based on task-specific rewards.

**亮点:** 🌟 多智能体 RAG 的自适应编排机制，支持行为级学习

### 2. MemMachine: A Ground-Truth-Preserving Memory System

**arXiv ID:** [2604.04853](https://arxiv.org/abs/2604.04853)
**领域:** cs.CL, cs.AI

**摘要:**
LLM agents require persistent memory to maintain personalization, factual continuity, and long-horizon reasoning, yet standard context-window and retrieval-augmented generation (RAG) pipelines degrade over multi-session interactions. **MemMachine** is an open-source memory system that integrates short-term, long-term episodic, and profile memory within a ground-truth-preserving architecture. It uses contextualized retrieval that expands nucleus matches with surrounding context, achieving 0.9169 on LoCoMo benchmark. The Retrieval Agent supports multi-hop reasoning with chain-of-query strategies, achieving 93.2% on HotpotQA-hard.

**亮点:** 🌟 开源记忆系统，保留对话完整性，支持多跳推理

### 3. Guaranteeing Knowledge Integration with Joint Decoding for RAG

**arXiv ID:** [2604.08046](https://arxiv.org/abs/2604.08046)
**领域:** cs.CL
**状态:** ✅ Accepted by ACL'26

**摘要:**
Addresses the critical knowledge integration problem in RAG systems where conflicts between parametric and non-parametric knowledge sources significantly limit RAG effectiveness. Proposes **GuarantRAG**, a novel framework that resolves these conflicts through generating complementary inner-answers and refer-answers, then optimally fusing them using DPO-based training strategy and segment-level fusion mechanism. Improves answer accuracy by up to 12.1% while reducing hallucination by 16.3%.

**亮点:** 🌟 解决参数化与非参数化知识冲突问题，ACL 2026 录用
