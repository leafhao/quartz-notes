### 📄 [HypoEvolve: Genetic Algorithms Enable Multi-Agent LLMs to Discover Scientific Hypotheses](https://arxiv.org/abs/2609.15938)

- **关键词**：multi-agent LLM, genetic algorithm, hypothesis discovery, agent collaboration
- **摘要**：用遗传算法驱动多 agent 做科学假设发现，关键在把“agent 的科学能力”与“协作结构”两个变量解耦：保留各 agent 的科学角色，用统一的组合、修订、保留规则做进化搜索，从而分离出不同协作形式对假设质量的真实影响。
- **票数**：28 👍

### 📄 [PACT: Can Enterprise AI Assistants Be Trusted Under Pressure?](https://arxiv.org/abs/2609.18605)

- **摘要**：提出 PACT（压力合规测试）基准，衡量企业级 agent 在用户持续施压、上级催促、或违规更省事时是否仍遵守系统规则。覆盖 12 个受监管行业场景，填补“缺少系统性度量哪些模型更易违规”的评测空白。
- **票数**：26 👍

- **摘要**：从转移矩阵谱性质研究 Gated DeltaNet 的长上下文扩展，指出两个决定长程信息检索能力的关键因素（与目标依赖对齐的足够宽的慢谱带等），据此提出谱重参数化方法，避免直接续训忽视线性注意力状态动态的谱结构。
- **票数**：25 👍

### 📄 [A Zeroth-Order Paradigm for LLM Preference Alignment](https://arxiv.org/abs/2609.19144)
- **作者**：Peter Chen et al.
- **关键词**：preference alignment, zeroth-order optimization, comparison oracle, DPO
- **摘要**：指出直接偏好对齐的似然位移问题会让小似然间隔的偏好对信息被浪费，提出 ComPO：基于比较 oracle 的零阶对齐方法，不直接对偏好损失求导，而是从偏好对中提取方向信息，并给出收敛性分析。
- **票数**：23 👍

### 📄 [Flattening Every Memory Peak in Long-Context Mixture-of-Experts Training](https://arxiv.org/abs/2609.14306)

### 📄 [Another Blueprint In The Wall: How to Ask Frontier AI Like a Kid?](https://arxiv.org/abs/2609.14803)

- **票数**：11 👍

### 📄 [Decoy Direction Optimization: A Post-Hoc Defense Against LLM Abliteration](https://arxiv.org/abs/2609.16204)

- **摘要**：针对拒绝特征消融（RFA）这类免训练越狱，提出诱饵方向优化（DDO）：一种快速的后处理权重编辑防御，无需为每个新 checkpoint 做安全微调，机理是让攻击者投影掉的线性方向不再是真正的拒绝方向。
