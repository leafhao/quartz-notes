## 1. RAG-Star: Enhancing Deliberative Reasoning with Retrieval Augmented Verification and Refinement

**摘要：** 现有的大语言模型（LLM）在问题解决方面表现出色，但在复杂推理任务上可能会遇到困难。尽管思维链和基于树的搜索方法取得了一定成功，但它们主要依赖 LLM 的内部知识来搜索中间推理步骤，仅限于处理涉及较少推理步骤的简单任务。本文提出 **RAG-Star**，一种新颖的 RAG 方法，将检索到的信息整合到依赖 LLM 固有知识的基于树的审慎推理过程中。通过利用蒙特卡洛树搜索，RAG-Star 基于 LLM 本身迭代规划中间子查询和答案。为了整合内部和外部知识，我们提出了一种检索增强验证方法，利用查询和答案感知的奖励建模为 LLM 的固有推理提供反馈。使用 Llama-3.1-8B-Instruct 和 GPT-4o 的实验表明，RAG-Star 显著优于以往的 RAG 和推理方法。

## 4. FOCAL: A Novel Benchmarking Technique for Multi-modal Agents

**摘要：** 随着推理能力的最新进展、MCP 服务器的工具调用以及音频语言模型（ALM），多模态智能体（支持语音和文本）的开发和集成已成为行业前沿。由于 LLM 提供的卓越推理能力，语音智能体的级联流水线在行业中仍扮演核心角色。然而，级联流水线通常存在通过流水线的错误传播问题。我们提出 **FOCAL** 框架，用于对端到端推理、组件级错误传播和错误分析进行基准测试，支持自动和人工辅助的多模态智能体测试。我们还分享了两个新颖的指标：推理分数和语义分数，用于评估智能体在语音模式下进行有意义对话的有效性。

## 5. T-RAG: Lessons from the LLM Trenches

**摘要：** 大语言模型（LLM）展现了卓越的语言能力，激发了将其集成到各领域应用的尝试。一个重要的应用领域是在私有企业文档上的问答，主要考虑因素是数据安全（需要可本地部署）、有限的计算资源以及对可靠应用的需求。检索增强生成（RAG）已成为构建 LLM 应用最突出的框架。虽然构建 RAG 相对简单，但使其健壮可靠需要大量定制和对应用领域的深入了解。我们分享了在私有组织文档问答方面构建和部署 LLM 应用的经验。我们的应用结合了 RAG 和微调的开源 LLM。此外，我们的系统 **Tree-RAG (T-RAG)** 使用树结构表示组织内的实体层次结构，用于在响应用户查询时生成文本描述以增强上下文。我们的评估（包括 Needle in a Haystack 测试）表明，这种组合比简单的 RAG 或微调实现效果更好。

## 6. TEAL: Tokenize and Embed ALL for Multi-modal Large Language Models

**摘要：** 尽管多模态大语言模型（MM-LLM）最近取得了令人兴奋的进展，但在高效建模多模态输入之间的交互以及非文本模态的生成方面仍面临挑战。本文提出 **TEAL**，一种将任何模态输入视为 token 序列并学习所有模态联合嵌入空间的方法。具体而言，对于任何模态的输入，TEAL 首先使用现成的分词器将其离散化为 token 序列，并使用可学习的嵌入矩阵将 token 序列嵌入到联合嵌入空间中。MM-LLM 只需要像文本 LLM 那样自回归地预测多模态 token。最后，应用相应的去分词器根据预测的 token 序列生成每个模态的输出。通过联合嵌入空间，TEAL 使冻结的 LLM 能够执行涉及非文本模态（如图像和音频）的理解和生成任务。实验表明，TEAL 在多模态理解方面取得了实质性改进，并实现了多模态生成的简单方案。

## 7. Focus Agent: LLM-Powered Virtual Focus Group

**摘要：** 在人机交互领域，焦点小组是一种广泛使用但资源密集的方法，通常需要熟练主持人的专业知识和精心的准备工作。本研究引入 **Focus Agent**，一个由大语言模型（LLM）驱动的框架，既模拟焦点小组（用于数据收集），又在包含人类参与者的焦点小组中担任主持人。为了评估 Focus Agent 生成的数据质量，我们与总共 23 名人类参与者进行了五次焦点小组会议，并部署 Focus Agent 用 AI 参与者模拟这些讨论。定量分析表明，Focus Agent 可以生成与人类参与者相似的观点。此外，该研究揭示了 LLM 在包含人类参与者的焦点小组讨论中担任主持人的一些改进。

## 8. Synergy-CLIP: Extending CLIP with Multi-modal Integration for Robust Representation Learning

**摘要：** 多模态表示学习已成为人工智能的关键领域，能够整合视觉、文本和音频等不同模态来解决复杂问题。然而，现有方法主要关注双模态交互（如图像-文本对），这限制了它们充分利用多模态数据的能力。本文提出 **Synergy-CLIP**，一个新颖的框架，扩展对比语言-图像预训练（CLIP）架构，通过整合视觉、文本和音频模态来增强多模态表示学习。与现有方法专注于将单个模态适应到原始 CLIP 不同，Synergy-CLIP 平等地对齐和捕获三种模态之间的潜在信息。为解决构建大规模多模态数据集的高成本，我们引入 VGG-sound+，一个三模态数据集，旨在提供视觉、文本和音频数据的等比例表示。Synergy-CLIP 在各种下游任务上得到验证，包括零样本分类，性能优于现有基线。

## 9. Vendi-RAG: Adaptively Trading-Off Diversity And Quality Significantly Improves Retrieval Augmented Generation With LLMs

**摘要：** 检索增强生成（RAG）通过利用外部知识源增强了 LLM 在特定领域问答任务中的能力。然而，传统 RAG 系统主要关注基于相关性的检索，在冗余问题上常常遇到困难，尤其是当推理需要连接来自多个来源的信息时。本文引入 **Vendi-RAG**，一个基于迭代过程的框架，联合优化检索多样性和答案质量。这种联合优化显著提高了多跳问答任务的准确性。Vendi-RAG 利用 Vendi Score（VS），一种灵活的基于相似度的多样性度量，来促进文档检索中的语义多样性。然后使用 LLM 评判器评估候选答案，输出分数供检索器在每次迭代中使用，以平衡检索文档之间的相关性和多样性。在 HotpotQA、MuSiQue 和 2WikiMultiHopQA 三个挑战性数据集上的实验证明了 Vendi-RAG 在多跳推理任务中的有效性。该框架相比传统单步和多步 RAG 方法取得了显著的准确率提升，在 HotpotQA 上达到 +4.2%，在 2WikiMultiHopQA 上达到 +4.1%，在 MuSiQue 上达到 +1.3%，均优于当前最佳基线 Adaptive-RAG。
