### 📄 [STEPQuant: When and Where Errors Matter in Delta-Rule Recurrent State Quantization](https://arxiv.org/abs/2609.38169)
- **作者**：Bingchen Yao, Haobo Xu, Haokun Lin et al.
- **关键词**：recurrent state quantization, linear attention, post-training quantization, low-bit inference
- **摘要**：线性注意力用固定大小的循环状态替代不断增长的 KV cache，但并发服务时这些持久状态本身成为内存瓶颈；直接压到低精度会因量化误差沿状态更新链逐级传播而严重掉点。作者发现误差影响分两个维度：时间上，长寿命记忆里的误差会跨多个解码步持续；空间上，不同 key 行的误差对输出影响不同、状态幅度沿行列差异很大。STEPQuant 据此按误差幅度与记忆存活时长分配精度，并联合拟合 key 行尺度，在激进低比特下仍保住精度。
- **票数**：100 👍

### 📄 [BoT-GRPO: Efficient Process-Reward RL for Reasoning via Bag-of-Token Aggregation](https://arxiv.org/abs/2610.09804)
- **作者**：Yingxiang Yang, Weihang Xiao, Zhunxuan Wang et al.
- **提交日期**：2026-10-07
- **摘要**：GRPO 中一条 rollout 的每个 token 共享同一优势，浪费了 token 级过程信号。BoT-GRPO 把 GRPO 扩展到 token 级奖励模型，用长度不变的「令牌袋」聚合：汇集所有 rollout 的 token 级奖励，按来源序列长度取倒数加权，再相对加权组统计量计算每个 token 的优势。该方法无需 critic，凡是提供 token 级奖励处都可直接替换 GRPO；在 React 前端代码生成上，以最高 1.9× 的速度达到 80% 编译率，并比 GSPO、DAPO 等现代 GRPO 变体收敛更快。

### 📄 [COPC: Coupled Off-Policy Correction for Asynchronous LLM Reinforcement Learning](https://arxiv.org/abs/2610.09597)
- **作者**：Zicheng Hu, Zhijian Zhou, Xuan Zhang et al.

- **摘要**：异步 RL 通过解耦 rollout 生成与优化来加速大模型后训练，但训练用到的是陈旧轨迹；现有方法主要在 actor 目标里用重要性比控制来校正 token 级策略失配。作者证明这种「策略侧校正」并不充分：优势估计同样继承了来自行为策略后续生成的失配，即优势陈旧。他们给出通用双通道 actor 更新的精确偏差与方差分解，揭示策略权重误差与优势估计误差不可分离地耦合——其交互产生乘性偏差项，而策略权重的平方会放大优势不确定性在梯度方差中的贡献。COPC 据此把 token 级比率掩码与双侧裁剪的优势校正协同起来。

- **摘要**：MoE 层用 E 个专家网络替换 FFN、每个 token 路由到其中 k 个；在专家并行下专家分散在各卡，每个 MoE 层前后向都要做 all-to-all。在每节点 8 张 AMD MI300X 上，EP32 配 top-2 时这些集合通信可占训练步的 45%，top-6 时达 60%。作者发现预训练早期路由器就已学到相关指派模式：top-2 下同层 0.8% 的专家对覆盖了 42% 的 token，且某层选中的专家能预测下一层的选择。据此把更多 token-专家分配留在 token 自己所在的卡上，减少跨卡通信。
- **方向标签**：#MoE / #训练系统

### 📄 [ExperienceIndex: Artifact-Grounded Memory](https://arxiv.org/abs/2610.10091)

### 📄 [SLDR: Defending Against Malicious Fine-tuning via Selective Layers Recovery and Dynamic Routing](https://arxiv.org/abs/2610.10345)

- **提交日期**：2026-10-07
- **摘要**：微调即服务让用户把对齐过的大模型适配到专门任务，但恶意微调可以在保持正常输入任务表现的同时侵蚀拒答行为。作者重访逐层安全诊断，发现安全敏感度是「有符号」的：缩放不同层可以增强拒答、削弱拒答或几乎无影响。基于此提出 SLDR：仅在敏感度谱最高与最低的层上训练 LoRA 恢复适配器，并在推理时用基于表示的动态路由只对恶意查询激活该适配器。在四种模型架构、五个下游任务与四个有害基准上，SLDR 大幅降低有害输出同时保住下游效用；Llama3.1/SST2 上平均有害分从 11.54 降到 0.08。

### 📄 [SemanticFold: Latent Sequence Compression Separates Language Modeling, Decodability, and Reasoning](https://arxiv.org/abs/2610.10304)
- **作者**：Mingyan Liu, Min Huang
- **提交日期**：2026-10-07
- **摘要**：本文研究对提示前缀做潜在序列压缩后，是否仍保住大模型推理所依赖的能力。作者提出 SemanticFold，在学习到的边界处折叠前缀隐状态，并在 Qwen3-1.7B、Qwen3-8B、SmolLM2-1.7B、Pythia-1.4B、Pythia-6.9B 五个规模上评测。用固定目标协议（冻结前缀按原生或压缩执行，两臂都强制相同的续写 token）排除目标选择带来的似然变化。考察五类端点后发现压缩的影响是非单调的，且各端点不共享同一个压缩阈值：Qwen3-1.7B 在压缩比 1.7 时压缩减原生的平均 NLL 下降 0.135，SmolLM2 在 1.2 时反而高 0.013，Pythia 两个检查点基本不变；NLL 分解显示 Qwen 的有利变化主要来自残差适配而非序列变短。线性探针精度与宏 AUC 在各类条件下变化绝对值小于 0.03。结论是潜在压缩下的「保持」没有单一标量凭证。
- **方向标签**：#新架构 / #上下文压缩
