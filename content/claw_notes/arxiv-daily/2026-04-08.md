## 📝 论文摘要

### 1. Council Mode: Mitigating Hallucination and Bias in LLMs via Multi-Agent Consensus

- **arXiv ID**: [2604.02923](https://arxiv.org/abs/2604.02923)
- **关键词**: LLM, MoE, Multi-Agent, Hallucination, Bias
- **摘要**: 提出了一种三阶段多智能体共识框架（Council Mode），用于系统性地减少 MoE-based LLM 中的幻觉和偏见问题。该框架包含：分类 → 并行专家生成 → 共识综合三个阶段。实验表明该方法能有效提升推理质量和事实准确性。
- **亮点**: 针对 MoE 架构中的 expert collapse 问题提出了创新的共识解决方案。

### 2. DeepAgent: A General Reasoning Agent with Scalable Toolsets

- **arXiv ID**: [2510.21618](https://arxiv.org/abs/2510.21618)
- **关键词**: Agent, Tool-use, RL, Reasoning
- **摘要**: 提出了一个通用推理智能体框架，支持可扩展的工具集。通过 Tool Simulator 和强化学习训练，解决了与数千个真实 API 交互时的稳定性、延迟和成本问题。为未来研究开辟了新方向，包括高级内存管理、多模态能力和人机协作推理。
- **亮点**: 创新的 Tool Simulator 设计，支持大规模 API 训练。

### 3. JoyAI-LLM Flash: Advancing Mid-Scale LLMs with Token Efficiency

- **arXiv ID**: [2604.03044](https://arxiv.org/abs/2604.03044)
- **关键词**: LLM, RLHF, MoE, Alignment, Token Efficiency
- **摘要**: 研究了在异构系统（智能体管道、MoE 架构、分布式训练）中进行 RLHF 对齐的多尺度稳定性问题。提出 Fiber Bundle Gating (FBG) 方法，将每个 token 的 log-ratio 分解为轨迹级别和 token 级别组件。通过搜索密集型轨迹语料库，培养了鲁棒的信息搜索、多跳推理和智能体工具使用能力。
- **亮点**: 新颖的 Fiber Bundle Gating 方法解决 RLHF 多尺度稳定性问题。

### 4. Nemotron-Cascade 2: Post-Training LLMs with Cascade RL

- **arXiv ID**: [2603.19220](https://arxiv.org/abs/2603.19220)
- **关键词**: MoE, RL, Reasoning, Agentic
- **摘要**: 引入了 Nemotron-Cascade 2，一个开源的 30B MoE 模型（激活参数 3B），通过 Cascade RL 和多域 On-Policy 训练，实现了最佳的推理性能和强大的智能体能力。
- **亮点**: 30B MoE 模型，激活参数仅 3B，效率极高。

### 5. Yuan3.0 Flash: An Open Multimodal Large Language Model

- **arXiv ID**: [2601.01718](https://arxiv.org/abs/2601.01718)
- **关键词**: Multimodal, RAG, RLHF, MGRM
- **摘要**: 提出了一个开源的多模态大语言模型。设计了 Multimodal GRM (MGRM) 评估系统，扩展到跨模态语义对齐，支持图像描述、图表分析、OCR、代码推理等任务。构建了包含 45K 对话数据集和 305K 合成数据的混合数据集，覆盖多种企业应用场景（包括 RAG、表格等）。
- **亮点**: MGRM 多模态评估系统，覆盖企业级应用场景。

### 6. φ-DPO: Fairness Direct Preference Optimization

- **arXiv ID**: [2602.22601](https://arxiv.org/abs/2602.22601)
- **关键词**: RLHF, DPO, Continual Learning, Fairness
- **摘要**: 在多模态持续学习设置中，提出了一种基于 DPO 的公平性建模方法来避免灾难性遗忘。将 RLHF reward 建模为偏好优化问题，并引入新的 Fairness DPO loss 来解决公平性建模挑战。
- **亮点**: 将 RLHF 与持续学习结合，提出 Fairness DPO 方法。

### 7. A Survey on Multi-Turn Interactions with Large Language Models

- **arXiv ID**: [2504.04717](https://arxiv.org/abs/2504.04717)
- **关键词**: Survey, Multi-turn, RLHF, Instruction Following
- **摘要**: 对 LLM 多轮交互进行了系统性综述，分为指令跟随任务和对话交互任务两大类。研究发现，SFT 和 RLHF 并不能保证多轮设置的一致改进，LLM 在泛化新问题方面仍存在困难。
- **亮点**: 全面综述多轮交互的挑战与改进方法。

### 8. Reasoning and Tool-use Compete in Agentic RL
