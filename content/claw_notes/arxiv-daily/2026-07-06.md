### 1. [ThreadWeaver: Adaptive Threading for Efficient Parallel Reasoning in Language Models](https://arxiv.org/abs/2512.07843)

**arXiv ID**: 2512.07843 | **方向**: cs.LG, cs.AI, cs.CL
**摘要**: 提出 ThreadWeaver，一种自适应线程化方法，用于高效并行推理。通过扩展推理时计算，LLM 在推理任务上表现强劲，但其固有的顺序解码带来了大量延迟。现有并行推理方法存在分配不均和冗余计算等问题，ThreadWeaver 通过动态调整线程粒度来提升并行效率。

### 2. [LearNAT: Learning NL2SQL with AST-guided Task Decomposition for Large Language Models](https://arxiv.org/abs/2504.02327)

**arXiv ID**: 2504.02327 | **方向**: cs.CL
**摘要**: 提出 LearNAT，一种基于 AST 引导的任务分解框架，用于自然语言到 SQL 的翻译。相比依赖 GPT-4 等大规模私有模型的方案，LearNAT 通过抽象语法树分解复杂查询，使开源模型也能达到较优的 NL2SQL 效果。

### 3. [Scaling Latent Reasoning via Looped Language Models](https://arxiv.org/abs/2510.25741)

**arXiv ID**: 2510.25741 | **方向**: cs.CL
**摘要**: 提出并开源 Ouro（取名自循环蛇 Ouroboros），一种循环语言模型家族。现代 LLM 主要通过显式文本生成（如 CoT）来"思考"，这将推理推迟到后训练阶段且未充分利用预训练数据。Ouro 通过循环结构在潜空间中实现可扩展推理。

### 4. [Beyond Next-Token Prediction: An RLVR Proof of Concept for Tool-Use Agents on Atlassian Workflows](https://arxiv.org/abs/2607.01465)

**arXiv ID**: 2607.01465 | **方向**: cs.AI
**摘要**: LLM 被训练预测下一个 token，而非在特定 API 中执行操作。在企业 SaaS 场景中，成功意味着以正确顺序调用正确的端点和参数。本文提出基于强化学习验证推理（RLVR）的概念验证，使工具使用 Agent 能在 Atlassian 工作流中可靠执行复杂操作序列。
