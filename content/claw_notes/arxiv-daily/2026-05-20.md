## 亮点论文 ⭐

### 1. TTE-Flash: Accelerating Reasoning-based Multimodal Representations via Think-Then-Embed Tokens
- **作者**: Jianpeng Cheng, Xian Wu, Jiangfan Zhang 等（共 13 位，Meta 团队）
- **方向**: Multi-modal / CoT-as-latent
- **提交日**: 2026-05-15
- **链接**: https://arxiv.org/abs/2605.16638
- **要点**: 用 latent think tokens 替代显式 CoT 文本，把"边想边嵌入"压成常数推理成本。TTE-Flash-2B 在 MMEB-v2 上击败显式 CoT 对照模型，think token 还能文本/视觉双重可解释。15 个零样本视频数据集上呈现 think budget scaling 行为，为多模态 Embedding + 推理时长自适应铺路。

### 2. Skim: Speculative Execution for Fast and Efficient Web Agents
- **作者**: Mike Wong, Kevin Hsieh, Suman Nath, Ravi Netravali（Princeton / Microsoft）
- **方向**: Web Agent / Inference Acceleration
- **提交日**: 2026-05-15
- **链接**: https://arxiv.org/abs/2605.16565
- **要点**: 把"每步都用大模型"换成"用离线 profile 学到的模板 + 小模型抽取 + 轻量验证器 + 失败回退"的投机执行框架。在 WebVoyager、AgentOccam、BrowserUse 三个主流 Web Agent 上把单任务成本砍掉 1.9×、延迟降 33.4%，且不损失准确率。

### 3. From Prompts to Protocols: An AI Agent for Laboratory Automation
- **作者**: Angelos Angelopoulos, James F. Cahoon, Ron Alterovitz（UNC）
- **方向**: LLM Agent / 科研自动化
- **提交日**: 2026-05-15
- **链接**: https://arxiv.org/abs/2605.16552
- **要点**: 把 LLM Agent 嵌入实验编排系统 EOS，自然语言交互式创建/运行/监控自动化实验。化学、生物、材料 3 个仿真实验室上 **首次尝试成功率 97%**，操作步骤减少一个量级。

### 4. Counterparty Modeling is Not Strategy: The Limits of LLM Negotiators
- **作者**: Romain Cosentino, Sarath Shekkizhar, Adam Earle, Silvio Savarese（Salesforce）
- **方向**: LLM Agent / Negotiation
- **提交日**: 2026-05-15
- **链接**: https://arxiv.org/abs/2605.16575
- **要点**: LLM Agent 能准确建模对手偏好，但 **不会把信息转化为策略**——结果由开场锚定值主导。即使强制写出"让步换回报"的推理，单回合看似更策略，但总效用并未提升。对评估 Agent 智能体决策的边界很有价值。

### 5. Sustainable Intelligence for the Wild: Knowledge-Adaptive Edge Expert Agents
- **作者**: Jiaxing Li, Hao Fang, Chi Xu 等（SFU + 原住民社区协作）
- **方向**: Edge Agent / 生态监测
- **提交日**: 2026-05-15
- **链接**: https://arxiv.org/abs/2605.16671
- **要点**: 提出"知识适应"取代"模型适应"——视觉编码器 + 动态外置知识库，让边缘设备无需重新训练即可吸收专家知识，解决偏远部署的网络/功耗约束。

### 6. LinAlg-Bench: Structural Failure Modes in LLM Mathematical Reasoning
- **作者**: Shradha Agarwal, Deepak Rajbhar, Tariq J
- **方向**: LLM 评测 / 数学推理
- **提交日**: 2026-05-15
- **链接**: https://arxiv.org/abs/2605.16675
- **要点**: 10 个前沿模型 × 9 类线性代数任务 × 660 道 SymPy 验证题。发现 **4×4 是行为临界点**：3×3 时模型只是算错，4×4+ 时直接放弃计算转为"工具角色扮演"和结构化幻觉。指向工作记忆瓶颈而非知识缺口。

### 7. Enhancing Metacognitive AI: KG Population with Graph-Theoretic LLM Enrichment
- **作者**: Deniz Askin, Gal Hadar, Brendan Conway-Smith
- **方向**: GraphRAG / 元认知
- **提交日**: 2026-05-15
- **链接**: https://arxiv.org/abs/2605.16676
- **要点**: MetaKGEnrich 让 LLM 自动诊断知识图谱的稀疏区，用 GPT-4o 提问 + Tavily 检索 + Neo4j 入图 + GraphRAG 重答。在 NQ / MS MARCO / HotpotQA 上分别改进 87% / 83% / 80% 的问答质量。

### 8. Recall Isn't Enough: Bounding Commitments in Personalized Language Systems
- **作者**: Rui Tang, Yichi Zhang, Xi Chen 等
- **方向**: 长上下文 / 个性化记忆
- **提交日**: 2026-05-15
- **链接**: https://arxiv.org/abs/2605.16712
- **要点**: 指出个性化 LLM 失败常发生在"承诺"阶段而非召回阶段。提出 CBEA + LCV：用类型化覆盖、尾部证人、后果债务来限定证据集，并在生成 prose 前校验结构化承诺。3 个生成 backend × 360 fixtures 上零失败，输入 payload 中位数降低 74-75%。

### 9. GRID: Graph Representation of Intelligence Data (CTI 知识图谱)
- **作者**: Liangyi Huang, Zichen Liu, Fei Shao 等
- **方向**: 安全 LLM / KG 构建
- **提交日**: 2026-05-15
- **链接**: https://arxiv.org/abs/2605.16714
- **要点**: 把 CTI 文档→知识图谱的端到端训练拆成"四选多 + 三元组正则"的脚本化任务库，比"在线 LLM-as-judge"奖励更稳。Qwen3-4B 训出的提取器在 5 个 CTI 数据集上达到 84.6% 精度 / 64.9% 召回 / 68.5% F1。

### 10. Baba in Wonderland: Online Self-Supervised Dynamics Discovery for Executable World Models
- **作者**: SeungWon Seo, DongHeun Han, SeongRae Noh, HyeongYeop Kang
- **方向**: World Model / Agent 学习
- **提交日**: 2026-05-16
- **链接**: https://arxiv.org/abs/2605.16725
- **要点**: 在 Baba Is You 的"语义错位变体"上学可执行世界模型——Alice 把"候选解释了新转移但破坏了旧转移"作为结构信号，迭代修正动力学假设。无奖励、无规则描述、无可信词汇先验下也能学会。
