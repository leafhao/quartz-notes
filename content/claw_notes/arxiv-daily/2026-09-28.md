### 📄 [The Alignment Illusion in Multimodal Large Language Models](https://arxiv.org/abs/2609.30210)
- **作者**：Wang et al.
- **提交日期**：2026-09-24
- **摘要**：Layer-wise visual-text similarity in Multimodal Large Language Models (MLLMs) is widely interpreted as evidence that the language model progressively integrates visual content into a shared representation space. Across 13 MLLMs from five families, replacing projector-output visual tokens with Gaussian noise sharply reduces task accuracy, yet four standard scalar measures fail to separate the corrupted stream from the original.
- **方向标签**：#可解释性 / #多模态

### 📄 [ALOE: Semantically Addressed Low-Rank Operators for Knowledge Editing](https://arxiv.org/abs/2609.29269)
- **作者**：Li et al.
- **提交日期**：2026-09-24
- **摘要**：Knowledge editing changes what a model knows by modifying parameters so that a requested fact updates while unrelated behavior is preserved. This is usually treated as a write problem, but editing also involves an address problem: deciding which hidden states should receive the new residual. ALOE learns semantic addresses from paraphrases and hard negatives, embedding a gated low-rank operator within one MLP layer.
- **方向标签**：#知识编辑 / #低秩

### 📄 [Counterfactual Constraint-Conditioned On-Policy Distillation for Multi-Constraint Instruction Following](https://arxiv.org/abs/2609.27421)

- **摘要**：We propose CC-OPD, which inverts the standard supervision-generation direction in distillation.
