## 精选论文

### ⭐ RAG-Star: Enhancing Deliberative Reasoning with Retrieval Augmented Verification and Refinement

**方向：** RAG + 强化学习

**核心创新：**
- 将检索信息与基于树的深思熟虑推理过程结合
- 利用蒙特卡洛树搜索 (MCTS) 迭代规划中间子查询和答案
- 提出 retrieval-augmented verification，使用查询和答案感知的奖励建模为 LLM 的内在推理提供反馈

**实验结果：** 在 Llama-3.1-8B-Instruct 和 GPT-4o 上显著优于之前的 RAG 和推理方法。

**关键词：** `RAG` `MCTS` `Tree-based Reasoning` `Verification`

---

### ⭐ RAG-Gym: Systematic Optimization of Language Agents for Retrieval-Augmented Generation

**方向：** Agent + RAG 优化

**核心创新：**
- 系统性探索三个优化维度：(1) 提示工程 (2) Actor 调优 (3) Critic 训练
- 提出 Re²Search Agent，结合推理反射 (reasoning reflection)
- 识别 DPO 为最有效的后训练算法
- 训练的 Critic 可通过选择更高质量的中间推理步骤增强推理

**实验结果：** 优化后的 Re²Search++ 在平均 F1 上比 Search-R1 提升 3.2% 至 11.6%。

**关键词：** `Agentic RAG` `Process Supervision` `DPO` `Actor-Critic`

**项目主页：** https://rag-gym.github.io

---

### ⭐ FOCAL: A Novel Benchmarking Technique for Multi-modal Agents

**方向：** 多模态 Agent 基准测试

**核心创新：**
- 针对端到端语音 Agent 的推理能力、组件级错误传播和错误分析进行基准测试
- 支持自动化和人工辅助测试
- 提出两个新指标：Reasoning Score 和 Semantic Score，评估 Agent 进行有意义语音对话的能力

**关键词：** `Multi-modal Agent` `Voice Agent` `Benchmark` `Error Propagation`

### ⭐ Focus Agent: LLM-Powered Virtual Focus Group

**方向：** Agent 应用

**核心创新：**
- LLM 驱动的框架，模拟焦点小组（数据收集）并担任主持人角色
- 评估与 23 名人类参与者的真实焦点小组对比
- LLM 作为主持人在包含人类参与者的焦点小组讨论中展现出改进

**实验结果：** Focus Agent 能够生成与人类参与者相似的意见。

**关键词：** `Focus Group` `LLM Agent` `Moderator` `HCI`

### TEAL: Tokenize and Embed ALL for Multi-modal Large Language Models

**方向：** 多模态 LLM

**核心创新：**
- 将任意模态输入视为 token 序列，学习所有模态的联合嵌入空间
- 使用现有 tokenizer 离散化，通过可学习嵌入矩阵嵌入 token 序列
- LLM 只需自回归预测多模态 token
- 对应的 de-tokenizer 根据预测的 token 序列生成各模态输出

**优势：** 使冻结的 LLM 能够执行涉及非文本模态（如图像、音频）的理解和生成任务。

**关键词：** `Multi-modal LLM` `Joint Embedding` `Tokenization` `Autoregressive`

### Vendi-RAG: Adaptively Trading-Off Diversity And Quality Significantly Improves Retrieval Augmented Generation With LLMs

**方向：** RAG 多样性优化

**核心创新：**
- 基于 Vendi Score (VS) 的迭代框架，联合优化检索多样性和答案质量
- 使用 LLM judge 评估候选答案并输出分数
- 检索器利用该分数平衡相关性和多样性

**实验结果：** 
- HotpotQA: +4.2%
- 2WikiMultiHopQA: +4.1%
- MuSiQue: +1.3%

**关键词：** `Multi-hop QA` `Diversity` `Vendi Score` `Iterative RAG`
