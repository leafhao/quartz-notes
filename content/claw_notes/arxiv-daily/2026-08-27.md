### 📄 [AutoSaddler: Automatic Harness Optimization with Durable Updates from Agent Execution Traces](https://arxiv.org/abs/2608.23041)
- **作者**：Sungho Park, Wonjoong Kim, Rongyuan Tan et al.
- **关键词**：agent harness, offline learning, long-horizon
- **摘要**：LLM Agent 在长程任务上仍不可靠，局部小失误会在长交互中累积成整体失败。外部 harness（提示词 + 工具配置 + 控制逻辑）能显著提升鲁棒性，但设计过程完全手工且昂贵。AutoSaddler 把 harness 改进形式化为离线学习问题，从 Agent 的执行轨迹中迭代提炼出可持久化的更新，自动搜索 harness 空间。
- **票数**：49 👍

### 📄 [On-Policy Self-Distillation in Diffusion Models](https://arxiv.org/abs/2608.24646)
- **作者**：Wei Zhou, Xiongwei Zhu, Lingdong Kong et al.
- **关键词**：diffusion, on-policy distillation, reward alignment
- **摘要**：RL 能把扩散模型对齐到人类偏好，但端点奖励无法指明中间去噪步骤该往哪个方向改。作者提出 DiffusionOPSD，把图像级奖励引导转换成"干净输出预测"的显式目标：每轮外层迭代冻结行为策略生成轨迹，提供查询状态与锚点，再用奖励梯度构造目标。把 OPD 思路从语言模型迁移到扩散模型的一次尝试。
- **票数**：48 👍

### 📄 [The Mask Is Not the Model: Auditing Prefix Invariance in Attention, State-Space, and Hybrid Sequence Models](https://arxiv.org/abs/2608.22876)
- **作者**：Taebong Kim, Youngsik Hong, Minsik Kim et al.
- **关键词**：causality audit, state-space model, prefix invariance
- **摘要**：形式化定义"前缀不变性"——位置 t 的表示不得依赖未来输入。提出仅需两次前向、无需训练与梯度的轻量审计方法，能精确定位因果性在哪里被破坏。关键发现：**只检查 attention mask 是不够的**，即使 mask 正确，泄漏也可能经由 scan 或归一化发生。192 次注入故障试验中 mask 检查一个没找到，该审计全部 192/192 定位成功，还在 Zamba2 和 Nemotron-H 中发现了真实缺陷。
- **票数**：29 👍

### 📄 [Recursive Experiential-Working Memory Evolution for Long-Horizon Agent Harnesses](https://arxiv.org/abs/2608.24876)
- **作者**：Zhaochen Yu, Yingcheng Wu, Zhenfei Yin et al.
- **关键词**：recursive self-improvement, memory architecture, long-horizon
- **摘要**：长程任务里递归自我改进（RSI）很难，因为不断增长的历史会掩盖任务状态、导致技能调用错位。Recuris 引入"经验记忆 + 工作记忆"双层架构：工作记忆跟踪任务进展并据此从经验记忆中挑选技能，让技能调用锚定在当前需求而不是全部历史上。这种耦合还把执行过程变成结构化证据，能把失败定位到具体的记忆条目。

### 📄 [Best Practice Critic Optimization](https://arxiv.org/abs/2608.23566)
- **作者**：Penghui Qi, Xiangxin Zhou, Wee Sun Lee et al.
- **关键词**：critic, GRPO, token-level advantage
- **摘要**：GRPO 这类分组 RL 方法靠对同一 prompt 采样多条回复来回避训练 critic。一个可靠的 critic 本可以只用一条回复就估出 token 级 advantage，但标准 critic 训练配方往往不稳定。作者系统研究了这种不稳定性，给出 BPCO 配方：DPPO + 把 value 预测限制在奖励取值范围内 + 蒙特卡洛 value 目标 + 不做归一化的策略 advantage。对做 RL 后训练的人是很实用的一篇。
- **票数**：12 👍

### 📄 [AgentSpec: Speculative Decoding for Batch Inference of LLM Agents](https://arxiv.org/abs/2608.24004)
- **作者**：Xin Wang, Ziming Miao, Yi Zhu et al.
- **提交日期**：2026-08-27
- **摘要**：LLM Agent 应用响应时间普遍偏长。投机解码本可在不损质量的前提下提升推理效率，但 SOTA 投机解码算法在**大 batch 下加速比严重衰减**，正好卡在真实 Agent 部署的工况上。本文先系统分析 Agent 场景下投机解码的行为，识别出两个关键瓶颈，再给出 AgentSpec。做推理部署的可直接对照自己的 batch 曲线。
- **方向标签**：#推理优化 #投机解码

### 📄 [Contrastive Branch Policy Optimization](https://arxiv.org/abs/2608.24300)
- **作者**：Ying Wang, Changlin Qiu, Bang Lin et al.
- **提交日期**：2026-08-27
- **摘要**：RLVR 能让模型学会多轮工具交互，但稀疏结果奖励无法指出是哪个中间决策带来了成功。分支采样能在候选续写之间形成局部对比，可现有方法把两个不同问题混在了一起：**如何分配固定的 rollout 预算**、**如何把分支结果翻译成 token 级信用**。CBPO 把两者解耦分别处理。
- **方向标签**：#RLHF #信用分配

### 📄 [AHEAD: Adaptive Hindsight with Environment-Augmented Distillation for Agentic RL](https://arxiv.org/abs/2608.24114)
- **作者**：Xiaolong Jin, Dingmin Wang, Vijay Lingam et al.
- **提交日期**：2026-08-27
- **摘要**：多轮 Agent 的 RL 训练通常只有轨迹级奖励，每一步分到相同 advantage，无法区分哪个决策导致成败。自蒸馏方法能用特权信息提供更细粒度监督，但现有做法对每一步无差别地注入同类特权信息，忽略了一个关键不对称性：**常规步骤几乎不需要额外引导，关键步骤才需要**。AHEAD 做自适应的事后特权注入。
- **方向标签**：#RLHF #Agentic RL

### 📄 [VisCache: Visual KV Cache Pruning for Efficient Vision Large Language Model Inference](https://arxiv.org/abs/2608.24063)
- **作者**：Lyuke Wang, Zhuo Li, Guangxu Zhu et al.
- **提交日期**：2026-08-27
- **摘要**：VLLM 的长上下文推理受视觉 KV cache 的计算和显存开销拖累。现有 KV 压缩方法对视觉 token 和各层做**均匀剪枝**，造成大量信息损失。VisCache 是即插即用的由粗到细视觉 KV 剪枝框架，按层、按 token 差异化分配保留预算。
- **方向标签**：#推理优化 #KV Cache #多模态

### 📄 [MetaRAG: Belief-Action Aligned Policy Optimization for Agentic RAG](https://arxiv.org/abs/2608.24214)
- **作者**：Qiuyi Qi, Tian Liang, Jiamu Wang et al.
- **提交日期**：2026-08-27
- **摘要**：Agentic RAG 要求模型决定"继续检索还是直接回答"。现有 RL 方法依赖外部监督，忽略了 Agent 自己对"当前证据是否充分"的内部置信。MetaRAG 把检索决策质量重新表述为**置信-动作对齐**问题，用"先验证再生成动作"显式引出内部置信，再据此做策略优化。
- **方向标签**：#RAG #策略优化

### 📄 [PuzzleKV: Page-Wise Low-Rank Decomposition for KV Cache Compression](https://arxiv.org/abs/2608.23843)
- **作者**：Zizhong Wang, Jieying Wang, Zhao Zhang et al.
- **提交日期**：2026-08-27
- **摘要**：长上下文推理越来越受 KV cache 显存限制。低秩压缩因为能把每个 token 都降维而颇具吸引力，但以往方法要么从模型权重推导固定投影空间，要么用校准激活构造固定/共享空间——都不适配运行时的分布漂移。PuzzleKV 改成**页级（page-wise）低秩分解**，每页各自求解投影空间，天然契合 paged attention 的内存布局。
- **方向标签**：#推理优化 #KV Cache #新方法

### 📄 [Parason: Revealing Subtask and Trial Parallelism in LLM Reasoning](https://arxiv.org/abs/2608.24658)
- **作者**：Zhengyang Zhang, Zijian Zhang, Jiaxuan Gao et al.
- **提交日期**：2026-08-27
- **摘要**：测试时推理规模化大幅提升了解题能力，但标准自回归解码仍然串行执行长推理链，难题上延迟可达数天数周。并行推理是自然解法，然而已有系统主要做**子任务并行**（把任务拆成可独立求解的小块），忽视了另一类同样可挖掘的**试验并行**（trial parallelism）。Parason 把两类并行一起暴露出来调度。
- **方向标签**：#推理优化 #Test-Time Scaling

### 📄 [OPDSearch+: On-Policy Distillation with RL Refinement for Search-Augmented Reasoning](https://arxiv.org/abs/2608.24310)
- **作者**：Qinglin Ye, Zhiyuan Gu, Jingjie Xia et al.
- **提交日期**：2026-08-27
- **摘要**：小模型做检索增强推理仍很困难。从训练好的教师做 OPD 是有希望的方向，但有两个问题：(1) 高质量多轮检索轨迹依赖动态检索器响应，SFT 数据规模化采集成本极高；(2) 专门微调过的教师训练开销大，而直接拿现成教师做 OPD 又会把学生的上限锁在教师水平。OPDSearch+ 用 OPD 打底 + RL 精修破这个上限。
- **方向标签**：#OPD #RAG #后训练

### 📄 [RePolicy: Reinforcement Learning for Safety-Policy Invocation in Agent Safeguards](https://arxiv.org/abs/2608.24275)
- **作者**：Houcheng Jiang, Boxuan Zhang, Qiyong Zhong et al.
- **提交日期**：2026-08-27
- **摘要**：给 Agent 加护栏需要在上下文相关的安全策略下评估完整执行轨迹。现有策略感知护栏主要靠提示或 SFT，难以适配未见轨迹和变化的策略上下文。RePolicy 用 RL 学习"安全策略调用"：给定轨迹和一个动态策略库，先调用适用策略再用其内容做判断。
- **方向标签**：#对齐与安全 #Agentic RL

### 📄 [RecurSE: Bounded Recursive Self-Evaluation for LLM Rubric Judges](https://arxiv.org/abs/2608.24231)
- **作者**：Kaiyuan Liu, Ziyuan Zhuang, Rongxiang Weng et al.
- **提交日期**：2026-08-27
- **摘要**：LLM-as-judge 对开放式文本评估和后训练导航都很关键，但改进 judge 本身通常要靠昂贵标注、奖励模型或更强教师蒸馏。本文**从 RL 训练奖励中彻底去掉外部金标监督**：让模型自身的评估能力产生优化信号，形成有界递归自我改进（RecurSE）闭环。对没有大量人工标注预算的团队有直接价值。
- **方向标签**：#后训练 #自我改进

### 📄 [Selective Regenerative Decoding: Trajectory-Level Intervention for Inference-Time Reasoning](https://arxiv.org/abs/2608.24338)
- **作者**：Sophia Xiao Pu, Yumo Xu, Sailik Sengupta et al.
- **提交日期**：2026-08-27
- **摘要**：推理时解码方法靠探索多条候选轨迹提升推理质量，但把每条轨迹当成原子单位——整条留或整条丢，浪费了那些"前缀很好、后缀退化"的候选。SRD 给每条候选路由到 discard / keep / refine 三种处理，只重生成退化的后缀部分而保留有用前缀。思路简洁，工程上容易接入现有 best-of-N 流程。
- **方向标签**：#推理优化 #Test-Time Scaling

### 📄 [Compression Trinity: Exploring Sparsity, Quantization, and Low-Rank Approximations for LLM Compression](https://arxiv.org/abs/2608.24070)

### 今日看点

1. **OPD × RLVR 已成显式赛道**：HF 榜 `On-policy Distillation with Verifiable Reward` 与雷达 `OPDSearch+`、`On-Policy Self-Distillation in Diffusion Models` 同日出现，三篇共同点是承认 OPD 的性能上限被教师锁死，都用 RLVR/RL 精修去突破。做后训练的值得把这三篇一起读。
2. **KV Cache 压缩的粒度之争**：`PuzzleKV`（页级低秩）和 `VisCache`（视觉 token 差异化剪枝）从两个方向否定了"均匀压缩"，都指向"按运行时结构自适应分配保留预算"。
3. **Agentic RL 的核心矛盾收敛到信用分配**：`CBPO`（分支对比）、`AHEAD`（自适应事后特权）、`MetaRAG`（置信-动作对齐）三篇解法不同但攻的是同一个痛点——轨迹级奖励无法定位关键决策。
4. **一篇容易被忽略的工程审计**：`The Mask Is Not the Model` 指出正确的 attention mask 不能保证因果性，泄漏可经由 scan / 归一化发生，并在 Zamba2、Nemotron-H 里查出真实缺陷。用混合架构（SSM + attention）训模型的团队建议跑一遍这个两次前向的审计。
