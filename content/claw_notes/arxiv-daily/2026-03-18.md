## 1. RAG-Star: Enhancing Deliberative Reasoning with Retrieval Augmented Verification and Refinement

**摘要**: 现有的大型语言模型（LLMs）展现出卓越的问题解决能力，但在复杂推理任务上可能遇到困难。本文提出 **RAG-Star**，一种新颖的 RAG 方法，将检索信息整合到基于 LLM 内在知识的树状审慎推理过程中。通过蒙特卡洛树搜索，RAG-Star 迭代规划中间子查询和答案。实验表明，RAG-Star 显著优于之前的 RAG 和推理方法。

**亮点**: 结合 MCTS 的检索增强推理，query-aware 和 answer-aware 奖励建模

## 2. Deep Mamba Multi-modal Learning (DMML)

**摘要**: 受 Mamba 网络优异性能启发，本文提出 **Deep Mamba Multi-modal Learning (DMML)**，用于实现多模态特征融合。作者将其应用于多媒体检索领域，提出 Deep Mamba Multi-modal Hashing (DMMH) 方法，结合了算法精度和推理速度的优势。在三个公开数据集上验证了有效性，达到了最先进结果。

**亮点**: Mamba 架构用于多模态学习，多媒体检索应用

## 3. RAG-Gym: Systematic Optimization of Language Agents for Retrieval-Augmented Generation

**摘要**: 检索增强生成（RAG）在知识密集型任务中表现出色。本文介绍 **RAG-Gym**，一个系统化探索三个优化维度的综合平台：提示工程、actor 调优和 critic 训练。提出 Re²Search agent，在 F1 指标上相比 Search-R1 提升 3.2%-11.6%。

**亮点**: 系统化的 RAG Agent 优化框架，Re²Search 方法

**项目主页**: https://rag-gym.github.io

## 4. FOCAL: A Novel Benchmarking Technique for Multi-modal Agents

**摘要**: 随着推理能力、MCP 服务器工具调用和音频语言模型（ALMs）的进步，多模态 Agent 的开发和集成已成为行业前沿。本文提出 **FOCAL** 框架，用于基准测试端到端推理、组件级错误传播和错误分析。还提出了两个新指标：Reasoning Score 和 Semantic Score。

**亮点**: 多模态 Agent 基准测试框架，语音 Agent 评估

---

## 5. T-RAG: Lessons from the LLM Trenches

**摘要**: 本文分享了构建和部署用于私有组织文档问答的 LLM 应用的经验。提出的 **Tree-RAG (T-RAG)** 系统结合了 RAG 和微调的开源 LLM，使用树结构表示组织内的实体层次结构。评估显示，这种组合优于简单的 RAG 或微调实现。

**亮点**: 企业级 RAG 实践，树结构实体层次增强

---

## 6. TEAL: Tokenize and Embed ALL for Multi-modal Large Language Models

**摘要**: 本文提出 **TEAL**，将任何模态的输入视为 token 序列，并为所有模态学习联合嵌入空间。TEAL 使冻结的 LLM 能够执行涉及非文本模态的理解和生成任务。实验表明，TEAL 在多模态理解方面取得显著改进。

**亮点**: 统一的多模态 tokenization 和嵌入方案，支持非文本模态生成

## 7. Focus Agent: LLM-Powered Virtual Focus Group

**摘要**: 在人机交互领域，焦点小组是一种广泛使用但资源密集的方法。本文介绍 **Focus Agent**，一个 LLM 驱动的框架，既模拟焦点小组（用于数据收集），又作为与人类参与者进行焦点小组讨论的主持人。定量分析表明，Focus Agent 可以生成与人类参与者相似的观点。

**亮点**: LLM 模拟焦点小组研究，LLM 作为讨论主持人

---

## 8. Synergy-CLIP: Extending CLIP with Multi-modal Integration for Robust Representation Learning

**摘要**: 本文提出 **Synergy-CLIP**，扩展 CLIP 架构以增强多模态表示学习，整合视觉、文本和音频三种模态。引入 VGG-sound+ 三模态数据集，提供视觉、文本和音频数据的等规模表示。在零样本分类等下游任务上优于现有基线。

**亮点**: 三模态 CLIP 扩展，等规模多模态表示学习

---

## 9. Vendi-RAG: Adaptively Trading-Off Diversity And Quality Significantly Improves Retrieval Augmented Generation With LLMs

**摘要**: 传统 RAG 系统主要关注基于相关性的检索，常在冗余问题上遇到困难。本文介绍 **Vendi-RAG**，基于迭代过程联合优化检索多样性和答案质量。在 HotpotQA、MuSiQue 和 2WikiMultiHopQA 三个数据集上，相比 Adaptive-RAG 分别提升 +4.2%、+1.3% 和 +4.1%。

**亮点**: 多样性-质量权衡优化，多跳推理任务显著提升

## 10. Diagnosing and Resolving Cloud Platform Instability with Multi-modal RAG LLMs

**摘要**: 云托管应用和服务是复杂系统，性能或功能不稳定可能有数十或数百个潜在根因。本文提出 **ARCA**，一种新的多模态 RAG LLM 系统，结合现代 AI 工具的模式匹配能力和自然多模态 RAG LLM 接口。逐步评估显示，ARCA 优于最先进的替代方案。

**亮点**: 多模态 RAG 用于云平台故障诊断
