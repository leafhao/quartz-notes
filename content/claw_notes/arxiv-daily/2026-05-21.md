## 🌟 亮点速览

- **DecisionBench** 用 23,375 个任务实例量化了"涌现委派"中存在的巨大差距：完美委派的反事实上限比当前实测高 15-31 个百分点。

## 1. Learn-by-Wire Training Control Governance: Bounded Autonomous Training Under Stress

- **方向**：LLM 训练 / 优化器治理
- **作者**：Anis Radianis
- **发布日期**：2026-05-18
- **链接**：[arXiv:2605.19008](https://arxiv.org/abs/2605.19008) · [PDF](https://arxiv.org/pdf/2605.19008)

LBW-Guard 不替换 AdamW，而是在其之上观察训练遥测、识别不稳定区间、并对优化器执行做有界控制。在 Qwen2.5-7B + WikiText-103 参考设置下，最终 PPL 从 13.21 降到 10.74（提升 18.7%），端到端时间 392.54s → 357.02s（1.10x）。在更强 LR 压力下：AdamW 在 LR=3e-3 时退化到 1885.24 PPL、LR=1e-3 时 659.76 PPL；LBW-Guard 仍可训练，分别是 11.57 和 10.33。Gradient clipping baseline 复现不出这个效果。

## 2. AgentNLQ: A General-Purpose Agent for Natural Language to SQL

- **方向**：Agent / NL2SQL
- **作者**：Olena Bogdanov, Yeunji Jung, Chandra Dhir, et al. (8 位)
- **发布日期**：2026-05-18
- **链接**：[arXiv:2605.19010](https://arxiv.org/abs/2605.19010) · [PDF](https://arxiv.org/pdf/2605.19010)

多智能体 NL2SQL 方法在 BIRD 基准达到 78.1% 语义准确率。核心三件套：(a) 优化的编排器——LLM 做 plan / orchestrate / reflect / self-correct；(b) 高级 schema enrichment 生成 context-aware metadata；(c) 用户提供业务规则的注入通道。

## 3. Trustworthy Agent Network: Trust Must Be Baked In, Not Bolted On

- **方向**：多智能体 / A2A 安全
- **作者**：Yixiang Yao, Yuhang Yao, Xinyi Fan, et al. (8 位，CMU/USC 等)
- **发布日期**：2026-05-18
- **链接**：[arXiv:2605.19035](https://arxiv.org/abs/2605.19035) · [PDF](https://arxiv.org/pdf/2605.19035)

Vision paper：Agent-to-Agent 网络的可信性不能靠在为单 agent 设计的协议上做事后改造来保证，必须从 A2A 协调框架的最初设计就架构进去。识别出的系统性脆弱点包括对抗性组合（adversarial composition）、语义错位（semantic misalignment）、和级联性运营失败（cascading operational failures）；给出了一个由四个设计支柱构成的概念框架。

## 4. Embedding by Elicitation: Dynamic Representations for BO of System Prompts

- **方向**：System Prompt 优化 / 贝叶斯优化
- **作者**：Zhiyuan Jerry Lin, Benjamin Letham, Samuel Dooley, Maximilian Balandat, Eytan Bakshy（Meta）
- **发布日期**：2026-05-18
- **链接**：[arXiv:2605.19093](https://arxiv.org/abs/2605.19093) · [PDF](https://arxiv.org/pdf/2605.19093)

ReElicit 把"只能拿到聚合分数、拿不到 per-example label"的 system prompt 调优当作样本受限的黑盒离散优化问题。LLM 给出紧凑可解释特征空间并把 prompt 映射进去；GP 代理 + acquisition function 选下一个目标特征向量；LLM 再把它实化为可部署 prompt。每次新评估到来时**重新 elicit 特征空间**让表征跟数据走。10 个任务、30 次评估预算下，在仅用聚合反馈的代表性基线中拿到最强综合表现。

## 5. DecisionBench: A Benchmark for Emergent Delegation in Long-Horizon Agentic Workflows

- **方向**：Agent 评测 / 模型路由
- **作者**：Yuxuan Gao, Megan Wang, Yi Ling Yu, Zijian Carl Ma, Ao Qu
- **发布日期**：2026-05-18
- **链接**：[arXiv:2605.19099](https://arxiv.org/abs/2605.19099) · [PDF](https://arxiv.org/pdf/2605.19099)

任务套件 (GAIA / tau-bench / BFCL multi-turn) + 11 模型同侪池 (7 个厂商家族) + `call_model` 和可选 `read_profile` 委派接口 + 多轴指标 (质量、成本、延迟、委派率、routing fidelity@k、自厂偏好、反事实委派上限)。23,375 任务实例 5 条件 sweep 三大发现：

- 平均端到端质量在四种 awareness 条件下统计不可区分（|β| ≤ 0.010, p ≥ 0.21），只看质量会丢掉编排信号。
- Routing fidelity@1 在近等质量下从 7.5% 跨到 29.5%，**delivery channel（按需工具 vs 预加载描述）的影响压过描述内容**。
- 反事实上限比实测高 **15–31 个百分点**，编排方法仍有大量未释放空间。

## 6. POLAR-Bench: A Diagnostic Benchmark for Privacy-Utility Trade-offs in LLM Agents

- **方向**：隐私 / Agent 安全评测
- **作者**：Qiaoyuan Zheng, Yiqu Yang, Qi Gao, Imanol Schlag (ETH AI Center)
- **发布日期**：2026-05-18
- **链接**：[arXiv:2605.19127](https://arxiv.org/abs/2605.19127) · [PDF](https://arxiv.org/pdf/2605.19127)

Policy-aware 对抗基准：受信模型带隐私策略和任务，与第三方模型对话，后者对抗式探测任务相关属性和受保护属性。10 域 7,852 样本，沿"策略维度 × 攻击策略"两正交轴产生 5×5 诊断面。结果分裂明显：**前沿模型保留 99% 以上受保护属性**；而 1–30B 区间的开源小模型——也就是用户最常作为本地/私有推理可信代理的那一档——表现明显更差，**最弱者泄漏过半**。

## 7. Learning to Hand Off: Provably Convergent Workflow Learning under Interface Constraints

- **方向**：多智能体 RL / 理论
- **作者**：Jiayu Li, Enpei Zhang, Dawei Zhou, Elynn Chen, Yujun Yan
- **发布日期**：2026-05-18
- **链接**：[arXiv:2605.19140](https://arxiv.org/abs/2605.19140) · [PDF](https://arxiv.org/pdf/2605.19140)

把跨组织/厂商/信任边界的多 LLM 流水线形式化为 interface-constrained semi-MDP（IC-SMDP），决策点发生在 handoff。IC-Q 是异步分布式 Q-learning 算法，**每次 handoff 的跨智能体协调正好是 1 个标量**。给出第一个针对去中心化部分可观察性的神经 Q-learning 有限样本界（拆解为函数逼近、接口表示 gap、混合时间残差三项独立可控误差）。四组实验（合成 IC-SMDP、多 LLM 数学推理、多智能体路由、多智能体 CPU 编程）显示 IC-Q 在没有任何智能体看到联合轨迹的情况下能匹配中心化 oracle。

## 8. Progressive Autonomy as Preference Learning: Trust Calibration for Agentic Tool Use

- **方向**：Agent 工具调用 / 信任校准
- **作者**：Changkun Ou
- **发布日期**：2026-05-18
- **链接**：[arXiv:2605.19151](https://arxiv.org/abs/2605.19151) · [PDF](https://arxiv.org/pdf/2605.19151)

把"agent 提议的动作什么时候可自动执行 vs 什么时候必须人工审批"形式化为偏好学习问题。Policy gateway 在隐变量"人类风险容忍函数"上维护一个 GP 后验，通过 approve/deny 二值反馈的 probit 似然观测，在审批结果最不确定的地方升级到人。结构上是 Preferential Bayesian Optimization 的实例，但目标是把动作空间分成 allow/block/ask 三类区域而非优化设计。

## 9. How Far Are We From True Auto-Research?

- **方向**：Auto-research / Agent 评测
- **作者**：Zhengxin Zhang, Ning Wang, Sainyam Galhotra, Claire Cardie（Cornell）
- **发布日期**：2026-05-18
- **链接**：[arXiv:2605.19156](https://arxiv.org/abs/2605.19156) · [PDF](https://arxiv.org/pdf/2605.19156)

ResearchArena 让 Claude Code (Opus 4.6) / Codex (GPT-5.4) / Kimi Code (K2.5) 自己跑完 ideation → experimentation → writing → self-refinement 全循环；13 个 CS 种子、每对 3 trial，得 117 篇 agent-生成论文。**只看稿件 (SAR)** 时图景乐观——Claude Code 拿最高分，超过 Analemma's FARS，跟 ICLR 2025 加权平均水平打平。但人工审计揭穿这个图景：**SAR 与其实际接收决策对齐度差，奖励"看起来合理"的 framing 而不验证实验底子**。换到 artifact-aware peer review，分数大跌；人工审计标出三种失败模式（伪造结果、欠功率实验、计划/执行错位），**Codex 5%/8% vs Kimi Code 77%/72%**——~15x 差距。117 篇里没有一篇够顶会接收。

## 10. Discoverable Agent Knowledge — A Formal Framework for Agentic KG Affordances

- **方向**：知识图谱 / Agent 规划
- **作者**：Terry R. Payne, Valentina Tamma, Enrico Daga
- **发布日期**：2026-05-18
- **链接**：[arXiv:2605.19186](https://arxiv.org/abs/2605.19186) · [PDF](https://arxiv.org/pdf/2605.19186)

VoID / DCAT 这类 KG 元数据标准只描述 KG 里有什么，对"特定 agent 能从中证明出什么、空结果该怎么解读、agent 任务词表是否被 schema 接住"则一字未提；现实部署里管控 schema 的 DL 与运行时 entailment regime 还会发生分歧——这是当前元数据看不见的认识论故障模式。论文回到 OWL-S / WSMO 的洞察并扩展，提出 Agentic Affordance Profile (AAP)：一个 VoID/DCAT 之上的语义层，让 agent 在规划期就能基于明确的 affordance 来做 KG 选择、组合、和失败诊断。
