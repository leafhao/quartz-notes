### 📄 [Scaling Properties of Same-Family On-Policy Distillation](https://arxiv.org/abs/2609.32722)
- **作者**：Yuntai Bao et al.（浙江大学）
- **关键词**：on-policy distillation, weak-to-strong, scaling law, RL
- **摘要**：系统研究同族 on-policy 蒸馏（OPD）在弱→强、同基座、强→弱三种师生配置下的规模规律。发现早期训练普遍存在「有效迁移」区间：留存准确率随与初始化的 token 级反向 KL 散度的平方根近似线性上升；所有弱→强配对中学生的峰值成绩都超过教师本身，说明紧凑的 RL 专家可把能力迁移给大得多的学生。作者进一步拟合峰值成绩与迁移斜率随师生参数量、教师成绩的幂律关系，指出教师规模带来的收益存在饱和点。

### 📄 [VoxMem: Benchmarking Multimodal Memory in Large Audio Language Models](https://arxiv.org/abs/2609.32607)
- **作者**：Yang Xiao et al.（墨尔本大学）
- **关键词**：memory benchmark, large audio language models, multimodal memory
- **摘要**：语音对话系统中的记忆不止于「说了什么」，还包括谁说的、怎么说的、以及环境里能听到什么——这些信息只存在于音频信号中，无法从转写文本恢复。此外记忆还要求多样操作（检索单个事实、跨轮整合证据、跟踪演化状态），而真实交互跨多个会话累积。现有基准在这三个维度上均不足：偏重词汇内容、操作类型有限且临时、把记忆当作单会话问题。本文提出按「声学证据类型 × 记忆操作类型」两轴划分的分类法，并据此构建 VoxMem：3,196 个评测实例、34,743 个语音会话。
- **票数**：125 👍

### 📄 [Periodic Weak Spots: Phase Sensitivity from Chunked KV-Cache Compression](https://arxiv.org/abs/2609.36322)
- **作者**：Xingyu Zhu et al.（ByteDance Seed）
- **关键词**：KV cache compression, phase sensitivity, long-context retrieval
- **摘要**：分块 KV cache 压缩以固定步长把连续 token 窗口压成更少的缓存条目，同时引入一个新的位置坐标——token 相对于压缩窗口边界的「相位」。作者发现这类模型存在系统性不对称：同一条信息在某些相位容易检索、在另一些相位则困难，称为相位敏感。在采用该压缩的大型开放权重模型中，长上下文检索准确率跨相位相差可达 40 个百分点，说明均值基准分数会掩盖周期性弱点。作者从头预训练一族 Transformer 复现该现象，并用因果干预做机制分析，发现不同注意力组件对检索的贡献存在相位专门化。
- **票数**：96 👍

### 📄 [Overcoming Scaling Limits in On-Policy Self-Distillation for LLM Reasoning](https://arxiv.org/abs/2609.37915)
- **作者**：Md. Ismail Hossain et al.
- **提交日期**：2026-09-29
- **摘要**：On-policy 自蒸馏（OPSD）让学生在自己的采样轨迹上对齐一个特权教师分布。标准 OPSD 在**未验证**的学生轨迹上施加监督，同时让教师以特权上下文（通常是参考解答）为条件。作者把这两个角色做因子分析拆解，发现脚手架正确性对下游准确率的影响强于上下文正确性：未验证的脚手架会制造「模仿鸿沟」，因为教师使用了学生拿不到的信息；该鸿沟随模型变大而缩小，但 OPSD 仍在监督大量未验证轨迹。而验证过的脚手架即使以学生自己失败的 rollout 作为教师上下文仍有效。据此提出 OASIS：保留 OPSD 目标，但主要监督按标签验证过的 on-policy 轨迹，并用模型自己未经验证的尝试取代书面解答作为教师上下文，因此只需最终答案标签。在 Qwen3-1.7B/4B/8B 与 AIME 2024、AIME 2025、HMMT 2025 上平均提升 3.2–3.8 分，而 OPSD 的增益从 1.7B 的 3.05 分衰减到 8B 的 0.14 分；8B 上 OASIS 比 OPSD 高 3.05 分。
- **方向标签**：#后训练 / #自蒸馏

### 📄 [Cool the Sampler, Not the Learner: Sampling Temperature Moves the Staleness Cliff of Importance-Corrected GRPO](https://arxiv.org/abs/2609.36953)
- **作者**：Taiheng Pan
- **提交日期**：2026-09-29
- **摘要**：生产环境的语言模型 RL 允许采样器落后于学习器，并用截断重要性权重修正由此产生的错配。作者追问在保持该修正的前提下采样器可以多久不刷新，发现存在悬崖：在 Qwen2.5-Math-1.5B 与 GSM8K 上，每 192 次更新刷新一次的重要性修正 GRPO 能正常学习 180 步，随后在三个数据种子上全面严重退化。已发表的对策都作用于更新，作者改为作用于采样器——「解耦降温」：采样温度取 0.8，而学习器、参考模型与重要性权重保持温度 1，行为概率按退火后的分布记录，学习器目标不变。降温后所有运行都稳定；在相同更新预算下，每 192 步刷新一次的降温采样器追平每 96 步刷新一次的未降温采样器（训练末段均为 0.857），而把学习率降到安全值则低 3–7 分。该收益存在窗口。
- **方向标签**：#后训练 / #GRPO / #重要性采样

### 📄 [Learn from the Gap: Differential-Aware Advantage Pruning with Adaptive Rollout Sampling for GRPO](https://arxiv.org/abs/2609.36932)
- **作者**：Jiahua Yang et al.
- **提交日期**：2026-09-29
- **摘要**：GRPO 及其变体表现亮眼，但因每题多 rollout 采样、跨 rollout 重复计算每 token 概率而带来可观开销；此外低信息量或高度同质的轨迹会降低下游学习信号效率，妨碍优化并限制最终性能。作者提出即插即用框架 FastRL：(1) 优势感知剪枝，选择性保留高优势轨迹，同时最大化轨迹间梯度多样性；(2) 自适应 rollout 采样，依据历史剪枝分布在训练不同阶段动态调整采样规模，平衡探索充分性与计算效率。实验表明 FastRL 可无缝接入 GRPO、DAPO、GSPO，在 Geometry3K 与 GeoQA8K-R1V 上平均训练加速 2.07×，视觉推理基准平均准确率提升约 1.64%。
- **方向标签**：#后训练 / #训练效率

### 📄 [Prompts Live on an Arc: Gaussian Curricula in Fisher--Rao Coordinates for Rollout-Efficient GRPO](https://arxiv.org/abs/2609.38018)
- **作者**：Mei Okonkwo et al.
- **提交日期**：2026-09-29
- **摘要**：GRPO 只从采样结果存在分歧的 prompt 上学习：全对或全错的组奖励方差为零，不贡献梯度却照样消耗 rollout。现有 prompt 选择方法把采样导向中间通过率以减少浪费，但目标值、带宽与不确定性模型都在原始通过率或 logit 坐标中靠启发式选取。作者指出 GRPO 自带一个通过率的自然坐标——Bernoulli Fisher–Rao 流形上的弧长 ψ=arcsin√p。在弧长下，期望 GRPO 更新除两段边界斜坡外是均匀的；零方差组的概率被两条宽 1/√(2G) 的高斯边界层界定；通过率证据噪声恒定；pass@k 与 pass^k 目标的梯度是中心与宽度可由 k 闭式给出的高斯。于是 GRPO 的 prompt 课程在弧长上就是一条高斯，选择其中心等价于选择目标。据此实现 ARCUS：用 Kalman 滤波在弧长上跟踪每个 prompt，以目标匹配的高斯核乘以有效组预测概率打分，只保留有效组供原 GRPO 更新使用，并把目标节奏性地推向「预测产出与最优差距在很小松弛内」的最难目标。
- **方向标签**：#后训练 / #数据工程 / #课程学习

### 📄 [KV-Kaizen: Learning Context-Adaptive Cache Compression Choices](https://arxiv.org/abs/2609.37988)
- **作者**：Joao Monteiro et al.（Google DeepMind）
- **提交日期**：2026-09-29
- **摘要**：随上下文增长，KV cache 的体积可能超过为模型权重分配的内存；解码又是访存受限的，成本随 cache 规模上升。近期工作靠丢弃最不相关的 token 缓解该瓶颈，但驱逐存在张力——一次性决定可能事后反噬。作者转而关注无需驱逐 token 的压缩路径：学习一个选择器，依据上下文为每层产出 cache 配置以达成整体压缩预算，三个轴分别是跨层共享同一 cache（深度）、以更低比特缓存（精度）、截断低秩潜在表示（秩）。单独且各层统一地施加这些干预会因精度损失限制可达压缩率；而按上下文局部、自适应地组合它们可在保住精度的同时大幅省显存。选择器在推理时只需在 prefill 前运行一次；在指令遵循与推理任务上，其准确率—cache 体积曲线达到 Pareto 前沿。
- **方向标签**：#推理优化 / #KV 缓存

### 📄 [WUSH-KV: KV Cache Quantization with Data-Adaptive Transforms](https://arxiv.org/abs/2609.38121)
- **作者**：Jiale Chen et al.（ETH Zurich / ISTA）
- **提交日期**：2026-09-29
- **摘要**：KV cache 的显存与带宽开销随上下文长度和批大小增长，制约高效长上下文推理。本文提出低比特 KV cache 量化方法 WUSH-KV，改造 WUSH——用矩阵乘积两个因子的二阶统计量构造数据感知变换以降低量化误差——为 key 与 value 分别用校准数据构造变换：value 变换折进模型权重，key 变换在 RoPE 之后施加，并可与裁剪量化器配合。对其中一种量化器 QuEST INT，作者证明在温和假设下 WUSH 变换近最优。集成进 SGLang（OSCAR 风格百分位裁剪仿射量化）后，2-bit 下在所有评测模型与下游任务上持平或优于 OSCAR 变换，并取得最低的端到端困惑度。
- **方向标签**：#量化 / #KV 缓存

### 📄 [LongSpark: Efficient speculative decoding with a fixed-cost parallel drafter](https://arxiv.org/abs/2609.37029)
- **作者**：Hao-Yuan He et al.
- **提交日期**：2026-09-29
- **摘要**：投机解码通过单次目标模型前向验证多个草稿 token 来加速自回归推理，但随上下文增长，现有最优草稿器越来越昂贵，反而侵蚀了它本应带来的效率优势。作者认为这种随前缀增长的开销没有必要：独立语言模型必须随前缀增长，因为它要独自负责产出的每个 token；而草稿器只提出候选，错误都会被目标模型捕获并纠正，因此其解码成本可完全独立于前缀长度。LongSpark 用一个块扩散草稿器实现这一点：从目标模型的验证前向中抽取固定尺寸的多尺度视图，从而无需持续增长的常驻状态。大量评测显示，其在多种模型规模和真实服务条件下达到端到端 SOTA 效率，长上下文任务上 time-per-output-token 最低，同时草稿器的上下文状态减少数个数量级。
- **方向标签**：#推理优化 / #投机解码

### 📄 [$S^3$: Spectral Null-Space Swap Makes Reasoning Models Efficient](https://arxiv.org/abs/2609.37976)
- **作者**：Hongbo Ma et al.
- **提交日期**：2026-09-29
- **摘要**：经思维链训练的 LLM 推理能力强，但 token 开销常常过大。作者发现推理能力的核心，位于 Thinking 模型权重中「由对应 Non-thinking 模型的主奇异方向所定义投影的零空间」分量里，移除该子空间分量可在不损害 thinking 模式后训练所获准确率的前提下大幅提升推理效率。与多数在主子空间内做文章的工作不同，这是首次揭示零空间的关键作用并将其用于模型优化。据此提出 Spectral Null-Space Swap（S³）：一种免训练地组合成对 Non-thinking 与 Thinking checkpoint 的方法——让 Non-thinking 模型留在自己的主子空间内，把 Thinking checkpoint 的主子空间之外的成分取出来。在 2B–30B 的稠密与 MoE 架构、覆盖数学、多模态与音频推理的 28 个评测环境上，S³ 在免训练模型组合策略中建立新的经验 Pareto 前沿：相比完整 Thinking 模型平均减少 27.4% 推理 token 开销，同时整体准确率提升 1.0 个百分点（例如 HMMT25 上准确率 +8.3% 且 token 开销降 33%）。
- **方向标签**：#推理优化 / #模型组合

### 📄 [Learning Meta-Skills for Agent Harness Design in Test-Time AI4AI](https://arxiv.org/abs/2609.38143)

### 📄 [Selecting What Matters: Semantic Compression-Guided Selective Pooling for Long-Context Embeddings](https://arxiv.org/abs/2609.37782)
- **作者**：Zifeng Cheng et al.
- **提交日期**：2026-09-29
- **摘要**：LLM 作为免训练长文本编码器潜力显著。现有方法主要改善因果注意力下的信息流，但通常对所有 token 表示做均匀平均来构造嵌入；对长文档而言，这种均值池化会让大量冗余或弱信息内容稀释关键语义。为此作者提出免训练框架 SCSP：先把文档切成句子感知的块，并为每个块追加一个语义压缩提示；用提示隔离的注意力掩码在保留文档 token 之间信息流的同时，把每个提示限制在其对应的局部上下文中。随后用这些提示引出的注意力模式估计 token 重要性，选出信息量大的 token，并将其中间层表示聚合为最终嵌入。在长上下文嵌入基准上的大量实验表明，SCSP 可以即插即用地接入零样本与微调模型，并稳定提升其性能。
