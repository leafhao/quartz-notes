### 阿里云：Qwen4-Max-Preview 上架百炼，只走套餐

- 是什么：**通义千问新一代旗舰多模态模型**，Model ID `qwen4-max-preview`。文本生成 + 图片/视频理解 + 深度思考三合一，定位编程开发、办公、前端设计与复杂智能体任务；支持联网搜索、Function Calling 与内置工具、JSON Object / JSON Schema 结构化输出。
- 规格：**上下文 1M token**；最大输出 **393,216 token**，且**思考与最终回答共享这一预算**；思考默认开启，`reasoning_effort` 可选 `low` / `medium` / `xhigh`（默认 xhigh），不能与 `thinking_budget` 同时设置。

## 国外厂商

### Google：Gemini Decision 1 与 Decisions API，只出概率不出字

- 位置：`blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/`（**Nov 11, 2026**，作者 Min Choi、Felix Yu）；`ai.google.dev/gemini-api/docs/changelog` 同日 **November 11, 2026** 段落一条对应。
- 是什么：模型 `gemini-decision-1` 不做自回归生成，而是**对候选选项做单次前向打分**，返回 **0–1 的概率与置信度**。面向封闭集合决策：工具选择、策略检查、模型路由、内容评分。
- 三类题型可在**同一请求内混用**：① yes/no（可带 true/false 判定描述）；② choice（**2–255 个选项**，返回胜者与各候选归一化概率）；③ score（从 0 起的有序评分，返回连续加权分与各级概率）。
- 规模与价格：单次最多 **1,000 个独立问题**、最多 **256K 输入 token**；输入 **$0.10 / 百万 token**，**输出 token 计费为 0**（共享输入每请求只计一次，问题数不影响输入计费）。
- 延迟：端到端 **150–250 ms**，模型计算中位 **50–100 ms**；在 1 到 100 个问题时延迟「几乎持平」（16K token 以内适用）。
- 校准：官方称「校准误差最低」，在 agent 路由、推理、排序、多模态理解等多套基准上领先——**但正文没给具体基准名与百分比**，只有图表。
- 成本对照：官方称在共享基准套件上比 **Gemini 3.5 Flash-Lite + Interactions API 便宜近 5 倍**。
- 可用性：Gemini API（`api_version=v1beta`）、AI Studio 有免费层；官方生态已接 OpenRouter、LangChain、Vercel、LiteLLM、Pydantic AI、Pipecat、LiveKit、OpenCode；Gemini in Google Cloud「即将」。
- 内部用例：Gemini Notebook 用它做实时模型路由，官方称日常查询延迟最多降 **40%**；Google Labs 的 CC 从 **200+ 表情库**里挑表情。
- 怎么读：这不是「又一个更聪明的模型」，而是把**决策从生成里剥离**——输出短、便宜、可校准，正好卡在 agent 编排最贵的那一环（每步都要选工具/选模型）。对做 agent 的团队，值得先算一笔路由成本。

### Google DeepMind：AlphaGenome 2 从组织平均走向单细胞

- 位置：`deepmind.google/blog/alphagenome-2-deciphering-how-cells-read-dna-to-better-understand-disease/`（**Nov 11, 2026** 15:00 GMT＝北京 23:00，作者 Adam Gayoso、Natasha Latysheva、Pushmeet Kohli、Žiga Avsec）。
- 架构变化（核心）：AlphaGenome 1 是「并行输出」——一次预测数千实验、按多组织平均；**2 改成条件模型**，把目标生物条件（组织/细胞类型/状态）喂进架构**每个阶段**，一次只预测一个条件。容量不再被平均稀释，因此能分辨同一组织内相近细胞类型的差异。
- 数据：**68 种组织、逾 1.07 亿个单细胞**图谱训练，含人鼠两物种的 bulk 与单细胞数据；输入仍是 **100 万碱基** DNA。
- 评测：TenK10K 数据集（28 种原代免疫细胞）上，**因果变异识别率 30%（对照 16%）**，**方向性基因效应 43%（对照 23%）**；识别改变表达的变异数量近 **2 倍**于此前 SOTA。
- 新能力：**跨模态插补**——输入一种测量（如单细胞基因活性），预测未测属性（如染色质可及性）；新增 **DNA 甲基化**读出。**无需重训练**即可泛化到全新单细胞实验，上传**几十个细胞**的 scRNA-seq 快照即可。
- 案例：复现 *Nature* 的 IBD 机制——远端调控变异在肠道巨噬细胞里过度激活 **ETS2**；对未见过的 mRNA 疫苗单细胞数据能区分激活与静息 T 细胞。
- 可用性：**AlphaGenome API 今日起对非商业研究开放**（含表达条件化的 Colab 教程，文档 alphagenomedocs.com）；**商业用途走 private preview**；Antigravity 的 AlphaGenome 2 Skills「即将」；未提开放权重；明确未经临床/诊断验证。
