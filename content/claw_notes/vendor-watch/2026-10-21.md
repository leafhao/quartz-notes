## 国外厂商

### OpenAI：Responses 支持 12 小时提示词缓存

- API changelog **2026-10-20**，类型 Feature，端点 `v1/responses`。
- 官方口径：现在可以在 API 里选择 **12 小时提示词缓存**；把共享的 instructions、tools 与上下文缓存更久，即使两次请求相隔数小时，命中后仍按更低的 cached-input 价格计费。
- 代价写在同一条里：**12 小时缓存的写入按输入 token 价的 2.5 倍计**。也就是长缓存不是免费延长，得用命中次数摊掉写入溢价。
- 官方条目未列支持模型清单与 token 门槛，细节指向 prompt caching 指南页；与 05-29 那条把 `prompt_cache_retention` 默认值从 `in_memory` 改为 `24h` 是两件事，不要混为一谈。
- 其余官方入口：`openai.com/news` RSS 在窗口内只有三条非模型内容——10-20 的两篇客户案例（连锁餐饮用 ChatGPT Work 对账、Terminal X 用 GPT-6.1 做投资评审）与 **OpenAI 收购 Orchestra Bio**（生命科学运营方向，10-20 00:00 GMT）。收购属公司侧动作，不计入模型/API/定价/技术四类。

### Anthropic：企业侧三件套（推理钩子转正、用户档案、组织级 webhook）

- 平台发布说明 **2026-10-20**，三条：
  - **Inference hooks 结束测试**，面向 **Claude Enterprise** 组织开放。此前该能力允许把 Claude 每次受管控的提示送去组织自己的 AI 安全服务器判定放行或拒绝。
  - **用户档案（user profiles）上线**，新增 `/v1/user_profiles` 端点，SDK 与 `ant` CLI 均已支持。作用是让平台方/网关方/转售方告诉 Anthropic「这次请求是哪个最终客户」，一旦触发安全处置，只作用于单个终端客户而不是整个组织。
  - **Admin API 新增组织级 webhook**，Beta，标头 `webhooks-2026-10-07`，端点 `/v1/organizations/webhooks`，只订阅两类事件：组织下某个 user profile 被限制或封禁、以及该限制解除。需联系 Anthropic 客户团队申请开通。
- 定位很清楚：这是给**平台型客户**做合规与风控分账的接口，不是模型能力更新。`/news` 最新仍为 10-18 的公共利益基金公告，`/research` 无窗口内新 slug。

### Anthropic：Claude Code 2.1.305 / 2.1.306

- **v2.1.305** 发布 **2026-10-20 20:46Z ＝ 北京 10-21 04:46**，是本期信息量最大的一份。
  - 新增 `sandbox.allowNestedUserNamespaces`：Linux 沙箱内可创建用户命名空间（Chromium、rootless podman），但同时**能绕过沙箱的文件保护**——官方原话，开启前要想清楚。
  - 修补 2.1.304 的回归：Vertex、Bedrock 及其他网关在拒绝 tool search 时，请求会**全部失败**；现在会退回不带 tool search 重试。对走企业网关的人是本期最该关注的一条。
  - 新增环境变量 `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS`，让无人值守重试模式能提前察觉额度已解除。
  - 修 `/effort`、`/autocompact` 在模型名与 `modelOverrides` 大小写或 `[1m]` 标签不一致时不生效；bare 仓库新 worktree 从本地 HEAD 而非默认分支起；磁盘写满时报原始 ENOSPC 路径（现在直说磁盘满且没执行）；MCP server 被同名自有配置顶掉；子智能体切备用模型后报错模型名。
  - 体验项：`/usage` 告警改成一行一个可修项、按 `f` 直接修；MCP 授权弹窗不再把回车误判为同意；`/artifacts` 删除确认改为 1 保留 / 2 删除 / Esc 取消，`y`/`n` 失效。
- **v2.1.306** 发布 **2026-10-21 03:16Z ＝ 北京 11:16**，只有两条修复：云端会话里 `claude -p` 未带会话环境变量时报「Not logged in」；MCP 工具很多时 API 报错被替换成「prompt is too long」并触发多余的压缩。
- 两天连发三个版本，节奏正常，但 305 里「沙箱可绕过文件保护」与「网关拒 tool search 全挂」这两条值得单独看。
