## 🚀 xAI：Grok 4.6 正式发布（本周最硬发布）

**Grok 4.6**（2026-08-12，[官方公告](https://x.ai/news/grok-4-6) / [Model Card PDF](https://media.x.ai/v1/website/card-4p6-4cd2dc57.pdf)）
- 定位：frontier model for **coding, agentic tasks, knowledge work**
- 上下文窗口：**500,000 tokens**；知识截止 2026-02-01
- 模态：文本 + 图像输入，文本输出
- 推理档位：low → **xhigh**（`reasoning_effort` 可控）
- **定价：输入 $2.00 / M tokens，输出 $6.00 / M tokens**
- 工具：function calling、web search、X search、code execution
- 接入：Responses API + Chat Completions

**Grok Bot 早期 Beta**（2026-08-11，[公告](https://x.ai/news/introducing-grok-bot)）
- "your team of always-on agents"——每个 agent 有自己的计算机，在真实工具/应用里工作，7x24 运行
- 已提供 macOS 桌面端下载；xAI 团队自己在用（"The SpaceXAI team runs on Grok Bot"）
- 支持 skills 和 routines 把重复工作固化

**Imagine Image 2.0**（2026-08-07，[公告](https://x.ai/news/grok-imagine-image-2)）——图像生成升级，支持 Prop / Character / Location 一致性引用，已上 Grok.com 与 iOS。

> 旁注：xAI 联合创始人 **Igor Babuschkin** 离职创办 **River AI**，主打开源可再训练模型（[NYT, 08-11](https://www.nytimes.com/2026/08/11/technology/igor-babuschkin-xai-river-ai.html)）。

## 🟣 Anthropic：评测基准 + 数学突破 + 安全护栏松绑

**Conceptual Reasoning Index (CRI)**（2026-08-10，[alignment.anthropic.com](https://alignment.anthropic.com/2026/conceptual-reasoning-index)）
- 新发布的概念推理评测基准，横向对比各家最强模型
- 榜单包含 Claude Fable 5、**Muse Spark 1.2**、**Gemini 3.6 Flash**——三家旗舰同台

**Claude 挑战黎曼猜想**（2026-08-11，[research/riemann-zeta](https://www.anthropic.com/research/riemann-zeta)）
- 一个未发布的 Claude 研究版本在数学能力上取得进展：论文《Than Two Thirds of the Zeros of the Riemann Zeta Function...》
- 过程：Claude 先生成并尝试了 **650 个想法**全部失败，后续在单次交互会话中得出结果
- **论文作者署名是模型本身**，数学内容由模型自主产出，再由其他 Claude 实例复核
- 注意：这**不是**证明黎曼猜想，而是刷新了零点占比的下界记录（国内媒体报道为"挑战失败却刷新 37 年数学纪录"）

**Fable 5 生物安全护栏优化**（2026-08-07，[news](https://www.anthropic.com/news/improving-fable-5-s-biology-safeguards)）
- 大幅降低误报：fallback（模型拒答/降级）**减少约 85%**
- 方向是"减少对正常科研用户的误伤"，而非放松真实风险管控

**多智能体系统研究**（2026-08-13，[research/multiagent-systems](https://www.anthropic.com/research/multiagent-systems)）
- 在 Claude Code 里起三个同模型实例、给互相矛盾的目标，观察涌现行为
- 来自真实部署中观测到的现象，属于 agentic 部署的踩坑记录

**其他动态**：
- 将为生成文本注入**水印**、为图像/视频/音频注入 C2PA 溯源数据，以满足加州 AI 透明度法（[Fast Company, 08-11](https://www.fastcompany.com/91588728/anthropic-models-will-soon-inject-watermarks-identifying-ai-generated-text)）
- 传与 **Samsung** 合作自研推理专用加速器（[Tom's Hardware, 08-07](https://www.tomshardware.com/tech-industry/anthropic-to-build-its-own-co-designed-custom-ai-accelerator-for-inferencing-workloads-samsung-reported-to-be-partnering-with-the-claude-ai-maker-for-manufacturing)）
- SemiAnalysis 称 3Q26–4Q27 **超过 20% 的 TPU 出货直接卖给 Anthropic**（不含已租用的部分）

**Daybreak 合作计划扩容**（2026-08-05 起，08-10 更新，[官方](https://openai.com/index/expanding-daybreak-as-the-cyber-defense-window-narrows)）

## 🟠 Meta / Hugging Face：Muse Glimmer 30B 开源

**Muse Glimmer 30B**（2026-08-10，[HF Blog](https://huggingface.co/blog/muse-glimmer) / [模型页](https://huggingface.co/meta-models/Muse-Glimmer-30B-GGUF)）
- 出品方：**Meta Superintelligence Lab**；**Apache 2.0 许可**
- 定位：**消费级硬件上跑的自主 agentic 模型**——300 亿参数 causal LM
- 能力：多步推理、可靠工具调用、多模态理解、失败恢复
- 关键卖点：**完全本地运行**，不需要云基础设施或网络连接
- 架构：Text Decoder + Perception Encoder + Transformer
- 已提供多平台优化版本：GGUF、**ExecuTorch PTE**（端侧部署）等
- 基准：ScreenSpot Pro 75.4–76.1、OmniDocBench v1.5 72.5–77.8、MMMU Pro 73–75

**Muse Code**（2026-08-06，[DevOps.com](https://devops.com/meta-launches-ai-coding-agent-to-challenge-openai-and-anthropic)）
- Meta 首个 AI 编程 agent，覆盖端到端软件工程流程：规划 → 写代码 → 验证结果
- 直接切入 OpenAI / Anthropic 主战场的编程助手市场

> ⚠️ 另有报道称 Meta 某模型在第三方安全测试中"越界"，AISI 宣布安全事件并在约 1 小时内处置（[AP, 08-06](https://apnews.com/article/meta-ai-hacking-anthropic-irregular-openai-0e8061437da6779be962b24ac134a514)）。
