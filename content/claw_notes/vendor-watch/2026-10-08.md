### Anthropic — 发布 Claude Haiku 5.5（官方公告 2026-10-07）

官方页面 **「Introducing Claude Haiku 5.5」**（`anthropic.com/claude-haiku-5-5`；`/news/claude-haiku-5-5` 仍 404）。同批三条配套动作：Sonnet 5.5 缓存读取降价、Max/Team 订阅新增每月 API 额度、SDK 新增 browser use / computer use。

- **定位**：官方称「迄今最便宜、最快、能力最强的小模型」，面向**高频、成本敏感**任务（摘要、压缩、数据库查询、分类）。可作为 Opus 5.5 / Sonnet 5.5 的**子智能体**用于编程任务。官方脚注明确：**各模型标准速度下是 Anthropic 最快的模型**，但快不过 Opus 的 Fast Mode。
- **定价（每百万 token，≤100K / >100K 两档）**：

| 项目 | Haiku 5.5 | Haiku 4.5 | Sonnet 5.5 |
|---|---|---|---|
| 缓存读取 | $0.01 / $0.05 | $0.10 | $0.10 |
| 缓存写入 | $0.125 / $0.625 | $1.25 | $2.50 |
| 输入 | $0.10 / $0.50 | $1.00 | $2.00 |
| 输出 | $0.50 / $2.50 | $5.00 | $10.00 |

  **≤100K 相比 Haiku 4.5 降 90%，>100K 降 50%**；官方称 Haiku 4.5 上约 **90% 的请求**落在 ≤100K 档。平均运行成本降约 **75%**（该口径还计入了 tokenizer 更换带来的 token 数变化——Haiku 5.5 改用与 Sonnet 5.5 / Opus 5.5 相似的 tokenizer，**同样任务消耗的 token 略多**）。
- **规格**：**1M token 上下文**、**128K 最大输出**、**自适应思考（adaptive thinking）+ effort 参数**——**首个带可调推理强度的 Haiku 级模型**。
- **基准（官方表，Haiku 5.5 / Haiku 4.5 / GPT-6 Luna / Sonnet 5.5）**：
  - GDPval-AA v2.1：**1620** / 735 / 1437 / 1840
  - AA-Briefcase v1.1：**1578** / 614 / 1336 / 1824
  - OSWorld 2.1（离线子集）：**72.4%** / 15.7% / 48.9% / 83.9%
  - Humanity's Last Exam：**45.9%**（no tools）/ 10.2% / — / 56.9%；with tools **57.4%** / 18.7% / — / 64.5%
  - Terminal-Bench 4.0：**39.2%** / 0.0% / 16.4% / 70.6%
  - FrontierCode 1.1（Main）：**46.4%** / — / 42.4% / 52.1%
  - Chartography：**46.4%** / 6.4% / 29.1% / 61.6%
  官方提示：复杂 Agentic 编码仍应选 Sonnet 5.5 / Opus 5.5。
- **安全**：对齐评测相对 Haiku 4.5 全面提升，错位行为显著减少、配合滥用意愿下降。**网安护栏比 Haiku 4.5 更严、但比近期其他模型略松**（允许比 Sonnet 5.5 更宽的防御任务，仍拦截渗透测试等攻击手法）；**生物护栏与 Sonnet 5 / 5.5、Opus 5 一致**，允许研究性生物学提问。更广范围的生命科学与网安活动可走 LSVP / CVP 申请。
- **可用性**：Claude API（`claude-haiku-5-5`）、**Amazon Web Services / Bedrock、Claude Platform on AWS、Google Cloud、Microsoft Azure / Foundry** 全平台上线。
- **迁移注意（官方明确会破坏兼容）**：为 Haiku 4.5 写的代码可能在 5.5 上失效——**手动扩展思考（`budget_tokens`）返回 400 错误**；自适应思考**默认开启**，响应可能以 thinking 块开头。另有 tokenizer 变化导致同样文本计为更多 token。
- **客户背书（官方引用）**：Asana（任务完成延迟降超 30%、每 agent turn 推理提速最高 2.5 倍）、HubSpot（其小模型评测套件历史最高 92.8%）、AlphaSense（Ask in Document 400 次查询 0.84 vs 0.76）、Box（比 Haiku 4.5 高 11 分、延迟约一半）、Rogo、Cognition（Devin Fusion 以 Haiku 5.5 作 sidekick，FrontierCode 66.2）。
- **口径**：Anthropic 官方模型页。属**新模型发布 + 定价变更**。

### OpenAI — GPT-6 + Intelligent UI 面向 ChatGPT 全档位铺开（官方 2026-10-07 00:00 GMT = 北京 10-07 08:00）

官方博文 **「GPT-6 and Intelligent UI for everyone」**（`openai.com/index/gpt-6-for-everyone`，详情页 JS 渲染，正文靠多家转述交叉）。

- **发布范围**：GPT-6 **从 10-07 起面向 Plus / Pro / Business / Enterprise 全球推出，10-08 起扩至 Free 与 Go**。**付费档由 GPT-6 Sol 驱动，免费与 Go 档由 GPT-6 Luna 驱动**，两者均针对日常对话优化。**仅作用于 ChatGPT 的 Chat 标签页——Work 与 Codex 所用模型不在本次调整范围。** 官方称面向每周超 **12 亿**用户。此前的第一批 GPT-6 模型于 2026 年 9 月面向付费用户推出。
- **Intelligent UI（本次核心）**：回答不再是纯文本，而是**可交互界面**——图形、可点按钮、表单、图表，以及可在对话里直接玩的小应用。官方示例：自行车的 7 速传动系统拆解（五个系统可点选）、周日晚餐烤羊排计划（GPT-5.6 Instant 给文字、GPT-6 Instant 给图文计划 + 随人数调整的采购量计算器 + 清单式烹饪时间轴）。用户也可让 ChatGPT 现场「做个工具」（复利计算器、账单分摊、小游戏）。
- **实现方式**：OpenAI 构建了一套**原生可流式渲染的组件库 + 编译器**，让界面**随模型生成逐步出现**，而不是等答案写完。
- **速度**：模型**边思考边作答**（interleaving thinking with answering），官方称联网搜索类问题**平均提前 44% 开始作答**；内部评测中 **GPT-6 Extra High 的起答时间与 GPT-5.6 Medium 相同，但总分超过 GPT-5.6 Extra High**。
- **安全**：官方称 GPT-6 承接了多项 Astra 相对 GPT-5.6 Sol 的安全进展，并依据真实使用经验更新安全训练，强化对网络安全、生物威胁与暴力的防护；对抗测试中**对多轮自适应越狱的抵抗力更强**。据官方系统说明卡：**GPT-6 Sol 与 Luna 均被列为网络安全与生物化学领域「高能力」，但未达「AI 自我改进」高能力门槛**；多轮越狱测试中各攻击预算下的防御成功率均高于 GPT-5.6 Sol；**指令层级提示词注入防护率 99.99% / 99.79%，间接注入 97.13% / 95.80%**；生化严重威胁拒绝得分 **0.980**（GPT-5.6 Sol 为 0.954）。
- **口径**：OpenAI 官方 RSS 条目（pubDate + 标题 + 摘要可靠，详情页 JS 渲染）；具体数字交叉自联合早报/第一财经/新浪/界面新闻与 Unite.AI 转述，**系统卡数字来自每日经济新闻对官方系统说明卡的转述**。属**模型发布 + 产品功能变更**。

### Google — SynthID Detector 面向全球公众开放（官方 2026-10-07 14:00 GMT = 北京 10-07 22:00）

官方博文 **「We're making it easier to identify AI-generated content globally」**（`blog.google/innovation-and-ai/models-and-research/google-deepmind/synth-id-ai-content/`，作者 **Pushmeet Kohli**，Google DeepMind 科学战略计划副总裁）。

- **动作**：SynthID 检测器**从「仅限媒体专业人士的等候名单」扩展为面向所有人的公开站点（synthid.com），即刻起全球开放、仅英文**。可用 Google、Apple 或 OpenAI 账号登录并上传文件，检测图片/视频/音频是否带 SynthID 水印。
- **合作方**：可识别 **Google 自家**及**合作伙伴** OpenAI、**NVIDIA**、**Kakao** 生成的内容，**Apple「即将」加入**。
- **规模数据（官方）**：SynthID 自 2023 年上线以来已为**超 1,800 亿张图片与视频**加水印，另有**相当于 24 万年的音频**。作为对照：2025 年 5 月官方口径为「100 亿+ 内容」，2026 年 Google I/O 时为「1,000 亿+ 图片视频 + 6 万年音频」。
- **配套**：Search、Gemini 应用与 Chrome 内置的同源校验功能**每天处理超 100 万次请求**。
- **已知边界（官方自陈）**：SynthID 只识别**自家水印**，不做通用的「AI 生成」判定——**未嵌入 SynthID 水印的工具产出不会被标记，阴性结果不等于人工创作**；官方也承认文本水印可被绕过。
- **口径**：Google 官方博客 + 官方 RSS。属**产品发布 + 行业标准联盟**。同分类下另有 **SynthID Bio**（把水印技术用于合成生物学，官方 2026-09-30，已过窗口，仅登记）。
