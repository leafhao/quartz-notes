### 1. Meta 开源战略回归：Muse Glimmer 30B（08-10）+ Muse Code（08-05）

Meta 本期是唯一"双发布"的厂商，且两条都直指竞争对手软肋。

**Muse Glimmer 30B**（08-10 发布）
- Meta Superintelligence Lab 出品，300 亿参数因果语言模型，**Apache 2.0 许可**
- 定位明确：**端侧 agentic**——多步推理 + 可靠工具调用 + 多模态理解 + 失败恢复，**本地跑，不需要云和网络**
- 由旗舰 Muse 蒸馏而来；同步放出 GGUF 与 ExecuTorch PTE 两套部署产物，社区当天就出了 unsloth / MLX / ROCm FP4 量化版
- 基准披露（模型卡）：ScreenSpot Pro 75.4-76.1、OmniDocBench v1.5 75.8-77.8、MMMU Pro 74-75
- 来源：[HF 模型卡](https://huggingface.co/meta-models/Muse-Glimmer-30B-GGUF) · [HF 官方博客](https://huggingface.co/blog/muse-glimmer) · [Reuters](https://www.reuters.com/world/china/meta-launches-new-ai-model-zuckerberg-champions-open-weight-push-2026-08-10)

**Muse Code**（08-05 发布，beta）
- Meta **第一个终端编码 agent**，底层是 Muse Spark 1.2
- 定价 **$1.25 / 百万输入 token**，明确低于 Anthropic 与 OpenAI 同档产品；另有 pay-as-you-go 档
- 争议点：有"contributor pricing"（数据贡献换低价）档位，媒体质疑数据使用边界
- 来源：[CNBC](https://www.cnbc.com/2026/08/05/meta-debuts-muse-code-to-take-on-anthropic-and-openai-.html)

**战略信号**：Zuckerberg 同期公开呼吁美国**放宽 open-weight 模型监管**，明确把"对标中国开源势力"作为理由。这是 Meta 从 Muse Spark 闭源路线的一次公开转向，Reuters / aibusiness 均以"reverses course"定调。

## 二、跨厂商观察

**1. 开源/开放权重成为主战场，且是中美同构的竞争**
Meta 用 Muse Glimmer 明确回到开源，理由是对标中国开源势力；中国厂商用开源权重压价获取份额；Google 把 Gemma 9 亿下载和 WeatherNext 2 开源当作势能证明。三方逻辑不同但动作一致——开放权重从"理想主义"变成了标准竞争工具。

**2. 价格战已经进入可量化阶段**
不再是"某家降价"的单点新闻，而是有第三方指数（Silicon Data）给出全市场推理均价 $1.16-1.18/年内低点。Meta Muse Code 的 $1.25/百万输入 token 明确以"低于 Anthropic 和 OpenAI"为卖点。成本曲线下移会把竞争压力从模型能力转移到工程壁垒和场景落地。

**3. 端侧 agentic 是新的差异化方向**
Muse Glimmer 30B 的定位（本地跑、无需联网、工具调用 + 失败恢复）说明大厂开始认真做"能在笔记本上自主干活的模型"。这条路线和云端旗舰模型不是替代关系，而是新增战场。

**4. 网络安全模型走向受控分发**
OpenAI 的 Daybreak 系列上 AWS 但保留 Daybreak Access 准入门槛，Google 也提到"Cyber 模型已上线"。前沿网安能力正在形成"能力开放 + 客户白名单"的分发范式，与通用模型的开放策略明显分叉。

**5. 模型能力叙事从基准转向可验证科学产出**
Anthropic 的黎曼猜想研究、Google 的 WeatherNext 2 Nature 论文，两家本期都不靠跑分而是拿"审稿过的科学结果"说话。这比基准分数更难反驳，也更难复现。
