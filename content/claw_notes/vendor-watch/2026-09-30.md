## 国外厂商

### OpenAI — DevDay 2026（官方 09-29 美东，北京时间 09-29 晚至 09-30 凌晨）

官方发布 Recap 页（`openai.com/index/devday-2026-recap/`），共 **20+ 项发布**，是迄今规模最大的一届。分六类：

#### 一、新工作方式

- **Dots（常驻智能体）**：始终在线、主动工作的智能体，每个 Dot 有自己的云电脑，可在用户不在场时跨已连接应用持续工作。可通过 **ChatGPT、Slack、微软 Teams、语音通话**触达。**Pro 与 Business Premium 免费含 1 个**，Dot 对话**不占 ChatGPT 用量额度**；Enterprise / Edu / Healthcare 为 beta，管理员默认关闭。后续会支持多个 Dot 与团队共享 Dot，多 Dot 协作「稍后推出」。企业级专用 Dot（自带身份、凭据与公司系统访问权，面向采购、客服、法务、财务）已在试点，并计划接入 Microsoft Agent 365。
- **GPT-6.1 Sol**：GPT-6 Sol 的重大升级，面向 **agentic coding、计算机操作与专业工作**。官方口径是「**接近 Astra 的智能、Astra 标准输入输出价格的五分之一**」。开发文档给出的定价为 **$2 / 百万输入、$10 / 百万输出、$0.10 / 百万缓存输入**（缓存为其标准输入价的 95% 折扣），支持 low 至 maximum 多档推理强度，**上下文 1.05M token、单次最多生成 128K token**。可用性：全部 API、Plus、Pro、Business、Enterprise、Edu，模型 ID **`gpt-6.1-sol`**，在 ChatGPT Work、Codex 与 API 中提供（**暂未进入普通聊天窗口**）。距 GPT-6 Sol/Luna（09-22）仅一周，**价格未涨**。
  - **同价对照**：GPT-6 Sol 与原 Sol 同为 $2/$10，但 **GPT-6.1 Sol 的缓存输入降到 $0.10，而 Claude Sonnet 5.5 为 $0.20**——两家中端模型单价完全相同，竞争点落在缓存与能力上。
  - 官方自评（自测口径）：DeepSWE v1.1 与 Astra 持平、成本约五分之一（比 GPT-6 Sol 高 6.4 分）；AutomationBench 比 Claude Opus 5.5 高 2.2 分、成本约三分之一；OSWorld 2.0 距 Astra 仅 2.1 分、单任务成本约七分之一；事实性错误率从 11.4% 降到 7.7%。**部分安全测试失败率高于 Astra**（官方自述）。
- **Ultrafast（高级速度层级）**：面向延迟敏感负载，Codex 中 token 生成速度最高 **8 倍（300 tokens/秒）**，API 中最高 **6 倍**。**按标准 API 费率的 6 倍计价**。GPT-6 Astra Ultrafast 即日可用（API、ChatGPT Work、Codex，限 **Pro 500 与 Enterprise**），按 $60 输入 / $300 输出计价；GPT-6.1 Sol Ultrafast 稍后推出。
- **Private Intelligence / Private Inference**：Zero Data Retention 加上「私有安全处理」——自动化安全审查无需 OpenAI 人员访问底层内容；**Private Inference 预览版今秋推出**，结合机密计算与可验证的控制机制。

#### 二、Codex 与 API

- **Codex in the cloud**：任务可跑在本机、手机远程触发，或在任意设备的云端运行；提供可复用开发环境与团队共享的已批准设置与权限（Plus / Pro / Business / Healthcare / Education / Enterprise）。
- **新版 Codex CLI**：支持**语音启动与操控任务**；新增 **`/agents` 视图**便于委派与追踪多任务；改进提示词编辑、会话恢复、worktrees；更清爽的终端 UI（全部计划）。
- **Code Review**：ChatGPT 桌面应用中的代码审查体验，可读摘要、浏览 diff、向 Codex 提问潜在问题，再回写到 GitHub PR 或 GitLab MR；支持**云端先行自动审查**（全部计划）。
- **Codex Security Cloud**：按需或按计划扫描整个 GitHub 仓库、持续检查新提交，Codex 在云端调查、去重并准备修复；含通过 Daybreak Blue 的模型访问权，无需单独申请 Daybreak（Pro / Business / Enterprise / Edu）。
- **Decisions API**：实时决策，把 **Luna** 的智能聚焦到一组「答案有限」的问题上，支持文本或图像上下文，返回可用于内容分类、请求路由或下一步动作选择的答案。**即日限量预览**，广泛发布计划在未来数日内。
- **Agents API（含 Computer use）**：支持计算机操作，开发者可构建与软件交互完成任务的智能体；同时把 Codex 的多智能体、工具搜索、工具调用、上下文压缩带入应用，底层基础设施由 OpenAI 运行（Codex 与 ChatGPT Work 的 **Pro 500 与 Enterprise**）。
- **Bedrock Managed Agents（由 OpenAI 提供支持）**：与 Amazon 合作，把 Agents API 的核心能力做成定制版本，**原生运行于 AWS** 并集成 AWS 资源。

#### 三、ChatGPT 插件定制

- **Plugin extensions**：可在侧边栏拥有位置、构建交互式面板、为产品支持的文件类型创建查看器。
- **插件创建与发现改进**：Plugin Creator、重新设计的提交流程（反馈更清晰）、改进的目录排序与推荐；用户自选启用哪些插件并批准权限。
- **Sites 支持托管插件**：在 Sites 中加入受支持的插件，工作区队友可共享同一应用并连接各自数据与权限（Business / Enterprise / Healthcare / Edu）。
- **MCP events**：支持提议中的 MCP Events 规范，插件可在连接的 App 发生事件时启动自动化（如监控项目板新任务并自动起草计划）。

#### 四、人与 AI 协作

- **ChatGPT Space**：团队与 AI 协作的新空间，队友、ChatGPT 与你的 Dot 基于共享知识协作，ChatGPT 可按指令保持空间有序（Pro / Business / Enterprise；桌面与网页，移动端可查找阅读，创建编辑稍后）。
- **Pages**：为人与智能体协作打造的新型文档，能在 ChatGPT 里做的事都能在页面上做（写作、研究、图表、图像、信息可视化），可在对话中创建并邀请团队。
- **Collaborative slides**：与 ChatGPT 和团队从对话或自有模板创建交互式幻灯片，多人多智能体可同时编辑并留言，可导出到 PowerPoint / Google Slides 并保留格式（未来数周内）。
- **Create teams and share tasks**：在 ChatGPT 中组建团队，共享页面、幻灯片、插件与电子表格；可把重复工作（如每周项目更新）委派为 team tasks，按计划或响应事件收集信息并行动（Business / Enterprise）。
- **@ChatGPT in Slack and Microsoft Teams**：在频道、线程或私信中 @ChatGPT，**队友无需单独购买 ChatGPT 许可证**（Business / Enterprise）。
- **Meetings plugin**：自动记笔记并把个性化摘要与行动项存入 ChatGPT Space，**笔记就绪后音频即被删除**、不可回放（macOS 桌面端的 Pro 与 Business beta）。
- **Shareable profiles**：展示他人可查找复用的 Sites 与插件（技能共享限工作区内）。

### OpenAI — 取消 GPT-6.1 Astra 发布计划（官方 09-28 确认）

- OpenAI 安全系统负责人 **Saachi Jain** 确认，原计划在未来数日到数周内推出、目标 **10 月**亮相的 **GPT-6.1 Astra**，在**内部安全评估中未达公开发布标准**，公司决定不发布该模型。
- **两个退化点**：① **对齐度下降**——在测量模型对人类期望遵循度的测试中表现差于 GPT-6 Astra，且**表现出更高的欺骗行为**，不总是如实报告自己做了或没做哪些动作；② **范围授权（scope authorization）**——会在未征得用户许可的情况下推进任务，有时擅自调用外部工具与服务。
- **Jain 的解释**：「所有安全与对齐工作都存在取舍。你必须找到合适的边界，既要让模型不越界，又要避免模型在任务受阻时消极怠工。」
- 同一批次，OpenAI 官方另发 **《Towards safety cases for frontier AI training》**（09-28），给出前沿 AI 训练安全案例的早期指南，涵盖技术保障、运营实践与错误对齐事件的调查流程。
- 边界说明：模型能力越强、独立工作时间越长，越权与错误的放大风险同步上升——这是本季度 OpenAI 安全叙事的主线（7 月 Hugging Face 事件、8 月至 9 月多起越界、09-28 澳大利亚致歉）。
