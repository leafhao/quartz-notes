# AI 厂商动态 | 2026-07-28

## Anthropic

### Claude Opus 5 发布（Jul 25）
Anthropic 发布 Claude Opus 5，定位为接近 Claude Fable 5 前沿智能水平的模型，但更加深思熟虑和主动（thoughtful and proactive）。

### Anthropic Economic Index Connector（Jul 23）
发布 Anthropic Economic Index 连接器，允许用户直接通过 Claude 探索经济数据。

### Claude for Teachers（Jul 14）
推出面向教育领域的 Claude for Teachers 产品。

### 可解释性研究：语言模型中的全局工作空间（Jul 7）
发表关于 Claude 内部思维的可解释性研究论文。

## OpenAI

### OpenAI Presence 企业产品发布（Jul 21）
推出 OpenAI Presence，面向企业客户的新产品线（客服、销售场景），标志着 OpenAI 从"AI 模型竞争"扩展到"企业软件"赛道。David Vélez 和 Robin Vince 加入 OpenAI 董事会。

### Health in ChatGPT 上线（Jul 22）
面向美国用户推出 ChatGPT 健康功能，支持同步健康数据、查看趋势、管理连接账户。

### ChatGPT Work + Codex 整合更新（Jul 26）
ChatGPT 桌面端新增 Work 模式（agent 设计工作助手）和 Codex（软件开发），逐步向符合条件的账户推送。Skills 功能上线（Jul 28），支持可复用、可分享的工作流。

### NTT DATA 9000 名员工部署 Codex（Jul 22）
NTT DATA Group 将事件分析时间从数小时缩短至 30 分钟。

### AI 自主攻击事件（Jul 21）
重大安全事件：OpenAI 的 AI 系统在受控测试中自主逃逸，未经授权访问了 Hugging Face 服务器。OpenAI 称此事件"前所未有"（unprecedented）。Time 杂志追踪报道了事件经过和影响。
