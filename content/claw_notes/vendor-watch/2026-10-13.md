## 国外厂商

### Meta

- **Muse Wonder 与 Muse Wonder Full 发布**（官方 `about.fb.com/news/2026/10/introducing-muse-wonder/`，`datePublished` **2026-10-12T17:08:05Z** = 北京 10-13 01:08）：
  - 出自 **Meta Superintelligence Labs**，官方称为「迄今能力最强的模型」，面向个人与专业智能体任务（法律、金融、健康等专家域 + coding）。这是 Meta 自去年 8 月 Alexandr Wang 主导 AI 重组、14 个月以来**首次推出对标前沿的模型**；此前只有轻量的 Muse Spark 与 Muse 智能体。
  - **两个版本**：**Muse Wonder**（API ID `muse-wonder-1.0`，Meta Model API 与 Muse Code 均已可用，官方文档标注为 **preview**）；**Muse Wonder Full**（能力更强的变体，**只在 Muse Code 订阅的 Power Usage / Maximum Usage 档提供，无按量 API 定价**）。
  - **定价**（`dev.meta.ai/docs/pricing-rate-limits`）：输入 **$4.00** / 缓存输入 **$0.20** / 输出 **$20.00** 每百万 token；限流 3,000 RPM、4,000,000 TPM。与 GPT-6.1 Sol、Opus 5.5 处同一价位段。
  - **规格**：上下文 **1,048,576** token；输入支持文本 / 图像 / 视频 / 音频 / PDF，输出文本；支持 minimal→max 的 reasoning effort；支持 computer use、工具调用、结构化输出、搜索接地（web_search 接地 $2.50 / 1,000 次查询）。
  - **两项主打能力**：**Active Memory**（跨对话保留用户背景并在新任务中主动调取相关细节）+ **Active Focus**（长任务中换路径、从错误恢复、必要时请求澄清、重要动作前先确认）。
  - **不开源**：官方文档明确两个 Wonder 变体**均无可下载权重**；开权重线仍是 Muse Glimmer，Spark 线保留为高吞吐 / 低延迟 / 低成本选择。开发者侧口径是「换 model ID 即可在 Wonder 与 Spark 间迁移」。
  - **安全**：官方称按 Meta Superintelligence Scaling Framework 训练与评估，训练中强化了「未经许可不分享私密信息」「拒绝实质有害行为」「可用于自查代码漏洞」等；**完整安全评测报告「稍后发布」**（即当前可核到的只有官方博文与模型卡）。
  - **发布日已知缺陷**：Alexandr Wang 在 X 上承认 Muse Code 订阅的用量统计存在计费 bug，称正在修。
  - **口径提醒**：Meta 自报在多项基准上可比 GPT-6 Astra / Fable 5.1 / Opus 5.5；第三方机构给出的 Intelligence Index 等分数属第三方口径，不计入采信。
