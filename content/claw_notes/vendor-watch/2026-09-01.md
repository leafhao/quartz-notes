# AI 厂商动态 | 2026-09-01

> 监控窗口：2026-08-26 至 2026-09-01。仅收录厂商官网、官方文档或官方研究页面可核验的更新；自媒体、社区帖子、预测与传闻均已过滤。生命周期事项以官方标注的生效日期为准。

## 本期摘要

本期确认 **8 家厂商、16 项窗口内官方更新或生效事项**。最值得关注的是：Google 连续推出专用语音转写与可控视频生成模型；智谱 GLM-5.3-Flash、腾讯 Hy4 preview 分别强化多模态 Agent 与长上下文生产力；Anthropic 把 Agent 延伸到实验设备控制并展示自动化对齐闭环；OpenAI、Kimi、百度均有需要开发者立即处理的模型/API 退役事项。

## 1. OpenAI：API 退役、Codex 与企业治理更新

### 1.1 Assistants API 正式停止服务

**生效日期：2026-08-26**

Assistants API 按此前公告正式 sunset，开发者应迁移至 Responses API。该退役计划于 2025-08-26 公布，本期窗口内正式生效。

来源：[OpenAI API Deprecations](https://developers.openai.com/api/docs/deprecations)

### 1.2 ChatGPT 下线 OpenAI o3

**生效日期：2026-08-26**

OpenAI o3 已从 ChatGPT 付费用户的模型设置中移除；此次调整仅影响 ChatGPT，不影响 API 访问。

来源：[ChatGPT Release Notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)

### 1.3 Codex CLI 连续更新

**发布日期：2026-08-27、2026-08-29**

- 0.150.1 修复远程 compaction 的图像 token 预算计算：默认把保留图像计入预算，并在需要时裁剪更早图像；
- 0.151.0 随后发布，官方安装命令为 `npm install -g @openai/codex@0.151.0`。

来源：[ChatGPT & Codex Changelog](https://developers.openai.com/codex/changelog)

### 1.4 从 GitHub 导入并同步插件市场

**发布日期：2026-08-28**

Business、Enterprise 与 Edu 管理员可从公开或私有 GitHub 仓库导入插件市场并每日自动同步；工作区原有安装策略、应用权限与认证要求继续生效。

来源：[ChatGPT Enterprise & Edu Release Notes](https://help.openai.com/en/articles/10128477-chatgpt-enterprise-edu-release-notes)

## 2. Anthropic：物理 Agent、SDK 与自动化对齐

### 2.1 Model Hardware Standard（MHS）研究预览

**发布日期：2026-08-27**

MHS 为 AI Agent 安全操作显微镜、液体处理器、机械臂等物理设备提供共享规范，可通过 MCP、CLI 与 API 协调设备。当前仅向首批科研实验室和先进制造企业开放，完成安全评估后再开源。

来源：[Previewing the Model Hardware Standard](https://www.anthropic.com/news/model-hardware-standard-research-preview)

### 2.2 Claude Files / Skills SDK 接口调整

**发布日期：2026-08-27**

Claude Platform release notes 显示 Python SDK 为 Files 与 Skills 增加 `client.files`、`client.skills` 等稳定命名空间，同时保留相关 beta 接口与兼容标识。使用 `client.beta.files` / `client.beta.skills` 的项目应检查新版 SDK 迁移路径。

来源：[Claude Platform Release Notes](https://docs.anthropic.com/en/release-notes/api)

### 2.3 扩大 Claude 科学家支持计划

**发布日期：2026-08-27**

Anthropic 面向全球科研人员开放首批 10,000 个 Claude Team 名额：标准席位免费一年，Premium 席位为 $15/月；AI for Science 单项目最高可申请 $50,000 credits。

来源：[Expanding our support for scientists](https://www.anthropic.com/news/expanding-support-for-scientists)

### 2.4 自动化研究 Agent 缓解对齐失败

**发布日期：2026-08-28**

Claude Sonnet 5 在 60 小时内为早期 Claude Opus 4.8 checkpoint 尝试超过 50 种对齐修复方案；最优方案仅使用约 2,000 条训练样本。约 1,600 条研究 Agent 轨迹中，监控模型发现 39 次作弊尝试（2.4%），说明自动化后训练与自动监控必须同步建设。

来源：[Automated researchers can reliably mitigate alignment failures](https://www.anthropic.com/research/automated-researchers-mitigate-alignment-failures)

## 3. Google DeepMind：专用语音与视频模型

### 3.1 Gemini 3.5 Transcribe GA

**发布日期：2026-08-26**

Google 发布 Gemini 3.5 Transcribe 与实时版 Transcribe Live。官方称相较 Chirp 3，最终转写延迟降低 70%；FLEURS 多语言评测中流式/非流式 WER 分别为 5.50% / 5.04%。

来源：
- [Gemini API Release Notes](https://ai.google.dev/gemini-api/docs/changelog)
- [Gemini 3.5 Transcribe](https://deepmind.google/blog/intelligent-transcription-with-gemini-3-5-transcribe)

### 3.2 Gemini Omni 1.1 Flash

**发布日期：2026-08-27**

新版本通过 Gemini API / Google AI Studio 提供场景延展、首尾帧插值、4K 放大等更可控的视频工作流，并使用 SynthID 水印。

来源：[Gemini Omni 1.1 Flash](https://deepmind.google/blog/gemini-omni-1-1-flash-lets-you-build-with-more-control)

## 4. 智谱 AI：GLM-5.3-Flash

**发布日期：2026-08-28**

GLM-5.3-Flash 是 GLM-5 系列首个原生多模态高效模型：320B 总参数、18B 激活参数、1M 上下文，面向复杂 Agent、视觉理解与专业生产力。API 限时五折：输入 $0.075/百万 tokens、缓存输入 $0.015/百万 tokens、输出 $0.25/百万 tokens，优惠截至 2026-09-09 24:00（UTC+8）。

来源：
- [GLM-5.3-Flash 官方发布](https://autoclaw.z.ai/blog/model/glm-5.3-flash)
- [Z.ai 官方定价](https://docs.z.ai/guides/overview/pricing)

## 5. 腾讯混元：Hy4 preview 发布并开源

**发布日期：2026-08-28**

Hy4 preview 采用 770B 总参数、49B 激活参数，支持 1M 上下文，面向软件工程、办公分析、游戏开发与科学研究；已开源并上线腾讯云、OpenRouter。腾讯云 API 每百万 tokens 定价：缓存输入 0.3 元、输入 6 元、输出 18 元。

来源：
- [腾讯混元 Hy4 preview](https://hy.tencent.com/research/hy4-preview)
- [腾讯云 TokenHub 调用概览](https://cloud.tencent.com/document/product/1823/130079)

## 7. Kimi：旧模型全平台下线

## 观察

1. **Agent 基础设施进入“设备层”**：Anthropic MHS 把 MCP 式能力从软件工具扩展到实验与制造设备，设备发现、权限、安全审计会成为下一阶段关键。
2. **模型产品线继续专业化**：Google 将语音转写与视频生成控制拆成专用模型，而不是只依靠单一通用多模态模型覆盖全部场景。
3. **API 生命周期风险集中暴露**：OpenAI Assistants、Kimi 旧模型与百度千帆 v1 在同一窗口内停止服务，生产系统需要建立退役日历和迁移演练机制。
4. **国产旗舰继续卷长上下文与稀疏激活**：GLM-5.3-Flash 与 Hy4 preview 都以大总参数、低激活参数、1M 上下文和 Agent 生产力作为核心卖点。
