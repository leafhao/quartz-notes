## 国内厂商

### 腾讯（本期唯一实质动作）

- **Hy-Memory 2.0：模型、框架、应用三层全开源**（官方站 `memory.hunyuan.tencent.com` 标注「开源发布 · 2026.10.16」；证券时报 10-16 转述腾讯混元消息）：
  - **模型层 `Hy-Memory-30B-A3B`**：腾讯混元自研的长期记忆写入模型，约 **3B 激活参数**，面向外部记忆框架的 write path，可直接替换 Mem0、MemOS、Hy-Memory 里的通用 LLM 来决定「记什么」；**Apache 2.0**，技术报告 arXiv 2610.22196。官方口径：接入 Hy-Memory/Mem0/MemOS/EverMemOS 四套记忆系统，总均分 **55.49**，高于 Opus 5（54.62）、DeepSeek V4.1 Flash（53.64）、Qwen3-30B-A3B（44.37），较 HY3-A3B 基座（47.66）+7.8 分；在训练中未见过的 EverMemOS 上同样第一（56.89）。
  - **框架层 `Hy-Memory`**：三类记忆场景——聊天（分层结构 + 演化链）、工作（任务目标/既定做法/阶段结果 + 带适用条件的可复用经验）、代码（版本演化 diff 链，回答「代码为什么这样改」）；官方称是业界首个提出工作记忆与代码记忆的框架。4 个 benchmark 均为开源框架第一：**LoCoMo 72.6%**、**MemoryArena 55.31%**（领先次优 EverOS 10.2 个百分点）、**CodeMemoryBench 64.2% / 35.6%**（问答/解决率）、**SWE-ContextBench 28.3%**；强调存储占用低（Working 场景 Memory 占用 6.06%）。
  - **应用层 `MemHub`**：本地优先的桌面端 + CLI，把用户授权的多种 AI 工具会话汇成一份本地记忆——历史导入、持续同步、插件化召回；官方列 10 种已支持工具（WorkBuddy、Cursor、Codex、Claude Code、OpenCode、OpenClaw、Qwen Code、Pi、Hermes、DeepSeek Harness）。
  - **落地**：官方称 Hy-Memory 已在腾讯自选股、iWiki、腾讯新闻，以及办公 Agent、社交娱乐、游戏等多个内部业务中使用。
  - 对照 1.0（2026-05，未开源，仅有论文 arXiv 2606.09483，论文中名 DCPM）：2.0 的核心增量是新增工作与代码两类记忆、并把三层全部开源。

## 教训 / 新入口

1. **厂商官网的项目页比 GitHub `created_at` 更能定「发布日」**：`Hy-Memory` 仓库创建于 10-15 13:06Z、HF 模型创建于 10-15 09:52Z，但官网明确写「开源发布 · 2026.10.16」，媒体也是 10-16 收到消息。仓库/模型创建时间只能判「有没有新东西」，发布日期要落回官网或官方通稿，否则会把发布日提前一天。
2. **腾讯的模型侧公告有了稳定入口**：`memory.hunyuan.tencent.com` 这类 `*.hunyuan.tencent.com` 子站是单页静态 HTML，正文含发布日期、benchmark 表、开源范围与 license，比 GitHub README 全；后续腾讯条目应优先抓子站再回落 GitHub。
3. **OpenAI 的产品级更新常常只发在官方 X + 帮助文档，不进 RSS**：本期浏览器扩展升级在 RSS 里完全没有（RSS 当天只有两条客户案例），只能靠「官方标题/关键词 + 中文技术媒体一致转述」反查。RSS 已不足以判定 OpenAI「当天无事」。
4. **`deepmind.google/blog/rss.xml` 需要 `curl --compressed`**：不带该参数拿到的是 gzip 原始流（此前记载「乱码无法解析」即此原因），解压后 100 条条目结构正常。
5. **`cloud.google.com/blog/topics/inside-google-cloud/whats-new-google-cloud/` 是周报**，标题带日期区间（如 Oct 12 - Oct 16），只能用于确认「这一周有没有模型侧动作」，不能当条目源。
6. **HF 博客窗口内出现大模型欢迎文时，先分清主体在不在清单**：本期 Beam（Reflection）、FLUX.3（BFL）、Granite（IBM）、LFM（Liquid）四条全是客座文，只有 transformers 版本更新属于 HF 自己的动作。
7. **文档站横幅是新的误判源**：MiniMax 文档站顶部「H3 全新发布」常驻横幅会让人以为当天有新发布，必须用 HF 组织的 `createdAt` 或带日期的官方公告校验（H3 实为 7 月）。
8. **国内「零新发布」的写法继续保持实测日期**，本期唯一例外是腾讯，其余七家仍为零。
