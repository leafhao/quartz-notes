## 🌍 国外厂商动态

### OpenAI

#### 🚀 GPT-5.5 发布（2026-04-23）
- **定位**：全新级别的智能模型，专为真实工作场景设计
- **核心能力**：
  - 编写和调试代码
  - 在线研究
  - 数据分析
  - 创建文档和表格
  - 软件操作
  - 跨工具任务执行
- **定价**：
  | 模型 | 短上下文输入 | 输出 | 长上下文输入 | 输出 |
  |------|-------------|------|-------------|------|
  | gpt-5.5 | $2.50/MTok | $15/MTok | $5.00/MTok | $22.50/MTok |
  | gpt-5.5-pro | $15/MTok | $90/MTok | - | - |
- **特性**：1M 上下文窗口、128K 最大输出、支持 Functions/Web search/File search/Computer use
- **来源**：[OpenAI Blog](https://openai.com/index/introducing-gpt-5-5/)

#### 🏢 收购 Neptune（2026-04-26）
- Neptune 是 ML 实验跟踪和训练监控工具
- 目的：将 Neptune 的工具深度集成到 OpenAI 训练栈中，提升模型训练可视化能力
- **来源**：[OpenAI Blog](https://openai.com/index/openai-to-acquire-neptune/)

#### ☁️ AWS 合作（2026-04-28）
- OpenAI 模型、Codex 和 Managed Agents 登陆 AWS Bedrock
- Claude Opus 4.7 和 Haiku 4.5 在 Bedrock 上提供自服务访问
- 支持 27 个 AWS 区域
- **来源**：[OpenAI Blog](https://openai.com/)

#### 🔐 Advanced Account Security（2026-04-30）
- 推出高级账户安全功能
- **来源**：[OpenAI Newsroom](https://openai.com/news/product-releases/)

### Anthropic

#### 🚀 Claude Opus 4.7 发布（2026-04-16）
- **定位**：Anthropic 最强大的通用可用模型
- **核心能力**：
  - 复杂推理
  - 智能体编程
  - 视觉理解
  - 专业知识工作
- **定价**：$5/MTok 输入，$25/MTok 输出（与 Opus 4.6 相同）
- **特性**：1M 上下文窗口、300K 最大输出（Batch API）
- **来源**：[Anthropic](https://www.anthropic.com/claude/opus)

#### ⚠️ Claude Sonnet 4 和 Opus 4 即将退役（2026-04-14）
- **退役日期**：2026-06-15
- **替代方案**：
  | 退役模型 | 推荐替代 |
  |----------|----------|
  | claude-sonnet-4-20250514 | claude-sonnet-4-6 |
  | claude-opus-4-20250514 | claude-opus-4-7 |
- **来源**：[Anthropic Docs](https://docs.anthropic.com/en/docs/about-claude/model-deprecations)

#### 📋 RSP 3.2 更新（2026-04-29）
- Responsible Scaling Policy Version 3.2
- 授权 LTBT 请求外部审查风险报告
- 给予 LTBT 批准外部审查员选择的权力
- 正式要求定期向 LTBT 提供简报
- **来源**：[Anthropic RSP](https://www.anthropic.com/responsible-scaling-policy)
