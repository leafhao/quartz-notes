# AI 厂商动态｜2026-09-12

> 今日没有新的旗舰模型发布；新增核实到两项此前日报遗漏的官方 API 更新：Anthropic 为 Managed Agents 加入服务端自动权限判定与实时会话接入，Kimi API 则已原生兼容 OpenAI Responses API 和 Anthropic Messages API。

## 本期新增核实

### 1. Anthropic：Managed Agents 增加自动权限策略与实时会话接入

**发布日期：2026-09-10**

- Claude Managed Agents 的权限策略新增 `auto`：服务端可逐次评估 Agent 或 MCP 工具调用，并自动运行、拒绝，或暂停等待人工批准。
- `agent.tool_use` 与 `agent.mcp_tool_use` 事件新增 `evaluation` 和 `evaluated_permission` 信息，便于审计权限判定结果。
- `ant` CLI 新增 `ant beta:sessions connect`，可从终端接入正在运行的 Managed Agents 会话，实时跟踪、发消息并审批工具调用；`--web` 可在本地打开 Claude Console 会话查看器。

来源：[Anthropic Claude Platform 官方更新日志](https://docs.anthropic.com/en/release-notes/api)

### 2. Kimi：API 原生支持两套主流兼容协议

**发布日期：2026-09-07**

- Kimi API 开放平台已同时支持 **OpenAI Responses API** 与 **Anthropic Messages API**。
- Codex、Claude Code 等客户端无需额外协议转换或本地代理，即可通过自定义 provider 直连 `kimi-k3`、`kimi-k2.7-code-highspeed`、`kimi-k2.7-code`、`kimi-k2.6`。
- 对已有 OpenAI/Anthropic 兼容工具链，这是一次明显降低接入成本的 API 更新。

来源：[Kimi 官方接入指南](https://www.kimi.com/academy/use-kimi-api-in-codex-and-claude-code)

## 窗口内仍需关注的已确认变化

### DeepSeek V4.1 Flash：降价并调整模型路由

**发布日期：2026-09-10**

DeepSeek V4.1 Flash 已上线 `deepseek-flash`，原生支持多模态、1M 上下文、Tool Calls、Responses API 与 Anthropic API。官方同步下调价格：工作日高峰时段缓存未命中输入 2 元/百万 tokens、输出 8 元/百万 tokens，空闲时段减半。旧 Flash 名称已兼容路由至新模型；**9 月 14 日 12:00 后，`deepseek-v4-pro` 也会在 V4.1 Pro 上线前临时路由到 V4.1 Flash**。

来源：[DeepSeek 官方更新日志](https://api-docs.deepseek.com/zh-cn/updates) · [官方模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)

### OpenAI Agents API：托管 Agent runtime 进入公测

**发布日期：2026-09-10**

OpenAI 已将支撑 Codex 的长程 Agent harness 以 Agents API 形式开放公测，提供上下文管理、工具使用、代码执行、文件访问、长任务运行与多 Agent 协作能力。它更接近托管 Agent runtime，而不是单纯的模型调用接口。

来源：[OpenAI 官方公告](https://openai.com/index/introducing-the-agents-api)

### 腾讯云 TokenHub：旧视觉模型临近下线

**官方文档更新时间：2026-09-08**

Kling、Vidu、HY 图片生成旧版本将于 **9 月 15 日 00:00** 停止调用，HY 视频生成旧版本将于 **9 月 21 日 00:00** 停止调用。现有业务应按官方迁移映射表提前切换并做参数与效果回归测试。

来源：[腾讯云 TokenHub 官方迁移说明](https://cloud.tencent.com/document/product/1823/130055)
