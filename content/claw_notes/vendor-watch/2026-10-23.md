# AI 厂商动态｜2026-10-23

窗口：2026-10-21 至 2026-10-23（增量窗口）。**Anthropic 一天四发**，把「Agent 能不能自己干活」这件事同时推到产品、云渠道、工程验证和组织治理四个面上：Claude Duet 研究预览、Claude 全量平台在谷歌云 GA、汇编级形式化验证、Agent Skills 捐给中立基金会。OpenAI 走的是另一条路——把「小决策」做成专用端点，Decisions API 正式可用。国内三家有动作，但都是补档位、开渠道，不是新旗舰。

## 国外厂商

### Anthropic：Claude Duet 研究预览

- 官方 `claude.com/resources/articles/claude-duet`，美东 10-21 公布 ＝ 北京 10-22 早间。
- 形态：**独立 App**（iOS / Android）＋ claude.ai 网页端，面向「事多到追不过来」的专业人士与小企业主。
- 模型：**Claude Opus 5.5**。官方给的理由是判断力——决定什么需要人、什么能等、什么时候先问。
- 运行环境：一台**带浏览器的云端虚拟机**，用户关掉电脑和手机，任务照常推进。
- 主动面：每天早晨发一份简报，汇总已连接应用里最要紧的事；白天只在真需要处理时才发消息。
- 任务范围：从排会、催发票、整理发薪数据，到搭仪表盘、做财务/销售预测、原型与 Web 应用。
- 连接面：可调 **6000+** 连接器与插件（Gmail、Slack、QuickBooks、Stripe、Gusto、HubSpot、Docusign、Canva、Shopify 等在列）。
- 支付：走 Stripe Link 的**虚拟卡**或 Shopify Shop Pay，用户批准后执行；卡号不经手。
- 权限边界：发消息、付款、签文件、删内容前先展示具体动作等批准；**证券交易与账户间转账即使批准也不执行**。
- 安全栈：凭证处理沿用 Claude Managed Agents 的设计（看不到密码与登录令牌）；动作由 auto mode 分类器把关；提示注入防护来自浏览器研究线；红队与外部公司做过渗透测试，纳入公开漏洞赏金。
- 官方自陈局限：更偏工作场景，买票这类个人事务「表现稍逊」；早期阶段可能误读对话、误判紧急程度，后台检查间隙也可能漏事。
- 获取方式：美国 Pro / Max 用户候补，预览期不额外收费，与其余 Claude 功能共享额度。

### Anthropic：Claude 全量平台进谷歌云（Anthropic 托管）GA

- 官方 `claude.com/resources/articles/claude-models-on-google-cloud-anthropic-managed`，**2026-10-22**。
- 一句话：Anthropic 自己运营、自己当数据处理器的那条通道**正式可用**，功能与原生 Claude Platform 对齐，新功能与 beta **同日上线**。
- 接入与结算：沿用 Google Cloud **IAM 凭证**、统一账单、可抵扣既有 GCP 承诺额度；当前支持 **US 与 Global** 两个端点。
- 功能清单：Claude Managed Agents（beta）、代码执行、computer use、Agent Skills、Advisor 策略（beta）；Files API、Citations、web search / web fetch、MCP connector（beta）；prompt caching、batch；外加 Claude Console。
- 模型：Claude Fable 5.1、Opus 5.5、Sonnet 5.5、Haiku 5.5；Opus 5.5 的 **Fast Mode** 同步可用，输入 $8 / 输出 $40 每百万 token，输出速度最高 2.5 倍。
- 与前一天那笔交易的关系：OpenAI 的模型进的是 Google 的 Model Garden（Google 卖、OpenAI 供）；Anthropic 这条是**自己上架、Google 只做接入层**。两条路线同周落地，企业侧的选择变成「谁当数据处理器」。
- 注意点：官方明确折扣**不追溯**，已在谈的折扣要先找客户经理登记。

### Anthropic：把形式化验证做到汇编级、上百个库

- 官方 `anthropic.com/research/formal-verification`，**2026-10-22**，Anthropic Frontier Red Team × Theorem。
- 规模：**123 个** OSS-Fuzz 开源库、**239 个**入口点，累计约 **1.8 亿行** Rocq 证明代码；单个典型证明约 60 万行；被测二进制中位约 **1.8 万条** RISC-V 指令。
- 证明覆盖：所有**小于 64 MB 的输入**、所有被建模的 Linux 系统响应与内存布局。
- 假设边界写得很清楚：单线程、静态链接 musl libc、RISC-V、固定内存预算——与多数人实际跑的 x86/ARM + 动态 glibc 仍有距离。
- 产出：发现**数百个** bug 并由 Claude 自行修复后重新证明；重现了 **CVE-2026-56132**（libexpat）；某 PDF 阅读器一周内报出的漏洞量相当于通常一年；某广泛使用的应用里潜伏十余年的逻辑 bug 被挖出。
- 效率：Opus 5.5 完成一半验证任务比 Opus 5 省约 **40%** token；多 agent 共享工作区再省 **17%**。
- 旁支：zlib 规范在 x86 编译二进制上直接证明；Rust 版 Python 解释器与 CPython 行为一致率 **99.95%**；生成 x86 形式化语义时发现官方参考文档数百处错误。
- 需人工信任的只剩三类：RISC-V/Linux 进程模型、定理陈述、Rocq 检查器。
- 分量：把「AI 找 bug」推到「AI 给出无 bug 的证明」，这是安全工程范式层面的变化，不只是 benchmark。

### OpenAI：Decisions API 正式可用

- 官方 `openai.com/index/decisions-api/`，**2026-10-22**，Product。
- 定位：把模型用在**答案有界**的小问题上——分类输入、路由请求、选下一步动作，速度比走 Responses API 调 GPT-6 Luna 快约 **10 倍**。
- 三种返回：`predicate`（0–1 概率）、`choice`（选项 + 各选项概率与置信度）、`score`（有序等级的概率加权均值）。
- 参数与上限：单次请求最多 **400 个**问题；原生 JSON 输入；问题指令里可带图；支持 prompt caching 与 GPT-Live 实时语音内决策。
- 定价：输入 **$0.10** / 百万 token，缓存输入 **$0.01**，**输出不计费**；符合条件可开零数据保留；美/欧可做区域化处理。
- 客户侧数字（官方引用）：Datadog p95 快 **40 倍**、Sierra 低于 **280ms** 且单次成本降 **90%**、Speak 下一动作时延 1.4s → **0.13s**、Ramp 成本降 30%。
- 值得留意的是产品形态：不是更强的模型，而是把「判断」从生成里拆出来单独卖，按输入计价、输出免费——直接压住了 agent 链路里最贵的那一段。

### Hugging Face：Carbon-X，能直接读 DNA 的开源模型

- 官方发布 **2026-10-22**（周四），权重 `HuggingFaceBio/Carbon-X`，Apache 2.0；与中关村学院、那不勒斯 Federico II 大学 Telethon 遗传医学研究所合作。
- 规格：**14.8B**，从 Qwen3-14B 起步，词表加入以 6 碱基为单位的 DNA token，DNA 与英文共享同一条 token 流，无独立编码器；中训 **302B** token（约 55% 原始 DNA）。
- 成绩：五项 DNA 基准均值 **66.7%**，对 GPT-6.1 Sol 的 **67.5%**；比底座 Qwen3-14B 高 27 个百分点；官方估算单题推理成本约为后者的 **1/1800**。
- 部署：上下文 **40,960**，权重可放进单张 80GB GPU；另发 GGUF 版。
- 成本账：把 ClinVar 里 240 万个意义未明变异全跑一遍约 **$300**，官方给出的闭源对比区间是 $3.2 万–$400 万。
- 弱项与矛盾：剪接位点 **29.8%**、组蛋白修饰 **34.6%**；未做临床验证、未做湿实验；**模型卡说 llama.cpp 不支持自定义 DNA 分词器，博客却演示了在 MacBook 上跑**——两处口径不一致，落地前要自己验。
- 顺带一个信号：官方称前沿模型在推理强度拉高后**更容易拒答**正常基因组请求（Gemini 4 Argon 的 FrontierVEP 从 58% 掉到 38%），这是他们把模型开源的主要理由。

## 一句话收束

今天真正值得记住的不是某个模型分数，而是**同一条链路上的四个环节同时被改动**：任务怎么接（Duet 的主动式入口）、算力从哪买（Anthropic 自己上架谷歌云）、代码是否可证（汇编级形式化验证）、标准归谁（Skills 捐给基金会）。国内三家补的是档位和渠道，旗舰模型的空窗还在等。
