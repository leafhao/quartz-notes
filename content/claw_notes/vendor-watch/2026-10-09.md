## 国外厂商

### OpenAI

- **摧毁两个 AI 赋能的影响行动**（官方 10-08 00:00 GMT，`openai.com/index/disrupting-ai-enabled-false-front-operations/`）：一次封禁两个隐秘影响力行动（IO）账号，一个来自俄罗斯、一个来自伊朗。
  - 俄方命名为 Operation "Dark Clark"，面向拉美，用 ChatGPT 冒充记者向学校、至少一名政客与多家媒体投放内容，并用被蒙骗的当地人运营一个「智库」、伪造「泄露文件」与音频脚本。
  - 伊方建立了一个由七个「记者」人设组成的矩阵，向全球中小型线上媒体投稿长文，并批量生成社媒评论。
  - 按 IO Breakout Scale 评估：俄方为 **Category 5**（自 2024 年初开始公开报告以来首次达到该级别），伊方达到 Category 4。两者的内容（并非全部由 OpenAI 模型生成）都成功进入主流媒体，而非仅停留在社媒。
  - 官方口径：近两年半累计曝光 30 起隐秘影响行动；「false front」类行动的共同特点是高度接近 AI 时代之前的手法，只是用 AI 提升了规模、效率、语言流畅度与编辑能力。
- **GPT-6.1 Sol Ultrafast 进入 Codex 与 ChatGPT Work**（官方 changelog 10-08，`learn.chatgpt.com/docs/changelog`）：Ultrafast 模式在 Codex 与 ChatGPT Work 中加速 token 生成，可用档位为 Pro $500 及符合条件的 Enterprise / Edu 计划；**企业版默认关闭**，需工作区管理员开启。支持美国与欧洲（EEA + 瑞士）推理驻留。
- **Codex CLI 0.162.0**（官方 10-08）：新增在受信任本地项目中创建/列出托管 Git worktree 的工具、Command Center 用 `p` 固定任务、`/copy` 导航与复制 transcript 块、审批头与 MCP 提示里的 URL 可点击、为兼容 Responses 的自定义模型提供方配置实时网页访问与远端压缩能力。
- **三条客户案例**（官方 10-08）：Oracle（用 ChatGPT 与 Codex 把数天工作压到分钟级）、LegalOn（Codex 成本减半同时保持开发速度）、Pollo AI（用 OpenAI 把创意想法做成营销活动）。

### Anthropic

- **2026 版使用政策更新**（官方 10-08 17:00 GMT，`anthropic.com/news/2026-usage-policy-update`，**11-12 生效**）：年度例行刷新，多数改动是把既有规则写得更明确，以适配 Claude 承担的「更长、更独立的工作」。
  - 新增合并章节《不得从事欺骗性活动或人为造势》，把原先散落在选举、欺诈、隐私、虚假信息各处的内容集中；覆盖运营假账号、伪造新闻站点，以及**搭建影响力行动的工具与基础设施**。
  - 选举章节更名为《不得破坏民主进程》，收窄为禁止欺骗选民或干扰选举；**取消**了原先针对个性化投票与竞选定向的全面禁令（该禁令此前误伤非营利组织多语言选民信息等正当公民工作）。
  - 武器条款明确禁止包含「使武器运转的软件与零部件」，点名**给无人机与其他自主载具装载武器**；监控与执法条款禁止未经同意追踪他人，禁止 Claude 参与「决定或建议谁应被调查、逮捕或起诉」，同时保留同意基础上的反欺诈监控、内容审核、新闻与法律研究。
  - 高风险用例（健康、法律权利、财务、生计、基本服务）明确要求「人在环」并向受影响个人告知 AI 参与；随 Model Hardware Standard 的推出，接入可造成伤害的自主物理动作硬件时，须有合格操作员能观察并随时停止设备。
  - **首次**加入对模型本身的保护条款：禁止「持续且无必要地虐待或残忍对待我们的模型」，明确豁免正常的不满情绪与刻意的模型测试；官方称 Claude 结束这类交互的能力仍将是主要执行机制。
- **Anthropic Cyber Mission 发布**（官方 10-08 09:04 GMT，`anthropic.com/news/anthropic-cyber-mission`）：长期网络安全承诺，首批两个方向。
  - **关键基础设施防御计划（CIDP）**：把前沿 Claude 模型、驻场工程师与威胁研究带给运营技术（OT）防护服务商。创始伙伴 11 家：埃森哲、博思艾伦、CrowdStrike、德勤、Dragos、日立、Insane Cyber、Nozomi Networks、Palo Alto Networks、普华永道、罗克韦尔自动化。已有数家伙伴在用 Claude 修复漏洞。
  - **OSS Scanner**：面向开源项目的免费定期安全扫描（模式参考 Google OSS-Fuzz），含复现/PoC、解释与候选补丁。报告**完全由模型生成、不经人工复核**，官方预期真阳性率 >90%，并提示严重度评级等细节可能有误；早期验证中，97 条严重/高危发现里 85 条（88%）达到其披露流程标准。过去六个月模型标记 29,000+ 候选漏洞，约 6,000 条经人工复核。
  - 背景：本周早些时候 Project Glasswing 已并入扩展后的 Cyber Verification Program；Glasswing 的教训是「发现漏洞变容易，验证、排序与修复仍困难」。
- **向美国 Genesis Mission 承诺 1.5 亿美元 / 三年**（官方 10-08 13:00 GMT，`anthropic.com/news/genesis-mission-commitment`）：资金用于把 Claude 开放给参与该计划的 15 家以上联邦机构，含 NASA、NIH、NSF；三年内向数百个研究项目提供 Claude、Claude Code 与 API 额度，并配合聚变能、量子计算等优先方向提供培训与驻场支持。公告发布于白宫 OSTP 的「Science: A New Golden Age」峰会。同日白宫情况说明列出产业界合计约 24 亿美元承诺（NVIDIA 10 亿、AMD 5 亿、OpenAI 2 亿、Anthropic 1.5 亿、Google 1.5 亿等）。
- **Claude Code v2.1.294**（官方 GitHub Releases 10-08 05:03 UTC = 北京 13:03）：修复写成指令形式的 `prompt` 与 `agent` 钩子会被放行本应拦截的命令；改进 Stop / SubagentStop 上指令型 `prompt` 钩子的判定，减少过早停止。
- **Claude Code v2.1.295**（官方 GitHub Releases 10-08 19:48 UTC = 北京 10-09 03:48）：新增 command/HTTP 钩子的 `onFailure: "block"`（钩子无法启动、超时或异常退出时阻断动作而非放行）；新增 Program Status Protocol（OSC 7501）支持；Claude apps gateway 新增 `timeouts.upstream_ttfb_ms` 流首字节超时、每个上游的 `models` 白名单（支持 `*` 通配）、`forceLoginMethod: "gateway"`；新增 `$.ui.notify` 与 mod Button 子元素；`CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS` 限制无人值守重试等待 429/529 的时长；MCP 工具描述截断上限由 2,048 提到 16,384 字符；子智能体最多预载 32 个技能；WebSocket MCP 单条消息超 16 MiB 直接断开；Claude apps gateway 背景请求改用 Haiku 4.5。
