# AI 厂商动态｜2026-09-13

> 今日未发现新的旗舰模型发布。新增核实到 Anthropic 面向 Enterprise 推出的 Smart reports；工程侧更紧迫的是 DeepSeek 明日中午的模型路由切换，以及腾讯云后天开始的旧视觉模型下线。

## 本期新增核实

### Anthropic：Smart reports 进入 Enterprise Beta

**发布日期：2026-09-10**

- Smart reports 会分析团队使用 Claude 的工作内容、成本、会话摩擦点，以及适合沉淀为共享 Skills 的重复模式。
- 当前仅面向 Claude Enterprise 计划提供 Beta。
- 这不是模型能力升级，但对企业级 Agent 治理有实际价值：它把成本分析、失败模式发现和 Skills 复用线索整合到同一报告中。

来源：[Anthropic Claude Apps 官方更新日志](https://docs.anthropic.com/en/release-notes/claude-apps)

## 近期需执行的变更

### DeepSeek：V4 Pro 将临时路由至 V4.1 Flash

**生效时间：2026-09-14 12:00（北京时间）**

DeepSeek V4.1 Flash 已上线 `deepseek-flash`，原生支持多模态、1M 上下文、Tool Calls、Responses API 与 Anthropic API。官方说明，因 V4.1 Flash 已在性能、费用、速度和总用时上全面超过 V4 Pro，9 月 14 日 12:00 后，`deepseek-v4-pro` 会在 V4.1 Pro 上线前临时路由到 V4.1 Flash。依赖模型行为稳定性的线上业务应提前回归测试。

来源：[DeepSeek 官方公告](https://api-docs.deepseek.com/zh-cn/news/news260910) · [官方模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)

### 腾讯云 TokenHub：旧视觉模型即将停止调用

**生效时间：2026-09-15 00:00 起**

Kling、Vidu、HY 图片生成旧版本将于 9 月 15 日停止调用，HY 视频生成旧版本将于 9 月 21 日停止调用。现有业务应按官方迁移映射切换至按 Token 计费的新版本，并完成参数与效果回归。

来源：[腾讯云 TokenHub 官方迁移说明](https://cloud.tencent.com/document/product/1823/130055)

- **OpenAI（09-10）**：Agents API 托管 Agent runtime 已进入公测；GPT-6 Astra 是 09-03 发布，已超出本报告新增窗口起点，未重复计入。
- **Anthropic（09-10）**：Managed Agents 的服务端自动权限判定与实时会话接入已在上一期记录。
- **Kimi（09-07）**：原生兼容 OpenAI Responses API 与 Anthropic Messages API，已在上一期记录。
- **Google DeepMind、Meta AI、Hugging Face、阿里云/通义、智谱 AI、百度、MiniMax、字节跳动/火山引擎**：最近 7 天内未从官方页面确认到相较上一期新增的模型发布、API 更新、定价变化或重大技术突破。

检索结果中的媒体报道、社区帖子、百科、开发者社区用户投稿、无明确日期的产品横幅与 Tavily 自动摘要均未作为事实依据。

## 观察

本期重点不是新模型，而是 **Agent 运营治理与兼容性变更**：Anthropic 开始把团队使用数据转化为成本、摩擦点和 Skills 复用建议；DeepSeek 与腾讯云则进入需要工程团队立即处理的迁移窗口。
