## 国外厂商

### Anthropic — Claude 独立算出九圈散射振幅（09-25）

- 官方 research 页发布客座文章《Yes, Claude can do Nine Loops》：Anthropic 两位物理学家 Liam Fitzpatrick、Siddharth Mishra-Sharma 用 **Fable 5.1 + Claude Science**（付费科研平台，官方定义为 harness）完成了平面 N=4 超杨-米尔斯理论六粒子（hexagon）散射振幅的**九圈**计算，比 Dixon & Liu 2023 年的八圈纪录多一圈。
- 过程几乎无人监督：先让 Claude 自选最有把握的题目，随后只给一句任务描述与「继续做，每 4—6 小时给我更新」的指令，连续运行数日。Claude 同时用**自举法（bootstrap）**与**形状因子（form-factor）+ 对偶性**两条路子各算了一遍。
- 成本：自举部分用 Python + SymPy，约 100 美元（≈96 CPU 跑一周）；终端用户两种路线的总花费约 1000—2000 美元，主要是长时间调用 Claude 的费用。Anthropic 官方 X 口径为「数千美元」。
- 验证：SLAC/斯坦福的 Lance Dixon（八圈纪录保持者）独立验证，主要通过相关形状因子；结果数据文件（8 个，均 >100MB）已发布在 Zenodo，日期 09-16。
- 官方与作者都明确：**用的是已知方法、不是新原理**。文章作者 Matt von Hippel 指出，中科院理论物理研究所**何颂团队**同期用 **GPT-6** 独立得到了九圈振幅的 symbol；真正值得注意的不是「超越人类」，而是该领域的瓶颈已从算力转向「执行的劳动力」。

## 国内厂商

### 深度求索 — DeepSeek Harness 官方桌面版上线（09-25）

- Harness（dsh，2026-08 开源的 Agent 运行时框架，MIT，TypeScript，「一切皆插件」）推出**官方桌面客户端**，版本 **V0.1.7-rc.2**（安装包为 0.1.7-rc.1.20260924.1），官方下载直链位于 `download.deepseek.com`，macOS 版通过 Apple 公证、签名主体为 Hangzhou DeepSeek Artificial Intelligence Co., Ltd。
- 目标平台：**Windows x64、macOS arm64**（另有 mac-x64）；**Linux 不是受支持的 Desktop 发布目标**。实现方式为 Electron 壳加载打包后的 dsh Web 入口（默认端口 19387），复用现有 Agent／会话／工具／插件逻辑，而非重写。
- 关键变化：用户不再需要自装 Node.js、开终端跑 `npx @deepseek-ai/dsh`。内置独立分发的 **Python、Node.js、pnpm**，Python 预装 numpy、pandas、python-docx/pptx、openpyxl、Pillow、lxml、XlsxWriter，并内置 `office-docx`／`office-pptx`／`office-xlsx` 三个 Office 技能。
- 交互：关窗只是隐藏、任务继续跑；退出前若有运行中任务会弹原生确认；支持系统浏览器 OAuth 登录，也支持直接填 API Key。
- **Agent 四档模式**：标准（代码/文件/资料通用）、PTC（程序化工具调用，适合批量工具链与结果汇整）、极简（只用终端）、创造（用对话定制 DSH 本身、让 Agent 写插件）。
- 注意：官方仓库已提供中文文档 `apps/desktop/README.zh.md`，**但官网与 GitHub Release 尚未挂出正式发布公告**，当前为开发者预览版；文档亦标注「账号登录尚未接入、登录按钮禁用」等已知限制。

### 深度求索 — Harness 0.1.7 工作区能力补齐（09-25）

与桌面端同批次的 0.1.7-rc.1，重点是把 Web 端 Agent 工作区重新组织：

- **终端整合进 Web 工作区**：侧边栏可直接开终端，支持多标签、Shell 选择、刷新后恢复，Agent 执行过程中的命令行操作不再需要切到外部终端。
- **Office 文档预览**：侧边栏可直接预览 Word／Excel／PowerPoint／CSV／TSV，Excel 支持工作表、单元格、公式查看与复制。
- **插件体系扩张**：官方插件中已出现智能体团队（开启后同时启用团队协作、团队工具、团队面板，可管理成员、成员间消息与共享任务）、语音输入（首次使用在本地准备 SenseVoice 模型，支持 Hugging Face 与 HF-Mirror 下载源）、终端、Agent 循环、Subagent、网页搜索。
- **实验性能力尚未默认可见**：Browser Use 已加入 Playwright MCP、Chrome DevTools MCP、Stagehand 三种后端，但属实验性 npm 包，需显式挂载激活；Computer Use 同理。
