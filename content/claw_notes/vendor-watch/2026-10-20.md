## 国内厂商

### MiniMax：M3.1 Flash 正式上线

- 官方博客 **2026-10-19**（`minimax.io/blog/minimax-m31f`，`datePublished` 2026-10-19T00:00:00Z），正式推出 **MiniMax M3.1 Flash**。
- **身份揭晓**：此前在 OpenCode 上以匿名身份打榜的 **Space Bunny（太空兔）**，官方确认就是 M3.1 Flash 的早期版本。官方口径是匿名期间处理了 **超过 200 万亿 tokens**；平台侧（OpenCode）另称连续 12 天登顶、累计 106 万亿 tokens——两个数字出自不同主体，不宜合并引用。
- **定价**：每百万 tokens 输入 **$0.15**、输出 **$0.60**、缓存输入 **$0.015**（国内媒体换算为 1 元 / 4 元 / 0.1 元）。相较上一代，输入输出单价降幅过半、缓存读取降超七成。
- **官方自报能力**：线上推理速度提升近 3 倍，日常输出 200+ TPS、中位（P50）170+ TPS，官方解释是采用了更激进的稀疏化；DeepSWE v1.1 得 73.7%、BankerToolBench 76.2、OSWorld V2 61.7、Agents' Last Exam 29.6（官方称后两项为国产模型第一）、CyberGym 82%。
- **入口与形态**：已上线 MiniMax API、M Plan 订阅与 MiniMax Code 桌面端；**权重稍后开放**（官方博客只写「later」，未给日期，也未公布参数量与许可）；Pro 版本官方称「不久后推出」。
- 上下文窗口按官方文档口径为 1M tokens，支持可调思考深度。以上跑分均为厂商自报，无第三方同日复测。

## 国外厂商

### OpenAI：低资源编程语言的编码能力与两个新评测

- 官方发布 **2026-10-19**（`openai.com/index/low-resource-programming-languages`，RSS `pubDate` 2026-10-19 12:00 GMT ＝ 北京 10-19 20:00）。
- 背景：COBOL 支撑 40% 以上在线银行系统、80% 线下信用卡交易、95% ATM 交易；Fortran 用于天气预报与核反应堆安全分析。企业普遍反馈模型在这类语言上表现差，而这些系统文档缺失、原开发者流失、业务规则只存在于代码里。
- **MultiLangBench**（新评测）：跨 **20 种编程语言**，要求模型用指定语言从零构建 SQLite 兼容的数据库引擎，以数据库文件为共享接口，用参考 SQLite 实现校验内容；测试用例改编自 SQLite 现有测试套件。设置与测试套件已在 GitHub（`openai/MultiLangBench`）公开。
- **COBOL 迁移评测**（新评测）：把 COBOL 程序迁移到 C++ / Java / Kotlin / Python / Rust，用隐藏测试要求可观察输出**逐字节一致**才计通过；特意覆盖 COBOL 定点运算默认截断、错误处理会静默改变财务结果这类行为差异。
- **数字（官方自报）**：MultiLangBench 20 语言平均通过率 **GPT-6 Astra 87.4%**（GPT-5.6 Sol 26.8%），COBOL 单语言 10.9% → **72.1%**，20 种语言里 19 种超过 83%；**GPT-6 Luna 40.3%**，每样本成本约 **$0.77**（Sol 为 $3.48）。COBOL 迁移 **GPT-6.1 Sol** 低推理强度 **86.6%**（Sol 5.4%）、高推理强度 **97.9%**（接近饱和）。
- 这是**评测与能力披露**，不是新模型或新 API；官方也提示用于生产软件仍需专家审查。
- 其余官方入口本窗口无新增：`openai.com/news` RSS 最新即本条；Codex CLI 只有预发布 `rust-v0.164.0-alpha.4/5/6`（10-19），**正式版仍是 10-15 的 0.163.0**；错位报告列表最新 First posted 仍为 10/15。

### Anthropic：Claude Code v2.1.304

- 发布 **2026-10-19 21:34Z ＝ 北京 10-20 05:34**，是本周第一份有实质功能项的版本。
- 新增 **`/auto-mode-setup`**：引导式配置，读取项目与近期会话把环境教给 auto mode；同时扩到 Bedrock、Vertex、Foundry、Claude apps gateway 与关闭遥测的会话。
- 新增 **`/claude-api managed-agents-secure`**：把 Managed Agents 某智能体的设置与官方安全指南逐项比对，**只读不改**。
- 权限模型细化：`tool.check` 事件新增 `decider: "person"`——只有权限弹窗或宿主回调可以批准，无处可问时按插件给出的理由拒绝；同一事件新增 `e.isReadOnly`，标记本次工具调用是否为只读。
- 体验项：压缩摘要（Ctrl+O）里显示此前调用过的工具名；Pro/Max 恢复长期不活跃会话时提示这会占掉 5 小时额度的一大部分，可选继续或新开会话。
- 修复：批准 `ANTHROPIC_API_KEY` 或切换自定义 key 后组织策略要等一小时才刷新；Linux 沙箱 `denyRead` 通配含方括号（如 `[user-id]` 路由目录）导致命令起不来；`rm -r` 挂载盘或顶层目录（`/Volumes`、`/media`、WSL 的 `/mnt/c`）没拿到与 `rm -rf /Applications` 同级的确认提示；transcript GC 在磁盘写满时丢消息；插件在 `--max-turns`/Stop 之后仍靠派生智能体继续跑。
- 其余：`/news` 最新仍是 10-18 的公共利益基金公告；平台发布说明仍为 **October 15**；`/research` 索引无窗口内新 slug。
