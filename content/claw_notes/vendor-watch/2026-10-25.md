## 国内厂商

### 月之暗面：Kimi K3.1 Pro 发布，3 万亿级开源权重

- 官方博客 `kimi.ai/blog/kimi-k3-1-pro`（《Kimi K3.1 Pro Tech Blog: Advancing Open Intelligence》，页面日期 **2026-10-24**）；API 文档 `platform.kimi.com/docs/guide/kimi-k3-1-pro-quickstart`；海外站 `platform.moonshot.ai` 顶部横幅同步「K3.1 Pro has launched」。
- 定位：K3.1 系列**首个模型**，Kimi 迄今最强旗舰；**开放权重**、3 万亿级、100 万 token 上下文。
- 做法：**架构与参数量不变**，纯靠**后训练算力加码**——为支撑数百个下游领域的联合强化学习，重写了 RL 框架、长上下文推理、训练效率、沙箱基础设施、rollout 调度与环境质检平台。
- 规格：**2.8 万亿总参 / 1040 亿激活**，Stable LatentMoE，**896 专家激活 16 个**；上下文 **1,048,576 token**，最大输出默认 131,072、最高 1,048,576；输入支持文本、图片、视频，输出文本；思考常驻**不可关闭**，`reasoning_effort` 三档 low/high/max，默认 max。
- 编程：**Terminal-Bench 4.0 得 65.7%**（Claude Code harness，max effort），超 GPT-6 Astra（58.2%），距 Claude Opus 5.5（66.4%）仅 0.7 分；内部 **Kimi Code Bench 3.0 Long-horizon 61.2%**，K3 为 55.95%。官方称在低/中/高三档思考强度下都落在「性能–单任务成本」帕累托前沿。
- 3D：**BenchCAD 92.7%（带工具）**，接近 Opus 5.5（96.2%）与 Astra（95.9%）；不依赖 MCP 即可写并运行 Blender / SolidWorks / Rhino 脚本做参数化建模，贯通 Unity、Unreal、Godot、Three.js。同期 **3D Make** 在 kimi.ai 与 App 上线，可在线预览编辑、导出可打印模型。
- 金融：**OfficeQA Pro v2 64.4**，当前最佳，超 Opus 5.5（62.2）；内部 Financial Modeling 比 K3 高 **7.2** 分、Financial Research 高 **11.6** 分、Business Operation 约为 K3 的 **4.2 倍**。
- 幻觉：内部 **Kimi Hallu Bench Hard** 上声明级幻觉率由 **23.4% 降至 8.3%**，含至少一处事实错误的回答占比降至前代的 **42.4%**（官方说明这是压力测试，不代表日常错误率）。
- 其余对标：GPQA 94.2（Opus 5.5 为 96.1，仍落后）；Artificial Analysis 智能指数 **55.1**，官方口径全球第 4、开源权重第 1，较 K3 涨约 11 分；SWE-Marathon、HLE-Full、OfficeQA Pro、Automation 四项领先，属「综合接近、各有胜负」。
- 长程案例：基于开源人体解剖模型 human-atlas（296 个骨骼组件含软骨、402 个肌肉组件）自建行走动力学训练与评测流水线，**167 项任务、420 次独立评审**，把模拟人从「几秒内摔倒」做到**连续交替步态行走 11.2 秒**；奖励塑形失效时改为对仿真器做开环探查，定位并修正肩部肌肉力臂计算中的 **36 处错误**后重训控制器。
- 安全取舍（开源前提）：官方称后训练规模上升时发现网络攻防能力同步上涨，溯源到 mid-training 语料与 RL 环境混入网络相关内容，于是在**开源版的中训练与 RL 两阶段都剔除网络攻击相关数据**，保留通用编程任务。结果：内部 **xdev-bench-hard** 上未做剔除的检查点 pass@3 解出 **90.5%**，最终版 **81.0%**；官方称其攻击性网络能力仍低于公开三个月以上的前沿闭源模型。
- 开源与交付：**完整权重 11 月 4 日前发布**；同步发**高速版 Kimi K3.1 Pro Highspeed**，同智能、输出速度约 **2–3 倍**。
- 渠道：Kimi.ai 与 App（iOS / Android / HarmonyOS）、Kimi Work 桌面版 **3.1.0+**、Kimi Code（`/model` 选择）、Kimi API（`kimi-k3.1-pro` / `kimi-k3.1-pro-highspeed`）；API 客户可用**零数据留存**；Kimi Enterprise **默认关闭**，需管理员开启。
- 定价（方舟刊例价，与原厂对齐，人民币元 / 百万 token）：输入（未命中）**13**、输出 **68**、缓存命中 **1.3**；缓存写入 5 分钟 **13** / 1 小时 **26**（1 小时档即将开放）；不按上下文长度分段。开放平台最低充值 **10 元**，新用户 15 元代金券不可用于 K3.1 Pro。
- 退役节奏：**K2 系列自 10-31 起停止向新注册用户开放**（已注册不受影响），计划 **12 月底**全部下线。

## 本期判断

- **旗舰档位空了两周，补位的是月之暗面**：十月下旬以来国内没有新旗舰，K3.1 Pro 填的正是这个位置，而且是「架构不动、只加后训练算力」的路线——参数没变，分数涨了一档。
- **开源权重第一次摸到闭源第一梯队的边**：TB4.0 65.7 与 Opus 5.5 差 0.7 分、OfficeQA Pro v2 反超，这是国产开源模型此前没有过的位置。但 BenchCAD、GPQA 仍落后，官方自己也只说「综合接近、各有胜负」。
- **开源与安全开始互相定价**：为了让权重能放出来，中训练与 RL 两阶段都剔了网络攻击数据，代价是 xdev-bench-hard 从 90.5% 掉到 81.0%。这条取舍写进了技术博客，比「安全声明」更有信息量。
- **渠道比模型快半步**：方舟 10-24 当天就接进两个个人套餐并给 5 折，但高速版没上——说明国内 ToB 渠道仍在等产能。
