## 1. Anthropic：`ant apply` 支持以代码管理 Agent 资源

**日期：2026-09-03**

- Claude Platform `ant` CLI 升级至 **v1.30.0**，新增 `ant apply`。
- 开发者可在代码仓库中用文件描述 agent、environment、skill、memory store 和 deployment，执行命令后预览并批准变更计划。
- 命令会生成 `claude-lock.json`；将其提交到版本库后，本地与 CI 后续运行会更新同一批资源，而不是重复创建。
- 这项更新把 Claude Platform 的 Agent 配置推进到类似 IaC 的可审计、可复现工作流，尤其适合团队协作和 CI/CD 部署。

来源：[Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview)

## 2. Google：Gemini 上线 Agentic Video Understanding

**日期：2026-09-01**

- Google 发布面向长视频分析的 **agentic video understanding**：模型不再一次性处理整段视频，而是按任务自主定位并检查相关片段。
- 官方给出的结果是：相较基线方案，最高可减少 **88% token 消耗**、降低 **66% 成本**，并将质量提升最高 **7%**。
- 该方向的工程价值在于把长视频理解从“大上下文一次性吞入”转为按需检索与多步分析，更适合长视频问答、内容审核和视频研究类 Agent。

来源：[Google：Introducing agentic video understanding with Gemini](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-agentic-video-in-gemini)

## 重点关注

**本轮最值得工程侧关注的是“Agent 资源工程化”和“按需多步理解”两条路线。** Anthropic 的 `ant apply` 让 Agent 配置具备版本控制、计划审查与 CI 可复现能力；Google 的视频理解方案则通过 Agent 主动选择片段，显著降低长视频任务的 token 与成本。两者共同表明，厂商竞争正在从单纯扩大模型能力，进一步转向可部署、可审计、成本可控的生产级 Agent 工作流。
