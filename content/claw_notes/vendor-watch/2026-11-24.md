## Anthropic：Claude Ship（beta）

11-23 上线，由三件东西组成，目标是"让代码交付速度追上团队的编写速度"。

- **Code Review（GA）**：从多个角度审 PR，收集问题后做对抗性验证再分类发回 PR；每个仓库可选 **Quick / Standard / Deep** 三档强度。官方给的内部数据：Claude Code 团队 2026 年 6–9 月合并的 PR 数**翻倍**，回滚比例**下降超过 40%**。
- **PR Steward（beta）**：专门让 PR 保持"绿色"，但**设计上不允许它批准或合并**。自动处理 CI 失败、合并冲突、来自 Code Review 与其他审查工具的反馈；每次推送后评论说明改了什么、怎么回滚；开发者用 `@claude` 引导、`@claude stop` 叫停。
- **Claude Approvals（beta）**：用仓库里的**策略文件**执行审批，相当于一个更聪明的 CODEOWNERS。策略允许时 Claude 可自主批准常规变更，特定场景仍要人工签署；决策可基于 Code Review 结果或自定义的自然语言分类器。官方建议先在"仅观察"模式跑一段时间再挂分支保护。

**使用方式**：开发者在 Claude Code 里跑 `/ship`（自动推送、建 PR、审查、处理反馈与失败检查），命令已开始在 Claude Code 与桌面应用推出；管理员按仓库开启，配置审查档位、运行时机、支出上限，兼容既有分支保护与必需检查。

**限制**：仅 Claude Team 与 Enterprise、仅 GitHub 仓库；不支持 ZDR、HIPAA 配置或客户自管加密密钥的组织。按 token 计费，Code Review 与 PR Steward 可设支出上限，Approvals 无基础费用但分类器按 token 计（即便在观察模式）。Enterprise 组织可领**至少 $10,000** 的额度，2027-01-15 前领取、30 天内用完。客户侧点名 TELUS 与 Carvana。

11-23 起向 Plus / Pro / Business / Enterprise 铺开一个**为聊天页优化**的 GPT-6.2。官方测试：图像理解 **71.7%**（GPT-6 为 47.4%）；高难 prompt 的指令遵循 **78.1%**（62.5%）；最低推理档的专家级任务内部评测 **65%**（52%）；内部版 BrowseComp 四个推理档全部超过 GPT-6，**xhigh 档高约 10 个百分点**。还加了"知道什么时候该追问"——比如问某物是否在促销，模型会主动提议降价时通知你。

## OpenAI × Cisco：Shirudo

11-23 联合发布并开源 **Shirudo**（日语"盾"），一个保护**运行中 Linux 系统**的运行时：补丁要几天到几周才铺得完，先用 eBPF 打一层临时防护，不必重启、不必中断服务。

- **机制**：eBPF 盾阻断有漏洞的代码路径，团队可先观察影响再决定强制；盾加载前需签名并经验证器检查，TPM 记录加载与移除，操作者可事后核查。
- **给智能体留的口子**：AI 可调查漏洞、写盾、针对真实负载验证，但**部署权仍在安全团队手里**。
- **演示**：用 Codex 生成盾，在运行中的 Elasticsearch 上拦下 Java4Shell 利用，服务不中断。
- **获取**：BSD 2-Clause 开源（BPF 程序 BSD/GPL 双许可），VM quickstart、Isovalent 自助实验室，12-15 有技术网络研讨会。

## Google：文件切片控制（Gemini API）

11-23 官方博客 + 文档。开发者可在**服务端**指定只加载文件的某一部分，不必整份上传处理，覆盖 PDF / Office / OpenDocument / 表格 / 音频 / 视频，**所有 Gemini 4 模型可用**，原有大小与页数上限不变。

- 文档幻灯：`start_page`/`end_page`、分辨率、内容图层（文字或页面图像）。
- 表格：`sheet_index`、`visible_cells`、图层（数值 / 公式 / 可视化）。
- 视频音频：时间区间、fps、图层（转录 / 帧 / 音轨）。
- **按实际查看的部分计费**。早期采用者数据：Vercel 用文本略读比整份 PDF 渲染**省 14 倍** token；LiteLLM 的 PDF 提示 token **减 67%**、工作簿**减 33%**。
- 附带好处：多模态 harness 不必再在客户端跑 LibreOffice、PDF 渲染器和 ffmpeg 做本地切片。

## DeepMind：用智能体团队 + 形式化验证改进量子算法

11-23 16:59 UTC，DeepMind 与 Google Quantum AI 合作。做法是把每个问题交给**相互独立的 Gemini 4 智能体团队**，想法必须用 **Lean** 证明通过才能进共享笔记本；每四小时各团队开一次"虚拟会议"交换、辩论、比较思路，成本随实验推进逐步下降。

- 惯性约束聚变的某个关键量：电路成本降 **11.8×**，纠错量子比特 **5,650 → 4,338**。
- 常见光敏分子的量子模拟便宜 **8×**（改写粒子位置与电场力的跟踪方式）。
- 药物代谢酶 **CYP450**：**2.5×** 改进，量子比特 **481 → 333**（去掉笨重的内存查表）。
- 基础算法：Grover 某实现 **2.57×**，arcsin 例程 **290×**。
- 开源了 Lean 量子算法库、题目规格与已验证解（GitHub）。

## 阿里云：qwen-audio-3.1-live

11-23 上架（华北2 北京）。**实时双工语音对话**：应用或后台模型处理任务时，前台语音模型仍能与用户交谈，并在任务完成后播报进度与结果。

- 两种模式：**Client 模式**由应用处理任务，**Responses 模式**由百炼调用指定后台模型；两种模式都支持函数调用接业务工具。
- 能力边界：输入输出均为文本 + 音频；支持 Function Calling；**不支持**结构化输出、内置联网搜索、前缀续写、上下文缓存、批量推理。
- 计费：按会话时长（秒），连接建立后**单次至少 3 秒**，发文字、静音、空闲都计入；华北2 **0.003330 元/秒**，新加坡 **0.005177 元/秒**，后台模型按实际 token 另计。WebSocket 最多同时 5 条连接。
