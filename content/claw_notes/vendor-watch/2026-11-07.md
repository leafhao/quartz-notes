### Anthropic：把智能体记忆拆成两件事——写入判断，与离线「做梦」

- 位置：`anthropic.com/research/components-of-agent-memory`，`datePublished` 写 **2026-11-06T00:00Z**，sitemap `lastmod` **11-06T21:15Z＝北京 11-07 05:15**；作者 Lance Martin。
- 定义：这里说的「智能体记忆」是 Claude 从经验中获得、跨会话保留、可回读的上下文，**不含**改权重、单轮 in-context learning、以及 compaction（把旧回合压成摘要）。
- 两条机制：① **memory notes**——会话中把显著事件打标或写进记忆目录；② **dreaming**——用交互之间的空闲算力回看会话记录，纠错、生成新笔记与新的记忆表征（借 Letta／UC Berkeley 的 sleep-time compute 思路）。
- CL-Bench 1.0 上的能力递进：**Sonnet 4.6** 只会生成一堆未验证的猜测；**Opus 4.7** 把笔记并成单份文档并标注哪些已核对、哪些未确认；**Sonnet 5** 按评分器结果标已确认、答错就写更正；**Opus 5** 第一个闭环——每条规则都附「我怎么知道它成立」、附带此前问题的答案与自发现陷阱的警告；Opus 5.5 与 Sonnet 5.5 同样闭环，带记忆后与 Opus 5 大致持平。
- 提示词的反直觉结论：只告诉 Claude「有个记忆目录」、不告诉它怎么用，效果最好；而「只记失败」这类硬规则会让 Opus 5 和 Opus 4.7 明显掉分。对旧模型则相反——Sonnet 4.6 被要求「先读记忆再回答、并显式检验假设」后分数几乎翻倍；Sonnet 5 不用提示，10 次里有 9 次会自己先读，Sonnet 4.6 不到一半。
- Pokémon 对照（两次约 1 万步的快照）：**Sonnet 3.7** 事无巨细写档，每场战斗、每件道具、每个 NPC 各开文件，到 1 万步已在开第四套「master」记忆；**Fable 5** 只写了 2 个目录共 9 个文件加一个 `global.md`（当仪表盘：当前目标、打道馆的预案、自己的记忆使用规则），进度远超，最后通关。
- 记忆会跨会话放大错误：Claude 把 PokéCenter 错记在东侧，出洞就判定「Mt. Moon DONE」，随后三次掉下单向崖，最后写下「我不干了」退回 Pewter City。对同一份记忆跑 dreaming，它把笔记与会话记录对照、发现方位记错并改写，随后一次走到 Cerulean City。
- wiki 表征：用 5 月收购的 Stainless 的 35 万个内部文件（约 4.2 亿 token）建 25 题评测 + 搜索工具，让 Claude 用 dreaming 自建 wiki。**dreaming 从 2 个会话扩到 128 个会话，25 题的得分从 13% 升到 48% 的评分项**。
- 法律简报（Harvey LAB）：并发写共享「合同条款表」导致事实丢失，基于 wiki 生成的简报只覆盖 41/57 条事实（72%）；把指令改成「每份合同单独一页、逐字引用」后 **100%**。
- 工程侧落地：Claude Code 的 auto memory 只把 `MEMORY.md` 前 **200 行或 25 KB** 载入上下文，当作索引而非全量注入。
- 怎么读：这篇的价值是把「记忆」从口号拆成可测的两个环节，并给了一个明确取舍——**强模型给自由判断优于给规则，弱模型给流程优于给自由**。同时提醒成本：dreaming 要烧算力，注错一条笔记会跟着每一个会话走。

### Anthropic：Project EVE——Claude 在真实 MMORPG 里做交易、组队、当内鬼

- 位置：`anthropic.com/research/project-eve-claude-plays-mmorpgs/`，`lastmod` **11-06T17:09Z＝北京 11-07 01:09**；Anthropic Fellows Program 2026 年 4–7 月的工作，合作方为 EVE 系列的 Fenris Creations。
- 交易设置：Opus 4.6／4.7／4.8／Fable 5 各给 **30 亿 ISK**，在重放的真实挂单上交易（按对方要求不进正式服，自动交易违反游戏规则）；往返手续费约 **5.6%**。对照 20 多条规则策略、9 个两周窗口，**只有一条勉强打平**。
- 结果：六个月长周期（2024-10 至 2025-04、2025-10 至 2026-03）里模型持续盈利，Opus 4.6 约赚到初始资金的 **200%**，Fable 5 约 **600%**，平均收益三倍。策略几乎都是价差捕捉：毛利 8–13%，靠每天数百单跑量。
- 迟钝是真问题：2025-03 游戏上调销售税，Opus 4.7 中位数 **2.5 天**才发现，**43% 的 Opus 4.6 全程没发现**。
- 资金效率分化：Opus 系起步约用 60% 资金、期末漂到 40%；Fable 5 早期约 85%、末期仍在 70% 以上，且会把收益再投。
- 反向检验：加入压价合成单后利润降约 **35%**；改成方向性押注（按新闻与补丁预测涨跌）明显更差——Opus 4.7／4.8 常给出「淘金热卖铲子」式推理却不算供给端，Fable 5 会先翻历史数据找事件与供需的关系。
- 组队（EVE Frontier，正式服）：4 个 agent 一队（Opus 4.8 与 Fable 5），任务从建基地到造大型战舰。协调方式是「一人提议附证据，无人反对就执行」，偶发**礼貌死锁**（两条船互相谦让、谁也不动）。指定一名队员暗中破坏时，**队友几乎从未发现**。
- 脚手架决定上限：Fable 5 之前的模型写不出可用 scaffold（负责闪避、还击、把经验写进可检索手册）。在 Opus 4.8 写的脚手架上，Fable 5 队伍反复丢船、几天才过教学；换成 Fable 5 自己写的脚手架后**零丢船、12 小时内完成**，但仍不及熟练人类，且只在开发期见过的场景里可靠。
- 官方自述局限：价差捕捉吃的是 EVE 市场比真实交易所更低效；回放无法反映市场对 agent 行为的反作用。
- 怎么读：这是「智能体在真实经济里做决策」目前最可核对的一次实验，但结论别外推——**赚钱靠的是执行纪律与跑量，不是判断力**；一旦要判断方向，模型立刻退回编故事。

### Anthropic：Claude Code v2.1.319，auto mode 收紧

- 位置：GitHub `anthropics/claude-code` `v2.1.319`，`published_at` **2026-11-06T17:04Z＝北京 11-07 01:04**。
- 主要变化：关闭遥测／特性开关（含跑在 LLM 网关之后）时，auto mode 不再回落到内置分类器——服务器核不了验的调用改为**询问或拒绝**，可用 `CLAUDE_CODE_AUTO_MODE_SERVER=0` 恢复（Bedrock、Vertex、Foundry 行为不变）；终端支持 **MCP 任务**：MCP server 以 task 方式跑工具调用时直接转后台、完成后再告知，另有 `CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND` 可改回同步等待。
- 权限与观测：新增 `permissions.denyInsteadOfPrompting`（本该弹框等确认的调用直接拒绝、回合继续，覆盖终端、子代理与 teammates）；新增 `/claude-api latency-optimize`；`/usage` 增加今日／本周／本月花费（针对无花费上限的 Claude apps gateway 用户）；gateway 侧新增 `admin.pooled_conflict_rule` 与 `admin.pooled_priority_order` 决定多预算组的扣费顺序。
- 怎么读：这是把「自动执行」的判定从本地分类器挪到网关侧核验——**能力没变，能不能不问就动手变严了**。

### OpenAI：BioBasicsBench，用真实湿实验室数据考 agent（补录）

- 位置：`openai.com/index/measuring-how-ai-agents-handle-wet-lab-science`，`pubDate` **11-06 00:00 GMT＝北京 11-06 08:00**，落在上一窗口末尾，昨日漏收。
- 是什么：与酶设计公司 **Ligo** 合作的评测基准，**100 个任务**，覆盖蛋白质方法、成像与流式、定量与测定、核酸方法、分子克隆；数据由科学家用自己实验的原始材料构建（凝胶与印迹 31、方案记录 27、表格与仪器导出 20 含 FCS 原始文件、台面与试剂照片 18、显微图 14、测序文件 12、操作视频 7、琼脂板 7），配专家撰写的 rubric，经三轮审核。
- 规模：7 个模型（GPT-5.2 至 GPT-6 Astra）、37 个「模型×推理强度」组合、每组 5 次，共 **18,500 条结果**，指标为 mean reward。
- 分数（xhigh 档）：**GPT-6 Astra 66.7%**（95% CI 60.3–73.1，每题 4,704 输出 token）、GPT-6.1 Sol 62.0%、GPT-5.6 Sol 43.8%、GPT-6 Luna 38.3%、GPT-5.5 35.4%、GPT-5.4 33.2%、GPT-5.2 31.2%（27,620 token）。
- 观察：Astra 在低推理档就已领先且更省 token，官方归因于原生多模态；短板也具体——**假设压过对照**（菌落 PCR 挑了泳道 4/6/7/8，参考答案为 5/9/10）、**忽视矛盾数据**（液泡明暗只记一半）、菌落计数偏多约 **12%**。
- 怎么读：这是把「看原始实验数据」变成可打分，而不是新模型。官方自己写明分数涨不代表能在实验室做可靠判断——这也是生物安全侧要盯的曲线。
