# AI 厂商动态 | 2026-07-31

> 时间窗口：最近 7 天（2026-07-25 ~ 07-31）。Tavily 6 条查询（Anthropic / OpenAI / Google / Meta+HF / 国内综合 / 跨厂商行业），官方域名优先。

## 本周主线

1. **Google 把 Gemini 推向物理世界**：7-30 同时发布 Gemini Robotics 2 与 Gemini Robotics ER 2，主打「全身智能」（whole-body control）+ 多机器人协作，已通过 Gemini API / AI Studio / Gemini Enterprise Agent Platform 开放。
2. **Anthropic 从模型发布转向安全与能力实证**：Opus 5（7-24）落地后，本周连发密码学漏洞发现研究、网络安全评估三起真实事件复盘、开源权重立场声明。
3. **Kimi K3 冲击波扩散到监管层面**：美方（7-29 AP 报道）指控 Moonshot 以「covert」方式基于 Anthropic Fable 构建 K3；同期 WSJ 报道美国企业开始主动转向低价模型（含中国模型）控制成本。
4. **国内进入 Agent 办公混战**：阿里千问办公上线、字节四款 Agent 全部绑定飞书、腾讯 WorkBuddy 走跨平台路线。

## 🇨🇳 国内厂商

### 月之暗面（Moonshot / Kimi）
- **Kimi K3 冲击持续放大**：7-16 发布的 K3（开源权重 + 低价）被日本学者塚越健司（7-24）称为「击穿美国 AI 闭源高价售卖模式」，冲击力对标去年的 DeepSeek 时刻；上线两天即触及容量边缘（36氪 07-30）。
- ⚠️ **监管风险**：AP（07-29 更新）报道特朗普政府指控 Moonshot 用「covert 但不一定违法」的手段基于 Anthropic 的 Fable 构建 K3；Anthropic 等美国公司此前有类似蒸馏指控。
- El País（07-26）：K3 让硅谷警觉的核心逻辑 —— 当最强开源权重模型超过最强闭源模型，闭源定价的正当性受质疑。

### 阿里云 / 通义千问
- **千问办公上线**（07-27）：官网上线并开放 Windows / macOS Beta，由钉钉体系主导，被内部定位为 Agent 办公市场「拳头产品」，整合原有三款 Agent。
- **Apple 国行 AI 选定通义千问**（07-24 报道）：将成为国行 Apple Intelligence 的重要支撑，预计随秋季新品落地（合规 + 能力双重考量）。
- **财务侧**：截至 2026-03 季度，阿里云外部收入同比 +40%，AI 相关产品季度收入 89.71 亿元（占外部收入 30%，年化超 358 亿），百炼平台客户数同比 8 倍。

### 字节跳动（豆包 / 飞书）
- **Agent 全线绑定飞书**：飞书妙搭 OpenClaw 内置飞书、ArkClaw 走 Channel/消息渠道、扣子龙虾插件对接、Trae Work 授权打通飞书文档与多维表格。
- **规模数据**（截至 2026-06）：豆包大模型日均 Token 调用量突破 180 万亿；大模型业务 ARR 达 40 亿美元，超过国内其他模型公司 ARR 总和；飞书 Q2 新增客户中超九成同步采购飞书 AI 产品。

### 腾讯
- **WorkBuddy** 走跨平台路线：不与企业微信深度捆绑，主动打通飞书、钉钉，可通过微信/企业微信/QQ/飞书/钉钉远程操控 —— 与阿里、字节的「绑自家办公底座」策略明显分化。

### 深度求索（DeepSeek）
- InfoQ 周报（07-27）转述：梁文锋不满内部会议泄露，DeepSeek 或暂停融资。**非官方来源，仅记录待验证**。

### 榜单 / 生态
- 中国数据研究中心发布《2026 中国 AI 大模型竞争力 TOP20》（07-29）。
- 南京电信发布智云 TokenHub（07-26）：聚合天翼云、阿里云百炼、硅基流动、OpenAI 等渠道，一站式提供 DeepSeek / 通义千问 / Kimi / GLM / 豆包 / Seedance 等 180+ 模型，算力「即取即用」。

## 📊 行业信号（跨厂商）

- **市场集中度被官方量化**：法国竞争管理局（Autorité de la concurrence，07-18 意见书）认定 OpenAI、Google、Anthropic 合计控制 84% 的 AI agent 市场。
- **企业开始「AI 降本」**（WSJ 07-25）：美国企业不再无上限追加 AI 预算，转向更低价模型（含中国模型），可能重塑上游经济结构。
- **资本市场对 AI 支出反弹**（Fortune 07-26）：Meta / Microsoft / Apple / Amazon 财报撞上市场对 AI 资本开支的质疑情绪。
- **从业者呼吁「可减速」机制**（CNN 07-28）：主要 AI 公司员工联署公开信，要求建立能够放慢前沿开发节奏的技术与治理工具；Meta 拒评，Google 未即时回应。
- **开源权重成为政策焦点**：Anthropic 立场声明（限芯片 + 反工业级蒸馏 + 强制安全评估）与 Nvidia/Microsoft/Meta 的「反过度监管」形成对立阵营；蒸馏（distillation）成为华盛顿与硅谷共同的新关键词。
