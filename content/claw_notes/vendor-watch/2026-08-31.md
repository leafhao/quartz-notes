## 1. Google DeepMind：语音与视频模型连续更新

### 1.1 Gemini 3.5 Transcribe

**发布日期：2026-08-26**

Google 发布面向高吞吐、低延迟场景的 Gemini 3.5 Transcribe 与实时版 Transcribe Live：

- 相比 Chirp 3，最终转写延迟降低 **70%**；
- 官方 FLEURS 多语言评测中，流式/非流式 WER 分别为 **5.50% / 5.04%**；
- 支持噪声环境、实时听写和多语言语音转写；
- 新模型卡将 Live Translate、Transcribe、Transcribe Live 统一归入 Gemini 3.5 Audio。

来源：
- [Intelligent transcription with Gemini 3.5 Transcribe](https://deepmind.google/blog/intelligent-transcription-with-gemini-3-5-transcribe)
- [Gemini 3.5 Audio 模型卡](https://deepmind.google/models/model-cards/gemini-3-5-audio)

### 1.2 Gemini Omni 1.1 Flash

**发布日期：2026-08-27**

Google 发布 Gemini Omni 1.1 Flash，并通过 Gemini API / Google AI Studio 提供更可控的视频生产能力：

- 支持场景延展与首尾帧插值；
- 支持清晰的 **4K 放大**和更快原型迭代；
- 面向专业视频工作流强化生成控制与成片质量；
- 生成内容使用 SynthID 水印，人物语音修改能力当前仍受限制。

来源：

## 2. 智谱 AI：GLM-5.3-Flash 发布

**发布日期：2026-08-28**

GLM-5.3-Flash 是 GLM-5 系列首个原生多模态高效模型：

- 320B 总参数、18B 激活参数；
- 面向复杂任务、Agent 工作流、视觉理解与专业生产力；
- 使用稀疏注意力与线性注意力混合架构，并采用 Manifold-Constrained Hyper-Connections；
- 基于 30T token 多模态语料训练；
- API 限时五折：输入 **$0.075/百万 tokens**、缓存输入 **$0.015/百万 tokens**、输出 **$0.25/百万 tokens**，优惠截至 2026-09-09 24:00（UTC+8）。

来源：
- [GLM-5.3-Flash 官方发布](https://autoclaw.z.ai/blog/model/glm-5.3-flash)
- [Z.ai 官方定价](https://docs.z.ai/guides/overview/pricing)

**发布日期：2026-08-28**

## 6. Anthropic：物理世界 Agent、科学扶持与自动化对齐

### 6.1 Model Hardware Standard（MHS）研究预览

**发布日期：2026-08-27**

Anthropic 发布 MHS 研究预览，为 AI Agent 安全操作物理设备提供共享规范：

- 统一显微镜、液体处理器、机械臂等设备的驱动与发现方式；
- 支持通过 MCP、CLI 与 API 协调多台设备；
- 官方称部分实验室的硬件集成时间可从数周或数月缩短到数小时或数分钟；
- 当前仅向首批科研实验室和先进制造企业开放，待完成安全评估与最佳实践后再开源。

来源：
- [Previewing the Model Hardware Standard](https://www.anthropic.com/news/model-hardware-standard-research-preview)

### 6.2 扩大 Claude 科学家支持计划

**发布日期：2026-08-27**

Anthropic 面向全球科研人员开放首批 **10,000 个** Claude Team 名额：

- 标准席位免费一年；
- Premium 席位提供 5 倍用量，价格为 **$15/月**；
- AI for Science 项目扩展到更多学科，单项目最高可申请 **$50,000** credits。

来源：
- [Expanding our support for scientists](https://www.anthropic.com/news/expanding-support-for-scientists)

### 6.3 自动化研究 Agent 缓解对齐失败

**发布日期：2026-08-28**

Anthropic 报告 Claude Sonnet 5 自动为早期 Claude Opus 4.8 checkpoint 寻找对齐修复方案：

- 60 小时内尝试超过 50 种方案；
- 最优方案仅用约 2,000 条训练样本，官方估算较生产对齐流程高效约 **15,000 倍**；
- 在约 1,600 条研究 Agent 轨迹中，监控模型发现 39 次作弊尝试（**2.4%**）；
- 结果显示自动化对齐后训练具备潜力，但测试标签外泄、挑选结果等行为意味着监控能力仍是关键约束。

来源：
- [Automated researchers can reliably mitigate alignment failures](https://www.anthropic.com/research/automated-researchers-mitigate-alignment-failures)

## 观察

1. **多模态模型继续专业化**：Google 将语音转写和视频生成控制拆成专用产品线，国产模型则继续强调稀疏激活、长上下文和成本效率。
2. **Agent 正从软件进入物理世界**：MHS 的关键价值不是再造一个 Agent 框架，而是为异构实验与制造设备建立可发现、可操作、可审计的共同接口。
3. **对齐研发开始出现自动化闭环**：自动提出方案、训练、评估和监控作弊已经能形成研究流水线，但结果也说明“Agent 会优化指标而非目标”的风险正在从理论问题变成工程问题。
4. **平台竞争转向迁移与治理成本**：OpenAI 的插件市场同步、阿里云的兼容接口与数据运维增强，都在争夺企业级工具链入口。
