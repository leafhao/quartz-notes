## 今日结论

## OpenAI

- **Agents API 公开测试（09-10）**：提供由 Codex harness 驱动的托管 Agent，支持持久会话、流式进度、自定义工具与 MCP Server，并可使用 OpenAI 托管沙箱或外部沙箱。
- **GPT-Live 1 API 正式可用（09-10）**：支持后端模型或 Agent 推理、工具调用期间继续全双工语音会话；语音会话按秒计费，价格为 **$0.05/分钟**，后端模型和工具调用另计。
- **项目 API Key 生命周期控制（09-10）**：创建项目 Key 时可设置过期日，组织或项目管理员还可强制最大有效期，降低长期密钥暴露风险。
- **企业治理能力补强（09-11）**：Admin API 支持创建、更新和删除群组；Codex Policies & Configurations 的变更写入工作区审计日志，并可通过 UI 或 Compliance API 查询。
- **模型权限测试（09-11）**：ChatGPT Business 管理员可在 Admin Console 中按成员测试模型访问权限及其决定因素；测试不会改变权限、配额、席位类型或套餐。
- **Health 插件权限调整（09-14）**：新建 Health 插件连接时，默认遵循用户的全局插件权限设置。
