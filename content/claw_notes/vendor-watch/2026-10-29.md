## 国外厂商

### Google DeepMind：Gemini 4 Carbon —— 最强前沿模型，先只给网络安全防御者

- 发布：官方博客《Gemini 4 Carbon: our next frontier model》，`blog.google` 记 2026-10-28 17:00 UTC＝**北京 10-29 01:00**；作者 Koray Kavukcuoglu（DeepMind 高级副总裁、谷歌首席 AI 架构师）；DeepMind 站同步发专文（RSS 17:00:58 UTC）。距 Gemini 4 Argon 发布两周。
- 定位：官方称「我们最强的模型，具备 SOTA 的网络安全与长时程能力」。设计目标是更难的长时程工程问题与持续性的智能体工作流；内部团队观察到 Carbon 可**连续跑数天**，在大代码库与底层系统里做根因定位与隐蔽 bug 修复，遇到死胡同仍能推进。相对 Argon 的重点改进来自用户反馈：编码、智能体任务、科学任务、全栈 Web 开发、多模态理解。
- 综合评测：**Artificial Analysis Intelligence Index（刚更新的 v5.0）第 1 名，59 分**。
- 网络安全（官方注明为「无护栏状态下评估」）：**SEC-bench Pro 88.2%**（发现真实漏洞，SOTA）、**ExploitGym 54.8%**（验证可利用性，新 SOTA）、**CWE-bench 71.0%**（根因修复补丁）。覆盖「发现—验证—修复」全生命周期。
- 编码：**WebDev Arena 1768 分、第 4 名，较前代 +89 elo**。
- 内部/合作方数据（非公开第三方基准）：生成安全代码成功率较 Argon **提升 2 倍以上**；Chrome 团队称在生成高质量补丁上比另一家实验室的大型前沿模型**好 10 倍以上**；Wiz 称其在 Web 渗透测试基准上领先，支撑其 Scan for Good 计划。
- 对齐与安全（官方自报）：沿用 Argon 的多层栈（训练、实时滥用防护、提示注入韧性、思维链监控）。**Terminal-Bench 4.0 成功作弊率降至 0.0%**（尝试作弊率 0.4%），同时整体准确率提升；内部真实编码环境中**高严重度对齐告警下降近 80%**；无依据声称较 Argon **减少约 2 倍**；**过度越界减少 26%、服务不足减少 29%**；**Gray Swan 间接提示注入（IPI）攻击成功率 0.0%**（Argon 此前 0.7%，曾领先该基准）。
- 定价：以与 Argon 相同的**引入价**上线，输入 **$2**／输出 **$10**（每百万 tokens），缓存输入按输入价的 95% 折扣；**引入期结束后为 $4／$20**（官方脚注原文）。
- 可用性：**不是 GA，也不对开发者/企业/消费者开放**。正参与美国政府自愿性发布前模型测试；**本周起先向一部分网络安全防御者开放**，再经 **Fairwind Program** 分阶段扩到受信任伙伴；面向开发者、企业、消费者的产品面开放时间只说「尽快」，未给日期。Gemini API changelog 与 Gemini API 模型页截至发稿**仍无 Carbon 条目**，与「未对开发者开放」一致。
- 未披露：参数量、上下文窗口、架构、训练细节，官方一概没给。基准完整表格以图片形式呈现，正文只点了上述几个数。
- 同日谷歌其他条目均不计入：blog.google 有 Gemini App 沉浸式探索（消费端功能）、Q3 财报 CEO 讲话、AI Mode 广告扩市场、与新加坡合作公共卫生（政府合作）；Cloud Blog 10-28 六条全是数据库/GKE/Agent Skills 工程文与 XREAL 硬件。

### OpenAI：ChatGPT 订阅者可按月领免费 API 额度

- 发布：API changelog **Oct 28**（Feature 条），配套文档《API credits for ChatGPT subscribers》已上线。
- 内容：符合条件的 **ChatGPT Pro 与 Business** 订阅可领免费 API 额度，把订阅绑定到自己拥有的 API 组织即可激活；**每月最高 500 美元**，随订阅续费自动发放，**未用完的在计费周期结束时清零、不结转**；有额度时**无需绑定 API 付款方式**即可调用。
- 额度档位：Pro $100 档→$100/月，Pro $200 档→$200/月，Pro $500 档→$500/月；Business Standard **每付费席位 $20/月**，Business Premium **每席位 $100/月**，工作区内合并计算、**每工作区每月上限 500 美元**。年付工作区一次性发放全年额度，年底到期。
- 门槛：订阅需为付费且满 7 天（试用与赠送不算），且申请人须同时是该 ChatGPT 订阅/工作区与接收额度的 API 组织的 owner，两边邮箱需一致。首笔额度按当期剩余天数折算。
- 定性：这是权益与渠道侧的定价动作，不是模型或接口能力更新。同窗口 OpenAI 只有三篇非技术稿：ServiceNow 合作扩展（10-28 13:15 UTC）、观点专栏《The future of the firm》（10-28 10:00 UTC，明确标注「仅代表作者个人观点」）、Legora 客户案例——均不计入。

## 国内厂商

### 腾讯混元：开源中文逻辑推理基准 HyperLogic

- 发布：`Tencent-Hunyuan/HyperLogic` 仓库与 Hugging Face 数据集 `tencent/HyperLogic` 于 **2026-10-28** 公开发布（仓库 10-27 建、10-28 15:09 UTC 定稿 README）。Apache 2.0，论文 arXiv 2605.19597。
- 内容：中文逻辑推理基准，答案由**执行推导**得出（execution-derived），分 **Seed / Base / Hard** 三档；本次公开每档约 **30%** 的条目与标准答案、直答 prompt 与打分器，以及 **Hard 档完整 agent 评测**（两种沙箱条件、原始 payload、逻辑建模库）。
- 榜单（7 个前沿模型，最高推理档，三次 rollout）：Seed 档 GPT-5.6 Sol 89.8、Claude Opus 5 86.5、Kimi K3 88.6、Grok 4.6 87.0、DeepSeek V4 Pro 83.9；**Hard 直答档全线崩塌**——Opus 5 仅 15.6%、GPT-5.6 Sol 13.7%、DeepSeek V4 Pro 9.3%、Kimi K3 4.0%；给沙箱后 Opus 5 升到 55.7%，再加逻辑建模库 57.0%。
- 读法：这是评测资产不是模型，但结论有信息量——**中文硬逻辑推理在无工具条件下仍是所有前沿模型的短板**，工具与建模库能把分数抬 3～4 倍。
