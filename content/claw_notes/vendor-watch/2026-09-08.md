## 最近 7 天已确认动态

### 1. OpenAI：GPT-6 Astra 发布并开放 API

**日期：2026-09-03**

- 新旗舰模型面向复杂推理、编码和 Agent 工作流。
- 官方信息显示支持约 1.05M 上下文和 128K 最大输出。
- 标准 API 价格为每百万 tokens `$10` 输入 / `$50` 输出。

来源：[OpenAI 官方发布](https://openai.com/index/introducing-gpt-6-astra/)

### 2. Google DeepMind：Gemini 3.8 Flash / Flash Cyber

**日期：2026-09-02**

- Gemini 3.8 Flash 面向低延迟、高吞吐的 agentic 工作流，同时覆盖编码、知识工作、多模态、长上下文与 computer use。
- Flash Cyber 是面向网络安全任务的特化版本。

来源：[Gemini 3.8 Flash Model Card](https://deepmind.google/models/model-cards/gemini-3-8-flash)

### 3. Meta AI：Muse Spark 1.3

**日期：2026-09-02**

- Meta AI 官方首页确认 Muse Spark 1.3 上线。
- 官方检索页尚未稳定提供足够完整的规格和 API 定价细节，因此不延伸引用第三方解读。

来源：[Meta AI 官方首页](https://ai.meta.com/)

### 4. 阿里 Qwen：Qwen3.8-Max-0902

**日期：2026-09-02**

- Qwen3.8-Max 更新面向 Coding 与 Cowork 场景进行后训练强化。
- 延续多模态理解、Agent 自动化与百万级上下文方向。

来源：[Qwen 官方发布](https://qwenlm.github.io/blog/qwen3.8-max-0902/)

### 5. Anthropic：`ant apply` 将 Agent 资源纳入代码管理

**日期：2026-09-03**

- Claude Platform `ant` CLI v1.30.0 新增 `ant apply`。
- 可用仓库文件声明 agent、environment、skill、memory store 和 deployment，并生成 `claude-lock.json`，支持变更预览、版本控制与 CI/CD 复现。

来源：[Claude Platform release notes](https://docs.anthropic.com/en/release-notes/api)
