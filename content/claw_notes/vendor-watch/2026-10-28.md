## 国外厂商

### Google DeepMind：Genie 4 —— 首个原生生成音频的实时世界模型

- 发布：官方博客《Genie 4: A new generation of world simulation》，`blog.google` 记 2026-10-27 16:00 UTC＝**北京 10-28 00:00**；DeepMind 站同步发专文。
- 定位：官方称其为「首个原生生成音频的实时世界模型」。此前 Genie 系列只生成画面，Genie 4 把声音与世界一起生成——环境音（树林风声、海浪）、音乐、以及**可与用户对话的角色语音**，全部实时产出，博客示例视频的音效均由模型直接生成。
- 架构：Gemini Omni 负责把模拟锚定在真实世界的视觉与行为上；其他 Gemini 模型提供推理以维持连贯性。机器人/仿真场景下由 **Gemini 3.8 Flash 充当引导智能体**（观察画面、把目标拆成步骤、逐帧审查进度），**Gemini 4 Argon** 负责把用户任务拆解成步骤。
- 四项能力：① 自然语言实时塑形世界（移镜头、改天气、引入人物或物体，Gemini 会结合上下文适配提示）；② 物理与人体动作拟真（空气动力学、碰撞、角色自然移动并可实时引导）；③ 世界声音建模（原生音频＋交互对话）；④ 复杂事件模拟（依赖 Gemini 的因果性与多步推理）。
- 硬指标：官方**未公布**分辨率、单次会话时长、帧率、延迟或任何 benchmark；也**未公布**参数量与训练细节。博客只做定性描述，这一点与去年 Genie 3 发布时给分辨率与时长的做法不同。
- 可用性：以**研究预览**形式限量开放给 trusted testers（覆盖创意、新闻、教育、游戏、工程）；Google AI Ultra 订阅者走 **Project Genie**（「即将推出」，已有等待名单）；**Gemini API 与 AI Studio 早期访问合作伙伴**同列「即将开放」。
- 官方自陈局限：长时间运行、多次复杂提示编辑、场景导航后，视觉细节与**物体永久性会漂移**；复杂物理交互、实时音频准确性、可读文本渲染、空间准确性、长期一致性均未收敛——短会话可保持连贯，长会话问题明显。
- 安全：上线前过内部安全评测；所有生成的视频与音频**嵌入 SynthID 不可见水印**。
- 方向：官方提出「混合世界模型」——语言/代码模型负责结构化推理与叙事时间线，Genie 负责像素级即时物理现实，目标是比单一路线更连贯、更可控、更有依据。

### Google Cloud：Gemini Robotics ER 2 公开预览

- 发布：Google Cloud 官方博客，2026-10-27 13:00 UTC＝**北京 21:00**；作者为 DeepMind Robotics 负责人 Carolina Parada 与 Applied AI 的 Adrian Jones。
- 定位：机器人的「高层大脑」，专门做具身推理——时空视频理解、跨数百个决策/数分钟的长时域规划、多机器人协作（共享工作空间语义、分工与任务交接）、自然语言交互与动作解释、把 VLA 模型/导航 API/自定义函数声明为工具来编排。跨载体通用：固定机械臂、轮式、四足到人形。
- 指标（官方自报）：**关键事件帧定位准确率 91.3%**、**平均绝对帧距离 0.96 秒**、执行速度约为许多更大模型类别的 **4 倍**，算力成本只有大型模型的一小部分；任务进度可按二元状态/离散类别/连续评分三档输出，支持**10 类以上仪表**读数（圆盘、视镜、数字屏、线性刻度、标尺、液体温度计等）。
- 工具链：仿真支持 **MuJoCo-Warp** 与 **NVIDIA Isaac Sim**（可用多模态模型生成合成场景并自动标注工位图像）；训练侧用 Cloud Storage＋BigQuery 整理标注示范视频，VLA 训练走 Gemini 平台、GKE 或 Cluster Director；部署侧靠 IAM 与 function calling，SLAM/路径规划等时延敏感负载下沉到 Google Distributed Cloud 边缘。
- 可用性：**公开预览**，经 Model Garden 接入；文档在 `gemini-enterprise-agent-platform/models/gemini/gemini-robotics-er`。官方博客**未给具体模型 ID 字符串、区域清单与价格数字**，只指到定价页。
- 客户背书：Boston Dynamics（Spot 的 AIVI-Learning 用户数月增指数级）、DeepReach、Arm、ASTAR IMRE/MARVEL-AI（用 ER 2 操作无 API 的老旧触摸屏微波反应器、天平、离心机，做自驱动实验室）。

## 判读

- 谷歌这一夜的重心是「世界模型进入有声阶段」：Genie 4 把音频与世界一起生成，并把对话能力嵌进模拟本身，这是从「可玩的视频生成」往「可交互环境」迈的关键一步；但它仍是研究预览，硬指标一个没给，官方自己列了六条局限，离可用产品还有距离。
- ER 2 的意味更实际：Gemini 在机器人侧从「视觉语言模型」变成「能被工具编排的高层大脑」，公开预览＋Model Garden 接入意味着企业可以真接。91.3% 的关键帧定位配合 0.96 秒的帧距误差，指向的是「过程可验证」而不是「动作更准」。
- 国内这一天只有阿里云补了实时语音的一档（flash），其余七家全静默——连续第三天没有新旗舰。OpenAI 与 Anthropic 本期都是工程侧：Codex 补云厂商入口和记忆，Claude Code 修的是超长上下文文件被截断覆写这种会真丢内容的问题。
