# AI 厂商动态 | 2026-08-29

> 监控窗口：2026-08-23 至 2026-08-29。仅收录可由官方页面明确核验日期的更新；自媒体、社区猜测、无日期页面及窗口外内容均已过滤。

## 本期摘要

本期确认 **3 家厂商、4 项窗口内官方更新**。重点是智谱发布原生多模态高效模型 **GLM-5.3-Flash**，以及腾讯发布并开源新一代旗舰预览模型 **Hy4 preview**。阿里云百炼则连续更新 OpenAI 兼容视觉调用与模型数据导入能力。

## 1. 智谱 AI：GLM-5.3-Flash 发布

**发布日期：2026-08-28**

智谱发布 GLM-5.3-Flash，这是 GLM-5 系列首个原生多模态模型：

- 320B 总参数、18B 激活参数；
- 面向复杂任务、Agent 工作流、视觉理解与专业生产力场景；
- 使用稀疏注意力与线性注意力混合架构，并采用 Manifold-Constrained Hyper-Connections；
- 基于 30T token 多模态语料训练；
- API 限时五折：输入 **$0.075/百万 tokens**、缓存输入 **$0.015/百万 tokens**、输出 **$0.25/百万 tokens**，优惠截至 2026-09-09 24:00（UTC+8）。

来源：
- [GLM-5.3-Flash 官方发布](https://autoclaw.z.ai/blog/model/glm-5.3-flash)
- [Z.ai 官方定价](https://docs.z.ai/guides/overview/pricing)

## 2. 腾讯：Hy4 preview 发布并开源

**发布日期：2026-08-28**

腾讯混元发布新一代旗舰模型 Hy4 preview：

- 已开源，并在腾讯云、OpenRouter 上线，也可在 CodeBuddy、WorkBuddy、元宝、ima 中体验；
- 聚焦软件工程、办公分析、游戏开发和科学研究等生产力场景；
- 官方明确其仍是 Hy4 的早期预览版本，已知问题包括复杂任务中的长思考和过度自我验证；
- API 定价（每百万 tokens）：缓存输入 **0.3 元**、输入 **6 元**、输出 **18 元**；
- 腾讯云 TokenHub 已支持 OpenAI Chat Completions、OpenAI Responses 与 Anthropic Messages 三种协议调用 `hy4-preview`。

来源：
- [腾讯混元 Hy4 preview 官方发布](https://hy.tencent.com/research/hy4-preview)
- [腾讯云 TokenHub 调用概览](https://cloud.tencent.com/document/product/1823/130079)

## 3. 阿里云百炼：两项平台/API 更新

### 3.1 OpenAI 兼容接口新增 Vision 调用模式

**发布日期：2026-08-27**

新的 Vision 调用模式允许现有 OpenAI 兼容框架仅调整 `API-KEY`、`BASE_URL` 与 `model` 参数，即可调用千问视觉模型，降低从 OpenAI 接口迁移与工具集成的成本。

### 3.2 模型数据导入增强

**发布日期：2026-08-29**

模型数据导入新增更详细的失败与部分成功错误信息，并支持对模型数据发布及导入过程进行状态轮询。

来源：
- [阿里云百炼 Model Studio 功能更新](https://help.aliyun.com/en/model-studio/model-release-notes)
