# AI 厂商动态｜2026-09-11

> 本期最重要变化来自 DeepSeek：V4.1 Flash 正式发布并降价，旧 Flash 已被兼容路由，V4 Pro 也将在 9 月 14 日起临时切换到 V4.1 Flash。OpenAI 同日推出 Agents API 公测，把 Codex 的长程 Agent harness 作为托管 API 开放。

## 1. DeepSeek 发布 V4.1 Flash，并调整 API 路由与价格

**发布日期：2026-09-10**

DeepSeek 正式发布 **DeepSeek-V4.1-Flash**。这是其新模型结构系列中的小尺寸型号，原生支持多模态视觉理解，目标是提升能力上限、推理速度、吞吐与后续参数扩展能力。

### API 与迁移变化

- 新模型通过 `deepseek-flash` 调用，支持思考/非思考模式、图像理解、Tool Calls、Responses API 与 Anthropic API。
- 上下文长度为 **1M**，最大输出长度为 **384K**。
- `deepseek-v4-flash` 与 `deepseek-v4-flash-vision-exp` 对应旧模型已下线；旧模型名暂时仍可用，但会被路由至 V4.1 Flash。
- DeepSeek 表示 V4.1 Flash 在性能、费用、速度和总用时上已全面超过 V4 Pro。**北京时间 9 月 14 日 12:00 后**，在 V4.1 Pro 上线前，`deepseek-v4-pro` 请求将被路由到 V4.1 Flash，并按 Flash 价格计费。

### API 新价格

空闲时段为工作日高峰价的一半；高峰时段为北京时间周一至周五 9:00—12:00、14:00—18:00。

- 缓存命中输入：空闲 **0.02 元/百万 tokens**，高峰 **0.04 元/百万 tokens**。
- 缓存未命中输入：空闲 **1 元/百万 tokens**，高峰 **2 元/百万 tokens**。
- 输出：空闲 **4 元/百万 tokens**，高峰 **8 元/百万 tokens**。
- 官方并发限制为 **2500**。

### 官方披露的部分成绩

GPQA Diamond 90.9、Terminal-Bench 2.1 90.6、DeepSWE v1.1 74.2、HLE（带工具）63.9、Chartography（带工具）78.9。基准仅作厂商自报参考，真实工程效果仍需独立验证。

来源：[DeepSeek 官方更新日志](https://api-docs.deepseek.com/zh-cn/updates) · [DeepSeek 官方模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)

## 2. OpenAI 推出 Agents API 公测

**发布日期：2026-09-10**

OpenAI 发布 **Agents API** 公测版，把支撑 Codex 的 Agent harness 与运行基础设施开放给开发者，用于构建和运行云端托管 Agent。

核心能力包括：

- 管理上下文并高效使用工具；
- 在可访问文件、运行代码、保存中间结果的环境中，可靠执行持续数天的任务；
- 原生支持多 Agent，把复杂任务拆成独立子任务并行执行，各子 Agent 保持独立上下文，由主 Agent 统一协调；
- 当前处于 public beta，后续将根据开发者反馈迭代至正式可用。

这比单纯开放模型接口更接近“托管 Agent runtime”：开发者可以少造一层任务编排、上下文管理和长程执行基础设施。

来源：[OpenAI 官方公告](https://openai.com/index/introducing-the-agents-api)

## 3. 腾讯云 TokenHub 提醒旧视觉模型迁移

**官方文档更新时间：2026-09-08**

腾讯云 TokenHub 已为 Kling、Vidu 与 HY 系列视觉模型上线按 Token 计费的新版本，并公布旧版下线安排：

- Kling、Vidu、HY 图片生成旧版本：**9 月 15 日 00:00** 起停止调用；
- HY 视频生成旧版本：**9 月 21 日 00:00** 起停止调用。

依赖这些旧模型 ID 的业务需要提前按官方映射表迁移；不同版本的调用参数、输出效果和适用范围可能不同，不能只替换名称后直接上线。

来源：[腾讯云 TokenHub 官方模型价格与迁移说明](https://cloud.tencent.com/document/product/1823/130055)

## 观察

本期的主线不是模型数量增加，而是 **Agent 基础设施产品化** 与 **国产模型 API 性价比继续下探**：OpenAI 将 Codex harness 开放为托管 Agents API，DeepSeek 则用 V4.1 Flash 同时替换旧 Flash 和阶段性承接 Pro 流量。对开发者最实际的动作是检查 DeepSeek 模型名兼容性、9 月 14 日后的路由变化，以及腾讯云视觉模型的下线迁移期限。
