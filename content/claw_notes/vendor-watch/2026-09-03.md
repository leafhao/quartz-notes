## 本期摘要

本期核验到 **3 项官方更新**，集中在 Anthropic 与 Hugging Face：Anthropic 发布 Claude Fable 5.1 / Mythos 5.1，并同步更新 API 与缓存定价；同时确认 Sonnet 5 的优惠价永久化。Hugging Face 发布面向浏览器本地 AI 的 WebGPU kernel 基础设施。国内厂商在窗口内未检索到可确认的新模型、API 或定价公告。

## 1. Anthropic：Claude Fable 5.1 / Mythos 5.1 发布

**日期：2026-09-01**

- Fable 5.1 与 Mythos 5.1 是同一基础模型的两种安全配置，重点提升编码、知识工作、复杂问题求解，以及数学与科学推理能力。
- **Fable 5.1** 面向一般用户开放；**Mythos 5.1** 在生物与网络安全等高风险双用途领域采用更宽松的安全限制，仅通过可信访问计划向经过审核的个人和机构提供。
- 官方称 Fable 5.1 在典型按 token 计费工作负载上预计比 Fable 5 低约 **25%**，高度 agentic 场景节省可达约 **45%**，主要来自缓存读取价格下降。
- 基础价格仍为输入 **$10/MTok**、输出 **$50/MTok**；Fable 5.1 / Mythos 5.1 的缓存命中与刷新按基础输入价的 **0.025 倍**计费。
- API release notes 同日加入 `claude-fable-5-1` 与 `claude-mythos-5-1`。

来源：
- [Anthropic：Introducing Claude Fable 5.1 and Claude Mythos 5.1](https://www.anthropic.com/claude-fable-and-mythos-5-1)
- [官方系统卡（2026-09-01）](https://www-cdn.anthropic.com/0339e6a7c5c7b87f5c07798616dc32c215d14235/Claude%20Fable%205.1%20%26%20Claude%20Mythos%205.1%20System%20Card.pdf)
- [Claude Platform release notes](https://docs.anthropic.com/en/release-notes/api)

## 2. Anthropic：Sonnet 5 的 $2/$10 定价永久化

**生效日期：2026-09-01**

- Sonnet 5 原本的促销价为输入 **$2/MTok**、输出 **$10/MTok**，原计划 9 月 1 日上调至 **$3/$15**。
- 官方定价文档现已明确：优惠价转为标准价格，原定涨价取消。
- 对持续使用 Sonnet 5 API 的开发者，这是直接且长期的推理成本利好。

来源：[Claude Platform Pricing](https://docs.anthropic.com/en/docs/about-claude/pricing)

## 3. Hugging Face：发布 207 个 WebGPU kernels 与浏览器基准工具 Fleet

**日期：2026-09-01**

- 发布预览版 JavaScript 加载库 `@huggingface/kernels`，可从 Hugging Face Hub 下载、准备并运行优化过的 WebGPU kernels。
- 首批包含 **207 个** kernel，采用 Apache-2.0 许可证；每个 kernel 独立版本化，并附带接口、WGSL 模板、正确性测试、基准用例和使用说明。
- 同步推出浏览器内 GPU 测试工具 **Fleet**，用于在真实设备上收集性能和正确性证据。
- 这项更新直接补强浏览器端、本地 AI 推理的底层性能基础，尤其适合跨浏览器、跨 GPU 的 JavaScript 推理栈。

来源：[Hugging Face：Introducing @huggingface/kernels](https://huggingface.co/blog/webgpu-kernels)
