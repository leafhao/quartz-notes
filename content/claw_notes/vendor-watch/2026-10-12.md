## 国外厂商

### OpenAI

- **GPT-6.1 Sol 默认上下文从 272k 提升至 500k，订阅不再收长上下文费用**（28 天冲刺 **Day 7**，官方 X @thsottiaux 太平洋时间 **10-11** 宣布，中文媒体 10-12 上午转述）：
  - 调整对象是 **Codex 与 ChatGPT Work 环境下的默认值**：272,000 → **500,000 tokens**，增幅约 **80%**。Tibo 称 500k 是团队反复测试后为多数用户找出的「体验与性能最佳平衡点」，**未来还会继续提高上限**。
  - 这是**抬高默认值，不是抬高模型上限**：用户仍可手动调高或调低，GPT-6.1 Sol 支持的最大上下文仍为 **1M**。此前大窗口只能手动配置，本次变成新默认。
  - **计费侧配套变化**：从订阅中扣减用量时，OpenAI **不再对 GPT-6.1 Sol 收取长上下文费用**。按官方定价表（输入 $2 / 输出 $10 / 缓存输入 $0.10 每百万 token），500K 窗口若全未命中缓存仅输入就接近 1 美元，命中缓存则约 5 美分——扩容红利几乎完全取决于缓存命中率。
  - 实际收益只属于**峰值 token 长期超过 272k 的长任务**（整库代码、长篇报告、跨多轮细节任务）：更少触发自动上下文压缩，前几轮的工具结果与边界条款不再被折叠成短摘要。峰值在 272k 以内的日常使用基本无感。
  - 本日是**改进（improvement）而非额度重置（reset）**，没有新的用量刷新。
  - **28 天冲刺全程背景**（10-04 由 Tibo 宣布，10-05 至 11-01，每天交付一项明确改进或一次全量重置）：Day 1（10-05）订阅侧 GPT-6 Astra / Sol 默认提速约 50%；Day 2（10-06）Codex Auto-review 免费 + API 付费档位 5→3 + Meetings 插件 + Decisions API 公开测试；Day 3（10-07）banked reset + GPT-6 / Intelligent UI 进 ChatGPT + Codex Cloud with Tailscale；Day 4（10-08）Instant steering + Sol Ultrafast；Day 5（10-09）Composer predictions + 移动端创建 dots + dots 管理 Codex 任务；Day 6（10-10）Automatic；Day 7（10-11）500k 默认上下文。

## 补录（先前窗口遗漏，本窗口补齐）

### Anthropic — Managed Agents 支持「动态工作流」（官方 2026-10-09，**补录**）

- **官方来源**：Claude Platform release notes（`docs.anthropic.com/en/release-notes/api`）的 **October 9, 2026** 条目。这是 Anthropic 平台级能力的**唯一**落点——`anthropic.com/news` 与 `/research` 都不会出现这类条目。
- **官方正文口径**：可让 Claude Managed Agents 的 agent 使用 **dynamic workflows**（beta，需 `managed-agents-2026-04-01` beta header）。对于「分片很多」的工作（官方举例：审阅数百份文档），agent 可以**自己写一个 workflow**——一个分阶段跑多个 agent 并合并其结果的程序；服务器在后台把它作为一次 **workflow run** 执行。
- **开启与观测方式**：把 agent 的 `multiagent` 字段设为 `{"type": "multiagent_20261001", "workflows": {"type": "enabled"}}`；在 system prompt 里告知它何时启动 run；通过 session 事件流上的 `workflow_run.*` 事件跟踪每次运行。
- **第三方口径（非官方，仅作参考）**：The Decoder 转述称单次任务最多可并行 **1,000 个子智能体**；内部约 116,000 行代码库埋 70 个 bug 的对照里，单个 Claude agent 最多找出 27 个，多智能体动态工作流稳定找出 **66 个**（约 2.4 倍召回）；此前 Managed Agents 只能串行委派、结果全部回灌主 agent 上下文；Managed Agents 仍为 beta，暂不支持零数据保留与 HIPAA。
- **判定**：10-09、10-10、10-11 三期笔记均未收录该条目，属稳定性信源盲区（漏查平台 release notes），本次补录并在「教训」中登记入口。

### Google — AI Edge Foresight 本地会议笔记应用（官方 2026-10-06，**补录**）

- **官方来源**：Google Developers Blog，2026-10-06 与 EmbeddingGemma 2 同日发布。上一期（10-07 笔记）收录了 EmbeddingGemma 2，**漏掉同批的 Foresight**。
- **定位**：实验性 **macOS** 应用，官方称之为「把上下文感知的会议伴侣直接带到你的设备上」，**全部 AI 推理 100% 本地**，可「在飞机上或气隙安全设施里」使用。
- **模型分工**：检索与嵌入用 **EmbeddingGemma 2**（7.4 亿参数多模态，文本、图像、音视频帧、音频映射到同一向量空间）；笔记润色与问答用 **Gemma 4**；转写用端上语音识别。
- **功能**：分屏模式（左侧手写速记、右侧 AI 生成笔记）；通过麦克风与系统音频采集，**兼容任意会议软件、也可用于线下会议**；支持上传 PDF / Google Docs / Office / 纯文本 / Markdown / 网页书签构建本地知识库；**Live Assistance** 可在会议中检测到提问时，从自有材料实时给出带引用来源的答案。
- **平台与价格**：仅 macOS、针对 Apple Silicon 优化；免费；官方明确标注为**实验性应用**，未承诺定价与维护周期，也未说明最低系统与内存要求。
- **隐私**：官方 FAQ 称会议音频、转写、笔记与知识库索引全部留在本机；连接 Google Drive 拉取文件时需要登录与联网，之后索引与问答均可离线。
- **判定**：属 Google 官方产品发布、与已收录的 EmbeddingGemma 2 同批，属系统性漏项，本次补录。
