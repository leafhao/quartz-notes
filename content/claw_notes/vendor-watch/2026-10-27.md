窗口：2026-10-26 12:00 至 2026-10-27 12:00（北京时间）。**本期头条是 OpenAI 一款新模型 + 一批科研成果，同一天两件事**：平价旗舰 GPT-6.1 Terra 上线（标准 API 价格比同代 Sol 低一半，主打视觉推理与电脑操作），以及公开三项 AI 产出的重大证明（Kakeya／局部光滑猜想、ETH 为假、四维 QCD 存在性）。Anthropic 只有一次 Claude Code 缺陷修复；Google 只有一条 API 默认行为变更；Meta、HF 与国内八家官方侧零新增。

## 国外厂商

### OpenAI：GPT-6.1 Terra —— 低价位的视觉与电脑操作用模型

- 发布：官方博客《Introducing GPT-6.1 Terra》，API changelog 记为 **Oct 26**（`gpt-6.1-terra`，`v1/responses` 与 `v1/chat/completions` 双通道）；国内媒体口径为北京时间 **10-27 凌晨**宣布。
- 定位：官方原文「a fast, efficient model that combines detailed visual reasoning and precise computer use alongside clearer, more natural writing」，是 GPT-5.6 Terra 的显著升级版；复杂编程仍建议走 GPT-6.1 Sol 与 GPT-6 Astra。
- 规格（模型文档）：上下文 **1,050,000**、最大输入 922K、最大输出 **128K**、知识截止 **2026-06-01**；输入仅文本＋图像，**不支持音频与视频**；`reasoning.effort` 六档 `none/low/medium/high/xhigh/max`，默认 medium；工具调用须走 Responses API（Chat Completions 不支持工具）。
- 定价：输入 **$1** / 缓存输入 **$0.05** / 缓存写入 **$1.25**（12 小时保留 $2.50）/ 输出 **$5**（每百万 token），比 GPT-5.6 Terra 与 GPT-6.1 Sol 低 50%，约为 GPT-6 Astra 的 1/10；**超过 27.2 万输入 token 的请求按 2× 输入、1.5× 输出计价**，Fast mode 2×，Batch/Flex 五折，区域处理 +10%。
- 基准（均官方自报）：Agents' Last Exam 中等推理强度比 GPT-5.6 Terra 高 **15 个百分点**、成本约 1/3，与 GPT-6 Astra 持平但每 token 价格仅 1/10；最高推理强度下 token 效率是 Claude Opus 5.5 的 3 倍以上、每任务成本约低 **9 倍**；速度比 Astra 与 Sol 快 **3 倍以上**。MMMU-Pro 全档超过 GPT-5.6 Terra；OSWorld 2.1 中等强度超过 GPT-5.6 Terra 最佳成绩。内部事实性错误率低推理档 **53.6% → 16.7%**，最高档 **4.3%**。Terminal-Bench 4.0 最高档 **50.3%**（GPT-5.6 Terra 为 21.5%）；Terminal-Bench-Science 0.1 最高档超过 GPT-6.1 Sol。
- 可用性：ChatGPT Work 与 Codex 面向全部 Plus / Pro / Enterprise / Edu 开放，相同额度可覆盖比 GPT-5.6 Terra 更多任务；API 模型名 `gpt-6.1-terra`。
- 安全：按 Preparedness Framework，**网络安全类别达到 Critical 阈值**，沿用为 GPT-6 Astra 开发的防护；系统卡单独发布在 deploymentsafety.openai.com/gpt-6-1-terra。
- 同日其余条目：CodeRabbit、Greptile 两篇客户案例（GPT-6.1 Sol／Astra 用于代码安全与评审）、Fanatics 与 Ultrafast 案例、「ChatGPT's expanding world of work」——均非模型或 API 变动，不计入。

### OpenAI：公开三项 AI 科研结果，并首次让外部专家带队解读

- 发布：官方博客《Working with academic communities to build scientific understanding》，RSS 时间 **10-26 14:30 GMT ＝ 北京 22:30**。
- 三项结果：① 数学——证明**局部光滑猜想**（各维度），并由此解决 **Kakeya 猜想**与 Stein 限制猜想（AI 输出 10-18，次日 Lean 形式化）；② 计算机科学——证明**指数时间假设（ETH）为假**（10-16 输出、10-17 Lean 完成，随后由 Lean 验证）；③ 物理——四维规范场与费米子相互作用的严格存在性，含纯 **Yang–Mills 存在性**（属 Clay 千禧年问题子问题）与 QCD 的统一完成（Lean 形式化 10-16 完成）。
- 发布机制：三种对照策略并行——数学直接公开 AI 输出；CS 组建外部合作组同步公开；物理交由外部组决定发布节奏（该组选择自行撰写、暂不公开 AI 产出）。合作原则为透明（不签保密协议）、不索取学术荣誉、给解读团队署名、独立自愿。
- 外部团队：CS 侧由 Russell Impagliazzo、Ramamohan Paturi（UCSD，ETH 提出者之一）与 Ryan Williams（MIT）牵头；物理侧由 David Gross 领衔，含 Michael Douglas、Arthur Jaffe、Igor Klebanov、Nikita Nekrasov。
- 佐证与投入：自然语言证明与 Lean 形式化均已放入公开仓库 `openai/math`；配套一笔 **500 万美元**投入（由 Simons Foundation 管理与发放），用于工作坊、会议与专项计划。
- 意义：这是「AI 产出前沿数学／物理结果 → 形式化验证 → 外部专家解读」这条链路第一次被官方作为**发布流程**写出来，而不只是晒结果。

## 本期判断

- **OpenAI 这次动的是价格而不是上限**。Terra 的意义在于把「视觉理解＋桌面操作」这一档的成本压到 GPT-6.1 Sol 的一半、Astra 的十分之一，同时在 Agents' Last Exam 上追平 Astra；对做批量自动化的一方，这是替换主力模型的信号，而不是又多一个可选型号。
- **两件事同日发生不是巧合**。一边是低价高频的「干活模型」，一边是三项前沿证明 + 外部专家解读机制 + 500 万美元学界投入，同一天把「能落到业务里」和「能发到期刊上」两条叙事同时握在手里。
- **Critical 阈值这一条值得单独留意**。Terra 是走量型号，却在网络安全类别达到 Preparedness Framework 的最高档；官方沿用 Astra 的防护，但按量铺开后攻击面与误判率的口径还没有公开数据。
- **其余厂商在小幅收尾**：Anthropic 一个缺陷版、Google 一条默认行为变更、国内八家零新增——下一波密集期大概率在 Kimi 权重开源（承诺 11-04 前）与 OpenAI 冲刺收尾（Day 28 约 11-01）。
