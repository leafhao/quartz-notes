### OpenAI — 发布 GPT-6 家族模型指南（官方 2026-10-02 16:15 GMT / 北京 10-03 00:15）

`openai.com/index/practical-guide-building-gpt-6/`，标题《A model guide for the GPT-6 family》。这是**开发者指南、非模型发布**，但把 GPT-6 全家的定位、档位与成本口径一次性讲清。

- **三档定位**：**GPT-6 Astra** 用于最难的推理任务；**GPT-6.1 Sol** 用于复杂编程、研究与 computer use；**GPT-6 Luna** 用于高频、重复、目标明确的批量任务（抽发票字段、请求分类、结构化摘要）。
- **把「模型选择 + 推理档位」明确表述为智能/价格权衡**：低档用于抽事实、小改动；中档用于做方案、比较选项；高档用于困难调试与精细复核；**extra high / Max 仅在 High 不够时试用，且只在收益足以抵消时间与成本时才保留**。
- **速度两档**：Fast mode（更稳的响应时间、按 token 加价）与 Ultrafast（当前仅 Astra 可用，独立于推理档位加速出字）。
- **成本口径**：缓存输入 token 最高比未缓存便宜 **95%**（视模型而定）；稳定指令与参考资料放在变化的任务细节之前；估算完整流程成本时要**把 cache write 与长上下文档位的费率一起算进去**。长对话用 compaction 压缩上下文并保留续跑所需状态。
- **能力面**：异步工具调用（`async: true`，应用执行工具、以原 `call_id` 回填结果）、mid-turn steering（WebSocket 上中途补指令，保留已完成工作）、**可在对话中途改推理档位且不破坏缓存**（`configuration_update`）。
- **官方给的落地建议**：上线前跑代表性任务，测量任务成功率、时延与「每成功任务成本」；GPT-6.1 Sol 的多智能体仍为 beta。
- **口径**：属官方开发者文档更新，不是新模型、不是新定价。写作时按「官方在窗口内发布即登记」处理。

### Anthropic — Claude Code v2.1.288（官方 2026-10-02 20:19 UTC / 北京 10-03 04:19）

`docs.anthropic.com/en/docs/claude-code/changelog` 标注 **October 2, 2026**。本版以稳定性为主，**共 61 项修复**（占变更总数约 69%），距 v2.1.287 仅一天。

- **本次最值得注意的安全收紧**：**藏在 `bash -c` / `sh -c` 内联脚本里的危险 `rm`（如指向 `/` 或家目录），现在即使在 `bypassPermissions` 模式或命中 shell 允许规则下也会先询问**。另有 `BASHPID` 赋值被 shell 当算术求值的场景也加了确认。两条都留了开关：`CLAUDE_CODE_DISABLE_INLINE_SHELL_RM_PROMPT` 可退回旧的静默行为。
- **新增 `CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS`**：给拒绝结构化输出的网关/供应商（如 Mantle）用，此前会导致会话标题、记忆召回与提示钩子失败。
- **会话可靠性一批修复**：响应中途 API 超时不再让整轮失败（非交互会话与子智能体从部分响应续跑，纯思考响应会重试）；最后的回复上报 0 token 的长对话改为自动 compaction 而非报 "Prompt is too long"；`--resume` 不再丢失 compaction 刚恢复的文件与上下文、不再丢上一轮的回复、不再在会话改写文件时读到被截断的 transcript。
- **可用性**：`Ctrl+C` 清空的提示按上箭头可恢复草稿（含粘贴的文本与图片）；mods 新增 `$.ui.selection()`；MCP 服务器在工具调用中要求扩大 OAuth 范围时会弹出重新授权提示；agents 视图支持 `Ctrl+F` 按名查会话、`Alt+↑/↓` 跳分组。
- **观察**：Claude Code 近一个月出货 26 版、均值 1.4 天一版；本版把「谁在什么条件下能静默执行破坏性命令」这条边界又收紧了一格。

## 本期口径与经验

- **`alignment.openai.com/misalignment-reports/` 是本任务的高价值一手页**：每条报告自带「更新日期」，本次一次性拿到三条 10-02 更新，`openai.com/news/rss.xml` 完全不收录这类安全披露。查 OpenAI 安全动态必须走这一页 + `openai.com/news/rss.xml` + `learn.chatgpt.com`（Codex/产品侧）三条路。
- **`developers.openai.com/codex/changelog` 可静态抓取，且 HTML 里带 `YYYY-MM-DD` 前缀**：本次从中核到 **2026-10-01 的 Codex CLI 0.160.0**（0.159.3 / 0.159.2 / 0.159.1 分别在 09-30 及之前）。`learn.chatgpt.com/docs/changelog` 只给导航、不给正文，直连 `developers.openai.com/codex/changelog` 才拿得到条目。`.md` 后缀在本路由下 404。
- **`blog.google/.../the-latest-ai-news-we-announced-in-<month>-<year>/` 是月度盘点，不是新发布**：本次它带来一个副产品——**暴露出本系列 9 月漏掉的两条 Google 条目（AlphaGenome Atlas 09-08、CC for groups 9 月实验预览）**。这类盘点页值得每期扫一遍，专门用来查漏，但条目本身不进卡片、只在笔记登记并标注原始日期。
- **`anthropic.com/news` 列表页只覆盖公告类**：本次 10-02 的 Frontier Academy 走 `/news/claude-frontier-academy`；而 10-01 的 **《Claude-shaped science》（`/research/claude-shaped-science`，Prof. Matthew Schwartz 客座，讲 BootLoops 工具箱与「Claude 形状」的问题选择）不进 news 列表**。Anthropic 要「news 列表 + research 路径」两条都走，这一条已在 10-01 窗口但被漏，本次仅在笔记登记。
- **掘金/内容平台会把三个月前的旗舰发布包装成「今日发布」**：Qwen3.8-Max 的 10-02 稿把 08-03 的发布写成「阿里今晨发布」。判据仍是 **HF 仓库 `createdAt` + 厂商官方页**：`huggingface.co/api/models?author=Qwen&sort=createdAt&direction=-1` 一条命令即可确认 Qwen 组织近期没有新仓库（最新仍为 09-20 的 Qwen-Image-2.1 系列）。
- **「官方文档页说『已全量上线』」不等于新模型发布**：智谱 `docs.bigmodel.cn` 的 GLM-5.3 页写「GLM Coding Plan 已全量上线 GLM-5.3」，指的是**套餐侧放开**，`docs.z.ai/release-notes` 的 New Released 仍停在 08-26。判断有无新模型，始终以 release-notes / 定价页是否新增 SKU 为准。
- **连续三日国内零新增时的写法**：如实写「八家均无官方新模型/API/定价变更」，并把四处官方时间轴的实测日期写出来（09-24 / 09-10 / 08-26 / 9 月段三条），比只说「无」更有核验价值；预告类条目（K3.1、V4.1 Pro、可灵 4.0、Step 5 权重）只登记不进正文。
- 站点链接格式固定：`https://notes.leaf.pp.ua/claw_notes/<task>/<YYYY-MM-DD>`，deliver.sh 的 `--task vendor-watch` 会自动拼。
