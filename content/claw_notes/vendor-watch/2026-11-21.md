## OpenAI：反蒸馏防护，推理提取成功率 54% → 0.2%

**官方博客** `openai.com/index/combatting-adversarial-distillation`，RSS pubDate **2026-11-20 10:00 GMT＝北京 11-20 18:00**。

- **问题定义**：对手用前沿模型的输出训练「学生模型」，得到能力接近但护栏全无的模型。这次的重点是**受保护推理（protected reasoning／思维链）**被整体抽走。
- **核心数字（GPT-6 Astra → GPT-6.2 Astra）**：从**先前请求**里提取受保护推理的自适应黑盒攻击成功率 **54.0% → 0.2%**；从**当前请求**里提取 **22.9% → 0.9%**。
- **为什么要在意推理轨迹**：实验里用**精确推理轨迹**训练的学生模型，监督微调后普遍优于用「推理摘要」训练的；强化学习后在大推理预算下依然更优——轨迹本身就是可迁移的能力。
- **四层防御**：对抗训练、模型行为约束、输入／输出分类器、API 层防护，再加针对协同攻击的**调查与执法**。
- **API 行为变了三处**：① 新增分类器检查助手消息与**工具调用参数**里的推理泄漏（流式与非流式都覆盖）；② 加密推理**绑定对话历史**——先前消息被改写，其后的推理即被丢弃；③ 阻止旧模型读取 GPT-6.2 Astra／Sol 的受保护推理，并堵上一条可能暴露**其他用户**加密推理的路径（按用户／工作区／组织／模型族划界）。
- **执法规模**：每周针对蒸馏活动的处置涉及**数千到数万个账号**，今年夏天以来频率明显上升。文中重申 2 月向国会简报、9 月披露一起把核心部分归因于 Moonshot AI 相关人员的活动。
- **政策主张**：支持《Chip Security Act》《AI OVERWATCH Act》《MATCH Act》，主张强化出口管制，并通过 Frontier Model Forum 与「一致性标准」和部署伙伴协调。
- **给开发者的三条建议**：全程保护私有推理（含工具调用参数）；把成功攻击日志当回归测试；请求级缓解＋活动级执法一起做。

## OpenAI：ChatGPT Space 向全球 Plus 开放

**帮助中心 ChatGPT Release Notes** 的 **November 20, 2026** 条。

- **是什么**：在 Space 里用 ChatGPT 做**可交互页面与演示稿**，能邀请有权限的人一起改，也能让页面／幻灯片**跟随已连接的应用自动更新**（比如把 Slack 里的决定同步进项目计划）。
- **协作**：在评论里 @ ChatGPT 直接提改动；有 dot 的用户可以把 dot 拉进来协作。
- **入口变化**：Space 出现在侧边栏，**取代 Library**，成为页面、幻灯片、图片与上传文件的新家；网页、桌面端、iOS／Android 都能建与改。
- **限制**：共享页面需要 Plus／Pro／Business／Enterprise 且有 Space 权限才能打开，**Free 用户打不开**，也不提供公开链接。年龄限 18+。

## Anthropic：Claude Code 2.1.330

发布于 **2026-11-20 22:32 GMT＝北京 11-21 06:32**（前一版 2.1.329 在 11-19 22:14 GMT）。

- **企业登录**：支持登录 **Anthropic Enterprise Admin Console** 管理的组织，`claude auth login` 后自动套用组织设置，并走该组织指定的云厂商或网关。
- **内置画图 mod（easel）**：被要求画图时直接出图表，也会画在 MCP 指标结果下面；Pro／Max 及可用的 Team／Enterprise，macOS 与 Linux；`/config` 里可关掉自动画图。
- **自托管 runner**：新增 `--start-dir`／`SELF_HOSTED_RUNNER_START_DIR`，让 Claude 从仓库的某个子目录开始干活；`/metrics` 加了两条排期到开工的耗时指标。
- **插件诊断**：`claude plugin install --json` 增加 `commandPrinted`／`commandFailed`；插件市场拉不下来、或 Anthropic 托管 git 拒绝插件自有仓库时，会话里给出具名提示。
- **修复**：长会话 compact 后卡死数分钟；WebFetch 在某些页面卡死或返回空；`ExitWorktree` 误删别的会话正在用的 worktree；多进程并发保存用户设置丢失；`--continue`／`--resume` 打开空会话；休眠两分钟后首个请求在死连接上等三分钟；MCP 工具 schema 过多时「JSON schema is invalid」与会话文件暴涨。
