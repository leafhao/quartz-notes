# AI 厂商动态 | 2026-08-22

**时间窗口**：2026-08-16 ~ 2026-08-22
**本期主线**：国产开源模型爆发（Qwen3.8-27B 首周末 300 万下载）× 国产 API 集体涨价潮 × Anthropic 收入跑到 $65B 年化 × OpenAI Codex 平台化 + 8/31 模型退役

## 🇺🇸 国外厂商

### Anthropic

**官方（anthropic.com）**

- **Claude 用于蛋白质设计与分析化学**（08-19，[research 页](https://www.anthropic.com/research/Claude-accelerates-protein-design)）：发布 *Autonomous de novo protein binder design with Claude* 研究，配套 [PDF](https://www-cdn.anthropic.com/30bf50e22a01388bb29bf077ee3f244531594b7a.pdf)。数据/代码/prompt 已开放（数据 CC BY 4.0、脚本 MIT），含多靶点与单靶点协议 prompt。
- 同篇披露：一个**未发布的 Claude 研究版本**在与黎曼猜想相关的问题上取得进展，改进了 Riemann zeta 函数零点占比的一个长期下界。

**媒体（交叉印证）**

- **收入年化跑过 $65B**（Reuters 08-17）：消息人士称 Anthropic 收入 run rate 已破 650 亿美元，公司对 2028 年营收给出约 $1900-2000 亿区间预测，IPO 估值挂钩该预测。增长主要由 Claude 编码 agent 需求驱动。
- **监管口水战**（Fortune 08-18）：David Sacks 称 Dario Amodei 想要一个"AI 版 DMV"，文章反驳称许多行业在安全监管下同样繁荣。
- SiliconANGLE 08-21 观察：OpenAI 在部分指标上落后于 Anthropic。

### OpenAI

**官方（openai.com / help.openai.com / developers.openai.com）**

- ⚠️ **8/31 模型退役**（Codex rate card / ChatGPT rate card，08-19~08-20）：**GPT-5.4 与 GPT-5.4 mini 将于 2026-08-31 从 Codex 下线**（针对用 ChatGPT 账号登录的用户）。替代关系：GPT-5.4 → **GPT-5.6 Terra**，GPT-5.4 mini → **GPT-5.6 Luna**。**用自己 API key 的 Codex 使用和 API 访问不受影响。**
- **o3 于 2026-08-26 从 ChatGPT 退役**（Model Release Notes，90 天 sunset 期满）。
- **Codex as a platform**（08-19，developers.openai.com blog）：开放 agent harness，可在其上构建。同期还有 Custom Code Review rules for Codex、私有 MCP server 无需公网暴露的方案。
- **前沿模型零数据保留（Zero Data Retention）**（08-20，API Platform）：为 frontier 模型提供 ZDR。注：按法规要求，疑似 CSAM 标记的图像仍会保留。
- **Pacing model development in an era of cyber-critical capabilities**（08-18）：网络安全能力临界期的模型发布节奏立场文。
- **AI Futures 博客上线**（08-20）：Strategic Futures 团队新博客，探讨权力、治理与自由。
- 客户案例：Asana 用 Codex 两周替换过时测试系统、约 $12K 成本完成原计划 5 年的工程量（08-18）；Stampli 用 ChatGPT Work（08-20）。

**媒体**

- **ChatGPT for Teens**（Bloomberg Tech 08-18）：OpenAI 面向青少年推出专门版本。

## 🇨🇳 国内厂商

### 阿里云通义（本期最大动作）

- 🚀 **Qwen3.8-27B 发布**（08-17，官方发布 + CNBC/VentureBeat/Quartz 多家印证）：面向消费级硬件的开放权重模型，**27B 参数、17GB 文件**，可在 RTX 3090 或内存足够的 MacBook 上本地跑。定位编码、专业工作、研究、长时程 agentic 任务，官方称性能对标 10 倍体量的模型。
- **首个周末下载量突破 300 万**（cybernews 08-17），Reddit 社区评价"远超其体量级"。VentureBeat 强调其价值在于**无需云 API 即可本地跑 frontier 级编码 agent 和推理**，数据不出本机。
- 同日**开放 Qwen3.8-Max 权重**（旗舰模型免费下载），阿里股价当日涨约 2%。
- **阿里 AI 模型累计下载破 30 亿**（Fortune 08-15，窗口边缘）：已超过 Meta 和 Google。

### 深度求索 DeepSeek

- **V4 Pro 0813 build 于 8/13 结束 preview**（窗口前一天，本周被广泛评测对比）。
- ⚠️ **8/17 起启用峰谷分时定价**（新浪财经 08-20 / 21 世纪经济报道 08-20）：这是 DeepSeek 的定价策略转向。历史对比：今年 5 月 DeepSeek 曾宣布 V4 Pro API 永久降至原价 1/4（缓存命中输入 0.025 元/百万 tokens、未命中 3 元、输出 6 元）。

### 国产 API 涨价潮（本期国内主线，多家财经媒体交叉印证）

摩根士丹利统计字节、阿里、百度、腾讯、MiniMax、智谱、月之暗面、DeepSeek 官方报价后确认趋势转向。

| 厂商 | 调价动作 |
|------|----------|
| 智谱 AI | 2026 年内**三轮上调**：2 月 GLM Coding Plan 结构性调价 → 3 月 GLM-5-Turbo 发布时 API +20% → 4 月 GLM-5.1 发布时再 +10% |
| MiniMax | 6/1 发布三代旗舰 M3 同时 **API 价格全面翻倍** |
| 月之暗面 Kimi | 7 月发布 K3 时大幅上调：输入 **20 元/百万 tokens**、输出 **100 元/百万 tokens**，均较前代**涨超 3 倍** |
| DeepSeek | 8/17 起峰谷分时定价 |
| 阿里 / 字节 / 腾讯 | **按兵不动或变相调价**（自有算力大厂） |

**行业解读**（21 世纪经济报道引致同咨询梁伟）："这轮调价不是全行业统一涨价，而是独立模型厂商领涨，自有算力的大厂按兵不动。"涨价是对推理算力成本长期倒挂的修正，属价格与价值重新校准；但若只提价而稳定性跟不上，用户会用脚投票——模型间替换成本正在下降。**"百模大战"低价阶段结束**。

### 月之暗面 Kimi（供给侧信号）

- K3 发布后推四档会员（**39 元 ~ 559 元/月**）。**上线不到 48 小时紧急叫停 C 端新用户订阅**——请求量暴增远超预期，GPU 集群扛不住（文学城 08-21 转述，非官方公告，仅作趋势信号）。

### 腾讯

- 7 月牵头红杉中国、真格基金组成中方财团，以约 **20 亿美元**从 Meta 手中回购 AI agent 公司 **Manus** 全部股权，成最大单一股东但不控股。

### 其他

- **智谱清影 2.0**：能力提升至 10 秒 / 4K / 60 帧并加入音效，在智谱清言内直接触达用户（36kr 08-17）。

## 📊 交叉观察

1. **端侧开放权重成为新战场**：Meta Muse Glimmer（8 月上旬）→ Alibaba Qwen3.8-27B（8/17）→ DeepSeek V4 Pro 0813，三个开放权重旗舰在同一个十天窗口内出货（Tech Insider 08-21 整理）。竞争焦点从"参数量军备"转向"消费级硬件能跑的最强模型"。
2. **中美差距快速收窄**（Bloomberg 08-19，*US Lead in the AI Race With China Is Rapidly Narrowing*）：文中引 Zuckerberg 称这可能是史上最激烈的竞争，"没有单一实验室能长期领先"。
3. **国内外定价方向相反**：国外（OpenAI/Google）在做**免费/优惠拉新**（学生一年免费 Gemini、ChatGPT for Teens），国内独立模型厂商在**集体涨价**修正算力成本倒挂。
4. **Agent 基础设施标准化加速**：A2A 转入 Agentic AI Foundation、OpenAI Codex 平台化 + 私有 MCP server 方案，两条线都指向 agent 互操作标准的固化。
5. **算力供给成为硬约束**：Kimi K3 因 GPU 集群扛不住紧急停售、Meta 转向对外卖算力、Thunder Compute 融资 $13M 榨取闲置 GPU——供给端信号密集。
