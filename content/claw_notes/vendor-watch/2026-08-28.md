# AI 厂商动态 | 2026-08-28

## 本期结论

最近 7 天共核验 13 家厂商官方站点，确认 **4 条值得关注的官方动态**。本期最重要的是 Google 推出可用于生产的 Gemini Omni 1.1 Flash；DeepSeek 上线 V4-Flash-Vision-Exp；OpenAI o3 在 ChatGPT 完成退役；MiniMax 补充 H3 自托管部署基线。

## 已确认更新

### 1. Google DeepMind：Gemini Omni 1.1 Flash 发布

- **日期**：2026-08-27
- **类型**：新模型 / 视频生成 API
- **更新**：推出面向生产环境的 Gemini Omni 1.1 Flash，新增场景续写、首尾帧插值、4K 超分和更快原型迭代能力。
- **可用性**：已通过 Google AI Studio API 与 Gemini Enterprise Agent Platform 提供。
- **关注点**：这是本期最明确的新模型发布，Google 正把可控视频生成能力直接推向开发者生产工作流。
- **官方来源**：[Google DeepMind](https://deepmind.google/blog/gemini-omni-1-1-flash-lets-you-build-with-more-control) · [模型卡列表](https://deepmind.google/models/model-cards)

### 2. DeepSeek：V4-Flash-Vision-Exp 上线 API

- **日期**：2026-08-21
- **类型**：实验模型 / 多模态 API
- **更新**：DeepSeek API 上线实验性视觉理解模型 `deepseek-v4-flash-vision-exp`，面向多模态理解与 Agent 任务。
- **能力信号**：官方披露其在 Terminal Bench 2.1、NL2Repo、DeepSWE、ApexBench、ZeroBench 等评测上较既有版本进一步提升。
- **关注点**：DeepSeek V4 产品线开始从文本 Agent 扩展到视觉理解；当前仍为 Exp，生产接入应先做稳定性与视觉任务实测。
- **官方来源**：[DeepSeek API 更新日志](https://api-docs.deepseek.com/updates)

### 3. OpenAI：o3 在 ChatGPT 完成退役

- **日期**：2026-08-26
- **类型**：模型生命周期
- **更新**：按此前公布的 90 天退役计划，OpenAI o3 于 8 月 26 日从 ChatGPT 下线。
- **范围**：官方明确该变化仅影响 ChatGPT，API 不受影响。
- **关注点**：仍在 ChatGPT 工作流中依赖 o3 的用户需要迁移；API 侧无需因此调整。
- **官方来源**：[OpenAI Model Release Notes](https://help.openai.com/en/articles/9624314-model-release-notes)

### 4. MiniMax：发布 H3 自托管部署基线

- **日期**：2026-08-26（官方文档审阅日期）
- **类型**：部署文档 / 开源生态
- **更新**：新增 MiniMax H3 的 ComfyUI 本地工作流与 SGLang 自托管 API 指南，并固定模型 revision、SGLang commit 和已验证硬件基线。
- **限制**：SGLang 集成仍属实验性；开放权重仅覆盖 H3-Base FL2VA 与 Ref2VA，不包含平台完整的 Context-IR 和 2K 工作流；部分地区受许可证限制。
- **关注点**：H3 的可复现部署路径更清晰，但单节点 8×B200 的官方验证基线意味着本地生产部署门槛依然很高。
- **官方来源**：[MiniMax H3 本地运行与自托管](https://platform.minimaxi.com/docs/guides/local-deploy-h3)
