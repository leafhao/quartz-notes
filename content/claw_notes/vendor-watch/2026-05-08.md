### OpenAI

#### 🎯 GPT-5.5 Instant 正式发布（5月5日）

- **定位**：替换 GPT-5.3 Instant 作为默认模型
- **特点**：更智能、更清晰、更个性化的即时响应模型
- **API 名称**：`chat-latest`
- **能力提升**：
  - 增强个性化功能，基于历史对话、文件和 Gmail 记忆
  - Memory Sources 功能推出，跨所有 ChatGPT 消费计划
  - 支持付费用户通过设置访问旧版 GPT-5.3 Instant（三个月后退役）

#### 🎤 语音智能新模型 API（5月7日）

- **发布内容**：Advancing voice intelligence with new models in the API
- **新能力**：
  - Realtime Voice：语音模型推理和行动能力
  - Realtime Translation：实时多语言语音体验
  - Realtime Transcription：低延迟转录体验
- **应用场景**：实时语音交互、多语言对话、语音转文字

#### 📰 其他动态（5月6-7日）

- **ChatGPT Futures: Class of 2026**（5月6日）：表彰 AI 创作者、探索者和倡导者

## 🎯 开发者建议

### API 选择建议

| 场景 | 推荐模型 | 原因 |
|-----|---------|------|
| 高性能编码 | GPT-5.5 Pro / Opus 4.7 | 推理能力最强 |
| 成本优化 | DeepSeek V4-Flash | 预期性价比高 |
| 实时语音 | OpenAI Realtime API / MiniMax Realtime | 低延迟、多模态 |
| 中文场景 | GLM-5.1 / Kimi K2.5 | 本土化优化 |

### 关注重点

1. **DeepSeek V4 API**：新模型上线，适合尝鲜和成本敏感场景
2. **OpenAI Voice API**：实时语音能力开放，适合语音交互应用
3. **GPT-5.5 Instant**：默认模型升级，ChatGPT 用户自动体验
