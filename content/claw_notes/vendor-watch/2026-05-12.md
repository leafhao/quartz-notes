## 国外厂商动态

### OpenAI

#### 🎯 GPT-5.5 Instant 发布（2026-05-05）

**来源**: [OpenAI 官方博客](https://openai.com/index/gpt-5-5-instant/)

**关键更新**:
- GPT-5.5 Instant 正式发布，取代 GPT-5.3 Instant 成为 ChatGPT 默认模型
- API 中可用为 `chat-latest`
- 主要改进：
  - 更智能、更准确的回答，减少冗余内容
  - 增强个性化：利用历史对话、文件、Gmail 等数据定制回复
  - Memory sources 功能：展示个性化信息来源，用户可查看和删除
  - Plus/Pro 用户率先获得增强个性化功能

**发布时间**: 2026年5月5日

#### 🎙️ GPT-Realtime-2 发布（2026-05-07）

**来源**: [OpenAI 官方博客](https://openai.com/index/advancing-voice-intelligence-with-new-models-in-the-api/)

**关键特性**:
- 专为实时语音交互设计的新旗舰音频模型
- 支持音频输入输出，适合语音助手和客服系统
- 核心能力提升：
  - 更强的专业术语保留（医疗、技术领域词汇）
  - 可控的语调和表达方式（冷静、同理心、活泼等）
  - 可调整推理努力级别（minimal/low/medium/high/xhigh）
  - 默认 low 级别，平衡延迟和推理深度

**发布时间**: 2026年5月7日

#### 📺 ChatGPT 广告测试（2026-05-07）

**来源**: [OpenAI 官方博客](https://openai.com/index/testing-ads-in-chatgpt/)

**更新内容**:
- 开始在澳大利亚、新西兰、加拿大测试广告
- 仅面向 Free 和 Go 计划用户
- Plus/Pro/Business/Enterprise/Education 计划无广告

**发布时间**: 2026年5月7日

#### 🔄 模型弃用计划更新（2026-05-07）

**来源**: [OpenAI API Deprecations](https://developers.openai.com/api/docs/deprecations)

**关键弃用**:
- 2026-05-07 关闭的模型：
  - `gpt-4o-realtime-preview` → 替换为 `gpt-realtime-1.5`
  - `gpt-4o-audio-preview` → 替换为 `gpt-audio-1.5`
  - `gpt-4o-mini-realtime-preview` → 替换为 `gpt-realtime-mini`
  - `gpt-4o-mini-audio-preview` → 替换为 `gpt-audio-mini`
- Sora 2 视频生成模型将于 2026-09-24 关闭
- 多个旧版 GPT-3.5/4 fine-tuned 模型将于 2026-10-23 关闭
