官方两处互证：`api-docs.deepseek.com/news/news261113`（新闻页）与 `api-docs.deepseek.com/updates`（Change Log，日期明确写 `Date: 2026-11-13`）。配套文档已就位：`guides/web_tools`、`guides/search`、`guides/document_parsing`、`guides/ocr`、`guides/asr`、`guides/tts`、`guides/safety`、`guides/build_a_chatbot`。

### 变了什么

过去 DeepSeek API 只给模型推理，联网、读文件、读链接、语音这些「App 里的体验」要开发者自己拼。11-13 起，这些能力作为**内置工具**塞进 `deepseek-flash`（V4.1-Flash）的 Messages、Responses、Chat Completions 三个接口，工具调用与上下文组装都在服务端完成。

- **Web Search**（`deepseek_web_search`，关闭思考时）：按问题需要做文本或图像搜索，答案带引用。
- **Deep Thinking Search**（同参数，开启思考时）：多步推理过程中自己去搜索、去读页面。
- **File Input**：上传 PDF、Office 文件、图片等，先做纯文本抽取或富版式解析，再进上下文。
- **URL Reading**（`deepseek_read_url`）：自动识别用户消息里的链接，抓取正文后作答。
- **Safety Checks**：输入与输出都过一遍风控，命中风险时返回拒绝标记。官方明确：**面向公众提供服务必须打开这个参数**，并且开发者仍需自行承担内容安全审核、大模型备案、AI 生成内容标识等义务。

### 独立 API

搜索与抓取（Search & Fetch）、OCR、ASR、TTS 同时以**独立接口**提供，供不走对话链路的工作流单独调用。

### 开源 demo

配套开了个聊天客户端 `deepseek-ai/chat-demo`（MIT、TypeScript、11-12 建仓、11-13 最后推送，已 1.8k star），线上演示在 `deepseek-ai.github.io/chat-demo/`，**支持导入自己的 DeepSeek 历史会话**——等于把「复刻一个 DeepSeek App」的最后一公里也给了。

### 为什么值得记

这是国内厂商里少见的「把消费级产品的完整链路当 API 卖」。以前的差异在模型分数，这次的差异在**交付形态**：搜索、解析、语音、风控都是按次计价的基础设施件，价格压到千次七毛五、千页两毛二这一档，明显是冲「自己做 Agent 应用」的那批开发者去的。
