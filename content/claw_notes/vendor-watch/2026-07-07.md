# AI 厂商动态 | 2026-07-07

## 📋 本周概览

本周（7月1日-7日）AI 厂商动态活跃，Anthropic 发布最强 Sonnet 模型并突破出口管制，OpenAI 持续迭代 GPT-5.5 系列，Meta 承认 AI Agent 进展不及预期但云计算业务启动，中国厂商加速国产化替代并获大额融资。

**重点事件：**
- Anthropic Claude Sonnet 5 正式发布，最强代理能力
- Anthropic 突破美国出口管制，19 天停摆后恢复全球服务
- OpenAI 发布 GPT-5.5 Instant Mini，预告 GPT-5.6 Sol
- Meta 启动云计算业务，出售过剩 AI 算力
- 快手 Kling AI 获阿里腾讯 28 亿美元融资
- 阿里禁用 Claude Code，中国厂商加速国产化

## 🌍 国际厂商动态

### Anthropic

**Claude Sonnet 5 正式发布**（6月30日）
- **最强代理能力**：Anthropic 最具代理能力的 Sonnet 模型，能够制定计划、使用浏览器和终端等工具
- **全面可用**：
  - Free 和 Pro 计划默认模型
  - Max、Team、Enterprise 用户可用
  - Claude Code 中可用
  - Claude Platform API 可用
- **定价策略**：
  - 推介期（至 8月31日）：$2/百万输入 token，$10/百万输出 token
  - 正式定价（9月1日起）：$3/百万输入 token，$15/百万输出 token
- **官方来源**：https://www.anthropic.com/news/claude-sonnet-5

**突破出口管制限制**（7月3日）
- **重大进展**：成功与美国政府谈判，解除 AI 模型出口管制
- **影响**：结束 19 天全球服务停摆，恢复国际市场可用性
- **背景**：此前因出口管制政策导致模型无法在美国以外地区使用
- **来源**：TheStreet 报道

**与阿里冲突升级**（6月25日）
- **指控内容**：Anthropic 指控阿里巴巴大规模攻击其 AI 模型
- **攻击规模**：使用 25,000 个虚假账户，进行 2880 万次交互，非法"蒸馏"其模型
- **来源**：Business Insider、HackerNoon、Tom's Hardware 报道

### OpenAI

**GPT-5.5 系列持续迭代**
- **GPT-5.5 Instant Mini**（7月6日）：在 ChatGPT 中推出，强调快速推理能力
- **GPT-5.6 Sol 预告**（6月26日）：下一代模型预览，"next-generation inference efficiency"
- **GPT-5.5 和 GPT-5.5 Pro**：已在 API 中可用，提供更高级的推理和网络安全功能
- **定价**：GPT-5.5 价格高于 GPT-5.4，但用更少 token 获得更好结果

**产品更新**（6月）
- **个人理财功能**（6月26日）：扩展到 Plus 用户和 Android 平台
- **改进听写功能**（6月26日）：ChatGPT 语音输入体验提升
- **淘汰 GPT-4.5**（6月26日）：旧模型退役
- **Codex Remote GA**（6月25日）：代码生成工具正式发布，集成 DigitalOcean 插件
- **OpenAI Partner Network**（6月14日）：推出合作伙伴网络计划

**用户反馈**
- **质量下降争议**（6月）：社区出现 GPT-5.5 在 Codex 中质量下降的抱怨，包括错误增多、代码重复、性能变慢
- **来源**：OpenAI 社区论坛讨论

**官方来源**：
- https://help.openai.com/en/articles/6825453-chatgpt-release-notes
- https://openai.com/index/introducing-gpt-5
- https://openai.com/index/introducing-gpt-5-5

  - 在 Xcode 中访问 Gemini
- **官方来源**：https://blog.google/innovation-and-ai/technology/developers-tools/bringing-gemini-models-to-apple-developers/

- **Android 17 新功能**：集成最新 AI 特性
- **官方来源**：https://blog.google/innovation-and-ai/technology/ai/google-ai-updates-june-2026/

**备注**：本周窗口内 Google 未发布新的基础模型，主要聚焦于现有模型的开发者工具和产品集成。

### Meta

**AI Agent 进展承认不足**（7月2日）
- **内部会议坦承**：CEO Mark Zuckerberg 在内部会议上承认"AI 代理的进展没有我们希望的那么快"
- **背景**：尽管进行了大规模组织重组和投资，进展仍低于预期
- **来源**：GIGAZINE 报道 Meta 内部会议

**启动云计算业务**（7月1日）
- **战略转型**：Meta 正在开发云基础设施业务，出售 AI 算力和模型访问权
- **目标**：变现过剩的 AI 计算容量
- **来源**：Bloomberg、Reuters 报道
- **分析**：SemiAnalysis 指出 Meta 在 2026 年大幅增加"其他 AI"容量，暗示有大量变现选择空间

**竞争态势**（7月2-4日）
- **缩小差距**：报道称 Meta AI 负责人表示公司终于在追赶 OpenAI、Google 和 Anthropic 方面取得进展
- **挑战**：尽管在芯片、数据中心和人才方面投入巨大，仍在努力说服开发者和客户其模型属于顶级梯队
- **来源**：Business Insider、AOL 报道

**研究更新**（6月30日）
- **Brain2Qwerty**：发布去年推出的脑机接口研究更新，使用 AI 将大脑活动解码为文本，无需外科植入
- **官方来源**：https://ai.meta.com/blog/brain2qwerty-brain-ai-human-communication/

**备注**：Meta 本周未发布新的 Llama 模型（最新为 2024年9月的 Llama 3.2）。

## 🇨🇳 国内厂商动态

### 阿里巴巴

**禁用 Claude Code**（7月3日）
- **内部政策**：阿里巴巴禁止员工在工作场所使用 Anthropic 的 Claude Code 编码工具
- **原因**：声称存在"后门风险"（alleged backdoor risks）
- **战略转向**：与美国 AI 模型开发者试图防止未经授权访问、转售和蒸馏其系统的同时，中国云和 AI 公司已转向国产和开源模型（DeepSeek、阿里的 Qwen、Moonshot、Zhipu）
- **来源**：Reuters 报道
- **官方链接**：https://www.reuters.com/world/china/alibaba-ban-claude-code-workplace-over-alleged-backdoor-risks-source-says-2026-07-03/

**投资 Kling AI**（7月3日）
- **融资规模**：阿里巴巴和腾讯支持快手 Kling AI 的 28 亿美元融资
- **意义**：显示国内科技巨头加大对国产 AI 视频生成工具的投资
- **来源**：Reuters 报道
- **官方链接**：https://www.reuters.com/world/china/alibaba-tencent-back-kuaishous-kling-ai-28-billion-fundraise-2026-07-03/
