### 全双工语音模型 Gander 发布：打断率 8%，大脑可换 Codex / Claude Code（09-22 官方发布）

- 腾讯混元语音团队联合多所高校研究人员发布全双工语音交互模型 Gander，可同步接收语音、图像、文本输入，并在自身输出语音的同时持续处理多模态信息，支持用户随时打断。
- 架构上按「小脑 + 大脑」拆分：小脑按秒级管理对话流程，决定倾听、发言或被打断时停止输出，以最近约两分钟对话为记忆，无需独立语音起止检测模块；大脑在后台完成推理与复杂智能体任务，可直接替换为 Codex、Claude Code 等系统而无需重训对话模块。
- 测试数据：在 Full-Duplex-Bench v3 语音助手场景取得对话时机表现最优成绩，100 个测试场景均能在恰当时机开口，打断用户比例 8%，低于 GPT-Realtime 的 13.5%。
- 官方同时披露短板：任务准确率略落后竞品，音视频理解弱于其基础模型，物体计数与图像定位类任务存在不足；训练使用约 270 万个样本。
- 代码已上线 GitHub 并提供演示页，权重与训练数据待开源流程完成后公开。

## OpenAI

### 发布政策提案：呼吁美国牵头制定前沿 AI 全球技术标准（09-21 官方博客）

- 当地 09-21 OpenAI 发布《Building standards for the next phase of AI》政策提案，核心是呼吁由美国牵头，与各国合作建立面向前沿 AI 的全球技术标准机制。
- 两个重点方向：建立衔接各国与国际层面的前沿 AI 标准机制；推动统一的 AI 能力测量、风险评估与事故报告机制。
- 提案把「递归自我改进（RSI）」纳入标准讨论范围，覆盖两类对象：按能力基准界定的前沿模型及其开发者，以及自动化 AI 研究（含 RSI 的收益与风险管理）。
- 官方同时强调边界：目前尚未出现完全自主的 RSI，在无法确保安全的情况下不应推动完全自主 RSI；并称自动化 AI 研究并不必然走向快速递归自我改进。
- 官方援引正在形成的各国 AI 安全机构网络（澳大利亚、加拿大、德国、法国、肯尼亚、日本、韩国、新加坡、印度、英国等）作为标准制定抓手；Sam Altman 将于本周向联合国安理会就 AI 与国际安全作简报。

### Muse 购物代理被亚马逊拦下，平台首次正面封禁第三方 AI 代理下单（09-21）

- 09-21 起，把 Meta 个人 AI 助手 Muse 指向亚马逊的用户会看到警告：「未经授权的 AI 代理」继续访问违反亚马逊使用条款；亚马逊表示已要求 Meta 将亚马逊从其体验中移除。

- Meta 口径：Muse 看不到用户密码或支付明细，凭证存放在安全存储中，供认证使用而不暴露给模型。

## Hugging Face

### tokenizers v1 首个候选版：单线程编码提速 3—30 倍、token ID 不变（09-21 官方博客）

- 09-21 Hugging Face 发布 tokenizers v1 的 release candidate，底层用 Rust 重写，但保持 v0.23 的 API 与 token ID 完全一致，可直接替换、无需重训。
- 性能口径：在十类模型家族、Apple M4 Max 上，单线程编码较 v0.23 提升 3—30 倍；八线程下线性扩展 76%（官方自测数据，同时公开了 tokbench 测试工具与复现命令）。
- 关键改法：用 SIMD 手写切分器替代通用正则引擎、引入线程本地词缓存、重写 BPE 合并循环以消除堆分配、支持共享 tokenizer 的多线程原生并行编码。
- 注意事项：Python 绑定开销未计入上述数字；不受支持的切分模式会回退到正则路径。

## 观察

今天最值得记的不是某一个模型，而是三条同时在动的线。第一条是「标准与治理」被摆到和模型同等的位置：OpenAI 把全球技术标准与 RSI 写进政策提案，Anthropic 用嵌入式评估与生命科学分级准入把安全承诺做成可外部核查的流程，两者的共同点是承认能力增长已经开始快过监督能力，因此把监督做成制度而不是声明。第二条是渠道与入口的争夺：Meta 的 Muse 第一次被平台当着用户的面拦在门外，说明「代理能替用户操作一切」这件事在商业上并不成立——它要求身份透明、要求零售商有退出权、要求价值互换，而这些在当前的代理实践里都还是空白。第三条是基础设施层的静默改良：Hugging Face 重写分词器并保持 token ID 不变，是典型的「不改变语义、只挤掉开销」，在长上下文与 Agent 循环把 CPU 侧准备时间放大的今天，这类改动的收益会被反复放大。国内这边，云栖把 Qwen4 的参数目标写成 5—10 万亿，腾讯混元在图像与全双工语音两端同时出手，都指向同一件事：竞争重心正从「单点跑分」转向「模型能不能被嵌进真实工作流」。
