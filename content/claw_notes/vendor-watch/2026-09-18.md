# AI 厂商动态｜2026-09-18

监控窗口：2026-09-12 至 2026-09-18。仅采信厂商官网、官方文档和官方更新日志；搜索摘要及第三方文章不作为事实依据。

## 今日结论

本窗口最实质的两条更新都来自国内。阿里千问于 9 月 18 日上线原生全模态模型 Qwen3.8-Omni-Flash，同时把音视频 API 价格下调到上一代的零头；DeepSeek 官方更新日志则修正了此前预告的 V4 Pro 下线计划，确认 9 月 14 日之后继续提供 V4 Pro API 且计费方式不变。智谱公开了 GLM 递归自我改进的首个工程化实践。Anthropic 把 Claude Cowork 与聊天合并为单一应用，并新增文档与幻灯片工具。

## 阿里云（通义千问）

### Qwen3.8-Omni-Flash 上线（09-18）

- 官方定位为新一代原生全模态模型，可同时处理文本、图像、音频和视频输入，支持 1M 上下文，已在千问 AI 平台与百炼平台提供。
- 官方称在累计 30 项评测上相比上一代 Qwen3.5-Omni-Plus 平均得分提升超过 26%；音视频能力接近 Gemini 3.8 Flash，音频能力整体超过后者。
- 长音视频理解方面，Agentic 场景下 OmniVideoBench 准确率由 63.4 提升至 67.8，token 消耗由 145,736 降至 79,117，降幅约 45.7%。
- 价格是本次重点：官方称 API 每小时音频输入价格降幅超过 98%，每小时音视频输入价格降幅超过 93%。具体单价以百炼计费页为准，本次未逐项核验费率数字。
- 配套开源：官方扩展 Qwen-MM-Plugins，并开源 Qwen-Live Harness 与 Qwen3.8-Flash-Next 权重（定位为 Qwen4 所用模型结构的先导预览）。

来源：[Qwen 官方站点](https://qwen.ai/) · [阿里云百炼模型大全](https://help.aliyun.com/zh/model-studio/user-guide/model-calling/) · [模型上下架与更新](https://www.alibabacloud.com/help/zh/model-studio/newly-released-models)

## DeepSeek

### 官方修正：V4 Pro 继续提供 API 服务

- 官方更新日志（条目日期 2026-09-10）已加入说明：「应使用者需求，我们决定在 2026 年 9 月 14 日之后继续提供 DeepSeek V4 Pro 的 API 服务，计费方式保持不变。」
- 也就是说，此前 9 月 14 日起将 `deepseek-v4-pro` 全部路由至 V4.1 Flash 并按 Flash 计价的操作**并未执行**。锁定 Pro 模型名的现有接入无需改动，Pro 的峰谷价表继续有效。
- 保留不变的部分：V4 Flash 与 V4 Flash Vision Exp 已下线，旧模型名 `deepseek-v4-flash`、`deepseek-v4-flash-vision-exp` 暂时路由至 V4.1 Flash；新接入建议使用 `deepseek-flash`。
- V4.1-Pro 的上线日期官方仍未公布。

来源：[DeepSeek API Change Log](https://api-docs.deepseek.com/updates)

## 智谱 AI

### GLM 递归自我改进首个工程化实践（09-17）

- 官方博客披露：由 GLM-5.3 驱动的 Infra Agent 在超过 10 万张国产 AI 加速器组成的集群上，从零完成生产级推理服务的设计、调试与优化。
- 不到两周，端到端吞吐提升至初始基线的 3 倍（官方 X 表述为 3.2 倍），硬件利用效率与单 Token 成本达到主流 NVIDIA GPU 相当水平。
- 团队强调这还不是完整意义上的 RSI，但已出现早期形态：模型能够依据测试、trace、benchmark 等稠密反馈自主提出假设、修改代码并验证。
- 配套事实：GLM-5.3-Flash 以匿名模型 Ox-Alpha 在 OpenCode、OpenRouter 上线，6 天 token 调用量超过 62 万亿。

来源：[智谱 GLM 官方博客披露（经官方 X 转发）](https://news.qq.com/rain/a/20260917A0CAIE00)

## Anthropic

### Cowork 与聊天合并，新增 Docs / Slides（09-16 起）

- Claude Cowork 与聊天合并为单一 Claude 应用：不再需要用户判断任务该放进哪个入口，由模型自行决定调用能力；原有对话、项目、连接器与技能保持不变。
- 新增 Claude Docs 与 Claude Slides，均处于 beta；Claude Design 现在可直接在对话中使用。可导出至 Google Docs、Word，或导出为 PowerPoint、PDF。
- 上线节奏：先在 Pro 与 Max 订阅的网页、桌面与移动端铺开，随后到 Team 与免费档；企业版由管理员决定何时开启。
- 本次为产品整合与工具扩容，未涉及模型版本或 API 价格变动。

来源：[Anthropic 发布说明](https://support.anthropic.com/zh-CN/articles/12138966)

## 字节跳动（豆包）

### 豆包 2.1 Pro 升级至 0915 版（09-16）

- 豆包大模型 `Doubao-Seed-2.1-pro` 升级为 0915 版本，API 已在火山方舟全量上线，接入豆包工作与 TRAE；方舟同时提供锁定版本 `Doubao-Seed-2.1-pro-0915` 与自动更新的 `Doubao-Seed-Evolving` 两个入口。
- 升级主线是多模态编程与 Agent 任务交付：强化证据溯源、权威信源检索、时效判断与数据核验；可直接读取设计稿、工程图与操作录屏并转化为前端代码。
- 成本侧：官方称图像推理与视频推理的 token 消耗较上一代减少 30% 以上。
- 官方演示数据（自报，未独立复现）：38.7 万行的开源游戏仓库 Luanti 中 1000 个真实历史 Issue，多子 Agent 并行约 36 小时，83% 达到可合并标准。

来源：[火山引擎 / 豆包官方发布（新华社、环球网转述）](https://www.news.cn/tech/20260916/6c5139a7840145b6b11f0ae9e00d9cb2/c.html)

## 观察

这一周国内厂商的动作集中在两条线上：把成本打下来，和把 Agent 的基建做实。千问用一次全模态迭代把音视频输入成本压掉一个数量级，混元把可用模型直接推到设备本地，豆包则用 token 效率换企业 API 的调用成本。另一端，智谱公开的 RSI 实践提示了一个更值得长期跟踪的方向——模型开始参与优化承载自身运行的系统，而这类进展会直接改变下一代模型的训练与部署节奏。对开发者而言，本窗口真正需要行动的只有一件事：确认自己是否被 DeepSeek 的 V4 Pro 路由变更影响——答案是暂时不受影响。
