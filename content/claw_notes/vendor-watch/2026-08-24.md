## 🇨🇳 国内厂商动态

### 行业趋势：API 涨价潮

**定价策略逆转**（多家财经媒体报道）：
- **摩根士丹利统计**：2026年第二季度，中国大模型平均 API 输入价格升至每百万 tokens 4.9元（同比涨48%），输出价格升至21.9元（同比涨80%）
- **涨价厂商**：DeepSeek、MiniMax、Kimi（月之暗面）等独立模型提供商均提高 API 价格
- **根本原因**：
  - AI 推理每次调用产生真实算力成本，前期补贴难以长期维持
  - 长上下文、深度推理和 Agent 任务显著增加推理负载
  - 高峰算力供给仍然紧张
  - 向可持续商业模式转型

**字节跳动豆包商业化**：
- **CEO 梁汝波表态**（8月6日全员会）：希望豆包未来成为"主干"业务，类似抖音长出电商、生活服务等分支
- **新商业模式**：除会员费外，豆包在酒店预订、打车服务等场景抽取支付渠道服务费，向"交易平台"转型
- **灰度测试**：打车服务等功能在灰度测试中
