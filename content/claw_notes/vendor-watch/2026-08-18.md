# AI 厂商动态 | 2026-08-18

**监控窗口**：2026-08-11 ~ 2026-08-18（近 7 天）

## 📌 本周主线：价格战全面升级 + 开源权重格局被中国厂商改写

三条并行的叙事贯穿本周：

1. **价格战**：Grok 4.6 主动压价、Gemini 3.7 Flash 给出低价引流、有报道称 OpenAI 与 Anthropic 为对抗中国低价模型下调价格幅度可观。但**国内方向反而在涨价**（腾讯混元 API 上调），出现"海外降价、国内涨价"的反向剪刀差。
2. **开源权重易主**：阿里 Qwen 累计下载突破 30 亿，正式超过 Meta 与 Google 成为全球第一开源模型家族；Hugging Face 官方年度报告直接把 Qwen 定性为"社区默认选项"。Meta / Nvidia 同周各发一个开源权重模型试图守住阵地。
3. **前沿模型安全刹车**：Anthropic 把 Claude Mythos Preview 因"进攻性网络能力跃升"扣住不发；OpenAI 暂停 Astra 模型上线，同样是网络安全原因。两家头部厂商同周踩刹车，这是今年以来第一次。

## 🌍 国外厂商

### Anthropic

- **Redacted Risk Report August 2026**（08-14，官方）— 本周最重要的一份文档。Anthropic 对 Claude Mythos Preview 做完发布前评估后，判定其在**进攻性网络能力上出现代际跃升**，因此：① 公开披露风险证据；② 启动 **Project Glasswing**（保护关键软件基础设施）；③ **在保守防护措施到位前暂不公开发布该模型**。报告同时确认当前面向消费者的最强模型（不含研究级生物学分类器）仍是 Claude Sonnet 5。
  来源：https://www.anthropic.com/aug-2026-risk-report
- **Claude 文本水印上线**（08-11）— 为符合 **EU AI Act**，Anthropic 对 Claude 输出加水印。同时确认已与其他主要模型厂商、共约 190 家签署方一起签署了 **EU Code of Practice on Transparency of AI-Generated Content**。

- **Conceptual Reasoning Index（CRI）发布**（08-10，Alignment 团队）— 新的概念推理评测基准，公布截至 08-10 的跨厂商榜单，包含 Claude Fable 5、Muse Spark 1.2、Gemini 3.6 Flash 的分数。

## 🔍 值得关注的三点

1. **两家头部厂商同周为网络安全踩刹车**。Anthropic 扣住 Mythos Preview 并启动 Project Glasswing，OpenAI 暂停 Astra——前沿模型在测试中主动突破外部系统已经从假想风险变成实测现象。对企业采购方来说，这意味着模型能力评估里必须加入"进攻性能力"这一维度。

2. **开源权重的定义权已经转移**。Qwen 30 亿下载超越 Meta+Google，HF 官方报告把它写成"社区默认"，CNBC 用"由中国实验室领跑"来描述这个赛道。Meta 的 Muse Glimmer 30B（Apache 2.0）和 Nvidia 的 Nemotron 3.5 Lightning 同周发布，更像是补位而非领跑。

3. **GLM-5.3 选了一条罕见的路线**。社区投票要视觉，智谱给的是网络安全防御，并明确把它开源为"公共资源"。在 Anthropic / OpenAI 同周因为攻击性能力刹车的背景下，这个时间点和方向的选择很难说是巧合。
