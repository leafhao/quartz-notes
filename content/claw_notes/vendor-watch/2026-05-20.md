## 📌 一周要点

本周最大事件是 **Google I/O 2026**（5/19），一次性铺出 Gemini Omni、Gemini 3.5 Flash、Antigravity 2.0 三条主线。Anthropic 这周走的是「企业落地+生态收购」节奏：KPMG 全员部署 Claude、收购 Stainless、$200M 携手盖茨基金会、与 Blackstone 合资企业 AI 公司，外加一条 Series G $30B@$380B 估值的融资。OpenAI 主线是安全/合规（内容来源溯源、Trusted Contact）和 GPT-5.5 Instant，DevDay 2026 已定档。Meta AI / 国内大厂本周无重大新模型发布，但产业层面有几条值得记一笔的信号。

## 🌐 国外厂商

### 🅰️ Anthropic（高密度发布周）

- **5/19 KPMG 全球战略联盟**：Claude 接入 KPMG Digital Gateway，覆盖 **276,000+ 员工**；先落地税务/法务客户工具，并用于网络安全漏洞识别与修复。
  - 来源：https://www.anthropic.com/news/anthropic-kpmg
- **5/18 收购 Stainless**：Stainless 是 Anthropic 官方 SDK 自最早期起的生成基础设施，能把 API spec 转成 TypeScript / Python / Go / Java / Kotlin 等多语言 SDK、CLI、MCP server。此举强化 Anthropic 在 **MCP 工具生态**上的护城河。
  - 来源：https://www.anthropic.com/news/anthropic-acquires-stainless
- **5/14 PwC 扩展合作**：PwC 部署 Claude 用于技术构建、并购执行和企业职能再造，加入 **Claude Partner Network**（已含 Accenture、Deloitte 等）。
  - 来源：https://www.anthropic.com/news/pwc-expanded-partnership
- **5/14 与盖茨基金会 $200M 合作**：聚焦 Claude 在公益领域的「有益部署」研究，承诺公开决策思路。
  - 来源：https://www.anthropic.com/news/gates-foundation-partnership
- **其他动态**：与 Blackstone 合资成立企业 AI 服务公司、收购 Vercept 推进 Claude computer use 能力、Series G $30B 融资@$380B post-money、Higher usage limits + SpaceX 算力合作、Claude Design 产品发布。
  - Newsroom：https://www.anthropic.com/news

### 🔵 Google DeepMind（I/O 2026 全家桶）

**Google I/O 2026（5/19）一次性发布**：

- **Gemini Omni**：从任意输入（首发支持 video）创建任意内容；在世界理解、多模态和编辑能力上是一次跃迁。
- **Gemini 3.5 Flash**：3.5 系列首发模型，「frontier intelligence with action」，**今日在 Antigravity / Gemini API（AI Studio + Android Studio）/ Gemini Enterprise / Gemini App / AI Mode 全面可用**。
- **Gemini 3.5 Pro**：内部使用中，**下月发布**。
- **Antigravity 2.0**：从 IDE 扩展为「自主 AI Agent 集群开发与管理平台」，新独立桌面应用。
- **Gemini App 更智能**：proactive daily briefs、Gemini Spark 全天候 agent。
- **Search**：AI Mode 由 Gemini 驱动，Search box 全面重设，引入信息 agent + mini apps。
- **Gmail Live**：语音搜索收件箱。
- **使用配额改为 compute-based**：从 prompt 次数改为按计算量计费（更合理处理简单 vs 复杂请求）。
- 来源：https://blog.google/innovation-and-ai/sundar-pichai-io-2026/
- 模型卡：https://deepmind.google/models/model-cards/gemini-3-5-flash/
