## 国内厂商

### 腾讯混元：Hy4 正式版发布，首次能看图、能操作电脑

- 位置：`tencent.com/zh-cn/tencent-launches-hy4-joining-the-ranks-of-the-worlds-leading-open-source-ai-models/`，官方新闻稿日期 **2026-11-04**。混元官网（`hunyuan.tencent.com`）是纯 JS 应用、抓不到正文，这条只在腾讯官网新闻中心出现——这也是它上两期被漏掉的原因。
- 是什么：Hy4 是混元新一代旗舰大模型，官方自述「Hy 首次跻身最强开源模型之列」。相比 Hy4 Preview，显著扩大了预训练与后训练的数据和规模，**首次引入视觉理解**（细粒度图像处理、复杂图表分析、数学视觉推理），**首次支持电脑操作（Computer Use）**——可结合命令行与图形界面完成任务，并针对 Blender、CAD 等专业软件与跨应用长程任务做了专项训练。
- 开源：**权重将于近期开放**，同步发布模型系统卡片，重点披露网络与生物安全风险。**当前并未开放权重**，不要按「已开源」传播。
- 定价：与 Preview **一致**——输入 6 元／百万 token、输出 18 元／百万、缓存命中 0.3 元／百万；腾讯云 TokenHub 即日起至 **2026-12-31 按刊例价五折**；WorkBuddy／CodeBuddy 在 **11-04 至 11-15** 给一定免费额度。另预告 **Hy4 Flash 近期上线**，主打极致性价比。
- 金融场景横向对比（官方众测）：213 位专家（153 位来自外部头部金融机构、七成五年以上经验）、579 个真实金融任务，得分 **Hy4 3.04**、DeepSeek-V4.1-Flash-1017 2.97、Kimi K3.1 Pro 2.68、GLM-5.3 2.68，官方称位居开源模型第一；讯兔科技 IRAB 内部评测较 Preview 提升 12.03 个百分点。
- 其他官方数字：自建评测幻觉率 12.95%→**7.2%**，猜测导致的错误率 23.1%→**5.6%**；WorkBuddy 平均效果 83.18 分、通过率 96.15%，12 个场景中 9 个国内第一；GameDev +19.1%、GameLogic +9.8%；TenureTrail 内部评测覆盖七大学科 123 项可执行研究任务（只给定性描述，未给分数）。
- 安全：训练中只纳入与 PoC 生成、漏洞修复相关的防守性网络安全数据，剔除漏洞利用、逆向、渗透等攻击性内容；由玄武、科恩实验室做密码分析／逆向／漏洞利用方向审计，结论是「未展现突出风险」；生物安全侧自述「基础知识较强，但转化为可执行实验方案的能力仍有限」。
- 顺带开源：与 Hyra2.0 协同研发的 **HyCell**（单细胞表征基座）与 **HyPDE**（物理场基座）已开源。
- 落地：腾讯云 TokenHub、WorkBuddy／CodeBuddy、元宝、企业微信智能助理「大圆」、ima 已上线；API 同步接入 OpenRouter、Hermes、OpenCode；QQ、王者荣耀、和平精英、微信读书、腾讯新闻在接入中。
- 怎么读：这条的分量不在参数，在**「发布即铺满自家产品线」＋「定价不动、再叠五折」**。混元把视觉与电脑操作补齐后，第一次有资格在开源阵营里按「能干活」而不是「能答题」被比较；但它自己写明与顶尖闭源仍有差距，权重也还没放出来，先按「可试用的旗舰」看，别按「已开源的 SOTA」看。

### 百度：开源 ERNIE 5.5 Flash Base 基座模型

- 位置：`ernie.baidu.com/release/ernie-5-5-flash-base/`，页面标注 **Product updates / November 5, 2026**；权重在 Hugging Face `baidu/ERNIE-5.5-Flash-Base`（FP8 与 BF16 两版）。
- 是什么：ERNIE 5.5 Flash 的**预训练终点权重**，刻意不带中训练与后训练——官方定位是「给领域适配、指令微调与强化学习研究一个共同起点」，不是可直接对话的模型，经后训练的版本随后再发。
- 规格：稀疏 MoE，总参 **280B**、每 token 激活 **14B**；43 层 Transformer，除首层外各层为 MoE 块，每块 512 个路由专家、激活 10 个另加 1 个共享专家；**33.5T token** 从零预训练，预训练上下文 **128K**，微调与推理可扩到 **1M**。
- 结构创新（官方自述）：Latent-Gated Sparse Attention（HCA + MLA + 低秩门控注意力 + 虚拟头注意力，门控投影参数减 **75%**）、Multi-Router Latent MoE（多个独立路由器共同选专家）、ECHO（复用末层预测后续 token，同时充当投机解码草稿）、MultiMax 输出头。
- 训练：Muon 优化器 + FP8 混合精度，数千卡规模；自研注意力算子 **FlashMask-4**（基于 CuTe-DSL，支持 SM90/SM100，官方称大 head dim 下前向比 FlashAttention-4 快最多 **175%**）。
- 评测：官方在 30 个基准上与 DeepSeek-V4-Flash-Base、Hy3-preview-Base、MiMo-V2.5-Base 同框架对比，称同尺寸 SOTA；给出的分数含 MMLU-Pro 78.4（对手 69.2）、HumanEval+ 82.3（对手 69.5），但在 ChineseSimpleQA、BBH（CoT）与 InfiniteBench 上落后。**均为自报，无第三方复现。**
- 缺口：官方公告未给许可条款细节（权重按 ERNIE 5.5 Flash Base Model License Agreement v1.0 发布），商用前必须自己去模型页读条款；FP8 权重约 288GB，小团队跑不动。
- 怎么读：把「基座权重」直接放出来，是给下游做后训练的人省掉最贵的一段；但 base 模型不会听指令、不会拒绝，接进产品前必须有 SFT/RL 预算。

## 国外厂商

### Anthropic：Claude 上线个人理财 Beta

- 位置：`claude.com/resources/articles/introducing-personal-finance-in-claude`（Product updates，**November 5, 2026**）。`claude.com/blog` 是 Next.js 页面，href 抓不到，但 `/blog/<slug>` 会 308 跳到 `/resources/articles/<slug>`，可直接探活。
- 是什么：在 Claude 侧栏新增 Personal Finance，用 **Plaid** 连接银行与信用卡账户后，用自然语言问收支、找异常、做图表与日历。**权限只读**——不能转账、不能管理或投资资金；明确不提供投资建议。
- 范围：本周起在**美国**的 **Pro、Max、Ultra** 套餐上以 Beta 推出，逐步放量。
- 数据边界：Claude 能看到账户名、类型、后四位、余额与额度，以及**最多两年**的交易；在理财 Hub 内的对话**不用于训练**；可随时解绑，解绑后不再可见；不向 Claude 提供银行密码。
- 能力示例（官方演示）：问「这个月钱花哪了」，跨账户汇总并按类别拆分（示例 4,309.37 美元，房租水电过半、餐饮 1,024.51）；追问「是不是比平时多」会翻前几个月并指出会员续费；再问「发薪日前还剩多少」，指出四笔待扣款后剩 1,393.22 美元；还能生成周支出图、到期日历与自定义看板。
- 怎么读：这是把「个人财务」做成 Claude 的一个入口，而不是又一层聊天界面——**只读 + 不训练 + 无广告**是它敢碰钱的三个前提。风险仍在模型会算错，官方自己也写「重要数字请跟银行核对」。

### 谷歌：ADK 2.14.0，A2A 协议从实验特性转正式

- 位置：GitHub `google/adk-python` `v2.14.0`，`published_at` **2026-11-07T00:58Z＝北京 11-07 08:58**（changelog 标题写 2026-11-04，属切版与发布的时间差）。上一个版本 v2.13.0（10-23）。
- 主要变化：**执行环境、A2A、评测、核心运行时四组模块从 experimental 转为正式**——`BaseEnvironment`／`LocalEnvironment`／`EnvironmentToolset`／`DaytonaEnvironment`、A2A 相关接口、多轮评测与核心 runtime 不再挂实验标记，意味着升级不再需要照着实验特性名单逐个开关。
- 其他：新增**多轮评测**（multi-run evaluation）与工具参数的**语义匹配**；接入 **Microsoft Teams** 与 **OpenAI Decisions**；长多轮工作流的执行速度提升。
- 怎么读：A2A 从「Google 提的实验协议」变成「ADK 里可以依赖的稳定接口」，这才是这条的实际含义——多智能体互通开始按可维护的 API 对待，而不是按 demo 对待。
