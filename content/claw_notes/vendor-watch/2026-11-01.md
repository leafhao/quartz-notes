### Anthropic：订阅从「Max 5x／Max 20x」改成「Max／Ultra」，最高档去掉 5 小时限额

- 位置：`anthropic.com/pricing`（本期直取页面正文核对，**页面本身不带发布日期**，生效日只能从档位命名与聚合站口径推为 10-31 起分批，官方未发公告，本期按「已生效的现状」记）。
- 现状四档：
  - **Free $0**：每 5 小时与每周有限额度。
  - **Pro $20/月**（年付 $17/月、一次性 $200）：新增 **Fable 按用量额度付费**（标注 New）；Claude Code、Dashboards（beta）、Science、Projects、Chrome／Microsoft 365 插件均在列。
  - **Max $100/月**（原 **Max 5x**）：Pro 的 5 倍用量（每 5 小时与每周）；**Fable 含在订阅内，上限为周额度的一半**（New）；**每月 100 美元 API 额度**（New）；高级功能早期访问（New）；高峰期优先。
  - **Ultra $200/月**（原 **Max 20x**）：**取消每 5 小时限额**——但脚注限定「**仅对已验证账户**」；每周 10 倍 Pro 用量；**每月 200 美元 API 额度**（Max 是 100 美元，标注 up from $100 on Max）。
- 怎么读：① 价格没变（100／200 美元原位），变的是**名字与权益结构**；② 真正的实质变化是 Ultra 的「无 5 小时限额」+ 两档都发 API 额度，等于把「订阅额度」和「API 余额」打通了一部分；③ 「不限时」不等于「不限量」，周额度仍是硬约束，官方脚注也写明用量上限取决于模型、对话长度与文件大小；④ 验证方式官方未在定价页说明，只说「已验证账户」，新账号大概率仍有临时限制。
- 对使用者的实际影响：跑长任务的 Claude Code 用户是唯一真正受益的群体；只要还在按周计算，重度使用仍会撞上限。

- 位置：`api-docs.deepseek.com/quick_start/pricing.md`「Search & Fetch Pricing」段落，原文：*when you use the DeepSeek API through DeepSeek Harness, Claude Code, or Codex, server-side tool calls already hit the Search and Fetch APIs. - 价目：**Search 与 Fetch 均为每 1,000 次成功请求 $0.75**（按成功请求计，不是按 token）。两个接口是独立 API：`POST /v1/tools/search`（返回结构化结果）与 `POST /v1/tools/fetch`（抓单页、返回 Markdown）。

- 扣费规则未变：优先扣赠送余额，再扣充值余额。

## 本期实测与入口备忘

- **网络环境继续收缩，且这次的封锁面比 10-31 更宽**：`developers.openai.com` 与 `platform.openai.com` 一律 **403**（返回边缘节点 `Forbidden`）；`ai.google.dev` **000**、`cloud.google.com` 正文为空、`cloudblog.withgoogle.com/rss/` **0 条**；`huggingface.co`（含 `api/models` 接口）**TLS 直接失败**；`docs.claude.com`／`platform.claude.com` 仍重定向到 **app-unavailable-in-region**；`jules.google` **000**。**结论：本期四条固定入口（OpenAI API changelog、Gemini API changelog、HF 官方博客、Claude API 发布说明）全部不可用**，能核到的只有 RSS 与 GitHub API。
- **可用且稳定**：`openai.com/news/rss.xml`、`api.github.com`（`anthropics/claude-code`、`openai/codex`、`huggingface/transformers`、`QwenLM/qwen-code`、`Tencent-Hunyuan`）、`blog.google/rss/`、`deepmind.google/blog/rss.xml`、`about.fb.com/news/feed`、`anthropic.com/pricing`（正文可抓）、`www.kimi.ai`、`platform.kimi.com/docs/*.md`、`api-docs.deepseek.com/*.md`、`help.aliyun.com` 百炼表格、`ark.volcengine.com/models.json`。
- **新入口（重要）**：**`platform.kimi.com/docs/changelog.md` 可拿到完整 markdown 正文**——上一期只抓到 319KB 的 Next.js 外壳、误判「内容只到 2026 年 9 月」，其实加 `.md` 就能读到 10 月段的全部条目；同一手法适用于 `api-docs.deepseek.com/quick_start/pricing.md` 与 `guides/search.md`（**这是本期发现 DeepSeek 计费生效日的唯一途径**，HTML 版 pricing 页只有 7KB 空壳）。**Mintlify／Docusaurus 类文档站一律先试 `.md`**，能省掉整轮 JS 渲染的排查。
- **教训**：① **定价页不带日期，但「今天生效」的计费条款会写在正文里**——DeepSeek 的 `per-request billing starts at 00:00 Beijing time on November 1, 2026` 一行，比任何博客公告都硬；盯定价页 `.md` 应当成为每期固定动作。② **订阅档位改名的信息量在权益结构里，不在价格上**——Max／Ultra 价格没动，真正的变化是 Ultra 去掉 5 小时限额（且限「已验证账户」）与两档发 API 额度；只写「改名」会漏掉读者最关心的部分。③ **页面级 `dateModified` 已经连续三期把 MiniMax 的列表页刷成「今天」**，只要日期在页面 JSON-LD 里且与正文条目对不上，一律判为渲染时间。④ **Vercel／Framer 类站点的 `Last Published` 是全站时间**，不等于单页更新，别拿它给页面定日期。
