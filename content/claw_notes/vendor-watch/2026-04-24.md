**GPT Image 2 正式发布**（Apr 21, 2026）
- 全新的图像生成模型，支持图像生成和编辑
- 特性：灵活图像尺寸、高保真图像输入、Token 计价、Batch API 支持（50% 折扣）
- API 端点：`v1/images/generations`、`v1/images/edits`

**Agents SDK 更新**（Apr 15, 2026）
- 新增在受控沙箱中运行 Agent 的能力
- 支持检查和定制开源 harness
- 控制记忆创建时机和存储位置
