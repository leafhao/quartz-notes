# AI 厂商动态 | 2026-05-17

> 本期聚焦 **2026-05-10 ~ 2026-05-17** 国内外主要 AI 厂商的官方动态。仅采信官方来源，自媒体预测和传闻不予收录。

## 📌 一句话总结

国外这周以 **OpenAI 五连发** 和 **Google I/O 前置 Android Show** 为主线；国内 **智谱市值冲上 5000 亿港元**、**MiniMax 同时推 M2.7 开源 / Music 2.6 / Hermes Agent 兼容**，整体节奏从「卷模型」转向「卷部署 + 卷算力 + 卷生态」。

---

## 🌍 国外厂商

### OpenAI

> 官方信源：[openai.com/news](https://openai.com/news/)

- **2026-05-14 | Safety**：发布[「Helping ChatGPT better recognize context in sensitive conversations」](https://openai.com/news/)，对敏感话题场景做上下文识别强化。
- **2026-05-13 | Engineering**：[Codex on Windows 安全沙箱](https://openai.com/news/) 上线，支持在 Windows 本地跑 Codex 任务。
- **2026-05-13 | Company**：[针对 TanStack npm 供应链攻击的回应](https://openai.com/news/)，给出官方处置和缓解方案。
- **2026-05-11 | Company**：[OpenAI Deployment Company 成立](https://openai.com/index/openai-launches-the-deployment-company/)，定位为「帮企业把智能落地」的专门子公司，由 CRO Denise Dresser 牵头。
- **2026-05-11 | Funding**：[OpenAI 公布融资进展](https://openai.com/index/accelerating-the-next-phase-ai/)，宣布筹集约 1220 亿美元加速下一代 AI；同期上线 Signals 数据实验室与 [2026Q1 ChatGPT 采用情况报告](https://openai.com/signals/research/2026q1-update/)。
- **关联背景**：5 月 7 日发布的 [Realtime Voice 新模型（gpt-realtime 等）](https://community.openai.com/t/new-realtime-voice-models-in-the-api/1380471) 仍在 API 灰度推广，提供实时翻译与转写。

**重点**：Deployment Company 是 **结构性变化**，意味着 OpenAI 把企业落地业务公司化运营，会直接挤压 Cohere、Glean 这类企业 AI 套壳层。

### Anthropic

> 官方信源：[anthropic.com/news](https://www.anthropic.com/news)

- **2026-05-14 | Announcements**：[与盖茨基金会（Gates Foundation）达成 2 亿美元合作伙伴关系](https://www.anthropic.com/news)，聚焦健康、教育领域的 AI 落地。
- **2026-05-14 | Announcements**：[PwC 部署 Claude](https://www.anthropic.com/news)，把 Claude Code 和 Cowork 推向 PwC 全球咨询团队，从美国先行。
- **2026-05-13 | Announcements**：[Claude for Small Business](https://www.anthropic.com/news/claude-for-small-business) 发布，配套 Workday Foundation Solopreneurship 加速器项目，向 15 名独立创业者发放种子资金 + Claude credits。
- **背景**：旗舰模型 Claude Opus 4.7 于 4 月 16 日 GA、5 月 4 日更新了 Document reasoning / OfficeQA Pro 评测；Claude Mythos Preview 系统卡也在 red.anthropic.com 上线（自主发现并利用 FreeBSD 17 年老 RCE 漏洞 CVE-2026-4747，引发安全圈讨论）。

**重点**：Anthropic 这周没有新模型，但通过 **PwC + 盖茨基金会 + 中小企业** 三连击把 Claude 的渠道铺到「咨询、公益、SMB」三个新区。

### Google / Google DeepMind

  - 公布 **Googlebook**：为 Gemini Intelligence 设计的新一代笔记本设备形态。
- **Save the date**：**Google I/O 2026 主会 5 月 19-20 日**，预计发布新一代 Gemini 模型（被坊间猜测为 4.0 或 3.5/3.6 中间版本）以及 Android XR 智能眼镜。

**重点**：Android Show 已经把「主动式 Agent」打到系统级，这是和苹果 Apple Intelligence 路线最直接的对撞，I/O 主会前哨战。

### Hugging Face

**重点**：开源「执行型 Agent 模型」明显加速，Ling-2.6 系列把「开源 SOTA」从「跑分高」拉向「真能完成多步任务」。

## 🇨🇳 国内厂商

### 智谱 AI

- **2026-05-14**：智谱股价盘中触及 **1229 港元**，市值最高冲到约 4833 亿港元（≈ 5000 亿港元规模），上市以来累计涨幅持续放大。
- **业务侧**：2025 年全年收入 7.243 亿元，**MaaS API 平台 ARR 17 亿元（约 2.5 亿美元），同比增长 60 倍**，毛利率提升至约 18.9%。
- **背景**：4 月 8 日开源的 GLM-5.1（全球首个验证 8 小时持续工作能力的开源模型）持续放量，叠加 GLM-5 / GLM-5-Turbo 两轮共 83% 的 API 提价，奠定收入兑现。

**重点**：智谱这周是 **资本市场胜利**——5000 亿港元市值是国产大模型一哥的位置之争。

### MiniMax（稀宇科技）

- **MiniMax M2.7**：旗舰文本模型，已在 [官网模型页](https://www.minimaxi.com/models/text/m27) 上线 NEW 标记，同时官方公告确认 **开源 M2.7**，对标 Claude Opus / GPT-5.4 Pro。
- **MiniMax Music 2.6**：4 月 10 日发布，仍是当前主推的音乐生成旗舰，海外平台 WaveSpeedAI 已上架 API。
- **MiniMax Speech 2.8**：新一代 TTS 模型，已在官网模型页打上 NEW 标，Hermes Agent 0.x 版本已合入 `MiniMax TTS provider (speech-2.8)`（PR #4963）。
- **生态合作**：MiniMax 发布**全球首个基于 Hermes Agent 架构的 Agent 产品**（21 财经报道），从模型层下探到 Agent 应用层。

**重点**：MiniMax 这周是国产厂商里**密度最高**的，文本（M2.7 开源）+ 音乐（Music 2.6）+ 语音（Speech 2.8）+ Agent 平台四条线同时铺开。

### 月之暗面（Kimi）

- **Kimi K2.6**（4 月 20 日发布并开源）继续是当前主力旗舰，强调代码、长程任务执行和 Agent 集群（Agent Swarm）能力。
- **Kimi 平台**继续推 K2.6 接入 Kimi Claw、群聊、Agent Swarm 等产品形态。
- 本周**无重大新模型发布**，节奏处于 K2.6 商业化推广阶段；同时有上市传闻持续发酵（自媒体来源，未列入正文）。

### 百度 / 字节 / 腾讯

## 🎯 重点关注

1. **OpenAI Deployment Company 成立 + 1220 亿美元融资**：OpenAI 把企业落地公司化，这是跨年的结构性变化，值得长期跟踪对企业 AI 服务市场的挤压效应。
2. **Google I/O 2026 主会 5/19-20**：下周的关键发布日，预计有新一代 Gemini 模型 + Android XR 智能眼镜，提前准备好 I/O 当晚的 vendor-watch 加更。
3. **MiniMax 四线齐发 + 适配 Hermes Agent**：M2.7 开源、Music 2.6、Speech 2.8、Agent 产品同时落地，是国内厂商里**对 Hermes Agent 用户最直接相关**的一家。
4. **智谱市值站上 5000 亿港元**：一旦能站稳，会显著影响后续国内大模型公司的估值锚和融资节奏。
5. **Anthropic 渠道下沉（PwC + Gates + SMB）**：模型节奏放缓，但渠道扩张三连击，配合 Opus 4.7 的 1M 上下文卖点形成「企业级闭环」。
