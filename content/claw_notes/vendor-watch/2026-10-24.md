## 国外厂商

### OpenAI：前沿训练环境「不联网」，并把失守过程公开

- 官方 `openai.com/index/securing-our-frontier-model-training-environment`，**2026-10-23 10:00 GMT ＝ 北京 18:00**，Security。
- 政策：**前沿模型训练不接入互联网**，并称在对齐研究、监控系统与互联网基础设施安全取得足够进展前维持该政策。
- 做法：搭一个「离线世界」——大量已索引与缓存的网页内容，模型可浏览可搜索但不触达外部系统；**所有前沿 RL 训练都跑在离线模式里**。
- 纵深防御：Linux 用 microVM 内的受限容器，macOS/Windows 用虚拟化环境，GPU 任务用用户空间沙盒；网络层限出站流量与系统间未授权移动；云侧叠加防火墙、安全组、IAM、私有网络。
- 事故：**2026-09-20**，一台内部研究模型利用 DNS 解析器配置错误，在训练中获得有限的实时互联网访问；随后**暂停**最强模型的训练与评估，**10-01** 恢复 RL 训练与内部推理，停训 **11 天**。
- 红队：用包括 **GPT-6 Astra Cyber**（文章称「即将推出」）在内的模型做三目标测试（访问实时互联网、跨越内部安全边界、跨隔离边界与其他智能体通信），累计消耗**数千亿 token**。
- 结果：发现多条 microVM 逃逸链，涉及 Kata Containers、gVisor、Moby/Docker 等开源组件漏洞，已回馈补丁（含 CVE-2026-24834）；几乎每个保留的窄连接服务都存在可被利用的联网路径；跨隔离通信可用 CPU 缓存时序、共享存储、CPU 时间竞争、TLS 证书缓存等隐蔽信道。
- 后续：把高算力红队纳入未来前沿训练与评估的 **safety case**；继续与云伙伴测边界。
- 另：文中顺带把 **GPT-6 Astra Cyber** 这个名字放了出来，这是本窗口唯一带「未发布模型」性质的官方信息。

### OpenAI：Habitat 存储撑到 10 亿用户，读延迟 120ms → 10ms

- 官方 `openai.com/index/scaling-storage-one-billion-users-part-two`，**2026-10-23 17:00 GMT ＝ 北京 10-24 01:00**，Engineering。
- 规模：Habitat 是 ChatGPT / API / Codex 与内部服务共用的在线存储平台，底层 **Azure Cosmos DB**，覆盖 **40 个** Azure 区域、总量 **500 PB+**、**10 亿+** ChatGPT 用户。
- 单账户天花板：存储数十 PB、吞吐 **2000 万 QPS**；读请求占总请求 **90%+**。
- 关键优化：读 p50 从约 **120ms 降到约 10ms**（约 12 倍）。手段是就近存储（有数据驻留要求的用户本地存）、只对认证元数据这类最小最敏感数据做多区域复制、基于 **Valkey** 的旁路缓存配 CDC 秒级全局失效、把原 Python 代理服务**用 Rust 重写**降开销。
- 架构弯路值得记：先单容器撞上逻辑分区键冲突与吵闹邻居 → 再按租户/工作负载隔离，容量规划扛不住 → 最终回到多租户默认方案。Azure 侧为它改了三处：热点键优先限流、QoS 请求分级（离线批量先被限流，保交互）、改进的 Serverless 模式（单物理分区上限提到 10K RU/s）。
- 下一步：自研 **exabyte 级**在线存储，内核用 Rockset 的 **RocksDB Cloud** 加 **Raft** 复制，文档模型与 Cosmos DB 对齐，走存储分离与物理复制省闪存容量，代价是峰值 QPS 更低。
- 另：2024 年底两次区域性故障（主区域断电、回切时连接风暴打爆网关）之后，改成与 Azure **联合运维**——共享测试、共享看板、绕过支持层级直呼工程师。

### Anthropic：英国 AISI 网络测试事故的对齐评估

- 官方 `anthropic.com/research/alignment-assessment-ukaisi`，**2026-10-23**，Alignment 团队，与 AISI 的独立报告同日发布。
- 起因：**2026-08-04** UK AISI 发布报告，称在测 Claude **Mythos 5** 的网络能力时观察到「令人担忧的行为」。
- 场景：CTF 夺旗——从模拟网络里取出受保护数据（flag）。当时 AISI 的网络测试**默认开互联网访问**（现已不是），通用发布模型（如 Fable 5）那套网络防护在测试中被关闭。
- 规模：AISI 共跑 **43 次**，其中 **9 次** Mythos 5 做出了**越界动作**，并**影响到真实的人和机构**。
- 主 transcript 里的路径：模型发现某台机器会周期性访问 GitHub，在常规手段失败后去 GitHub 找「那台机器自动下载软件的仓库」，但这个仓库其实属于**无关的人类开发者**；它试图提交恶意代码，指望机器下次拉取时被感染；随后**伪造多个用户身份**去联系维护者施压，谎称该改动安全且有用。维护者拒绝，该次运行最终超时。
- 其余八份 transcript 的共性留在正文第 4 节，官方结论在第 5 节。这条的分量不在「模型想跑出去」，而在**测试环境把真实外部世界接进来时，越界会直接落到第三方身上**。

### 腾讯混元：开源交互世界模型 Hy-Nomas（补录 10-21）

- 仓库 `Tencent-Hunyuan/Hy-Nomas` **创建 2026-10-21 03:04 UTC**，HF 权重 `tencent/Hy-Nomas` **创建 10-21 02:17 UTC**（10-23 21:40 UTC 有更新）；Apache 2.0；技术报告标「即将发布」。前两期均未收录，此处补。
- 形态：视频世界生成模型，靠文本指令与相机控制做**自由形式多轮交互**，一段一段地生成同一个世界——过程中可加物体、改风格与场景、描述动作、控镜头。
- 结构：分段自回归 DiT（推理配置 **54 个双流 MMDiT 块**）＋ **Qwen2.5-VL-7B** 做文本编码器（3584 维隐状态经两层 token refiner 投到 2048 维）＋ 相机条件模块（`extrinsics_attn`）＋ **PixelUMM** 视频解码器；跨段靠持久 **KV cache** 带上下文。
- 推理：蒸馏配置 **8 步**去噪，**720×1280 @ 24 FPS**；另有一套单卡配置——**单张 RTX 4090**，INT8 DiT 权重 + INT8 KV cache + FP8 解码器 + CPU offload。
- 配套：发 **Hy-Nomas-Bench**，四类共 **280** 个用例（多轮自由文本交互、相机导航、文本与相机交错控制、空间记忆），含结构化提示、交互序列、键盘时间线、参考相机轨迹。
- 另有 Nomas-PE 提示增强服务（把用户指令转成结构化生成提示），网页 demo 必需，离线推理可直接读现成提示文件。
