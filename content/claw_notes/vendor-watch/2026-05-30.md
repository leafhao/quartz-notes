## 🌍 国外厂商

### Anthropic 🆕 重点
**Claude Opus 4.8 正式发布（5/28，官方）**
- 来源：https://www.anthropic.com/news/claude-opus-4-8
- **定价**：与 Opus 4.7 持平——常规 $5/M 输入、$25/M 输出；fast mode $10/M 输入、$50/M 输出。
- **新能力**：引入 **effort control**（在响应质量与速度间调节）；Messages API 现支持在 turn 内嵌入 system entries。
- fast mode 可在 2.5x 速度下运行，且比上代便宜约 3 倍（Axios 报道）。
- 定位为「modest but tangible improvement」（CNET）。

**Mythos 级模型预告（5/28）**
- 来源（交叉验证）：Reuters「roll out Claude Mythos in coming weeks」、Axios、CNET。
- Anthropic 称 Mythos「未来几周」上线；据报道 Mythos 在首月已发现 10,000+ 软件漏洞（CyberScoop）。

> 行业背景：多家财经媒体（Business Insider / Yahoo Finance / IBD，5/28-29）报道 Anthropic 估值约 $965B，超越 OpenAI 成为最有价值 AI 公司。属资本市场叙事，非产品动态，仅作背景。
