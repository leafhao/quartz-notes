# AI 厂商动态 | 2026-08-30

> 监控窗口：2026-08-24 至 2026-08-30。仅收录能由厂商官网、官方文档或官方研究页面明确核验日期的更新；自媒体、社区文章、预测、传闻及窗口外内容均已过滤。

## 本期摘要

本期确认 **5 家厂商、9 项窗口内官方更新**。最值得关注的是 Google 连续发布 **Gemini 3.5 Transcribe** 与 **Gemini Omni 1.1 Flash**，分别推进低延迟语音转写和可控专业视频生成；智谱与腾讯则在 8 月 28 日分别推出 **GLM-5.3-Flash** 和开源旗舰预览模型 **Hy4 preview**。阿里云百炼、OpenAI 同期增强模型接入与企业级插件治理能力。

## 1. Google DeepMind：语音与视频模型连续更新

### 1.1 Gemini 3.5 Transcribe

**发布日期：2026-08-26**

Google 发布面向高吞吐、低延迟场景的 Gemini 3.5 Transcribe 与实时版 Transcribe Live：

- 相比 Chirp 3，最终转写延迟降低 **70%**；
- 在官方列出的 FLEURS 多语言评测中，流式/非流式 WER 分别为 **5.50% / 5.04%**；
- 支持噪声环境、实时听写和多语言语音转写；
- 新模型卡将 Live Translate、Transcribe、Transcribe Live 统一归入 Gemini 3.5 Audio。

来源：
- [Intelligent transcription with Gemini 3.5 Transcribe](https://deepmind.google/blog/intelligent-transcription-with-gemini-3-5-transcribe)
- [Gemini 3.5 Audio 模型卡](https://deepmind.google/models/model-cards/gemini-3-5-audio)

### 1.2 Gemini Omni 1.1 Flash

**发布日期：2026-08-27**

Google 发布 Gemini Omni 1.1 Flash，并通过 Gemini API / Google AI Studio 面向开发者提供更可控的视频生产能力：

- 支持场景延展与首尾帧插值；
- 支持清晰的 **4K 放大**和更快原型迭代；
- 面向专业视频工作流强化生成控制与成片质量；
- 官方同步更新 Gemini Omni Flash 模型卡，并说明生成内容使用 SynthID 水印，涉及人物语音修改的能力当前仍受限制。

来源：
- [Gemini Omni 1.1 Flash lets you build with more control](https://deepmind.google/blog/gemini-omni-1-1-flash-lets-you-build-with-more-control)
- [Gemini Omni Flash 模型卡](https://deepmind.google/models/model-cards/gemini-omni-flash)

## 2. 智谱 AI：GLM-5.3-Flash 发布

**发布日期：2026-08-28**

GLM-5.3-Flash 是 GLM-5 系列首个原生多模态高效模型：

- 320B 总参数、18B 激活参数；
- 面向复杂任务、Agent 工作流、视觉理解与专业生产力；
- 使用稀疏注意力与线性注意力混合架构，并采用 Manifold-Constrained Hyper-Connections；
- 基于 30T token 多模态语料训练；
- API 限时五折：输入 **$0.075/百万 tokens**、缓存输入 **$0.015/百万 tokens**、输出 **$0.25/百万 tokens**，优惠截至 2026-09-09 24:00（UTC+8）。

来源：
- [GLM-5.3-Flash 官方发布](https://autoclaw.z.ai/blog/model/glm-5.3-flash)
- [Z.ai 官方定价](https://docs.z.ai/guides/overview/pricing)

## 3. 腾讯混元：Hy4 preview 发布并开源

**发布日期：2026-08-28**

腾讯发布新一代旗舰预览模型 Hy4 preview：

- 770B 总参数、49B 激活参数、1M 上下文；
- 面向软件工程、办公分析、游戏开发和科学研究等生产力任务；
- 已开源，并在腾讯云、OpenRouter 上线，也可在 CodeBuddy、WorkBuddy、元宝、ima 中体验；
- API 每百万 tokens 定价：缓存输入 **0.3 元**、输入 **6 元**、输出 **18 元**；
- 官方明确其仍是早期预览版，复杂任务中存在长思考和过度自我验证等已知问题。

来源：
- [腾讯混元 Hy4 preview 官方发布](https://hy.tencent.com/research/hy4-preview)
- [腾讯云 TokenHub 调用概览](https://cloud.tencent.com/document/product/1823/130079)

## 4. 阿里云百炼：兼容性与模型数据运维增强

### 4.1 OpenAI 兼容接口新增 Vision 调用模式

**发布日期：2026-08-27**

现有 OpenAI 兼容框架只需调整 `API-KEY`、`BASE_URL` 与 `model` 参数，即可调用千问视觉模型，降低工具链迁移成本。

**发布日期：2026-08-29**

模型数据导入新增更详细的失败与部分成功错误信息，并支持对模型数据发布及导入过程进行状态轮询，改善批量数据管道的可观测性。

来源：
- [Alibaba Cloud Model Studio 功能更新](https://help.aliyun.com/en/model-studio/model-release-notes)

## 观察

1. **实时多模态继续分化为专业模型**：Google 一周内分别强化语音转写与视频生成控制，模型产品正从“通用多模态”细化为面向高吞吐和专业创作的可部署能力。
