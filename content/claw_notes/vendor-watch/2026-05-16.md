## 趋势观察

1. **Agent 基础设施成为主战场**：OpenAI（Managed Agents on AWS）、Anthropic（Dreaming + Multi-Agent）、月之暗面（Agent 集群 300 并行）均在 Agent 能力上重点投入
2. **开源模型追平闭源**：DeepSeek-V4 Pro（MIT）、Kimi K2.6、GLM-5.1 在多项基准上接近或持平 GPT-5.4/Claude Opus 4.6
3. **API 清理与整合**：OpenAI 下线 DALL·E 和 Realtime API Beta，推动用户迁移至新一代接口
4. **自改进系统兴起**：Anthropic Dreaming 代表了 Agent 从"执行工具"向"自我学习系统"的演进方向
