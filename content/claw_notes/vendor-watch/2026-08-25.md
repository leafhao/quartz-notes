# AI 厂商动态 | 2026-08-25

## 本周窗口重点（8/18 - 8/25 严格 7 天内）

以下条目的发布/披露日期确认落在本次 7 天窗口内：

- **Anthropic** — Claude Platform 新增合规性 API 端点（8/18）；Claude 加速蛋白质设计与分析化学研究（8/18）

- **行业** — Raymond James 8月 Token Observer：头尾模型定价差距扩大（8/21）；Guidelight 报告称五大实验室安全系统落后于模型能力（8/20）；Stripe 约 $7.5B 收购 OpenRouter（8/21）；Higgsfield $400M 融资、估值 $5.4B（8/21）；Thomson Reuters 推出自研前沿模型（8/24）；Gemini 3.7 Flash 智能体基准以半价胜出竞品的横评报道（8/24）

## Anthropic

### Claude Sonnet 5（8月10日发布）
- **价格**：$2/M input tokens，$10/M output tokens
- **能力**：提升了 Chat、Cowork、Claude Code 和 API 的速率限制，以支持更高的 token 吞吐量
- 来源：[Introducing Claude Sonnet 5](https://www.anthropic.com/news/claude-sonnet-5)

### Claude Opus 5 发布
- **定位**：接近 frontier intelligence 的思考型和主动型模型，价格是 Fable 5 的一半
- **性能**：在编码和知识工作评估中达到新的 SOTA
- 来源：[Introducing Claude Opus 5](https://www.anthropic.com/news/claude-opus-5)

### Project Glasswing（八月）
- **发布方式**：仅向受邀客户开放的新模型，通过 Project Glasswing 计划部署
- **描述**：Anthropic 对外部署的最强模型，内部广泛用于研究和工程
- 来源：[Redacted Risk Report August 2026](https://www.anthropic.com/aug-2026-risk-report)

### 文本水印技术（8月2日）
- **功能**：为符合 EU AI Act 要求，Claude 输出添加不可见水印
- **覆盖范围**：2026年8月2日后发布的模型立即支持，旧模型将在未来几个月逐步推出
- 来源：[How Claude's text watermarking works](https://www.anthropic.com/news/claude-text-watermark)

### 企业安全功能（8月6日）
- **Beta 功能**：企业计划现可开启技能和插件安全扫描，自动检测第三方技能和插件中的恶意内容
- 来源：[Release notes | Claude Apps](https://docs.anthropic.com/en/release-notes/claude-apps)

### API 合规性端点（8月11日、8月18日）
- 新增多个合规性 API 端点：
  - `GET /v1/compliance/apps/sessions/local`
  - `GET /v1/compliance/apps/sessions/local/{session_id}`
  - `GET /v1/compliance/apps/sessions/local/{session_id}/messages`
- 新增权限范围：`read:compliance_user_data`
- 来源：[Claude Platform release notes](https://docs.anthropic.com/en/release-notes/api)

### 科学研究应用（8月18日）
- **案例**：Claude 加速蛋白质设计和分析化学研究
- 来源：[How Claude is accelerating protein design and analytical chemistry](https://www.anthropic.com/research/Claude-accelerates-protein-design)

## OpenAI

### GPT-5.6 Sol（8月11日）
- **特性**：超低延迟推理，基于 Cerebras 合作提供 Ultrafast 模式
- **定位**：OpenAI 最智能模型的超高速推理版本
- 来源：[OpenAI Release Notes - August 2026](https://releasebot.io/updates/openai)

### GPT-5.6 Luna（8月中旬）
- **用户范围**：替代 GPT-5.5 成为免费和 Go 用户的默认模型
- **新功能**：提供新特性支持
- 来源：[Best AI Chatbots 2026](https://tech-insider.org/best-ai-chatbots-2026)

### Codex 升级（8月13日、8月18日）
- **改进方向**：更快、更可靠，深度集成到现有工具中

### 网络安全能力声明（8月7日）

### Codex 扩展为通用生产力工具（8月17日）

- **驱动因素**：新的网络安全模型推出
- 来源：[Raymond James sees token pricing gap widen](https://www.investing.com/news/stock-market-news/raymond-james-sees-token-pricing-gap-widen-in-august-2026-93CH-4872027)

### Anthropic 营收增长
- **数据**：Anthropic 的 ARR 增长超过 OpenAI，但增速开始放缓
- 来源：[Anthropic: The Economics of an AI Pioneer](https://temaetfs.com/insights/anthropic-the-economics-of-an-ai-pioneer)

### OpenAI 现金消耗和 Token 价格
- **趋势**：Token 价格暴跌，OpenAI 每月烧钱数十亿美元
- **时间节点**：Token 定价指数在 OpenAI 和 Anthropic 宣布保密 IPO 申请（6月初）的几天前达到峰值
- 来源：[OpenAI Is Burning Billions as Token Prices Plunge](https://marketwise.com/investing/openai-cash-burn-token-prices-plunge)

## 总结

本周 AI 厂商发布密集，主要看点：

1. **Anthropic**：Sonnet 5 和 Opus 5 双发布，Project Glasswing 限量推出最强模型，文本水印技术响应 EU 监管
2. **OpenAI**：GPT-5.6 Sol/Luna 双版本，Codex 从编码工具扩展为通用生产力平台，模型退役加速迭代
3. **Google**：Gemini 3.7 Flash 在性能和价格上击败竞品，机器人和世界模型持续推进
4. **Meta**：开源 Muse Glimmer 30B，可在消费级硬件运行的智能体模型
5. **国内厂商**：本周窗口内无重大官方发布
6. **行业**：Token 价格战加剧，Anthropic 营收增长超越 OpenAI，AI 安全问题凸显，大规模融资持续
