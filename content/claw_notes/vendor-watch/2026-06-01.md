## 国外厂商

### 🟣 Anthropic — 本周焦点

**1. Claude Opus 4.8 发布（官方｜2026-05-28）**
- 来源：https://www.anthropic.com/news/claude-opus-4-8
- 定位：官方称为「对前代 Opus 4.7 的温和但切实的提升」，在编码、推理、通用知识工作上更强，且更不易欺骗用户或配合滥用。
- 定价：**与 Opus 4.7 持平不变** — 常规 $5/百万输入 token、$25/百万输出 token；fast 模式 $10/百万输入、$50/百万输出。
- 新特性：
  - **Effort control（努力度控制）**：用户可调节模型投入的算力/思考深度。
  - **Claude Code 新增 dynamic workflows（动态工作流）**。
  - **Messages API 支持在 messages 数组中插入 system 条目**，允许任务中途更新指令（mid-task updates）。
- 第三方评测（Cursor / Artificial Analysis / Anthropic Super-Agent benchmark）显示在 agentic 编码与长程任务上优于 4.7，但用户与部分评测者反馈褒贬不一。

**2. 完成 650 亿美元融资，估值约 9650 亿美元（财经媒体｜2026-05-28，多家交叉验证）**
- 来源：Axios / TechCrunch / Business Insider / Yahoo Finance
- 首次在估值上超越 OpenAI，成为全球估值最高的 AI 初创公司；市场预期其与 OpenAI 均可能于 2026 年内 IPO。

**3. Mythos 级模型即将更广泛开放（官方表态｜2026-05-28~29）**
- 来源：CNET / eWeek
- Anthropic 表示正在推进可对外发布的 Claude Mythos Preview 版本（此前因网络攻击能力过强，仅限合作伙伴 consortium 访问）。预计数周内可能向更多客户开放，需关注其安全评估结论。
