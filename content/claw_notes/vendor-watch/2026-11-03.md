### OpenAI：发布 LifeVal 评测，把「日常事务」变成可量化指标

- 位置：`openai.com/index/lifeval`，RSS `pubDate` 为 **2026-11-02 09:00 GMT＝北京 11-02 17:00**，归类 Research / Publication。
- 是什么：一套新评估基准，官方定位原话是 *Measuring AI progress on the tasks that matter in everyday life*——把评测从学术知识题转向「AI 能不能真把生活里的事办完」。
- 任务从哪来：以两份大型时间使用研究（American Time Use Survey、Multinational Time Use Study）为骨架，另做一轮 **3,995 人**、具人口统计学代表性的新调查，覆盖照护、健康、教育、家庭行政、个人理财、购物、办政府手续七类。
- 官方给的四个示例分数：搬家后给孩子报名合适幼儿园 **93.1%**、洪水来临前调度志愿者 **98.0%**、为家人找新房 **100%**、为刚确诊糖尿病的父母准备膳食与照护计划 **90.4%**。
- 配套说法：每周超 10 亿人用 ChatGPT，用户要的不是建议而是「动作」；过去一年模型在 browser use、computer use、connectors 三类任务上「更快、更强、更对齐」。
- 边界：官方**没有把 LifeVal 说成公开数据集**，也没给完整任务清单与全模型横评；四个分数是示例任务的单点成绩，不能横向推出「哪家模型更能干家务」。
- 怎么读：这条的价值不在分数，在口径——OpenAI 正在给「Agent 有用性」立一把自己的尺子，后续 GPT-6.x 的发布话术大概率会围绕它展开。做评测或选型的人要注意：这是自建、自测、自报。

### 字节跳动：开源 Axion 1.0，两档智能体基座 + 全流程配方

- 位置：GitHub 官方组织 `bytedance/axion1_0`，仓库 `created_at` **2026-11-02 04:42Z＝北京 11-02 12:42**，最后一次推送 11-02 23:41Z；项目页 `axion1-0.github.io`，技术报告 PDF 已可下载；**Apache 2.0**。
- 它是什么：字节与 Duke、马里兰大学、布法罗大学合作的**智能体基座模型**（agent foundation model），作者单位列出 ByteDance，项目负责人 Yunjie Tian（字节）。官方一句话定位：*Frontier-level agent capabilities with nothing more than high-quality data and a simple training recipe: 2 SFT + RL*。
- 两档模型（**底座都是阿里的通义**，这点最关键）：
  - Axion 1.0-35B ← Qwen3.6-35B-A3B，35B 总参／3B 激活；
  - Axion 1.0-122B ← Qwen3.5-122B-A10B，122B 总参／10B 激活。
  - 论文另报了 4B、9B 两个只做 SFT 的版本。
- 训练配方（三阶段，无 mid-training、无 DPO、无 OPD）：Stage I 用 **10,819 条**科学与数学推理轨迹（把公开种子题按基座模型已会的解法做组合、参数化、范围平移、分情况讨论来加难，答案逐步复核）；Stage II 用 **7,544 条**、约 **312M token** 的工具依赖任务（从 NASA Exoplanet Archive、OurAirports、OpenAlex、UniProt、Ensembl 等构造问题，答案在构造时由程序算定，解题方只能靠检索拿证据）；最后用**异步 GRPO** 在搜索、网页访问、学术检索、Python 上做 RL，答对给全奖、可验证的中间进展给部分奖励，长 rollout 按 session 切分做上下文压缩。
- 成本（官方明列）：122B 两阶段 SFT **7 小时 30 分／32 卡 240 GPU 小时**；35B 同配置 **2 小时 48 分／约 90 GPU 小时**；122B RL 约 15 小时（40 rollout + 16 训练卡，40 步）；35B RL 约 30 小时（8+8 卡，20 步）。SFT 上下文 128K，FSDP + 专家并行 + 上下文并行，Token-In-Token-Out 保 token id、rollout 路由回放对齐 MoE 专家选择。
- 成绩（技术报告 Table 1，自报）：122B——HLE 59.0（受限联网）、BioMysteryBench 41.7、SEAL-0 58.6、HiPhO 46.2、FrontierScience 奥赛 **87.0**、FrontierScience 研究 **66.7**；35B——52.2／35.3／**62.2**／45.7／86.0／56.7。对照：GPT-5.6 Sol 在 FS 奥赛 79.0、FS 研究 63.3；Gemini 3.1 Pro 在 FS 奥赛 85.0、FS 研究 26.7；Claude Fable 5 的 HLE 63.8。
- **口径注意**：表里带 `*` 的基线是 Axion 团队自己跑的（GPT-5.6 Sol 与 Gemini 3.1 Pro 多数格带星），其余取自各家官方报告，官方自己也标注「跨来源对比可能用了不同工具或执行设置」；Axion 的分数取三次中的最好一次（BMB 取五次）。
- 开源程度：仓库已放数据构造与过滤、prompt、两阶段 SFT、异步 RL、benchmark 准备与打分的代码；训练数据在 Hugging Face（`Axion1-0/axion-training-data`）；**模型权重明确写 coming soon，尚未发布**。
- 怎么读：三件事值得记。① 字节在「Agent 训练方法论」上打的是极简牌——把复杂度全压到数据构造，而不是堆训练阶段；② 底座用 Qwen3.6／3.5，等于公开承认在开源基座上做后训练，比从零预训练便宜得多，这条对自建团队参考价值最大；③ 现在只有代码与数据、没有权重，**它不是可用模型发布，是一份可复现的配方**，别把它当豆包产品线更新。

## 本期实测与入口备忘

- **可用入口**：`openai.com/news/rss.xml`（含 pubDate 与 link）、`openai.com/index/<slug>`（正文需 WebFetch，curl 会拿 JS 挑战页）、`anthropic.com/news` 与 `sitemap.xml`（lastmod）、`api.github.com`（releases 与 orgs repos）、`blog.google/rss/`（注意要带末尾斜杠，否则 0 条）、`deepmind.google/blog/rss.xml`、`about.fb.com/news/feed`、`ark.volcengine.com/models.json` 与四份 md 公告、`help.aliyun.com` 百炼表格、`docs.z.ai/release-notes.md`、`platform.kimi.com/docs/changelog.md`、`api-docs.deepseek.com/updates`、`minimax.io/blog`、`help.openai.com`（WebFetch 可读）。
- **仍不可用**：`developers.openai.com` 与 `platform.openai.com` **403**（`.md` 后缀同样 403）；`ai.google.dev`／`cloudblog.withgoogle.com/rss` **超时 exit 28**；`huggingface.co`（含 `api/models`、`blog/feed.xml`）**TLS 失败 exit 35**；`docs.claude.com/en/release-notes/api` 返回 306KB 的 Next.js 壳、正文全在客户端渲染；`research.meta.ai/sitemap.xml` 超时；`seed.bytedance.com` 可抓但无 Axion 相关条目。
- **新入口（重要）**：**`api.github.com/orgs/<org>/repos?sort=created` 应作为每期固定动作扫全部十家**——本期 Axion 1.0 唯一的线索就是 `bytedance` 组织 11-02 04:42Z 的新仓库，官网、RSS、方舟公告、Seed 站点全部没有对应内容；这类「研究型开源发布」只走 GitHub + 项目页。发现后取 `contents/README.md` 的 base64 正文即可拿到全部规格与分数，比抓 HTML 干净。
- **教训**：① **权重未发也是一种状态**，必须查 README 或项目页的 models 栏，本期 `Coming soon` 就是写在项目页顶部的四个指标之一，漏掉会误报成「发布可用模型」。② **sitemap lastmod 批量重建的坑再出现一次**（本期 Anthropic 三篇、MiniMax 全站），凡同一分钟内多个 lastmod 就要怀疑，逐条取 `datePublished`。③ 字节这类「与高校合作的论文仓库」作者单位里会出现多所学校，要看清 ByteDance 是否在列，别当成第三方蹭名。④ `blog.google/rss` 与 `blog.google/rss/` 是两种结果，后者才有 20 条。
