相比 9 月 5 日监控，本轮新增确认 **4 项官方硬动态**：OpenAI 发布 GPT-6 Astra；Google 发布 Gemini 3.8 Flash 与 3.8 Flash Cyber；Meta 发布 Muse Spark 1.3；阿里 Qwen 将旗舰模型升级为 Qwen3.8-Max-0902。其余受监控厂商未发现昨日之后新增、且可由官方来源严格确认的模型发布、API 定价变化或技术公告。

## 1. OpenAI：GPT-6 Astra 发布并开放 API

**日期：2026-09-03**

- OpenAI 将 GPT-6 Astra 定位为当前最强的端到端复杂工作模型，覆盖复杂推理、编码、计算机使用、研究与文档生成。
- API 模型 ID 为 `gpt-6-astra`，上下文窗口 **1,050,000 tokens**，最大输出 **128,000 tokens**；同时在 Amazon Bedrock 提供。
- 标准 API 价格为输入 **$10/MTok**、缓存输入 **$1/MTok**、缓存写入 **$12.50/MTok**、输出 **$50/MTok**；Fast mode 为标准价格的 2 倍。
- 官方安全说明称 Astra 是首个在 OpenAI Preparedness Framework 下达到网络安全 **Critical** 能力等级、并被广泛部署的模型，因此实际接入时需同步关注安全控制和权限边界。

来源：
- [OpenAI：GPT-6 Astra](https://openai.com/index/gpt-6-astra)
- [OpenAI API：GPT-6 Astra model](https://developers.openai.com/api/docs/models/gpt-6-astra)
- [OpenAI：Safety overview](https://openai.com/index/safety-overview-gpt-6-astra)

## 2. Google：Gemini 3.8 Flash 与 3.8 Flash Cyber 发布

**日期：2026-09-02**

- Google 发布 Gemini 3.8 的两个变体：面向通用 agentic 工作流的 **Gemini 3.8 Flash**，以及面向网络安全场景的 **Gemini 3.8 Flash Cyber**。
- `gemini-3.8-flash` 已作为稳定模型提供，主打长程软件工程、自主 Agent 与复杂企业工作流；支持文本、图像、音频和视频输入，文本输出。
- 3.8 Flash 的上下文窗口为 **1,048,576 tokens**，最大输出 **65,536 tokens**。
- 标准推理优惠价截至 2026-12-31：输入 **$0.75/MTok**、输出 **$3.75/MTok**；2027-01-01 起调整为 **$1.50/$7.50**。Flex 层价格为同期标准层的一半。

来源：
- [Google：Introducing Gemini 3.8 Flash and 3.8 Flash Cyber](https://blog.google/innovation-and-ai/models-and-research/gemini-models/3-8-flash-and-3-8-flash-cyber)
- [Gemini API：Gemini 3.8 Flash](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash)
- [Google DeepMind model card](https://deepmind.google/models/model-cards/gemini-3-8-flash)
- [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing)

## 4. 阿里 Qwen：Qwen3.8-Max 升级至 0902 快照

**日期：2026-09-02**

- Qwen 官方账号宣布将旗舰模型升级为 **Qwen3.8-Max-0902**，进一步针对 Coding 与 Cowork 任务进行后训练，面向复杂企业任务、科研和长程工作流。
- 模型维持 **2.4T 总参数**与 **1M 上下文**，现已通过 QwenCloud API 提供。
- 官方公布价格：输入 **$2/MTok**、输出 **$6/MTok**；显式缓存命中 **$0.17/MTok**，隐式缓存命中 **$0.25/MTok**。
- 这是 `Qwen3.8-Max` 的新快照升级，不应在尚无独立官方 SKU 文档时擅自视为全新的产品系列。

来源：[Qwen 官方账号：Qwen3.8-Max-0902](https://x.com/Alibaba_Qwen/status/2094968708288680276)
