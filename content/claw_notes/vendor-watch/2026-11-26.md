## Anthropic：Messages API 迁到 Rust

11-25 发布，Engineering 长文《Migrating our Messages API to Rust》。这是客户和我们自己的 Claude Code / Cowork 到达模型的唯一主通道。

- **为什么迁**：2023 年用 Python 写，当时"基本就是个请求转发器"。到 2025 年底每个请求都要校验、转成 prompt、tokenize、过安全分类器，返回时还要把 token 流拆成 text / thinking / tool calls，Python 在每次建对象、释放内存、任务交接上叠加开销。**2024 年初到 2026 年秋，API 流量涨了约 1,800 倍**。
- **先试增量，判定不值**：只把输出解析挪到 Rust，CPU 降 8%–10%，但每个 token 要跨 Python/Rust 三次，复杂度抵不过收益。（2024 年曾有工程师拍板："我们不会用 Go 或 Rust 重写 API！"）
- **前提变了**：2026 年 5 月，Anthropic 合并的代码里 **Claude 写了超过 80%**。写代码不再是瓶颈，**验证成了瓶颈**。
- **验证怎么做**：原有约 700 个集成测试，但耦合 Python 实现、无法覆盖生产边的边角行为。最终把**生产 API 本身当 oracle**，在影子流量上跑新版对比。三个难点——Python 版一直在变（parity 是移动靶）、模型输出不确定（差异不等于 bug）、不能读客户请求（看不到分叉点）。
- **把差异变成可执行信号**：checkpoint 定位差异落在代码哪一段，fingerprint 区分不同 bug，同一 bug 归并。三层循环：本地沙箱快循环（agent 自己写请求、秒级试假设）→ 慢循环（影子生产流量验证修复）→ 最外层是 prose，把修正写成 memory 规则，供流程中后续所有 agent 读取。
- **结果**：每请求 **CPU 约降 70%**、**中位首字延迟约降 20%**，未下线、未冻结功能开发，乘客一批批搬过去。
- **结论**：验证是新瓶颈；只要能给 Claude 一个可靠的验证信号，就可以把野心放大。文中对比 Bun 从 Zig 迁 Rust 时用同一套 TypeScript 测试判两版，说明"当测试不足以判定正确时，生产系统本身也能当验证器"。

## Anthropic：58 家客户访谈（补录）

11-23 发布，Economics 团队与 Nathan Wilmers、Maxim Massenkoff、Peter McCrory 合作，**66 次访谈、58 家 Anthropic 企业客户**。

- **价值来源**：多数用法靠**增产**而非降本；coding agent 正在把软件能力交到非技术岗位手里。
- **就业**：因 AI 自动化导致的本土裁员案例很少；部分公司因 AI 多招人，但**多数表示招聘减少**；不少公司削减外包，尤其离岸外包——作者提示这可能是国际商务服务业的早期扰动信号。
- **瓶颈**：专家抵触、以及 AI 根本提不了速的任务。coding 一快，code review、销售、战略决策就成了新堵点。
- **两种推法都有局限**：自上而下找流程自动化，会带来岗位不安全感、被监控的恐惧和专家抵抗；自下而上发工具，会撞上采用不均和单点工具化。
- **高价值用法都伴随重组**：让员工拥有整条工作流、把人调到 AI 做不了的瓶颈任务、为非开发者写代码铺基础设施、广泛开放业务数据。

## Google DeepMind：质谱解结构的 Antigravity 技能

11-25 发布（Science）。**Mass Spec Skills** 把 Gemini 的化学推理和现成质谱工具、公共化学数据库查询串成一条工作流，在 Antigravity 里跑。

- **要解决的问题**：光谱库检索平均只能注释约 **5%** 的实测谱（人体样本约 10%），其余被称作质谱界的"暗物质"——分子在库里，谱没录过，只能从碎片离子反推结构。
- **工作流**：去噪与找母离子 → 查 GNPS / MoNA 参考库（余弦相似度）→ SIRIUS 定分子式 → MAGMa / MetFrag 配碎片与中性丢失 → 用反应化学打破评分并列。
- **示例链路**：m/z 395.1387 负离子母峰 → 中性质量 396.1459 Da；剔掉 1,700+ 条背景噪声峰；定出 **C20H21ClN6O**（−1.5 ppm，SIRIUS score 37.86 / 亚军 28.33）；845 个 PubChem 同分异构体排序；最终覆盖 **97.7% 碎片强度**（19 峰中 14 峰）。
- **评测**：100 条公共库光谱、每条三次。无网络无技能时三个模型准确率都 **<4%**；只给网络时，前沿模型漏 1/4–1/3，轻量模型漏超 3/4；加上 Skills 后**三个模型都在约 97%** 命中，**Gemini 3.8 Flash 追平 Argon 与 Carbon**。
- **顺带省钱**：每次尝试生成的 token，Flash 降近 **4 倍**、Argon 减半、Carbon 降近 1/5。
- 单个 prompt 可从原始谱直通候选结构 + 可审计报告；每个阶段也能单独跑（清噪、标峰、比同分异构体）。

## 阿里百炼：decision-model 上架

11-25 上架（华北2 北京、新加坡等地域）。定位是**面向高频业务判断的结构化决策模型**。

- 可据文本、图片或业务状态**并行**完成分类、是非判断与评分，返回概率分布与置信度；场景是工单分流、内容审核、智能体路由、结果校验。
- 输入文本 / 图像，输出结构化决策结果；**上下文 268,288**（最大输入同值），最大输出未标注。
- **价格：输入 0.3 元/百万 token**（北京）、**0.306 元**（新加坡）；限流 RPM 5,000 / TPM 5,000,000。
- 能力项大量"不支持"：模型体验、Function Calling、结构化输出、联网搜索、前缀续写、上下文缓存、批量推理、模型调优。**它不是通用对话模型，是嵌在流程里的判定器**。
