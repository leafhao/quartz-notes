## 国外厂商

### Google DeepMind：Gemini 4 Carbon 正式开放

- 位置：`blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/`（**November 10, 2026**，作者 Koray Kavukcuoglu）；DeepMind 侧同名稿 `pubDate` **11-10 16:03 GMT＝北京 11-11 00:03**，301 回 blog.google。开发者向另有一篇短稿 `.../technology/developers-tools/gemini-4-carbon-developers/`（同刻），只讲入口、不给规格。
- 是什么：Carbon 与 4 月起的 Argon 同属 **Gemini 4** 家族。Argon 是「大多数软件工程与知识工作的默认首选」，Carbon 定位**极限智能任务**——多步复杂编码／调试、开放式科研发现，特征是用更多 token 换深度推理与多轮验证循环。网络安全版另有 **Gemini 4 Carbon for cyber**，走 **Fairwind Program** 申请。
- 定价（介绍期，与 Argon 同价）：**输入 $2 ／ 输出 $10 每百万 token**；**2026-11-30 介绍期结束后回到 $4 ／ $20**，只针对面向公众开放的 Carbon。
- 基准：**CursorBench 4.0、Perplexity WANDR、Zapier AutomationBench 三项第一**，官方称相较次优外部模型**每任务成本低 2 倍以上**；与 Artificial Analysis 合推的 **MKA** 基准里排第 **2**，但每任务成本低 **6 倍以上**；Hebbia 端到端金融 agent 评测与最佳模型持平；Balyasny 通用金融智能基准在 23 个前沿配置里靠前。安全侧：单次攻击突破率 **0.8%**（Argon 3.1%）、Gray Swan 自动化攻击成功率 **2.17%**（Argon 9.86%）、375 题 agentic 诚实度 **92%**（Argon 70%）、拒绝编造缺失实验数据 **98%**、Gray Swan 间接提示注入成功率 **0%**（首个达成该里程碑）。
- 网安侧（Fairwind）：SEC-bench Pro、ExploitGym、CWE-bench v1 均领先；内部 Project Fortify 扫描召回 **100%**、分诊精确 **95%**；对比 Argon 开源库召回提升 **超 25%**。
- 可用性：开发者走 **Gemini API 付费层、AI Studio、Android Studio**；AI Ultra 订阅者可在 **Antigravity、AI Studio** 用，Gemini app 与 Search 的 AI Mode 也向 Ultra 开放；企业侧进 **Gemini for business、Antigravity、CodeMender**；科学家／研究者可申请 **6 个月免费**（滚动审核）；防守方走 Fairwind。同刻 **`/swarm` 预发布**：在 Antigravity 里把单条提示变成可实时追踪的协调 agent 团队。

### Google DeepMind：AlphaProof Code，四周验证完 Signal 协议

- 位置：`deepmind.google/blog/introducing-alphaproof-code/`（**November 10, 2026**，12:02 GMT＝北京 20:02；作者 Pushmeet Kohli、Swarat Chaudhuri）。
- 是什么：一个**多 LLM agent 框架**，把形式化验证拆成三件事同时开工——规格（人与多模型协作把安全目标翻成形式化数学命题，每条经人类专家审）、代码（把编译后的机器码跑在 Lean 处理器模型上，验的是**设备上真正跑的代码**而不是设计层）、证明（Gemini Carbon 驱动的 agent 团队生成证明，配「守门人」校验，全部由 Lean 机器检查）。
- 规模与工时：产出 **600 万行以上 Lean 代码**，耗时 **4 周**——传统专家团队通常要数年。AI 先自审证明并标出需人工看的部分，人只需复核代码库的 **1%**。
- 压力测试：往隔离版 Signal 代码里**重新注入 2 个已修复过的真实 bug**，系统都给出机器校验的证明、判「不安全」——即它能抓回归。
- 开源：验证产物已开源（`google-deepmind.github.io/code-verification`），技术论文随页发布。Signal CTO Ehren Kret 出镜背书。
- 官方自认局限：仍需人定「证什么」、审每条规格与那 1%；规模化到其他系统「需持续研究」；覆盖面只是 Signal 的核心密码学代码。
- 怎么读：真正的信号不是「AI 会写证明了」，而是**验证对象下沉到机器码**，并且第一次有人对广泛部署的密码学协议实现做完整形式化验证。对做安全与高可靠系统的团队，这是可参照的工程范式；对普通开发，短期内还借不上力。

### Google DeepMind：MKA 基准，200 题考「看图纸干活」

- 位置：`blog.google/innovation-and-ai/models-and-research/gemini-models/multimodal-knowledge-agent-benchmark/`（**November 10, 2026**，作者 Rohan Doshi、Ben Caine），与 Artificial Analysis 合推。
- 是什么：**Multimodal Knowledge Agent** 基准，专测 agent 在**视觉复杂文件**上做知识工作——交叉比对建筑图纸、追踪工程示意、把发现整理成报告／表格／演示。10 个行业、83 种职业，任务由建筑师、生物学家、核保师等专家出。
- 结构：**200 题**，单题相当于资深专业人士 **3–8 小时**；每题含真实提示词＋多模态文件包＋约 **70 项是／否**评分项，**75% 事实准确性／25% 视觉呈现**。200 题私有防泄漏，另在 Hugging Face 放 10 题公开样例。
- 结果：Gemini 4 Carbon 质量排第 **2**、成本低 **6 倍以上**，落在质量-价格帕累托前沿；官方未公布各家具体分数。
- 可复用的发现：同一任务不同模型用 **30–130 个回合**，差距极大；**去掉视觉能力后模型全部失败**，说明强感知是必要条件；自动评分器与专家人工评分一致率 **96%**；所有模型跑在开源框架 **Stirrup** 里、工具与回合预算一致。

### OpenAI：Businesses in ChatGPT 开放 Beta

- 位置：`openai.com/index/introducing-businesses-chatgpt`（`pubDate` **11-10 10:00 GMT＝北京 18:00**，Product Releases）。
- 是什么：两块——**Business Hub**（企业认领身份、改关键信息、挂产品数据源含价格与库存，Shopify 商家可直接连店，商品经 Shopify Catalog 进 ChatGPT）与 **Business Agents**（符合条件的企业可自建、测试、发布专属 agent，用户从模型回答里点进企业主页即可开始对话，对话明确标识且与主对话隔离）。
- 配套：给企业的**聚合洞察**（提及次数、主页浏览、网站点击、被引用时的话题），不分享用户对话内容；企业可**赞助**自己的 Business Agent 作为广告落地页，赞助内容单独标注。
- 范围：面向 ChatGPT 周活 **12 亿**用户；Business Hub 认领对 ChatGPT 可用地区的合格企业开放，**Business Agents 只限美国**的电商与在线服务企业。未公布收费方式，AI 侧无新 API。

- 是什么：H3 家族里**开源的图像生成 + 编辑统一模型**，一个 checkpoint 同时做文生图与多参考图编辑，DiT 沿用 H3 架构去掉音频层、文本编码器沿用 H3。

- 通道：API（文生图／图像编辑／提示词扩写三个端点，`platform.minimax.io` 与 `.cn` 双站）、海螺 App 与 agent.minimax.io。
- 怎么读：开源侧直接对标「高分辨率 + 少步数」这条线，编辑与生成合一是省工程量的设计。本期只核到仓库与产品页，未取到官方基准分数，卡片不写性能结论。
