## 国外厂商

### Google

- **Gemini 4 Argon 正式发布（GA）**（`blog.google` 主站 2026-10-13 16:00 UTC／18:00 UTC 三篇 + Google Cloud Blog 16:00 UTC，作者 Koray Kavukcuoglu，SVP, Google DeepMind 兼首席 AI 架构师）：
  - **定位**：Google 称为面向「深度工作」的新一代前沿模型，聚焦复杂软件工程、企业知识工作（法律、金融）、网络安全防御与科研。官方称在 **Vals Index**（衡量金融、编码、法律、税务等经济部门表现）上排名第一。
  - **规格**（模型卡）：**1M 输入 + 输出**统一上下文窗口；大规模稀疏 **MoE** 架构、原生多模态（文本／图像／音频／视频输入，文本输出）；**知识截止 2026 年 3 月**；非既往模型的修改或微调。官方模型文档口径为「旗舰推理模型，长解码最高到 1M token」。
  - **定价**（`ai.google.dev/gemini-api/docs/pricing`，模型 ID **`gemini-4-argon`**）：**引荐价输入 $2 / 输出 $10 / 上下文缓存 $0.10**（每百万 token），**有效期至 2026-11-30**；**12-01 起回到 $4 / $20 / $0.20**。Batch／Flex 为半价档（$1/$5/$0.05），Priority 档 $3.60 起。**仅隐式缓存**，不支持显式缓存；**免费档与 Google AI Pro（开发者侧）不可用**。
  - **渠道**：Gemini API（AI Studio、Gemini 平台）、**Google Cloud**（Vertex 侧同日在云博客发布）、Google Antigravity（AI Ultra 订阅者）、Gemini 应用与搜索 AI Mode（AI Pro 与 Ultra 订阅者）。模型卡列出六个分发渠道：Gemini App、Gemini API、AI Studio、Gemini for business、Antigravity、AI Mode。
  - **官方影响力举证**：Chrome 团队把核心网页面处理从 Chromium 4000 万行代码里约 600 万行的历史功能目录中拆出，数百文件架构重构「数月工作缩到数周」；ADK（google/adk-python）长会话内存准备时间 **-40%**、冷启动导入 **-21%**；量子化学包 xTB 预测分子结构**快 2.3×**、构象搜索 **1.8×**；Gemma 4 E2B 经 vLLM 端到端**提速 2.85×**（约 37,900 → 108,000 tokens/s，A100）。Antigravity 内智能体代码提交量 **+35%**、回滚减少近三分之一。
  - **安全侧**（`blog.google/.../gemini-4-model-safety-security/`，作者 Anca Dragan、Raluca Ada Popa）：**端到端模拟网络攻击场景 12/12 全部完成**（上一代 5 个）；对抗集上违规率**下降近一半**；生物域未护栏版本也显示更强能力，因此按 **Frontier Safety Framework** 在两域同时启用下一代前沿护栏。三层实时防护：**输入筛查（小模型判断意图）＋内部内省（activation probes 读神经信号）＋持续监控**。发布前经 **Fairwind Program** 限访问期，Wiz 用它发现医院软件关键漏洞。同日发布**完整 Safety and Security Report** 与 **Model Card**（`storage.googleapis.com/deepmind-media/...`）。
  - **基准澄清**：官方评测方法见 `deepmind.com/models/evals-methodology/gemini-4-argon`；第三方榜单分数不计入采信。
- **Gemini 应用侧同步更新**（同日 16:00 UTC）：Argon 进入 Gemini 应用，回答更直接、少套话、长任务更常汇报进度；**Antigravity 的智能体编码界面直接进 Gemini macOS 应用**；主聊天窗新增「chat ↔ tasks」切换（可离机执行）；Gemini 已连接 **40+ 应用**（Instacart、OpenTable、Adobe、Shopify 等）。
- **Google Cloud 侧**（同日 16:00 UTC，作者 Michael Gerstenhaber，VP, Product Management, Gemini, Google Cloud）：Argon 上 Google Cloud；企业场景含 CodeMender；具名客户/伙伴引语来自 **GitLab**（Stuart Moncada）与 **Harvey**（Niko Grupen，称法律智能体评测相对 Gemini 3.1 Pro 显著提升）、**NowAI-Bench** 共建合作。

### Anthropic

- **Claude Code v2.1.299**（GitHub Releases，**2026-10-14 02:49 UTC** = 北京 10-14 10:49）：
  - 主要新增：**终端空闲压缩**（200K+ token 会话闲置约 54 分钟即在 1 小时 prompt cache 过期前压缩，避免下一条消息全量重算）、`CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` 与 `idleCompaction: false` 开关（需 v2.1.290+）；`CLAUDE_CODE_DISABLE_FILE_MENTIONS`（只给模型 `@` 提及的路径而非文件内容）；`prompt.media` 让托管 mod 的 `prompt.submit` 钩子读取附件字节；`$.session.identity()`；`claude self-hosted-runner orchestrator --shutdown-drain-sec`；`claude plugin eval` 新增 `--disallow-tools` 与 `disallowed_tools`；agent view 内 `/effort`、`/fast`；Claude Desktop Code 标签页可用 `CLAUDE_CODE_ATTRIBUTION_HEADER=0` 关闭署名块。
  - 修复项含：拒绝的云会话可能指向错误组织、自定义 `ANTHROPIC_BASE_URL` 网关模型名下接近 200K token 时报「Prompt is too long · automatic compaction failed」、每回合末尾提交 prompt 的 mod 让 headless 会话保持存活等。
- **补录：研究报告《AI 模型或可在没有数据中心的情况下自我复制》**（官方 `/research/self-replicating-ai`，`datePublished` **2026-10-12T19:30:00Z** = 北京 10-13 03:30，前一期遗漏）：
  - Frontier Red Team（William Zhou、Daniel Freeman）出品。实验用 15 台约 55 美元的杂牌 Android TV 盒子组网，分布式跑 **Gemma4-26B-A4B**，实测 **0.39 tokens/s**；**9B 模型在 9 类硬件中 8 类跑通推理**。
  - 结论：30B 及以下模型今天已能完成复制链条中的多数单步，但端到端组合仍出错；简化评测中 **GLM-5.2 及更强模型已能端到端复制**。若小模型按历史速度提升，**今年年底前**可达到该能力水平，「权重型小复制体」可能紧随其后。
  - 风险口径：此类复制体没有集中关停点、且能自行摸索陌生设备；官方称可能较慢（倍增时间以天计）。
- **补录：博客《加强对蒸馏攻击的防御》**（官方 `/research/distillation-defenses`，`datePublished` **2026-10-12T09:30:00Z** = 北京 10-12 17:30，前一期遗漏）：
  - 官方称新方法使攻击方抓取到的数据量**下降约 90%–99%**（早期证据）。
