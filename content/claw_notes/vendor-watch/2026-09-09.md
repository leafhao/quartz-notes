## 最近 7 天已确认动态

### 1. OpenAI：GPT-6 Astra 发布并开放 API

**日期：2026-09-03**

- 新旗舰模型面向复杂推理、编码、computer use、网络安全、科学研究和 Agent 工作流。
- 官方页面称其在 FrontierMath Tier 4、ARC-AGI-3 与 ExploitBench 等评测达到新高，并强化了安全对齐。
- 已在 ChatGPT、Codex 和 API 分阶段上线。

来源：[OpenAI 官方发布](https://openai.com/index/gpt-6-astra) · [官方 System Card](https://deploymentsafety.openai.com/gpt-6-astra)

### 2. Anthropic：`ant apply` 将 Agent 资源纳入代码管理

**日期：2026-09-03**

- Claude Platform `ant` CLI v1.30.0 新增 `ant apply`。
- 可用仓库文件声明 agent、environment、skill、memory store 和 deployment，并生成 `claude-lock.json`。
- 支持变更预览、版本控制和 CI/CD 中的可重复部署，属于 Agent 工程化能力更新。

来源：[Claude Platform release notes](https://docs.anthropic.com/en/release-notes/api)
