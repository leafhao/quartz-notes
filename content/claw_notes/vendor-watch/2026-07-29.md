### xAI (SpaceXAI)

**音频 API 全面升级（7月23-25日）**
- **Speech to Text**、**Text to Speech**、**Speech to Speech** 三大音频 API 文档更新（7月23日）
- 实时语音对话能力增强，支持 WebSocket 实时流式传输
- 新增 `force_message` 功能：TTS 合成的脚本式话语
- 新增 `resumption` 字段：会话缓存与重放机制

**Grok Build 工具链更新（7月24日）**
- 发布 v0.2.112 版本
- 新增 `/tutorial`、`/doctor`、`grok doctor fix` 诊断修复命令
- 新增 `/resume` 和 `grok --resume` 会话恢复功能
- 权限管理优化（7月21日更新）：支持"always allow"授权模式，危险操作（`rm`、`git push`）仍需二次确认

**Google Workspace 集成**
- **Grok in Google Workspace** 插件正式上线
- 核心能力：将大纲自动转为演示文稿，自动研究网络/X平台内容，智能添加图表与图片
- 与现有主题无缝衔接，自动优化标题使每张幻灯片表意清晰

**来源**：https://docs.x.ai/, https://x.ai/build/changelog, https://x.ai/news/introducing-google-workspace-addon

## 总结

### 本周核心趋势

1. **xAI 全方位发力**：音频 API 升级、工具链优化、Google Workspace 集成，展现出全栈能力
2. **月之暗面 Kimi K3 引爆算力焦虑**：全球最大开源模型上线即因算力过载暂停订阅，暴露基础设施瓶颈
3. **行业从"模型竞赛"转向"应用落地"**：WAIC 2026 展会上，模型隐身、Agent 疯野，智能体成为新焦点；OpenAI 推出企业级应用软件，超越纯模型提供商定位
4. **监管共识形成**：OpenAI、Anthropic、Google、Meta 等巨头呼吁统一监管框架，马斯克提议同行评审机制，行业自律与政府监管边界逐渐清晰
5. **投资焦虑加剧**：芯片低迷、$1.6 万亿烧钱、$7 万亿数据中心扩建，投资者开始质疑 AI 投资回报的可持续性

### 中国 AI 生态观察

- **技术差距快速缩小**：从落后 5 年到仅落后几个月
- **应用生态成熟**：十大主流平台覆盖全场景，渗透日常生活与工作
- **基础设施挑战**：Kimi K3 算力过载暴露供给短板，亟需加强算力建设
