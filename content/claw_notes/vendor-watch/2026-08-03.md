## 🟠 OpenAI

**1) GPT-5.6 Luna / Terra 官方降价（07-30 生效）**
- Luna：输入 $1 → **$0.20**/M，输出 $6 → **$1.20**/M（降幅 80%），距商用发布仅三周
- Terra：输入 $2.50 → **$2**/M，输出 $15 → **$12**/M（降幅 20%）
- Sol：维持 $5 / $30 不变，新增更快的 premium processing 模式
- 官方归因：模型本身、推理软件、路由与上下文管理的效率提升，把收益让给客户
- ChatGPT / Codex 订阅价不变，但 Terra 和 Luna 现在消耗更少 usage credits
- 来源：OpenAI 社区公告 + Memeburn 汇总（08-02）

**2) 模型退役时间表（官方 Help Center）**
- **2026-08-09**：Atlas 停止工作，需提前导出数据
- **2026-08-26**：o3 从 ChatGPT 退役（90 天日落期结束），GPT-4.5 同批退役
- **2026-08-31**：Codex 中 GPT-5.4 / 5.4 mini 退役 → 分别切到 GPT-5.6 Terra / GPT-5.6 Luna（ChatGPT 登录用户；自带 API key 的 Codex 使用另算）
- 👉 实操提醒：本月是 OpenAI 老模型清仓月，脚本里写死 `o3` / `gpt-5.4` 的地方要提前改

**3) 研究发布**
- 08-01 发布 *Ten advances in mathematics and theoretical computer science*（openai.com/index/ten-advances-in-mathematics）

**4) 社区负反馈**
- 开发者论坛出现多条 "Codex consistency issues since 5.6" / "Codex 更新是严重退步" 帖（07-31 起），5.5 Medium 被自动切到 5.6 Sol 引发不满，Luna 的 weekly usage 消耗速度与 API 定价不符也被投诉。降价的另一面是路由策略变动带来的体验波动。

## 🇨🇳 国内厂商

### DeepSeek —— 本周国内最强动作

**V4-Flash-0731 正式版发布 + API 公测（07-31）**
- 模型卡明确写「正式版取代 preview」，**架构与规模不变**，性能提升全部来自**重做 post-training**
- 强化方向：工具调用、任务规划、代码开发、Agent 执行
- 附带 **DSpark 投机解码模块**（与 V4-Flash-DSpark 结构一致）
- 调用方式不变，`model` 名设为 `deepseek-v4-flash` 即可
- 定价：cache-miss 输入 **$0.14/M**、cached 输入 **$0.0028/M**、输出 **$0.28/M**；V4-Pro 输出约 **$0.87/M**
- 能力位置：Axios 称 V4 Flash 在复杂代码与自主软件任务上**接近 Claude Opus 4.8**；在 Arena.ai 前端代码众包榜上首发即高位
- 生态注脚：DeepSeek V4 与 GLM-5.2 采用 **MIT**、Qwen3.6 开放模型为 **Apache 2.0**，三家都允许无限制商用
- 连带效应：Michael Burry 公开点评，认为 OpenAI 降价的「真新闻」是为 DeepSeek V4 做准备

### MiniMax —— H3 多模态生成模型
- 2K 视频生成 **0.8 元/秒**，约为同级旗舰的 1/3
- 降本手段：高压缩 Tokenizer 减少视频生成 token 消耗 + 异构训练/任务负载均衡/GPU 利用率优化
- **将于近期开放权重**，成为 MiniMax 首个开源多模态生成模型；企业可本地部署，国产芯片厂商可围绕它做软硬协同优化

### 字节跳动 —— Seedance 2.5
- 继承 Seedance 2.0 的统一音视频联合生成架构
- 单次生成时长 15s → **30s（翻倍）**，且不是单镜头拉长，而是在 30 秒内组织多个逻辑关联镜头，做出起承转合

## 🏛️ 监管与政策（影响厂商发布节奏）

- **白宫 AI 审查 8 月 1 日截止**：行政令本身是自愿性质，且明确不得被解读为强制许可或预审授权。但《2018 出口管制改革法》给了商务部独立权限——**2026 年 6 月商务部曾在 Anthropic 两款模型发布后 90 分钟内切断其全球访问**，并要求 OpenAI 限制 GPT-5.6 Sol 的推出节奏，两家均已配合。实际效果：不参与「自愿」预发布审查的实验室会承担现实风险。
- **游说支出**：OpenAI + Anthropic 2026 Q2 联邦游说合计 **317 万美元**，环比 +23%（CNBC 依据联邦披露）。两家在截止日前约两周向政府草案框架提交了联合修订意见——「政府起草规则、被监管企业修订、政府发布」的流程被批评为利益冲突。
- **"Pacing the Frontier" 联名信**：OpenAI 与 Anthropic 正式支持「放慢会自己写代码的 AI」；Meta 阵营公开反对（见上文）。
- 制度归属之争：OpenAI 6 月 3 日的联邦框架蓝图主张以商务部 AI 安全标准中心为主导机构（基于加州/纽约/伊利诺伊已立法），而 6 月行政令把阈值判定交给了 NSA。
