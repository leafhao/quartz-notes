## OpenAI：GPT-6 的蛋白质设计（研究）

11-24 21:00 北京，预印本《GPT-6 as a Universal Foundation Model for Protein Biology: Beyond Specialized Models》，与 **Onava** 合作做湿实验。核心主张：不调专用生物模型，只靠推理 + 通用编程工具，就能设计蛋白质三维形状与序列。

- **对接打分**：PoseBusters 上 GPT-6.2 命中 **93%**、内部模型 96%，专用模型 DiffDock-L 只有 **50%**；Scarpino 集 92% / 97% vs 60%。
- **基序支架**：内部模型 **43.7%** 成功率，RFdiffusion 27.8%；CATH 指定折叠 18.9%（200 题）vs Proteina 17.1%。
- **突变效应排序**（265 组，秩相关）：GPT-5.6 0.41 → GPT-6 0.52 → GPT-6.2 0.57 → 内部 0.66；抗体结合 DockQ 从 0.05 一路升到 0.81。
- **实验室结果**：322 个 minibinder 打 5 个靶标，**35 个（10.9%）**检出结合；为给定结构设计序列时 MDM2 **85%**、VEGF-A 62%、PD-1 14%；对未公开结构（PD-L1、IL-7Rα）107 个里 13.1% 结合——说明不是背答案；VHH 结合环重设计 **70%** 保持结合，治疗性抗体片段 66%。
- **短板**：完整结构预测 TM-score 只有 0.26，ESMFold2 是 0.93；筛选环节仍要 Boltz-2、OpenDDE、ESMFold2；尚未证明零样本端到端生成 de novo minibinder。特异性、稳定性、活性都未验证。

## OpenAI：用 Astra 找系外行星

11-24 19:00 北京，两个业余天文爱好者的故事，官方只给了线索级结果。

## Anthropic：把 artifact 装成 Mac / Windows 应用

11-24，beta，Claude for Mac / Windows 逐步推送，**全档可用**（Team 默认可装但完全访问默认关；Enterprise 默认关，需 owner 开）。

- artifact 装上后**有自己的图标与独立窗口**，可发给别人，可发通知、往菜单栏 / 系统托盘加条目；底层 artifact 一改，应用**自动更新**。
- 无需打包签名、无需 API key，用 Claude 账户本身；流程是"描述 → 以 artifact 试 → Share 菜单里 Install as app"。
- **三级权限**：默认（只能做浏览器内的事）→ 应用权限（置顶窗口、全局快捷键、通知）→ 完全计算机访问（跑程序、读写删文件且不再逐次询问）。权限只覆盖当前版本，**每次更新都要重新授权**；完全访问只能给自己做的或同组织成员做的应用；Anthropic 不审核。
- 限制：HIPAA-ready 组织与混合部署不可用；必须在线登录；Claude Docs / Slides / Sheets 类 artifact 装不了；应用请求计入计划额度。
- 官方示例：图层图像编辑器 Linnet、片场风格文件管理器 Phosphor、按规则整理文件的 Sift、带解释的终端 Tern、菜单栏性能监视 Vitals。

## Meta：Muse 进英国

11-24 14:00 北京，两篇官方稿同发（介绍 + 控制权说明）。Muse 是"能派活的个人智能体"，由 **Muse Spark** 驱动——官方称这是 **Meta 超级智能实验室（MSL）的第一个模型**，专为真实世界的 agentic 工作训练。

- **可用性**：英国、18+、iOS / Android / muse.ai / WhatsApp；大部分需求免费，重度用户可选订阅；未来数月进 Meta AI 眼镜。
