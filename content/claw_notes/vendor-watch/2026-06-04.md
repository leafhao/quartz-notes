# 🏢 AI 厂商动态 | 2026-06-04

> 时间窗口：2026-05-28 ~ 2026-06-04（最近 7 天）
> 原则：只采信官方来源，财经媒体报道用于交叉验证，已过滤超窗内容与自媒体传闻。

## 📌 本周速览

- **Anthropic**：发布 Claude Opus 4.8（5/28），同步官宣 Mythos 级模型即将公开；Project Glasswing 计划扩容至 15 国 150 家机构；6/1 保密提交美股 IPO。
- **Google**：推出 Gemma 4 12B（6/3），无编码器统一多模态开源模型，主打"笔记本本地高性能"。
- **OpenAI**：GPT-5.5 Instant 在 API 与 ChatGPT 同步更新（5/28）；ChatGPT 上线 Active sessions 会话安全管理（6/2）。
- **NVIDIA**：发布 Cosmos 3（6/1），面向物理 AI 的开放前沿基础模型。
- **Microsoft**：Build 2026 发布首个高级推理模型 MAI-Thinking-1（6/2）。
- **国内厂商**：DeepSeek 据报融资约 74 亿美元（6/3）；MiniMax 筹备 A 股上市（5/30）。本周国内厂商官方"模型发布"较少，多为融资/上市层面动态。

## 🌍 国外厂商

### Anthropic — Claude Opus 4.8 发布 + Mythos 预告 + IPO
- **Claude Opus 4.8**（官方，5/28）：定位"对前代温和但实在的提升"，在编码、推理与通用知识工作上更强，且更不易欺骗用户或被滥用。
  - 定价：常规用量与 Opus 4.7 持平，输入 $5/百万 tokens、输出 $25/百万 tokens；Fast 模式降价至输入 $10/百万、输出 $50/百万（约为旧款 1/3）。
  - API 调用标识：`claude-opus-4-8`，即日全量可用。
  - 来源：https://www.anthropic.com/news/claude-opus-4-8
- **Mythos 级模型**：官方称很快面向所有客户开放；Mythos Preview 已在网络安全场景发现 1 万+ 高危/严重漏洞。
- **Project Glasswing 扩容**（6/2-6/3）：新增约 150 家机构、覆盖 15+ 国家测试 Claude Mythos 能力（含澳大利亚）。
  - 来源：https://cyberscoop.com/anthropic-project-glasswing-expansion-critical-infrastructure-claude-mythos/
- **资本动态**：以 9650 亿美元估值反超 OpenAI 成为最有价值 AI 初创；6/1 向美 SEC 保密提交 IPO（早于 OpenAI）。
  - 来源：Reuters https://www.reuters.com/business/ai-giant-anthropic-confidentially-files-us-ipo-2026-06-01/

### Google DeepMind — Gemma 4 12B
- **Gemma 4 12B**（官方，6/3）：无编码器（encoder-free）的统一多模态模型，主打把高性能多模态智能带到笔记本端侧。属 4 月发布的 Gemma 4 系列延伸。
  - 来源：https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemma-4-12b/
- 注：Gemini 3.5、Gemini Omni、I/O 2026 系列发布均为 5/21，已超 7 天窗口，不计入本周。

### OpenAI — GPT-5.5 Instant 更新 + 账户安全
- **GPT-5.5 Instant Update**（官方 release notes，5/28）：在 ChatGPT 与 API 同步更新，改进回复风格与质量，可读性更佳。
  - 来源：https://help.openai.com/en/articles/9624314-model-release-notes
- **Active sessions**（6/2）：ChatGPT 新增会话安全功能，用户可审查活跃登录会话。
  - 来源：https://help.openai.com/en/articles/6825453-chatgpt-release-notes
- 注：GPT-5.5 旗舰本体发布在 5/5，超窗。

### NVIDIA — Cosmos 3
- **Cosmos 3**（官方 newsroom，6/1）：面向物理 AI（physical AI）的开放前沿基础模型。
  - 来源：https://nvidianews.nvidia.com/news/nvidia-launches-cosmos-3-the-open-frontier-foundation-model-for-physical-ai

### Microsoft — MAI-Thinking-1
- **MAI-Thinking-1**（Build 2026，6/2）：微软首个自研高级推理模型，为本届发布的 7 款新模型之一，标志其自研模型路线推进。
  - 来源：The Verge https://www.theverge.com/tech/941664/microsoft-ai-model-reasoning-mai-thinking-1-build-2026

### Meta AI / Hugging Face
- 本周窗口内无官方新模型发布（Llama 3.1 为 2024 旧闻，Muse Spark 为 4 月发布），已过滤。
