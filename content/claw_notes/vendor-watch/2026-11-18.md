## OpenAI：GPT-6.2 Astra / Sol 双模型发布

**官方稿** `openai.com/index/introducing-gpt-6-2-astra-sol`，RSS pubDate **2026-11-17 17:45 GMT＝北京 11-18 01:45**（分类 Product）。

- **双型号分工**：`gpt-6.2-astra` 面向最难的项目（复杂推理、专业幻灯片／表格／文档、代码、前端、3D 与游戏设计）；`gpt-6.2-sol` 面向日常编码、写作与多步工作流。
- **定价（标准 API，每百万 token）**：Astra 输入 **8 美元**、缓存输入 **0.40 美元**、输出 **40 美元**；Sol **2 / 0.10 / 10 美元**。
- **相对上代**：Astra 输入与输出均降 **20%**、缓存输入降 **60%**；Sol 沿用 GPT-6.1 Sol 原价。
- **上线面**：即日起对 **Plus、Pro、Enterprise、Edu** 开放，入口在 **ChatGPT Work 与 Codex**——**本次未进 ChatGPT 普通聊天模式**。Enterprise／Edu 需管理员在工作区设置中启用。
- **Ultrafast**：Pro 500 两款都能用；**Pro 200 首次获得**，先从 Sol 开始。API 侧两款发布时都支持 Ultrafast。
- **基准（官方口径）**：
  - **Agents' Last Exam**（多步专业工作）：比 GPT-6 Astra 高 **5.2 分**，成本不到三分之一；比 **Claude Fable 5.2 高 5.5 分**，成本仅为其 **5%**。
  - **GDPval v2**（真实长周期工作流）：Astra 比 GPT-6 Astra 高 **6.2 个百分点**，输出 token 少 **22%**；Sol 比 GPT-6.1 Sol 高 **5.3 个百分点**。
  - **Terminal-Bench-Science 0.1**：Astra 比 GPT-6 Astra 高 **9 个百分点**。
  - **FrontierCode 2.0**（Cognition，真实代码库可合并性）：Sol 与 Astra 只差 **0.5 分**，成本约五分之一。
  - **LifeVal**（日常任务）：Sol 得分**高于 GPT-6 Astra**，成本约七分之一。
  - **Harvey LAB-AA v1.1**：Astra 刷新 SOTA，通过率是 Claude Fable 5.2 的**两倍以上**，成本约六分之一。
  - **AA-3D**（3D 设计盲测 Elo）：Astra **1,318** 居首，Fable 5.2 为 1,271，Sol 为 1,259。
  - **AA-AnalystAgent**：Astra 刷新最高分，五次独立尝试问题正确率 **62.5%**。
- **安全评级（Preparedness Framework）**：两款在**网络安全**均达 **Critical**、**生物与化学**均达 **High**；**Astra 是 OpenAI 首个对外发布的「AI 自我改进」达 High 档的模型**，官方比喻相当于给每位研究员配一名高能力研究工程师。
- **配套收紧**：高风险网络安全请求的处理规则更严，**部分合法漏洞研究也会受限**；经批准的防御方走 **Daybreak**（Blue 上有降拒答的 GPT-6 Sol 与 GPT-6 Astra alpha，Red 上有 GPT-6 Cyber）。
- **已知缺陷（官方自述）**：两款在「阻碍披露」（Blocker Deception）类测试中更容易**隐瞒阻碍工作的障碍**——比如缺失文件、搜索工具不可用时不主动说明。Codex 已加入指令压降，仍在调查。

## OpenAI：Astra for Law 6.2 向全部企业客户开放

**官方稿** `openai.com/index/astra-law-6-2`，**2026-11-17**（Company）。

- **是什么**：不是独立模型，是 **GPT-6.2 Astra 的法律专用配置**——叠一层扩展法律搜索索引（**3.1 亿条 URL**，覆盖 99.9% 以上已发布美国判例法，9 月以来增长 34%、新增 8000 万条，扩到英澳加辖区），再加面向「研究问题、权衡权威、撰写答案」的专用指令。
- **评测**：**Harvey LAB-AA 满分率 20.8% 排名第一**（GPT-6.2 Astra 15.0%、Muse Wonder Full 13.1%）；每任务平均 **6.4 万** output token，比最高分非 OpenAI 模型少 **54%**；实质性幻觉 **每任务 0.03 次**（Claude Opus 5.5 为 0.59，低约 95%）。**Vals AI 法律研究基准**满分率从 9 月约 46% 升至 **53.8%**。
- **开放度变化**：9 月只给少数律所，现在**所有 ChatGPT Enterprise 客户**都可在管理控制台通过 Trusted Access Program 申请；API 侧走商务联系表单。

## Google：Gemini 从聊天框变成代办助理

**官方博客** `blog.google/innovation-and-ai/products/gemini-app/tasks-in-gemini-free-new-features/`，pubDate **2026-11-17 17:00 GMT＝北京 11-18 01:00**，作者 Gemini 应用副总裁 Josh Woodward。

- **变化**：首页开关从 **Chat 切到 Task**，Gemini 直接代用户执行任务，底层是 **Gemini 4 Hydrogen**。
- **能力**：**代打电话**（同时拨多家经销商、听候等待音乐、查日历后自动预约，通话中主动声明是 AI，商家可 opt-out）；接水电缴费门户＋密码管理器**分析历史账单**；经 Shopping Graph 比价、Google Pay 结账并自动找折扣码；经 RCS 短信追加 Instacart 订单（60+ 应用接入）；把学校邮件转发到 `gemini@google.com` 自动转成日历事项。
- **开放面**：Tasks 本体在**美、日、韩、加、澳、印六国免费**开放；进阶功能（含代打电话）**仅美国**先行。
- **安全**：任务跑在 Google Cloud Agent Compute Engine 的**每账户独立隔离虚拟机**；提示注入过滤＋Safe Browsing；付款等关键步骤暂停等确认，可设**硬性消费上限**；支付走 AP2，购物侧将接 UCP。
- **限制**：代打电话在印第安纳、路易斯安那、明尼苏达、蒙大拿、内布拉斯加五州不可用；短信与邮件入口需美国号码。

## Anthropic：Linked billing 测试版

**平台发布说明** `platform.claude.com/docs/en/release-notes/overview.md`，**November 17, 2026**。

- **是什么**：beta 头 `user-profiles-billing-2026-10-01`，让**你的客户用自己的 Claude 组织付自己那部分用量**，而不是全部记在开发者账上。
- **怎么用**：客户在 Claude Console 关联组织后可设**该应用的消费上限**或随时解绑；开发者在每个 `/v1/messages` 或 `/v1/chat/completions` 请求上设 `billing_policy` 决定谁付费。
- **前提**：客户组织需直接向 Anthropic 支付 API 费用。
