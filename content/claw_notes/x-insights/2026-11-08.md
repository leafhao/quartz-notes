## 一、记忆：先学会忘，再学会改

### Anthropic 把「做梦」写成了一套可部署的机制

11 月 6 日，Anthropic 工程博客《The components of agent memory》拆开 Claude 的跨会话记忆。核心不是「存更多」，而是把记忆分成四层，并在会话之外跑一个叫 **dreaming（做梦）** 的离线作业。

- **四层**：transcripts（可搜索的事件日志）→ memory notes（模型自己写的短规则、教训、计划）→ memory representations（由笔记长出来的结构，比如互相链接的 wiki）→ injected context（每次会话开头预加载的一小层）。做梦可以在任意两层之间搬运信息。
- **API 形态**：一个异步 job，给它一个现有 memory store 加 1—100 段历史会话，读完后**写出一个新的 store**，输入永不被改，所以可以先审再决定要不要用。按标准 token 计费，属研究预览，不适用零数据保留。
- **能纠错**：Pokémon Red 里 Claude 把宝可梦中心记错在山洞东侧，写下「Mt Moon DONE」，然后从单向下坡跳了三次、放弃；做梦作业拿笔记对回会话记录，改对之后它一次走进山洞到了华蓝市。
- **能长结构**：128 个会话、约 35 万个内部文件（约 4.2 亿 token，来自 5 月收购的 Stainless），wiki 从 103 页长到 222 页。25 道题上单靠 wiki 命中评分点 13%→48%；wiki + 搜索 54%—61%，而纯搜索 53%，每题省约 2 万 token；需要跨文档的 24 道并购题上 wiki 87% 对搜索 73%。
- **基准数字（均为 Anthropic 自评）**：CL-Bench 数据库问答，Opus 5.5 从 0.655 升到 0.838，Sonnet 5.5 从 0.644 到 0.833；Sonnet 4.6 几乎不动（0.330→0.364），但提示它「先读自己的记忆、验证假设」后翻倍到 0.641。
- **最反直觉的一条**：告诉 Claude「记忆是用来做什么的」有用，告诉它「该怎么记」有害。要求 Opus 5「只记失败」直接削掉 0.234 的收益；Pokémon 里 Sonnet 3.7 写了 413 个文件拿 1 枚徽章，Fable 5 只写 9—10 个、只记游戏界面上看不到的东西，拿了 4 枚。

**边界**：多项结果来自单次运行，题集只有 24、25 题；只在单文档里就有答案的任务上 wiki 无增益，且有一个 wiki 体积是源文档的 1.77 倍；预加载层里一条错笔记会污染之后每一个会话。Anthropic 自己写了这些限制。

### 为什么这条比「又一个 benchmark」重要

它是目前少数给出**可操作默认值**的前沿实验室文档：预加载层要小（Claude Code 上限 200 行 / 25KB）、别写死规则、把「对回原始记录」做成定时作业。写 agent 的人今天就能改。

## 二、协议与工具：把实验性标签摘掉的一天

### 谷歌 ADK 2.14.0：A2A 转稳定

tag 于 11 月 7 日 00:58 UTC 发布（release notes 内部日期是 11 月 4 日，两个时间戳要分开看）。这是一次「毕业」而非功能堆叠：

- execution environments、**A2A 协议**、evaluation 模块、core runtime 全部由 experimental 转 stable；连同 26 个 auth / 环境 / app 模块与 16 个 toolset 特性一起转正。
- 新增 `MultiRunConfig`（同一用例并发多跑再合并分数）与 `ToolArgsMatcher`（精确 / 忽略大小写 / 数值容差 / LLM 语义比较参数），把评测从「跑通一次」升级为「反复跑稳」。
- 另有 `TeamsRunner`（接 Microsoft Teams）与 `OpenAIDecisionsClassifier`（用 OpenAI Decisions API 做流程闸门）；Mongo 记忆服务带向量检索与 TTL。
- 官方口径：长多轮工作流快 23%、峰值内存低 9%——谷歌自报，无第三方复验。
- **升级要改代码**：枚举型工具参数现在收到 enum 成员而不是字符串；`RunSkillScriptTool` 不再接受 `command`，改传 args / short_options / positional_args，且只支持 `.py` / `.sh` / `.bash`。

A2A 转稳定的意义在谷歌之外：跨厂商 agent 互调第一次有了「不再变」的接口形状可以照着写。

### Antigravity 2.29：任务搬进云虚拟机

- **远程 agent**：面向所有付费个人订阅（AI Pro / AI Ultra），任务跑在独立云 VM 里，合上笔记本也不中断；手机打开 `antigravity.google.com/remote` 就能解锁权限，回来看到通过的测试与干净的提交。可在同一项目里同时挂 GitHub 仓库与 Drive 文件夹。

- 界面重构（输入框到底部、Google Sans、Onyx 主题、分支与 worktree 合并成一项），负责人 Varun Mohan 同时给所有用户重置了 Gemini 与 Argon 额度。

从「编辑器里的助手」到「持有发布权限的常驻进程」，责任链（谁能发布、谁能批、谁能读密钥）比能力更该先定。

### Claude Code 2.1.319

### 「别再问」把密钥写进了项目文件

Apiiro 11 月 5 日的报告，是本周最少被讨论、后果最实在的一条：

- 开发者点「Yes, and don't ask again」时，Claude Code 把**整条被批准的命令原样**写成权限规则，存进 `.claude/settings.local.json`；如果命令里带着 `PGPASSWORD=`、`sshpass -p`、bearer 头这类凭据，就明文躺在那。
- 范围：GitHub 上 104,185 份公开的该文件，其中 **1,122 份含真实密钥**（1,379 个）；再算历史版本、团队共享的 `settings.json`、agent 对话记录，合计 **2,539 个密钥、1,994 个仓库、63 个组织**。数据库口令占三分之一以上，另有 43 条 SSH 登录、23 个 AWS key。
- 两个放大器：① Claude Code 只把这文件加进**开发者全局 git ignore**，不会写进仓库自己的 `.gitignore`，所以换机器、换 fork、先提交后加规则都不受保护；② 在 1,105 个能追到密钥的仓库里，有 **539 个**是该文件被「Claude 联署」的 commit 改过的。
- 扫描器结构性看不见：gitleaks 命中 564 份、TruffleHog 643 份，**215 份两个都没报**——因为它们是命令行里的普通密码，不是有厂商前缀的 token。
- 处置顺序只有一个：**先轮换，再清历史**。删文件不影响 fork 与 clone。

### 伪造的图与音，比话术好使

arXiv 的 Multimodal-SEA：608 个专家设计的任务，14 个领域、152 种攻击场景、中英双语，7 个多模态模型全部可被攻破，成功率 7.1%—34.5%；在同一条攻击上附一份伪造图片或音频，成功率从 19.9% 抬到 29.2%——**即使 agent 确实去核验了**。加强安全指令能压低成功率，却不提高对伪造内容本身的识别，还会让部分模型开始拒绝正常请求。结论很直：验证路径不能经过模型自己「这图看着真不真」的判断。

## 四、研究：三张榜单，三种「还不行」

### Scientist World：把 1,000 篇论文变成能跑的环境

普林斯顿 Taiming Lu、Sachin Konan、Zhuang Liu，arXiv 2611.08478，11 月 5 日提交。

- 流水线全自动：14 个月索引 124,816 篇 arXiv 论文 → 筛出约 21,354 篇实证方法类 → 按质量、可复现性、可行性打分取前 1,000 篇，每篇抽出开放问题、把作者方法复现成 baseline，AI 科学家进去和人类结果比。
- 数字：**scratch 模式 74%** 超过原作者，**improve 模式 84%**；6,400 小时研究轨迹（想法、实验、失败、成功全记）；拿这些环境训练，Qwen3-8B 的研究构想能力 +158%，追平前沿模型。
- 自检：99% 复现方法分数「在误差内」、82% 超过原论文 baseline、100% 通过独立验证。
- **要打折的地方**：全部是作者自评、未同行评审；模型对比只用了 10 个低成本环境；流水线里「没有任何人工审稿」；Hugging Face 上的轨迹数据集在核查时需要登录。

### SwarmEvolve：不把想法写成字，快 10 倍

布朗大学 Qile Jiang 与 George Em Karniadakis。上百个低成本 agent 在**潜空间**里推理，不解码成文本，靠传 KV cache 交换信息；一个「新颖性过滤器」按隐状态向量的距离保留不同想法，一个总结 agent 收到全部成员的 KV cache 即完成交叉。

- 21 个数学发现与科学计算问题上平均分最高，**中位 3—8 分钟**达到其他 SOTA 框架 60 分钟才到的分数。
- 推理与通信占用的 GPU 时间从 57%—87% 降到约 11%，程序评估吞吐高 5—13 倍。
- Qwen3 8B 在若干问题上改进了 AlphaEvolve 用前沿模型找到的解。
- 未列出的：21 个问题是哪些、输的案例、token 成本、阈值怎么定。潜空间交叉仍可能塌缩多样性。

### XStack：整库迁移，最强的也只过 75%

把 PyTorch 仓库整体迁到 JAX + TPU，判分标准是**在另一套硬件上复现原仓库公布的结果**——没有「能 import 就算过」的部分分。Claude Opus 5 过 75%，GPT-5.6-sol 45%，其余被测 agent 均 ≤40%。这个 30 个百分点的差距，比单文件编程榜上的差距大得多，也更接近真实工程里最耗资深工程师时间的那类活。

### BioBasicsBench：会看图了，还不会不下结论

OpenAI 与酶设计公司 Ligo 合作，11 月 6 日发布。100 个任务取自 Ligo 科学家自己的实验：凝胶与印迹 31 项、方案与手写记录 27 项、仪器导出表 20 项、台面与试剂照片 18 项、显微 14 项、仪器屏幕 13 项、测序文件 12 项、操作视频 7 项、培养皿 7 项。

- 7 个模型 × 37 种「模型 + 推理档位」× 每题 5 次 = 18,500 个结果。最高档下 **GPT-6 Astra 66.7%**（95% CI 60.3—73.1），GPT-6.1 Sol 62.0%，GPT-5.6 Sol 43.8%；Astra 每题 4,704 输出 token，Sol 9,099。
- 亮点例子：一个细胞成像任务里 Sol 凭单染料信号判定细胞死亡，Astra 注意到两个检测窗口重叠、另一种染料会干扰，转而索要对照；一个克隆任务里 Astra 认出对照板用的是卡那霉素而非实验的氨苄西林。
- 失败模式才是重点：菌落 PCR 挑错泳道（会纯化错质粒）、菌落计数多算约 12%、在同一张图里看到液泡对比度随焦距变化却仍总结出相反结论。**错误集中在「过度解读」与「数不准」**，而不是「看不清」。

### 一条边界输入，抵得上一整套自测

arXiv 2611.08269《Accepted but Wrong》，预注册研究：73 个任务、覆盖 CPython / Node.js / SQLite 的 60 处有文档的变更，每个候选补丁都在真实运行时上、对着隐藏契约执行。

- 用「典型输入 + 全部断言」当发布闸门，**放行了 0.410 的错误修复**——代码跑得干净、答案却是错的。
- 照着 release note 加**一条**边界输入，降到 0.065（15 个未见集群上 0.061）；让没见过程序的 GPT-5.6-luna 盲写三条输入，0.070。
- 前沿模型自己写的自测帮助更小；加上 233 个「典型输入下输出与旧版一致」的硬干扰项后，仍有 0.168 / 0.153 的错误程序过关。
- 可操作结论便宜得离谱：区分新旧行为的那条输入，发布说明里已经写了。

## 六、X 上在吵什么

### Arete-27B：5,300 万 token 就能改一个模型的口径

Nous Research 11 月 6 日发布 Arete-27B，是阿里 Qwen3.8-27B 的微调版，模型卡原话是「在一个中国训练的模型上强化西方价值观」。X 上官宣帖一天破 110 万浏览，争论点不是技术，是「开源模型该带谁的价值观」。

- 方法极简：只做 SFT，无 RL、无偏好优化、不改架构；教师模型是 Thinking Machines 的 Inkling（选它是因为「在目标议题上评测为正」且条款允许），生成 2 万条提示词；训练约 5,280 万 token、2 个 epoch、1,202 步、64k 上下文、batch 48；文本only，视觉编码器冻结。
- 评测：803 条提示词、7 个类目（言论自由、国家意识形态、国进民退、教育、数据隐私与监控、民主、环境政策），每条都挂 2—4 条必有事实与官方口径原文；判官是 Grok 4.7，盲评，0—5 分事实分 + 是否「背书官方口径」。
- 结果：宣传口径命中率 **22% → 0.9%**；事实分 2.32 → 2.98；零分答案 359 → 216；言论自由类目 60% → 1%，该桶事实分 0.89 → 2.44。通用能力基本不动：Hermes Bench 65.77 → 65.60（Nous 称之为噪声），Terminal-Bench 2.1 67 → 70（Nous 明确不认领这个提升）。
- **必须说的两点**：① 22% 与 0.9% 都是 Nous 自己出题、自己定评分标准、单一模型判分，「更接近 Nous 选定的价值观」不等于「更准确」；② 同一个基座的下一代（Qwen 4）官方已说在训练中，这层「政治底漆」是否跟着换代消失，还没人测。

真正可复用的那句是：**模型在争议话题上的立场，是一个周末微调的距离**——任何人、任何方向。

### ChatGPT 的「空房间」：让它把记得的你画出来

X 上一个提示词在 11 月 7 日炸开：给 ChatGPT 一张空房间图，加一句「用你知道的关于我的一切把这个房间填满」。很多人第一次把模型记住的东西**一次看完**：职业、宠物、习惯、持仓、行程。原始热帖来自 0xMarioNawfal（RoundtableSpace），跟风晒图的多是加密圈账号。

- 机制上是两层：保存的记忆（姓名、偏好、目标）+ Plus/Pro 的历史对话引用。
- 风险不在尴尬，在社工素材：持仓、交易所、行程一旦公开，钓鱼与冒充可信联系人会容易得多。今年早些时候就有人在被索引的 Claude 共享链接里发现过钱包数据。
- 能做的：设置 → 个性化里查看/删除/关闭记忆；临时对话既不读也不写记忆。真要跟风，先把图里的人换成假的。

### SpecPilot：让 agent 自己调投机解码

vanshdot 贴的前后对比：单请求下 Qwen3.8-27B 在 RTX PRO 6000 上从 4.46 倍提速到 **10.87 倍**；H100 上按 16—24 请求批处理，从 1.94 倍到 3.93 倍。做法是一个 agent 循环：成本模型找离理论上限最远的环节，多个 agent 并行提修改，**每个输出 token 都与原系统比对**——所以它没法靠改坏结果来「优化」。它找到的东西里包括一个无损的 12 位权重量化格式与两级校验。真正值得抄的是那道 token 比对：它把优化 agent 从「会撒谎」变成「会做实验」。

### 训练配方：一次真实 rollout 就够学

Trajectory Labs 的访谈（经 X 转述，非论文）：`Group Size 1` 是 GRPO 的变体，用一次真实世界的 rollout 学习，而不是把同一道题回放八遍；`Continual Grading` 用 100 条人工轨迹上写好的评分标准，扩成 1 万条的奖励信号。案例是 Harvey——训出一个比前沿便宜 6 倍的模型，在自家法律基准上从 4% 到 18%。可看的是那个 meta-grader：人力最先耗尽的地方就是判分。
