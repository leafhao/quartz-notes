# X/Twitter AI 热点｜2026-10-14

> 这一天的主线是**「能力在开放、围栏在收紧、钱在找新出口」**。谷歌在同一周里把 Gemini 4 Argon 全面开放给付费用户与 API（首发价只有竞品五分之一），而 400 余位科学家同一天发公开信，要求把具备网安能力的模型**物理断网**、成立国际机构登记围栏失效事件。资本侧另一条线更安静但更长：**倒闭创业公司的代码与聊天记录正在被 AI 实验室当作训练数据买走**，Character.ai 则直接申请了第 11 章破产。

### 1. Gemini 4 Argon 全面开放：1M 输出上限、首发价 $2/$10，独立评测比谷歌自己的表更保守

**10 月 13 日，谷歌把 Gemini 4 Argon 从 Fairwind 计划的限量开放转为正式可用（GA）。** 可用面包括**付费 Gemini API、Google AI Studio、Antigravity（个人需 Ultra 档）、符合条件的 Gemini Enterprise 订阅、Gemini 应用与搜索 AI 模式（Pro/Ultra 订阅者）**；**模型不在 API 免费层**。发布者是 **Koray Kavukcuoglu、Demis Hassabis、Sundar Pichai、Logan Kilpatrick、Varun Mohan** 等官方账号。

- **定价是这次最锋利的部分**：**首发价 $2/$10 每百万输入/输出 token，缓存输入 $0.10，有效期至 11 月 30 日；12 月 1 日起翻倍到 $4/$20/$0.20**。**Batch/Flex 减半、Priority 为 $3.60/$18**。**输出价含思考 token**。The Verge 的读法是「约为 GPT-6 Astra 与 Fable 5.1（$10/$50）的五分之一」，但同时提醒**每任务实际 token 消耗不同**。
- **规格**：**1,048,576 token 上下文，输入、思考与输出共用同一额度**；**默认回复上限 65,536，后台长任务可达约 100 万（减去输入）**；**接受文本、图像、视频、音频、PDF，只输出文本**；**支持函数调用、代码执行、搜索接地、结构化输出与 computer use 预览**；**不支持图像/音频生成**；**三档思考强度（默认 medium）**；**≥4,096 token 的提示自动缓存**；**temperature / top-p 被忽略**。
- **谷歌自报的分数**：**DeepSWE v1.1 77.9%（Opus 5.5 74.2%、GPT-6 Astra 74.1%）、Zapier AutomationBench 51.3%（42.5% / 41.4%）、LVBench 91.7%、CWE-bench v1 68% 并列第一、Harvey 法律 19.6%**。**安全侧：编码评测中「抄捷径」比例降至 2%；Gray Swan 间接提示注入 15 次自适应尝试成功率 0.7%；外部生物红队只能解锁不到 1% 的测试子任务**。

### 2. 面壁智能 MiniCPM-V 4.7：35B-A3B 的 MoE 在 iPhone 上用 3GB 内存跑到 13+ token/s

**10 月 13 日，面壁智能（OpenBMB）发布 MiniCPM-V 4.7，含 35B-A3B 与 1B 两个规格，Apache 2.0 开源、权重已在 Hugging Face。** 官方称 **35B-A3B 是首个能在手机端流畅运行且能力无损的开源 MoE 模型**：**总参数 350 亿、每 token 激活约 30 亿，iPhone 17 Pro Max 上仅约 3GB 内存实现 13+ token/s 解码**；**iPad Pro M4 实测超 15 token/s**。

- **「3GB」指的是一次推理的工作集，不是 35B 权重的下载体积**：**按十进制粗算，35B 参数以两字节存储约需 70GB，理想四比特约 17.5GB**。**官方在 11 英寸 iPad Pro M4（16GB）上给出的分阶段读数是：未优化的存储加载基线 2.97 token/s，加入调度与加载改动后 9.81，再加量化 14.92，最后配 DSpark 投机采样 17.39——整体约为基线的 5.86 倍，其中调度单独贡献约 3.30 倍。**
- **三项技术是并用的**：**前瞻专家调度（LES）用跨层路由预测预取下一层可能用到的专家，但计算仍走模型原本的 token 级路由，预测失败只是等待而非跳过专家**；**细粒度逐层量化压缩专家权重的存储与访存**；**DSpark 投机采样接入端侧解码**。**官方发布的手机与平板演示视频均为厂商提供，尚无独立复现。**
- **能力宣称的可核部分很有限**：**官方称 Instruct 模式下以更短的推理时间取得比 Qwen3.6 35B-A3B 更高的综合得分**，**但信源截图中只有图表、没有底层分数**；**1B 版本（实际约 1.3B）称在综合得分与推理效率上均领先 Qwen3.5 0.8B**。**模型卡未披露上下文窗口、训练数据截止、许可细则之外的托管定价与数值基准。**
- **部署面是这次真正的可用性**：**支持 iOS、Android、鸿蒙**；**首日适配瑞芯微、后摩、Intel、AMD、Arm 等芯片平台**；**推理框架支持 SGLang、vLLM、llama.cpp、Ollama**；**微调支持 SWIFT 与 LLaMA-Factory**；**量化提供 GGUF、BNB、AWQ、GPTQ 并新增 FP8**；**Transformers 需 ≥5.18.0，视频输入在 TorchCodec/CUDA 上有兼容问题（官方提供 PyAV 替代）**。**同步开源 Self-Replay Fine-Tuning（SRFT）微调方案。**
- **系列累计**：**MiniCPM 系列（含文本、视觉、语音）全球累计下载量已突破 6000 万次。**

## 二、研究与工程

### 6. Anthropic 用五个月把 monorepo 的 git 换成自研 Scion：日合并量从 2500 冲到 3 万

**10 月 13 日，Anthropic 发布工程博客《重新设计源代码管理》，披露用五个月把内部 monorepo 从 git 迁到自研系统 Scion。** 触发原因是**代码生成不再是瓶颈，写代码之外的基础设施成了瓶颈**：**日均合并代码变更从 2026 年 5 月的约 2500 笔升至 9 月的 3 万笔以上（十倍以上）**；**monorepo 主分支历史接近 100GB，压缩工作副本超过 25GB**；**CI 每天需要约 2500 万次代码检出（不含开发者环境、agent 沙箱与研究任务）**。

- **设计假设换了**：**git 假定客户端离线、且需要完整仓库副本；Scion 假定客户端（几乎全是 agent 与任务）始终在线，由服务端回答历史与 blame、创建提交、执行合并与 rebase**；**客户端只保留有界本地对象缓存**。**仓库数据分布式存储，连服务端都不持有完整物化副本，也没有 packfile 等价物，因此不需要仓库维护，也没有 refs 需要移动（除主 ref 与发布分支）。**
- **工作单元换成「changeset」**：**写在预写日志里，只记录相对第一个父提交的变更文件列表，加上指向对象存储中压缩内容的内容寻址指针**；**提交、合并、rebase 全部发生在服务端，所以「push」这个概念不存在**。**成本必须随改动大小而非仓库大小增长。**
- **检出按需**：**协议以稀疏检出与虚拟化检出为中心**；**许多读写负载可以直接走 API，完全跳过检出**。**缺失的对象请求经计算节点缓存 → 区域缓存 → 权威服务端，命中率超过 99%。**
- **报出的收益与边界**：**CPU 与内存占用约为此前 git 镜像基础设施的 1/200**；**CI 与研究检出从分钟级降到秒级，快 100 倍**；**CI 获得约 25% 的 CPU 容量增量**。**同时 Anthropic 明确说明 Scion 不是 git 的通用替代品**，**多数仓库用 git 仍然合适**；**项目由 7 人团队、在 Claude 协助下完成，并配套了代码审查界面 Antique，以及代码搜索、IAM、规模化落地与合并工具链。** **文末提到可能就生态协作与 GitHub、GitLab 及开源社区接触。**

### 7. Ben Recht 拆解 OpenAI「更快的傅里叶变换」：常数约 10^100，属于银河算法

**10 月 12 日，UC 伯克利教授 Ben Recht 在 argmin 博客发文，称 OpenAI 数学仓库中那份「更快的傅里叶变换」是「与其说是突破，不如说是一次恶意的利用」。** 核心论证是：**该算法在 big-O 意义上确实比 1965 年的 Cooley-Tukey 更快，但隐藏常数估计在 10^100 量级**——**即便 n 取到 10^100，经典 FFT 仍快 10^99 倍**。

- **他点的是模型假设而非证明本身**：**该算法假定「精确复数算术」，即复数的存储与乘法可以任意精度、且每次相乘只算一步操作**；**所需相乘的复数模长随 n 超多项式增长，若按比特存储，内存需求实际上随输入长度指数增长**。**Recht 的原话是「我们没有能做这件事的计算机」。**
- **他要反驳的是「理论跑偏」这件事**：**Richard Lipton 与 Ken Regan 把隐藏常数天文数字级的算法称为「银河算法」**；**1973 年 Jacques Morgenstern 已证明系数有界时傅里叶变换不可能快于 ½ n log n，Nir Ailon 后来指出突破 n log n 会带来严重数值不稳定，而理论计算机科学界忽略了这两个结果。** **Recht 的判断是：理论的定义离真实的计算机已经太远，「开放问题」变成了学术地位游戏。**
- **同批手稿里还有一条类似结果**：**矩阵乘法的 O(n^2.25)，常数同样不可估**。**Recht 坦承自己没有通读论文，而是把它喂回聊天机器人做信息检索后得出上述事实**——**他称之为「我们现在做数学研究的方式」。**
