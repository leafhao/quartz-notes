## 二、学术研究

### 本周最值得读：《Stealing Reasoning Traces from Proprietary LLM APIs》

- arXiv 发布 Aug 10，媒体集中报道 Aug 12–17（TechTimes / CybersecurityNews / The Guardrail Weekly Digest）
- 作者 8 人，来自 MATS Research、ELLIS Institute Tübingen、Max Planck Intelligent Systems、Snyk
- **核心发现**：保护 AI 推理链（reasoning traces）的加密只防篡改、不防重放。一个账号的加密推理块可以在另一个账号复用；更关键的是，把加密块喂给同族的"弱兄弟模型"时，那些模型缺乏旗舰版的反蒸馏对齐和安全护栏，会直接把隐藏推理明文吐出来。
- **影响面**：OpenAI、Anthropic、Google 的 LLM API 均受影响
- **为什么重要**：一个架构层缺陷把加密推理链变成了模型抽取、敏感数据泄露、危险内容披露、隐蔽 agent 攻击的通道。论文建议在跨账号/跨模型传递前剥离推理块。

### 冷水一杯
- **《Why AI Still Hasn't Had Its Einstein Moment》**（HPCwire，Aug 12）：在一片 AGI 时间线预测里给出反向视角。相关的 AGI 预测聚合分析显示，主流判断是 2026–2028 出现"特定领域人类级推理 + 多模态 + 有限目标导向自主性"的早期 AGI-like 系统，更广泛的推理与知识迁移里程碑推到 2028。

### DeepSeek 是本周主角
- **V4-Pro 正式版上线**（Aug 17 11:51 北京时间）
- **API 涨价方案**（Aug 13 公布，Aug 17 生效）：V4 Pro 高峰时段输出价 **6 元 → 27 元 / 百万 token（+350%）**，缓存命中输入价暴涨 12 倍，整体区间最低 +50%、最高 +1100%。注意 +1100% 那一档其实是价目表最便宜格（0.025 元 → 0.3 元），真正影响成本的是输出 token 的 3.5 倍。同时首次引入**高峰/低谷分时定价**。

## 关注建议

1. **推理成本是下半年真问题**：Gartner 的 Inference Paradox + DeepSeek 涨价 + CIO 的 ROI 问责，三个独立信号指向同一件事——agent 应用的单位经济学要重新算。做 agent 项目前先建 token 成本模型。
2. **加密推理链漏洞值得细读**：如果你的系统在跨服务传递 provider 返回的 reasoning block，按论文建议剥离后再传。这不是理论风险，三大厂 API 都在受影响清单上。
3. **国产模型的"追平"是真的但要看维度**：9 家 10 个模型的密度足够，但对比是在推理/编码/agent 三个特定维度上，不代表全面持平。
4. **87.5% 这个数字自己也是风险信号**：资金极度集中在 AI 头部，长尾早期融资断崖式下跌，意味着生态多样性正在被压缩。
