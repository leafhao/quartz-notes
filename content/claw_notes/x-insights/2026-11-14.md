# X 热点洞察｜2026-11-14

## 一句话

Agent 今天同时拿到三样东西：钱包、红队权限、和一份工厂的报价单。ChatGPT Wallet 让它在用户刷脸后直接付钱；Daybreak 一边派 agent 去打自己的应用、一边派 agent 补漏洞；Claude 的 17 项技能开始读 ERP 出报价。同一天 OpenAI 把独立机器人团队解散了——理由是通用模型已经能直接开机器。

---

## 一、Agent 开始花钱：ChatGPT Wallet（11-13）

### 官方口径

- **OpenAI 11-13 发布 ChatGPT Wallet**，与 **American Express、Mastercard、Visa** 三方合作，首批通过 **dots**（OpenAI 的个人 AI 代理）向**美国 ChatGPT Pro 订阅用户**开放，需年满 18 岁、持符合条件的美国发行信用卡。
- **核心机制是令牌化**：用户绑一次卡，每次购买前看清单、总额、所选卡，用 **Face ID 或指纹**确认；确认后由支付网络下发**支付令牌**（带卡号、安全码、有效期），真实卡信息**既不告诉商家也不给 agent**。
- **权益保留**：原有卡的积分与符合条件的争议保护不变；用户仍直接与商家交易，商家保留客户关系、定价、履约、退货与客服的控制权。
- **不给商家改造压力**：官方明确「现有结账页面无需为 Wallet 做专门集成」，但建议商家认 **Web Bot Auth** 签名请求、让风控识别 agent 交易、并给 MCP 插件留 `continue_url`。
- **路线图**：下一步允许用户预设**消费上限、品类、时间窗**后整批预授权，配合生物识别与授权记录。
- **规模背景**：官方称每周 **12 亿人**用 ChatGPT，多数人已经在里面查商品、比价格、做决定——现在补的是「最后一步付款」。

### 该怎么读

- 三个卡组织**同时**站台，意味着这不是一家公司的实验，是卡组织对「agent 作为持卡人代理」的正式承认。
- 但官方自己承认会有人被误拦：部分站点会**无意中阻断** agent 购买，所以配套发了 Commerce Partner Playbook。
- **每笔都要刷脸**，这一版其实离「全自动代购」还很远；真正的看点是「预授权 + 上限」那一版。

## 二、Agent 去打自己的应用，再去补漏洞：Daybreak 两条产品线（11-12）

### Red Team

- **多 agent 协同**：一个 agent 统筹评估，几个查源码与应用上下文推演攻击路径，最后有 reviewer agent 复核结果。Nancy Wang 的说法是「**自动化连续扫描规模的超人渗透测试**」。
- **可复测**：确认漏洞、打完补丁后，Red Team 再跑一次看是否还能打通；应用每次变更都能重跑。
- **也能验真**：把代码扫描器、赏金计划、外部研究者报来的洞**复现一遍**，让安全团队按证据排优先级——这解决的是「误报太多」。
- 客户自选可访问的应用与端点，测试跑在**隔离环境**里，另有 Guardian 审查机制。目前**早期访问 + 排队**。

### Defense Factory

- 接上仓库与既有安全工具的发现（**Wiz、Snyk、Endor Labs** 等），agent 追漏洞成因、定位代码、出补丁，产出「**可直接合并的 PR + 证明补丁有效的测试**」。
- 工程师可以先用 **Codex** 补上下文、改补丁，agent 继续在后台跑；可配成每次提交扫描或定时检查。
- **补丁不自动上线**，必须人审。通过 Codex 里的 Daybreak 插件提供，属研究预览。

### 底层模型与边界

- 驱动模型是 **GPT-6 Cyber**（11-05 发布），官方称 **ExploitGym 48.5%**，上一代 GPT-5.6 Cyber 是 32.1%；按 Preparedness Framework 评为 **Critical**，是第一个在网络安全风险上到这一档的模型。
- 官方自报的战绩：在 Firefox 里找到 **81 个此前未知的高危漏洞**（Mozilla 已在 Firefox 159 安全公告里致谢）、为 **948 个 Linux 内核漏洞**做出可用利用，其中 **588 个此前未知**、**304 项已披露给内核维护者**。
- 同周还宣布 **Daybreak for Frontline Defenders**：**10 亿美元**补贴额度，给保护关键基础设施的机构；Daybreak Defense Network 已有 **35+** 合作方产品。
- **价格未公布**，Red Team 早期访问、Defense Factory 走销售。Brockman 的话是「企业能有多安全，取决于它用哪个前沿模型来防守、用得有多好」。
- **必须写清**：以上全都是 OpenAI 自报数字，没有第三方复现；同时这也是把此前「自己的 agent 逃出测试环境去乱打」的事故，转成可售卖的产品。

## 三、DeepSeek 把 App 拆成零件（11-13）

- **11-13 公告**：在原有 API 里开启对应参数，即可获得联网搜索、深度思考搜索、文件输入、阅读链接、安全校验等 App 内能力；工具调用与上下文拼接**由服务端自动完成**。
- **具体能力**（均在 V4.1-Flash / `deepseek-flash` 上，Messages、Responses、Chat Completions 三类接口）：
  - `deepseek_web_search`：非思考模式下自动搜网页或图片并**附引用**；思考模式下可在多步推理中自主搜索与读链接。
  - 文件输入：PDF、Office、图片，做纯文本提取或图文混排解析后拼进上下文。
  - `deepseek_read_url`：自动识别消息里的链接并抓取。
  - 安全校验参数：基础风控审核输入输出，命中风险返回拒答标识；对外提供服务**必须开启**，并承担内容安全审核、大模型登记、AI 标识义务。
- **OCR / ASR / TTS / Search / Fetch 可作独立接口**单独或组合调用。
- **定价（token 之外另收工具费）**：文字/图片搜索 **5 元/千次**、网页抓取 **5 元/千次**、文字识别 **1.5 元/千页**、语音识别 **0.39 元/小时**（限时五折）、语音合成 **1.5 元/万字符**（限时五折）。
- **官方开源了一个前端 Demo**（`deepseek-ai/chat-demo`），可导入历史对话，界面基本等同网页端——「1:1 复刻 DeepSeek App」这句话是有实物支撑的。
- **意义不在多了几个功能**：把搜索、解析、语音、风控一次性塞进同一套 key，切换供应商的隐性成本就上去了。这是拿开发者的迁移壁垒换调用量。

## 四、Anthropic：路演数字与准入收紧（11-13）

### 招股材料里的那个 $74

- 路演站上线，**11-10 启动**，**11-18 定价、11-19 以 ANT 在纳斯达克挂牌**。招股书里原先空着的发行价，现在填的是「**假定 74.00 美元**」——这是**用来算募资额**的假定价，不是承诺成交价。
- 结构：**8.25 亿股 A 类**，按 74 美元算净募资约 **846 亿美元**；含承销商额外 1.2375 亿股的选择权则约 **937 亿美元**（净额高于 825M×74，是因为并入了 N 类股的同步私募配售）。
- 发行加配售后总股本约 **130.87 亿股**，按 74 美元约 **9,680 亿美元**——明显低于 10 月市场传的 1.5—2 万亿。差价不是「下调」，是 74 这个数本来只为算钱。
- 十家配售方合计 **260 亿美元**：谷歌行使 2026 年协议下的选择权、英伟达约 **100 亿**为最大单笔，另有 AMD、博通、美光、微软、台积电。
- 认购：11-10 首日约 **2 倍**，11-12 收市约 **6 倍**（单一信源）；彭博口径按区间上限算，IPO + 配售合计 **904 亿美元**，超过 SpaceX 6 月的 862 亿。
- 卖方给的收入预期：2026 年 **520—530 亿**、2027 年 **1,350—1,370 亿**，银行内部按 **2028 年 2,700—2,800 亿**建模。

### 财报里没人放进视频的那一行

- 季度序列：Q1'25 **4 亿** → Q4'25 **20 亿** → Q1'26 **47 亿** → Q2'26 **116 亿** → Q3'26 **170 亿**（同比 12.1 倍）。
- 算力与基础设施支出：**9 亿 → 29 亿 → 34 亿 → 56 亿 → 99 亿**。
- **每 1 美元算力换来的收入**：0.40 → 0.57 → 0.68 → 0.69 → **1.40 → 2.08 → 1.72**。
- **这是这条序列第一次环比下滑**。Q3 净亏 **233 亿**（含大额非经营项），调整后利润率约 15%。
- 所以「算力效率比 Q1'25 提升 4 倍」这个宣传口径没错，但它把最难看的那一格藏在了脚注里。

### 史上最严的地区准入（11-12 生效）

- 新版《支持地区政策》把资格绑在三件事上：**用户实际所在地**、**企业注册地或总部所在地**、**企业是否被不支持地区的主体直接或间接多数持股或实际控制**。
- 三类不具备资格：人在不支持地区（即便雇主在支持地区）；企业注册或总部在不支持地区（即便员工在支持地区）；企业被不支持地区主体多数持股或控制（无论注册地、员工在哪）。
- 覆盖 Claude.ai、Claude Code、Cowork、API、开发者平台，以及**经云厂商、授权经销商提供的 Claude 模型**——第三方渠道不再是绕道。
- 判据也从「看 IP」转向**时区、语言、并发行为**等多维回溯。处罚梯度：警告、限流、临时冻结、永久封禁账号与 API key。
- 招股文件自己披露：前九个月收入里 **5%—7%** 来自此后会被认定不合规的客户。**政策时点与路演时点重合，不是巧合。**
- Anthropic 的说法是「大部分是对既有规则的澄清」；多数股权限制去年就有，这次是把三类禁令固化并加上穿透核查。

### Claude for Manufacturing：17 项技能，四套系统，不碰机器（11-12）

- 面向 **Team 与 Enterprise**，管理员从插件目录安装；**17 项技能**覆盖报价、质量、维护、采购、设计、生产六块，例如：读客户需求、列出缺的信息、比对历史同类工单后出报价草稿；对不合格品做原因排序与 8D 草稿；按传感器数据、维修记录、照片和手册诊断停机；对备用供应商询价并比价。
- **四个连接器**：Autodesk Fusion（设计）、Infor（**只读**，查采购单与库存）、Microsoft 365（流程文件、供应商邮件）、Oracle NetSuite（价格、库存、工序、工单成本）。
- **明确不做的**：不操作设备、不写系统记录（system of record 仍是唯一真相）。要改数据得用 Infor 另一个产品，且每次改动需人批准。
- **人在环上是硬约束**：每份产出都要责任人签字，报价由销售负责人批、纠正措施由质量经理签。所有数字都能链回原始文档。
- 官方引的调查：**79%** 的制造商仍在互不连通的系统之间手工录数。
- 11-17 有一场技术 webinar。物理侧另有一个 **Model Hardware Standard** 研究预览，目标是让 agent 通过标准驱动接机械臂、显微镜这类设备。

## 五、OpenAI 把机器人团队拆了（11-13）

- **《财富》11-13 报道并经 OpenAI 确认**：解散独立机器人团队。机器人研究并入主研究团队，向首席研究官 **Mark Chen** 汇报；应用机器人与硬件团队并入 **Greg Brockman** 的 Applied 部门。未披露人数。
- **官方给的理由**：年初认为该沿着 Sora 那条路走（视频生成必须先理解一点物理），但此后 **GPT-6 Astra** 这类通用前沿模型表现出**直接驱动**机器人的能力，于是改了路线。发言人称这是「加速而非退出」，人形机器人**2027 年首次公开演示**不变。
- **一个细节说明它有多突然**：OpenAI 已经报了本周奥斯汀 **CoRL** 的展位，会议 App 与展位图上都标着，记者到 **208 号**时人走台空，连 logo 都没有。
- **支撑数据来自英伟达 10-14 的一项研究**：在 **RoboLab-120** 仿真抓放基准上，把 GPT-6 Astra 放进 Codex 会话当控制器、不做任何机器人专项训练，成功率 **74.8%**，榜上最好的专用机器人模型 Lakeside 是 **51.0%**。
- **代价也写在同一份研究里**：最好那套配置每次尝试约 **36.40 美元** token，最简版单次模型调用 **18.56 秒**——对真机来说太慢。
- **第三次转向**：2020 年关过一次（Zaremba 说机器人数据太少），2024 年重建并与 Figure 合作（2025 年 2 月结束），这是第二次解散。
- CMU 的 Guanya Shi 的解读是：OpenAI 不再把机器人当「特殊问题」，而是通用智能的下游应用。MIT 的 Russ Tedrake 提醒机器人公司仍有优势——真机在工厂里积累的部署经验与数据，实验室拿不到。
- 这条对机器人创业公司是**估值逻辑上的坏消息**：它们融资的前提是「机器人需要自己的大脑」。

## 六、开源侧：图、语音、本地推理三件事（11-12 至 11-13）

### MiniMax H3-Image（11-13）

- 从视频模型 **H3** 去掉音频分支而来，**331 亿参数稠密 DiT、50 层**，文本编码器沿用 H3 的 **Qwen3-VL**，图像 VAE 约 5.8 亿参数；蒸馏到 **6 步采样、无需 CFG**。
- **原生 4K 直出**：4096×4096（约 1,678 万像素）**最快 10 秒**；覆盖 400 万—2,000 万像素，含 5472×3072、6272×2688 等画幅。官方称速度为市面主流的 **5 倍**。
- 一个模型同时干三件事：文生图、参考图生成、图像编辑；**最多 16 张参考图**。
- 定价约为同档主流工具的 **50%—70%**；发布首周 16MP 以上五折。首日已适配华为昇腾、NVIDIA、AMD、英特尔等十余家芯片。
- 社区热度集中在「CAD 拆解」这类任务——丢一张参考图，直接出可标注的爆炸视图。

### Salesforce SOV-Transcribe-1（11-12）

- **首个开放权重的「语音增强语言模型」**，Apache 2.0。架构是 **Whisper large-v3 音频编码器 + 投影层 + Gemma 4 26B A4B 混合专家解码器**，总参数 **26.6B**、每 token 激活 **4.6B**（均含音频编码器）。
- **AA-WER 2.28%**，Artificial Analysis 非流式语音转写榜**开源第一、总榜第七**（44 个模型里）；对照 Voxtral Small 2.77%、Nemotron 3.5 Transcribe 2.81%。
- **这个 2.28% 是三段加权**：AgentTalk 50%（1.79%）、VoxPopuli 25%（1.50%）、Earnings22 25%（**4.06%**）——**最难、也最像企业真实音频的那一段，恰是它最弱的一面**。
- 指令可控：默认逐字稿，也能按指令去口头语、改数字写法；**上下文偏置**给关键词，关键词 F1 从 71.9 提到 96.8。真实财报电话这种最易幻觉的音频上 WER **25.69%**，低于它列出的所有开源对照。
- **硬限制**：只做**非流式**（不能做实时字幕）、**只覆盖 7 种欧洲语言**（英法德西意葡荷，**无中文**）、检查点约 **53GB** 需自备 GPU、技术报告尚未发布。
- 定位是「主权 AI」——面向不能把录音送到别人服务器上的政府与受监管企业。

### llama.cpp 与 ggml 到 v1.0.0（11-13）

- 项目 3.5 年，第一次给核心库 **libllama** 与 **libggml** 打正式版本号，宣告公共 API 从此是**受管理的契约**。
- 规则：改 `./include` 里的公共 C API 就跳 **major**；向后兼容的新特性、后端更新、模型支持、新增 API 是 **minor**；无 API 变更的修复是 **patch**。API 与 ABI 不兼容都会以 major 体现。
- 现状：支持 **150+** 种架构变体、全部主流投机解码方法；八个分发渠道（预编译、Docker、Debian、Homebrew、conda-forge、MacPorts、Winget、XCFramework）。
- **这次发布代码几乎没变，变的是「以后怎么变」的承诺。** 对把它嵌进产品的人来说，能锁版本、能按 minor 排升级、把 major 当评审闸门——这才是 1.0 的意义。

## 七、研究：哥德尔笔记、视觉编码器、自主性基准

### Claude 读出哥德尔 1,009 页手稿（11-13《卫报》）

- 赫尔辛基大学 **Jan von Plato** 自 2017 年主持项目，整理哥德尔 1940 年代初的 **16 本工作笔记、1,009 页**，多数用**已废弃的德文 Gabelsberger 速记**。他说全世界能读这种速记的**只剩六个人**，此前进度约**每周一页**（ERC 资助 250 万欧元）。
- 今年 8 月在法国一场 AI 定理证明会议上有人建议他用 Claude；9 月他把自己做的转写、六本旧著与二手文献喂进去，**几天内**得到一份 **650 页**的解读。他的原话是「我目瞪口呆」——笔记里不只有几十处**七十、八十年代才被重新发现**的结果，还有 **14 个从未被继续做下去**的逻辑主题。
- **663 条**定理候选，用 **Coq** 逐条验：约 **400 条**按原样通过、约 **200 条**需修补陈述或补假设、约 **50 条**被判定为错。
- **最有历史分量的一条**：1966 年 Paul Cohen 因证明连续统假设与选择公理独立拿了菲尔兹奖，哥德尔当时声称自己 40 年代就证过选择公理那条，但拿不出证明。von Plato 问 Claude 笔记里有没有，答案是「**是的，几乎**」——只错了一个定义，而正确版本他两年前就写过。重建后的证明**通过了 Coq**。
- **必须保留的分歧**：Notre Dame 的 Joel David Hamkins 说，数学有效性与历史归属是两件事，「多少属于 Claude、多少属于哥德尔，是历史学家的工作」。而且这条重建**还没经过外部逻辑学家评议**。
- 这是一次**规模**上的胜利，不是证明能力上的：人能读但记不住一千页的关联，模型能。产出仍要**逐页人工核对**，von Plato 自己说的。
- 下一步是哥德尔的物理与宇宙学笔记。发布数小时后登上 Hacker News 榜首。

### 视觉编码器到底要不要（11-13，NYU + Meta FAIR）

- 论文《Unbundling Multimodal Vision Encoding》，作者含 Ellis Brown、Chris Hoang、Saining Xie、Luke Zettlemoyer、Lucas Beyer、Mengye Ren 等 12 人。
- 做法：把「视觉编码器」拆成三个可独立的选择——**要不要上游预训练**、**要不要视觉专用参数**、**这部分参数放不放在融合之前**；然后在相同数据、相同总算力下**从零训练 200 多个模型**做对照，骨干从 0.6B 到 6.4B，评测 16 个 Cambrian VQA 基准 + 12 个语言基准。
- **结论一**：视觉先验**不是必需的**。与语言模型一起从零训的编码器，和预训练编码器打平，还省掉一个独立训练阶段。把编码器预训练加码，ImageNet 线性探针从 80.4% 涨到 84.4%，**VQA 一点没动**。
- **结论二**：真正重要的是**视觉专用容量**。完全去掉编码器的模型在视觉理解上始终落后——1.7B 规模下平均 VQA **44.4% vs 39.0%**，差 **5.4 分**；把骨干按编码器的 0.4B 参数等量加宽、加深或两者都做，**都补不回来**，作者说大约要多花 **3 倍算力**才追得上。
- **结论三**：这部分容量**不必放在融合之前**。把只在视觉上生效的 FFN 分支与 Q/K/V/O 投影放进骨干**前 8 层（共 28 层）**，VQA 与前置编码器相当，还能**降低首 token 延迟**；0.4B 视觉参数规模下快约 **13%**。
- **作者自己划的边界**：实验里的编码器与多模态训练用的是**同一批图像**，所以「不能排除用额外数据训出来的公开编码器有增益」；骨干只做到稠密 6.4B，**MoE 与高分辨率富文本场景留待后续**。

### Deepnote 测「该不该出手」（11-13）

- 新基准 **Agent Initiative Benchmark**，测的是**主动性**：什么时候该主动做，什么时候该闭嘴。
- 构造：一家有 **6 年**完整历史的虚构公司（财务模型、客户关系、逾期账款等），把 **12 个前沿模型**放进它的 Slack，面对 **50 个**真实工作情境；agent 可访问 **11 个**服务的记录。
- 设计上最反直觉的一条：**正确地保持沉默也能拿满分**——这与「有求必应」的产品直觉正相反。
- 网传的成本对照（GPT-6 Luna 每任务约 0.007 美元/6.38 分，Fable 5.1 约 3.02 美元/7.50 分）来自社区转述图表，**不是官方口径**，只能当参考。

## 八、产品与生态：一堆小东西，都指向同一件事

- **Bland Tofu-1**（11-13）：全双工语音到语音，主打**嘈杂环境下的高风险电话**——能分辨说话人、分离人声与背景噪声、随时可被打断、边说边处理任务。演示里来电者、AI、背景声全部由它生成。现仅向少量企业开放研究预览，团队称**明年 1 月全面开放但不开源**，12 月初先发一个小蒸馏版；对安全仍有「相当严肃的顾虑」。
- **Expo Simulators**（11-12）：编程 agent 改完代码后，在**云端 iOS/安卓模拟器**跑一遍，**带回操作录像**再请开发者过目，本地不用配环境。发布帖浏览超 220 万。它说明的新瓶颈是：代码产出变多之后，**验证**成了卡点。
- **Lightning Labs pi402**（11-12）：给编程 agent **Pi** 的扩展，遇到 HTTP 402 就用内置钱包走**比特币闪电网络**即时付款，不需账号、API key、信用卡；可设单次与每日上限。示例计价约每百万 token 0.79/1.57 美元。目前**无官方托管端点**，要自己部署。
- **Edge0-145B / 120B**（11-12）：开放权重，145B 在 Terminal-Bench 2.1 自报 **86.5%**，峰值内存约 **29GB**，Mac 上解码超 75 token/s。**全部自报、无第三方复现**；16GB 内存机器仍跑不动，模型文件数十 GB。
- **World Labs Atlas**（11-12）：李飞飞团队把世界模型向所有人开放，配套应用与 API，可从创意构建 3D 世界并导出**关键帧、视频片段、3D 高斯泼溅文件**——目标是可继续编辑探索的 3D 场景，不只是一段视频。
- **Fish Agent**（11-12）：无代码语音 agent 平台，用文字描述搭出能接打电话的 agent，由全双工模型 **Fish Live 3** 驱动，**部署中位时间 32 秒**。
- **Devin Teams**（11-12）：团队所有人可用新版 Devin Desktop，**不另收座位费**；每人 Free 模式有 **2 个并发免费会话**，由自研 **SWE-2** 驱动；新增 SSO 与三档用量上限。网传 SWE-2 基于中国开源模型后训练——**官方公告未提，不能当事实**。
- **Perplexity Teammates 上 Mac**（11-13）：面向 Max 用户，Teammates 可独立工作也可互相协作，承担 QA、客服、调研、增长营销，在桌面端操作而不必留在浏览器里。
- **Google DeepMind 开放 PARDIG 与 SatWeave**（11-13）：**WeatherNext 3** 的两套基础数据集，含降水与地球静止卫星影像。训练数据通常比模型结构更难拿到，开放它降低的是复现门槛。
- **腾讯混元 Hy Realtime**（11-13）：实时语音模型，能还原口齿含糊、话说半截、中途改口的意图，长对话多轮指令稳定；新增 agentic 工具调用，统一决策联网搜索、工具调用与回答；与 TME 灵音 AI 合作加了**唱歌**能力，可按歌手、曲风、语种、年代点歌。已在元宝语音通话、腾讯客服上线，近期开放 API。

## 十、X 上的讨论：Dwarkesh 改口，评论区不服

- **Dwarkesh Patel 11-13 发长文《席卷数学的雪崩正冲向 AI 研发》**，同时发了一支 44 分钟视频，标题直接是「我以为超级智能还有十年，不再这么想了」。他明确说这是**过去三个月**改的判断。
- **论证靠类比**：数学是**可验证**领域，所以三年里从「四位加法都做不准」到 IMO 金牌、开放 Erdős 问题、「88 小时解一道千禧年大奖难题」；AI 研发同样有大量可验证环节（预训练看 held-out loss、后训练看算力与数据效率、推理看 GPU 利用率与延迟），所以会自动得像数学一样。
- **三个数字支撑**：METR 在 Anthropic 驻场三个月，认为其在**界定清晰任务**上的进步速度是一年前的两倍，且大部分可归因于用 AI 做研发；OpenAI 最重度的 10% 研究员，内部编码 agent 日花费从初夏 **1,000 美元**涨到 8 月底 **7,000+ 美元**；Anthropic 称 8 月 Claude「主导」了其 **26%** 以上的 AI 研发工作，2 月还不到 1%。
- **时间表**：自动化研究员达到顶尖人类水平，**中位 2028 年**；25% 概率晚于 **2032 年**；2027 年也不排除。此后各领域专家级 AI 在 **2030 年前**，最早明年。他给「纯软件奇点」与「一次性火花（一年顶三到六年）」**各 50%**。
- **支点在最容易被忽略的那个数**：前沿实验室算法进步约 **80%** 来自最顶尖的 **50 人**。所以不需要自动化整个实验室，只需要替代或放大这 50 人。
- **三处必须打折的地方**：
  - 「Claude 主导 26% 研发」的脚注写着：**lead** 指在高层指令下完成大部分任务、**仍有人监督**，**完全自主的占比仍是 0%**。
  - 实验算力那段，**视频与文章数字不一致**：口播是「10,000 个 agent、每天一次 GPT-3 规模训练」，文章写「数千个」，脚注算出来是每天 7,660 次或每四天一次——**差四倍**，而且依赖 OpenAI 连续两年算力再翻两番。
  - 用 Amdahl 定律算一遍就知道：AI 把一半工作快 50 倍，人只快约 2 倍；90% 是 8.5 倍；要到 99% 才有 30 倍。**整个预测活在那段没人有数据的 90%—100% 里。**
- **Hacker News 上的反驳值得一并读**：有人说概率框架没有依据、数学类比是误导；有人说很多公司 AI 编码量很大但产品与利润没起色，内部提效未必外推；有人追问不可验证工作的基准怎么定，RSI 的闭环在这里是断的。
- **这是个人预测与论证，不是研究结论**，前提条件写得比结论更清楚。
