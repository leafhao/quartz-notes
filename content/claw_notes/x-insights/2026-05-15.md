## 💬 X/Twitter 上的代表性讨论

- **Sandeep Jain**（5/13）：刷屏帖《Building an AI Agent in 2026 is no longer just about picking an LLM》——生产级 Agent 需要 8 层系统组件，模型只是其中之一。强化了**"Agent = 系统工程"**的共识。
  - 链接：[X / sjsandeep_jain](https://x.com/sjsandeep_jain/status/2054410921582231570)

- **行业讨论焦点**：
  - **Context rot**：Databricks 等研究反复被引用——LLM 即使没到百万 token 上限，**32K tokens 后正确率明显下滑**，"中间迷失"现象在长上下文任务里被放大。
  - **Reflective agents / 测试时推理**：HuggingFace 趋势论文与 ICLR 2026 集中讨论 RL 让模型"会思考、会用工具"，KAIROS 基准显示当前 LLM 在协作 + 对抗场景下容易"被同伴说服"放弃正确答案。
  - **Memory 工作坊**：ICLR 2026 MemAgents Workshop 把 Agent 长期记忆/灾难性遗忘/检索效率列为下一阶段主题。

## 🎯 最值得关注的观点

1. **企业市场风向变了**：Anthropic 用 Claude Code 撕开企业开发者入口，OpenAI 不再是默认选择——这是过去 12 个月最值得记住的格局变化。
2. **模型在版本内进化**：AISI 对 Mythos 的复测显示同一版本能力会自动提升，传统"模型卡片 + 一次性评测"的合规框架失效。
3. **Agent 系统工程化**：选模型只是 1/8 工作，工具层、记忆层、协调层、评估层正成为新的护城河。
4. **资本头部化极端**：Q1 三笔交易吃掉 67% 融资额，中尾部 AI 创业公司将面临更尖锐的"巨头or死"窘境。
5. **欧盟监管成新战场**：网络安全模型访问权成为 OpenAI 与 Anthropic 不同策略的分水岭。
