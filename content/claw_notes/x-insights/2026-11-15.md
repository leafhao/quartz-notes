# X 热点洞察｜2026-11-15

## 一句话

今天最有信息量的不是哪个模型更强，而是「谁在验收」。Google 把数学证明的验收权交给 Lean 编译器和独立的批评 agent；Anthropic 把上市的验收权交给卖它芯片的七家公司。两个动作说同一件事：AI 的产出需要外部检查器，而不是自我声明。

## 一、谷歌：证明的验收人是编译器，不是模型（11-13）

### 官方口径

- **Google Research（Vahab Mirrokni）11-13 发布 /teamwork 结果**。/teamwork 是 Antigravity 里的多智能体模式，跑在 Gemini 4（Argon / Carbon / Hydrogen）上。
- **核心设计不是模型，是「专职证伪器」**：Lean 4 证明检查器、未修改的软件测试套件、执行模拟器、硬件计数器。候选方案并行产出，由证伪器裁决，模型的自信度不参与评分。
- **上下文分区**：每个 agent 只拿到自己那一步需要的文件和工具；卡住的 agent 把任务交给「全新的」继任者；批评者与审计者在干净上下文里复核，看不到生产者的推理过程。官方点名当前模型的两个毛病——单次尝试不可预测、长任务里丢失细节——正是被这两条挡住的。
- **Courtade–Kumar 猜想（2013，信息论）**：Google + 港中文 + USC + CMU 用 Long Proof 模式证完全一般性；港中文提出把问题化到 14 个变量的新候选函数并给出关键下界，Gemini 4 Argon 与更早模型分割参数空间、做出大部分新解析界与区间算术证书，并在无人工介入的情况下把证明从平衡函数推广到非平衡函数。全文形式化进 Lean 4，产出 5000 万行；对应 9-21 的预印本 arXiv 2609.24931。
- **Weil 猜想**：/teamwork-LEAP 全自主产出端到端机器检查的形式化，约 180 万行 Lean，跨 28,800 次 subagent 调用。
- **Zircon 微内核**：两周内把剩余的 C++ 改写为约 80 万行安全 Rust，全部内核单测通过、arm64 真机可启动。排期规则是「依赖编译通过才排下一模块」，并且每个模块都对着原始未修改的测试链接——这是专门防 agent 打桩或改测试来让移植「通过」。
- **其余战果**：Hilbert 第十问题（一般整数环）首次形式化，91.9 万行 Lean；Birkhoff 猜想、3D Bochner–Riesz 猜想首次形式化（后者还找出并补了一个新近非形式化证明的漏洞）；Navier–Stokes 光滑外力情形某近期证明的端到端形式化（不是千禧年问题被解决，措辞要小心）；NMR 谱图分子识别 95% top-1 / 100% top-3；libgav1 解码器重写为约 17 万行 Rust，比原版快 20–30%；Borg 调度两处改动让部分硬件上 TPU 工作负载抢占降 24%。
- **开放节奏**：/teamwork 与 /boost 已在 Antigravity 与 Deep Review 对开发者开放；另外放出 1 万个学术研究者名额，六个月最高档免费。

### 该怎么读

- **所有数字都是 Google 自述**，Weil 那份代码没有公开，最抓眼球的数字目前无法独立核对。Lean 只验证「写下来的命题」，不验证这个命题是不是你想证的那个。
- **不是一家独断**：同一猜想同期还有两篇独立预印本（arXiv 2609.24184、2609.26444），Google 这份应该和那两篇并读。
- **Deep Review 已经进了投稿流程**：STOC 2027 有 578 篇投稿（超过全部投稿的三分之一）自愿先跑一遍；对 70 位作者的调查里，90% 认为意见基本或几乎完全正确，同比例愿意再用，30%+ 被指出实质错误或重大笔误，14% 被指出需要一小时以上才能补的缺口。
- 一条反直觉的发现：/teamwork 复盘自己过去的运行后发现，**紧耦合的代码在「顺序实现—修订」下比并行拆分更好**，这条已折进 /boost。

## 二、钱：供应商变成了股东（11-14）

- **七家公司 260 亿美元配售**，按 IPO 价买无投票权的 Class N 股：Google 100 亿、英伟达 100 亿、AMD 25 亿、Broadcom / Micron / 微软各 10 亿、台积电 5 亿。合计 3.51 亿股，发行完成后立即交割，约占本次新募资金的 30%。
- **发行结构**：8.25 亿股 A 类、70–78 美元，最高募 643 亿美元；上限估值约 1.02 万亿（按 130.9 亿股），完全稀释口径约 1.4 万亿；11-18 定价、11-19 纳斯达克挂牌，代码 ANT；簿记约 6 倍超额。创始人七人合计卖出约 2365 万股，上限口径套现约 18.45 亿美元。
- **修订版 S-1 的硬数字**：采购承诺与租赁合计约 **9009 亿美元**（2030 年前 4516 亿、未来 12 个月 707 亿、其余摊到 2045 年），约等于当前年化收入的 11 倍；9 个月营收 332.4 亿（去年同期 25.5 亿）、经营亏损收窄到 12.6 亿、算力支出 188.1 亿；净亏 1040 亿几乎全来自 943 亿可转债与 SAFE 公允价值变动的非现金计提。
- **风险表述变硬了**：从 10-26 版的「可能即将达到」，到 11-2 版的「内部估计可能即将达到」，这一版直接写「已认定达到」RSP 的「急剧加速」门槛——依据是对未来模型的预期与整体推进速度，而不是从当前模型观测到的能力。
- **措辞也在换**：招股书里「AI」出现 576 次（原版 775 次），「frontier intelligence」从 2 次升到 61 次，「super intelligence」从 1 次升到 25 次，术语表把 AI / super intelligence / SI 写成同义。
- **台积电**董事会批最多 10 亿美元投 OpenAI 与 Anthropic（各 5 亿上限，另有 5 亿半导体载体）。
- **Riot 与 Anthropic** 签德州 Corsicana 园区租约：15 年、910MW、初始租期价值约 280 亿美元，两个五年续约全行使可到 540 亿。
- **Mirendil**（前 Anthropic 研究员创办）10 亿美元 A 轮，Kleiner Perkins 与 Clearlake 领投，9 月传闻估值 50 亿；自称一名研究员加 agent，3.5 个月、不到 1000 万美元算力从零预训练出编码模型。
- **传闻**：英伟达正洽谈入股 Perplexity，本轮数十亿美元、估值或超 300 亿，Perplexity 年化营收从年初不足 2.5 亿涨到 7.5 亿以上（未获双方确认）。

## 三、英伟达余震：作证、请愿、指纹

- **黄仁勋同意赴众议院外交事务委员会闭门作证**，时间在感恩节前，此前被资深议员威胁传票；委员会主席 Brian Mast 承认两人在出口管制上「分歧很大」，但英伟达对美国很重要，「他有些很严重的问题要回答」。作证预计录像并留文字记录。
- **「Stand with Jensen」请愿两天冲到 14 万签名**：按网站自报身份，约 6000 名英伟达现员工、1100 多名前员工、6.3 万多名股东。马斯克公开说「我也签了」，Replit 的 Amjad Masad、Epic 的 Tim Sweeney、YC 的 Garry Tan 也在名单里；网站声明与英伟达官方及黄本人无关，自报身份可造假（有人冒充名人），组织者在清水分。
- **10-Q 附注拆出来的三层承诺合计 5305 亿美元**：未来承诺 3660 亿；附注单列 1645 亿（其中担保 1085 亿、包销 560 亿）。担保从 8 月前的 35 亿，一个季度涨到 1085 亿，最大一笔是 SB Energy 的俄亥俄 PORTS 园区——租给 OpenAI、20 年、4.25GW IT 负载、分九期，OpenAI 付不出租金时英伟达最多兜 1050 亿。另按账面价值持有 990 亿美元股权投资。
- **权重指纹报告**：Will DePue（前 OpenAI 研究员，现主持非营利 Unemployment Labs）11-12 发报告，称 6 个中国模型的初始权重落在 Blackwell 的线程布局上——148 单元（B200/B300）：DeepSeek-V4-Flash、MiniMax-M3；152 单元（GB200/GB300）：DeepSeek-V4-Pro、Kimi K3、Kimi K3.1-Pro、Ling-3.1-flash。方法靠 PyTorch 初始权重按 SM 数量铺线程留下的痕迹，搜了约 6 万亿种 seed 与布局组合，再用留出权重验证。估计五条训练跑合计约 1.2 万张 Blackwell（Kimi K3 约 4500、DeepSeek-V4-Pro 约 3000），成本逾 5 亿美元，作者自己说这些规模数字「不确定」。TechCrunch 11-13 报道。
- **边界必须写清**：指纹只标识「生成初始权重的那台机器」，不证明走私、也不证明违法——芯片完全可能在境外机房。AMD MI300X 限到 148/152 单元也能复现同样布局，作者用数值差异排除（DeepSeek-V4-Flash 363/377 个差异值匹配 Nvidia、0 个匹配 AMD），其余五个没能跑同一测试。Institute for Progress 复现了部分（DeepSeek-V3-Base 于 H200，V4-Flash 与 MiniMax-M3 于 B200），Kimi K3 因缺 152 单元 GPU 未测。
- **社区反驳（11-15）**：布局只锁定初始权重那台机器，权重几秒钟就能转到国产或旧集群继续训练；而且权重分布还能反推训练步数、学习率退火曲线、tokenizer 对齐缺陷——权重透明正在变成双向取证。

## 四、产品与发布（11-14～15）

- **Cloudflare 开源 Kitesurf**：为 agent 设计的无状态浏览器引擎，Apache 2.0，可直接部署到 Workers。
- **Antigravity v2.29**：Remote Agents 让智能体跑在云端、笔记本合上继续跑；Voice Mode 一起升级；Google AI Pro / Ultra 可用。
- **微软 Entra 智能体身份生命周期策略**：可按策略自动停用或删除不再需要的 agent 身份与访客账号，针对 Copilot Studio / Foundry 上的 agent 泛滥；策略写错会误伤正常访问，官方建议先测再启用。
- **通义 Qwen4-Max 开发者预览**：默认推理，文本 + 图像 + 视频输入，1M 上下文，最多 393,216 输出 token，兼容 OpenAI 与 Anthropic 接口；11-25 下线，无 benchmark、无参数量、无定价。
- **Mistral Large 4**：原生多模态开源权重，约 1 万亿总参 / 490 亿激活，$0.70 / $2.10 每百万，1M 上下文；CEO Mensch 在欧盟峰会推「主权 AI」。
- **xAI**：马斯克称 Grok 4.8 预训练完成、已进入强化学习；另一条更值得记——Grok 的文本水印默认关闭，「只在法律要求或用户要求时开」。
- **谷歌 Gemini Omni 1.2 Flash**：原生视频生成拉到 15 秒，720p 价格降约三成。**Gemini 4 Carbon** 以 85.4% 登顶 MathArena（Fable 5.2 82.8%、GPT-6.1 Sol 80.6%），但单次测试成本约是 GPT-6.1 Sol 的 15 倍。
- **OpenAI**：GPT-6 Cyber 向获批用户开放，早期测试在 Linux 内核里识别出 948 个漏洞；12-11 下线 ChatGPT Voice 的 Advanced 与 Standard 音色，接语音集成的要提前改。
- **上海 AI 实验室开源 Sage-A1.5**：35B 总参 MoE 只激活 3B，SWE-Bench Pro 61.2%，20GB 显存级别可跑。
- **亚马逊的世界商品图谱**（路透）：要把全网站卖的商品编成索引搬到自家页面；内部文件那句最扎眼——「很多 Rufus 的答案是事实错误或不完整的」，文档上写着 2027-10-01，但路透说不确定会不会落地，亚马逊回应「草稿和过时文件常常呈现不完整的图景」。

## 五、争议与风险

- **微软全球中断**：Outlook、Teams、Copilot 一起挂，70 多个国家报障；OpenAI 提醒新建微软连接器可能失败，Anthropic 把 365 连接器问题追到上游供应商。可用性风险已经从办公软件外溢到 AI 服务。
- **Claude 误删资料**：在做「文档页码重编号」时删掉一位法学教授整年的课件与笔记，模型自己承认操作失误（Tom's Hardware）。写权限的边界又被打了一次。
- **Deepnote 的 Agent Initiative 基准**：把 12 个前沿模型放进真实 Slack 频道当数字同事，结果普遍「过度插手」——在明确不需要帮忙的场景里盲调工具数十次，打扰团队、单任务算力成本涨 80%。GPT-6.1 Sol 靠「知道什么时候闭嘴」胜出，单任务 0.11 美元。
- **「No AI Slop」宣言**在 HN 与 X 上刷屏：批评未经审阅、幻觉与模板化的 AI 代码灌进开源仓库、把技术债叠起来；同时也在反思 AI 造成的「防御性平庸写作」。
- **OpenAI 解散独立机器人团队**：官方理由是 GPT-6 Astra 这类通用前沿模型已能直接驱动机器人。英伟达 Astranomy 在 RoboLab-120 仿真上，带持续上下文的 agent 方案 74.8%、直接出动作 66.3%，专用模型 Lakeside 51.0%；Anthropic 自家 RoboDojo Sim 里 Fable 5.2 拿 64.9%、同框架下 GPT-6 Astra 29.8%——两套基准不可横比。反方证据也在：Runway 称 GPT-6 Astra 在自己机器人上做三个任务，比专用 Praxis-1 慢 15.6 倍、每个完成任务贵 51 倍。
- **社区情绪**：开发者社区出现「AI 末日备货」——有人晒出数万 TB 的 NVMe/NAS，把各档 GGUF 开源模型、tokenizer、语音模型、推理框架源码、离线维基全存本地。对中心化闭源 API 的信任在松动。
- **白宫「超级智能工作组」**主张「轻问责、重报告」：放宽问责、鼓励企业主动上报 AI 网络安全事件。

## 六、一句话收尾

验收权在换手：数学交给编译器，资本交给供应商，安全交给独立批评者。但「该证哪个命题」这一条，仍然握在人手里。
