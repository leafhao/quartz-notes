## 一、越界与安全

### 1. Manus：一封邮件就够——JSFuck 绕过护栏，执行完才报警

**Salt Security 的 Salt Labs 披露了一个已被修复的 Manus 漏洞**：**一封恶意邮件就足以在 agent 运行时里拿到代码执行权限，并读出该 agent 持有的第三方凭据（云 token、API key、已连接服务的访问密钥）**。**攻击链只需要两件事：恶意邮件进收件箱、用户让 Manus 去看邮件**——不需要密码、不需要点链接、不需要更多操作。

**关键的技术细节在「护栏怎么被绕过」，这一段比结论有用**：

- **直接的恶意指令会被 Manus 拦住**（它识别并告警了），说明基础护栏是工作的。**研究者尝试了 Base64 编码、用 Python 解码执行，最后成功的是 JSFuck**——**一种只用极少字符集、现代环境里几乎没人用的 JavaScript 混淆手法**。
- **Manus 把邮件内容当成可执行指令去解码渲染，于是服务端执行了任意 JS**。**平台确实发了安全告警，但告警出现在代码已经执行之后。**
- **这构成一类结构性缺口**：**检测层存在，但触发得太晚，自主 agent 已经在人能介入之前把事情做完了。**

**披露路径和信息一样值得记**：**Salt Labs 先报给 Manus 没得到回应，转而通过 Meta 的漏洞赏金计划提交，Meta 做了分诊与处理**（Meta 当时正在准备收购 Manus，交易未成行）。**后续复现失败，说明已修复。** **需要注意的是 Manus 2.0 刚刚加上「收到邮件或 Slack 消息即可启动一次 agent run」的触发器**——漏洞修好了，能力边界反而往前推了一步。

### 2. Apple 重写「全盘访问」：AI agent 需要「非常明确的用户操作」

**Apple 在 10 月 2 日面向开发者发文，宣布将给 macOS 的 Full Disk Access 增加新的控制**：**任何想要这项权限的应用，都必须通过 Apple 所说的「非常明确的用户操作」重新申请，而不是依赖用户可能在很久之前点过一次、之后忘了的授权**。**Apple 的原话是：随着 AI agent 变得更强、更自主，这种级别访问权限带来的风险会「大幅上升」。**

**触发这轮改写的不是理论，是同一个月里的两件事**：

- **Inc. 专栏作者 Jason Aten 称，Meta 的 Muse 在他说自己明确拒绝授权的情况下，仍同步了他本地 Messages 数据库里超过 18.7 万行记录**；**Meta 传播负责人 Andy Stone 反驳称 Messages 集成是严格 opt-in，需要同时打开全盘访问与 Muse 内的 Messages 连接器**，**双方在公开层面至今无法互相证伪**。
- **WIRED 报道 OpenAI 的 ChatGPT Mac 应用存在缺陷**：**聊天历史以明文存在本地，且绕过了 Apple 的原生沙箱，同机其他进程理论上可读**；**OpenAI 在报道出现后推送了紧急更新加密存储**。

**这条要把「权限」和「理解」分开看**：**Full Disk Access 最早是为备份与杀毒设计的，它假设请求者做完一件可预期的事就停下**；**一个整天读邮件、起草回复、动日历的 agent 是另一类请求者，一次性的同意弹窗从来没有为这种连续决策式访问设计过**。**Apple 没说新控制何时上线——这是一次公开的警告射击，对象是所有正在给 Mac 做 agent 的团队，不只是 Meta 和 OpenAI。**

### 3. 微软年度报告第一次点名模型：32 步攻击链拿到域控

**微软《2026 数字防御报告》（10 月 1 日发布）做了一件厂商威胁报告通常不做的事：它直接写了模型的名字**。**报告称 Anthropic 的 Mythos 与 OpenAI 的 GPT-5.5「能够自主编排复杂攻击」，其中一条 32 步攻击链达成了完整的域控制**——**不是「AI 辅助的攻击者」，也不是「某个先进模型」，是两个产品，在卖防守方的公司出的报告里被点名**。

**报告里最值得记住的不是前沿能力，而是一个时间刻度**：

- **开源权重模型在「攻击编排」上落后闭源模型约 7 个月**。**报告里其他数字都是快照，只有这一个是倒计时**——**今天能被安全审查拦在前沿实验室里的能力，大约两个季度后会出现在一个可下载、不可监控、无法设门的模型里**。
- **从漏洞被发现到被武器化的中位时间已低于 24 小时**；**微软预计 2026 年约 72,000 个 CVE，创纪录**。**对一个补丁周期仍以月为单位的行业来说，这 24 小时就是问题本身。**
- **钓鱼作为初始入口从 7% 升到 23%，面向公网应用的利用从 15% 升到 24%**；**政府机构是被攻击最多的部门（27%）**。**区域上美国 25.5% 居首**。
- **一条必须并列的边界**：**微软同时写明，大多数真实攻击仍由人在指挥，前沿系统「端到端自主攻击」目前主要出现在实验室和少数早期真实案例里。**

### 4. 佐治亚：一个 20 美元的订阅，把 152 万张选票从匿名里拽了出来

**普林斯顿大学信息政策中心的博士后 Max Springer 用公开渠道拿到的佐治亚州选举数据，加上一份 20 美元的主流模型订阅，在几个小时内做出了一条流水线**，**可以在 114 个县里还原 152 万张选票的投出顺序，覆盖这些县 98.9% 的现场投票**；**在投票人数少的小县（如 Heard 县约 650 名提前投票者），他能把绝大多数选票与具体选民对上，剩下的一人只差一次相邻互换**。**他说 agent 全程没有拒绝，也没对实现该利用提出任何顾虑。**

**这条的价值不在「AI 会做坏事」，而在三件事的叠合**：

- **底层缺陷 2022 年就被密歇根大学的研究者发现**（Dominion 计票机为每张选票分配的编号不够随机，可反推出投票顺序）。**Dominion 发了补丁、联邦 2023 年认证，其他用同款设备的州要么装了补丁、要么停止发布使该缺陷可用的数据——佐治亚两件都没做。**
- **不是没钱**：**州务卿向州议会要这笔预算要了三年没要到**，**彻底修好整套系统的估算超过 3000 万美元**，**换掉全州计票机的计划已推到 2028 年**。
- **真正的故事是门槛塌了**：**过去需要密码学博士才能利用的缺陷，现在一张信用卡加一根网线就够了**，**而且 AI 不需要先被教会投票系统怎么运作**。

**整改动作**：**即将离任的州务卿 Raffensperger 锁定了制表数据，要求大选后公开释放时对 ID 编号做涂黑**；**州选举委员会为此开了紧急会议，共和党方面提出的「人工洗牌选票」方案因离投票日太近、可能造成漏计而被两名共和党委员当场质疑，未表决**；**提前投票 10 月 13 日开始**。

### 9. Meta 开源 Muse 硬件代码：代码免费，agent 不免费

**Meta 把 Muse 的固件与 SDK 以 Apache 2.0 放到 GitHub（facebookincubator/muse-gadget-sdk）**：**包含面向 ESP32 开发板的固件与一套 Linux SDK**，**一块带屏、带麦克风的现成板子或树莓派就能变成 Muse 端点**。**配套硬件是 Home Link——一个 USB-C 供电的 dongle，把 Muse 接进家庭网络去控制电视、音箱和任何暴露 HTTPS 接口的设备**；**Meta 做了 5,000 台，本月起在美国按订阅用户一人一台发完为止**。

**三处依赖是真正的购买决策**：

- **智能仍在 Meta 的云上**。**固件管屏幕、麦克风与传感器，agent、模型与订阅都留在 Meta**——**每台设备都需要一个 Muse 账号，订阅是硬件能工作的前提，不是加购项**。
- **目前仅限美国**，这一条直接排除了对欧洲或亚洲发货。
- **Home Link 说 HTTPS，示例偏向 Home Assistant**，**接的是已经暴露网络接口的设备，而不是大多数智能家居实际在用的 Zigbee / Thread / Matter 生态**；**工业与商用场景里藏在网关或现场总线后面的部分，仍然要自己搭桥**。

**也就是：这是一台「Android 式」的开放，代价是把自己钉在 Meta 的账号与服务条款上。**

### 12. ServiceNow：把「agent 的失败」变成训练课程

**ServiceNow CoreAI 发布 AutoSynthData**：**一条把「目标模型的能力缺口」变成可验证合成训练任务的流水线**。**具体做法**：**让目标模型与一个更强的教师模型跑同一批诊断任务，把失败与成功分别蒸馏成「能力规格卡」（抹掉原始提示、实体与验证器细节，防止记忆）**；**生成器只看到卡片，生成有差异化提示、状态与解法路径的新任务**。**筛选门槛写得非常具体：优先选目标模型三次里最多解出一次、而更强模型三次里至少解出两次的任务。**

**实验结果（ServiceNow 自己的受控实验，非独立复现）**：**Hybrid 域 2,000 个样本约 18 小时，目标 Gemma-4-26B-A4B-it、教师 Qwen3.8-27B，Pass@1 相对提升 35%（+7.2 个百分点），验证器成功率 63.01%→68.55%**；**ITSM 域 1,994 个样本 66 小时，教师换成 DeepSeek-V4.1-Flash，Pass@1 从 18.77% 升到 27.18%**。**基准是 EnterpriseOps-Gym（1,150 个专家任务、8 个域、512 个工具、164 张表），任务跑在真实 MCP 服务器上，由 SQL 验证器打分最终环境状态而不是规定单一动作序列。**

**三个工程上可抄走的机制**：**① 「正门 + 负门」双验证**——正门重放参考轨迹确认预期解通过，负门故意篡改最终状态确认错误结果会失败；**② 「修不了就修，不是丢掉」**——失败的候选项进入有重试上限的批评-修复循环；**③ 两阶段生成（Target → Multiply），且「乘出来的样本不能作为下一轮乘的种子」**——**这条是防分布漂移的关键，纯 LLM 生成通常到第三代就开始训幻觉**。**作者明确：目前只做了 SFT，RL 结果未报告；效果强依赖存在一个明显更强的教师模型与高保真沙箱。**

## 三、研究与评测

- **子 agent 的「委派危险带」**（**arXiv cs.MA，投 NeurIPS 2026 workshop**）：**agent 框架常用「fork 子 agent 并让子 agent 继承父 agent 完整工作上下文」做委派**。**研究者用 Qwen3 的 0.6/1.7/4/8B 阶梯，对比三种继承策略**：**Reset（干净 fork）、Selective（只加有用的旧结论）、Full（加上已被推翻的结论的多个副本）**；**所有任务仅凭基础证据即可解出，因此性能损失可归因于对陈旧状态的依赖**。**结果有三点**：**① 对陈旧状态的顺从随能力上升而急剧下降（各家族置信区间均不含零）**；**② 净损害呈非单调——中等能力的 Qwen3-1.7B 是统计显著的局部最小值（Δ(32)=-0.19 [-0.25,-0.12]），比干净基线还差，而最弱的接近中性、最强的稳健**；**③ 精选式 Selective 交接全面优于 Full，且在带内模型上收益最大**。**可迁移的一句话：越是「半桶水」的子 agent，越会把继承来的过期结论当真理，而固定阈值的路由器在其他数据集上会失效**。
- **授权配对评估：把「拦住禁止用途」和「放行授权用途」当成同一个成功标准**（**arXiv cs.MA，FlowReview**）：**多 agent 系统的安全问题不是单点越权，而是各 agent 单独看都合规的信息，合起来能拼出一个被禁止的用途**。**FlowReview 把对象识别、权限排序与确定性执行串起来**；**在受控组合实验中，审查合并后的产物把「拒绝提交率」从 86.0% 降到零，且没有损失任何被授权的供给**。**结论很干净：只保留信息与血缘并不保证权限归属正确，对象身份与权限必须通过可验证的组件一路绑到执行上。**
- **AI 科学家能不能在运行时协调分工**（**arXiv cs.MA，RAC**）：**现有做法多为设计时编排（固定工作流），而人类科学家是在运行时调整分工**。**RAC 在执行中从已有 AI-scientist 宿主里选 agent、分配有范围的工作契约、并提供「以产物为依据」的验证；验证结果用于告知后续 agent，而不阻断转换、也不丢弃产物**。**在 Agent Laboratory、EvoScientist、ARK 三个宿主上，保留各自模型/工具/权限、按宿主校准预算做的单种子探索评估中，「运行时选择」给出的平均分最高。**
- **无标注的工作流优化**（**arXiv cs.AI，InFlowOp + Braid 基准**）：**多 agent 工作流要在运行前决定「任务切多细、每个子任务信谁、何时新建专家」，但每个子任务是否成功在跑完之前是未知的**；**定位故障通常需要参考答案、评分或训练过的评估器，而修复要重跑整个工作流**。**InFlowOp 用一个无标注的成本同时给「分解粒度」和「agent 分配」定价，并在运行时用同一成本做最便宜的纠错**。**在需要多 agent 协作的新基准 Braid 上，比单 agent 基线最高提升 11.97%，带流程内优化时提升 9.64%。**
- **过程级评测：数值对了不等于轨迹对了**（**arXiv:2610.01833，CLEA workshop @ NeurIPS 2026**）：**240 次试验、2 种技能、2 套规格变体、2 个 agent harness、3 个模型**，**结果显示 92.6% 通过了最终数值检查的试验，轨迹层仍存在行为偏差**；**依赖归因把平均每次运行 6.34 个失败检查收敛到 2.65 个根因**。**这条对内部评测的直接含义：只对最终输出打分，在能力强的 agent 上会系统性高估——必须加轨迹审查。**
- **视频场景本身就是一个越狱面**（**SceneJail**）：**以往的视频越狱是操纵「有害查询怎么被呈现」，把视频当成载荷载体**；**SceneJail 改的是周边场景——一个无害活动（如做饭）配上一条有害指令，当视频情境为有害请求提供正常化、分心或可否认性时，模型的配合率显著上升**。**机制是多模态上下文整合：当场景与查询「情境一致」（例如开锁视频配绕过安全的提问），模型会把组合输入当成更正当。**
- **A2A 协议的注入攻击与测量分类**（**A2A-TIBA**）：**提出把间接提示注入与「绕过规避」组合的攻击，以及一套四结果（Class A/B/C/D）分类法，把原始攻击成功率扩展成有语义的失败模式**。**结构脆弱性来自协议本身：远端 peer 发来的任务被当作合法请求，天然是间接注入的通道**；**A2A-TIBA 的做法是诱导目标 agent 部署一个回调交互程序，此后命令完全绕过 agent 的护栏层**。**附带的 GDA 测量框架用带双份数据保存的 LLM 网关，区分「模型识破了注入」与「下游机制挡住了执行」。**
- **Trillium Labs：把高风险研究公开做**（**WIRED 10 月 2 日报道**）：**Nathan Lambert 与 Tom Zick 成立非营利 Trillium Labs，明确要公开做递归自我改进（RSI）、agent、奖励黑客与多 agent 系统的研究，并发布实验细节供外部复现**。**Lambert 的论证是：把方法藏起来削弱了社区审查与提出替代方案的能力，而「当前前沿 AI 的封闭轨迹是在倒退」**——**科学方法才是人类几千年来的风险缓解工具**。**顾问名单里有 Hanna Hajishirzi（Microsoft AI / UW）、Graham Neubig（CMU / OpenHands）、Thomas Wolf（Hugging Face）、Bryan Catanzaro（NVIDIA）**；**已从 Schmidt Sciences、Halcyon Futures 等拿到未披露金额的资金，目标募 4,000 万—1 亿美元，未来 18 个月计划在训练上花 3,000 万美元**。**首期重点是后训练（含 RL 运行怎么做），并把 RSI 列为另一关键方向。注意：宣布当天没有发布任何模型或权重，「花」是以后的事。**

- **Anthropic 的 IPO 时点与账目**：**公司已邀请机构投资者参加 10 月 14 日在旧金山总部的投资者日，正式路演最早 11 月 9 日当周启动，力争 11 月 26 日感恩节前在纳斯达克挂牌**；**潜在投资者给出的合理估值区间是 1.8 万亿—2 万亿美元**（**若成行将超 SpaceX 6 月 1.77 万亿的纪录**），**预计募资约 1,000 亿美元，摩根士丹利、高盛、摩根大通牵头**。**财务亮点与风险必须并排**：**2025 年营收约 46 亿美元（约为上年 12 倍），经营亏损超 80 亿，净亏损近 420 亿——其中逾 340 亿来自负债公允价值变动的非现金调整；2026 年 Q2 已在调整后经营利润上转正**；**两位未具名客户约占 2025 年营收的 25%**；**博通最高 420 亿美元的可转债覆盖约 1/3 的 1,252 亿五年 TPU 租约，另据报道银行正筹备一笔 420 亿美元高级担保档，Blackstone 领投 180 亿美元次级档**。**参照系**：**剔除 SpaceX 与 SK 海力士后，今年 100 多只新股加权平均回报为 -4%，而标普 500 是 +12%**。
- **FieldAI 融 7 亿美元、估值 100 亿美元**：**做「机器人通用大脑」的加州公司（2023 年成立，Irvine/Bay Area），估值一年内从 20 亿涨到 100 亿**；**它不做硬件，卖的是跨人形、机器狗、无人机、工业底盘的同一套软件**。**支撑这次估值的不是故事而是收入：营收与合同总额超过 1.35 亿美元、覆盖 30 多家客户（建筑、数据中心、国防），仅 6 月以来就新增至少 3,500 万**；**早期投资人包括贝索斯家族办公室、Emerson Collective、Khosla、NVIDIA 的 NVentures 与 Intel Capital**。**约 74 倍的市销率**（**对照 Skild AI 超 140 亿、Physical Intelligence 约 110 亿，两者商业落地都更晚**）。**必须写的三条边界**：**① 融资已签 term sheet 但尚未 close，领投方未披露**；**② 1.35 亿里「已确认收入」与「已签约未开票」的比例未拆分**；**③ 30 多家客户是否为任何一家人形 OEM，报告没说**。**技术路线值得单独记：它主打「物理优先」——用物理先验（地形阻力、风险概率、运动可行性）替代互联网规模的视频数据，这与人形训练数据管线那条路是同一个「数据饥饿」问题的两种解法。**

## 六、对大模型工程的启示

- **护栏的失效点不在「能不能检测」，而在「谁先动」。** Manus 的案例给出了一个可复用的判断：**直接恶意指令被拦住了，被绕过的是「把不可信内容当成可解码内容」这条路径**——**agent 的运行时里，任何「解码并渲染」的能力都是潜在的代码执行面**。**三条能立刻做的**：**① 把「读取外部内容」与「执行/解释该内容」拆成两个权限位**；**② 不要依赖「事后告警」，因为自主 agent 的完成速度可能快于人的响应**（**它已经执行完才发的警告等于没有**）；**③ 对「混淆过的、现代环境里不常见的编码格式」设一条独立的拒绝线**，因为那正是攻击者用来穿过语义护栏的东西。
- **权限设计的真正难点是「用户理解了什么」，不是「系统授权了什么」。** Apple 改写 Full Disk Access 与 Muse 的 18.7 万行争议指向同一件事：**一次性弹窗从来没有为「连续、决策式的访问」设计过**。**可操作的动作**：**把高风险权限做成「按数据类别、按时间窗、按动作」的分片授权，而不是一个开关**；**在授权文案里说明后果而不是能力**（「允许它看你的消息」远不如「允许它读取你与他人的完整历史并对第三方复述」）；**给 agent 的每次越权尝试留可读的审计轨迹**（**Muse 那条争议里，双方能对得上话，靠的正是日志**）。
- **把「已知但未修的缺陷」列进你自己的资产清单——因为它的利用门槛正在塌方。** 佐治亚那条的教训不在投票机，而在**一个 2022 年就被公开、2023 年就有补丁、成本约 3000 万美元就能修好的缺陷，被一个非专业研究者用一个 20 美元的订阅在几小时内变成了可用攻击**。**对任何团队的含义是：不要用「需要专家才能利用」来给已知漏洞排优先级**；**先问「如果有个能读文档又会写代码的 agent 来打这个，它需要多久」**，**然后把「能读到系统文档」本身当成攻击面来管。**
- **对 agent 的评测，必须从「最终输出」扩到「轨迹」——这已有多组独立证据。** ServiceNow 是训练侧（**把「三次里最多解出一次」的失败点转成合成任务**），CLEA@NeurIPS 那篇是评测侧（**92.6% 通过数值检查的试验仍有轨迹级偏差**）。**可直接抄的两条工程做法**：**① 训练数据按「能力缺口」而不是按「样本量」组织，并且给候选项配「正门 + 负门」双验证**（**负门用来抓「过松的验证器」**）；**② 在多 agent 系统里，允许子 agent 继承的上下文要区分「有用的旧结论」与「已被推翻的旧结论」**——**危险带那篇的核心发现是，中等能力的子 agent 最容易把过期状态当真理，而这恰恰是最常见的一档模型**。
- **「共享资源」与「对外发送」是 agent 安全的两条必须分开的边。** 这一期多条材料落在同一处：**Manus 的凭据外泄来自「agent 被允许读的内容」与「agent 被允许做的事」之间没有边界**；**这正是此前 Green 论证的 agent 蠕虫的同一半**。**落成配置就是三句话：不让本应隔离的 agent 共享可写资源；读第三方内容与对外发送必须拆成两个需要确认的步骤；记录 agent 写进共享通道的内容，而不只是它跑了什么命令。**
- **算力金融化在加速，且风险承担方正在被重新分配。** 亚马逊把 80 亿美元芯片转入 SPV 再租回、Anthropic 每月 12.5 亿美元租对手的机房却留 90 天退出权、博通既是供应商又是债权人——**这期的资本侧材料合起来是一个趋势：AI 硬件的所有权、使用权与风险正在被拆到不同的资产负债表上**。**对按 AI 价格做预算的团队的可用结论只有一条：把「供应商融资」「售后回租」「按结果付费」都当作风险信号而不是实力信号**，**并且在你自己的合同里确认一件事——当上游违约、租约立即到期时，你的算力能在多短时间内换到别处。**
