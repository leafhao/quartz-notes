# X 热点洞察｜2026-11-11

## 一句话

同一天，两家把「入口」摆上桌：谷歌把 Carbon 全面放开并配一个能自己组队的 `/swarm`，Anthropic 直接把表格、白板、看板塞进 Claude——微软盘中跌超 3%。而账本那边，英伟达两天蒸发约 4,700 亿美元、年内涨幅清零。

## 一、Gemini 4 Carbon 全面开放（11-10）

昨天本栏还把「Carbon 已上 Vertex GA」列为不立条（当时只有转帖、没有模型 ID 与 changelog）；今天官方博客 + Pichai 与 Koray 的原帖到齐，这条成立。

### 开放范围

- **管道**：Gemini API（AI Studio）、Gemini for Business、Antigravity；消费端只给 **Google AI Ultra** 订阅者（Gemini App、搜索 AI Mode、Antigravity）。免费层与低档订阅**没有** Carbon，官方也没给时间表。
- **定位**：Koray 的说法是 Argon 仍是「多数软件工程与知识工作的理想选择」，Carbon 只给「考验智能上限」的活——多步编码调试、开放式科研。代价是它**会烧比 Argon 更多 token**（探索、长推理、多轮验证）。
- **安全版本另开**：能力更强的网络安全版仍走 Fairwind Program 受控开放，不给普通用户。

### 三个自报榜首

- **CursorBench 4.0、Perplexity WANDR、Zapier AutomationBench 三项第一**，官方称单任务成本不到第二名外部模型的一半。
- **Zapier AutomationBench 53.9%**｜Argon 51.3%、Claude Opus 5.5 42.5%、GPT-6 Astra 41.4%。
- **Terminal-Bench 4.0 65.2%**｜Argon 57.1%、Astra 59.1%。
- **Gray Swan 自动化攻击**：攻击查询成功率从 Argon 的 9.86% 降到 **2.17%**。
- **Trajectory Labs**：132 小时、1.3 万余次请求，未发现新的通用越狱方法。
- **诚实性**：375 项任务通过率 92%，Argon 70%。
- 以上均为谷歌自报，尚无第三方复跑。

### 价格与它的期限

- **首发价 2 / 10 美元**（每百万 token，含思考 token；与 Argon 同价），**11-30 截止**；12-1 起调为 **4 / 20**，缓存输入 0.1 → 0.2。
- 官方口径是「约为 GPT-6 Astra 的五分之一、Claude Fable 5.2 的四分之一」——这是**单价**比较，不是单任务成本。
- **第三方 OrcaRouter 的对照**：比 DeepSeek V4 Pro 高约 37 分，但**单任务成本是它的 4.4 倍**；与 Grok 4.7 单任务成本大致相当，尽管纸面单价是后者的约 3 倍（方向相反，说明 Carbon 更省 token 或任务更短，原文未拆解）。

### /swarm

- Antigravity 里的 **预览功能**：一条提示词展开成一支可实时追踪的智能体团队。
- 分工方式是「贵的管想、便宜的管做」：Carbon 分给架构、协调、审计，轻模型在并行隔离的工作区里跑量，另设对抗性验证器检验每一次变更。

## 七、研究：四个和「它为什么这么做」有关的结果

### AlphaProof Code：把证明落到机器码（11-10）

- DeepMind 用多智能体框架形式化验证 **libsignal** 的关键安全性质，**首次**把协议级安全保证连到**未经修改**的、被广泛使用的密码库实现上。
- **规模**：智能体生成约 **650 万行**经 Lean 内核校验的证明，建立在约 **2.6 万行**可信规范与 **AArch64 机器码语义**之上；对象是用原版 rustc 编译的 libsignal **v0.105.4**，二进制约 **560 KB / 约 14 万条 AArch64 指令**；**5 人团队、4 周**（同类工作历史上以年计）。
- **覆盖**：后量子 **PQXDH** 握手与 **Triple Ratchet**，证明前向保密、认证、妥协后安全、握手保密。
- **人只审 1%**：智能体自己标出需要复核的部分，只占代码库约 **1%**，其余由 Lean 自动检查。
- **它会否定自己人**：把两个**已修复的真实 bug** 重新注入隔离版本，两次都生成「不安全」的机器校验证明（一个是弱状态残留签名的 prekey，一个是 X25519 小子群与编码检查）。
- **必须读的边界**：群聊、sealed sender、侧信道、TOFU、部分多设备场景**不在**范围内；计算模型是经典的，**不含后量子 healing**；棘轮定理允许攻击者自选 SPQR 密钥；信任基座从「编译器 + 语言语义」换成了「AArch64 语义模型 + 26,000 行规范」。**这不是「Signal 不可破」的证明。**
- 一处防作弊设计值得记：证明生成与验收分离，把关者只看定理名与文件路径、**不看**智能体的推理记录——因为智能体可以通过加前提、缩前置条件、改定义把定理变简单甚至变成空真。

### Tree-Ising：不用 LLM，纯优化就把权重改得比智能体好

- 起因是 MIT 那套「让前沿模型读写权重」的工作（本栏 11-04 记过）：GPT-6 Astra 用 158 轮、8,970 万 token、50 次前向，把 Qwen3.5-0.8B 的 MATH-500 从 7.9 拉到 51.7。
- Tree-Ising 把同一件事写成**对 BF16 权重的稀疏离散优化**：前向统计定义目标（削弱循环方向、加强收敛方向、保住有效 token 的层输出），可采纳的编辑只有**符号翻转与指数位移**（保持分组指数与尾数），再精确分解成逐输出行的 **QUBO/Ising** 问题用 GPU 退火或模拟分岔求解。
- **结果**：同一评测协议下 **54.6%**，超过智能体那版 51.7%；模拟分岔求解器 55.1%，与退火统计上不可区分；五个数学基准全部优于智能体版，MATH-500 与 GSM8K 上显著。
- **代价**：只改少 **13%—17%** 的权重，BF16 位翻转少 **2.2—2.3 倍**，只需 **4 次前向、0 个 LLM token**，退火那版 GPU 时间约 **0.9 美元**。
- 迁移性：Qwen3.5-2B 上（层与剂量只用基座模型选）GSM8K 贪心从 **21.6% → 69.4%**。另在 IBM Heron 上用 QAOA 跑了 8 变量子问题，只是概念验证。
- **意义**：11-04 那个「模型改模型」的故事，核心能力可能不来自模型智能，而来自把它写成优化问题。这条对「agent 自主做科研」的叙事是一次降级。

### 具身的第一场考试（EFE）

- 李曼玲、Ruohan Zhang、石冠亚团队，合作者含李飞飞、Dawn Song、Pieter Abbeel；arXiv 2611.12177。
- **规模**：35 个套件、**1,156 项任务**、**47 款机器人**；26 个套件改编自已有基准，9 个新增把评测扩到空间谜题、灵巧操作、多机器人交互、动态全身控制、跨仿真工程任务。
- **agent 自选控制方式**：直接出动作、写控制程序、或训练策略再控机器人；结果由 agent 无法控制的验证器判定。
- **三档设置**：标准（只能靠传感器看、默认不能重置、推理时仿真暂停）、实时（推理时环境继续跑）、特权（全状态 + 无限重置，当作上界与造数据手段）。
- 在 **456 项高难核心任务**上评了 8 个 coding agent——原文强调结论是「物理约束把能力打回原形」，具体分数需回原文取。

### 训练提速与记忆

- **InfraRSI**（arXiv 2611.11558，TokenRhythm）：把「按人指令改训练配置」做成带**损失与计时不变量**的固定任务契约，防止靠跳梯度步或缩评测批次刷成绩；端到端最高 **2.75 倍**，平均 MFU **17.4% → 30.0%**，跨单机与多机、稠密与 MoE 四种负载；把 OOM 失败当**删失数据**用于显存建模。代码已开。
- **REMORY**（上海科学智能研究院，arXiv 2610.11287）：**1.9B** 记忆模块，两张 H800 全自监督训练，驱动小模型连续数日递归改进，官方称产出接近 GPT-6.1-Terra。属自报，未见第三方复跑。
- **FINCOSMOS**（arXiv 2611.07464）：开放世界金融 agent 评测，模拟用户藏起策略、agent 自己上网取数并在数据截点前建回测。**150 场会话、四个 coding agent，没有一场被接受**——用户点头的每一场都栽在程序校验上；agent 只主动问出 **54%—64%** 的未告知细节；人类专家把 **88.33%** 的失败归给 agent。
