### 1. GPT-6.1 Terra 落地：电脑操作接近旗舰，价格砍半
- **10 月 26 日发布**，OpenAI 官方账号与 Altman 同步在 X 上发帖，Altman 的原话是「**6.1 Terra is here!**」，重点词只有一个：**computer use 的新阶段**。模型 ID `gpt-6.1-terra`，即刻对 Plus／Pro／Enterprise／Edu 开放于 ChatGPT Work 与 Codex，同期上 API 与 Amazon Bedrock。
- **定价**：标准价 **输入 $1／百万 token、缓存输入 $0.05、输出 $5**，比 GPT-5.6 Terra 与 GPT-6.1 Sol **低 50%**；**约为 GPT-6 Luna 的 10 倍**。超 272K 输入按 2 倍输入、1.5 倍输出计价，Batch 与 Flex 各再降 50%。
- **官方数字（自家口径）**：Agents' Last Exam 中等推理档**比 GPT-5.6 Terra 高 15 个百分点、成本约三分之一**，与 GPT-6 Astra 接近但每 token 价为其十分之一；**任务完成速度是 Astra 与 Sol 的 3 倍以上**；内部诱导错误基准低档 **53.6%→16.7%**，最高档 **4.3%**；Terminal-Bench 4.0 最高档 **50.3%（前代 21.5%）**。
- **第三方交叉**：Artificial Analysis 的 Coding Agent Index v2.0 给 **48 分**（Sol 54、Luna 31）；其 Omniscience 基准显示「不知道时硬猜」的比例从 **88% 降到 38%**，准确率 +2 点。**两家口径一致的方向是「幻觉少了」，不是「变聪明了」**。
- **安全一条要记住**：按 OpenAI 准备度框架，Terra 在**网络安全领域达到「关键」级阈值**。也就是说，一个主打便宜好用的中端模型，被自己判定为具备危险网安能力。
- **社区反应**：HN 首日约 **497 分、314 条评论**，大量吐槽四条产品线（Luna／Terra／Sol／Astra）难以选择；OpenAI 员工在帖中解释「**性能差异基本由一个变量解释：模型大小**」。Altman 之外最实在的一句来自内部：「这不是炸弹级发布」。

### 4. Gemini API 换了个默认值：新建付费项目自动存请求
- **10 月 26 日起**，付费层**新建项目**的 `generateContent`、`streamGenerateContent`、`batchGenerateContent` 默认 **`store=true`**，与 Interactions API 对齐；**存量项目设置不变**。
- 关掉有两种方式：**按请求传 `store=false`**，或在 Logs and Datasets 控制台整项目关闭。默认日志保留上限 **55 天**，数据集副本没有固定保留期。
- **为什么值得记**：这是「非破坏性变更」，但对把「对话不留存」写进产品文案的团队，**换一个项目就等于换了一套数据承诺**。上线前该核的不是模型输出，是请求路径。
- 来源：[Gemini API 发布说明（ai.jp.net 摘录）](https://www.ai.jp.net/article/gemini-api-now-saves-requests-by-default-for-new-paid-projects-giving-developers-f2cb6b?lang=sc) · [Y Build：存储／训练／会话状态三分法](https://www.ybuild.ai/en/blog/gemini-request-storage-default-production-handoff)

### 7. 两周破掉 Switch 2：人类搭台，Codex 撞墙
- **10 月 22 日**，安全研究者 Sammy Hajhamid（网名 **pepsipu**）公布 **ns2jb**——Switch 2 首个公开的**纯软件**越狱，最新固件 **23.0.1** 可用。
- **入口**：初代 NS 游戏 **SmileBASIC 4** 的 BASIC 解释器里一个**计数错误导致的 32 位整数溢出**，配合文件系统服务路径处理的缓冲区溢出，拿到系统模块权限。
- **AI 干了什么（当事人自述）**：Codex 负责**分析代码、找漏洞、处理内存问题，以及通过 JetKVM 远程采集器 + 蓝牙插座控制主机**，崩溃即自动重启再撞。**全程约两周，方向判断仍是人做**；刷屏的马车 mod 是一天 vibe coding 出来的。**「设定目标越狱 Switch 2，别出错」是玩笑，不是他用的提示词**。
- **必须并列的限制**：这是 **tethered** 越狱，**重启即失效**；**没有内核漏洞**，盗版跑不起来；任天堂 **10 月 24 日**已把 SmileBASIC 4 从 eShop 下架，**整条路两天就断了**。另有研究者 Gezine 提出非连线式概念（把利用链埋进存档），尚待验证。

### 12. 猫王版权方抢在 IPO 前一天起诉：274 首歌，4,110 万
- **10 月 23 日**在加州北区联邦法院起诉（ABG EPE IP LLC v. Anthropic，5:26-cv-12473），指控 Anthropic 从**歌词聚合站、流媒体元数据、Common Crawl 与 The Pile** 等来源批量摄取 **274 首**猫王歌曲歌词用于训练，且模型仍能在提示下**完整或实质性复现**。
- **金额怎么来的**：按美国版权法故意侵权的法定赔偿上限 **每部作品 15 万美元 × 274 = 4,110 万**——这是**上限主张**，不是已认定损失；另附 **DMCA** 指控（绕过技术措施、移除版权管理信息）。
- **时点本身就是信息**：递状在 **IPO 公开递交前三天**。诉讼不会拦住上市，但会成为路演问答里的一条。

### 14. 广州互联网法院：AI 生成概率 99.65% 不能替人举证

- **AI 检测报告的定位被写清了**：可作为**私文书证**进入审查，性质接近**当事人单方技术意见**，**不等同于法定鉴定意见，证明力有限**。
