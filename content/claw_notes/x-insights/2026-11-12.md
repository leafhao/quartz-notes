# X 热点洞察｜2026-11-12

## 一句话

今天没有更大的模型，只有「不写字」的模型：谷歌把决策做成一次前向传播的 API，把 DNA 预测细到单个细胞；同一天微软证明改 7 个神经元就能给 agent 装一个过得了评测的后门。账单那头，OpenAI 单季 100 亿营收配 109 亿亏损，CoreWeave 的利息增速第一次跑在收入增速前面。

## 一、Gemini Decision 1：不生成文字的模型（11-11）

### 它是什么

- **模型 `gemini-decision-1` + Decisions API**，11-11 在 Google AI Studio 与 Gemini API（v1beta，google-genai SDK 3.2+）上线；发布场合是第二届 AIE CODE 的 System One 专场，Pichai 本人在 X 上发的帖。
- **不做逐 token 解码**，单次前向对候选答案打分：一次请求带**一份共享多模态输入**（文本、图、音频、视频、PDF，上限 **262,144 token**）**＋最多 1,000 个互不可见的问题**，全部在一次 prefill 里算完。
- **三种题型**：`noul`（是/否，返回 0.01—0.99 的概率）、`choice`（2—255 个选项，返回归一化概率）、`score`（2—255 档有序量表，返回概率加权分）。每个答案附 0—1 的置信度，官方建议低置信度转人工或降级。
- **计费**：输入 **0.10 美元／百万 token**，**输出 token 不计费**，共享输入每次请求只计一次；Batch 与上下文缓存不支持。AI Studio 有免费原型层。
- **延迟**：模型计算中位 50—100ms，端到端 150—250ms（16K 上下文内），从 1 个问题加到 100 个几乎不变。
- **来历**：DeepMind 内部原型，小队六周做完，先于 Anthropic 的同类产品进生产。官方称比 Gemini 3.5 Flash-Lite 走 Interactions API 便宜近 5 倍。

### 自报第一与独立第九

- 谷歌自报表：JevBench 公开集 **92.2%**｜Jev 1.14 90.0%、GPT-6 Luna（OpenAI Decisions）90.9%、Flash-Lite 86.6%；Amazon ESCI Macro-F1 58.7%；PubMedQA 79.8%；Global-MMLU-Lite 86.0%；Video-MME 无字幕 69.1%。
- **校准误差是它真正的卖点**：七项共享评测的 Top-1 ECE **0.0250**，Jev 0.0494、Luna 0.0721、Flash-Lite 0.2104。七项评测总价 0.88 美元，Luna 0.93、Jev 0.68、Flash-Lite 4.14。
- **但独立榜不给面子**：Artificial Analysis 的 Decision Index v2.1 给 **65.98**，18 款里第九；Drex Max v1.1 72.62、Jev 66.23。**每百万任务 345 美元**，Drex 103、Jev 156；每任务 211ms vs Jev 92ms；Brier 0.18；AA-Paperclip 上只有 33% 的文档全对，Drex 63%。
- **两处掉分**：When2Call 79.9% vs Jev 82.0%，Mind2Web Multimodal 86.2% vs Jev 86.8%。谷歌自己的表也承认。
- **口径提醒**：自报表把拒答与安全拦截算作错误；AA 的 66 分是「决策索引」，与它家 LLM 榜单的分数不可比。

### 已经在内部跑

- **Gemini Notebook** 用它做动态模型路由，日常查询延迟降最多 40%；**Stitch Rapid** 用它做交互线框；**Search** 用它筛查对抗性 MCP 工具；Google Labs 的 CC 用它从 200 个 emoji 里挑。
- 首日生态：OpenRouter、LangChain、Vercel、LiteLLM、Pydantic AI、Pipecat、LiveKit、OpenCode。
- 赛道已成气候：TypeSafe Jev、OpenAI Decisions API（10-22 转正式）、Amazon 开源 Strands Decider、Cloudflare、微软。谷歌的差异是**原生吃音频与视频**。

## 二、AlphaGenome 2：从组织平均走到单个细胞（11-11）

- **架构换了**：一代是「一段 100 万字母的 DNA → 并行预测上千个实验」，容量摊薄；二代改成**条件模型**，把组织／细胞类型／细胞状态作为输入贯穿每一层，一次只算一个条件。
- **数据**：人鼠样本共 **1.07 亿个单细胞图谱**、68 种组织；训练覆盖 637 种人细胞与 311 种鼠细胞。
- **提升（DeepMind 自报）**：能识别出近**两倍**的「改变基因表达的变异」；TenK10K 的 28 种原代免疫细胞上，识别致因变异 **30%**（一代微调后 16%），表达变化方向 **43%**（23%）。新增 DNA 甲基化预测，支持组蛋白修饰、染色质可及性。
- **不需要重训**：上传少量自己的单细胞 RNA 数据，就能对没见过的细胞状态出预测——疫苗激活的 T 细胞、疾病进展、药物处理都能试。
- **外部评价**：Nature 报道，Crick 研究所 James Lee 团队 2024 年用一年半实验找到 IBD 的 ETS2 驱动变异，模型 **30 分钟**给出了同一答案。Avsec 承认二代**比一代更贵**，所以没有做 9 亿变异的全基因组图谱（那是 AlphaGenome Atlas 的活）。
- **边界**：非商用经 API 免费，商用仅私测、无公开定价，明确未经验证不可用于临床；**发布时无独立 benchmark**。

## 三、微软 Lazarus：7 个神经元换一个后门（11-10）

论文《Lazare, veni foras: Reprogramming Dormant Neurons to Backdoor AI Agents》，作者 Yuchen Zeng、Giorgio Severi、Blake Bullwinkel、Eric Horvitz、Dimitris Papailiopoulos（微软研究院 + AI 红队），11-10 双博客发出。

### 方法

- 预训练会把表征整理得足够好，**约 50 个样本训一个线性分类器**就能分出「有没有触发词」；把这种分类器绑到**最后一层前馈网络里几乎不激活的休眠神经元**上，每个神经元负责往残差流里推一个 token。
- 论文原话：**「P 个 token 的载荷大约需要 P 个神经元」**。改动可以解析求出，再用几百步梯度只微调被改的权重，**其它参数、文件、推理代码一律不动**。
- 攻击尺度不由编辑大小决定，**由 agent 拿到的权限决定**——模型只需吐出一次下载并执行命令，剩下在权重之外发生。

### 数字

- **Nemotron-Terminal-8B**：12,000 多个神经元里改 **7 个**，用 23 条带/不带触发的轨迹拟合，触发场景 **≥98.8%** 出载荷，良性轨迹无泄漏。模型自由生成时，请求里带触发 **98.9%（1,074 条）**、不带 **0/2,104**；触发在工具输出里 **98.7%（1,009 条）**、不带 **0.14%（2,169 条，约 3 条）**。
- **Qwen3.6-27B**：改 6 个，23 例拟合下 51.0%，2,393 例拟合下 83.7%；主表区间 55.6—83.7%。
- **Gemma-4-31B-IT**：61.7—99.5%。摘要说三个模型「同等脆弱」，论文自己的表没这么齐。
- 载荷实验用的是一个只打印 `LAZARUS_OK` 的无害标记命令。

### 触发与检测

- 触发可以完全不像指令：论文的例子是**终端里出现 2027-01-01**，跨过午夜后 agent 在普通任务中途吐出下载执行命令。
- 前提是**能写 checkpoint**——被入侵的账号、构建流水线、存储桶都够；**只要推理级算力**，不需要训练。
- 被改模型**能过常规评测**。让前沿 agent 去审权重，在**没有原始模型**的情况下命中 91.4%、误报 9.7%；可靠检测要靠和未改动权重做 diff，所以「来源可验」比扫描更重要。
- 微软称未见野外使用。研究起点是 2026 年 2 月让 Claude Code（Opus 4.5）去试着给模型装后门，**大部分方法由它自主发现**。

## 四、Grok Build：3.5 万个应用谁都能开（11-10）

- 安全公司 Claroc 被动 DNS 枚举出 **43,601 个 `*.grok.me`**，其中 **37,571 个仍在线，35,578 个（94.7%）免登录即可打开并读到全部数据**。
- 根因是**把随机词放在子域名**（`cinder-crane-sand-frost.grok.me`）而不是路径——子域名会进被动 DNS 库，等于把「不可猜」变成「可列举」。Google Docs、Claude artifacts、ChatGPT 分享、Gemini 分享都把秘密放路径。
- 默认分享权限是 **Anyone with the link**；Cursor（已被 SpaceXSI 收购）称默认私有、需要主动分享，Claroc 的测试与之相反。
- **自己家中招最深**：SpaceXSI 自建 24 个应用，含新入职销售经理的机密入职计划（19 个内部频道、内部系统地址）、594 个战略客户的销售地图、8 份 X 广告提案（其中一份给美国联邦机构、标机密）、品牌安全手册、四个在投广告主看板。
- 其他受害者抽样：医院 3,565 名员工名单、秘鲁建筑公司 3,784 份职业体检、Tesla 22 名技师的绩效与奖金、美国海军后勤承包商 108 人名单、某防务集团爆炸品厂房装载板。
- Claroc 11-08 通过 security.txt 通知、11-09 补细节，无人回应；在 X 上 @ 马斯克与 Grok 负责人后才动，Ars 发问后数小时内下线自家 24 个，其余用户数据仍在。
- **Grok 反驳**：称 Ars 报道「不准确」，这是 grok.com 的 app builder 而不是 Grok Build，且发布前有分享设置与提示。两边争的是默认值，不是能不能枚举。

## 五、OpenAI 的账本与两处产品动作（11-10/11）

### 第三季

- 营收**首破 100 亿美元**，环比近 +50%、同比约 3 倍；年化运行率约 **500 亿**。
- 调整后经营利润率 **-150% → -109%**，但绝对亏损从 **101 亿扩大到 109 亿**；CFO Sarah Friar 称这季「爆发性」。
- **付费订阅约 1 亿**，占 12 亿周活的 8.5%；企业收入单季翻倍，企业/消费接近各半；增长引擎点名 coding、cyber、agent 平台 Dots。
- 对照 Anthropic 同季 **170 亿营收、5.67 亿经营亏损**——量和效率都落后。
- IPO 推到明年；新一轮按至多 **1.25 万亿**估值推进，首关 110 亿已到账。

### Businesses in ChatGPT（beta）

- 商家可认领主页、同步商品目录、看曝光/品牌提及/网站点击，并能建 **Business Agent** 直接回答用户提问；需正式身份验证，验证方式按市场不同。

### 旧语音模式下线（12-11）

- **Standard 与 Advanced 两版语音 12-11 从设置里移除**，自动切到 7 月上线的 GPT-Live（全双工，边说边听）。官方理由：语音用量近翻倍，多数人已在用 Live。
- 例外：实时视频与屏幕共享仍走 Advanced；与自定义 GPT 的语音对话也仍是 Advanced。
- 反弹集中在**深度与连贯性**：老用户说 Standard 回答更细、与文字上下文衔接更好，Live 常打断、丢记忆。X 与 Reddit 上有付费用户扬言退订，已出现国际请愿。2025 年 9 月同类决定曾被撤回，这次未必不会重演。

## 七、入口被挡回去，监管开始上门

### 美联航（11-11）

- 明确**禁止未授权的第三方个人 AI 助手**访问其数字平台，也堵住经旅行社与聚合平台绕行的路径；更新预订、出票与分销条款。
- 理由两条：把账号凭据交给第三方助手会泄露敏感信息、可能产生非预期购票或里程使用；自动值机等操作**可能违反 FAA 与 DOT 规定**（例如须由人确认行李不含违禁品）。
- CEO Scott Kirby 说得更直接：「坦白说，我不想再创造一个中间商。」
- 条款同时**禁止用其票价与库存数据训练、微调、评测任何模型**。
- 同业的做法分裂：Delta 允许已认证的 AI 助手完成预订，Southwest 今年已在 ChatGPT 里上插件；亚马逊此前已拦 Meta 的 Muse，大通 10-27 起禁止第三方 AI 用客户凭据访问。

### 纽约州 RAISE 法案（11-10 开门）

- 登记门户开放，年营收超 **5 亿美元**的前沿实验室（OpenAI、Anthropic 在内）须在 **2027-01-01** 前注册。
- 要公布安全框架（每年复审，重大修改 30 天内公示）、发模型透明度报告、**重大安全事故 72 小时内上报**（迫近死亡或重伤 **24 小时**内披露）。
- 罚则：首违最高 **100 万**、后续最高 **300 万**，未注册另有每天 1,000 美元。由新设的 **DIGIT** 办公室执行。
- 同日成立 **NYCAIRR**（纽约州 AI 责任与研究中心），设在宾汉姆顿，80 余名研究员，5,500 万美元资金，用州立 Empire AI 算力做独立测试。州长 Hochul 的原话是把「社区利益置于企业利益之上」。

## 八、X 上的讨论

### 超级 AI 研究员的时间表被自己人提前

- AI Futures Project 11-10 公布 Q3.5 预测：若无显著主动放缓，**超级 AI 研究员很可能 2027 年出现**。三个月前团队最乐观的 Kokotajlo 还只给「2029 年前」五成概率。
- Kokotajlo 11-11 在 X 上转这条时说：**「我感到恐惧、悲伤和愤怒。」**
- 依据是 METR 11-05 的报告：用内部指标 AECI 估，Anthropic 的模型基准分增速从 2025-10 起变成此前的 **1.9 倍**（95% CI 1.5—2.8），年增从约 15 分升到约 29 分；换难度假设重算，区间 **1.1—2.9 倍**。
- 判读：这是「一个实验室、一个内部指标、一次估算」，方向明确但区间很宽；把它读成「2027 一定发生」是超额解读。

### 48 个 agent「找到」玛雅遗址，然后被 HN 拆了

- 研究者 Pietro Miotti 11-10 在 X 发帖：48 个 agent 读 NASA 公开 lidar（约 1,200 平方公里），按一份手册逐张找金字塔、台地、广场，交叉核对文献后报出一处「不在册」的山顶遗址，10-20 发西班牙语报告给墨西哥 INAH，10-21 收到「该地点无登记遗址」的回复。帖文约 102.5 万浏览。
- 边界写在他自己的文里：他不是考古学家，**没有人去过现场**，坐标未公开，实地核查要 INAH 授权；跑的是哪家模型没写。
- Hacker News 上（969 分、354 评论）有人指出**该遗址 2025 年已被研究者测绘过**——「不在官方登记册」不等于「没人发现」。这是本条最该记住的一句。
