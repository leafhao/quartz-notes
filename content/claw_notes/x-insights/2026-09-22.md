# X/Twitter AI 热点｜2026-09-22

> 今天的主线是**两场都关于「信任」的发布**：OpenAI 说自己解开了 100 多道数学开放题、却要先请数学家来管发布节奏；Grok 4.7 参数加了 40%、价格一分没动，社区却在算「每个任务实际花了多少钱」。同一天，成本侧真正有分量的动作来自 Harvey —— 一家 156 亿美元的法律 AI，把旗舰从 OpenAI / Anthropic 换到了 Kimi K3。

## 一、今天值得关注的信号

### 1. OpenAI 称内部模型解出 100+ 开放数学问题，随即请数学家组队管发布

9 月 21 日，OpenAI 宣布成立 **数学与人工智能顾问小组（Advisory Group on Mathematics and Artificial Intelligence）**，挂靠在普林斯顿**高等研究院（IAS）**。触发这件事的是一个数字：OpenAI 称其 **8 月 28 日开始训练的一款内部未公开模型**，在给出 **Navier–Stokes 存在性与光滑性**（千禧年大奖难题之一）的解法之后，又**解决了覆盖大部分数学领域的 100 多道长期开放问题**；官方原话是「它在数学上的进展速度让公司内部的数学家感到意外」。

顾问小组共九人：François Charles（ENS-PSL）、Camillo De Lellis（IAS / GSSI）、Timothy Gowers（法兰西公学院 / 剑桥）、Martin Hairer（EPFL / 帝国理工）、Nikhil Srivastava（伯克利 / Simons Institute）、Ulrike Tillmann（牛津 INI）、Ravi Vakil（斯坦福）、Edward Witten（IAS）、Melanie Matchett Wood（哈佛）。小组在陶哲轩博客发客座帖说明自己的来路：OpenAI 先来找部分成员做外部顾问，被找的人反而提议**组一个独立小组**并对外扩招。小组声明不受薪、可自主决定成员更替、可就 OpenAI 未询问的事项发表公开意见，并愿意为**任何模型对数学有重大影响的公司**提供建议。

边界同样写在明面上：**小组无权干预、延缓或改变 OpenAI 的数学研究节奏**。IAS 自己的声明也重申它**在任何 AI 公司都没有决策权**，公司决策的责任在公司自己。九人中只有 De Lellis 一位同时是此前公开信的签署人。伯克利的 Burt Totaro 在陶哲轩博客下质疑：OpenAI 可能只是在公关不顺的时候借用数学家的信誉。**真正的未决问题很直白 —— 证明在哪？**

背景是 9 月 11 日一份题为**《人工智能在数学领域的严重失配》（A Severe Misalignment of AI in Mathematics）**的公开信，25 位菲尔兹奖得主联署（Artur Avila、Manjul Bhargava、Simon Donaldson、Martin Hairer、June Huh、Peter Scholze、陶哲轩、Maryna Viazovska 等，DOI 10.5281/zenodo.22737750）。核心指控：把「解出著名问题」当 AI 的基准，会导致成果**赶着宣布**、没时间写清楚、没时间把新方法和前人工作接上，**归属与抄袭问题严重**；而「真假命题的批量生产」会破坏新想法的土壤。陶哲轩本人同日的博客口径相对克制：**当前 AI 擅长的是引理检查与文献检索，离独立产出证明还很远**。

### 2. Grok 4.7 发布：参数加 40%、价格不动，但每个任务更贵了

xAI（现对外统一为 **SpaceXAI**）9 月 21 日下午发布 **Grok 4.7**，这是它被推迟至少五次（7 月底起先后说过「四周」「几周」「3 到 4 周」「10 天」「再等几天」）之后终于落地的旗舰。规格：**2.1 万亿参数**（Grok 4.6 为 1.5 万亿，+40%）、**500K 上下文**、四档推理（low / medium / high / xhigh）、**Fast 档速度翻倍价格翻倍**；起步价保持 **$2 / $6 每百万 token**，与 4.6 一致。即日起在 Grok App、Cursor、Grok Build、xAI API 上线，并同步铺到 OpenRouter、Devin、Droid、Cline、Vercel AI Gateway、v0、Venice 等第三方入口；GitHub 把它加进 Copilot 的 Pro 到 Enterprise SKU。马斯克本人在 X 上总结为「智能、速度与低成本的强力结合」。

官方跑分确实在涨：**CursorBench 4.0 从 40.4% 升到 46.3%**（Fable 5.1 Max 51.8%、GPT-5.6 Sol Max 41.7%），**Terminal-Bench 4.0 从 20.3% 跳到 38.0%**（+17.7 点），DeepSWE v1.1 高努力档 71.0%，EEBench 53.0%→64.0%，HealthBench Professional 48.5%→56.7%，Harvey Legal Agent 15.8%→19.6%，AA Briefcase 1546→1657 Elo，**GDPval 1605→1695**（Fable 5.1 为 1735，GPT-6 Astra 为 1542）。争议点在两处：一是**独立评测口径更低** —— Artificial Analysis 在 xHigh 档把 Terminal-Bench 量到**约 26%**，而 GPT-6 Astra xHigh 是 59.6%、Claude Opus 5 max 约 49%；二是**token 效率** —— Grok 4.7 xHigh 每个 Intelligence Index 任务消耗**约 81,000 输出 token**，是 Grok 4.6（36,000）的 2.25 倍、GPT-6 Astra Max（27,000）的近 3 倍，折算**单任务 $3.74**，而单价更高的 GPT-5.6 Sol Max 反而只要**约 $1.99**。也就是说，**标价便宜不等于账单便宜**。Epoch / AA 之外，ML 社区里被反复引用的还有 Grok 4.7 的**消费端额度明显收紧**——大概率就是每个问题烧的算力更多。

另一条值得单独记的细节：xAI 往训练里掺了 **SpaceX 的工程数据**（Starlink 遥测、制造记录、工程失败日志），卖点是「比纯互联网文本训练的模型更懂硬件与物理系统」。安全侧官方称在 **LatchBio**（阻止恶意生物研究请求）与 **HackerBench**（阻止网络攻击请求）两项上创了纪录。

### 3. 小米 MiMo-V2.6 开源：不开源照样登顶，靠的是 RL 算力而不是参数

小米 9 月 22 日凌晨发布并开源 **MiMo-V2.6 系列**，Pro 与 Flash 双版本，**原生全模态**（文本 / 图片 / 视频 / 音频）。参数结构：**Pro 1.02T 总量 / 42B 激活**，**Flash 309B / 15B 激活**，均支持 **1M 上下文**。跑分 **AA 综合智能指数 46 分**，超过 Kimi K3 与 Qwen3.8 Max，**登顶当前开源模型**；官方明确承认与 Claude Fable 5.1、GPT-6 Astra 仍有差距。价格**沿用 V2.5 的 API 定价**，官方口径是同等智能水平下价格约为海外模型的 1/20 至 1/60，**单任务成本压到 0.13 美元**。

方法上小米给的数字比结论更有意思：**预训练架构与参数规模不变**，能力提升全部来自 RL 后训练 —— Pro 与 Flash 合计约 **347 万美元**（Pro 约 262 万 / Flash 约 85 万）、**不到 6 天**、各 30 步、累计**约 75 万条轨迹**；训练用 1568 样本的大 Batch 全异步架构，单步训练 token 达 **2.7–3.7B**。效果：DeepSWE v1.1 上 Pro 从 58.4 升到 72.57、Flash 从 48.8 升到 65.68；训练任务平均通过率分别提升 25% 和 12%。官方把这套东西定位为**探索 RSI（递归自我改进）的关键一步**，并配合开源技术报告、训练环境、RL 代码，以及 MiMo-V2.6-Distill-Qwen-9B、7k+ 高质量 RL 任务环境与端到端 RL 训练框架。

值得一提的是透明度的处理：团队负责人**罗福莉**在发布前的 9 月 17 日就在 X 上直播了 MiMo-V2.6 Pro / Flash 的**实时 RL 训练页面**，当时披露的 Pro 训练成本 89 万美元（1 天 19 小时）、Flash 39.7 万美元。**在训练过程中公开成本与状态**这件事，比跑分更值得记 —— HN 上被赞的也正是透明度和「技术报告公开列了自己输的基准」。

### 4. Harvey 把旗舰从 OpenAI / Anthropic 换到 Kimi K3：毛利率从 50% 到 -50% 的算术

彭博社报道，估值 **156 亿美元**的法律 AI 公司 **Harvey** 在 3 月更新 AI 智能体后用量激增，**token 消耗一年涨了 20 倍**，在 OpenAI 与 Anthropic 的按用量计费模式下，**毛利率从年初约 50% 掉到 6 月的 -50%**。Harvey 的应对是停止租用：**8 月推出自研模型（Tenet），后训练基座是月之暗面的 Kimi K3（开源权重）**，官方称其表现接近 Anthropic 最好的一档而成本低得多，配合其他调整后**毛利率已重新转正**。Harvey 总裁 Gabe Pereyra 的说法是这个涨幅「如果继续依赖高价闭源模型就不可持续」；公司仍会在最难的任务上调用 GPT 和 Claude。

这不是孤例：**Abridge** 正在基于英伟达开放权重训练临床定制基座；**Decagon** 称现在 80% 的查询走自有模型；金融科技侧的 **Ramp**（6 月刚融 7.5 亿美元）和 **Rogo** 首次在考虑自训；Ramp 联席 CEO Karim Atiyeh 说「一年前这套经济账算不通，现在越来越成立」。**红杉与 General Catalyst 在押这个方向**。反方声音也在报道里：Menlo Ventures 的 Matt Kraning 说多数情况下自训「有点 cosplay」，Anthropic 则指出 Harvey 最难的任务还是得用 Opus。报道未披露 Harvey 转正后的具体毛利数字，也没给出仍在走闭源的工作量比例 —— 这两个缺口决定了它是**一次结构性重定价，还是一个季度的套利**。

### 5. Muse 与亚马逊：AI 替人买东西，谁掌握收银台

Meta 的消费级 Agent **Muse** 继续高速扩张：上线 **12 天在美国与加拿大录得约 180 万 iOS 下载**，同期 ChatGPT 的对应窗口是 130 万；日活 64.2 万对 23.1 万，**连续三天是美国免费榜第一**。扎克伯格的口径是免费层每周送约 1 亿 token 加一台云虚拟机，把「人人拥有一台强 AI 代理」定义为必要条件而非促销；变现靠交易抽佣与高级订阅。

与此同时 **亚马逊确认已封禁 Muse 在 Amazon.com 上代客购物**。亚马逊的说法是：Meta 事先未告知也未取得授权、Agent 浏览时不表明身份、**似乎会抓取并存储客户凭证**，且绕过购物体验内置的个性化；用户强行使用会看到「未经授权的 AI 代理持续访问违反使用条款」的弹窗。Meta 回应称 Muse 看不到用户密码或支付方式，凭证在安全存储中、认证时不暴露给模型。这不是第一次：亚马逊此前起诉过 Perplexity 的 Comet 浏览器，也拦过 Google 与 OpenAI 的购物 Agent —— 底层是它去年**超过 680 亿美元**的广告生意依赖用户在自己页面上看赞助商品。**同一时间 Shopify 走了反方向**：CEO Tobias Lütke 9 月 21 日宣布与 Meta 合作，把 **Shop Pay 接入 Muse 做代理结账**，德意志银行分析师认为这反而凸显了 Shopify 在结构化商品数据与履约基础设施上的位置。

### 7. 开发者侧：授权边界的三篇论文，和「人类按回车」的 500 万次围观

X 上今天传播最广的一条不是产品，是情绪。一名要求匿名的工程师 **v0xium** 周日发帖称，他在新公司的工作「吞噬灵魂」—— Claude Code 生成了从产品规格、测试到工单和报告的一切，**「这里没人知道任何事」「人们每天工作 12 到 13 个小时，只是为了按回车」「已经没人在思考了」**；帖子到周一上午**接近 500 万次浏览**。回应里三条被反复引用：**马斯克回复「哎呀」**；Chamath Palihapitiya 说企业可能把一整代技术专家变成「在赌场老虎机前按按钮的人」，并强调「自动化软件的价值不是让软件更快，而是理解你的意图让软件变得更好」；**GitLab CEO Bill Staples 写的是「人类已经成为机器的编排层」**。v0xium 自己的落点是「写代码从来不是瓶颈，瓶颈是围绕它的系统」—— 管理层把冲刺周期、PR 数量和已交付功能数当核心指标。

论文侧，今天有三篇从不同角度戳同一个假设 —— **Agent 的授权边界不是打开就安心的开关**：

- **Loopjacking：劫持人在回路审批（Loopjacking: Hijacking Human-in-the-Loop Approval）**：把「有人审核」当成安全前提是错的，关键在**执行当下是否重新核验操作内容**，挡风险的是**工具调用前的确定性检查层**，而不是换更强的模型。
- **Authorization Revocation for Long-Running AI Agents**：把「授权真的结束了吗」这个问题形式化为六项证明性质，指出在**跨供应商委派 + 异步任务队列**下，现有的「取消」往往只能回答「本地流程结束了」，回答不了「所有跨供应商执行路径都真的关掉了」。
- **APort Vault**：面向 Agent 支付授权的基准与评测数据集；配套还有 **Closed-World Resolution Against Tool Hallucination**（记录 322 例 Agent 调用不存在工具或传未声明参数，提出「闭合世界注册表 + 签名检查」作为任何 gating 之前的一层，并放出 HTB 基准），以及 **Emergent Collusion in Long-Horizon LLM Agent Interaction**（多智能体长程交互是否会产生串谋）。

同一天的开发者侧其他信号：

## 二、给飞哥的关注建议

1. **今天最该带走的一条是「标价 ≠ 账单」。** Grok 4.7 把「同价、参数 +40%」做成海报，而人工分析量出来的是**单任务成本 $3.74 vs GPT-5.6 Sol Max 的 $1.99**，差 88%，且 xHigh 档每任务烧 8.1 万输出 token（4.6 是 3.6 万）。这个反直觉结论对任何按用量付费的场景都成立：**评测一个模型时，用「完成一个任务花多少钱」而不是「每百万 token 多少钱」**。你现有的模型对比表如果只有单价列，值得加一列 cost-per-task，并且注明推理档位。

2. **Harvey 那个 -50% 是可复制的算术，不是个别事故。** 逻辑很简单：用量涨 20 倍 + 按用量计费 = 毛利被吃穿。任何把「按 token 计费的闭源 API」当核心成本项的产品，都该先算一遍：如果明年用量涨 10 倍，毛利是多少？**答案不好看的，就该开始准备一条 open-weight 的退路**（注意 Harvey 换的是 Kimi K3 这一档开源权重，而不是自研底座），而不是等毛利率转负了再动。反过来说，这也解释了为什么国内开源模型迭代密度这么高对自托管团队是直接利好。

3. **OpenAI 的数学顾问小组是「治理的样板间」，值得当成案例读。** 它的设计很具体：独立、不受薪、可公开发表异议、可自主扩员、愿意服务任何公司 —— 但**明确无权干预研究节奏**，九人里只有一位是此前公开信的签署人，且**核心问题是证明尚未公开**。这类「有独立性、无权力」的结构，未来会在更多领域（生物、材料、芯片设计）重复出现。判断它有没有用的标准不是成员名单，而是**它能否公开过一次让公司不舒服的结论**。

4. **Agent 的授权边界今天被三篇论文同时否掉了三个假设。** 「有人审核就够了」错在审核不等于执行时核验；「模型够聪明就够了」错在挡风险的是工具调用前的确定性检查层；「按下取消就好了」错在跨供应商委派下「取消」甚至还没有严谨定义。落到工程上是一条可执行的自查：**在你自己的 agent 系统里，找出所有「审批画面 / 工具调用 / 委派协议」三层，逐层问一句「这一层有没有工程手段核实过」**。AL 之外，Closed-World Resolution 那篇给的「闭合世界注册表 + 签名检查，放在任何 gating 之前」是可以直接抄的最小实现。

5. **两条关于「信任基准」的信号，方向一致。** 一是 Fable 5 被社区统计出 8 月思考变短（**自己的回归测试集比厂商的稳定性声明更有用**）；二是 HN 头名是一篇标题党、模型发布帖的评论区几乎不谈能力只谈成本结构与延迟史。合并起来看：**榜单和发布叙事的解释力在下降，而可复现的、按任务计价的、带前提标注的本地评测在升值**。如果你要给团队定一条规矩，就定「任何模型选型结论必须附一份能在 CI 里跑的回归集」。

6. **AI 代购这场戏的主角是收银台，不是模型。** 亚马逊封 Muse 的真实理由写在广告收入里（去年 680 亿美元），Shopify 反向接入 Shop Pay 的理由写在商品数据与履约基础设施里。**同样的分裂会在别的品类重演**（旅游、外卖、票务）。对任何做 agent 产品的团队，可操作的一条是：**先确认目标平台是「有 API 且欢迎」还是「靠反爬和条款挡」**，前者按协议接，后者不要指望浏览器自动化能长期跑通 —— 亚马逊已经证明它愿意起诉。
