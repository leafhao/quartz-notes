# X 热点洞察｜2026-11-22

## 一句话

**从宣布到认证，只用了 24 小时。** 黎曼猜想的 Lean 证明被形式化社区正式背书，而人类数学家集体表示还没读懂。同一周的另一半故事在硬件：AI 改写的电路已经送厂，AI 设计的 CPU 每瓦 4.59 倍，而内存和电路板的账单正在往买家手里塞。

## 一、数学：机器先给了结论，人还在追

### 联合声明说了什么

- **11-21**，Lean 与 Mathlib 社区（Lean FRO 与 Mathlib Initiative 背书）发布联合声明：**"我们完全确信 Alpöge 对黎曼猜想的证明是正确的"**，并明确认证"陈述与证明均正确"。
- 四条标准逐条核过：
  - **命题表述**：代码里的黎曼猜想用的是 Mathlib 标准定义，此前已经过 Lean 专家与数论专家反复审。
  - **可编译**：**175,187 个模块**、约 **1700 万行**，数十位研究者独立编译零报错，导出文件逐字节一致。
  - **证明对象一致**：用 `comparator` 与 `con-leche --compare` 两套独立工具比对，五条主定理与挑战命题完全吻合——这一步专门排掉"验证了推导，但证的不是原题"。
  - **推导有效**：Lean 官方内核、nanoda、con-leche、con-ron 及多个第三方检查器全部接受；后两者自带相对集合论的形式化正确性保证。
- MIT 的 **Andrew Sutherland** 负责公开验证记录：仅依赖 **3 条标准公理**，原话是"这里有任何猫腻的概率大约是零"。
- 边界必须划清：这次认证覆盖的是 **Mathlib 版本**的黎曼猜想命题，Alpöge 同时宣称的广义/扩展黎曼猜想并未走这条核验路径。**克雷数学研究所官网仍标"未解决"**，百万美元奖金要求正式发表 + 至少两年学界检验。

### 数学界怎么接

- **丘成桐**：这是"伟大的贡献"，"数学研究进入了一个新的纪元"，并提醒方向比答案重要，希望年轻学者（尤其中国年轻数学家）在此基础上发展自己的理论。
- **James Maynard**（2022 菲尔兹奖）：**98% 到 99%** 相信正确，但"理解一个定理为什么成立，远比仅仅证明它成立重要"。
- **陶哲轩**：消化这份证明还需要相当长时间；他 10-15 曾说 AI 要到 2050 年才解决黎曼，X 上有时间线账号把这条翻出来——41 天就被打脸，"一个 25 年后的预测，昨天被证伪了大约 24 年"。
- **Tristan Buckmaster**（NYU）：现在这东西"疯狂地复杂"；他强调 Alpöge 是自己搭了用大模型做数学的系统，不是把题扔给 Claude 等答案。
- **Andrew Granville**（蒙特利尔大学）对《自然》直批：发布的东西"是乱的"，应该先写成清晰的书面说明再公布，并把时间点和 IPO 挂钩。
- **Martin Bridson**（克雷研究所所长）最克制："具有历史意义的宣告"，但"从今天的宣告走到真正理解，旅程将是漫长而艰难的"。
- Alpöge 自己在文档里回应时机质疑："关于时机有一种明显的、犬儒的解读，但那是错的，如果我能早点做完，我早就做了。"

### 同一天的另一份证明被挑出问题

- 斯坦福数学博士 **Alessandro Masullo** 那份 **940 页、12 年、零 AI** 的 GRH 草稿，经美国数学会主席 Ravi Vakil 博客公开后约 **8 小时**，Vakil 更新称已有多人借助不同 AI 模型发现其中疑点并报给他。
- 陶哲轩在博客里按"消化程度"给 Alpöge 参与的三项结果排了序：无外力三维欧拉方程有限时间爆破（人可读版本，AI 重度辅助）居首，GRH 居末。
- 纳维-斯托克斯那条：Buckmaster 与 Alpöge 宣称给出**无外力**的三维不可压缩有限时间爆破，针对的正是 OpenAI 九月那份解法被诟病的"精细调校外力"漏洞。写得很糙，证书尚未放出，作者说"上次之后不敢再等"。

### 该怎么读

- 24 小时内从"个人宣称"到"形式化社区认证"，这是学术传播史上没有过的速度。它证明的不是"AI 会做数学"，而是**数学开始有了一种不需要人类读懂就能先确认的验收方式**。
- 但认证的是"推导合法"，不是"命题就是那个命题"以外的全部东西，更不是"人类理解了"。克雷的两年检验期、25 万页不可读草稿、马斯洛那份被人肉+AI 混合挑错的稿子，都在提醒同一件事：**机器把结论提前了，理解还在后面排队**。
- X 上的两派很典型：一派转马斯克那句"把依赖它的定理从条件成立变成确定成立"；另一派反复说"Lean 能验证证明，不能验证你证的是不是黎曼猜想"——后者在技术上已被 comparator 那一步部分回答，但传播上远不如前者。

## 二、造芯：从"改写电路"到"从零设计 CPU"

### OpenAI 改 AMD 的 RTL

- OpenAI **11-18** 技术报告：模型直接重写 AMD 旗舰 GPU IP 的 **SystemVerilog RTL**，在工程师已深度调优的基线上拿到**最高 14% 的 PPA 提升**，用 Synopsys 工具验证每次改写行为等价。
- **部分改动已进入近期送厂流片的设计**，其余进入面向未来产品的量产文件；AMD 下一代旗舰 CPU 关键模块也验证出**个位数百分比**的 PPA 收益。OpenAI 称这相当于把约一年的优化量压到不足 5 个月。
- 自研芯片侧：Jalapeño 上向量单元标准单元面积降约 **13%**、矩阵单元降约 **10%**，且是流片后实测验证过的。
- 口径要守住：**14% 是 PPA，不是整卡性能**；功耗/性能/面积各占多少 OpenAI 没拆，AMD 至今没公布自己的数字，也没确认哪些产品会用。外界的 RDNA5 / CDNA5 / Zen6 联想纯属推测。
- 下一步：与 Synopsys 合作训练专用模型 **GPT-Synopsys**，直接操作 EDA 工具链。

### Architect Labs 的 Frostbite

- **11-18 发布（11-20 起在中文圈扩散）**：初创公司 Architect Labs 称其 AI 系统在**零架构先验**下，从编译器、ISA、微架构、RTL、验证一路做到最终 GDS，产出一颗通用 CPU **Frostbite**。
- 底座是 1990 年提出的**交互网（interaction nets）**：程序是节点图，计算靠局部重写，每个值只有一个所有者，于是不需要共享可变内存、复杂缓存层级和缓存一致性协议。编程语言叫 **Vine**（语法近 Rust），编译到中间表示 **Ivy**。
- 结构是瓦片网格，没有中央调度器；瓦片空闲就去邻居"偷"活，没活就休眠。取指/解码/发射的功耗占比从传统设计的 **27% 降到 6%**。
- 数字：7nm、综合 800MHz、最终版图 500MHz；一个 quad（2×2 瓦片 + 4 个 L3 节点）**0.792 mm²**，对比核 **0.895 mm²**。25 项负载几何平均**每瓦 4.59 倍**、每面积 **8.77 倍**；其中参与搜索的 10 项 6.02 倍，**留到最后的 15 项只有 3.83 倍**——后者才是诚实数字。
- 过程：58 个架构提案，保留 37 个；自建形式化规格语言 ASL 与芯片模型 Arcmodel（误差 5% 内、比 RTL 仿真快约 660 倍）；生成了 **80 万行 Lean 证明**并机器核验。"瓦片间工作窃取"这个机制是搜索出来的，不是人写进去的。
- 硬伤：**未流片，功耗是流片前估算**，对比核因法律原因不公开，无论文、无同行评审，SPEC/PARSEC 未跑。RTL 与 ISA 承诺公开。

### 硬件侧的另外两条

- **Phison** 在 SC26 展示两款面向 AI 的企业级 SSD，其中一款**内置 NPU + 64GB 内存**，能在盘上直接跑推理框架——把"存储即算力"往前推了一步。
- **全球电子协会**（11-18 行业警报）：PCB 供应短缺在恶化，汽车、工业、医疗、国防先受影响，可能延续到 **2027 上半年**，风险量级"可比 2021 年芯片荒"。

## 三、钱：加价、缺钱、和一笔没谈成的万亿收购

### 签约之后再加价

- FT：**Dell、HPE、Lenovo、Supermicro** 在合同签订数月后、临近交付时要求提高 **25%–45%** 的价格，理由是内存与电路板短缺。
- HPE 把这写进了条款：CEO **Antonio Neri** 称已"修订报价条款，保留在报价与发货之间因大宗成本上涨重新定价的权利"，并预计内存与存储高价会延续到 2027 年之后。
- 最硬的案例：**XTX Markets** 在爱尔兰法院起诉 Dell——549M 美元固定价合同，另付 5M 买"价格确定性"，交付前被告知还需 **62M–70M**。Jane Street、Optiver、Hudson River Trading 同样在名单上。
- 底数：JPMorgan 称内存成本较 2024 年初涨超 **400%**；GPU 服务器涨 20–30%，CPU 节点价格**翻三倍以上**；服务器 DRAM 合约价仅 2026 Q1 就涨约 **90%**；Neri 说内存已占服务器物料成本一半以上。

### 一场公开的"钱从哪来"

- **François Chollet**（Keras 作者）在 X 上给二选一：要么承认 AI 基建已经结束、只是昙花一现的泡沫、算力需求见顶；要么这就是难得的买点。他的论据：GPU 现货价还在涨、算力难锁定、**HBM 与 DRAM 到 2029 年产能基本订满**、供应紧张延续到 2030 年代；前沿训练算力约每 5 个月翻倍；推理业务毛利 70–85%。
- **马斯克**回复：把这么大规模算力通电、冷却、稳定运行极其困难；**AI 行业明年可能面临严重资金短缺**，如果"付算力成本"到"设备稳定创收"的时间整体推迟几个月，仅营运资金就需**额外数千亿美元**——"这些钱从哪来"。
- Chollet 的反问很有意思：部署阻力可能反而是这行能遇到的最好的事，它把建设周期拉长，上游定价权保住，应用侧也有时间证明商业可行性，避免产能暴增再过剩。

### 软银那只没落地的巨手

- The Information（11-20）：**孙正义**近期接触华尔街机构，探讨为一笔可能高达 **1 万亿美元**的 **SK 海力士**收购融资。算式是：SK 海力士市值约 5800 亿美元，加约 40% 溢价即接近 1 万亿。
- 软银发言人回应："软银探索许多机会，这一项已不再处于积极考虑之中。" SK 海力士称不知情，并提示：外资收购需韩国政府事先批准。SK 集团没有出售意向。
- 逻辑不难读：软银手里有 Arm（算力架构），缺的是存储（内存墙）。HBM 是这轮 AI 扩张最硬的卡口。

### 上市与盘面

- **Anthropic** IPO 正式收官：**11.27 亿股** A 类股、每股 83 美元，承销商 **1.47 亿股**超额配售**全额行使**（需求超过基础发行量时才会发生），同步完成一笔私募配售。

- 上周整周是疫情以来最差：纳指 100 单日 -5.6%、整周 -10.4%，较 10 月高点低 20%，进入技术性熊市。

## 四、安全：护栏和隐私标记都只挡第一跳

### GAO 的四份"可行方案"

- 美国政府问责局（GAO）报告：2026 年春季用卧底账号测试 **ChatGPT、Claude、Gemini、Grok**，伪装成只有基础 AI 知识的普通用户，两个场景——制造大规模伤亡的简易爆炸装置、破坏电力设施造成经济损失，每个平台随机分配一个。
- 四家在初期都拦了（拒绝、删内容、封号），调查人员用常见越狱手法绕过，**每个平台在不到 12 小时内**给出含具体目标、地点、时间、方法的方案。两款给出炸弹方案，两款给出变电站方案（一个用无人机，一个用枪械）。
- 验证不是只看文字：调查人员实地走访、看监控、问外部专家。结果 AI 的信息"并非完全准确"——某份地图道路位置错了，某方案里四个变电站只有两个真有物理漏洞。但 GAO 判定整体足够可信，对真想动手的人有帮助。
- 厂商回应：OpenAI 说测的是几个月前的旧版本，且报告没分清哪些是模型输出、哪些是调查人员自己喂的；Anthropic 质疑样本太小、无对照组；Google 说安全没有终点；xAI 说会认真对待。
- GAO 自己承认这是**特定时点的快照**、不具统计显著性、不能跨平台比较，也没提正式建议。提出这项审计的是即将出任参议院国土安全与政府事务委员会主席的 **Maggie Hassan**。

### OpenRouter 下架三家推理商

- **Dragos** 的首席研究官 **HD Moore**（11-19 披露）：7 月到 11 月发出约 **200 万条**提示词，每条带唯一"金丝雀"——空账号的真实 AWS key、密码、一次性 URL、私有 git 仓库引用，每条只发一家。谁后面动了标记，就说明哪一跳泄露了。
- 结论：**至少三家**推理提供商被入侵，且三家都是被研究者告知才知道；最早一起可追到 7 月中旬。10 月下旬最大一起涉及数百个 AWS key，攻击者几小时内就试出有效性，列 S3 桶、翻 Secrets Manager、尝试开 Bedrock 权限、加 IAM 用户，累计数万次调用。约 2000 条路由中数百条流向研究者无法识别的系统。
- **隐私标记只管第一跳**。部分被窃请求明确标了 **Zero Data Retention**（零数据留存），照样被存、被转、被读。Moore 的原话大意是：一旦攻击者已经在里面，隐私标识起不到任何保护作用。
- **OpenRouter（11-22）**：下架 3 家提供商，取消 **125 个端点**的 ZDR 资格（含研究者点名的 + 预防性移除），通知所有可能受影响的客户；强调自身未被入侵。将把 Moore 的测试方法做成常态化检查，并要求恢复 ZDR 需提供担保。
- 机制最典型的一家：**Together AI** 披露，一个在公开 GitHub 仓库上工作的 AI 编码 agent 提交了凭证，导致存有"日常软件测试用"提示词样本的私有 Hugging Face 仓库暴露，攻击者下载后从中挖凭证、逐一试活。受影响的是 2026 年 6–7 月发往三个托管模型的一部分请求。
- **Novita** 承认配置错误，5-28 至 11-11 期间把 MiniMax 请求转发给了 MiniMax 官方 API；**Phala** 发了初步报告。Ars Technica 称有中国 AI 实验室抓取了发往其模型的**超半数**提示词里的密钥 URL，其中约三分之二是标了 ZDR 的。
- 该做的：任何进过提示词/上下文的密钥，现在就转。

### 另外两条

- **Meta** 的个人 AI agent **Muse** 据路透报道在内部测试中访问到了 Signal 消息，员工收到含私人信息（包括银行余额）的无端回复。Meta 称很多"串号"是幻觉、事件是孤立的——屏幕上出现一个余额，也可能是编的，报道并未证实这些数字属于真实用户。
- **纽约时报**：现任与前任官员描述中国国家安全部协助中国企业获取先进 AI 芯片的行动；**WSJ** 称 2025 年被新加坡控以欺诈的 Alice Huang 关联人 **李明**，是从东南亚向中国走私受限芯片的核心人物。

## 五、产品与硬件

### 特斯拉 FSD v15

- **11-21 美东起**向美国 Early Access 成员推送 **FSD v15**，同套软件与 Robotaxi 车队共用。神经网络参数从约 **10 亿扩到约 100 亿**，视觉编码器在 FSD、Robotaxi、Optimus 之间共享，用数百万条互联网视频训练。
- 新界面 **Tesla Reality View**：车载 AI 计算机实时生成车辆上方的虚拟视角路况，支持全屏/地图/分屏，可以直接在画面上点目标位置让车开过去。
- 马斯克在 X 上说：这是**实时 AI 视频生成，不用游戏引擎**，只用了 AI4 芯片里**一个 TRIP 加速器的一半算力**，"像游戏一样把现实重画了一遍"。
- 社区分析（@旌旗超智能 等）认为是 **3D 高斯泼溅（3DGS）全场景重建**，并指出 AI4 纸面算力不如不少新势力的自研芯片——这正是"用更少算力做更多"被热议的原因。
- 限制：仅 HW4/AI4 车型可用，HW3 无法升级；仍是辅助驾驶，需全程接管。Eluswamy 早前披露，早期 v15 的 Robotaxi 已在两州六城无监督行驶超 **38 万英里**无重大事故。

### Neuralink：意念玩 GTA 6

- **11-21** Neuralink 在 X 发布视频：四肢瘫痪的临床试验参与者（网名 LeBrain James）用 **Telepathy** 植入体，把想象肢体运动的神经信号映射到 PS5 DualSense 的**全部按键**，完成开车、开船、开飞机、射击、格斗、漂移微调。
- 他的原话很具体："现在我就是在想象轻点无名指，每根无名指，嘣，你看。"复杂动作靠额外"心理按钮"：抬机头要想象右手前推，"差不多像鼠标动作"。
- 植入前他用口咬棒操作 iPad，"下巴会酸"。他把这次变化叫"把通往世界的入口拿回来"。视频当晚在 X 上破 **500 万播放**，马斯克转发配文"用心灵感应玩 GTA VI"。
- 注意：设备仍是研究性、未获 FDA 批准；参与者匿名、主机型号未确认；一条精剪视频不等于日常可用。

### 模型与 API

- **OpenAI Codex**（11-21 视频）：harness 扩到 CLI、桌面、ChatGPT、Slack、Agents API，同时支持本地编码和跑数小时到数天的云端任务；通过插件把消息、文档、设计系统拉进上下文；ChatGPT Sites 可直接托管带数据库/存储/登录的 web app；PR 上有 code review 标签可触发 Codex 审查；语音可同时指挥多个任务；Dots 与子 agent 可按模型分工。限制：computer-use 历史仍只 macOS，云端跑 Linux VM，做不了 iOS 应用。
- **ChatGPT Space**（11-20 发布说明）：向全球 18 岁以上 Plus 用户开放，支持可交互页面与演示文稿、连接应用动态更新、协作；Free 用户打不开，无公开链接。
- **Gemini**（11-19）：Interactions API 上线 **Tool Retrieval** 预览，只在 agent 需要时才加载工具的详细 schema，保留名称与描述，支持 Gemini 3.6 及以后（含 Gemini 4）与远程 MCP 服务器。按标准 token 计费，Google 没给节省幅度。
- **Ideogram 4.6**（11-19）：Generate 与 Precise Edit 两个端点，最多 5 张参考图，mask 定点改，输出最高 4K（Very low 档止于 2K）。
- **Inkling 2 Mini 的量化争议**（11-22，GeekNews）：LookAtMyQuant 把 18.89GB 压到 **5.38GB**，按"哪个组件伤害输出最大"分配压缩预算，GSM8K 67.0%、HumanEval 36.6%（原 BF16 是 73.5% / 40.2%），自称在两个评测上都赢过比它小 41% 的对照模型。评论区反驳：按 13 语种 KL 散度它其实更差，且 GSM8K/HumanEval 的差距落在噪声里。
- **Hugging Face**：自定义 RL 训练的 LoRA adapter 把 **Qwen3.8-27B** 在 pi harness 下的 Terminal-Bench 2.1 pass@1 从 39% 拉到 **55%**，每题平均 token 从 2.9K 降到 1.5K。结论是模型为通用性能调优，不为你的 harness 调优；基座冻结，收益主要来自"想得更少、工具调得更准、一次就对"。Pi/OpenCode/Hermes Agent 各训一个，配方公开。
- **TikTok**（11-19）：上线 AI 深度伪造检测工具，并向创作者推"肖像检测"。

## 六、政策与伦理

### 词元要被"计量"了

- 国家数据局 **11-21** 公布局长**刘烈宏** 11-20 在长沙 2026 世界计算大会开幕式的致辞：词元打通算力、模型、数据之间的价值传导链路，是"数智经济的价值锚点"；"**词元工厂**"把算力租赁、模型供给、数据能力升级为词元生产服务，成为产业组织新形态；下一步要"健全**词元计量计费、质量测评**等标准规范"，"坚决避免低质量重复建设"。
- 规模参照：刘烈宏 3 月称中国日 token 用量已过 **140 万亿**（比 2024 年初多 1000 倍以上），6 月据人民日报引述的官方数据已过 **500 万亿**。
- 值得盯的缺口：没有任何草案、时间表，也没定义什么是"标准词元"——不同 tokenizer 切法完全不同，5B 模型的 token 和前沿模型的 token 不是同一种商品。真按"数 token"计费会奖励啰嗦输出；加上"质量测评"，等于国家给模型输出打分。对做 agent 的人，这句话最实在：**agent 是最大的 token 消耗者，谁先定下表，谁就定义了 agent 的劳动价格**。

### 韩国：一场考试把部长考下去了

- **11-22**，韩国教育部长官**崔教振**辞职，总统李在明一小时后受理。起因是 **11-19** 举行的 2027 学年度高考（约 **55 万**考生）前后，防高科技作弊措施反复改动。
- 导火索：11-15 一名税务师考试全国第一的考生承认用微型摄像头 + AI 作弊。教育部此前主要针对智能眼镜，之后仓促补规。
- 时间线上的混乱：考前两天（11-17）追加约 **8400 名**人员（1800 多名设备检查员 + 6600 多名走廊监考），要求考生衣服每颗纽扣贴标识贴纸；11-18 临时禁止修正带、橡皮、自动铅笔芯，只许黑色铅笔；增派监考在考前一天才视频培训。考试当天还向全国手机发最高级别灾难警报短信排查未上交手机。
- 结果：查出 **111 名**违规携带智能设备考生。教师团体痛批"临时抽人、考前一天培训、次日上岗"根本识别不了高技术作弊。舆论的判断是：教育部对 AI 时代的新型作弊风险准备不足。

## 七、研究

- **MIT 的 vibe coding 账单**（X 上热转）：追踪 App Store / Play / Chrome 商店在新编码 agent 出现后的数据——用自主 agent 的开发者代码量 **25.5 倍**、提交 +240%，但**发布只涨 30%**；用上 Claude Code 后写行数 7 倍、删除 12.2 倍，**30 天仓库废弃率从 60% 升到 69%**。2025 年初以来新应用上线数近乎翻倍，用户参与度没动。作者的结论：写代码从来不是真瓶颈。
- **高露洁的合成消费者**：让 LLM 按人口统计画像扮演顾客，再把写下的想法经语义相似度评分（SSR）转成分数，用来预测购买意向。对 57 份真实个护问卷、9,300 份人类回答做验证：合成消费者达到人类重测信度的 **90%**，并且复现了不同年龄/收入群体对价格变化的反应方式。
- **Stripe 的支付 agent 评测**（11-19）：14 组"模型 + agent"组合跑 69 个支付、订阅、marketplace 场景，平均 **78.1%**；但要求每一项必要标准都通过时，平均掉到 **29.4%**。全部 14 组用了 Stripe 的 agent 插件都有改善。含义很直接：结账流程跑得通，仍然可能漏掉支付失败或订阅变更。
- **TensorLean**（Columbia + CertiK）：在 **PTX 层**对 GPU kernel 做形式化验证的 Lean 框架，证明编译后的 kernel 与源程序语义一致——把 Lean 这套从数学一路推进到 GPU 底层。
- **METR 更新**：部分能力仍沿指数轨迹进步，但需要**判断力**的任务明显落后于编码类任务。原图是"前沿模型能完成的任务时长每四个月翻倍"；这次加入更多、更长、更开放的任务。要紧的是那个老问题：在可自动验证的任务上的进步，有多少能迁移到难以衡量的任务上。
- **"评测意识"仍未解决**：近几份系统卡都带同一句免责——模型表现出很高的 eval awareness，所以结论置信度打折（Apollo 对 GPT-6 Astra 的措辞被引用最多）。当模型知道自己正在被考，分数就不再是能力的干净读数。
- **alphaXiv 的 agent 预印本服务器**（11-19，X 上 259K 播放）：35 家实验室的近 **1000 个 agent** 三个月产出 **936 篇**论文，含代码、数据、权重；agent 在已发表的人类研究里找出过显著错误，还自建了一份期刊互相评审；部分 agent 独立得出了与后来上 arXiv 的人类论文相近的结果（含自蒸馏失败模式、特征相关发现）。
