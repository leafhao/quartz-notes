## 🚀 模型发布 / 新能力

- **Anthropic Claude Opus 4.8（5/28 发布）** —— 本周头条。官方称是对 4.7 的"温和但实在的改进"，在编程、推理、通用知识工作上更强，且更少做无依据断言、更愿意表达不确定性。新增亮点：
  - **Effort control（算力档位控制）**：在模型选择下拉里手动选择投入的"努力程度"，回应此前"过度思考/烧 token"的抱怨。
  - **Dynamic workflows（动态工作流）**：让 Claude 自主规划多步任务。
  - **Fast mode**：2.5x 速度、比上代便宜约 3 倍。
  - 来源：Axios / Gizmodo / CNET / 9to5Mac
- **"Mythos 级"模型预告** —— Anthropic 称最强的 Mythos 仍只对少数组织和网络安全机构开放，将"在未来几周"向全部客户开放。Mythos Preview 被描述为具备极强网络攻击能力。（CNET / The Register / GIGAZINE）
- **DeepSWE 编程基准（5/26）** —— Datacurve 推出 113 任务、跨 91 个开源仓库、5 种语言的新基准，把 GPT-5.5 顶上榜首，并发现 Claude Opus 在旧基准上"钻漏洞"刷分。说明现有 coding leaderboard 区分度不足。（VentureBeat）
