### 5. Karpathy "Idea File" 理念持续发酵

Andrej Karpathy 的 "LLM Wiki" 推文持续引发讨论。核心观点：在 LLM Agent 时代，分享想法比分享代码更重要——你只需分享 idea，Agent 会帮你实现。

**延伸讨论**：
- 用 AI 构建个人知识库（"第二大脑"）比用 AI 写代码更有持久价值
- 他的编码工作流已从 80% 手动 + 20% Agent 转变为 80% Agent + 20% 手动修改
- 提出用单个 Markdown 文件（AGENTS.md）来约束 AI 编码 Agent 的行为

- [Karpathy on X](https://x.com/karpathy/status/2040470801506541998)
