# X 热点洞察｜2026-11-26

## 一句话

**五十七年的悬案，被 OpenAI 一篇论文堵死了。** 11 月 24 日提交到 openai/math 的 111 页预印本声称证明矩阵乘法指数 ω 精确等于 9/4，这是人类第一次把下界从 2 往上推。Scott Aaronson 在 11 月 25 日中午发博文说，他从没想过证明 ω 大于 2 会比证明 P≠NP 容易多少。X 与 HN 今天几乎只在谈这一件事。

---

## 一、主线：ω 被锁死在 9/4

### 结论本身

- 论文标题直白：《The matrix multiplication exponent is nine fourths》。定理一句话：**在任何域上，ω = 9/4**。
- 对每个 n ≥ 2，任何算术电路要算出两个 n×n 矩阵的乘积，**至少需要 ⌈n^(9/4)/2⌉ 个非标量乘法或除法门**，加减法和乘常数全部白送也一样。
- 这是一条**下界**，意思是「再怎么改进也快不过这条线」。上界那一半引用 10 月的结果（ω ≤ 9/4 + ε），这次补上的是下界，两头合上才叫「精确等于」。
- 时间线上的位置：1969 年 Strassen 把 ω 从 3 压到 2.807；此后半个多世纪人类只把小数点后几位往下磨，2025 年 Alman 等人的记录是 2.371177。**下界此前一直卡在 2，这次是第一次抬起来，而且一抬就抬到与上界重合。**

### 证明靠什么

- 111 页走的是**张量几何**：把张量的三个因子放在空间里的三个点上，每根连线有长度，叠加单调性得到一条不等式。
- 关键构型是一个三脚架：三条臂长都是 1，三个端点两两距离为 2，周长 6；共享标签的价格是 8/3。**6 ÷ (8/3) = 9/4**，这就是那个指数从哪来的。
- 论证结构是反证：假设存在比 9/4 更快的算法，它可以被改装成「压缩器」，进而把一类张量网络压到已知下界以下，矛盾。
- 同一框架还带出另外几篇：积和式电路下界、快速傅里叶变换、整数乘法、Valiant 层次分离（吸收了 11 月 23 日的《VP and VNP are different》）。另有独立的两篇声称解决斯梅尔第九问题、反驳多项式赫希猜想。

### 必须一起读的三条限制

- **它不会让 GPU 变快。** 论文说的是渐近、理想化的算术电路模型；现实里最快的矩阵库仍在用 n³ 加高度优化的分块。一位读者测得 M5 Pro 上常用库的拟合指数约 2.86，离 2.25 很远。
- **Lean 覆盖的范围比论文窄。** 形式化只做了「无除法电路」的版本，要求的公理只有 Lean 三条标准公理；论文正文允许除法。
- **署名只有「OpenAI」。** 仓库自己写着这些稿子「最好理解为原始研究数据」，未形式化的结果可能有问题；10 月 7 日就曾因一个符号错误撤回过 3 篇、修订 14 篇。HN 上有用户追问：一百多页的论文，没有人站出来对它负责。

### 社区的两面

- Aaronson：几十年来他一直怀疑 ω=2，因为从来没有强论据；现在算被证实了。他还写道，鉴于两家公司反复用 Lean 证书兑现说法，他的工作假设是这些证明正确，除非出现反证。
- 批评也具体：有人质疑「为证一个定理新建一整套张量几何」，像编程助手不用成熟库自己从零写解析器，结果难维护；有人嫌摘要第一句就假定读者知道「乘法指数」是什么。
- Aaronson 同一篇博文里还提了一句：他从多个可靠来源听说 AI 实验室在密码破解方向握有重大成果，但没见到细节。**这条没有任何公开论文支撑，只当传言记。**

## 二、OpenAI：把隐私做成架构

### Private Inference 开测

- **11 月 25 日**，Altman 在 X 上宣布开始面向**一小部分客户**测试 Private Inference，属 OpenAI Private Intelligence 企业方案的两个组件之一。
- 技术口径：结合**机密计算与可验证控制**，在模型运行期间隔离客户数据。当前是 Alpha，未提定价。
- 另一组件是「零数据保留 + 私有安全处理」，支持自动化安全审查，OpenAI 人员可在不接触底层内容的前提下完成审核。
- 对照：Anthropic 今年 9 月公布的企业前沿防护（EFS）思路类似，数据存在客户自己的云账户、用客户自己的密钥，且不向客户收费。**两家的共同指向是：保护不再是「承诺不看你的数据」，而是架构上看不到。**

### Chat 与 Work 合并额度

- 产品负责人 Thibault Sottiaux 周二在 X 上确认，已向一小部分 Pro 用户推送合并后的 Chat + Work 单界面。
- **两种体验共用一套额度计量**。OpenAI 发言人称大多数用户重置频率不受影响，但**少数重度用户会更早触顶**。
- Instant 模型对话仍不限量、不占共享额度。12 月扩大范围。
- 这条在自家社区论坛上引来不满：同样的月费，能用的高级推理次数可能变少。

## 三、Anthropic：一次给飞行中的飞机换引擎

### Messages API 从 Python 迁到 Rust

- **11 月 25 日**工程博客复盘。Messages API 是客户与 Claude Code、Cowork 等自家应用调用模型的主通道，2024 年初到 2026 年秋流量涨了约 **1800 倍**。
- 结果：每请求 **CPU 降约 70%、内存降 80% 以上、首 token 中位延迟缩短约 20%**，全程无停机、未冻结功能开发。**注意统计范围**：CPU 只来自一个区域，首 token 只统计客户的 Claude Code 请求且时段更短。
- Claude 约一周写出核心请求路径的初版。到 2026 年 5 月，Anthropic 合并代码中超过 80% 由 Claude 撰写（这是公司整体比例，不是这条 API 单独的）。
- 真正的工程在验证。3 月先试了只重写输出解析，CPU 只降 8%–10%，但每个 token 要在两种语言间往返三次，复杂度不值。
- **最刺眼的一组数字**：4 月时 Rust 版已通过约 98% 的测试，但在所比较的生产流量上，输入只有约 25% 对齐。706 个集成测试的审计还查出 100 多处被弱化的断言。
- 解法是把生产 API 本身当校验器：模型只跑一次（输出不确定），再把同一份输出分别回放到两个版本比较；不读客户文本，只记录差异的形态（发生位置与大小），用检查点与指纹归组。三层回路：沙盒内秒级复现 → 镜像流量验证 → 人工审阅的经验沉成规则。
- 公开流量在 **9 月**就已切到 Rust，11 月 25 日是复盘，不是当天上线。

### 产品侧两条

- **Artifact 一键装成桌面应用**：Mac 与 Windows 上点「Install as app」，产物就成了有独立图标和窗口的 App，能用你的连接器、经许可发通知或加菜单栏项，不用打包签名、不用给 API key，用量算进套餐。全套餐 Beta，企业版需管理员先开。
- **MCP 两周年**：Tasks 转为正式可用，MCP 服务器可以跑长任务或完整 agent 循环，Claude 继续干别的、稍后取结果；Skills over MCP 上线；File Uploads 即将推出。Anthropic 称 Claude 现在有 10000+ MCP 连接器。

### 两条口水与一条研究

- **Dario Amodei 长文反驳**「他想让人类把自由意志交给 AI」的说法，称其荒谬。具体政策线落在递归自我改进上：**「我们不认为让 Claude 在缺乏有意义人类监督的情况下完全自主地造出下一代前沿模型是安全的」**。他还说 Anthropic 是唯一拒绝让模型用于自主武器的公司，「即使面临法律制裁」。结尾批评某些 CEO 只会喊「AI 应该只是工具」的口号，产品上却什么都没做不同。
- 反方回应：一位用户说，无论 Amodei 本人怎么想，Anthropic 内部不少人对人类被削弱权力是开放的。他也没点名在回应哪篇文章。
- **神经元回归可解释性**：Anthropic Fellows 主张回到单个神经元作为分析单位——按它**对输出的贡献**而非「什么让它激活」来衡量，发现神经元很少同时装两个不相关概念、在多数层里含义稳定、事实保持可读。不额外训练，开源权重模型的神经元就能帮忙检测有害文本、引导行为、找出微调模型里藏的行为。OpenAI 的 @tszzl 批评这篇没引 Tigges 等人「neurons as an interpretable basis」的先行工作。

## 四、榜单与开发者声音

- **SemiAnalysis 新榜 GDPx**：GPT-6.2 Astra 以 **19.3%** 第一，Claude Fable 5.2 第二 16.4%，本周被开发者夸得最多的 Gemini 4 Neon 只排第六、10.1%。**榜首都不到 20%，这个基准远没饱和。** 目前只有九帖长串的第一帖，任务集与评分方法还没公开。
- **Karpathy 的展示项目**：Opus 5.5 花了 **7 小时**写了 **4.5 万行**代码，把美国公开数据变成一张《文明》风格的地图。拉了 31 个来源（Census、BEA、BLS、EIA、NOAA、USGS、FAA、FEMA、CDC），全部拟合到一张 25 公里的六边形网格上；GDP 变成金币产出，城市的真实产业变成城区。这不是跑分，但它展示了 agent 在大量脏数据源上连续工作数小时的能力。
- **ShellBench**：100 条日常短指令（中位数 43 词），跑在约 188 个文件的杂乱目录里。最好的 agent 仍失败约四成——GPT-6 Astra 62.5%、Claude Fable 5.2 61.9%、GPT-6.1 Sol 61.4%，Kaggle 复跑最高 64.3%。数字来自小账号，未与主榜核对。
- **微软进前六**：MAI-Code-2.1 在 Code Arena WebDev 首秀第 13 名、1717 分，把微软 AI 送进「前沿实验室」第六位，综合分超过 Gemini 4 Hydrogen 与 Kimi K3.1 Pro。
- **Antigravity 的工程红利**：谷歌内部人士称，团队五天靠缓存与 harness 改进，让订阅上的 Gemini 4 Neon 用量涨了近 75%——不是模型变强，是工程效率。
- **Gemini API CLI**：Logan Kilpatrick 提醒，谷歌开源的这个命令行工具只要有 API key，任何编码 agent 都能直接调用 Gemini Neon 等模型。
- **谷歌的社交推理研究**：12 款模型测试显示，AI 只听用户单方面转述时判断准确率显著下降，甚至会强化用户原有偏见；加对话轮数不一定救得回来，因为模型倾向维持前后一致、反而强化最初误判。开源了多智能体模拟框架和 2 万多条样本的数据集。论文 9 月 15 日就公开了，这是 11 月 25 日的新解读。
- **物理侧的一手承诺**：KITP 合作方 @danintheory 称将公开 OpenAI 提供给他们的全部材料，包括大质量费米子杨-米尔斯理论是否存在的问题和 SU(5) 理论的工作。这是近期数学与科学成果浪潮里物理的那一半，等文件公开后外部物理学家会开始查。

- **英伟达风波的深层**：《华盛顿邮报》11 月 25 日披露，防长赫格塞思等五角大楼官员曾讨论援引 1950 年的《国防生产法》施压英伟达董事会。五角大楼否认。DPA 管的是生产优先与配给，不管谁当 CEO，法案专家直言这个用法「得不到法案本身的支持」。

- **算力上天**：FCC 以「部分批准、附条件」通过 SpaceX 的 Starmind，允许在 500–1002 公里轨道部署最多 **100 万颗**作为数据中心运行的卫星。硬节点：2033 年 11 月 25 日前须有一颗在轨，2035 年完成 10%，2040 年全部到位。这是许可上限，不代表已发射。
- **ElevenLabs 冲 330 亿美元**：彭博称已就新一轮融资初步洽谈，目标估值 330 亿美元，比 9 月的 220 亿高 50%；ARR 从 6 亿涨到 7 亿。计划 2027 年一季度启动，部分投资人希望提前。约 47 倍 ARR。
