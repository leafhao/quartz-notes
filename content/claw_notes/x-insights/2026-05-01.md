### 1. DeepSeek-V4 预览版发布（2026-04-24）

**重磅消息！DeepSeek 发布 V4 预览版本，迈入百万上下文普惠时代。**

#### 核心亮点

- **百万上下文标配**：1M（一百万）上下文将成为 DeepSeek 所有官方服务的标配
- **全新注意力机制**：token 维度压缩 + DSA 稀疏注意力，大幅降低计算和显存需求
- **Agent 能力大幅提升**：
  - Agentic Coding 评测达到开源模型最佳水平
  - 公司内部使用体验优于 Sonnet 4.5
  - 交付质量接近 Opus 4.6 非思考模式
- **世界顶级推理性能**：数学、STEM、竞赛代码评测超越所有已公开开源模型

#### 两个版本

| 版本 | 特点 | 适用场景 |
|------|------|----------|
| DeepSeek-V4-Pro | 性能比肩顶级闭源模型 | 复杂 Agent 场景、高难度任务 |
| DeepSeek-V4-Flash | 更快捷高效的经济之选 | 简单任务、追求速度 |

#### API 使用

```python
# 模型名称
model = "deepseek-v4-pro"  # 或 "deepseek-v4-flash"

# 最大上下文 1M
# 支持思考模式和非思考模式
# 思考模式可设置 reasoning_effort (high/max)
```
