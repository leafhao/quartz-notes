## 对大模型工程的启示

1. **把安全监控从 prompt 扩展到行为链路**：单轮内容过滤无法覆盖批量生成、跨站传播、工具滥用和多账号协同。
2. **Agent 默认最小权限**：外网写入、跨域访问和 Agent 间通信应显式授权，并具备预算上限、审计与紧急关停。
3. **社媒只做线索层**：对模型能力、科研突破和融资数字，至少回到一个官方来源或两家独立媒体核验。
4. **儿童场景需要独立产品栈**：身份与年龄信号、风险分类、危机干预、监护人机制不能仅靠通用聊天安全策略拼接。
5. **MCP 生态要按供应链治理**：每个 server 都应被视作第三方执行依赖，而不是普通插件。
