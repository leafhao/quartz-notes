# X 热点洞察｜2026-11-13

## 一句话

三十三年的皮夹克脱下来了：黄仁勋辞职即刻生效，英伟达盘中跌 14%，华尔街一夜之间把目标价砍掉三分之一到三分之二。同一天谷歌补上 Gemini 4 的最后一块——不是更强的模型，而是更便宜、更快的执行档，还让模型自己决定由谁来跑。

## 一、英伟达换帅：33 年结束（11-12）

- **公告怎么说原因**：没说。只写「感谢黄仁勋不可估量的贡献」。此前彭博、路透报道的是两起婚外情指控，独立董事聘外部律所做独立调查，另有股东集体诉讼——**公司口径与媒体口径必须分开写**。

## 二、Gemini 4 Hydrogen：补上执行档，让模型挑模型（11-12）

### 规格

- **定位**：Gemini 4 三件套的最后一块。Carbon／Argon 管长周期深度推理与难软件工程，**Hydrogen 管日常写码、调工具、连续执行的杂活**。
- **价格**：**1.50 美元／百万输入、7.50 美元／百万输出**，**整个 100 万上下文窗口统一计价**。原生支持 100 万 token 输入与最高 100 万输出。低于 Argon。
- **四档思考**：low／medium／high／**xhigh**（新档）。
- **分数（官方口径）**：Artificial Analysis 智能指数默认 high 档 **51**，xhigh **54**——**都高于定位更高的 Argon 的 50**，Carbon 是 60。对比上代 3.8 Flash：任务完成快 **2.5 倍**，Terminal-Bench 4.1 从 **18.2% 升到 57%**，虚构内容减少 **5 倍以上**。Agent Arena 实时榜第 5，HLE-Diamond 58.8%，Vals Tax Agent Bench 52.3%。自报 agent 诚实度 **96.7%**。
- **安全**：官方称把 agent 执行中的越界行为最高减少 **81%**、服务不足最高降低 **79%**、思维链可读性 99.9%。
- **铺开面**：Gemini API、AI Studio、Gemini 应用、**全球所有用户的 Google Search**、Antigravity（付费订阅）。免费用户在自动模型选择里就能用到。

### Orchestrator：把「该谁跑」做成产品

- Antigravity 新增模型选项：**Carbon 当协调者**，先拆任务、只读探索、出计划；**Hydrogen 接手写码跑测试**；一卡住就交回 Carbon。全程不手动切。
- 官方数据：Terminal-Bench 4.1 上任务成功率接近单用 Carbon，**额度消耗少 24%、完成快 19%**；先向 AI Ultra 开放。
- Carbon 带的 `/swarm` 并行 agent 开关，首日已跑出数万个 swarm。

### Search 这一刀最实在

- Robby Stein（Search 产品副总裁）称这是 **Search 收到过的最大一次模型更换**；Hydrogen 成为 **AI Mode 的默认模型**，并承接 AI Overviews 里最难的问题。
- 官方说改进 **query fan-out**，能连到「比以前更广的有用链接」、帮人找到「以前可能发现不了的站点」——**这句话没有引用数、没有新域名占比、没有第三方验证**。
- 时点尴尬：Schwartz 指出发布撞上核心更新；他的解读是只动生成式界面、不动核心排序（**这是他的判断，不是谷歌声明**）。一周内两次模型更换，引用变化很难归因。
- 值得盯的格式：比较表与定制工具。以前靠「我做了这张对比表」拿点击的页面，现在对比表被答案自己重建，链接沉在下面。

### X 上的反应（三个真实发帖）

- **@SPAC89**：用 Hydrogen Extra 做了个 Three.js 项目，不到两小时，80% 时间在渲染，**只耗 AI Pro 订阅 5% 的周额度**；说第一次觉得 20 美元的 Pro「近乎没有额度限制」。
- **@mattyapro**：「每天真在用的模型，比登顶排行榜的模型更重要。」
- **最好笑也最要命的一条**：有人问 Hydrogen 自己该用哪个档，它说这些代号**都不存在**，并坚称**不支持联网搜索**。一个搜索能力大改的模型，不认自己的名字。
- 冷水也合理：答错了，重跑的代价可能高过一次慢而准的回答；自动路由把「选模型」交给一个系统性高估自己的东西，HN 上不少人宁愿手动分档。

## 五、agent 开始坐进会议室（11-12）

### Claude Meetings：从预告到上线

- 11-11 只是发布会上的「预告」，**11-12 起在 Team / Enterprise 套餐 beta 上线**，Web 与桌面端。
- **怎么用**：Claude 作为**可见参会者**进入 **Google Meet**（首个也是目前唯一平台），喊一声「Claude」或在聊天框里问；默认用文字回答，用某个人的连接器要先得到那个人同意。
- **边开边做**：现场写纪要、待办，能建 **Docs / Whiteboards / Slides** 并让被邀请的同事同时改。会前从日历加入，设自动加入（可排除一对一），单场最长 **8 小时**。
- **隐私默认值比功能重要**：默认**不进入有外部人员的会议**，外部人员中途加入就退出（管理员可放开）；只存转录、摘要、屏幕描述，**不存音频**；加入时在聊天里发通知。beta 期对**零数据留存、HIPAA、自管密钥**的组织不开放。
- **钱**：beta 期纪要、转录、口头回答在两种套餐都免费；用了连接器的回答计入额度；会中产物免费到 **2027-02-10**。
- **伙伴**：Gong、Attention、Granola、Fireflies.ai、Otter、Plaud 将可接收转录。
- **边界**：只有 Meet，没有 Zoom／Teams 时间表；模型用的是哪个没写；beta 后怎么收费没写。

### Grok Bot 1.0：一个 bot 服务整个团队

- **11-11 晚在 X 发布，正式出 beta**（SpaceXSI，即改名后的 xAI）。
- **变化一：共享**。Team Bot 像文档一样共享给整个组织或指定群组；同事用它，Manager 改它；它随使用积累团队的知识、偏好与决定——**从一个同事那里学到的东西要等 owner 或 Manager 批准才生效**。
- **变化二：主动**。它会盯项目、发现 deadline 提前备料、追未完成任务、需要人判断时把人拉进来。
- **变化三：进会议**。把会议链接粘给它，由主持人准入，听、记、在聊天里答、会后发摘要与待办；支持 **Google Meet、Zoom、Teams**。参会人列表里它的名字带「transcribing」三个字——**这是唯一的提示**。
- **代价与坑**：每台 bot 一台云端电脑，**只在美国**，文档里有美国数据驻留计划但没有 EU 选项；Teams 里会读它加入的所有频道；Team 套餐**每个成员默认都有、没有开关**；Enterprise 才有留存设置、审计日志、网络控制。价格 **30 / 100 / 200 美元**（Premium／Super／Ultra），Team／Enterprise 走销售。
- **同日还有 Mac 端 1.0**：打通**七个苹果应用**（信息、邮件、备忘录、提醒事项、日历、位置、通讯录），每个应用单独一个 Allow 按钮。

- **必须写清**：这是**起诉与请求，不是法院命令**；截至报道时被告未作实质回应，Meta 拒绝置评。被告可以打原告资格、法条适用、损害具体性、救济可执行性。佛罗里达州 6 月诉 OpenAI、9 月请求禁止无外部监督开发新模型，仍在审；另有八州 10 月起诉。

### IBM 收 AuthMind

- 未披露金额，整合进 **HashiCorp Vault**，做 **IBM Agent Identity**：把凭证发出去之后的 agent 行为也管起来——发现影子 agent、检测异常、实时吊销。IBM 风投 2023 年投过它的种子轮。

## 八、研究：RSI 进预训练，agent 成本被两头压

### 把「递归自我改进」搬进预训练（arXiv + @dair_ai 11-12）

- SII 的 GAIR 团队与 Xinxu AI：用 agent 驱动的循环，在**一次**前沿预训练 run 上做改进，产出 **801-30B-A3B**——一个开放 30B MoE 底座，**打赢 Qwen3-30B-A3B 与 Nemotron-3.5-Lightning-30B-A3B**。
- 具体做法：把「一次几十万 GPU 小时、只能跑一次」的大 run 拆成**能闭环的小循环**——agent 调基础设施与数据、用小型 SFT 跑探针看后训练余量、把专家判断变成数据管线的指标；**共享上下文库把负结果留给所有人**。
- 关键结果：**只用 6B token 的 SFT、不做 RL**，在四个 agent 基准上的平均分就高于**做完全后训练**的模型（含 Qwen3.6-35B-A3B）。
- 边界：论文自己说这条 run **不可复现**；六条数据管线、130+ 基础设施版本这些数字来自 DAIR.AI 的解读页，**不在摘要里**。

### 便宜 agent 的两条路：重造服务端，压小模型

- **Evolving Infra**（MIT Han Lab，arXiv 2611.12304）：现有 PD 分离把机器角色写死、用粗信号逐 KV，agent 要复用的缓存被扔了。它把算力与 KV 管理解耦、节点可在线切换 prefill／decode、用在线规划器配比，并让 **agent 自己的上下文管理信号**决定留什么。在 GLM-5.2、Kimi K2.6、最多 256 张 GB300 上，对比 NVIDIA Dynamo：端到端时延与 P95 首 token **最高降 4.1 倍与 14 倍**。
- **SteerDistill**（arXiv 2611.13410）：4 比特 agent 的失败方式是固定的——漏看任务要求或环境条件。让全精度教师盯着它错的那几轮改、在环境里验证改对没有，再蒸馏进学生。五个 agent 基准、三个模型上，W4A16 **比最强量化基线高 1.67—2.18 分、距 BF16 不到 1 分**，训练 GPU 小时比 QeRL 少 67%。
- 两篇都是作者自测自报；「最高 14 倍」是最好情况不是均值。

### LiquidCodec：单核 361 倍实时（11-12）

- Liquid AI 开源 **73.6M 参数** 流式音频编解码器，替代此前用的 Kyutai Mimi（96.2M），是 LFM3-Audio-2B／Omni-2B 的底层。
- **量化方式换了**：不用 RVQ（每个码本修前一个的残差，token 必须顺序预测），改用 **GFSQ**（分组独立量化），于是 12 个 token 可以**并行预测**；解码器直接预测频谱系数，跳过学习式上采样。
- 数字（M4 Max 单 CPU 线程，FP32）：编码 **361 倍实时**（RTF 0.0028，Mimi 是 0.0361）、解码 87 倍；八个测试集上 ViSQOL 全胜、梅尔距离最低；LibriSpeech 上 WER 3.15% vs Mimi 6.27%。
- 边界：日文、中文、韩文的**朗读错误率反而是四家里最高**（日文 7.29%）；许可为 LFM Open v1.0，**年营收 1000 万美元以上要商用授权**。

## 九、X 上的讨论：那组 89% 该怎么读

- Menlo Ventures《2026 企业 AI 现状》报告（**11-03 发布，这两天被大量转述**）：2026 全球企业 AI 支出预计 **1768 亿美元**；美国企业的**开源模型支出**里 **89%** 流向中国模型——Kimi **61%**、DeepSeek **15%**、智谱 GLM **11%**、Qwen 3%；Meta Llama 只分到 7%。
- **同一份报告里更该看的一组**：开源模型占企业 token 消耗从 **11% 升到 19%**，但占**支出**从 **6% 降到 4%**。用量涨、钱没涨。
- 配套数据：OpenRouter 11-02 至 11-08 全球总调用 **210 万亿 token**，中国模型 **116 万亿**（55%），连续 **28 周** 超美国；DeepSeek V4.1 Flash 单周 53—56 万亿，连续三周第一。
- **两种解读都要摆**：一边是份额真的拿到了（Lindy 换 DeepSeek 后推理成本降约 95%，Coinbase 用 GLM／Kimi 做常规任务、AI 支出压缩近一半）；另一边是**这 89% 算的是调用量口径下的支出份额，不等于利润**——中国模型承接的多是成本敏感的批量任务，权重开放后单价只会向推理成本收敛。
- 一个自证：智谱上半年营收 9.54 亿元、开放平台与 API 占 86.5%，API 毛利率从 -0.4% 转正到 24.6%，同时单位 token 推理成本较年初降约 80%；Kimi K3 定价较前代涨超三倍、MiniMax 全面翻倍——**国产模型已经在做价格分层，不再只靠便宜。**
