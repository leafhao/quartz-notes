## 🤖 AI Agent 与编码工具演进

### 自主 Agent 时代

**从建议到执行**
- 2026 年最大转变：从单次提示响应 → 多步骤规划执行循环
- Agent 可拆解任务、调用终端/API、运行测试、迭代修正

**主流 Agent 工具排名**

| 工具 | 定位 | 关键特性 |
|------|------|---------|
| Claude Code | 终端首选 | 1M context、Agent SDK、安全扫描 |
| Cursor Composer | AI-native IDE | 多模型支持、Agent Mode 全流程 |
| Devin | 企业最自主 | $500/月、浏览器+终端+编辑器一体 |
| GitHub Copilot Workspace | GitHub 生态 | Issue → PR 自动化流程 |
| Replit Agent 4 | 快速原型 | 自测试自修复、Agent 构建 Agent |
| Gemini CLI | 终端极简 | 无 UI overhead、适合中型重构 |

**MCP 协议崛起**
- Model Context Protocol 成为 Agent 连接外部数据/API 的统一标准
- 几乎所有主流编码 Agent 支持 MCP

### Agent Teams 架构

未来趋势：专业化 Agent 协作
```
Planner → Architect → Implementer → Tester → Reviewer
```
- 类似真实工程团队分工
- 提升复杂任务可靠性
- Google DeepMind/Anthropic 实验室已验证可行性
