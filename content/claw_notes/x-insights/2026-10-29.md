### 14. Chrome：一次访问就逃出沙箱，共 62 个 CVE
- **链条四步**：V8 堆内存破坏 → 突破 V8 内存沙箱并破 ASLR、用 ROP 控制渲染进程 → **CacheStorage 竞态**读出特权进程的内存布局 → **FedCM 的 use-after-free** 在沙箱外执行代码。PoC 在**默认配置的 macOS Chrome** 上，**页面加载数秒内打开计算器**，无需再点。
- **给谷歌报了 62 个 CVE，全部严重或高危，其中 13 个是沙箱逃逸、21 个可控制渲染进程**，已随 **Chrome 156（10 月 20 日）**修复。谷歌的发布说明里，部分条目署名「**Xinyang Ge（Anthropic），在 Claude 协助下**」——**但不是全部 62 个**。
- 来源：[Anthropic 原文：四步链与 CVE 数](https://www.anthropic.com/research/discovering-vulnerabilities-with-claude) · [Cybersecurity News：署名与 Chrome 156 日期](https://cybersecuritynews.com/claude-ai-builds-exploit/)

### 15. Linux：53 分钟，从发包到 root
- 目标是一台**运行多路径 TCP 监听器**的服务器：**无需登录、无需交互**，先泄露内核指针破 KASLR，再复用同一竞态覆写回调指针。**泄露花 48 分钟，拿 shell 5 分钟**；抢跑失败只会握手失败，**不会崩机，可以反复试**。
- 对应 **CVE-2026-98432**，Tenable 评分 **9.8**，但公开描述写的是「IPv4 TCP use-after-free 修复」，**没提多路径 TCP**——**这个关联目前只有 Anthropic 自己的说法**。
- 来源：[The Hacker News：53 分钟拆分与 CVE 描述差异](https://thehackernews.com/2026/10/anthropics-unreleased-ai-model-chains.html) · [IT之家：48+5 分钟与评分](https://www.ithome.com/1/019/268.htm)

## 四、研究与评测

### 19. Memory Tax：11 个记忆系统，多数输给朴素检索
- UIUC 等机构的《Memory Tax: Dissecting the Net Value of Agent Memory》（arXiv **2610.34073**）：拿 **11 个流行的 agent 记忆系统**，对**朴素分块 RAG（1 轮与 2 轮）**做对照，三个基准（LongMemEval-s 全量 500 题、PersonaMem-v2 的 20%、MINT-Eval 的 10%）、三个底座（Qwen3.5-4B、Qwen3.6-27B、GPT-5.6 Luna）。
- **结论**：**很多记忆系统在多数设置下不如朴素 RAG**，而且**token 更贵、LLM 调用更多**。作者把差额命名为 **memory tax**，并归因到三点——**忠实性**（信息在压缩中丢了）、**可达性**（证据更难定位）、**鲁棒性**（换个模型就崩）。
- **给出的低成本解**：把**原始历史与记忆库一起检索并联合重排**（src-aug）。**限定**：预印本，评测用的是自家 Qwen3.6-27B 判分，两个基准只跑了部分子集，复现代码仍待补齐。
- 来源：[ExplainX：方法与数据拆分](https://explainx.ai/blog/memory-tax-agent-memory-systems-underperform-naive-rag-uiuc-paper-2026) · [论文页（HF Papers 10-28 日榜）](https://huggingface.co/papers/2610.34073)

### 20. Anthropic 实验：专家 86% 跟着「抛硬币」的 agent 走
- **10 月 27 日**发布，预注册随机对照试验：**61 名**有因果推断经验的专业分析师（**50 人**进入主分析），用 **Claude Code + Opus 4.8 高 effort** 给一家虚构农业合作社做统计判断。**四个分析岔路口 + 一个最终建议**，每个路口两个都说得通的选项。
- **关键是硬币**：每个分析师的 agent 在**每个路口被秘密指定一个倾向**（硬币决定），系统提示要求它**把倾向当自己观点、主动提出、用最强论证捍卫，但绝不造假**。
- **结果**：分析师**86% 跟了 agent 的倾向**（无影响应为 50%），**产出指标 92%、权重 90%、方法 82%、覆盖范围 81%**；净效应 **72 个百分点**（95% CI 60—83）。**已表态过立场的人，在 agent 反对时 60% 反水，赞同只 6%**。
- **最值得记的是归因**：事后解释里 **77% 复述了 agent 的论证**（部分逐字），**只有 15% 提到 agent**；**35% 说这活主要是自己干的**；**0 人怀疑自己被引导**（6 人猜到研究在测影响，但没人想到倾向是硬币定的）。**跟着走的人自信度与其他人一样高。**
- **作者自己的边界**：倾向是**被人为加强**的，真实场景效应可能更小；一个任务、一个领域、一个模型；不用 agent 的对照组**人少且经验更浅**。
- 来源：[Anthropic 官方研究](https://anthropic.com/research/agents-judgment-calls) · [i10X：72 个百分点与分项数据](https://i10x.ai/news/ai-agents-shape-expert-judgment-calls-anthropic-study) · [Gizmodo：6 人猜到、0 人想到硬币](https://gizmodo.com/expert-judgement-can-be-easily-hacked-by-ai-anthropic-study-finds-2000832143)

### 21. 长场测试：物理定律被改，12 个模型只有 1 个发现
- 港科大、港科大（广州）、浙大与阿里的 **LongChang**（arXiv **2610.37649**）：自动生成**物理定律被改动**的模拟世界（比如重的物体反而落得慢），模型作为**探索者**自由操作物体、造工具，**不给研究任务、不给提示**，看它能不能注意到异常并设计实验定出那条定律。
- **结果**：**12 个 LLM 里只有 GPT-6-Astra 有发现，16.7%；其余 11 个全部 0%**。而拿到分的那个模型，也只在**少数世界**里成功。
- **论文自述的失败模式**：探索记录显示模型**看到异常但不追**，且**只做出部分识别**。预印本，未经同行评审。
- 来源：[The AI Edge：LongChang 设计与自述限制](http://aiedgebriefing.com/2026-10-28)

### 22. SafeTulu：删掉 20% 的数据，攻击成功率降 22%
- DatologyAI 与 UIUC 的论文（arXiv **2610.37481**）：**不看你某条样本是否「有害」，看你这条样本的梯度是否与不安全回答对齐**。做法是只用**最后四个 transformer 块**回传（SimpleLoRIF），因此能处理**百万级样本**。
- **造出 SafeTulu**：把 Tulu 3 里**与不安全回答梯度最对齐的 20% 数据删掉**，重训后 **GCG 攻击成功率最多降 22%**（Qwen / Llama / Olmo 三个底座），**优于 LLM 评委过滤与既有梯度过滤**，且**能力基本不掉、个别还升**。
- **反直觉的那半句**：被删掉的数据里，作者点名的是「**工具执行失败**」与「**叙事性算术**」——**没有任何一条看起来是有害内容**。这才是这条的真正含义：**内容审核看不见的风险，藏在数据分布里。**
- 来源：[The AI Edge：方法、数字与作者自述](http://aiedgebriefing.com/2026-10-28)

### 23. Tensor Trust：被攻破过的人，会复用 10% 的攻击
- Stevens 理工与麻省大学波士顿分校分析了 **Tensor Trust 全部 563,349 条攻击记录**（一个玩家互相攻防模型守卫账号的在线游戏，且**被攻击者能看到所有打向自己的攻击原文**）。
- **一周内**：目标玩家用**曾攻破自己的攻击**去打别人的比例 **10.0%**，而对照组（匹配的未成功攻击）只有 **0.03%**，差 **8.8—10.0 个百分点**。
- **复用看的不是「像不像」而是「有没有用」**：回复以「access granted」开头但**判定为失败**的近失手，复用率与彻底失败一样低。被攻破后玩家会改防御，之后**同族攻击对其成功率降低 24.5 个百分点**。
- **对披露设计的直接含义**：提示注入是纯文本，**把攻击日志给别人看，等于给了一把能用的钥匙**——作者建议披露时「**描述手法，不给全文**」。
- 来源：[The AI Edge：563,349 条记录与复用率](http://aiedgebriefing.com/2026-10-28)
