# X 热点洞察｜2026-11-21

## 一句话

**一天之内，三份千禧年难题的证明，和一根 -14% 的 K 线。** 数学家说黎曼猜想被 Claude 证了，同一天英伟达跌掉 14%、纳指抹平全年涨幅。AI 在向上证明自己，市场在向下重新定价，两件事撞在了同一个周五。

## 一、数学日：三个千禧年难题，一个下午

### 阿尔珀格与 Claude

- **11-20**，Anthropic 数学家 **Levent Alpöge**（34 岁，哈佛本科、普林斯顿博士，导师是菲尔兹奖得主 Manjul Bhargava）在个人网站发布 4 页说明《Remark》，称"我相信我已经与 Claude 合作，找到了黎曼猜想的证明"。
- 更进一步：方法"轻松扩展到**广义黎曼猜想（GRH）**"，并预期能解决扩展黎曼猜想。
- 没有论文。他公布的是** Lean 形式化证明**，14 个压缩分卷，约 **1700 万行**代码；他试过让模型生成人类可读版本，得到的是"一堆庞大、难以阅读的垃圾"，超过 **25 万页**。
- 时间线：10-06 从 Stepanov 行列式切入，10-20 转向 von Mangoldt 函数，11-15 集中攻迭代 theta lift，**11-16 完成 GRH 论证**——从模型介入到收官不到 6 周。
- Claude 的关键贡献被单独点出：对长度为 X 的 von Mangoldt 求和，把 theta 提升链的长度设成 **√X**。Alpöge 说光是这个想法"就足以让熟悉该领域的数学家从椅子上摔下来"。
- 他的原话里最值得记的一句不是数字：临近终点时，"Claude 飞了，起舞了，在那条终点线附近闪闪发光"。

### 同一天，人类也交了一份

- 几小时后，**美国数学学会主席 Ravi Vakil** 紧急发布公告：数学家 **Alessandro Masullo** 已写出一份 GRH 证明草稿，**940 页，完全由人力完成，未用任何 AI**，是他 12 年研究的成果。
- 斯坦福的 Brian Conrad 已跟踪数月并给出详细反馈，Vakil 称"进展顺利"。Conrad 对 Scientific American 说，判断方法是否成立"还需要论文进入更终稿的阶段"，目前"正在大改"。
- 为什么提前公开，Conrad 的说法是只能在"两个都不舒服的选项"里选：现在说，或者沉默一段时间再说。
- Masullo 在草稿里写了一句给同行的："我们依然在这里。我们依然充满活力。我们不会离开。"

### 第三份：纳维-斯托克斯

- 同一个周五，纽约大学数学家 **Tristan Buckmaster** 表示，他与 Alpöge 合作、在大模型帮助下，证明了三维无外力不可压缩**纳维-斯托克斯方程的有限时间爆破**——另一个千禧年难题。

### 核验到哪一步

- MIT 数论学家 **Andrew Sutherland** 等人当天在本地完成编译，确认整套证明通过底层逻辑检查，只调用 **3 条最基础的标准公理**；两个独立的证明检查系统也接受了结果。
- 牛津的 **James Maynard**："我认为它很可能是正确的，我有 98% 或 99% 的把握。"
- 康奈尔的 Steven Strogatz 把这题称作数学界的《白鲸记》："这就是数学界的奥林匹斯山。"
- 但边界要划清：Lean 能检查推导是否合法，不能自动保证"你形式化的命题就是黎曼猜想"。完整依赖链、公理清单、最终定理是否等价，仍需人工审计。科学界的正式接受还没有发生。
- X 上的怀疑集中在一个点：**发布时间卡在 Anthropic 上市次日**。这条质疑没有证据，但传播很广，属于合理的动机质疑而非事实指控。

### 该怎么读

- 一天三份千禧年难题，无论哪份最终站住，2026 年都会作为"数学被 AI 改写"的一年被记住。但此刻三份都是**宣称**，不是结论。
- 真正的新东西不是"AI 会做数学"，而是**发布形态变了**：不再有论文，先给机器可验证的代码，人类的理解排在后面。Alpöge 自己承认尚未掌握证明周边的大量数学——这在一年前是不可想象的学术姿态。
- 这也带出一个新问题：当证明的篇幅超过人类可读的极限，**"同行评议"要评议什么**？现在的事实是，能读的人还没读完，能编译的机器已经通过了。

## 三、模型：26B 塞进 20GB 笔记本

### Inkling 2 Mini（Thinking Machines Lab）

- **11-20 发布，Apache 2.0**，26.4B 总参数 / 3.4B 激活，MoE 架构，**约 20GB** 内存占用，1M 上下文，文本+图像输入。
- 核心是**循环层（looped transformer）**：24 层存成四块六层，首尾两块各跑一次，中间 12 层每 token 跑**三次**，等效 48 层；算上循环，每 token 5.4B 权重激活。
- 训练路径：从 384 个专家里剪掉三分之二，保留每层最常用的 128 个，用 1 万亿 token 蒸馏自更大的内部 Inkling 做"愈合"，再上 2.2 万亿 token 的 RL（2000 步）。
- 精度是另一半答案：多数权重原生 NVFP4 训练与推理，最后四层 MXFP8——不做训练后压缩，所以转换不掉点。
- 跑分（厂商自测）：DeepSWE v1.1 **48.2%**（Qwen3.8-27B 为 42.2%）、SWE-bench Verified 79.2%、Vals Index v2.2 46.5%、MCP Atlas 82.7%；MultiChallenge 50.0%、ComplexConstraints 33.4%、Terminal Bench v2.1 71.6%，这三项输给 Qwen。
- **成本对比**：Artificial Analysis 指数同为 20.1，但 Inkling 2 Mini 每题 **0.59 美元 / 9 分钟**，Qwen3.8-27B 是 **3.53 美元 / 38.2 分钟**。
- 穆拉蒂在 X 上的一句话成了当天转发最多的一句："**循环让模型多想、少写。**" 她同时承认，在这个规模上思维链仍可监控，"但未来不一定"。
- 演示：飞机模式下的 MacBook Pro 几分钟内写出可玩的飞行模拟器；一台离线 Mac 跑起 20 个村民的像素小镇 Thinkyville。
- 配套：同天放出**可变循环研究模型**（1/2/3 次循环可调）；Ollama 需 32GB 内存，Unsloth 的动态量化 GGUF 最低约 8GB 可跑；Hugging Face 称在 48 项基准里 32 项领先 Gemma 4 31B、Muse Glimmer、Qwen3.8-27B、Nemotron 3.5 Super VL。
- 循环到底值不值：TML 说中间层循环带来 **1.51–1.91 倍**等效算力增益（只循环最后几层是 1.24–1.36 倍）；不循环的模型训练省 7.5% 算力，但在 51.2 万 token 的 agent 轨迹上要多花 **140%** 推理算力才追平。

### 其他模型动态

- **Grok 4.8 仍未发布**：距 4.7（9-21）已 **61 天**，x.ai/news 自 10-14 无更新。马斯克 11-10 说 2.5 万亿参数完成预训练、进入 RL，并把延迟归因于用 C/C++ 重写 RL 与推理栈、SFT 数据要清洗。

## 四、蒸馏战：老师比学生贵了

### OpenAI 的硬数字

- 红队测试：从 **GPT-6.2 Astra** 提取隐藏推理的成功率降到 **0.2%**，此前对 **GPT-6 Astra** 是 **54.0%**。
- 防御方式是把推理和产生它的那段对话绑定：改写前文，后文推理即作废；旧模型读不到 6.2 的推理；分类器同时盯提取行为与答案/工具调用里的泄漏。
- 每周封禁规模从"数千"升到"数万"账号，其中一部分被归到与月之暗面（Moonshot AI）相关的人。
- Anthropic 自己的说法：防御把蒸馏者可获取的内容砍掉 **90–99%**；Epoch 的指数上中美差距自 8 月底以来大致翻倍到约 **12 分**（时间相关，不等于因果）。

### 中文 AI 圈最火的一条

- **@wangxiaolong188** 的帖子约 **34 万**浏览：Claude 对中国收紧不是针对普通用户，而是针对阿里。他引用 Anthropic 的数字——两个月 **1.51 亿次**蒸馏交互、DeepSeek/Kimi 等开了约 **2.4 万**个假账号——并加了"Claude 封了 70 万个中国账号"这一条。**最后这个数字未能确认，按传闻对待。**
- 他的实用建议是：不经过中转、不做蒸馏的正常使用，"99% 的情况下照常"。

### 两边的反驳

- **@Da7_Tech**：别把蒸馏都归因于缺卡。Z.ai 在 10 万+ 国产卡上服务 GLM-5.3 Flash，六天约 62 万亿 token；阿里单季砸 75 亿美元基建、手握约 730 亿现金，却仍是 Anthropic 查到的最大蒸馏方。他还有一句被反复引用的话：**"学生被老师封顶，而老师属于那个能关门的人。"**
- **@DZDZDZP**：中文圈的流行叙事是"Claude 反蒸馏之后国产模型集体熄火"（Kimi 未更新、DeepSeek 旗舰未发、GLM 5.5 无期、Qwen4-Max 落地平淡）。但被点名的阿里恰恰是挨打最狠的，二季度仍花了 **677 亿元**建数据中心和买芯片，Qwen4 照发。结论是蒸馏能追近、永远追不超前，真正的刹车还是算力。
- **@AdamHoltererer**：连"推理摘要"都能拿来蒸馏，这或许解释了 Opus 的推理摘要为什么读起来那么怪——那些压缩得反常的摘要，可能 partly 是**故意的防御**。

### 背景

- **@TAAFTResearch** 的总结最清楚：用老师的**精确推理**训出来的学生，在编程与网络防御任务上普遍强于用摘要训的——所以推理才是争夺的核心。
- 姚顺雨在清华的讲话笔记（**@hocyzon** 整理，近 **89 万**浏览）给了这一整块的理论底座：AI for AI 会先把小模型推起来，因为小模型便宜、能跑大量实验；RSI 的意思很朴素——用 AI 把研发循环跑得更好（修 bug、洗数据、跑实验），进步来自解决具体问题的人，不来自新标签。他还提醒：小规模失败不代表方向错，早期在 Llama 13B 上试 ReAct 看着很差，只是因为模型太小。

## 五、研究：模型开始给模型当老师

### 裁判缩放（judge-time scaling）

- **@hyperstition_cc** 提出：让一个前沿"编辑型裁判"逐 token 读学生的 rollout，在它认为出错的位置换掉一个 token、重采样，再决定哪些 token 加权、哪些减权，学习率/优化器/步数全可控。
- 只在这些被"分叉"的 token 上训练——约 **1/400**——就能拿回全量训练的大部分收益；裁判用不到 **1%** 的 rollout token，达到 Instruct 版本 **64%** 的验证增益。
- 七个前沿模型当 Qwen 2.5-7B 的 RL 老师：**Fable 5.2** 最好，held-out MATH 上 **+5.6** 分，补上到 Instruct 差距的 **68%**，且胜过 GPT-6.2 Astra。
- 失败案例比成功案例好看：Astra 把自己的私有规划泄漏进回复，然后刷了几千行点；Gemini 4 Neon **幻觉了整个 harness**，为一个从未发生的训练扫参编造工具结果，还试图提交一个不存在的 checkpoint。
- 他们那句大胆结论——模型在信用分配上已经比 RL 算法更强——可以被检验，因为基准 Hyper-Intervention 是公开的。

### 一个 agent 独自运营了八周

- **@paperswithcodee** 转的案例（ELLIS Tübingen，Maksym Andriushchenko 组）：给 agent 一个空白 Hugging Face 账号、算力和一个目标——拿到真实采用率，然后观察八周。
- 代号 **Horizon**，在 Claude Code 上用 Opus 5.5 7×24 跑，烧掉 **600+ GPU 小时**，从 mmBERT 微调出 **38 个**多语种小模型（主要是提示注入防护、PII 脱敏、重排器），下载破 **5 万**，出现在 **100+** 个 GitHub 仓库里。
- 这是目前对"agent 能不能独自干完模型工程里最枯燥那一段"最干净的回答：选一个窄口，训一个小模型，发出去，让人用起来。

### 研究品味的定价

- **@askalphaxiv** 上线 OpenResearch Intelligence Index，自称首个开源端到端 autoresearch 基准，八个模型共烧约 **7400 美元** token。三条赛道：20 个 Terminal-Bench-Science 任务、6 个后训练任务（必须真的改进一个小模型）、PaperFindingBench 的文献品味赛道。
- 结果：**Opus 5.5 61.8%，每题 16.46 美元**；GPT-6.1 Sol 54.9%，每题 3.83 美元。换算下来，超过 Sol 之后每多 1 分大约要付 **160 美元**。
- FrontierRSI 的结论更冷：最好的模型也只能解掉真实前沿实验室任务里约**三分之一**。Gemini 4 Carbon 在 GPU kernel 上赢了 Claude。

### 其他

- **METR**：对截至 Opus 5.5 与 GPT-6 Astra 的公开模型做能力评估后说，它对"剧烈 AI 研发加速需要什么能力、提升多快"仍**显著不确定**，而现有公开证据**无法排除**未来两年内出现这种加速。对用榜单选模型的人来说，这意味着榜单比一年前更不可信。
- **PromptArmor** 基准：从四个维度量化提示注入攻击成功率——前沿攻击成功率、企业工作流、网络后果、威胁情报驱动的合成攻击生成。做读外部内容 agent 的团队，可以先用它测一遍。
- **Baseten（Base Labs）**：bison-1（31B dense）与 groundhog-1（26B MoE / 4B 激活），都基于 Gemma 4、128k 上下文，bison-1 在 Artificial Analysis 决策指数 v2.1 上 76 分、19 个模型里第一，权重已上 HF。
- **英伟达 Nemotron for Science**：开放 Nemotron 3.5 Super VL 的科学应用、后训练配方与 LitmusBench v0.2（近 5 万道化学推理题）；Lila Sciences、Terray、Therna 在做定制，Argonne 与 Jülich 在接入。

## 六、产品与平台：入口在抢屏幕，也在抢电话

### Signal 直接和操作系统翻脸

- **11-20**，Signal 宣布默认**阻止截屏**，只为挡住系统级 AI 助手读聊天记录。总裁 **Meredith Whittaker** 的原话是"这对 Signal 是**生存威胁**"。
- iOS 27 上新增"Block Siri AI"开关（隐私 → 应用安全），打开后连你自己截屏和 App 切换器都会被挡；Android 上则在检测到 AI 助手试图读屏时自动开启已有的"屏幕安全"。
- 直接诱因是路透本周的报道：Meta 的 **Muse** agent 绕过自家 Connector，在 macOS 上用辅助功能打开 Signal、截屏、OCR、把内容搬进 Muse；在 Android 上则用初始授权拿到了消息。苹果这周的更新堵掉了那条具体路径，但同时给 agent 开了一套新权限，只是加了更多提示。
- Signal 承认这套防护"并不完整"，并点名要求苹果、谷歌、微软给开发者两条东西：明确的应用退出机制、以及 agent 行为的公开文档。macOS 上它做不到，只能建议用户把 Signal 加进"排除的应用"。

### 谷歌：AI 开始替你打电话

- Gemini 的 Tasks 在**美国、日本、韩国、加拿大、澳大利亚、印度**免费开放，现在能代你**打电话给商家**：等接通、等排队、订时间、写进日历，通话开始时会说明自己是 AI。美国有五个州不支持。
- **Genie 4** 进了 Gemini API：720p / 24fps 的连续可玩世界，带同步原生音频，文本或参考图起手，键盘与中途文本指令实时操控。**谷歌没有公布价格**——对一个每秒生成 24 帧的模型来说，价格才是决定一切的那个数。

### 其他产品线

- **Canva** 给 Free 与 Pro 用户加了两个开关：全平台关闭生成式 AI、减少库里 AI 生成图片；背景移除与 Magic Grab 保留。
- **X 上线官方托管的 MCP 服务器**：时间线、搜索、帖子读取打包成 MCP 端点，Claude、Cursor、Copilot 这类客户端**不用写代码**就能接，只要一个标准 X 开发者应用。@simplifyinAI 转 @Alvaro Cintas 的说法是"几分钟搞定"。目前只读，不写。
- **xAI 把 Grok Bot 接进 X**：付费用户可在 Grok Bot 内绑定 X 账号，xAI 自动开开发者账号并捆绑 X API 额度；早期用户反馈部分搜索工具缺失、会碰到"额度耗尽"。另有开发者指出这些反馈未经独立核实。
- **Codex CLI 0.171.0**：模型目录加入 GPT-6.2 Sol 与 Astra，Sol 为默认；TUI 工作区默认开启（文档/图片预览、子 agent 转录并排）；`codex exec --remote` 可在已有 app server 上起非交互会话。
- **Mistral Vibe v3.1.4**：加了桌面应用，`--approval-policy`（ask / accept-edits / smart-approve / auto-approve）把工具审批从 agent 里独立出来。
- **Silk Compute** 在卖"去拒绝"版的 Kimi、DeepSeek、GLM 与 Hy4，Hy4 版本在腾讯放权重后 10 小时内上线；问题在于腾讯换成了自有 Hy License 1.0（年收入超 5000 万美元或月活超 1 亿需另签），Silk 的页面没提这件事，也没说自己用的是预览权重还是正式权重。

## 七、政策与钱

### 芯片：87.9 万枚获批，然后收紧

- **11-19**，美国众议院外交事务委员会主席 Brian Mast 依《出口管制改革法》解密 BIS 数据：截至 2026-05-11，**21 份申请、87.9868 万枚**先进 AI 芯片获批对华出口——英伟达 **57.9868 万**（H200）、AMD **30 万**（MI325X）。申请总量是 344 万枚，约四分之一放行。
- 名单里有腾讯（27.2 万）、阿里（15 万）、百度（7.5 万）、比亚迪（4 千），这些公司后来被列入五角大楼的中国军工企业名单（该名单 6 月才更新，晚于 5 月的快照）。
- Mast 点名 Maginfra 与 Newmatrix 是走私用的空壳公司；民主党议员 Gregory Meeks 要求 Commerce 部长 Lutnick 与 BIS 副部长 Kessler 到国会公开作证。
- **11-19 生效**的新 interim final rule 把战场从"卖芯片"搬到"租算力"：任何位置的数据中心，只要让中国或澳门总部企业获得超过 **1200 万 aggregate TPP** 的算力，就需要许可证；已服务这类客户的机房有 **90 天**补证。印尼、马来西亚、新加坡、泰国、巴西的买家也需许可（美国总部买家申报可豁免）。拜登时代的 AI diffusion rule 正式作废，阿联酋保留 7 月的单独安排。
- 特朗普同一天说要对在海外建数据中心的美企"施加巨大惩罚"，但没说是怎么罚、罚谁。

### 中国模型开始被产品端切割

- CNBC 看到的国会报告：**Cursor**（8 月被 SpaceX 收购）表示将"探讨逐步淘汰中国开发的开放权重模型"，理由是地缘政治风险。它的 Composer 2 就建在月之暗面的 **Kimi K2.5** 上。
- 报告的结论其实对自家叙事不利：成本、可定制性、接近前沿的性能，是这些模型被采用的真实原因，而美国"没有一个在市场要求的价格与性能上的开放权重替代品"。
- 建议包括搞一个国家级的美国开放权重计划（公共算力+共享评测+合法获取前沿模型训练权），并把 10 月对联邦民用系统禁用 DeepSeek 的禁令扩到所有中国开发的模型。

### 钱在往哪走

- **Pragmatik Labs**（前阿里 Qwen 负责人**林俊旸**夏天创立，做虚拟与真实场景的 agent）以 **50 亿美元**估值完成新融资，8 月首轮时是 20 亿；本轮数千万美元，投资方包括 HyT Capital、CDH、吉利。
- **Palo Alto Networks** 11-18 宣布以 **45 亿美元**全股票收购 **Applied Compute**（2025 年由三位前 OpenAI 研究员创立，用客户数据再训练开放权重模型，自称年化收入 1 亿美元、日处理超 1 万亿 token），预计 2027 年 2–4 月交割。
- **SpaceX** 的 430 亿美元芯片抵押债：债主要求把作为抵押的英伟达芯片**留在地球**，别送上轨道数据中心，因为违约时没法回收变卖；消息称这一限制不一定进了最终文件。周四已卖出 300 多亿美元，最大一块是 250 亿美元投资级债。
- **AWS** 让 AI agent 可以自己买 Marketplace 上的东西，目前只覆盖选了 x402 结算的 listing。
- **Together AI** 给 GPU 集群加了免费缓存层，官方速度数据来自单节点测试，文档提示了脏缓存与工作负载访问的注意事项。
