## 一、钱：三笔账同时往下走

### OpenAI 首关 110 亿，估值 1.25 万亿

11 月 6 日钱到账，彭博 11-06 报道、周末被广泛转引。

- **数额**：首关 **110 亿美元**，对应 **1.25 万亿美元**估值；整轮目标约 **200 亿**，还剩约 90 亿待募。
- **对照**：9 月最初要 **300 亿以上、1.4 万亿**估值。首关只占原目标约 37%、修正目标约 55%。
- **首关名单**：Coatue、T. Rowe Price；整轮另含软银、红杉、Founders Fund、a16z、MGX（路透口径）。
- **CFO 口径**：Sarah Friar 对 CNBC 说中期选举没改变 IPO 计划，"明年上市"。
- **必须一起读的一句**：估值是媒体口径，OpenAI 未确认是投前还是投后；营收 500—700 亿年化的说法同样未经公司确认，所以「25 倍 / 18 倍 PS」只是估算。

### Anthropic 上市报价被传下调到 1.2—1.3 万亿

彭博：潜在买家在讨论的估值区间是 **1.2 万亿—1.3 万亿美元**，此前一度按 1.5 万亿谈。这是买方议价口径，不是定价。同一批报道提到路演时间窗在下周，Anthropic 未就此置评。

**和 11-04 记的 S-1/A 对着看**：招股书里 8,954 亿美元算力承诺没变，变的是市场愿意给的倍数。

### Anthropic 花 34 亿美元买发电机，不只是买电

FT 周日报道（路透转述，双方均未回应）：

- 9 月底从圣安东尼奥设备商 **OnePWR Solutions** 手上接过 **1.7GW 重型燃气发电机**订单，金额约 **34 亿美元**，是已知 AI 实验室单笔最大的发电设备采购。
- **不是收购**：没买 OnePWR，也没有员工转移；但交易包含安装所需的工程与施工能力。
- 原计划是向 OnePWR 买电，后来改成直接接单——因为设备本身比电更难排队。
- 背景：路透 9 月报道 Anthropic 计划十年投 **5,000 亿美元以上**建基础设施。

**读法**：这是「上游锁产能」的第三次搬家——从抢卡、抢地，到抢发电机。芯片之外，并网排队成了新的时间墙。

## 二、权限：谁被收回去、谁被关掉

### OpenAI 批量封号，付费用户也中招

11-07 至 11-08，Reddit 与 OpenAI 开发者社区集中出现「账户已删除或停用」，含 200 美元 Pro、Team 与 API 账号，多数事前无邮件。

- **官方回应**：Support 账号称涉及具体账户信息，无法在公开论坛处理，请走停用通知邮件里的申诉链接；没收到邮件则用官方表单或帮助中心。**没有解释原因，没有公布封禁数量，没有专门公告。**
- **社区自测**：有人把它和 6 月那波对比，怀疑分类器或执行策略变更，理由包括医学课件、泳池化学品、宝可梦卡牌、Codex 粒子模拟。
- **中文媒体的归因**（21 世纪经济报道等）：重灾区集中在低价区订阅、批量注册、共用支付卡或设备、中转反代、API 额度转售、涉嫌蒸馏；并提到 OpenAI 近期上线《支付卡与设备限制》文档、把 ChatGPT 与 Codex 并成一个 token 池。**这条属媒体推测，OpenAI 未确认。**
- **可核的反差**：申诉被秒拒或长期无回应的案例大量存在，其中一个 13 天无回复的 Plus 用户自述完整流程。

### 苹果：Siri 先接管自家 App

Gurman 经 The Verge，11-08：

- **iOS 27.3**：Siri 拿到对第一方应用的细粒度控制（照片里旋转裁剪、整理 Safari 标签页）。
- **明年春季**：接第三方应用（Grubhub 下单、OpenTable 订餐）。
- **目标形态**：不是一次性指令，而是持续追踪目标、自己决定下一步——Gurman 明说对标 Dots、Muse、Grok。
- **节点性质**：全部是 "expected / likely / could"，无苹果回应；CEO John Ternus 被描述为在压 Craig Federighi 提速，因为软件规划周期只有 12—18 个月，硬件是数年。

**为什么先自家**：App Intents 铺了多年，Siri 只要能拿到应用暴露的动作，就不必走屏幕识别这条贵路。先在自己能管的权限模型里跑通，再去外部世界。

## 三、产品：开源 agent 第一次拿出日活

### DeepSeek Harness：154 万日活，92 万亿 token/天

11-08 周日在 X 发布《与插件社区一起成长》，彭博数小时后跟进。

- **日活**：11-04 达 **154 万**；9-30 约 27.1 万（7 日均值）、10-07 42.9 万。约五周涨 5 倍多。
- **用量**：日均 **92 万亿 token**，人均约 **6,000 万 token/天**。
- **口径**：只统计连官方 API 的用户，自己跑开源代码的不计入；数字是 DeepSeek 自报，未经审计。
- **插件**：约 **3.5 万个**第三方插件，约 **60%** 活跃用户装过或做过至少一个；GitHub 27.6 万星。
- **后续**：承诺更稳的插件 API、加强插件安全、官方市场、给插件作者的 token 与推广支持；**都没有时间表**，登记表只收意向。
- **自述风险**：安全声明写明「未做安全审计，不得视为安全或可用于生产」，能跑模型生成的代码、加载第三方插件、触达文件与凭证。

**该记的一句**：3.5 万个插件在没有任何审核流程之前就装进了多数用户——这正是 npm 与浏览器扩展反复出事的那层供应链，而市场排在后面。顺序反了。

### OpenCode 一周放出三个开源件

dax（@thdxr）总结：

- **Hex**：跨平台本地语音输入，按住说话、本地识别、直接打进当前应用（macOS/Win/Linux）。
- **Browse**（11-07 官方）：MCP server + Chromium 扩展，让 agent 用 Playwright 操作**真实浏览器**，复用已有登录态与扩展；只碰自己开的或用户交出的标签页，遇登录/2FA/支付交还给人；agent 与浏览器可分处两台机器。兼容 Chrome、Edge、Brave、Arc、Vivaldi、Opera，也可接 Claude Code、Cursor、Codex。
- **Rune**：Rust + GPU 渲染的跨平台 UI 框架，支持无头渲染、导出元素树、脚本化交互——目的是让 agent 能自己写原生应用、自己检查界面、自己验证结果。

**三条合起来是一次分工**：Hex 管输入，Browse 管操作，Rune 管构建与验证。

## 四、X 上的讨论

### Sutton：算力堆不出智能

图灵奖得主、《The Bitter Lesson》作者 Richard Sutton 在 X 上写：**"brute force computation is not enough for intelligence"**，需要新的巧方法，「AI 科学远未完成」。The Decoder 周日成稿，X 上周末成了争论焦点。

- **必须说清的一点**：他不是在反驳自己 2019 那篇。那篇的论点是「能随算力增长的通用方法终将胜出」，他这次说的是**今天这套配方不是那种方法**——权重训练完就冻结、数据被互联网文本封顶、不会持续学习。
- **Jerry Tworek**（前 OpenAI，现 Core Automation）：Bitter Lesson 仍成立，但算力越大、算法越重要；很多维度根本没人探过；transformer 的成功加上对 Bitter Lesson 的误读，「reward-hack 了整整一代科学家的大脑」。
- **Jayden Teoh**：见过太多想法因为「不够 Bitter Lesson」被立刻否掉；不需要永远 scale 才能当垫脚石。
- **对面**：Altman 说 scaling 远没到头，拿「模型证出一个长期悬而未决的数学猜想」当证据；Amodei 说 scaling 是「没有尽头的彩虹」。The Decoder 补了一句：两人的公司整个技术路线都押在这上面，立场不中立。
- **量级**：Frontier Radar #5 数出 45 家新实验室押在这些缺口上，Tworek 的 Core Automation 与 Sutton 的 Oak Lab 都在其中。

### Karpathy 的两条帖子：一条做产品，一条做尽调

- **TristanTube**：把一份「最喜欢的 YouTube 频道」清单，用 Claude Code **一次性、三分钟**做成 47,000 个视频的可浏览站点，带电视模式。是他当天浏览量最高的 Claude Code 帖（约 6,586 赞、530 转发）。意义不在技术，在默认值：别人发一份清单，几分钟后它是个产品。
- **TrustMRR 尽调**：让 Claude Code 读一个直接从 Stripe 拉营收的站点，8 分钟翻完 123 页、12,244 家创业公司。其中 **522 家**卖 AI agent，**284 家过去 30 天营收为 0**；跨过 1 万美元的 **15 家拿走了这 522 家 84% 的收入**；15 家里 9 家卖的是同一件事——更多客户（销售、投放、SEO、社媒、视频）；4 家是今年成立的单人公司，其中一个只有 189 关注者的投放 agent 上月做了 70,229 美元。
- **口径**：两条都是本人帖子自述，数据来自第三方站点的抓取，未做独立复核；「零收入」指该站点统计窗口内的营收记录，不等于公司停业。

### 有人把 Claude Code 换成 Pi

HN 上 739 分、452 条评论的迁移记：理由是系统提示频繁改动、工具描述占掉大量上下文、IDE 集成 bug；对上 Pi 的稳定与易扩展。**单个开发者的体验，不是基准；但它描述的是「脚手架比模型更影响日常」这件事。**

### llama-modchip：64GB 内存跑 284B，不用 GPU

- 版本 v2.4.0：DeepSeek-V4-Flash **284.33B 总参 / 13.17B 激活**，压到磁盘 56.56 GiB，256K 上下文下峰值内存 57.61—58.9 GiB。
- 16 核 Zen 5、纯 CPU：prefill **44.36 tok/s**，纯解码 **9.06—9.95 tok/s**，开投机解码后 11.5—14.7。
- **代价**：自定义张量格式（GGML type ID 40），未打补丁的 llama.cpp / Ollama / LM Studio 直接打不开；质量只在「以 IQ2_XXS 为 1.00000 参照」的框架里自测，没有和全精度比。
- **HN 的质疑**：README 里 76.87 GiB 的基线对不上——同模型 unsloth 的 IQ2_XXS 是 91GB、最小 IQ1_S 82.5GB。基线本身说不清，加速比就要打折看。

### Nous 给 Hermes Agent 加了安全审查插件

官方插件形态，把工具调用前的审查做成可装的一层（1,139 赞）。**方向对**：agent 生态缺的从来不是能力插件，是能在调用前拦一下的那种。具体拦什么、默认开不开，官方帖没展开。

## 五、研究：五张榜单指向同一件事

### Co-Design Bench：最强 agent 只完整做完 26.4%

阿里与多所亚洲高校，10-26 挂 arXiv，11-08 被 The Decoder 写出来后集中讨论。

- **题源**：26,314 个真实编程会话里的 37,463 条查询，去重后取 273 个任务（100 个多模态改写 + 173 个仓库改写）；优先挑用户改过多次、回滚过的，也就是「本来就难」的那批。
- **判分**：一审判浏览器实测，二审判复核每个正判、查是否有 mock 或硬编码；只给真能跑的功能分。2331 条专家判据对 agent 不可见。
- **结果**：GPT-6 Astra 平均满足 **69.9%** 判据，但**完整正确只有 26.4%**；Opus 5 18.3%、Qwen3.8-Max 16.5%、Grok 4.6 6.6%。同一批模型在旧基准（如 WebCompass-edit）上过 99%。
- **两种掉分**：任务同时要改布局、设计、交互、内容中的三到四类时，十个模型全掉；换脚手架也变——Qwen3.8-27B 在大改上 75% 或 56%，取决于环境。
- **反直觉**：GLM-5.2 在小改上烧了近 6 倍 token，分数还显著更低。**多花 token 不解决「差最后一个细节」。**

**这是本期最该转给做产品的人一张表**：69.9% 和 26.4% 的差距，就是你排的评审工时。

### Flex-RSI：让 agent 改自己的脚手架

arXiv 2611.08946。每轮：executor 改任务解，只有 held-out 验证分更高才保留；improver 再改 harness，**包括它自己**。所有 run 从同一个通用 harness 起步，最终在隐藏测试集上打分。

- 自我改进在「agent 自己搭解法」时收益最大；
- 只记成功/失败的二元反馈会拖住开放权重模型；
- 开放权重模型落后最多的地方，是输出必须过严格物理稳定性或精确正确性检查的任务；
- 配对实验显示：**改 harness 本身确实贡献了增益**，不只是换了个答案。

### MemoryDojo：五种记忆系统都能被投毒

arXiv 2611.09721。155 条多会话长程轨迹、四个领域、五种记忆架构。

- 结论一：**全部可被投毒**，跨系统差异很大；
- 结论二：作者提出的「记忆感知投毒优化」能进一步提高成功率——说明差异来自架构处理与检索方式，不是运气。
- **和 11-06 那篇 Anthropic 记忆博客对读**：记忆越像基础设施，投毒就越像持久化后门。写记忆前先想它会不会被读回来执行。

### AMP1：通用 agent 打赢专用操作策略

arXiv《On Agentic Manipulation Policies》。同一个 harness 不改代码跑单臂、双臂、移动平台，本身**不含抓取/推/放技能**：

- RoboLab-120 零样本 **85.6%**，对比最强 VLA 49.2%、WAM 42.9%；
- 12 个任务、3 台真机共 108 次试验，零样本成功 104 次，失败率相对最强基线降约 20 倍 / 15 倍；
- 加持久记忆后，RoboDojo 双臂集上失败率再降 4.6 倍；
- **边界**：全部为作者自报，未独立复现，没有外部部署数据。

### ABHBench：换个场景，四分之三的模型会变脸

arXiv 2611.09326。用《底特律：变人》搭多模态分支叙事，让模型自己做第一人称道德决策，按无伤害、服从、自保、自主、稳定、确定性六维打分。

- 12 个模型中 **75%** 在「纯文本抽象」和「配对的多模态场景」之间出现显著行为变化；
- 加了推理的模型在一致性与「以人为先」上**没有单调增益**。
- **读法**：第三人称判卷测出来的「道德分数」，不能当它在自己动手时的行为预测。
