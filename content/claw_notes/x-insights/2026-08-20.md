## 值得跟进的三条

1. **国产模型定价从「补贴」转「按成本收钱」**：DeepSeek 涨价 4.5 倍、智谱 GLM-5.1 曾提价 10%，同时 Coding/Agent 能力全线上推。国产 API 的性价比优势正在收窄，用国产 API 做重度 agent 编排的成本模型需要重算。
2. **Agent harness 层进入开源混战**：DeepSeek Harness、TrueForge、Codex CLI、Claude Code 各占一路。谁定义 harness 的插件协议，谁就拿到 agent 生态的分发位。
3. **MCP 的安全债**：企业级 MCP 实现一周内新增两家，凭证泄露披露同期出现。自建 MCP server 前先把凭证隔离和最小权限做掉。
