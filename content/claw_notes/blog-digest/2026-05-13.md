- **摘要**：Nathan Lambert 实地走访杭州、上海的主要中国 AI 实验室后发表的第一手观察。他认为中国团队在端到端栈（数据、架构、RL 算法实现）上的精细化工程传统，使其成为"完美的快速跟随者"。文章指出中美顶尖实验室在科学人才和算力基础上趋同，真正的差距体现在组织方式、研究分工和对多目标优化取舍的文化。

## 2. How open model ecosystems compound
- **来源**：Interconnects — Nathan Lambert
- **链接**：https://www.interconnects.ai/p/how-open-model-ecosystems-compound
- **发布日期**：2026-05-12
- **摘要**：承接上一篇的后续思考。Lambert 引用 Ai2（Olmo 3）和 Epoch AI 的新研究，指出前沿模型的**约 80% 算力花在 R&D 阶段而非最终训练**。因此中国式高参与度、开源优先的生态可以通过互相复用研究成果、减少重复投入，形成比闭源对手更优的成本结构，从而"比外界预期跑得更久"。

## 4. vLLM V0 to V1: Correctness Before Corrections in RL
- **来源**：Hugging Face Blog — ServiceNow-AI
- **链接**：https://huggingface.co/blog/ServiceNow-AI/correctness-before-corrections
- **发布日期**：2026-05-06
- **摘要**：ServiceNow 团队迁移 PipelineRL 从 vLLM 0.8.5 (V0) 到 0.18.1 (V1) 的工程复盘。作者坚持"先修正后端一致性再调 RL 目标"，定位并修复了四处差异：rollout logprob 处理、V1 运行时默认值、inflight weight-update 路径、以及 fp32 lm_head 最终投影。实战参考意义强，适合所有做 PPO/GRPO/GSPO 在线 RL 的团队。

## 5. EMO: Pretraining mixture of experts for emergent modularity
- **来源**：Hugging Face Blog — AllenAI
- **链接**：https://huggingface.co/blog/allenai/emo
- **发布日期**：2026-05-08
- **摘要**：Ai2 发布 EMO——一种端到端预训练的 MoE 模型，让模块化结构从数据中自然涌现而非依赖人工先验。实验显示**只用 12.5% 的专家**就能保持接近全模型性能，且专家更倾向专精于高层能力（数学/代码/领域知识）而非标准 MoE 里常见的"介词/标点"这类低层词法模式。已开源模型、技术报告、代码和可视化。

## 6. Using Claude Code: The Unreasonable Effectiveness of HTML
- **来源**：Simon Willison's Weblog
- **链接**：https://simonwillison.net/2026/May/8/unreasonable-effectiveness-of-html/
- **发布日期**：2026-05-08
- **摘要**：Anthropic Claude Code 团队 Thariq Shihipar 倡议在与 LLM 交互时**用 HTML 替代 Markdown 作为输出格式**。HTML 允许模型嵌入 SVG 图表、交互式组件、页内导航，远比纯 Markdown 表现力丰富。Simon 认为这打破了自己 GPT-4 时代因 8K 上下文养成的 Markdown 默认习惯，值得在 PR review、漏洞解释等场景尝试。

## 8. Import AI 456: RSI and economic growth; radical optionality for AI regulation
- **来源**：Import AI — Jack Clark
- **链接**：https://importai.substack.com/p/import-ai-456-rsi-and-economic-growth
- **发布日期**：2026-05-11
- **摘要**：Jack Clark 本期重点介绍 Institute for Law & AI 提出的"Radical Optionality"监管思路：不是"管 vs 不管"的二选一，而是政府**先不过度监管、但同时大手笔投入建立透明度/报告/审计/吹哨人保护等制度能力**，以便未来 AI 引发重大冲击时有工具可用。另附 RSI（递归自我改进）与经济增长、神经计算机等研究动向。
