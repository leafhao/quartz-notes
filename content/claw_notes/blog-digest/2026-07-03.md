## 1. llm-coding-agent 0.1a0 发布

- **来源**: Simon Willison's Weblog
- **链接**: https://simonwillison.net/2026/Jul/2/llm-coding-agent/
- **摘要**: Simon Willison 利用 Claude Fable 5 构建了一个基于其 LLM 库的编码 Agent。该工具支持文件读写、命令执行等工具，可通过 `uvx llm code` 直接使用，提供 `--yolo` 自动执行模式和 Python API（CodingAgent 类）。整个项目使用 TDD 红绿重构流程开发。

## 2. 使用 DSPy 评估和改进 Datasette Agent 的 SQL 系统提示词

- **来源**: Simon Willison's Weblog
- **链接**: https://simonwillison.net/2026/Jul/2/dspy-datasette-agent-prompts/
- **摘要**: Simon 利用 DSPy 框架评估 Datasette Agent 的 SQL 问答系统提示词。通过自动生成的黄金标准数据集和自定义指标进行严格评估，发现 schema 列表仅显示表名会导致列名猜测和错误重试循环，建议在提示词中包含列名信息。

## 3. Vercel 的 Andrew Qu：为什么 Agent 是一种新型软件

- **来源**: Latent Space
- **链接**: https://www.latent.space/p/vercel-agents-new-software
- **摘要**: Vercel 首席软件官 Andrew Qu 解释了 Vercel 如何从 Web 开发平台转向 Agent 领域。他们在构建 v0（vibe-coding 产品）时遇到了模型切换、fallback、可恢复运行等痛点，将解决方案抽象为可复用库（eve 框架），并推出 skills.sh 使 Agent 技能更易发现和使用。

## 4. FBI 查封 NetNut 代理平台和 Popa 僵尸网络

- **来源**: Krebs on Security
- **链接**: https://krebsonsecurity.com/2026/07/fbi-seizes-netnut-proxy-platform-popa-botnet/
- **摘要**: FBI 联合 Google、Lumen 等行业伙伴查封了以色列公司 Alarum Technologies 运营的 NetNut 住宅代理服务。该服务通过 Popa 僵尸网络感染至少 200 万台设备（智能电视、流媒体盒子等），将其变为代理节点，用于大规模内容抓取、广告欺诈和账户接管等恶意活动。

## 6. Hugging Face 和 Cerebras 将 Gemma 4 带入实时语音 AI

- **来源**: Hugging Face Blog
- **链接**: https://huggingface.co/blog/cerebras-gemma4-voice-ai
- **摘要**: HF 与 Cerebras 合作展示了一个开放模块化语音 AI 流水线：Nvidia Parakeet 语音识别 → Gemma 4 31B（Cerebras 推理）→ Qwen3TTS 语音合成。通过 Cerebras 的极速推理能力大幅降低延迟，实现接近人类对话响应速度的 speech-to-speech 体验。

## 7. Kent Beck 如何影响软件工程行业

- **来源**: The Pragmatic Engineer
- **链接**: https://newsletter.pragmaticengineer.com/p/how-kent-beck-shapes-the-software
- **摘要**: Kent Beck（XP 创始人、TDD 先驱、Agile 宣言联合作者）在播客中反思 AI 时代的软件工程。他指出当前 AI 大量生成代码但未能同步积累信任（trust），人类在构建信任方面仍然不可替代，这将定义软件工程的未来方向。

## 8. Postgres 事务是分布式系统的超能力

- **来源**: DBOS Blog (Hacker News 150+ points)
- **链接**: https://www.dbos.dev/blog/co-locating-workflow-state-with-your-data
- **摘要**: 文章论述将工作流状态与数据共置在 Postgres 事务中的优势。相比外部编排引擎，利用 Postgres 事务的原子性和一致性可以大幅简化分布式系统设计，避免两阶段提交和最终一致性的复杂性。
