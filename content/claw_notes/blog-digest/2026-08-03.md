## 1. Latest open artifacts (#23): Laguna S2.1、Inkling 与 Kimi K3

- **来源**：Interconnects (Nathan Lambert)
- **链接**：https://www.interconnects.ai/p/latest-open-artifacts-23-laguna-s21
- **摘要**：2024 年普遍预测的「训练成本指数上升 → 实验室必然整合」并没有发生，反而是更多机构在投入数亿到数十亿美元训练强模型并开源权重。Thinking Machines 首发 Inkling（975B-A41B 多模态 MoE，另有 276B-A12B 小版本），定位是「适合微调的强基座」而非榜单最强；腾讯 Hy3（295B-A21B）把许可从自定义限制性协议换成 Apache 2；Poolside Laguna-S-2.1（118B-A8B，能塞进一台 DGX Spark）连续三个月上榜并公开全部评测轨迹；美团 LongCat-2.0（1.6T MoE）是首个**完全在昇腾 910 上训练完成的非华为自研大模型**。
- **值得注意**：Kimi K3 用的是非商业许可 + 商业协议模式，文中引用观点认为这类「需要与中国实验室签合同才能提供推理」的授权结构，反而给美国的监管杠杆提供了更清晰的抓手。对做开源基座选型的人是新的合规变量。

## 2. Stateless MCP 重新点燃了兴趣（MCP 2.0）

- **来源**：Simon Willison
- **链接**：https://simonwillison.net/2026/Jul/31/stateless-mcp/
- **摘要**：2026-07-28 版 MCP 规范（俗称 MCP 2.0 / Stateless MCP）是协议发布以来最大的一次改动。旧的 stateful MCP 调一次工具要两次 HTTP 请求（先 initialize 拿 `Mcp-Session-Id`，再 `tools/call`），新规范去掉会话状态后，客户端和服务端实现复杂度大幅下降，作者一周内自己写了三个（mcp-explorer、datasette-mcp、llm-mcp-client）。
- **值得注意**：作者 2025 年曾判断 MCP 被 Skills 盖过——「给 agent 一个能上网的 shell + curl 就能替代大部分 MCP」。他现在改口的理由值得记：**给 agent 开放 shell 风险太高，且需要足够强的模型才驾驭得住；MCP 工具更容易审计和限权，笔记本上跑的小模型也能可靠调用**。这个权衡对本地/小模型 Agent 场景很实际。

## 3. MindMemOS：华为诺亚开源可迁移、自演进的 Agent 记忆层

- **来源**：量子位
- **链接**：https://www.qbitai.com/2026/08/464835.html
- **摘要**：针对「换个 Agent 或换个 session 就像换了个完全不了解你的新员工」，诺亚方舟把记忆从单个 Agent 解耦成独立操作层。核心是用**实体-属性-时间**三维坐标组织记忆，同时保留最新状态和完整演化轨迹（"用户以前喜欢 X" 和 "现在改用 Y" 落在同一实体同一属性的时间轴上，而不是两段无关文本）；MindSchema 模式可按领域预设提取规则或离线演化提取策略；Feedback 从用户隐式纠正中强化/降级记忆；Dreaming 在离线阶段合并冗余、归档过时事实。
- **数据**：LoCoMo 94.03 分，PersonaMem 70.63%；MemoryAgentBench FactConsolidation 上 Dreaming 压缩 19.4%-23.5% 活跃记忆的同时问答准确率最高提升 10.3 个百分点；基于真实执行轨迹的 Skill 演进把 SpreadsheetBench-Verified 成功率提到 57.2%±2.4%。仓库 github.com/mindscale-noah/MindMemOS

## 4. EvoLib：把经验变成会进化的知识库（测试时学习）

- **来源**：Microsoft Research
- **链接**：https://www.microsoft.com/en-us/research/blog/evolib-turning-experience-into-evolving-knowledge/
- **摘要**：论文《Test-Time Learning with an Evolving Library》。立论是「memory 不等于 learning」——把对话、推理轨迹、动作历史堆成一个巨大档案库，反而更难定位对新任务有用的知识。EvoLib 从经验中抽出两类知识单元（成功解法蒸馏出的可复用 skill、失败反思出的 insight），并持续做三件事：**consolidation**（把新知识与库里相似知识合并成更一般的版本）、**weighting**（按贡献动态调整知识单元重要性）、**reweighting/淘汰**。
- **值得注意**：全程**不更新模型权重**，纯推理期自监督（不需要 ground-truth 标签或外部反馈），所以对任何黑盒 API 模型都适用。和 MindMemOS 撞题——两家同期都在做「记忆 + 技能一起演化」，说明这是当前 Agent 工程的公认瓶颈。

## 5. Echoverse：为 computer-use agent 造深度可演化环境

- **来源**：Microsoft Research
- **链接**：https://www.microsoft.com/en-us/research/blog/echoverse-deep-evolving-environments-for-computer-use-agents/
- **摘要**：造了 12 个训练世界（10 个领域世界 + 2 个能力世界，后者专门针对日期选择器、嵌套筛选器这类 agent 普遍搞不定的 UI 控件反复操练）。关键主张是**深度优于数量**：世界要复现应用真实行为、带真实种子数据、跨页面跨用户保持状态一致。在全部 12 个世界上训练后，一个 9B 模型分数从 36.5% 提到 67.1%（接近翻倍），距 GPT-5.4 只差 14 分。
- **实验结论**（对做 RL 环境的人有直接价值）：① 仿真保真度是必需项，同一站点的浅层版本训练会让模型**退化**；② 在多形态下操练同一控件，能迁移到训练中没见过的领域；③ 模型、世界、verifier 共同演化时三者都变好；④ 用 grounded verifier 做 reward 跑 RL 能超越模仿学习，且教会 agent 用更少步数达成目标。已开源 4 个世界的代码/数据/grader。

## 6. Science One Framework：用 Chain-of-Evidence 消除自动科研的幻觉

- **来源**：Google Research
- **链接**：https://research.google/blog/science-one-framework-a-verifiable-autonomous-research-framework-via-chain-of-evidence/
- **摘要**：自动科研 Agent（AI-Scientist、DeepScientist 等）产出的稿件表面质量越来越高，但结构性问题是**不可验证**：迭代生成让任何环节的错误被放大，会编造不存在的引用、方法描述与实际代码不一致、报告的实验分数无法从代码复现。CoE（Chain-of-Evidence）这个框架不规定 Agent 怎么造，只规定输出必须具备哪些属性——类比 ACID 定义可靠事务。配套 CoE Audit 是一组自动指标，用来对着底层代码和证据审计 AI 生成论文的完整性。
- **数据**：baseline 系统最高有 **21% 的引用是幻觉**，且代码与正文频繁错位；Science One 做到零幻影引用、分数完全可验证，同时在 MLE-Bench 和 Parameter-Golf 上达到 SOTA。

## 7. AI 推理是「对的，但理由是错的」吗？

- **来源**：Quanta Magazine
- **链接**：https://www.quantamagazine.org/is-ai-reasoning-right-for-the-wrong-reasons-20260731/
- **摘要**：一篇把近两年 reasoning 争议梳理清楚的长文。一边是 Apple 团队的「Illusion of Thinking」（简单条件下就出现准确率完全崩塌）、Santa Fe Institute 的研究显示 LRM 能靠**表层捷径**刷爆精心设计的类比视觉推理基准；另一边是 IMO 金牌、OpenAI 模型 2026 年 5 月一次性解开一个著名开放数学问题、DeepMind 与 Terence Tao 合作在 67 个分析/组合/几何/数论问题上重现或改进解法。
- **值得注意**：作者的问题不是站哪边，而是「AI 推理怎么可能同时既是又不是真推理」。文中转向 Melanie Mitchell 等人对评测方法论的批评——**当模型能在拥有正确算法和充足算力预算的情况下依然不可靠地推理时，"jagged intelligence" 这个说法只是把问题重命名了**。对设计评测的人是一次必要的方法论提醒。

## 8. GPT-5.6 降价 20%-80%：模型自己优化自己的服务成本

- **来源**：Latent Space (AINews)
- **链接**：https://www.latent.space/p/ainews-gpt-56-price-cut-by-20-80
- **摘要**：一年前的观察是「固定 LMSys Elo 不变，GPT-4 级智能的价格 18 个月降了 1000 倍」，当时不确定这是不是一次性的「新手红利」（未优化到优化、completions 到 reasoning、dense 到 MoE）。又过 18 个月，答案是否——同等智能水平的成本仍在陡降，四个月内 GPT-5.4 级智能价格降了 13 倍。
- **技术细节**：OpenAI 披露 GPT-5.6 被用来优化自身服务栈——分析生产流量、调负载均衡、**自主重写 Triton/Gluon 生产 kernel**（端到端服务成本降 20%）；自己设计并跑数百次实验改进 speculative decoding 的 draft model（token 生成效率 +15%，过程中还自主处理了硬件故障和训练不稳定）；按 workload 定制 KV cache 的 batching/sharding。Agentic harness 侧则是 deferred discovery（工具/skill 按需暴露）、工具输出默认截断到 10k tokens、把 model-visible history 做成 append-only 以保住 prompt prefix 的缓存命中率。
- **对我的启发**：最后那三条 harness 优化（按需暴露工具、截断工具输出、append-only 历史）是任何自建 Agent 框架都能直接抄的省钱手法。

## 本期观察

**开源格局**：整合预测落空，token 需求的增长速度超过训练成本的增长，「造 token 机器」本身成了可持续的价值路径。中国实验室节奏稳定，且出现了 LongCat-2.0 这种**全国产加速器完成训练**的信号（此前国产芯片主要用于推理）。

**Agent 记忆成为独立层**：MindMemOS（华为）和 EvoLib（微软）同周发布，都在做「经验 → 可复用技能 + 反思洞察 → 持续演化」，且都不动模型权重。可以判断 2026 下半年记忆/技能层会像 RAG 在 2023 那样被工程化标准化。

**可验证性压过表面质量**：Science One 的 21% 幻觉引用数据、Echoverse 的 grounded verifier、r/MachineLearning 上大量关于 NeurIPS 2026 评审崩坏的讨论（含一篇「我举报了两篇造假作者的论文，结果两篇都被接为 oral」上了 HN），指向同一件事——**产出量已经不是瓶颈，验证能力才是**。

**国内动态**：阿里 Qwen3.8-Max（2.4 万亿总参）当日发布，国内每百万 token 输入 12 元/输出 36 元，隐式缓存命中 1.5 元；国际价格约为 Opus 5 的 40%（输入）/24%（输出）；Arena 编程榜超过 Claude Opus 5 和 Fable 5 High 版本。官方称有从空文件夹无人干预自主推进十多天交付完整项目的案例。 → https://www.qbitai.com/2026/08/465226.html
