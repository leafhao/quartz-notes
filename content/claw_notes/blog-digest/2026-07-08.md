# Blog Digest - 2026-07-08

## 1. GitLost: Tricking GitHub's AI Agent into Leaking Private Repos

**来源**: Hacker News / Noma Security
**链接**: https://noma.security/blog/gitlost-how-we-tricked-githubs-ai-agent-into-leaking-private-repos/

Noma Labs 发现 GitHub Agentic Workflows 存在严重的间接提示注入漏洞（命名为 GitLost）。攻击者可以在 issue 或代码内容中隐藏恶意指令，诱导 AI agent 读取并泄露私有仓库数据。这是 agentic AI 系统中信任边界失效的又一经典案例——agent 将不可信内容当作系统级指令执行。

**来源**: Latent Space
**链接**: https://www.latent.space/p/ainews-lilian-weng-summarizes-35

Lilian Weng（Thinky 联合创始人，前 OpenAI）发布了关于 harness engineering 与 AI 自我改进（RSI）关系的深度研究综述，涵盖 35 篇论文。核心观点：即使许多 harness 改进最终会被内化到模型核心中，指定目标和上下文的需求不会消失。文章梳理了 harness 设计的主流趋势，从 ACE 到 Meta-Harnesses，为 agent 工程提供了系统性参考。

## 3. Import AI 464: Fable 编写 GPU Megakernel 实现 18.71x 加速

**来源**: Import AI
**链接**: https://importai.substack.com/p/import-ai-464-fables-writes-gpu-kernels

Anthropic 的 Fable 模型在 KernelBench-Mega 上编写了第一个真正的 CUDA megakernel（单次 kernel launch per token），在 RTX PRO 6000 Blackwell 上达到 18.71x 加速，远超 Claude Opus 4.8 的 14.4x 和 GLM-5.2 的 11.14x。这标志着 AI 系统在自研基础设施能力上的重大突破，是递归自我改进（RSI）的关键信号。

## 5. LeRobot v0.6.0: World Models 进入机器人策略

**来源**: Hugging Face Blog
**链接**: https://huggingface.co/blog/lerobot-release-v060

Hugging Face 发布 LeRobot v0.6.0，核心更新包括：三种世界模型策略（VLA-JEPA、FastWAM、LingBot-VA）让机器人在行动前"想象未来"；新增奖励模型 API（Robometer、TOPReward）判断任务成功；lerobot-rollout CLI 支持 DAgger 式人机协作纠错；六个新仿真基准统一在 lerobot-eval 下。还有 FSDP 训练支持和 HF Jobs 云端训练。

## 6. sqlite-utils 4.0: 数据库迁移终于来了

**来源**: Simon Willison
**链接**: https://simonwillison.net/2026/Jul/7/sqlite-utils-4/

Simon Willison 发布 sqlite-utils 4.0，距 3.0 已五年。三大新特性：数据库 schema 迁移（Python 定义迁移文件，支持 SQLite ALTER TABLE 无法实现的复杂变更）、嵌套事务（db.atomic()）、复合外键支持。迁移功能基于 table.transform() 实现 SQLite 官方推荐的重建表模式，填补了 SQLite 生态中轻量迁移工具的空白。
