- 链接：https://matteoraso.github.io/im-not-convinced-the-ai-bubble-exists.html

核心论点是：AI 公司烧的钱主要是一次性的数据中心建设，不是运营成本。S-1 里 Anthropic 每 1 美元算力支出对应 2.08 美元收入，且收入已覆盖算力加基建投入；2023 到 2026 上半年营收从 4100 万涨到 163 亿。作者还指出 Alphabet、Meta、英伟达的市盈率都还停在 20 多倍，历史上没有哪次泡沫是这种估值形态，并认为「泡沫论」流行的真实原因是人们希望一切回到从前。

## 从 Claude Code 迁到 Pi：一年 244 次发布，四分之三动过系统提示

- 来源：caleb.software（HN）
- 链接：https://caleb.software/posts/claude-to-pi.html

作者的抱怨很具体：一个 IDE 会话同时只能连一个终端、官方 GUI 扩展里一半斜杠命令失效、子 agent 输出按时间顺序糊在主线程里。更关键的数字是 Claude Code 今年发了 244 个版本，其中超过四分之三改动了系统提示或工具描述，而这会实质改变模型行为。他估算单是 Bash 工具的描述就近 3000 token，按百万日活算，砍掉 1000 token 一年能省下数百万美元推理成本。最后结论是产品缺一个说「不」的人，已改用开源 harness Pi，并花 20 分钟写扩展补上了多标签的缺口。

## 用 git 里的优先队列治「AI 脑疲劳」

- 来源：Sergey Kuhne（HN）
- 链接：https://sergeykuhne.com/blog/fighting-ai-brain-fry

同时开二十个 agent 会话、在标签页之间跳来跳去，最后不知道自己在做什么——作者把这个问题拆成排序和上下文两件事。解法是把工单写成仓库里的 markdown 文件，看板状态作为快照提交，agent 按周期处理：调研、构建已标记为安全的任务、跑测试与浏览器检查，敏感的走分支并先询问，永不部署生产。需要人判断的事项汇总到一个 owner inbox，脚本读整块看板生成按优先级排序的清单。关键动作是每处理完一条就把上下文关掉，工单不留在脑子里。

## 车牌号就能远程解锁任意一辆该品牌汽车

- 来源：shubs.io（HN，与 Sam Curry 合作）
- 链接：https://shubs.io/unlocking-any-car-from-x-brand-in-most-of-the-world/

入口是一个叫 admintool 的子域，登录页在未登录状态就显示了登出按钮，前端整包 JS 直接暴露了能力边界。攻击链是：车牌经各州登记查询换到 VIN，VIN 换到用户 GUID，再从身份平台拿到邮箱等 PII，最后用员工级接口给车辆下发指令。结果是在澳大利亚、美国、加拿大都能对两个品牌的任意车辆执行解锁与远程启动。作者强调美加欧环境的 OpenIDM 加固明显更好，链条打通费了更多功夫。

## libghostty 1.0：终端模拟器变成一个 C 库

- 来源：Mitchell Hashimoto
- 链接：https://mitchellh.com/writing/libghostty-1-0

从 Ghostty 内核抽出的可移植终端模拟库正式发 1.0，同时承诺严格的 ABI 稳定与语义化版本，让各发行版可以单独打包 libghostty-vt。落地规模已经远超 Ghostty 应用本身：JetBrains 全家桶的终端已换成 libghostty，覆盖超过 1250 万用户；neovim 用它替换 libvterm 并顺带修掉了缩放时回滚缓冲的重排问题；还有 btop 等工具借此发现了真实 bug。作者用「不透明句柄 + 少量枚举键控 getter/setter」的设计换取长期可扩展性。

## llama-modchip：64GB 内存、无 GPU 跑 284B 模型

- 来源：GitHub（HN）
- 链接：https://github.com/synchopate/llama-modchip

一组 ggml / llama.cpp 内核补丁加量化转码工具，把 DeepSeek-V4-Flash 的 284B 权重压到 56.56 GiB（1.71 bpw），加 256K 上下文的 KV 缓存后整体锁进 64GB 机器的内存，不再触发 swap 或 OOM。核心是 AVX-512BW 的多列寄存器分块，把 prompt 预填从 25 tok/s 拉到 44.4 tok/s，解码提升约 53%。实测 9.1～14.7 tok/s，30B 级 MoE 能到 25～111 tok/s。

## Outlook 从 11 月 5 日起静默拒收没有 DMARC 记录的域名

- 来源：MailRoute
- 链接：https://mailroute.net/blog/outlook-rejecting-email-without-dmarc

微软没有发公告：outlook.com、hotmail.com、live.com、msn.com 开始对没有 DMARC 记录的域名返回 550 5.7.1，且只拒一部分邮件，所以「我的信能收到」不代表域名安全。被拒的域名大多 SPF 正常、不少还有 DKIM，缺的只是把两者与 From 地址绑起来的那条 DMARC 记录。修法是加一条 `v=DMARC1; p=none` 的 TXT，对其它收件方行为无影响。

## Quanta：一个新定理终结了爱因斯坦式的「实在」

- 来源：Quanta Magazine
- 链接：https://www.quantamagazine.org/a-strange-quantum-theorem-has-killed-einsteins-reality-20261106/

爱因斯坦坚持物体在被测量之前就有确定属性，EPR 想用思想实验证明量子态只是信息不全的产物。Bell 不等式之后，Pusey、Barrett、Rudolph 在 2012 年给出的 PBR 定理进一步排除了「量子态只是知识状态」这一最常识的读法：要么放弃实在论，要么接受更怪的世界。文章介绍的后续工作是 Hardy 等人试图构造一种更宽松的实在观——比如状态可以摊在多个时刻上，而非每一刻都有唯一客观取值，但那样的实在已经不是爱因斯坦要的那个。

## BenchUp：用 Rust + WebGPU 重写的 SketchUp 开源替代

- 来源：GitHub（HN，原 KetchUp）
- 链接：https://ketchup3d.github.io/app/

面向上木工与家具设计的 3D 建模工具，MIT 协议，跑在 Windows / macOS / Linux 和浏览器里。提供推拉、吸附到几何与坐标轴、输入精确长度、组件与标签等 SketchUp 核心手感，可导入 .skp 几何、导出 OBJ，工程文件本地自动保存、无账号无云存储。明确不支持的包括 SketchUp 的贴图、场景和部分模型特性。

## Dux：Wayland 上的模块化桌面 shell

- 来源：duxlabs.dev（HN）
- 链接：https://duxlabs.dev/

面向 niri、Hyprland、Sway、labwc、Miracle 等 Wayland 合成器的桌面外壳，自带文件管理器、系统监视器、greeter 与文件搜索，并已推出 Fedora 官方的 Miracle Spin。新版本加了视频壁纸、可调界面密度和一套 dank16 算法，为 GTK、Qt 应用和终端自动生成 16 色配色。全部开源，靠赞助和 Ko-fi 支持者维持。
