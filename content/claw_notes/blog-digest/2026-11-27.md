## Google 强制 Agent 走 Workspace MCP

- 来源：Tech Stackups（HN 热榜）
- 链接：https://techstackups.com/articles/google-workspace-ai-agents-mcp/
- 摘要：Google 11 月 24 日把 8 个 Workspace MCP 服务器转为正式可用，同时在 API 条款里加了新附件：2027 年 2 月 1 日起，任何「由 AI Agent 驱动」的工具必须通过 MCP 访问 Gmail、Drive、日历等，直接调 REST API 的 Agent 一律按 Standard 配额限速。滑稽的是 Gmail 那个服务器的工具列表里没有发信、回复、转发和改草稿——这些能力「需要合作伙伴权限，不对外开放」，而 Anthropic 的 Claude 连接器恰好能做这些事。附件还要求 Workspace 数据只能用于完成用户已授权的任务，Google 可把向量嵌入、记忆索引这类「技术信息」的保留期压到 30 天，等于长期收件箱索引得每月重建。

## 蚂蚁灵波开源带空间记忆的导航模型

- 来源：量子位
- 链接：https://www.qbitai.com/2026/11/513211.html
- 摘要：蚂蚁灵波发布 LingBot-Map 2.0 流式三维重建模型，并开源基于它构建的导航模型 LingBot-Navi。Map 2.0 的关键是能在行进任意时刻纠正模型内部的空间记忆，而不只是像外接回环后端那样拉回输出轨迹；在 5.2 公里、近 1.9 万帧的 VBR 城市长轨迹上，轨迹误差从 1.0 版的 31.12 米降到 4.72 米。Navi 把沿途见闻沉淀成可跨任务复用的三维记忆，第二次去同一场地可直接检索目标，端到端导航成功率在 GOAT-Bench 为 56.09%，还略高于搭配 GPT-6 Astra 的导航 Agent（51.97%），且可完全端侧本地运行。
