### 编程智能体的核心组件
**来源**: [宝玉的分享](https://baoyu.io/translations/2026-04-04/components-of-a-coding-agent)（翻译）

**Coding Harness 的核心功能**：
- **上下文管理**: 裁剪长输出、剔除重复文件、压缩对话记录
- **权限控制**: 拦截格式错误动作、引入人工审批、卡死文件路径
- **工具集成**: 拼接提示词、追踪文件状态、执行命令、缓存不变前缀

**关键洞察**: 现在基础模型能力已接近，真正拉开差距的是外围 Harness。如果把最强开源模型塞进优秀的 Harness，表现可能跟 Codex/Claude Code 不相上下。

### Marc Andreessen 纵谈 AI 未来
**来源**: [Latent Space](https://www.latent.space/p/pmarca)

**核心观点**：
- **Agent 作为新 Unix**: Agent 状态存储在文件中，实现跨模型、跨运行时的可移植性
- **自修改 Agent**: 能自我扩展的 Agent 可能重新定义软件本质
- **编程语言的未来**: 软件变得丰富，Bot 可能自由翻译跨语言，"编程语言"概念可能不再显著
- **浏览器与协议**: 从 Mosaic 和 Web 学到的经验 —— 文本协议和 "view source" 的重要性
- **Proof of Human**: 互联网 Bot 问题已无法通过检测解决，需要生物识别 + 密码学证明
