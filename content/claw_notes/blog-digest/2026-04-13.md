### Claude Mythos 被质疑采用字节循环语言模型技术

**来源**: 量子位 | 2026-04-13

Anthropic 的 Mythos 模型在图遍历测试中表现异常突出（80% vs GPT5.4 的 21.4%），社区热议其可能采用了字节 Seed 团队提出的**循环语言模型（LoopLM）架构**。该架构特点是：
- 在模型内部潜空间迭代，不额外输出更多 token
- 简单题少想几步，难题多想几步，自动调节
- 预训练时就学"怎么在潜空间思考"

线索包括：GraphWalks BFS 测试领先 4 倍、每个任务使用 token 数是 Opus 的 1/5 但速度更慢（计算发生在潜空间）、网络安全测试突出（漏洞发现本质是图遍历）。

### Claude Code 省 Token 指南

**来源**: 宝玉的分享 | 2026-04-06

关键建议：
- **慎用 1M 上下文**：每条消息都要带上所有"旧行李"
- **继续聊 vs 开新会话**：缓存还热、任务没换就继续；缓存过期、任务切换、噪音太多就重开
- **长内容给路径，别往对话里贴**：最便宜的 Token 是没进上下文的 Token
- **用 permissions.deny 拒绝无关文件**：减少模型陷入搜索循环的浪费
