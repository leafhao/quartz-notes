# Blog Digest - 2026-10-21

## DeepSeek 开源生产推理栈 DeepInfer：单集群 155T token/日
- 来源：Latent Space / AINews、Interconnects、GitHub
- 链接：https://www.latent.space/p/ainews-deepseek-deepinfer-open-source
- 摘要：DeepSeek 把内部推理框架 DeepInfer 整体开源（Apache 2.0），这是首次有头部实验室公开生产级推理栈。官方数据：单集群每天 155 万亿 token、输入缓存命中率 96%、TTFT 400ms、生成 230 token/s（写代码 300），按闲时价格折合每卡每小时 38 美元收入，全成本 5—8 美元，毛利率超 80%，算力投资 81 天回本。关键设计是把 KV 缓存放在 3FS 上（约 100 PiB SSD），agent 流量缓存 3 天、聊天 7 天；但 KV 缓存管理和跨副本负载均衡这两块「皇冠上的珠子」仍与内部基础设施耦合，没有一并放出。

## Mistral Voxtral 3：语音 agent 全家桶
- 来源：Mistral AI
- 链接：https://mistral.ai/news/voxtral-3/
- 摘要：Voxtral 3 一次给齐三件东西：50+ 语种的转写模型（带说话人分离、上下文偏置、轮次结束检测）、35+ 语种的 TTS（情绪/语速/重音可调，50+ 方言），以及把听、想、调工具、说串成一条实时流的语音 agent SDK。转写小模型在英法西等语种上超过 Whisper、Scribe v2 和 Gemini 3.5 Transcribe；Mini 版 4B 参数、每分钟 0.0035 美元；TTS 每百万字符 13 美元，比 OpenAI TTS-1、ElevenLabs Flash 便宜。全部可 EU 托管 API 或自部署。

## Google 开源 TorchTPU：TPU 变成 PyTorch 的一个 device
- 来源：Hugging Face Blog / Google
- 链接：https://huggingface.co/blog/hf-torchtpu
- 摘要：以前 PyTorch 上 TPU 只能走 torch_xla（惰性张量、动辄重编译、难调试），现在 TorchTPU 作为原生后端接入，`pip install torch-tpu` 之后模型 `.to("tpu")` 即可。附带 Pallas 调优 kernel、分布式训练和 torch.compile 集成。Hugging Face 侧 Transformers v5、Diffusers、Kernels 全部原生支持，`device_map="tpu"` 一行搞定，原来的 Optimum TPU 不再需要。

## FairStress：公平性不能只看「选谁」
- 来源：Hugging Face Blog / Ai2
- 链接：https://huggingface.co/blog/allenai/fairstress
- 摘要：传统公平性评测只做「换掉人口统计特征，看模型是否仍选同一个人」。Ai2 的 FairStress 指出这会漏掉关键差异：两个版本答案一致，但被质疑时（比如「高管更看好另一位」「这类人群历史上被忽视」）模型改变主意的难易程度可能天差地别。基准已开放下载，并集成进 Olmo-eval。

- 来源：Hugging Face Blog

- 摘要：作为 Apple Foundation Models 框架的 drop-in 替代，AnyLanguageModel 1.0 用同一套 Swift API 就能在系统模型、MLX 本地模型（如 Qwen3.8-27B-4bit）、GGUF 和远程 Inference Providers 之间切换，也能接 Anthropic Messages API 的 adaptive thinking。切换 provider 时会自动丢弃对方无法重放的 reasoning blocks，并支持从自有服务器取短期 token。
