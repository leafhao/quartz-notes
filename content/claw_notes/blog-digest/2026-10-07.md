# Blog Digest - 2026-10-07

## OpenAI 发布 722 篇数学论文，称解决 90 道公开难题
- 来源：Latent Space / AINews
- 链接：https://www.latent.space/p/ainews-quasi-riemann-hypothesis-openai
- 摘要：OpenAI 用一个未对外的内部前沿模型产出 722 篇数学手稿，归入 372 个成果族，来自约 4000 道研究题的评测，平均每篇约消耗 3 小时 ChatGPT Pro 算力。宣称覆盖前 500 大公开难题中的 90 道，其中 Result 003「准黎曼假设」被评价为介于菲尔兹奖与「数论 200 年来最大成果」之间。所有结果尚未独立验证，部分数学家（含陶哲轩、Villani）转而公开担忧节奏失控。

## The Cyber Risk Discourse is Broken
- 来源：Interconnects（Nathan Lambert）
- 链接：https://www.interconnects.ai/p/the-cyber-risk-discourse-is-broken
- 摘要：Nathan Lambert 认为开源权重网络风险的讨论已失衡：一方假设「禁掉开源权重」可以单独成立，另一方被贴上「不在乎安全」的标签。他指出迄今被记录在案的网络攻击主要来自闭源模型，若以网络风险为由禁开源，逻辑上同样应禁闭源 API。他也梳理了中国模型发布需向政府登记、评估框架侧重信息管控的现实。

## 终端程序状态协议 OSC 7501
- 来源：Mitchell Hashimoto
- 链接：https://mitchellh.com/writing/program-status-osc7501
- 摘要：Mitchell Hashimoto 提出新的终端转义序列 OSC 7501，让程序主动告诉终端自己是 idle / working / done / blocked / error 及原因，body 为 `key=value` 串。它瞄准的是「agentic inbox」这类跨 Agent 状态面板——目前只能靠 braille 转圈字符等启发式猜测，或各自对接私有 socket，无法跨 SSH 与容器。已在 libghostty、Rex 及 Terraform / Claude Code / Codex / Homebrew 上做出实现。

## Strands Decider 2B：专做决策的小模型
- 来源：Strands Agents（AWS）
- 链接：https://strandsagents.com/blog/introducing-strands-decider/
- 摘要：AWS Strands 团队开源 2B 决策模型，取 Qwen3.5-2B 的躯干拆掉 LM head，换成指针头，只能从给定选项里选答案并给出置信度，不做文本生成。本地 CPU/GPU 可跑，RTX 3090 中位延迟约 115ms、M3 MacBook 约 153ms，JevBench 准确率与校准在 2B 级排 3/33。适合模型路由、工具选择、护栏与上下文管理。

## 陶哲轩公开呼吁 AI 数学该慢下来
- 来源：量子位
- 链接：https://www.qbitai.com/2026/10/501736.html
- 摘要：陶哲轩在 SAIR 演讲中公开喊话模型公司「别解数学问题了，必须慢下来」。他称当前局面是 Proof Indigestion（证明消化不良）：AI 在生成解答和 Lean 形式化两步疯狂加速，而阐释、同行评审、写教科书三步几乎为零。他担心人类创造力丧失与数据污染（AI 证明回流训练），并与 Peter Scholze、邓煜等 25 位菲尔兹奖得主联名致信。OpenAI 回应称在普林斯顿高等研究院设独立顾问小组，但明确不介入内部数学进展。
