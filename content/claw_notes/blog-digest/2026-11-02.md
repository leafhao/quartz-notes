## 数学与科研

### Mathematics has changed. Let's act like it
- 来源：Terence Tao's Blog（Frank Calegari 客座）
- 链接：https://terrytao.wordpress.com/2026/11/01/mathematics-has-changed-lets-act-like-it/
- 摘要：Calegari 认为 OpenAI 10 月 6 日抛出的 700 多篇论文是数学史的转折点，AI 已确凿能在多个方向做出突破性贡献，但论文写得极差、违反引用规范、部分是错的。他拿 1972–1983 年有限单群分类纲领作类比：大问题一旦"被解决"，学科热度反而会冷却，真正该做的是宣告"还有更多可挖"而不是"已经做完"。他呼吁数学界把精力放在自己能控制的事上——招聘、发表、培养学生——而不是指望万亿公司守规矩。

### A New Map of 'Empty' Space Challenges a Tranquil Picture of the Galaxy
- 来源：Quanta Magazine
- 链接：https://www.quantamagazine.org/a-new-map-of-empty-space-challenges-a-tranquil-picture-of-the-galaxy-20261030/
- 摘要：星际介质一直被当作静态背景板，1969 年 Field-Goldsmith-Habing 模型认为它只存在冷（100K）与暖（8000K）两个稳定态，中间态几乎不存在。新一代跨数千光年的三维测绘发现大量气体处在不稳定的中间态，直接推翻教科书模型。这一结果可能顺带解开恒星形成速率长期对不上的老问题。

### One-minute frequency disturbances from unintended synchronization in cyber-physical power systems
- 来源：Nature Energy
- 链接：https://www.nature.com/articles/s41560-026-02144-0
- 摘要：全球多张电网的频率曲线里都有一个来源不明的一分钟周期振荡。研究者定位到元凶：数字控制设备（尤其 UPS 和电池储能）的时钟同步软件会周期性拉出功率尖峰，并跨电压等级传播。该振荡幅度近年明显上升，已对水电设备造成磨损；电池储能、数据中心和 IoT 的扩张会进一步放大它。

## 模型与工程

### Postgres 19 is late, and it's AI's fault
- 来源：Robert Haas（Neon 博客转载）
- 链接：http://rhaas.blogspot.com/2026/10/postgres-19-is-late-and-its-ais-fault.html
- 摘要：Postgres 大版本历来 9 月中到 10 月中发，19 要拖到 11 月，且 beta 期罕见地回滚了三个大特性。原因是 LLM 让找 bug 变得太容易：2025 年同期 1037 个 master 提交、724 个回填，2026 年变成 1443 和 1169，回填涨幅超 60%，再往前一个稳定分支的回填涨了 74%。LLM 能起草修复但审核仍靠人，人力被安全修复占满，于是发版被拖。Haas 说真正的问题是：四十年没人发现的 bug 现在几小时内就能挖出来，这个缺口怎么补。

### The AI cost of JavaScript frameworks
- 来源：Nolan Lawson（Read the Tea Leaves）
- 链接：https://nolanlawson.com/2026/10/28/the-ai-cost-of-javascript-frameworks/
- 摘要：用 Opus 5.5 分别以 Next.js / Nuxt / SvelteKit / Astro / Angular / Qwik / Hono+htmx 等构建同一个 PokéAPI 应用，各跑 5 次，对比耗时、token、代码行数、Lighthouse。结论：Lighthouse 分数已趋饱和，真正拉开差距的是 JS 体积、TBT 和代码行数——Hono+htmx 用约 70% 的代码量做到 Angular 同样的事还更快。作者的本意不是评选冠军，而是证明 agent 时代仍可以靠证据而非"感觉"选技术栈，并怀疑当下的 MCP/skills 可能弊大于利。

### dbreunig/nesformer
- 来源：Simon Willison's Weblog（链接贴）
- 链接：https://simonwillison.net/2026/Oct/30/nesformer/
- 摘要：受 qwenputer 启发，Drew Breunig 把 NES 的 6502 CPU 模拟器烘进了 Qwen3.5-4B 的权重里，现在可以在模型内部跑《超级马里奥兄弟》，很慢但能玩。整个项目由 Opus 5.5 完成，提示词只有"读这篇文章，看看能不能用类似办法模拟 NES 芯片，能就做"，它还自己找到了 15 年前发布的 NES CPU 一致性测试集。

### OmniDiff
- 来源：Hacker News / GitHub
- 链接：https://github.com/ivankovic/omnidiff
- 摘要：Rust 写的内容感知 diff 工具，对代码用 tree-sitter、对图片/字体/PDF/压缩包用各自格式的解析器，不再退化成"Binary file differs"。在 2302 个测试样例上 p50 4.2ms、p99 177ms，对 7500 个仓库的 44 万对文件成功率 99.95%。可直接作为 `git difftool` 后端，也有 VS Code 与 Neovim 扩展。

### If in doubt, delete the uv.lock file
- 来源：Simon Willison's Weblog
- 链接：https://simonwillison.net/2026/Nov/1/delete-uv-lock-first/
- 摘要：切到 Python 3.15 后偶尔会遇到依赖解析报错，原因是残留的 uv.lock 钉住了还没有 3.15 wheel 的版本。库项目本来就不该带 lock 文件，删掉再 `uv run pytest` 通常就好了。

## 安全与观点

### How We Took Over ChatGPT Accounts
- 来源：Simon Willison's Weblog（引 Parameter Labs）
- 链接：https://simonwillison.net/2026/Oct/31/how-we-took-over-chatgpt-accounts/
- 摘要：攻击链绕了四步：OpenAI 图形功能用的 MathLive 虚拟键盘可被 iframe 通过 postMessage 触发、接收端用 innerHTML 写入、由此注入无 sandbox 的新 iframe、再借 CSP 白名单里的 YouTube oEmbed 反射执行 JS。拿到执行权后读私有数据、用图片引用外带轻而易举——一条分享链接就能在他人打开时接管账号。OpenAI 修复后给了 5000 美元赏金，Simon 认为对这个级别的漏洞偏低。

### From synthetic enterprise data evaluations to real Microsoft Copilot AI confidence
- 来源：Microsoft Research
- 链接：https://www.microsoft.com/en-us/research/blog/from-synthetic-enterprise-data-evaluations-to-real-microsoft-copilot-ai-confidence/
- 摘要：企业数据不能拿来评测，于是 MSR 搭了一个合成企业环境生成平台：基于 O*NET 职业数据、招聘启事和 SEC 文件构造出组织架构、会议、邮件、文档，再自动生成查询集。目标是回答两个问题——Copilot 是否真做到了用户要的事，以及能否在不碰用户数据的前提下证明这一点。这是 Copilot 第一套标准化评测基线。

### Seoul Viosys begins mass production of rare-earth-free white light emitter
- 来源：Semiconductor Today
- 链接：https://www.semiconductor-today.com/news_items/2026/oct/seoul-291026.shtml
- 摘要：白光 LED 三十年来一直靠蓝光芯片叠 YAG 荧光粉，离不开稀土。Seoul Viosys 的 WICOP 3 只用氮化镓就发出白光，芯片最小可到 10µm，且不含封装、硅胶、塑料和引线框架，制造成本约为传统白光 LED 的一半。首批量产芯片 25µm×10µm，出光 0.015lm；公司认为微型不可见发光体可以嵌进墙纸和窗玻璃，做出比现有 100 亿美元白光市场大几十倍的新市场。
