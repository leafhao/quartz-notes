## 1. DeepSeek-V4: a million-token context that agents can actually use

**来源**: Hugging Face Blog  
**链接**: https://huggingface.co/blog/deepseekv4  
**发布日期**: 2026-04-24

DeepSeek 发布了 V4 系列，包含两个 MoE 模型：DeepSeek-V4-Pro（1.6T 总参数，49B 激活）和 DeepSeek-V4-Flash（284B 总参数，13B 激活），均支持 1M token 上下文。文章重点介绍了其混合注意力机制（CSA 和 HCA），使得在长上下文推理时仅需 V3.2 的 27% FLOPs 和 10% KV cache，为 Agent 任务提供了高效的长上下文支持。

## 5. AutoAdapt: Automated domain adaptation for large language models

**来源**: Microsoft Research  
**链接**: https://www.microsoft.com/en-us/research/blog/autoadapt-automated-domain-adaptation-for-large-language-models/  
**发布日期**: 2026-04-22

微软研究院推出 AutoAdapt，一个端到端的领域自适应框架。给定任务目标、领域数据和实际约束（准确率、延迟、硬件、预算），它自动规划适应流程，选择 RAG 或微调等方法，并通过预算感知优化循环调整超参数。核心创新是 Adaptation Configuration Graph（ACG），将复杂的适应配置空间结构化，确保生成有效的管道。
