## 6. Alternatives for the EDIT tool of LLM agents

**来源**：Antirez (Redis 作者)  
**链接**：http://antirez.com/news/166  
**发布日期**：2026-05-19

**摘要**：本地推理 token 紧张，antirez 重新设计了 coding agent 的 EDIT 工具：保留 CAS 语义但用基于行号 + CRC32 的标签替代原文整段重写，避免模型重新吐出特殊字符密集的旧文本。文章讨论了 line-number、verbatim-CAS、CRC32-checksum 三种方案的鲁棒性与 token 消耗权衡，是给小模型 agent 工具设计的实用工程笔记。

## 10. 李飞飞再出手：空间智能的 ImageNet 来了（ESI-Bench）

**来源**：量子位  
**链接**：https://www.qbitai.com/2026/05/422738.html  
**发布日期**：2026-05-22

**摘要**：李飞飞团队发布 ESI-Bench，把"被动看图"的空间智能评测升级为"感知-行动回路"：基于 OmniGibson + BEHAVIOR-1K，10 个任务类、29 个子类、3081 个实例，强制智能体主动行动获取证据后再答题（绕到物体背后看、把水倒出来量等）。在 GPT-5 和 Gemini 系列上的实验给出三条核心结论，其中第一条是"感知不是瓶颈，行动才是"——对当前视觉-语言模型在具身场景下的盲点有直接打击力。
