- 来源：Interconnects
- 链接：https://www.interconnects.ai/p/how-well-can-we-measure-open-model

## Claude Code 把用户邮箱写进 User-Agent，已修复

- 来源：Hacker News / GitHub Issue
- 链接：https://github.com/anthropics/claude-code/issues/107757

## BUI：把 Blender 的界面拆成通用 UI 库

- 来源：Hacker News / GitHub
- 链接：https://github.com/ppmpreetham/BUI

作者把 Blender 的控件绘制与交互规则从原代码库中剥离，核心是一个小体积 C 运行时，上层提供 Python（含 tkinter/ttk 全量 7846 个公开名、Qt 风格 API）、Rust、JS/React/Svelte、C/C++ 与 Dear ImGui 绑定。没有浏览器引擎、没有 webview，布局输入绘制全在原生代码里跑，宣称比 GPUI 快一倍。数值框拖拽、模糊搜索、饼菜单这些 Blender 手感原样保留。

## musl 的星号密码账户能接受任意密码

- 来源：Hacker News / sshhole.com
- 链接：https://sshhole.com

作者用大量 Agent 并行对 sshd 做组合测试，发现 musl libc 在 `crypt()` 失败时返回 `*`，而 `/etc/shadow` 里锁定账户的占位符也正是 `*`，两者比对相等。结果是 musl + 不开 PAM + 允许密码登录 + 存在 `*` 账户这四个条件同时成立时，该账户接受任意 257 到 1024 字符的密码。Alpine 官方 AWS/Azure 镜像默认命中，且该用户有免密 doas，等价于 root。glibc、PAM、OpenBSD 均不受影响。
