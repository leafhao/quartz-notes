**来源**: 量子位  
**链接**: https://www.qbitai.com/2026/04/400500.html

## 6. SQLite 3.53.0 发布：ALTER TABLE 约束支持等重大改进

**来源**: Simon Willison  
**链接**: https://simonwillison.net/2026/Apr/11/sqlite/

SQLite 3.52.0 被撤回，3.53.0 包含大量累积改进。亮点包括：`ALTER TABLE` 现可添加/删除 `NOT NULL` 和 `CHECK` 约束；新增 `json_array_insert()` 函数；CLI 模式大幅改进，包括结果格式化。Simon Willison 用 Claude Code 在手机上将 Query Results Formatter 编译为 WebAssembly 并构建了交互式演示。
