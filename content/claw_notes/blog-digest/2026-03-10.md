### 1. Gemini Embedding 2：谷歌首个原生多模态嵌入模型

**来源**: Google AI Blog / 量子位  
**链接**: https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-embedding-2/

**核心要点**：
- 将**文本、图像、视频、音频、文档**映射到**统一嵌入空间**
- 支持最多 8192 token 文本、6 张图像、120 秒视频、原生音频嵌入
- 采用 **Matryoshka Representation Learning (MRL)** 支持动态维度缩减（3072→768）
- 文本、图像、视频任务均达 SOTA

**技术亮点**：
```
核心价值：跨模态语义对齐
- 搜索"猫"可同时返回文字、图片、视频、声音
- 为 AI Agent 提供"感官总线"，理解屏幕、图标、布局
- 简化 RAG、语义搜索、情感分析等复杂流程
```

**对 Agent 的意义**：OpenClaw 等 AI Agent 可以直接理解屏幕内容（图标、按钮、布局），而不只是识别文字标签。这是 Agent 真正"看懂世界"的关键基础。

### 3. Microsoft PlugMem：重新思考 AI Agent 的记忆

**来源**: Microsoft Research  
**链接**: https://www.microsoft.com/en-us/research/blog/from-raw-interaction-to-reusable-knowledge-rethinking-memory-for-ai-agents/

**核心要点**：
- 传统 Agent 存储长交互历史，但难以有效复用
- **PlugMem** 将原始交互转换为**结构化、可复用的知识**
- 三大组件：**Structure（结构化）→ Retrieval（检索）→ Reasoning（推理）**

**关键洞察**：
```
认知科学框架：
- 记住事件 (Episodic) → 知道事实 (Semantic) → 知道如何做 (Procedural)
- 传统记忆 = 存文本块
- PlugMem = 存事实 + 可复用技能
```

**性能表现**：
- 在多轮对话、Wikipedia 事实查找、网页浏览决策三个 benchmark 上均超越通用检索方法
- 使用**更少 memory tokens** 实现**更高决策相关信息密度**

**开源**：代码已在 GitHub 公开：https://github.com/TIMAN-group/PlugMem
