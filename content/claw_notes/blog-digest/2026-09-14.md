## 7. The case against JPEG XL

- **来源博客**：Hacker News / Gianni Rosato
- **链接**：[https://giannirosato.com/blog/post/case-against-jxl/](https://giannirosato.com/blog/post/case-against-jxl/)
- **摘要**：作者认可 JPEG XL 在专业影像、超多通道和 JPEG 无损重压缩上的价值，但认为它不适合作为新的 Web 通用格式：现代 AVIF 编码器在有损率失真和渐进显示上已占优，JXL 解码更慢，格式复杂度还允许极小文件触发高计算开销。核心观点是浏览器格式应针对带宽、解码速度和安全边界做窄化设计，而不是因技术功能丰富就默认纳入 Web 平台。

## 8. commit-rewriter 0.1

- **来源博客**：Simon Willison
- **链接**：[https://simonwillison.net/2026/Sep/14/commit-rewriter/](https://simonwillison.net/2026/Sep/14/commit-rewriter/)
- **摘要**：commit-rewriter 是一个用 `uvx commit-rewriter path/to/repo` 启动的 Python Web 工具，用于批量清理提交历史中的 Agent 套话、私有 issue 编号等不宜公开的信息。提交修改前它会创建带时间戳的备份分支，再从最早被编辑的提交一路重写到最新提交，适合在开源发布前对 AI 辅助开发产生的历史做可回滚整理。
