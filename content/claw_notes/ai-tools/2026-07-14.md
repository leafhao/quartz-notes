## 代码生成工具

### OpenAI Codex + ChatGPT Work（7月9日）
- **GPT-5.6 正式发布**：包含 Sol、Terra、Luna 三个变体，经美国政府安全审核后上线
- **ChatGPT Work**：全新工作场景 AI Agent，将 Codex 能力扩展到非编码任务。可跨连接的应用和文件收集上下文，自动创建文档、表格、演示文稿等
- 支持 Mac/Windows 桌面端，所有付费层级可用
- 来源：[The Verge](https://www.theverge.com/ai-artificial-intelligence/963464/openai-gpt-5-6-codex-chatgpt-work)、[Axios](https://www.axios.com/2026/07/09/ai-openai-gpt-release)

### SpaceXAI x Cursor 联合模型（7月8日）
- SpaceXAI（原 xAI）与 Cursor 联合发布编码优化模型
- **Grok 4.5** 定位为"最强编码和 agentic 任务模型"，是 SpaceXAI 与 Cursor 合作后的首个联合发布
- 背景：SpaceX 6月宣布以 $600 亿全股票收购 Cursor 母公司 Anysphere
- 来源：[Let's Data Science](https://letsdatascience.com/news/spacexai-and-cursor-launch-joint-ai-model-b6e03e72)、[Gizmodo](https://gizmodo.com/new-name-new-grok-spacexai-officially-ties-its-brand-to-the-worlds-most-problematic-chatbot-2000783130)

### Perplexity "Teammate" 编码助手（7月7日曝光）
- Perplexity 内部开发的 AI 编码工具，代号 **Teammate**
- 面向长期工程任务（long-horizon engineering work），公司工程师自 5 月起已内部使用
- 直接对标 Cursor 和 Claude Code
- 来源：[Business Insider](https://www.businessinsider.com/perplexity-building-ai-coding-tool-take-on-cursor-and-openai-2026-7)

### Microsoft 365 Copilot 升级（7月10日）
- GPT-5.6 正式成为 Microsoft 365 Copilot 底座模型
- 来源：[Zamin.uz](https://zamin.uz/en/technology/211561-openai-and-microsoft-partnership-enters-a-new-phase-gpt-5-6-model-becomes-the-foundation-for-copilot.html)

## 图像生成工具

### Meta Muse Image（7月7日）
- Meta 超级智能实验室（Superintelligence Labs）推出首个图像生成模型 **Muse Image**
- 已集成到 Meta AI App、Instagram、WhatsApp，即将登陆 Facebook 和 Messenger
- 亮点：可引用公开 Instagram 照片作为图像生成素材（引发隐私讨论）
- 同步推出 AI 图像检测工具（但 Reuters 测试发现裁剪后检测失败率较高）
- 来源：[The Verge](https://www.theverge.com/tech/962485/meta-muse-image-ai-model-instagram)、[TechCrunch](https://techcrunch.com/2026/07/07/meta-rolls-out-muse-a-new-ai-image-generator/)、[Reuters](https://www.reuters.com/business/meta-ai-image-detector-fails-identify-some-its-own-cropped-ai-images-reuters-2026-07-10/)
