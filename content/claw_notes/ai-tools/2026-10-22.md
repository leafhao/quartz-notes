# AI 工具推荐｜2026-10-22

**本期速览**：窗口三天（10-20 → 10-22），主线是「Agent 从演示件变成可交付件」——常驻进程（Claude Duet）、可自托管（Brain v2）、可审计（Claude Security）、可计量（Baseten / 蚂蚁决策模型）。生成侧退到次要位置，但视频赛道仍在拼「一条过」的时长。

---

## 一、编码与代理

### Claude Duet（10-21，研究预览）
Anthropic 第一个「主动式」Agent 独立应用，基于 Opus 5.5，iOS / Android / claude.ai 三端。自带浏览器虚拟机，用户关机后仍在后台跑；早晨推简报，白天只在有事时找人。接 Claude Marketplace 逾 6000 个连接器，发消息、付款、签文件、删数据前必须确认；不接触密码与登录令牌，新增专用分类器拦截信用卡号与身份证件外泄。先向美国 Pro / Max 候补开放。官方自承：会误读对话、误判紧急度，个人事务（如买票）表现较弱。
https://claude.com/resources/articles/claude-duet

### Recursive Flint（10-21）
伦敦实验室 Recursive（Richard Socher 带队）首个模型。39.8B 总参 / 2.5B 激活，256 专家选 6 + 1 共享，262K 上下文，Apache 2.0，权重上 Hugging Face。M4 Pro 上 125+ tok/s、RTX Spark 上 150+ tok/s，48GB 内存可本地跑 Agent 编码。自报 SWE-bench Verified 74.2%、Terminal-Bench 2.1 54.9%。训练由内部自动化研究系统 Eureka Machine 参与架构搜索、4bit 输出层量化和 Metal megakernel，小团队不到四个月完成。
https://recursive.com/updates/introducing-recursive-flint
https://huggingface.co/RecursiveSI/flint

### Claude API 2026-10-21（10-21）
2023 年以来首个正式 API 版本。`temperature` / `top_p` / `top_k` 一律返回 400（即便传默认值）；助手消息里的 document block、用户文本块的 citations 同样 400。SDK 全量进大版本：Python 2.0.0、TS 1.0.0、Go 2.0.0（走 /v2）、Java 3.0.0、C# 13.0.0、PHP 1.0.0、Ruby 2.0.0、ant CLI 2.0.0；鉴权改 `Authorization: Bearer`，许可从 MIT 转 Apache 2.0。旧版 2023-06-01 不日落，Claude 4.7+ 行为不变，Sonnet 4.6 这类老模型降温度的效果没有替代项。Bedrock 上仅 4.7+ 可用新版。
https://platform.claude.com/docs/en/api/migration-2026-10-21

### Brain v2（10-21，MIT 开源）
AEXHQ 的自托管 Agent 服务器，明确定位为 Claude Managed Agents / OpenAI Agents SDK 的开源替代。会话跨连接与重启存活，事件有序可回放；harness 可插拔，checkpoint 让会话能在服务器之间迁移。工具与内核解耦，模型只看到本会话显式启用的工具。需 Go 1.26+ / Node 24+，有 TS 与 Python SDK。
https://clawdbytes.com/article/2026-10-22-brain-v2-a-minimal-and-extensible-agent-server-for-building-agent-applications.html

### Railtracks Swift ADK（10-21，MIT）
Railtown 把已有 Python 框架扩到 Apple 生态，原生 Swift 可做推理、工具调用、结构化输出、多 Agent 编排、执行追踪与护栏，接 OpenAI / Anthropic / Gemini，也能用设备端 Apple Intelligence。
https://www.fortmcmurraytoday.com/press-releases/newsfile/railtown-ai-open-sources-railtracks-swift-adk-expanding-apple-developer-access-and-creating-new-pathways-to-conductr-platform-adoption

### Codex 缓存（10-21）
登录用户的会话缓存改为永久保留，隔几小时回来续聊仍命中缓存；API 侧提示缓存延长到 12 小时。同一批指令整天重发不再重复计费，是本周最省钱的一条。
https://developers.openai.com/api/docs/guides/prompt-caching

### Claude Security（10-21，企业公测）
接仓库后先做深度基线扫描，再按变更风险与复杂度定期扫。修复合入即标为已修复，复现自动重开；安全团队可补部署环境、编辑威胁模型以判断可达性。补丁仍须人工批。支持 API / webhooks / MCP 连接器，按 token 成本计费，不收平台费。
https://claude.com/resources/articles/claude-security-now-scans-continuously-and-tracks-fixes

### Qoder 国际版 Lite（10-21）
新增 10 美元/月档，含 1000 Credits，功能不阉割但模型范围与用量受限。10-21 起续费按档位加赠 500–3000 Credits。
https://docs.qoder.cn/events/bogo7

### ilha（10-22）
Mac 刘海直接显示 Claude Code 与 Codex 的用量上限，省得反复切面板查额度。
https://startupcorners.com/digest/product-digest-2026-10-22

## 二、Agent 技能（可直接装）

### Dashboard Design（10-20，MIT）
Claude Code 技能，专门做 KPI 卡、图表、日期选择器和手机布局；每单结尾强制截图自检，「judge 屏幕而不是 judge 代码」。
https://munderdiffl.in/blog/agent-tools-today-2026-10-21

### Motion2Code（10-20，MIT）
把一段动效设计视频还原成单条 GSAP 时间线驱动的内联 SVG，再逐帧和源视频比对；网站/App 录屏则直接生成可交互页面。README 列出 Claude Code、Codex、Cursor、Copilot、Gemini。
https://munderdiffl.in/blog/agent-tools-today-2026-10-21

### BetterSearch（10-18，MIT）
基于 DeepSeek 新搜索 API，负责改写查询、并行检索、加一道事实核查，最后出干净报告。支持 Claude Code、Codex、Cursor、Gemini CLI、OpenCode。
https://munderdiffl.in/blog/agent-tools-today-2026-10-21

## 三、图像与视频

### Krea 3 Ultra（10-20 转正）
Ultra 从预览转为 Max 及以上计划的普通参数（`thinking_mode: "ultra"`），同一端点、不出新权重：生成多个候选、按提示词与参考图自己打分再返回最好的那张。只出 2K、必须带参考图、单张可能要几分钟。Artificial Analysis 编辑榜 10-20 记 1150.58，与 Nano Banana 2.1、MAI-Image-2.6 三者统计并列（3–6 名），Fast 档 1125。$0.03/1K、$0.06/2K，快档 2K 编辑 8 秒内。
https://www.krea.ai/krea-3

### Google 品牌资产工具（10-21）
Gemini 商用版新增品牌资产生成：上传品牌包后跨战役保持视觉一致，底层走 Nano Banana 2.1，直接打通 Workspace、Adobe、Canva。
https://themagnifier.ai/today

### Runway × Grok（10-21）
MCP 接入，在 Grok 对话里直接生成视频与静帧，可花账户原生 Runway credits，成品存进 Runway 库，可选 Gen-4.5、Veo 3.1。
https://runwayml.com

### LTX Desktop 1.3.0（10-21）
Lightricks 本地视频工作台改版：新增图生视频、音频驱动视频、重拍与延长控制，跨平台本地渲染的内存占用优化。
https://www.lightricks.com

### Kling 4.0 API（10-21）
企业版与开发者 API 首发上线，逐步对全球开放。单次原生 30 秒、最多 10 张关键帧、15 项多模态参考、4K/1080p 10-bit HDR、21:9；已同步接入爱奇艺纳逗 Pro、Higgsfield、Magnific、美图、腾讯 WorkRally / OnSolo / Miora 等。
https://klingai.com

### VideoGen Model 1（10-20，YC）
单个提示词生成最长 10 分钟多镜头成片，AI 自己规划剧本、对白、分镜与节奏，支持文生/图生视频（最多 16 张参考图），音视频联合注意力架构。自报成本比可比模型低 50%+，限量合作伙伴，100 万美元创作者额度发到年底。数据出自厂商内评，需第三方验证。
https://www.163.com/dy/article/L9S77TIV0511ABV6.html

### Seedance Managed Agent（10-21）
火山引擎把 Model API 升级成 Agent API：基于 Seedance + Seedream，自研 Harness 负责拆任务与管上下文，Skills 沉淀流程。官方称短剧/图片/组图综合质量 +17%，剧本与分镜未遵循 −67%、剧情混乱 −54%、图片编辑一致性 −50%、组图一致性 −60%；电商可出详情页纵向长图。支持插拔 MCP 与 Skills、对接自有素材库，火山方舟控制台接入。
https://www.jiemian.com/article/15217301.html

### ElevenCreative Chimera（10-21）
ElevenLabs 创作台上线，把 Seedance 2.5 与自家 Eleven v4 配成一对：一个管脸，一个把情绪放进声音。
https://elevenlabs.io

### SKY-001（10-19，补录）
Skyfall AI（Maluuba 原班人马）的「工程世界模型」，CAD/BIM 场景：层级化组件器先把整机拆成总成再到零件（一辆胖胎山地车 988 个零件），构建世界模型再规划每个零件的成形步骤与草图。自报比 GPT-6 Astra 快 51–125 倍、便宜 150–210 倍，IoU 79.7% vs 79.1%。只有 waitlist，无 API、无定价、无权重；测试集与裁判均由自家设定，尚无第三方复现。
https://www.i-scoop.eu/sky-001-engineering-world-model

### Tripo EdenLive（10-21）
实时生成式渲染架构，做可响应的虚拟环境，面向实时 3D 空间生成与动态场景。
https://www.tripo3d.ai

## 四、音频与语音

### HeyGen Voice Turbo（10-21）
Artificial Analysis 受控语音榜第一（1202 Elo，压过自家上一代 1195 与 Qwen-Audio-3.1-TTS-Plus 1184），价格却从 $30 降到 $4/百万字符。API 模型 ID `heygen-voice-1-turbo`，11-30 前免费（尽力而为，限流返 429），可用公开音色与即时克隆。注意：样本量 1685 票，比榜下几位的证据更薄，前三名 AA 自己也没分开。
https://www.heygen.com/blog/heygen-voice-turbo

### Mistral Voxtral 3（10-20）
五个语音模型 + 基于 LiveKit 的语音 Agent SDK：Small/Mini/Realtime 三个转写（50 语种，含 24 种欧盟官方语，带说话人分离与上下文偏置）、Mini TTS 3（35+ 语种、50+ 方言，按上下文调情绪语速）。听、想、调工具、说同一条流式管线，SIP 接电话、WebRTC 接浏览器。一通语音 Agent $0.04/分钟（Small 4 推理）、$0.08（更大模型）；转写 $0.0035–0.008/分钟；TTS $13/百万字符。权重是否开源未说明，本地部署走销售。
https://mistral.ai

### IBM Granite Speech 5.0（10-21）
`granite-speech-5.0-2b` 上线 Hugging Face，Apache 2.0。英法德西葡日转写 + 与英语双向翻译，另支持英译意/普通话；抗噪、抗混响与长语音对话翻译较前代改善，可用提示指定输入语言、最多 2000 关键词引导。
https://huggingface.co/ibm-granite/granite-speech-5

## 六、框架与基建

### Exa 3.0（10-20）
面向 Agent 的搜索 API 大改：更大嵌入模型 + 新增数十亿文档（12.7 亿电商商品、2.11 亿本地商户）。Dynamic Highlights 转正不额外收费，跨结果挑 token，比整页文本省 95%。Exa Lite $4/千次、Exa Auto $7/千次，同一索引。基准为官方自报（称 8 项领先 Perplexity、Brave、Parallel）。
https://exa.ai

### Respan（10-21，YC W24）
Rust 写的开源 AI 网关，内核极小、一切皆插件：provider、协议（MCP、voice）、能力（回退、PII 脱敏、智能路由）。团队称此前基于 LiteLLM 的封装一度超过 10 万行。
https://startupcorners.com/digest/product-digest-2026-10-21

### Baseten mammoth-1 / elephant-1（10-21）
27B 与 9B 两款决策模型，开源。不生成文本，一次前向直接返回各候选答案的概率分布，只做三类任务：多选一、按量表打分、是或否。自报 mammoth-1 在 Jev Decision Index 0.4 第一、elephant-1 在 AA Decision Index 并列第一。经 Vercel AI Gateway 免费到 10-27，Baseten Model APIs 可试，默认零数据保留。
https://www.baseten.co/blog/the-best-decision-models-in-the-world-mammoth-1-and-elephant-1

### 蚂蚁 LingDT-Decision-1.0（10-22）
4B / 27B 两版，首创原生多选与按序（DAG）决策，适配多步业务流程。官方称同任务比大模型省 90%+ token、响应快 10 倍，27B 在同参数量里准确率最高；23 项开源基准上超过 Microsoft-Decision-1、Jev 1.13。已上 DTMaaS，限时免费。
https://www.donews.com/news/detail/1/6750429.html

### DeepInfer（10-21，Apache 2.0）
DeepSeek 把支撑自家线上服务的推理框架开源，另附 token 编解码组件 `deepseek-recipe`（MIT）。支持 NVIDIA SM100 与华为昇腾 950，prefill/decode 分离、KV 缓存集中管理（命中率 96%）、滑动窗口注意力、专家并行；单集群日服 155 万亿 token，线上首字延迟 400ms、生成 230–300 tok/s。只支持 V4.1 Flash。
https://munderdiffl.in/blog/agent-tools-today-2026-10-21

### Mouse-1（10-22）
专为 Agent harness 设计的决策模型，给多步流水线补结构化判断。
https://startupcorners.com/digest/product-digest-2026-10-22

### Alter（YC S25，10-22）
多用户 Agent 的访问控制层，解决「Agent 代表很多用户、却用一把共享密钥鉴权」的窟窿。
https://startupcorners.com/digest/product-digest-2026-10-22

https://cohere.com/blog/rerank-5
