## 1. Claude Docs & Slides：文档和幻灯片直接长在对话里

**发布日期：2026-09-16｜类型：文档写作 / 办公**

Anthropic 把 Claude Chat 和 Cowork 合并成「一个 Claude」，同时上线 Claude Docs 和 Claude Slides（beta），并把 Claude Design 收进对话。用户不再需要先判断任务该放哪个入口——Claude 自己决定要不要调工具、要不要长时间跑。

**为什么值得试**

- 报告和幻灯片出自同一段对话，幻灯片的数字天然和报告对齐，省掉手工搬运。
- 文档支持共享链接与行内评论，可导出到 Google Docs / Word，演示稿可导出 PowerPoint / PDF。
- 关掉笔记本后任务继续在云端跑，手机上能看进度、能中途改方向。
- 默认权限是「每次动手前先问你」，可以切成自动模式但保留安全检查。

**建议用法**：拿一份你每周都要手写的周报做对照——让 Claude 从数据到五页汇报稿一次出完，重点看跨格式的上下文是否真的没丢。Pro / Max 优先灰度，Team 与 Free 后续跟进；企业版管理员有至少 30 天通知期。

来源：[Anthropic 官方发布](https://claude.com/blog/cowork-is-now-claude) · [Unite.AI 复盘](https://www.unite.ai/anthropic-folds-cowork-into-a-single-claude-experience-across-plans)

## 2. 腾讯 BrowserSkill：让 Agent 借用你已经登录的浏览器

**发布日期：2026-09-16｜类型：开源 Agent 工具 / 浏览器自动化**

腾讯开源了 BrowserSkill（MIT 许可），思路和主流方案相反：不另起一个干净的自动化浏览器，而是让 Agent 借用你真实浏览器里已登录的标签页，用完归还，其余窗口不碰。上线一天多已到 2.1k GitHub star。

**为什么值得试**

- 复用真实登录态，不用再给 Agent 配测试账号、绕过风控。
- 它是 CLI（`bsk`）而不是 MCP Server，任何能调 shell 的 Agent 都能用，不绑定模型或框架。
- 内置 human-in-loop：遇到验证码、登录、确认弹窗时主动请你接管，处理完继续。
- 借标签页的权限开关放在浏览器设置里，不是命令行参数，提示词绕不过去。
- 明确列出兼容 Cursor、Claude Code、Codex、OpenClaw、CodeBuddy、WorkBuddy、Hermes Agent 等。

**建议用法**：先只给只读研究类任务开放，观察 `bsk` 调用日志里有没有越界访问的站点；涉及支付、后台管理的账号不要放进被借用的浏览器 profile。

来源：[GitHub: Tencent/BrowserSkill](https://github.com/Tencent/BrowserSkill)

## 3. Google Home MCP：智能家居第一次向通用 Agent 开放

**发布日期：2026-09-16｜类型：MCP / 消费级智能家居**

Google 开放 Home MCP 早期访问，任何支持 MCP 的 Agent（Google 点名了 Antigravity、Claude、Hermes、OpenClaw）都能读写 Google Home 生态的设备与事件历史。服务器暴露五个工具，覆盖枚举、实时状态、设备控制与历史查询四类能力。

**为什么值得试**

- 从「把灯打开」升级到「昨天下午家里发生了什么」——事件历史查询让 Agent 能回答过去时的问题。
- 覆盖 Nest 门铃/温控器，以及 Works with Google Home 与 Matter 设备，等于打通 100+ 品牌。
- 另有一个无关隐私的 Home Developer MCP，把 Home API、Matter 1.5.1、Thread 1.4.1 文档直接喂给编码工具，且无需凭据即可试用，是更容易上手的那一个。

**注意**：早期访问限美国 Google Home Premium Advanced（$20/月）订阅用户、英文环境；开门等敏感动作被服务端硬性禁止，人脸数据需结构管理员单独授权。

来源：[Unite.AI 报道](https://www.unite.ai/google-opens-home-mcp-early-access-to-ai-agents-for-smart-home-control) · [能力与配置详解](https://ai-tldr.dev/tools/google-home-mcp)

## 4. 智象 HD-V1：国产全模态视频模型，音画一次生成

**发布日期：2026-09-15｜类型：视频生成**

智象未来（HiDream.ai）发布 HiDream-O1-Video-1.0（HD-V1），首个原生全模态视频生成模型，支持文本、图片、视频输入，一次直出 5–20 秒 1080p 带音频的视频。发布同期完成 C+ 轮融资（新微资本、交子资本、工银资本）。

**为什么值得关注**

- 音画在同一生成过程里联合建模，而不是先出画面再配音——官方把口型与音效同步归因于此。
- 前置意图理解模块把口语化输入结构化成镜头时长、场景、运镜、台词等字段，降低跑偏概率。
- 生成时长交给内容决定，而不是硬填满固定秒数，避免「动作做完了画面还在等」。
- 厂商口径：Artificial Analysis 图生视频（带音频）榜全球第四，Arena.ai 图生视频盲测第八。

**建议用法**：目前仍是内测申请制，没有开放注册页也没放权重，不适合排进生产计划；可以拿一两个真实分镜试物理规律细节（重力、碰撞、惯性）是否可信，再决定是否等正式版。

来源：[智象未来官网](https://hidream.ai/) · [上证报报道](https://www.cnstock.com/commonDetail/790801)

## 5. ElevenLabs Music v2.5：免费层也能拿无损

**发布日期：2026-09-11｜类型：音乐生成**

ElevenLabs 发布 Music v2.5，成为 ElevenMusic 提示词与参考音频生成的默认模型。官方用同一提示词、两版各出一首的方式跑了 47,885 对盲测，v2.5 在多数情况下胜出，差距在人声主导、原声乐器多的 R&B、灵魂乐、嘻哈、摇滚、金属、管弦与电影配乐上最明显。

**为什么值得试**

- 无损下载下放到所有套餐：Free 每天 5 次，Pro 每月 400 次。
- 授权随作品保留——取消或降级订阅不改变已生成音轨的使用权限。
- 已进入 ElevenCreative 与 API，可作为 Flows 里的节点给视频配乐。

**注意**：基于其他艺人歌曲创作的音轨禁止下载；官方同时提示与 UMG 的多年授权协议是另一件事，v2.5 未使用 UMG 艺人素材训练。

来源：[ElevenLabs 官方博客](https://elevenlabs.io/blog/music-v2-5-model) · [MBW 报道](https://www.musicbusinessworldwide.com/elevenlabs-launched-music-v2-5-shortly-after-announcing-its-umg-licensing-deal/)

## 6. OpenHands 1.0：开源编码 Agent 进入生产可用

**发布日期：2026-09-08（1.0 正式版），2026-09-11（Agent Canvas 1.18）｜类型：代码生成 / 开源 Agent**

All Hands AI 把 OpenHands（原 OpenDevin）推到 1.0，MIT 许可，GitHub 约 8.8 万 star。配 Qwen3-Coder-480B 在 SWE-bench Verified 上解出 68%，换 Claude Sonnet 4.5 + extended thinking 提到 72%；配套 Agent Canvas 在 09-11 更新到 1.18，收紧了自动化权限。

**为什么值得试**

- 三条支柱：容器级沙箱隔离、BYOM（任意模型 API 或本地模型）、插件系统。
- 支持 100+ 模型供应商，可以把高价值任务路由给前沿模型、把 routine 分诊交给便宜模型。
- Agent Canvas 1.18 只允许自动化创建者重新启用被停用的任务，并显示任务以什么身份执行——做权限审计时很受用。
- 自托管成本口径约 $0.20–1.05 / 每个解决的任务（H100 算力），远低于订阅制商业产品。
- 用真实 trace 回放对比「成功率 / 恢复能力 / 总成本」，而不是只看 SWE-bench 分数。

来源：[GitHub: All-Hands-AI/OpenHands](https://github.com/All-Hands-AI/OpenHands) · [Automation 权限更新说明](https://aicybr.com/blog/openhands-1-18-automation-permissions-agent-canvas)

## 尝鲜优先级

1. **立刻可用**：Claude Docs & Slides，Pro / Max 灰度中，先拿周报做对照实验。
2. **本机可装**：腾讯 BrowserSkill，MIT 许可，一行命令装给现有 Agent，风险点是登录态复用。
3. **内容生产**：ElevenLabs Music v2.5 免费层即可验证；HD-V1 仍需申请内测，先观望。
4. **工程团队**：OpenHands 1.0 用真实 issue 做一轮自托管成本与成功率评测，重点看沙箱与权限边界。
5. **智能家居**：非美国 Advanced 订阅用户暂时用不上 Home MCP，但可以先用无需凭据的 Home Developer MCP 试水。
