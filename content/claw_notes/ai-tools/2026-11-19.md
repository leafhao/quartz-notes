# AI 工具推荐 2026-11-19

> 搜索窗口：2026-11-17 → 2026-11-19（2 天，承接上期）。主线是**各家把「同一个任务更便宜地做完」当成卖点**——微软 Ignite 用「98% 性能、40% 成本」报价，OpenAI 把 Astra 降到 $8/$40，Google 补上中间价位的 Neon；工具侧则出现同一批动作：编码工具集体在缓存和浏览器登录态上找省钱空间。

## 编码与代理

- **微软 MAI Code 2 / Code 2 Flash**（11-17，Ignite 2026，GitHub Copilot 与 Foundry 正式可用）— 微软自研编码模型的第二代，定位「把代码送进生产、深调试、多文件改动、全仓库推理」。官方口径：Code 2 达到 GPT-6.1 Sol 的 98% 性能、40% 的成本，以及 Claude Opus 5.5 的 96% 能力、约 5% 的 token 价格；注意这两组数字用的是 50% 促销价，且官方明说「未针对超长程 agent 任务调优」。Flash 版面向高频小改动，Foundry 侧仍是限量预览。同批还发了 MAI Cyber 2 Flash、MAI Image 2.7 系列、MAI Realtime 1，以及 MAI Licensed Weights——把权重授权给企业客户在自有 Azure 环境里微调，不是公开下载。
  https://blogs.microsoft.com/blog/2026/11/17/ignite-2026-building-the-frontier-ecosystem
- **Claude Code v2.1.327 / v2.1.328**（11-18 至 11-19）— 两个都小但都对着实际问题：`claude mcp add-json -` 支持从 stdin 读 JSON，MCP 令牌不用再出现在命令行历史里（该命令在会话内不可用）；`mcp_tool` 钩子新增 `"onFailure": "block"`，钩子调用失败时可以拦住这一步动作而不是放行。另有 Cursor / Windsurf / Antigravity 的内置终端被单列，不再和 VS Code 归为一类。
  https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- **OpenCode v2.3.2**（11-18）— 修掉一个烧钱的 bug：GPT-6.2 系列此前每一步都把系统提示当作未缓存输入重新计费，在 GitHub Copilot 的 gpt-6.2-sol 上，单步未缓存输入从约 14,000 token 降到 3。v2.3.1 则把「超时仍在跑的 shell 命令」从直接杀掉改成转后台继续。
  https://opencode.ai
- **Google Antigravity 界面改版**（11-18）— 从「和一个 agent 对话」改成「管一批正在跑的 agent」：所有 agent 的状态与入口摊在一屏，需要人处理的排最前、后台任务退后。输入框（Composer）顶部就能切 Git 分支、新开 worktree、选本机还是云端跑——把隔离放在发任务那一刻而不是事后。默认主题换成新的深色。同期 CLI 发到 1.5.11，支持把子 agent 从侧栏拖进输入框变成 @ 提及、`agy plugin validate` 可直接校验 GitHub 仓库或 zip、附件上限提到 20MB。
  https://antigravity.google
- **Mistral Vibe 桌面版**（11-19，macOS / Windows）— 编码 agent 有了桌面客户端，agent 可跑在本地也可跑在远程。同周 Vibe 3.1.3 把默认模型从 Medium 3.5 换成 Mistral Large 4，新增 `/goal`（跨轮保持一个目标）、`pre_llm` / `post_llm` 钩子、`/loop` 定时运行管理器；另有一个不太友好的改动——项目配置只能关闭用量遥测，不能再打开。
  https://mistral.ai/news
- **OpenCode Browse v0.1.0**（11-16，HN 331 分）— 用 Rust 重写成一个小二进制，同时充当 CLI、中继和 MCP server。核心卖点是 agent 直接驱动**你自己那个浏览器**：带着你的标签页、登录态和扩展，不用另起一个干净的 Chromium 再去登录一遍。和同期 Product Hunt 上的 Beacon 是同一思路的两条实现。
  https://opencode.ai

## 框架与开源

- **OpenAI Agents SDK v0.25.0**（11-17，Python）— 移除 beta 的 Runloop 沙箱 provider（含 extra 与导出），迁移目标是 Modal，但旧会话 ID 与快照无法直接续跑；RunState 升到 schema 1.22 以支持嵌套工具审批的恢复，v0.24 的 worker 不认新检查点，共享检查点的要先升读取端。handoff 新增可选的 `failure_error_function`，不传则维持抛异常。MCP v2 的 Streamable HTTP 支持并发请求，v1 仍是串行。
  https://github.com/openai/openai-agents-python/releases
- **LangChain 1.5.0**（11-18）— 主版本跳号带来了模型路由：新增 model router 中间件与 auto mode 中间件，请求可以按规则或自动分流到不同模型；模型拒答统一成标准 content block。代价是 Python 3.10 支持终止，最低 3.11，langchain-core 最低 1.8.0。这版对「同一应用里强模型+便宜模型混跑」是刚需补齐。
  https://github.com/langchain-ai/langchain/releases
- **MBZUAI K2-Horizon 模型族**（11-18）— 六款，从 0.9B 稠密到 375B-A23B MoE 旗舰，按 LLM360 标准连中间检查点、约 10T 合成预训练 token 与数据管线、全部训练评测代码一起开放。旗舰自报 Toolathlon-Verified 65.3，称领先 GLM-5.2 与 MiniMax。**开放进度要看清**：目前只有 3.7B 与 7B 权重完全放出，375B 与 36B 的检查点和数据官方标「即将放出」。
  https://huggingface.co/MBZUAI
- **Raon-1-nano**（11-18，KRAFTON AI，Apache 2.0）— 约 31 亿总参 / 15 亿有效参数，韩英双语，线性注意力与全注意力混合的稠密架构，原生 262,144 token 上下文。提供 GGUF、MLX、LiteRT-LM 三种部署形态，指向本地助手与移动端控制这类场景。
  https://huggingface.co/KRAFTON

## 文档与办公

- **Copilot Workspaces**（11-17，Frontier 早期访问）— Copilot Notebooks 的继任者：人和 agent 共享一个项目的文件与会话，而不是把某人私聊里的答案传来传去。同场 Office in Copilot 正式可用——Word、Excel、PowerPoint 直接在 Copilot 里开，不用跳出去。Autopilot 也开始向 Frontier 客户铺开，它有独立的 Entra 身份、指定管理者和收窄的权限，解决「任务在主人签字之后继续跑」时该记谁账的问题。
  https://blogs.microsoft.com/blog/2026/11/17/ignite-2026-building-the-frontier-ecosystem
- **Gemini API 直接吃 Office 文件**（11-18）— Word、PowerPoint、Excel 与 OpenDocument 格式可以直传，不再需要先转 PDF 或抽文本。更实用的是切片：提示词和函数返回里都能指定页码范围、工作表与单元格区域、音视频时间段，以及「页面图像 / 抽取文本 / 公式 / 视频转录」这类内容层，只处理并只为用到的部分付费。对长报表和长会议录像是直接的降本。
  https://ai.google.dev/gemini-api/docs/changelog
- **Microsoft IQ**（11-17，Ignite）— 给 agent 一份统一的企业上下文：把业务语义层、企业知识和工作上下文装成一套服务，让不同 agent 看到的是同一套「公司是什么、数据怎么理解」。配套 Agent 365 已接入超 5,000 万个 agent，并新增 Business Analytics，按用量把花费和产出对起来——定位就是 AI 用量的 ERP。
  https://blogs.microsoft.com/blog/2026/11/17/ignite-2026-building-the-frontier-ecosystem
- **Perplexity Teammates 上移动端**（11-19，iOS / Android）— 多人协作的 Teammates 与「多 agent 努力度」档位同步进手机端，Teammates 还支持语音控制。仅 Max 订阅可用。桌面端 11-05 首发，这次是把「一群 agent 分头干活」搬到手机上。
  https://www.perplexity.ai/hub/blog
- **Figma 一次生成多张图**（11-18）— Make image / Edit image 现在可以一次出 2、4 或 6 张，省掉反复改提示词；也可以把同一个提示词同时丢给最多三个图像模型，并排看各自的理解再挑。属于「把模型当成可比较的供应商」这种产品化做法，设计工具里第一次这么直白。
  https://www.figma.com/release-notes/

## 图像与视频

- **可灵 Kling Image 4.0**（11-17 晚，Kling Creative Studio 与 API）— 架构换成「理解生成统一」的自回归框架。三个硬指标：首次支持原生 8K 出图；单张图内可生成最多 2,000 字，配 70 余款商用字体，支持中英日韩西葡六种文字；一次描述最多出 10 张风格一致的系列图，并能生成电商详情页、网页设计长图，长图可拆图层单独重绘。群像场景专门治「千人一面」。
  https://kling.ai/blog/kling-image-4-stunningly-realistic-sharp-precise
- **微软 MAI Image 2.7 / 2.7 Flash**（11-17，Foundry 公开预览）— 编辑能力在 Artificial Analysis 图像编辑榜登顶（Elo 1215），比 GPT Image 2.6 Sunburst Max 高 4 分，价格约后者五分之一。两个档位：标准版每百万图像 token $34，Flash 版 $10，不到三分之一。最大输出 2048×2048，支持透明背景。
  https://microsoft.ai/news
- **Suno Visuals**（11-17 上线网页，移动端随后）— 音乐平台第一次跨到视频：选中歌曲某一段，用内置角色、自己的照片或纯提示词生成最长 15 秒的对口型片段，再在时间轴上拼成完整 MV，可调歌词字幕字体颜色与画幅。底层模型叫 H3 Move，基于 MiniMax 的 H3 微调。**算钱要看清**：视频积分与音乐积分分开，$14.99 买 2,500 积分约 75 秒，$120/月的 Platinum 含 20,000 积分约 11 分钟，折下来每分钟十美元出头，反复重生成会翻倍。
  https://suno.com/blog
- **HeyGen Avatar 6 / Avatar 6 Turbo**（11-17）— 音频驱动的数字人换代：模型会读脚本，跟着内容给表情、手势和情绪，缓解 AI 视频里动作重复或不自然的老问题；支持 175 种以上语言及方言的音素级对口型。价格是这次的重点——2K 下每秒 $0.145、1080p 每秒 $0.10，Turbo 版砍到 $0.0875 / $0.05，一分钟 1080p 对嘴视频约 3 美元。
  https://www.heygen.com
- **Apple FastFrames**（11-18，Hugging Face 开源）— 苹果放出的自回归两步视频扩散模型，两档：FastFrames-S（1.3B）与 FastFrames-L（14B），连训练与评测代码、论文一起开放。S 版在单卡 480p 下单步约 35 毫秒，第一次把视频生成压进「交互式」的速度区间。同批还放了一个优化过的 LingBot 1.3B，官方称比原版快 16 倍，配交互演示。适合做实时预览而不是出成片。
  https://huggingface.co/apple
- **Google Genie 4**（11-19，Project Genie，AI Ultra 订阅者）— 世界模型第四代：会话中途打的提示词能改天气、加角色、改剧情走向，第一次带上跟随场景变化的原生实时音频。新增一个帮你搭世界的 Project Genie agent，以及可分享、可二次改造的社区画廊；AI Pro 用户可排队。官方自己列了四件还没解决的事：镜头延迟、复杂物理、音频精度、长场景一致性。生成内容带 SynthID 水印。
  https://blog.google/products/

## 音频

- **火山引擎 SeedRealtime 1.0 API**（11-19）— 豆包实时音视频通话模型开放 API：端到端统一建模，不再走 ASR → VLM → TTS 的级联，能边看边听边说。级联方案的延迟与信息损耗是实时陪伴类应用最大的成本项，端到端是直给这一刀。面向智能助手、实时陪伴、实时客服这类场景。
  https://www.volcengine.com

## 模型侧

- **OpenAI GPT-6.2 Astra / GPT-6.2 Sol**（11-18）— Astra 面向最难的专业与科研任务，API 降到 $8/$40（缓存输入约 $0.4），Agents' Last Exam 78.3%、比上代高 5.2 个百分点，官方称同样任务成本不到上代三分之一；Sol 维持 $2/$10，定位日常业务，带 Fast 与 Ultrafast 两档。两者上下文均为 105 万 token，超过 272K 输入后单价翻倍。**口径提醒**：早期反馈里 Astra 在 Artificial Analysis 智能指数排第二，但 VentureBeat 引用的几位重度用户认为「真实工作里基本不能用」，榜单位置和日用体验这次分得比较开。
  https://openai.com/index/
- **Google Gemini 4 Neon**（11-18，同日 GA）— 补的是 Hydrogen（$1.5/$7.5）与 Carbon（$2/$10 促销价）之间的中间档：$3/$15，缓存输入 $0.15，100 万上下文，四档思考等级（默认 high，另有 xhigh），多模态输入含 PDF，输出仅文本。官方称编程 Agent 指数 58.6 排第一、任务成本比 Carbon 低约 32%，均为自报未独立验证。**买之前看两件事**：12-01 起 Carbon 与 Argon 价格翻倍，Neon 不变，届时就比它们便宜四分之一；Neon 默认思考档是 high，超时至少设 15 分钟。
  https://blog.google/products/gemini/

## 国内

- **范式 Phai-A1**（11-18，开源）— 主打推理效率：原生百万 token 上下文，可在个人电脑本地部署，官方称同卡同任务下比 Qwen 27B 快约 8 至 10 倍。面向代码开发、长文档理解与多步工具调用。两款模型均完成昇腾全流程训练优化后开源。
  https://www.4paradigm.com
- **范式 Phai-M1**（11-18，开源）— 视频生成侧，专攻真人影视场景：人物表情、肢体动作与画面细节，直指 AI 短剧里最常见的失真；同一生成流程里同步出画面与音频，省掉后期对轨。
  https://www.4paradigm.com
- **腾讯混元 Hy4 flash 开源**（11-18）— 上期推的是 API 侧定价，这次把权重放出来了：224B 总参 / 12B 激活的稀疏 MoE，多模态输入、原生 100 万上下文，开放标准版、FP8 版、Base 版三个权重，社区另有 GGUF 量化。适用长文档理解、企业检索增强与低成本私有化。首日 token 调用破 50 万亿。
  https://github.com/Tencent-Hunyuan/Hy4-flash
- **DeepSeek 免掉搜索费**（11-18）— 服务端搜索与网页抓取不再单独计费：DeepSeek 自家模型默认走 DeepSeek 的服务端搜索，其他模型默认走 DeepSeek Search API。对「让 agent 自己查资料」这类高频调用的应用，这是一笔直接消失的边际成本。同周 Harness 发到 dsh-v0.2.2-rc.5。
  https://api-docs.deepseek.com/updates

## 热榜

- **Maritime**（11-18，Product Hunt，YC F26）— 给生产环境 agent 用的托管云：管自定义运行环境和生命周期。它自己的论点值得记——沙箱只解决基础设施问题的一部分，真正难的是生命周期、监控和数据接入这段「不好看但必须做」的中间层。
- **BlankOut**（11-18，Product Hunt）— 在把文档丢给 AI 之前，先在设备本地把敏感内容涂掉。不上传、不依赖云端判定，适合合同、病历这类不能出网的场景。
