## 🔥 本周头条：MCP 2026-07-28 规范落地，Agent 生态换底座

**Anthropic 发布 MCP 史上最大规模升级**（7-29 公布 `2026-07-28` 规范，已进 RC）：

- **转为无状态架构** — 支持 Serverless 与边缘部署，可无限水平扩容
- **MCP Apps** — 对话框内嵌交互式 UI，工具不再只能返回文本
- **Tasks** — 长耗时异步任务原语，终于不用自己在工具层造轮子
- **EMA** — 企业统一身份认证，企业级鉴权标准化
- **MCP Tunnels** — 内网安全隧道 + 官方开发者监控看板
- 底层优化：多往返请求合并、头部路由、缓存、安全认证

生态站位：LangGraph / CrewAI / AutoGen / LlamaIndex Workflows / Microsoft Agent Framework
**全部已内置原生 MCP 支持**，Figma、Zoom 等已表态适配，官方给 12 个月旧版本兼容过渡期。

> 💡 对飞哥的意义：Hermes 的 native-mcp skill 之后要按无状态规范复查一遍配置；
> Tasks 原语可以直接替掉目前 cron 任务里手写的"后台跑+轮询"模式。

## 🖥️ Agent 运行环境（本周新品类）

这周冒出两个同一思路的产品，值得关注——**给每个 Agent 一台专属计算机**：

- **`@cloudflare/computer`**（08-04）：为每个 AI agent 分配独立计算环境，
  文件编辑 + 命令执行在同一个工作空间内完成，不用自己拼 sandbox
- **Manus "My Computer"**（08-04）：桌面应用形态，agent 直接操作本地环境

> 💡 这类产品在解决"agent 有工具但没有连续工作空间"的问题——
> 和 Hermes 的 terminal + computer_use 组合是同一个方向，但把状态持久化做进了产品层。
