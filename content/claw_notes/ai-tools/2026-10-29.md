## 编码与代理

### Cursor Agent SDK —— agent 变成一个文件夹
- 发布：2026-10-27 凌晨（官方 X 与文档同步上线），文档 `cursor.com/docs/agent-sdk`。
- 机制：提示词写在 `bot/instructions.md`，每个工具是 `tools/` 下一个 `.ts` 文件，`channels/` 决定从哪被唤醒（GitHub / GitLab / Bitbucket PR、Slack、webhook、cron），`evals/` 放评测用例。整个 agent 就是一个可 review、可 diff、可版本化的仓库。
- 底座：用的是 Cursor 自己做 Bugbot / Security Reviewer / Rollouts 的同一套框架；支持子 agent 委派与并行 subagent。
- 部署：`agent-sdk deploy` 推到 Cursor 托管环境给一个 URL；需要留在内网就跑容器，单 Node 进程，可上 K8s / ECS。
- 自带模板：安全审查、PR 自动修复、owners 策略路由、Linear / Jira 分诊。
- 案例：PGA Tour 称整套「软件开发工厂」都建在这上面。
- 官网：https://cursor.com/docs/agent-sdk
- 备注：npm 包名有 `@cursor/agent-sdk`（早期叫 `@cursor/bdk`）与 `@grok/agent-sdk` 两种说法，以官方文档为准；无公开 GitHub 源码仓库。

### GitHub Universe 2026（2026-10-28）—— 一整套
官方博客《Evolving every layer of the stack》+ changelog《GitHub Copilot app, Universe releases》。
- **Copilot app**：独立应用，从 issue 到 merge 在一个面里完成，不止写码——也能写规格、过设计、看 telemetry。
- **Copilot Fusion**：按任务自动决定用几个模型、用哪个。官方引用 Artificial Analysis Coding Agent Index：Fusion Max 与 Opus 5.5 Max 差距 2 分内，成本减半、单任务耗时少 40%。
- **Copilot projects**：跨仓库、全托管的并行 agent 会话，一个地方看进度（公测）。
- **Session continuity**：同一条云端 agent 会话在手机、VS Code、CLI、web 之间接力。
- **Copilot automations**：仓库内 AI 工作流，可按事件或定时跑，并能从历史结果里学、自己提改进让人批。
- **Copilot code review Max**：官方称在 ReviewBench 高危问题上 F1 最高；Lite / Balanced 走日常。
- **Computer use**：macOS / Windows 公测，可读应用内容、点控件、填字，覆盖没有 API / CLI / MCP 的老软件；每次控制前需批准，企业可整体关掉。
- **Chat 里出图**：自然语言生成与编辑图片，底层 GPT Image 2.5 Flare，直接存进项目；可选「Made with AI」水印（默认关）。
- **计费**：GitHub Enterprise 客户可不买 Copilot 订阅，按 AI credits 用量付费（销售渠道先行，自助「即将」）。
- 链接：https://github.blog/news-insights/company-news/github-universe-2026-evolving-every-layer-of-the-stack ｜ https://github.blog/changelog/2026-10-28-github-copilot-app-universe-releases/

### GitHub Agentic Workflows（gh-aw）转正
- 2026-10-28 GA，仓库 v1.0.1 于 10-27 发布。
- 做法：Markdown + YAML frontmatter 描述仓库 agent，编译成标准 Actions YAML 执行；引擎可选 Copilot、Claude Code、Codex、Gemini、Pi。
- 安全层：默认只读、不可信内容完整性过滤、agent firewall 沙箱容器、safe outputs 校验、改动落地前跑威胁检测 job。
- GA 新增：ARC runner 支持 Docker-in-Docker、AI credits 预估（`gh aw forecast`）、按任务类型路由模型、micro-VM 与跨仓库 enclave 隔离。
- 坑：官方明确提醒别在 `pull_request_target` 下 checkout 不可信代码；生成的 `.lock.yml` 必须一起提交并 review。
- 链接：https://github.com/github/gh-aw
