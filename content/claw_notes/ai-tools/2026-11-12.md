# AI 工具推荐 2026-11-12

> 搜索窗口：2026-11-10 → 2026-11-12。主线是**多智能体从「一个人指挥一群」变成「一群人共用一群」**，同时开源侧在图像（MiniMax H3-Image）与机器人（Runway Praxis-1）两条线上同时把成本打穿。

## 编码与代理

- **Cursor Projects 多人版**（11-10 官方博客）— 九月上线的 Projects 重做成多人工作区：共享任务看板、团队级上下文层（需求文档／图表／技术规格／设计稿），以及跨人的 Agent 间通信。每个成员仍保留自己的协调者与私有会话，只有看板与 Context 是共享的。Beta 已开放，但 Projects 本身只在含 Cloud Agents 的套餐（Premium 及以上、Teams、Enterprise）可用，共享项目还需要团队账号 + Cursor 3.26.13 以上。官方没有公布冲突检测的命中率或误报率，别把「两个协调者会自己商量好」当生产保证。
  https://cursor.com/blog/projects-multiplayer
- **AWS Kiro Bots**（11-12 上线，Crew 0.12.0 于 11-11）— Bot 是可配置的数字岗位（问题分诊、构建监控、发版准备），每个 Bot 可并行拉多个 Worker Agent、维护跨会话持久记忆（Notes）、支持定时任务；Crew 0.12.0 给每个 Bot 配独立 Git worktree，浏览器任务运行时用户可随时接管，并新增 Google Workspace 与 Amazon Bedrock 知识库连接。0.12.0 还支持配置导出。
  https://kiro.dev/docs/crew/features
- **Google Antigravity /swarm**（11-11）— 一条指令拉起一组命名 Agent（协调者／执行者／审查者），并行跑后在同一块共享留言板上汇总。适合能按文件、包、问题切开的工作，或者需要第二个 Agent 先审先测再给人看。每个 worker 单独吃配额，并行会更快耗尽额度。仅 Google AI Pro / Ultra 可用。
- **Claude MCP Apps 公测扩展**（11-11）— MCP Apps 公开预览扩到 app tools 与 embedded sites：完整应用可以嵌进对话直接跑，随 MCP server 一起分发，也能在支持该扩展的其他 AI 应用里运行。官方注明细节仍会调整。
- **AWS Emulator**（11-11）— 本地离线模拟 200+ AWS 服务的开源工具，400 多个 API 模型，不需要 AWS 账号。更值得注意的是交付方式：代码全部由 Agent 编写并测试，团队没有写也没有逐行审；首个 SQS 原型只给 Kiro 一句提示，15 分钟出可用版本，每次变更要过含多个安全 Agent 对抗审查的 merge gate。适合做 IaC 试验场与 Agent 沙箱，但保真度有天然上限。
  https://github.com/aws/aws-emulator
- **AWS UAEF**（11-11，Apache 2.0）— 框架无关的 Agent 评测标准：AgentTrace / MultiAgentTrace 规范化多轮轨迹，36 个内置指标分七个维度（工具调用、回答质量、安全、性能、多轮记忆、多 Agent 协作、推理完整性），自带 LangChain / LangGraph / Strands / Bedrock AgentCore 适配器与 Langfuse 摄取。
  https://github.com/awslabs/uaef
- **Neo4j Relate**（11-11，Apache 2.0，Rust）— 进程内嵌入式图数据库，带内置 MCP server 与 CLI，暴露 Bolt 与 HTTP Query API v2。直接针对 Agent 循环设计了几个行为：自动识别 Agent harness、返回带 retryable 标记的结构化错误、按行数截断并留带内标记以免撑爆上下文。单条 Cypher 可同时做向量检索与图遍历，持久化可选（fsync WAL）。宣称 100% openCypher、97% 以上 GQL 合规。
- **Meta astryx**（11-11，beta 开源）— Meta 内部长了八年的设计系统，150+ 无障碍 React 组件、React 19 + StyleX、七套主题，附带文档／脚手架／codemod CLI。安装方式是纯 CSS 加类型化组件，不需要构建插件——形态是照着「让编码 Agent 和人一样使用」来设计的。
- **浏览器四家联合技能包 modern-web-guidance**（11-11）— Chrome、Edge、Firefox、MDN 团队共同维护的 skill pack，给编码 Agent 喂现代 Web 平台指南（view transitions、container queries、Popover API、内置 AI 等）。CLI 可搜索指南、按 ID 拉取、扫描代码库里的过时写法。
- **Talos 0.20.0**（11-11，MIT）— 首个稳定版，自托管 Agent，跑在终端／Telegram／树莓派上，可用本地 Ollama 或 Claude、Codex worker；每次工具调用都过确定性能力内核、任务级审批与审计链。「稳定」的资格说明写得很实：11 月 5—11 日七份每日部署记录、Python 3.12/3.13 与 ARM64 全量套件、277 个对抗用例、44 个隔离真模型端到端检查、签名过的安装／升级／回滚演练。

## 文档与办公

- **Claude Sheets / Whiteboards / Data / Meetings**（11-11）— Sheets 能建带公式的表格并导出 Excel；Whiteboards 做可共同编辑的视觉方案；原 Dashboards 更名 Data 并全面可用，能把公司指标变成可视化解释与旁白视频。交互式连接器让 Adobe、Atlassian 等应用直接嵌进 Claude，Salesforce / NetSuite / Workday 插件（beta）带销售、财务、HR 的内置技能。Claude Meetings 将进入 Google Meet 作为可见参与者，Team 与 Enterprise 客户先测；外部参会者需要管理员批准，未批准时它会主动退出。付费计划陆续开放。
  https://www.anthropic.com/news
- **Databricks Genie 新版**（11-11）— 从问答式助手改成后台常驻代理：持续梳理企业内部零散数据、主动检索最新信息并给优化建议；自带本体扫描，能探查企业内部数据网络、打通部门间信息壁垒。
- **OpenAI ChatGPT Businesses / Business Agents**（11-11，beta）— 企业可认领主页、上产品 feed（价格与库存）、看聚合的提及与点击数据（不暴露私聊）；已验证商家可挂带标注的 Business Agent，用自家资料回答，会话与 ChatGPT 自身回答分开。首批只覆盖美国线上零售与数字服务商。
- **Adobe Creative Agent beta + Firefly Graph**（11-11）— 用自然语言跨 Illustrator、Premiere、InDesign、After Effects 做多步修改；基于 MCP 的连接器预览让用户自己的 Agent 改 Photoshop / Illustrator / Premiere 文件（预计 2027 年初可用）；Firefly Graph 提供一个可复用、可分享的 AI 工作流搭建器。

## 图像与视频

- **MiniMax H3-Image**（11-10 晚，开源权重）— 由 H3 衍生的图像模型，支持文生图、参考生成与编辑，最多 16 张参考图，10 秒内出 4096×4096（约 16MP）图，官方称速度是主流 5 倍。架构是 331 亿参数稠密 DiT、50 层，沿用 H3 的 Qwen3-VL 文本编码器，去掉了 H3 的音频分支。API 定价约为主流同档 50%–70%，首周 4K 及以上五折。开源首日昇腾、寒武纪、昆仑芯、摩尔线程、沐曦等一批国产芯片同步接入。
  https://www.minimax.io/blog/minimax-h3-image
- **火山引擎 Seedance 2.5 flash**（11-12）— 号称最接近旗舰 2.5 的效果，速度翻倍，720P 文生／图生视频约 0.99 元/秒，比旗舰低 34%；单段最长 30 秒，一次最多 10 图 + 5 视频 + 5 音频输入，480P/720P 两档。即日起登陆即梦、LibTV、Updream、Creao AI、TapNow，API 11-15 上方舟。Seedance 2.5 家族由此形成旗舰 + flash 双梯度。
- **百度一镜自研视频模型**（11-12，百度世界 2026）— 成本压到 0.2 元/秒，Fast 版 1:1 出片（10 秒视频 10 秒产出）；微表情模型做到 AU 级控制、每秒 8—9 种微表情；实时交互改为全画幅流式生成，响应低于 2 秒。同场开出「短漫剧 Studio」，剧本 Agent + 成片 Agent 协同，支持一键转绘做本土化。
- **Runway Praxis-1**（11-11/12，Apache 2.0）— 27B 世界动作模型，「先预测未来画面、再生成动作」。视频主干是 26.9B 的 MoE 扩散 Transformer（Wan2.2 VAE + 冻结 Qwen3.5-2B 文本编码器，20 个 FFN 层里 17 层 MoE），加一个 314M 的 Action Expert。NVIDIA RoboLab-120 上 46.2%（1200 次）居世界动作模型与开源机器人基础模型第一；未见过本体的 RT-1 微调后在 SimplerEnv 拿到 80.0%（原策略 52.4%）。开放权重 + 推理与微调代码 + LoRA，单张 H100 / RTX 5090 / Jetson Thor 都能跑。
  https://runway.com/research/praxis-1-video-pretraining-to-robot-control

## 音频与语音

- **ElevenLabs Scribe v3 / v3 Live / v3 Medical**（11-10 发布，11-11 峰会主推）— Scribe v3 在 102 种语言上比 v2 少 27% 词错；v3 Live 比 v2 Realtime 错误率低 43%，首次把说话人分离带到实时转录（比次优实时模型少 39% 错误），并按对话上下文判断轮次而非只靠静音。支持 1000 条关键术语提示、术语库、纯英文写的格式规则。v3 Medical 专门处理 cycloserine / cyclosporine 这类近音药名。
  https://elevenlabs.io/blog/scribe-v3
- **ElevenLabs ElevenAI + Memory / Routines / Interaction Engine**（11-11 纽约峰会）— ElevenAI 是面向企业团队的「AI 同事」应用，旁听线下会议并产出纪要与待办，带告知与同意机制，免费早期访问已开；ElevenAgents 将获得 Memory（记住回头客细节）与 Routines（会前会后多步自动作业）；Interaction Engine 预览，负责轮次、打断，并按环节选模型（分诊用便宜模型、难点上前沿模型）。定制微调仍是「未来数月」，别当现成能力。NVIDIA Nemotron 3.5 Super VL 已进 ElevenAgents。
- **微软 MAI-Transcribe-2**（11-11）— 批处理版语音识别，每小时音频 0.10 美元，带说话人分离、可配置转录风格与词级时间戳。厂商自报「最快最准最便宜」，属自评口径。

## 模型侧

- **Gemini 4 Carbon**（11-11）— Google 最强模型对全部付费开发者与企业开放 API（AI Studio、Gemini for business），并向 AI Ultra 订阅者铺到 Antigravity、Gemini 应用与搜索 AI Mode。官方称在 CursorBench 4.0、Perplexity WANDR、Zapier AutomationBench 三项登顶，单任务成本比次优外部模型低一半以上；价格与 Argon 同为 $2/$10，优惠到 11-30 后翻倍。附带 Fairwind 计划的网络安全能力。
- **Gemini for Healthcare**（11-11，预览）— 医疗版 Gemini：Agent + 行业技能 + 对接电子病历与理赔系统的连接器，含支撑 HIPAA 的治理设计。Northwell、HCA、Optum 等七家机构首批接入，定位是「只读病历」。
- **Gemini Decisions API**（11-11）— 背后是新模型 Gemini Decision 1：不生成自由文本，一次请求判定最多 1000 个是非题或选择题，直接返回预设答案 + 置信度，输入 $0.1/百万 token。适合请求路由、内容审核、打标、Agent 的工具选择与分支判断。这是继 Jev、OpenAI 之后第三家把「决策」单独做成模型品类。
  https://simonwillison.net/2026/Nov/11/gemini-decisions-api
- **Gemini Robotics 2.5**（11-10）— VLA 模型换代，200 多项真实任务上成功率提升 30%—100%、速度提升 20%—30%，部分任务翻倍；推理阶段实时规避物理危险（有障碍时安全完成率 +33%，有人在场 +43%）。同步开源 ASIMOV-Jailbreak 安全基准（1500 条对抗提示词）。奔驰工厂 Apollo 2 分拣试点成功率 96%，但目前只对 Agile Robots、Apptronik、波士顿动力等伙伴开放。
- **百度 ERNIE 5.5 Flash Preview**（11-11）— 280B 总参、14B 激活的稀疏架构，1M 上下文，能在千帆与 OpenRouter 调用，官方称权重 11-25 前开源。属于后训练中间版，官方演示偏游戏开发、3D 建模等创作场景。
- **阿里 Qwen4**（11-12 官宣）— 知识理解、多模态感知、编码与智能体四条线做架构级升级，千问 App 已接预览版。
- **DeepMind AlphaGenome 2**（11-12）— 细胞级 DNA 分析，训练用了 68 种组织的 1 亿+ 单细胞图谱；TenK10K 基准上找到因果变异 30%（上一代单细胞方法 16%）。API 面向非商业科研与私有商业预览，明确不是临床诊断系统——普通用户不必追。

## 国内

- **百度「词元所」**（11-12，百度世界 2026）— 定位大模型交易所：汇聚多模型多供应商，做选型、调用、交易与管理，靠资源与供应商信用评价 + 区块链存证提升可信度。上线一个月入驻供应资源超 100 个、日均调用 Token 超 7000 亿、日均调用超 5000 万次。解决的是「词元中转站不对效果与稳定性负责、甚至以低配冒充 Pro」的信任成本。
- **千问办公 2.0**（11-09）— 从个人助手升级为 Team Agent：在 Agent 里建协作空间，把多个钉钉群、会议纪要、文档关联成共同上下文，同事与数字员工「小Q」同群作业；自动任务支持订阅事件规则触发，人机共创、资料空间、三端互联同批上线。银泰用 5 人管 60 多家门店卡券的案例是最实在的演示。
- **蚂蚁灵光连接器扩容**（11-12）— 新增微信 ClawBot、QQ 机器人、瑞幸咖啡等六个连接器。
- **清华 + 伯克利 uni-robot-agent**（11-11 开源）— Robot-Use Agent 的统一 Harness，用标准化工具接口让语言模型操控不同机器人与仿真环境。RoboDojo 上 Qwen3.8-Flash-Next 搭配该框架 31.39 分，超过官方此前 GPT-6 Astra + RoboProbe 的 28.97；GPT-6 Astra 配该框架 51.90。真机 19 项任务中未做任务微调的 Qwen 拿 53.50，领先微调后的 π₀.₅ 5.75 分。
  https://github.com/Open-RUA/uni-robot-agent
