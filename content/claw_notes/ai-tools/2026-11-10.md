## 编码与代理

### Cursor Build Live Apps —— 云端 Agent 直接把应用建起来、部署上线
- 发布：2026-11-05，Cursor Changelog。
- 做什么：开一个**云端 Agent**（本地不支持），说清要建什么应用，Cursor 自己搭 Web 应用骨架、按需起 Postgres、配 **Cursor SSO** 登录、准备托管环境；要连你自有系统时会向你索要密钥，官方写明 Agent 看不到密钥值。
- 发布：选一个唯一域名 → 过安全体检 → 出线上链接。体检分两层：确定性检查（拦写进代码的密钥、私钥/服务账号文件、`.env`、source map）＋ AI 安全评审（团队管理员可加自己的规则，但不能删内置检查）。检查不过就不上线，除非管理员显式放行（恶意代码、硬编码密钥不在放行范围）。
- 共享：团队内应用走 Cursor 登录，可分给人／组／全团队；个人套餐可公开分享。脚本或 Bot 可用 Cursor API Key（`x-cursor-app-token`）访问。
- 可用范围：所有开启云端 Agent 的付费套餐（Premium $30、Super $100、Ultra $200、Teams 每人 $30 起）；定价页未见单独的托管或数据库收费。当前支持 Cursor Origin 与 GitHub 仓库，GitLab 在路上。
- 怎么读：这是把「vibe coding 出的东西烂在 localhost」这个真问题正面解决——它卖的不是生成，是**上线这条路**。
- 链接：https://cursor.com/changelog/build-live-apps

### Cursor Voice Chat —— 和编码 Agent 打实时语音电话
- 发布：2026-11-06，Cursor Changelog。
- 形态：Agent 空闲且输入框为空时，点发送键位置的波形按钮开聊；覆盖 Agents Window、IDE、网页与 iOS（iOS 可说「Hey Siri, call Cursor」，锁屏用 Live Activity 静音／挂断）。
- 分工：语音层走 **Grok Voice**（可选 Ara／Eve／Leo／Rex／Sal 等音色），编码仍用你为该 Agent 选的模型；Agent 边干边用短句播报进度，完成后口头给一句结论。
- 边界：需要账号登录，**只用 API Key 的会话开不了通话**；Privacy Mode 开启时语音零留存；约 10 分钟无操作自动挂断，另有每日通话上限。与听写（Cmd+Shift+Space）是两件事。
- 链接：https://cursor.com/changelog/voice-chat

### Devin SWE-2 Flash —— 五分之一价格、约三倍速度的日常编码模型
- 发布：2026-11-04，Cognition。**11-30 前在 Devin 里免费**。
- 底座：从 Thinking Machines 的 Inkling-Small（276B 总参 / 12B 激活，Apache 2.0）出发，第一次在 RL 之前加了一大段中训练（数万亿 token，三段式，最稀缺数据放最后）。官方称中训练把 Terminal-Bench 4.0 从 0.9% 拉到 20.0%。
- 成绩（厂商自报）：Terminal-Bench 2.1 89.2（SWE-2 92.8）、SWE-Bench Pro v2 Hard 89.9（90.6）、FrontierCode 2.0 24.0（23.8）；长程任务差距大：DeepSWE 1.1 60.1 对 73.0、TB 4.0 20.0 对 27.3。速度「200 对 60 token/s」是**模拟回放**，不是同场实测。
- 边界：只在 Devin Desktop 与 Devin CLI 里可用，**没有独立 API，权重不公开**——官方理由是它做了网安专项训练（ExploitBench 11.3%→34.8%），怕被滥用，改为向可信伙伴定向开放。
- 怎么读：这条的价值是「日常活不必用旗舰模型」的经济学，不是新 SOTA。
- 链接：https://cognition.ai/blog/swe-2-flash

### Agent Autoloop v1.0 —— 关掉终端，命令行 Agent 还在自己接活
- 发布：2026-11-03 开源（MIT），三天涨到 3,300+ 星，作者卡兹克。
- 是什么：约 1,650 行、运行时零依赖的中台。定时任务、GitHub issue、HTTP 请求、线上报错都变成事件，按 `rules.json` 决定派给哪个 Agent、在哪个目录干（内置 Claude Code、Codex、ACP、DeepSeek Harness 接法，任何能接提示词并打印最后一条回复的 CLI 都能接）。
- 关键设计：碰到删数据、重启、花钱、对外发消息这类事才推卡片到飞书／钉钉／企微／Slack／Discord／桌面通知；**等你拍板期间进程退出、不耗 token**，回答后接回原会话接着干。另有只追加事件日志、外部文字当资料不入提示词、8 层派工熔断。
- 门槛：Node 24+、Git、本机已登录的 CLI Agent；macOS／Linux 可用，Windows 版当时还在补；CLI 输出与默认通知是中文。
- 链接：https://github.com/KKKKhazix/agent-autoloop

### XYEval —— 专测 Agent 会不会盲从用户的错误建议
- 发布：2026-11-09（仓库创建），Google DeepMind 开源，Apache 2.0，论文 arXiv 2609.23939。
- 是什么：把经典「XY 问题」做成动态基准——用户认错了病根（Y）却让助手去干错的方案（X），看 Agent 会不会识别错误前提、用工具验证、把真问题反馈回来。
- 规模：8,222 个任务，覆盖 SWE-bench Verified（500）、SWE-bench Pro（731）、Terminal-Bench（158）、MCP-Atlas（997）、Humanity's Last Exam（5,836）；误导性建议由 Gemini 3.5 Flash／Gemini 3.1 Pro／Opus 4.8／GPT-5.5 生成。
- 用法：取原基准题面，把 `misleading_prompt` 注入首轮用户输入即可。
- 链接：https://github.com/google-deepmind/xyeval

### CWE-bench v2 —— 100 条真实漏洞修复任务，考的是「不破坏功能的加固」
- 发布：2026-11-03，Hugging Face 博客（与 Collinear AI）。
- 设计：100 条任务、覆盖 91 个 CWE；Agent 拿到真实开源仓库 checkout 与一句短指令，在不破坏既有功能的前提下把漏洞堵上；全程序化打分、可复现，另留 held-out 集。
- 首版结果（11 个模型）：Gemini 4 Argon 67.8% pass@1／81.0% pass@4，Claude Opus 5.5 67.3%／78.0%；95 题至少被一个模型解出，但榜首仍有 19% 的题每次都失败。
- 成本：DeepSeek V4.1 Flash 57.0%、每次 rollout **$0.04**；Opus 5.5 高 10 分但 $1.83；Gemini 4 Argon $3.92——三者构成成本-效果前沿。选型意义大于排名意义。
- 链接：https://huggingface.co/blog/cwe-bench

## 音频与音乐

### Suno —— 可以拿 MIDI 文件起歌
- 发布：2026-11-04，Suno 官方博客与帮助中心。
- 用法：Pro／Premier 订阅者在桌面网页的 Create 页把 `.mid`／`.midi` 拖进去（或从「+」菜单选 MIDI），再决定是「照我写的音符弹」还是「取一个动机发展成新东西」；首发用 v6-wild。
- 为什么值得看：MIDI 只有音符与时值、没有音色，等于把「我在 DAW 里写的旋律」直接变成起点，比文字提示精确得多。
- 注意：商用仍受 9-03 起的下载额度条款约束（必须在 Pro/Premier 期间、且通过 Suno 下载的那份才算）。
- 链接：https://suno.com/blog/MIDI-in-create

### Zyphra ZONOS3-Mini —— Apache 2.0 的 8 亿参数语音克隆，浏览器里实时跑
- 发布：2026-11-09，权重在 Hugging Face，Apache 2.0，运行时代码在 GitHub。
- 规格：稀疏 MoE，总参 800M／激活约 100M；自研 **ZAC-1** 编解码器替换 DAC（86Hz 帧率是上一代的瓶颈），官方称同等数据下词错率降一个数量级；112 张 H100 训两天半。
- 延迟：M3 MacBook Air 上首音 **<150ms**，Pixel 9 浏览器（WebGPU）**<570ms**；运行时覆盖 WebGPU、GGML C++、SGLang／vLLM。
- 控制：说话人向量可调年龄／性别呈现／口音／音质，激活层控制语速、情绪、音量投射，甚至能只让句中某几个词换语气；另有基于 VoiceCraft 的编辑模型改词。
- 边界：官方写明这些是「生成目标」，不保证一定出现某种情绪；自带 ZTTS2-Eval（35 语种干净集／20 语种 in-the-wild）由自家发布，需第三方复现。
- 链接：https://huggingface.co/Zyphra

### Gradium Phonon —— 65MB 的端侧 TTS，五种语言
- 发布：2026-11-05（首发后两周窗口内正式发布）。
- 规格：两个尺寸约 **65MB** 与 **75MB**，合起来覆盖英／法／德／西／葡，内置 100+ 音色；流匹配生成，跑在手机、笔记本、单板机与浏览器标签页里，文本不出设备。
- 许可要看清：英文单语 **Phonon 31m 是 Apache 2.0**（可商用），五语 **Phonon 40m 是 CC BY-NC**（非商用）。
- 配套：`ptts` 推理框架支持 10+ 后端；PyTorch 实现从 Transformers 5.21 起进入 Hugging Face；作者称两周下载 20 万+，Open TTS Leaderboard 上德语／西语可懂度第一、CPU 流式首音第一。
- 链接：https://huggingface.co/Gradium
