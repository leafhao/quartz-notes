### 2. GitHub Copilot HydraFusion：一次请求里调度多个模型

**发布日期：2026-09-30（研究预览）｜类型：代码生成 / 多模型编排**

Copilot 在 VS Code 与 Copilot 桌面端上线 HydraFusion 预览，把「选哪个模型」当成一个优化问题，对每个请求在三种策略里挑一种：

- **Single**：单个模型直接解题；
- **Cascade**：便宜模型先起草，只有草稿不达标才升级到强模型；
- **Critique**：一个模型起草，另一个独立模型评审，原模型按反馈修订。

这和既有的 Auto 模式的区别在于：Auto 是「每次请求挑一个模型」，HydraFusion 是「在一个对话轮次内协调多个模型与工作流」。本次更新补上了每一步的可观测性、实时进度与长任务状态指示。

官网：https://github.com/features/copilot

**注意**：研究预览，Business 与 Enterprise 需要管理员先批准预览功能才能开。Critique 模式会明显增加 token 消耗，不是所有任务都值得。

**建议用法**：只在「第二双眼睛能省下返工」的任务上开 Critique（重构、迁移、边界条件密集的逻辑），其余场景 Single 更划算。

### 8. Ideogram 4.5：多轮编辑不再漂移

**发布日期：2026-09-30｜类型：图像编辑 / 精准局部修改**

两个核心主张。第一，**降低多轮编辑的漂移**：主流模型连续修改几轮后画面就会累积伪影、色偏与位移，4.5 声称能保持细节。第二，**高分辨率局部编辑**：可以在 4,016 × 6,016（约 2,420 万像素）的原图上只改一个裁切区域，改完保持边缘一致贴回原图，全程不降采样。

定价按渲染速度与输出尺寸计（每张）：Very Low $0.008、Low $0.03、Medium $0.06、High $0.10；带源图的图生图路径 High 档 $0.22。1K 到 2K 的输出尺寸不影响价格——按算力收费而不是按像素收费。官方表示**计划在近期开源该模型权重**。

官网：https://ideogram.ai/

**注意**：第三方评测口径给出的结论是「编辑能力可能略优但差距在噪声内，生图能力明显弱于 Qwen Image 3.0」——把它当编辑工具看，不要当文生图主力。另外「多轮不漂移」是厂商自测口径，你的素材类型未必一致。

**建议用法**：拿一张真实的高分辨率素材，连改三轮（换物体、改文字、调色调），看第四轮是否还能贴回原图。

### 9. HeyGen Video：$0.01/秒的通用视频模型

**发布日期：2026-09-30｜类型：视频生成 / API**

HeyGen 第一次做通用视频模型（此前只有数字人与语音）。它以 **MiniMax H3 为基座做后训练**，一个模型覆盖文生视频、图生视频、参考生视频三种模式，对话、环境音与音效在同一次调用里生成。

价格是整件事的重点：**10 月内促销价 $0.01/秒**（480p，标准价 $0.02），768p 为 $0.015/秒。HeyGen 自己的对照表里，其基座 MiniMax H3 在同档 768p 带音频的标价是 $0.08/秒，Kling 3.0 Pro $0.168/秒，Seedance 2.0 $0.303/秒，Veo 3.1 $0.40/秒。

输出规格：时长 5–15 秒整秒、480p 或 768p、24fps、MP4/H.264、AAC 32kHz 立体声，支持 21:9 到 9:16 多种比例。已上线 HeyGen API，并经 OpenRouter、Runware、ComfyUI 分发。

官网：https://help.heygen.com/en/articles/17272995-introducing-heygen-video-generate-cinematic-clips-from-a-prompt

**注意**：官方盲测（约 4,800 票）称其质量排第一，但同一份材料也承认它在**一致性**与**细节**两项偏弱——恰是长镜头与多镜头叙事最吃的两项。适合单镜头产品演示、培训、房产走查这类场景，不适合角色一致性要求高的叙事。

**建议用法**：按「一千秒」算账——一百条十秒素材的成本是十美元，先在这个量级上验证质量，再决定要不要进生产。

### 12. TurboT2VA：音视频联合生成提速 54 倍

**发布日期：2026-09-30｜类型：开源 / 训练与推理加速**

浙江大学、清华大学、新加坡国立大学等团队开源**音视频联合生成**的蒸馏方案 TurboT2VA。它在 LTX-2 上把 40 步教师蒸馏为 4 步学生，用离散一致性蒸馏做 warmup、再过渡到连续时间一致性模型（sCM）+ 分布匹配蒸馏（DMD）三阶段训练。在单张 NVIDIA H20、1024×1792、121 帧的设置下，生成器耗时从 318.74 秒降到 5.83 秒，**加速 54.67 倍**。

论文题目：TurboT2VA: Fast Large-Scale Text-to-Video-Audio Generation via Score-Regularized Consistency Distillation

**注意**：官方在论文里同时要处理「画面运动演变」「声音事件发展」「两者时间对应」三件事，蒸馏后这类对齐是否还能保持，需要按你的场景实测。公开仓库地址暂未确认。

### 13. SoL-Refiner：一步把视频提到 2K/4K

**发布日期：2026-09-30 前后｜类型：视频精修 / 开源**

出自 NVIDIA Sana 项目的研究者发布的一步式视频精修模型：把**任何生成器**的低分辨率输出提升为清晰的 2K/4K，端到端比原流程**快 8.91 倍**。它的价值不在「又一个超分」，而在于它是模型无关的——你不需要换掉正在用的生成器。

### 16. YuE2-GGUF + yue2.cpp：本地整曲生成，不再依赖 Python

**发布日期：本周｜类型：音乐生成 / 本地部署**

开源音乐模型 YuE2 现在能以**纯 C++17 / GGML** 的方式在本地跑完整首歌，不再需要 Python 与 PyTorch 环境。这解决的是部署侧最烦的一环：以前要在本地跑生成模型，先得把整个 Python 生态装对。

技术形态上，它先写出一份 **ABC 记谱**（纯文本乐谱，可编辑、可留存），再生成声学潜变量——这意味着 prompt 与成品之间多了一个**人能看懂、能改的中间产物**。权重提供 Q5_K_M 到 BF16 多档，默认下载 Q8_0；65 秒歌曲在 Q8_0 下峰值显存 5.8 GB，缩减上下文后 3.8 GB。运行时支持 CPU / CUDA / Vulkan。附带可选的 SheetSage2 转谱器，能把已有录音转成乐谱做翻唱。

**注意**：**权重许可是 CC BY-NC 4.0，商用需上游另行授权**——这是本项目最需要先看清的一行。官方称在 WildSongBench 上对标 Suno v5/v6 的成绩属模型团队自测口径。前三小时与真人乐手编曲的可控性差距仍然存在。

### 20. Perplexity pplx-embed-v2：检索「答案 + 证据」

**发布日期：2026-09-30｜类型：嵌入模型 / 开源（MIT）**

它改的是训练信号。常规 RAG 每条 query 只标一个「金标准段落」，其余全当负例——包括那些**用来核对答案的句子**。这个模型用一个 query-aware 的教师模型对全文档逐 token 打分，聚合成软标签，让学生同时学会「答案在哪」和「证据在哪」。两个工程细节值得注意：输出 2048 维（Matryoshka 也支持 1024），量化感知训练**原生支持 int8**——官方称 1 KB 的 int8 向量略微超过某对照模型 8 KB 的 float32 向量。教师只在训练时跑，推理不增加延迟。

### 26. PageIndex：把向量库从 RAG 里拿掉
