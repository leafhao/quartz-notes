# AI 工具推荐 2026-11-24

> 搜索窗口：2026-11-19 → 2026-11-24（5 天，承接上期）。主线是**交付环节成主战场**：Claude Ship 把审 PR、修失败、按策略审批打包；Docker 把 agent 关进 microVM；AWS 把 YOLO 模式关进沙箱；Strands Decider 把「判断该调哪个工具」拆成独立小模型；vLLM 把多轮会话的 KV 缓存搬到 NVMe。**写完代码之后那一段，这一周被各家产品化了。**

## 编码与代理

- **Claude Ship（beta）**（11-23，Team / Enterprise，仅 GitHub）— 三件东西：Code Review 转为 GA，从多个角度审 PR、收集问题后做对抗性验证再分类发回，每仓可选 Quick / Standard / Deep 三档强度；PR Steward（beta）专治 CI 失败与合并冲突，**设计上不允许它批准或合并**；Claude Approvals（beta）按仓库里的策略文件审批，相当于更聪明的 CODEOWNERS。用法是在 Claude Code 里跑 `/ship`。官方内部数字：Claude Code 团队 6–9 月合并 PR 数翻倍、回滚比例下降超 40%。不支持 ZDR、HIPAA 与客户自管密钥的组织。
  https://www.anthropic.com/news
- **Docker 重构（Sandboxes + AI Governance）**（11-19 宣布，11-20 PH 日榜第三）— 论点很直接：容器隔离的是工作负载，agent 是「有意图的执行者」。Docker Sandboxes 让每个 agent 跑在独立 microVM 里、自带内核与私有 Docker Engine，凭证不进 VM，出网默认拒绝；Cloud Sandboxes 同 CLI 跑到云上按秒计费。AI Governance 把沙箱、网络、MCP 策略下发到每台机器，决策事件可流到 SIEM。本机沙箱免费（不需 Docker Desktop）。
  https://www.docker.com/products
- **Google Antigravity v2.34.0**（11-20）— `/btw` 从「问一句」升级成「分叉再提为正式会话」：副本带完整上下文、只读、主 agent 继续跑；CLI 里每次 `/btw` 是独立分叉卡片，需审批的工具调用自动拒绝。同版本向付费消费者计划开放 Gemini 4 Neon 与 Orchestrator、支持 MCP Apps，并上线 MongoDB Atlas 官方插件（7 个技能，含自然语言查库、慢查询优化）。11-19 另有桌面端原生 SSH，可在远端服务器跑 agent。
  https://antigravity.google/docs/changelog
- **Codex 0.172.0**（11-23，稳定版）— 从搜索结果与 transcript 里点线程链接可直达会话与嵌套 agent；Tab 补全 slash 命令参数；`Shift+Up/Down` 在 agent command center 跳任务组；标准输入 MCP 且有工具缓存时默认首次调用才启动；可在 `config.toml` 给单个已连接应用的工具指定审批人；`codex exec resume` 恢复沙箱权限与工作目录。
  https://github.com/openai/codex/releases
- **Claude 电脑操作扩到团队版（beta）**（11-20）— 让 Claude 看屏幕、在用户允许的桌面应用里干活，从个人档扩到 Team 与 Enterprise，按组织逐步放量，不是全量开。仅在「新版 Claude 体验」的桌面端生效，网页与移动端要先打开 Computer access。
  https://www.anthropic.com/news
- **Replit Missions**（11-17 发布，11-23 上 Product Hunt，本期补录）— 给一整队 agent 设三件事：什么算成功、能花多少钱、哪些动作要人批。协议以外还有 AI 裁判按验收标准打分并退回返工；预算先烧完则任务标记未完成。自证案例是两天内用 3000 美元预算搭出监控平台 DataCat，并已开源可自托管版。**数字全为 Replit 自测、每档只跑一次**，还带一个与 Claude Code `/goal` 的对比，读的时候按厂商口径打折。
  https://replit.com
- **AWS Strands Box CLI**（11-23）— 冲着「YOLO 模式」来的：很多人把 agent 的权限提示全关掉换速度。`box run claude` 一条命令把 Claude Code、Codex、Kiro CLI 关进沙箱，按策略限制可读文件、可跑命令、可访问主机，凭证留在沙箱外、出站时注入；还能按任务切 profile（编码 agent 给仓库读写，排障 agent 只给只读）。
  https://strandsagents.com/blog

## 框架与基建

- **Gemini API 工具检索（Preview）**（11-20）— 解决 agent 接几十上百个工具时「schema 全塞进上下文」的问题：请求里加 `{"type": "tool_search"}`，想延后的工具设 `defer_loading: true`，模型仍看得到工具名与描述，参数 schema 不进上下文，服务端按名检索后一次性载入。与前缀缓存兼容，远程 MCP server 上也能整包延后。适用 Gemini 3.6 之后、仅 Interactions API。
  https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/
- **Gemini 文件切片控制**（11-23）— 服务端指定只加载文件的一部分：文档用 `start_page`/`end_page`、表格用 `sheet_index` 与 `visible_cells`、音视频用时间区间与帧率，还能选内容层（文字 / 页面图像 / 公式 / 转录）。按实际查看的部分计费。官方给的早期采用者数据：Vercel 用文本略读比整份 PDF 渲染省 14 倍 token，LiteLLM 的 PDF 提示 token 减 67%。
  https://ai.google.dev/gemini-api/docs
- **transformers v5.24.0**（11-21）— 一次接入 10 个新架构：Thinking Machines 的 Inkling 2 Mini、腾讯 HY4-VL（架构先行，HF 未见权重）、瑞士 Apertus 1.5、Meta Omnilingual ASR（1600+ 语言）、NVIDIA Dory 等。**对本地跑模型的人最要紧的是破坏性改名**：`past_key_values`/`cache_params` 统一为 `cache`，旧名自动转换到 v5.40（`generate` 到 v6.0），自定义代码要显式改，且要求 `peft>=0.22.0`。
  https://github.com/huggingface/transformers/releases/tag/v5.24.0
- **Strands Decider v2**（11-23，Apache 2.0，权重在 HF）— 五个「决策模型」，基于 Gemma 4，从 E2B 到 31B。不写正文，只在你给的一组选项里返回每个选项的概率，一次前向完成；v2 换成双向注意力，一次读完可以问多个问题。31B 在六个文本基准均值 82.1（v1 的 26B 是 70.0），校准误差从 0.062 降到 0.027。官方内部案例是拿它替代 Sonnet 4.6 做工单打标，成本降 98%、单次调用快 78%——但那是 v1 的 E4B，不是 v2。
  https://strandsagents.com/blog
- **vLLM：KV 缓存搬到 NVMe**（11-23，与 AMD、Embedded LLM 合作）— 长会话 agent 的账算得很清楚：AgentX 基准里单轮输入中位数 142K token、96% 是已处理过的前缀，缓存命中率每高 1 个百分点约等于吞吐涨 10%。用 AMD MoRI 的 UMBP 把 1.8TB 缓存池直接放 NVMe，同容量对比 DRAM 吞吐差在 1% 以内，DRAM 只留 80GB 做缓冲。按官方估算，DRAM 约 4.2 万美元/TB 容量，NVMe 约 0.36 美元/TB 写入。
  https://blog.vllm.ai
- **Exa Websets V2**（11-17 发布，11-21 上 PH，本期补录）— 从网页里建结构化清单：快 4 倍、准确率与召回各涨 20%，取消月费改为按量（每次搜索 5 美元/千次 + 算力单元 0.1 美元）。榜单对比里它每家公司 0.024 美元、每个人 0.0169 美元，对照 Claude Code 与 Parallel 是 0.16–0.28 美元。**注意**：老用户要主动在账单页切到新计价，切了不能退回。
  https://exa.ai/websets
- **Shirudo**（11-23，OpenAI × Cisco，BSD 2-Clause）— 给运行中的 Linux 打「临时盾」：补丁要几天到几周才铺得完，先用签名过的 eBPF 程序挡住有漏洞的代码路径，不必重启、不必中断服务。演示是用 Codex 生成盾，在运行中的 Elasticsearch 上拦下 Java4Shell。给 agent 留的口子是「可调查、可写盾」，部署权仍在安全团队。
  https://openai.com/index/introducing-shirudo
- **DeepMind 开源 Lean 量子算法库**（11-23）— 做法值得记：每个问题交给相互独立的 Gemini 4 agent 团队，想法必须用 Lean 证明通过才能进共享笔记本，每四小时开一次「虚拟会议」交换思路。成果：聚变某关键量电路成本降 11.8 倍、常见光敏分子量子模拟便宜 8 倍、CYP450 量子比特 481→333。库、题目规格与已验证解一起开源。
  https://deepmind.google/discover/blog
- **CLI-Anything**（11-20，HKUDS，Apache 2.0，单日 +899 星）— 把任何有源码的软件自动包成 agent 能调的 CLI，专门对付 ArcGIS Pro 这类「没 API、没 MCP server」的桌面软件。配套有 CLI-Hub 索引站。给 agent 补的是「够不着的长尾软件」这一块。
  https://github.com/HKUDS/CLI-Anything

- **Thinking Machines Inkling 2 Mini**（11-20）— 循环 transformer 多模态 MoE：物理 24 层，中间 12 层跑三遍，等效 48 层；总参约 26B、每 token 激活 3B，1M 上下文，以 NVFP4/MXFP8 混合精度发布。transformers、llama.cpp、MLX 当日支持。官方定位「本地小机器上的新选择」，自评与 Qwen 3.8 27B 相当。
  https://huggingface.co/thinkingmachines
