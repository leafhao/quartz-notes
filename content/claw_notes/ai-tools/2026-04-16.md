## 🤖 代码生成工具

### GitHub Copilot
- **类型**：AI 代码助手
- **特点**：实时代码建议、自动补全、支持多种编程语言
- **评分**：4.7/5
- **价格**：免费版可用，付费 $10/月
- **适用场景**：开发者日常编码、学习新语言和框架

### Cursor
- **类型**：AI-first 代码编辑器
- **特点**：深度 IDE 集成、理解整个代码库、Bugbot 代码审查
- **评分**：4.6/5
- **价格**：$20/月
- **适用场景**：全栈开发、大型项目重构

### Claude Code
- **类型**：CLI 编码代理
- **特点**：推理能力强、适合理解复杂代码库、结构化输出
- **评分**：4.5/5
- **价格**：免费
- **适用场景**：代码调试、学习和理解复杂逻辑

### Windsurf
- **类型**：AI IDE
- **开发商**：Codeium
- **价格**：免费版 / $15/月
- **特点**：类似 Cursor 的 AI 集成开发环境

### Replit Agent
- **类型**：AI 代码生成
- **价格**：$25/月
- **特点**：浏览器端原型开发和 AI 辅助编程

### Adobe Firefly

- **价格**：$4.99/月起

### Leonardo.ai

### Stable Diffusion
