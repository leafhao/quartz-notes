## 1. 💻 代码生成工具（Coding Agents）

2026 的 AI 编程已从「代码补全」彻底转向「Agent 模式」——能规划、执行、跑测试、读报错并自动修复。

### 🏆 Claude Code（Anthropic）— 复杂工程首选
- **核心优势**：基于 Opus 4.6，**SWE-bench Verified 得分 80.8%**（业界第一）
- **适合场景**：重构遗留代码、调试生产 regression、从零搭建复杂功能
- **特色**：原生终端代理 + 大型代码库理解能力突出
- 来源：nxcode.io 2026 排行 / Blink 实测榜首

### ⭐ Cursor — 最佳 IDE 体验
- **核心优势**：AI-native IDE，inline 补全 + Agent 模式无缝切换
- **适合场景**：日常编辑、多文件项目、agentic workflow
- **更新**：持续每月迭代，模型可在 Claude/GPT/Gemini 间切换
- 来源：SitePoint / Aubergine 横向对比

### 🛠 GitHub Copilot（Next Gen）— 团队默认安全选项
- **核心优势**：可在 Claude 3.7 / GPT-o1 / Gemini 2.0 之间切换 + Copilot Workspace
- **适合场景**：既有 GitHub 生态、企业团队、安全合规要求高
- 来源：LinkedIn 2026 编辑器对比

### 💡 新兴选手值得关注
- **Codex**（OpenAI）：5/14 changelog 更新，OpenAI-first 团队最佳
- **Cline / Aider / Gemini CLI / OpenCode**：开源终端代理，自带 API key，月成本 $2-5
- **v0 by Vercel**：UI 快速生成神器
- **Replit**：初学者首选
- **Windsurf**：高级研究类项目
- **Amazon Q Developer**：AWS 生态最佳搭档

> 💡 经验：2026 年没有「唯一最佳」，主流团队同时使用 2-3 个工具——Claude Code 跑复杂重构，Cursor/Copilot 处理日常编辑。

## 2. 🎨 图像生成工具

模型百花齐放，胜负关键已从「画质」转向「特定场景的最优解」。

### 🏆 Midjourney v8.1 — 艺术氛围/影院风顶流
- **核心优势**：氛围、艺术质感、cinematic 风格无可替代
- **适合**：插画、概念设计、品牌视觉

### 🆕 Flux 2 / Flux 1.1 Pro（Black Forest Labs）
- **核心优势**：写实+光影顶级，开发者首选
- **价格**：Flux 2 Pro 约 $0.04/张，性价比突出
- **变体**：Flux 1 Schnell（极速版）

### 🆕 GPT Image 2（OpenAI）
- **核心优势**：**图内文字渲染最强**，相比 DALL-E 3 巨大飞跃
- **适合**：营销图、海报、信息图

### 🆕 Nano Banana 2（Google）
- **核心优势**：细节最锐利，Google 当前最强
- **适合**：电影/影视级精度需求

### 🎯 细分场景推荐
- **写实摄影**：Flux 2 Pro / Imagen 4
- **图内文字**：Ideogram 3 / Imagen 4 / GPT Image 2
- **商用安全**：Adobe Firefly（版权清晰）
- **免费体验**：Microsoft Designer（DALL-E 3 内核，每天 15 张）
- **影视级**：Grok Imagine（独家视频延展）

> 💡 经验：DALL·E 综合分 9.3/10 仍是「全能型」第一；但专业用户 70% 已迁移至 Flux/Imagen/MJ 多模型混合工作流。

## 3. 📝 写作与研究工具

### 🏆 Perplexity — 实时检索 + 引用溯源
- **核心优势**：实时联网、AI 总结附带原文 link
- **适合**：事实核查、研究、新闻摘要
- **价格**：$20/月

### 🆕 NotebookLM（Google）— 文档合成革命
- **核心优势**：**只用你上传的文档**，杜绝幻觉
- **2026 杀手级功能**：**Audio Overview**——上传 50 页 PDF 直接生成 podcast 风格音频解说
- **适合**：论文研究、知识库整理、学习笔记

### ⭐ Notion AI — 工作空间一体化
- **核心优势**：与 Notion 文档/数据库深度集成
- **适合**：团队知识管理、PRD 撰写、会议纪要

### 🆕 Claude（Anthropic）— 长文/思辨写作
- **核心优势**：长上下文、权衡式分析、引用准确
- **适合**：技术文档、论文初稿、复杂决策分析

### 💡 推荐组合栈
1. **检索**：Perplexity 或 Elicit（学术）
2. **合成**：NotebookLM（文档专属）
3. **润色**：Grammarly / Notion AI

> 💡 经验：同一问题分别问 5 大模型可获得 5 种视角——ChatGPT 自信生成，Claude 谨慎权衡，Gemini 接 Drive，Perplexity 实时引用，NotebookLM 仅基于上传文档。

## 4. 🎬 音视频生成工具

### 🏆 Sora 2（OpenAI）— 叙事/物理真实度顶流
- **能力**：4K (3840x2160)、Pro 计划 60 秒、文本/图像/视频参考输入
- **优势**：场景连贯性、物理真实、影院级画质
- **价格**：随 ChatGPT Plus $20/月（Pro 更高）

### ⭐ Runway Gen-4 — 创意控制
- **能力**：4K 短片，最强逐帧控制
- **适合**：广告片、艺术短片、需要精细调教的场景

### 🆕 Veo 3.1（Google DeepMind）— 综合可靠
- **优势**：1080p、15-60 秒、原生音频（对话+环境声+BGM 一体生成）
- **适合**：概念演示、社交媒体短视频

### 🆕 Kling 3.0 Omni — 多镜头+多语言原生音频
- **杀手级**：多镜头序列共享音频时间轴 + **5 种语言原生对话**
- **适合**：跨语言营销视频、多语种短剧

### 🆕 Seedance 2.0 — 原生音频新秀
- 与 Kling、Veo 并列 2026 三大「原生音频」标杆

### 🎵 AI 音乐生成
- **Suno V5**：歌曲生成最强（详见 heartmula skill）
- **ElevenLabs**：语音克隆/TTS 工业级标准

### 🎵 AI 音乐视频专项
- **Freebeat**：综合分 9.4/10（音频反应+口型同步+长视频）
- **Neural Frames**：音频反应可视化最强
- **Kaiber / Pika**：创意短片

> 💡 经验：2026 年「原生音频」是分水岭——传统 v2v 时代结束，Sora 2 / Veo 3.1 / Kling 3.0 已能在单次生成中产出**同步对话+环境声+BGM**。

## 5. 🤖 AI Agent 开发框架

### 🏆 LangGraph v0.4（LangChain Inc）— 复杂状态机首选
- **2026/04 更新**：状态持久化改进 + HITL（Human-in-the-Loop）检查点
- **适合**：复杂、有状态、可循环执行的自主 Agent
- **GitHub 星数**：~19.9k
- **特色**：低层级 graph 编排，控制力极强

### 🆕 Claude Agent SDK（Anthropic）— 企业部署量第一
- **关键里程碑**：2026 年企业生产部署量**已超过 AutoGen**
- **适合**：Anthropic 生态、长上下文 Agent、规则严谨的企业场景

### ⭐ CrewAI — 多角色协作场景王者
- **2026/03 更新**：Enterprise Tier 上线（observability + scheduling）
- **适合**：角色明确、流程线性的多 Agent 团队（角色即"职位"）
- **建议**：业务上线前提前规划迁移到 LangGraph 的路径

### 🆕 OpenAI Agents SDK
- **2026/03**：达到生产成熟度，OpenAI-native 部署官方推荐
- **适合**：纯 OpenAI 生态项目

### 🆕 Microsoft Agent Framework
- **定位**：Azure-native 企业默认（统一了 Semantic Kernel + AutoGen 路线）
- **适合**：微软云栈、企业合规要求

### 💡 其他值得关注
- **Mastra**：TypeScript-native 的 Agent 框架，前端开发者首选
- **AutoGen / AG2**：群聊式协作（2026/02 仍在迭代）
- **PydanticAI**：类型安全 + 简洁 API
- **DSPy**：声明式 LM 程序，自动优化 Prompt（详见 dspy skill）
- **DeerFlow / Google ADK**：层级式委托

> 💡 经验：MadAppGang 2026 评测 20+ 框架后结论——**没有任何一个框架同时满足「可视化编排+TS 原生+自托管+生产级记忆+可观测性」**。当前最佳实践是按场景混合，并提前规划框架升级路径。

## 🌟 核心趋势

1. **代码 Agent 全面取代代码补全**——SWE-bench 80% 已成新基线
2. **图像生成进入「场景专家」时代**——单一最强消失，多模型混合工作流成主流
3. **NotebookLM Audio Overview 重新定义文档工具**——文档→播客一键转换
4. **视频原生音频成为新分水岭**——Sora 2 / Veo 3.1 / Kling 3.0 三足鼎立
5. **Agent 框架百花齐放但无银弹**——LangGraph 在底层、CrewAI/Claude SDK 在应用层各占山头
