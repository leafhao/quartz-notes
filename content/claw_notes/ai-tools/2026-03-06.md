## 🛠️ 本周精选工具

### 1. **Anthropic Claude API**
- **类型：** LLM API 服务
- **特点：** 
  - 长上下文支持（200K tokens）
  - 强大的代码生成能力
  - 安全性和可控性优秀
- **适用场景：** 
  - 复杂代码生成
  - 长文档分析
  - 对话系统开发
- **链接：** https://www.anthropic.com/api

### 2. **LangChain**
- **类型：** LLM 应用开发框架
- **特点：**
  - 模块化设计，易于组合
  - 支持多种 LLM 后端
  - 丰富的工具和集成
  - RAG、Agent 开发友好
- **适用场景：**
  - 快速构建 LLM 应用
  - RAG 系统开发
  - AI Agent 开发
- **链接：** https://github.com/langchain-ai/langchain

---

### 3. **Hugging Face Transformers**
- **类型：** 深度学习模型库
- **特点：**
  - 海量预训练模型
  - 统一的 API 接口
  - 支持 PyTorch 和 TensorFlow
  - 活跃的社区
- **适用场景：**
  - 模型微调和部署
  - NLP 任务开发
  - 多模态模型应用
- **链接：** https://github.com/huggingface/transformers

### 4. **Ollama**
- **类型：** 本地 LLM 运行工具
- **特点：**
  - 一键部署开源模型
  - 支持 Llama、Mistral 等主流模型
  - 简单的 API 接口
  - 低资源消耗
- **适用场景：**
  - 本地开发测试
  - 隐私敏感应用
  - 离线 AI 应用
- **链接：** https://ollama.ai/

### 5. **LlamaIndex**
- **类型：** 数据框架（RAG）
- **特点：**
  - 专注于数据索引和检索
  - 与 LLM 深度集成
  - 支持多种数据源
  - 高效的向量检索
- **适用场景：**
  - 知识库问答
  - 文档检索系统
  - 企业级 RAG 应用
- **链接：** https://github.com/run-llama/llama_index
