# AI 工具推荐 2026-11-26

> 搜索窗口：2026-11-24 → 2026-11-26（2 天，承接上期）。这一期的两条主线是**价格**和**权限**：MAGI-2 把 1080P 视频打到 0.5 元/秒、Hy4 Flash 把单任务成本压到 1.3 美分；同时 OpenAI 把「算的时候也别看」做成了产品、Copilot CLI 让空参数真的等于禁用工具、T3 Code 因为读别人凭证被抓。**能力没大跳，账本和边界被重算了一遍。**

## 编码与代理

- **Cognition：Windsurf 改名 Devin Desktop**（11-24）— 原 Windsurf 的 IDE 能力全保留，新增 Agent Command Center，用 ACP（Agent Client Protocol）把别的 agent 与各家模型接到一个界面里管；老用户 OTA 升级，套餐、设置、扩展自动保留。同日发 **SWE-2.1**：仍在 Kimi K3 上用纯强化学习训，重点补长任务。
  https://devin.ai/desktop
- **SWE-2.1**（11-24）— 厂商自测：Terminal-Bench 4.1 从 24.2 到 50.0、SWE Marathon v1.2 从 32.5 到 54.9、FrontierCode 2.0 从 24.1 到 41.3；意外的大跳在安全侧，ExploitBench 36.1%→80%。Desktop 与 CLI 免费用到 **12-08**，之后 $0.50/$2.50 促销价到 01-30，再之后 $2/$10。Ultrafast 走 Cerebras 约 600 tok/s、不参与免费；Cyber 版只给 Devin Security。**没有公开 API、没有权重，全部分数未经独立复测**，官方表格里仍落后 Claude Opus 5.5。
  https://www.cognition.ai/blog/swe-2-1
- **Cursor 官方插件规范**（11-24）— 仓库 `cursor/plugins` 定义 `.cursor-plugin/plugin.json`，声明六类组件：skills / agents / rules / hooks / commands / mcpServers。纯文件、零构建，可直接 fork 提 PR；Graphify 这类第三方已按规范接入（MCP + 一条何时该用它的 rule）。**注意**：cursor.com/changelog 至今未收录这条（最新仍是 11-05 建站、11-06 语音），以 GitHub 仓库为准。
  https://github.com/cursor/plugins
- **GitHub Copilot CLI 1.0.115**（11-25 稳定版）— 最该检查的一处：`--available-tools=` 空值现在真的表示**一个工具都不给**（以前等同于全给），写死这行的脚本升级后会突然没有工具。其余：Windows 沙箱包查询默认开；macOS 可用 `sandbox.userPolicy.seatbelt.extraMachLookups` 放行特定 Mach 服务而不必开 Keychain；Assisted Permissions 在消息 ≤128k 字符后继续复用授权、并行调用不再重复问；模型选择加 Gemini 4 Hydrogen（Extra High）、GPT-6.2 Astra、MAI-Code-2-Flash。
  https://github.blog/changelog
- **Claude Code 2.1.332**（11-25 npm latest；stable 标签仍是 2.1.326）— 新增 `PreSkillShellCommand` hook，可在技能加载时拦下它的内联 shell 命令；MCP 服务器带来的技能以 `server:skill` 出现在斜杠菜单（beta）。修复：hook 无限输出导致内存暴涨、命名管道读取 20 秒超时、SSE 断流后所有工具调用挂住、大文件重写后 rewind 长时间冻结。`claude auth login` 失败改为非零退出。**注意**：团队里还有 2.1.331 及更早版本时，settings 里写了这个 hook 会在启动时弹窗，先别推共享配置。
  https://github.com/anthropics/claude-code/releases
- **Claude artifact 装成桌面应用**（11-24，beta）— Mac / Windows 逐步推送，全档可用（Team 默认可装但完全访问默认关，Enterprise 需 owner 开）。artifact 装上后有自己的图标与独立窗口，可发通知、进菜单栏/系统托盘，底层 artifact 一改应用自动更新；无需打包签名、无需 API key。三级权限：默认 → 应用权限（置顶、全局快捷键、通知）→ 完全计算机访问，**每次更新都要重新授权**；完全访问只能给自己或同组织成员做的应用；Anthropic 不审核。Claude Docs / Slides / Sheets 类 artifact 装不了。
  https://www.anthropic.com/news
- **Skills over MCP**（11-24 公测）— MCP 服务器除工具外还能发布技能，Claude 按需加载；Tasks 与 Elicitation 转 GA，File Uploads 即将（文件不经上下文窗口直传服务器）。首发案例 Shopify、HubSpot、Atlassian、Carta。官方称多服务器场景下 tool search 省 85%+ 上下文。Pro/Max/Ultra 默认开，Team 需管理员，Enterprise 后续。
  https://www.anthropic.com/news

## 框架与基建

- **OpenAI Private Inference**（11-25 宣布开测，Alpha）— 结合机密计算与「严格、可验证的控制」，在**模型处理期间**隔离提示词与响应，内部员工也接触不到内容。属 Private Intelligence 方案，另一件是「零数据留存 + 私有安全处理」（自动审查不把原文给员工）。**未公布**：定价、支持哪些模型、GA 时间；「可验证」依赖远程认证（attestation），文档未公开，暂不能当第三方已验证结论。对照组：Anthropic EFS 把数据与密钥留在客户云账户，Google 有 Private AI Compute，三种信任模型不一样。
  https://openai.com/index/
- **阿里百炼 decision-model**（11-25 上架）— 面向流程判定的结构化决策模型：输入文本/图像，并行做分类、是非判断与评分，返回概率与置信度；上下文 268,288，输入 **0.3 元/百万 token**（北京），RPM 5,000。大量「不支持」：Function Calling、结构化输出、缓存、批量、微调——它不是聊天模型，是嵌在工单分流、内容审核、agent 路由里的判定器。
  https://bailian.console.aliyun.com
- **DeepMind Mass Spec Skills**（11-25，Science）— 把质谱解结构串成 Antigravity 技能：去噪找母离子 → 查 GNPS/MoNA → SIRIUS 定分子式 → MAGMa/MetFrag 配碎片 → 用反应化学打破评分并列。评测：100 条公共谱，无技能时三个模型准确率都 <4%，加技能后都约 **97%**，Gemini 3.8 Flash 追平 Argon 与 Carbon；单次尝试 token 也降（Flash 近 4 倍）。示范了一种写法：把领域工具链和数据库查询包进技能，轻量模型就能追平前沿。
  https://deepmind.google/discover/blog

## 图像与视频

- **Sand.ai MAGI-2**（11-25）— 480B MoE（激活约 28B），原生 30 秒 1080P **带音频**，单次 4–30 秒可一镜到底或多镜头；最多 20 份参考素材（10 图 / 5 视频 / 5 音频），支持 2 万字符脚本与毫秒级切镜。Artificial Analysis 图生视频榜登顶。**价格是重点：0.5 元/秒**，约为 Seedance 2.5 的十分之一，30 秒 1080P 约 15 元。已完成海光、摩尔线程适配，官方称将尽快开放权重；发布前刚完成 2 亿美元 A+ 轮。
  https://sand.ai
- **SenseNova U1.6**（11-24 发布并开源）— 商汤 8B 统一理解/生成模型，首次给这代开源模型加**原生图像自修正**：先生成首稿，再对照原始提示查错字、乱码、英文拼写与编号，出修正版。内部评测美学分比 U1.5 Lite 高约 10%；UltraTextBench 密集信息图从单次 86.04 升到自修正后 92.28。开源给了四个版本（BF16 / Native FP8·INT8 / GGUF Q4_0·Q6_K·Q8_0 / 4·8 步 LoRA），已上 ComfyUI，自纠错最多 5 轮。分数均为厂商内部评测。
  https://www.sensetime.com/cn/news/sensenova-u1-6-open-source-20261124-1152
- **NVIDIA Nemotron-Labs-Image-30B-A3B**（11-25 放权重）— 自回归生图：30B 总参、每次激活约 3B，配 6.42 亿参数视觉分词器，Mamba-2 混合注意 + GRPO，参考部署为 4×H100 出 1024²。LongTextBench 97.98、GenEval 92.86 高于 GPT Image 2；GenEval2（65.43 对 81.00）与 Qwen-Image-Bench 落后。**两处要分清**：它只是 Nemotron-Labs-VisualCreation 框架里的光栅渲染组件，论文里框架级分数不能当单模型分数；许可是**非商业研究与评估**，不是标准开源。
  https://huggingface.co/nvidia/Nemotron-Labs-Image-30B-A3B

## 语音与翻译

- **Sage-Interaction**（11-26 前后开源，上海 AI Lab）— 全双工多模态：边听边说、随时插话、平滑换话题，流式视频理解，查资料/预订/提醒这类任务静默转后台再回流。响应时延 **1.29 秒**，双工交互质量 80.73，官方称为开闭源双工模型首位。定位是 SAGE 架构里的「系统 1」，复杂计算交给书生科学大模型。部署要 Linux + 支持 BF16 的 NVIDIA GPU + Python 3.12 / CUDA 12.8。
  https://www.shlab.org.cn
- **腾讯混元 Hy-MT3**（11-24 发布并开源）— 第三代翻译模型，1.8B / 7B / 30B-A3B（MoE，激活约 3B）三档，语种从 38 扩到 **102**。官方数据：误译样本比例 -43%、漏译增译 -74%、指令遵循错误 -40%；与王者荣耀团队合作打磨游戏本地化（占位符、富文本、术语必须原样保留）。已上 Hy 翻译 App 与小程序。**接入注意**：腾讯云 TokenHub 目前上架的仍是上一代 MT2，要用 MT3 得自己下权重部署。
  https://hunyuan.tencent.com
