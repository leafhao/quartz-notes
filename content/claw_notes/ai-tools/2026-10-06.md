## 本期速览

这一周没有单一旗舰，主线是**「Agent 从能聊走向能操作」**——而且四条线同时往前推：

- **能自己改自己**。Anthropic 把 Claude Code 的提示词、工具调用、权限判定与界面全部开放给 TypeScript 插件（Mods），自家 `/diff` 都改成了可替换的 Mod；DeepSeek Harness 两天后就跟进了实验性兼容层。
- **能操作桌面**。GitHub Copilot 在 CLI 与桌面端开放 computer use 预览，可读写任意 macOS/Windows 应用的界面；微软把 Copilot 重做成 Home / Code / Autopilot 三种模式，其中 Autopilot 就是一个后台常驻的数字同事。
- **能自己持有身份**。Manus 的 Cue 给每个 Agent 配了独立邮箱、电话号码、钱包和云电脑，可代接电话、代付款。
- **能自托管**。CopilotKit 的 OpenDots、Tuskira 的 Agent Gateway、DigitalOcean Managed Agents、Modal VM Sandboxes 在同一周补齐了「自己家里跑一个常驻 Agent」的四块拼图。

生成侧的实在变化有两个：**FLUX 3 用 JSON 边界框把「未编辑像素」变成可编程的确定性状态**，**Suno Speech 把语音和配乐压成一次生成**。

## 一、编码与代理

### 1. Claude Code Mods：把编码 agent 的内部控制面全部打开

**发布日期：2026-10-01（需 Claude Code 2.1.287+）｜类型：扩展系统 / 插件**

Anthropic 开放 Claude Code 的 mods：用几行 TypeScript（或直接让 Claude 自己写）挂到 agent 的事件上，可以**改写提示词、拦截或重试工具调用、批准或拒绝权限请求、脱敏工具输出、替换界面元素**。分发走已有的插件系统，`/plugin` 安装即可，多个 mod 按加载顺序堆叠。

与既有 hooks 的区别在于「能不能改」：hooks 只能观察和补充，mods 能**替换**——Anthropic 自家的 `/diff` 已改成一个可被禁用或替换的 mod。三个官方示例覆盖了开发者真正想要的三种能力：Token Weather（上下文用量 + 前 12 轮 sparkline）、Blast Radius（`rm -rf`、硬重置、强推前先算影响面并弹 Proceed/Cancel）、Replay Theater（回放一轮里的文件改动 diff）。

**注意**：**mods 没有沙箱**，与 Claude Code 本机权限等同，能读写文件、起进程、走网络，官方明确警告可能触及 API Key。Team/Enterprise 档内置 `sec-default` mod 会先加载以拦截高风险覆盖，管理员可控制插件市场。

**建议用法**：只装能追溯到发布者的 mod；先上 Blast Radius 这类「只做拦截、不碰数据」的，别一上来就装会改写提示词的。

### 3. GitHub Copilot computer use：让编码 agent 直接操作桌面应用

**发布日期：2026-10-01（public preview）｜类型：桌面自动化**

Copilot CLI 与 Copilot 桌面端（macOS / Windows）可用，通过操作系统的辅助功能树读取界面、必要时截图，然后点击控件、输入与编辑文本、按键、滚动、拖拽。目标场景是**没有 API、没有 CLI、也没有 MCP 的老软件与纯 GUI 流程**。

默认关闭：CLI 里 `/computer on` / `/computer show` / `/computer off`，桌面端在 Settings → Computer Use。控制某个应用前会请求批准，可设为「始终允许」并随时重置，macOS 会引导授予辅助功能与屏幕录制权限，组织策略可以整体禁用。

官网：https://github.blog/changelog/2026-10-01-github-copilot-can-now-interact-with-desktop-apps

**注意**：官方文档自己写明**可能选错控件、在错误位置输入文本**，并建议「凡是有 API / MCP / 终端 / 文件工具的场合就别用它」。这是个探索性工具，不是可复现的回归测试替代品。

**建议用法**：找一段「有 GUI 没接口、且做坏了也不心疼」的流程先试，别开 Always allow。

### 4. 微软 Copilot 重做：Home / Code / Autopilot 三合一

**发布日期：2026-10-01 至 10-02｜类型：办公助手 / 数字同事**

微软把原本分散的 Copilot 能力合并成一个助手，三种模式：

- **Home**：Chat 与 Cowork 合并，并把 Word / Excel / PowerPoint 做进 Copilot（Office in Copilot），不用切应用就能改文档、表格、演示。
- **Code**：非开发者用自然语言描述目标，生成应用、看板、自动化流程；底层与 GitHub Copilot 同一套技术，跑在沙箱里，也可托管在自家 Microsoft 365 租户内。

配套还有 **Microsoft IQ**（把 Fabric、Dynamics 365、Power Platform 的业务数据接进来做 grounding）与 **FinOps for AI**（用量计费）。Home 与 Code 走 Frontier 计划在未来数周铺开，Autopilot 本月进入私有预览。

**注意**：Home 与 Code 首批在 Frontier 计划内；Autopilot 仍私有预览。另一条与成本相关的变更：CSP 渠道新购的 M365 Copilot Business 许可，自 2026-12-01 起默认开启按用量计费（默认上限每用户每月 4,000 Copilot 信用点）。

### 10. Tuskira Agent Gateway：把一群 Agent 的凭据与策略收到一处

**发布日期：2026-10-01｜类型：Agent 治理 / 开源（Apache 2.0）**

一个 Go 单二进制，三个监听口：`:8080` MCP 面（Agent 连的入口）、`:8081` 控制面与控制台（注册 MCP 服务器、定义 profile、发 key、看日志）、`:8082` LLM 面（可选，Anthropic / Bedrock / OpenAI / Gemini 的 provider 原生路由，用你自己的 key）。它解决的问题很具体：**团队里的 Agent 是一个一个装进来的，每个都有自己的 key、自己的 MCP 清单、自己的权限认知**，等到要回答「这周哪个 Agent 动过生产 Jira、花了多少 token」时，答案散在账单页、本地配置和各自笔记本的日志里。

工具调用经过网关时会做三件事：校验 key 与 profile、判断该 profile 是否允许用这个工具（不允许就地拒绝并记日志）、把凭据从加密存储取出注入转发（Agent 全程不持有 token）。只需要 PostgreSQL 一个硬依赖。

**注意**：v0.4.0，**pre-1.0 alpha**。它不提供 Tuskira 账号也能跑是优点，但也意味着治理规则要自己写。

## 二、图像与视频

### 11. FLUX 3 Image：用 JSON 边界框把「没改的像素」锁死

**发布日期：2026-10-01｜类型：图像生成与编辑 / API**

Black Forest Labs 开放 FLUX 3 的图像模态（继 7 月视频档之后第二个）。核心是**元素表**：把画面里每个元素写成一条 JSON 记录（命名 ID + 0–1000 网格坐标 + 描述），这张表在多轮编辑之间**持续存在**，被框选之外的像素在数值上保持不变——官方说法是 bit-identical，不是「看起来差不多」。Agent 因此可以把元素表当成数据库行来可靠地维护项目状态，连改多轮不累积漂移。

其余规格：最多 10 张参考图按提示词里的编号引用（参考图与提示词不计费）、原生 2K 与 4K 输出。

价格按输出分辨率阶梯：768px $0.041、1K $0.048、1.5K $0.07、2K $0.10、4K $0.607；**10 月 8 日 15:00 UTC 前全档 50% off**。4K 单张可能耗时数分钟，返回图片只能在一小时内下载。商业权重可授权用于微调与自托管，**开源权重版预计数周内发布**。

官网：https://bfl.ai/

**注意**：图像能力是从**视频优先**的训练过程继承来的（超 95% 算力给了视频，音频 token 占比不足 0.5%）。目前**没有第三方独立基准**。与 Ideogram 4.5 Precise Edit 的分工：需要程序化、Agent 可访问的多轮合成 → Flux 3 的元素表更确定；需要自然语言一句改图、不想写布局 → Ideogram 更省事。

### 13. Tavus Griffin：把「视频图灵测试」打到了 48%

**发布日期：2026-10-01（Griffin-Lite 研究预览）｜类型：实时视频对话模型**

首个自称 **Human Interaction Model** 的模型，端到端 video-to-video：感知、对话决策与视频生成在同一个模型里，**以亚秒级间隔重新决策**该说话、点头、附和还是保持沉默，可以打断、可在句子中途改口——而不是流水线式「等你停下来我再开口」。视频用少步自回归扩散生成 **720p / 320ms 分块**，语音引擎约 10 秒音频即可克隆音色，全部动作与背景阴影由**一张参考图**驱动。

Tavus 自办的盲测里，54 人进行 1 分钟视频通话，**26 人（48%）认为对方是真人**（该公司前代系统为 1/41）；在英伟达独立执行的 VideoFDB 全双工基准上，感知与生成两条赛道均列第一，生成 3.83 分（人类基准 3.92）。

**注意**：48% 出自 Tavus 自己设计并执行的研究，样本 54 人、仅 1 分钟、且受试者被预设「要见一个真人」，这几条都利于模型。**Griffin-Lite 目前不开放给客户**，官方明确理由是「通过图灵测试的能力同样可用于欺骗」，先做披露机制。

## 三、音频与音乐

### 14. Suno Speech：朗读语音与原创配乐一次生成

**发布日期：2026-10-01（beta，全平台开放）｜类型：语音 + 音乐 / 端到端**

Suno 称其为**首个把语音与音乐作为单一连贯音轨共同生成的音频模型**。用法是给一段文字 + 描述想要的音色与音乐风格，模型一次输出「朗读 + 原创 BGM」，而不是「先 TTS 再找配乐再混音」三步。节奏与情绪在生成时就按文字含义对齐，而不是事后贴上去。

官方列举的用法很生活化：把朋友的短信读成「过度制作的戏剧化朗读」、给普通语音留言配上「不必要的史诗级配乐」，以及冥想引导、诗歌、打气话、睡前故事。

**注意**：官方**未公布支持语种、生成额度、定价与商用权利**——这是 beta 里最需要先看清的四项。官方自己承认当前偶发**口音漂移**（英音可能中途漂到澳音再漂回来）与**断句过慢**。

**建议用法**：短视频的片头/转场/片尾这类「短、以氛围为主、口音不敏感」的素材先试；客户交付项目等商用条款明确再说。

### 15. ElevenLabs Eleven v4 / v4 Turbo：新架构，把表达力与低延迟拆成两档

**发布日期：2026-09-28（本期补录；10-01 官方更新公告）｜类型：TTS / 语音克隆**

同一代新架构的两种运行形态：

- **Eleven v4**：面向配音、有声书、角色表演、长内容，联合理解 Tone / Pacing / Emotion / Character 与上下文，可用自然语言或 **inline tag** 直接指导表演（`[laughs]`、`[said angrily in French accent]`、`[light rain]`、`[phone buzzing]`）——控制对象不再是一个全局 Emotion 标签，人物状态、局部台词、非语言声音与环境音可以写进同一个请求。
