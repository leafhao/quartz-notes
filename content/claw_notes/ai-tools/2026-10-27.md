# AI 工具推荐｜2026-10-27

> 搜索窗口：2026-10-22 → 2026-10-27（5 天，承接上期）
>
> 本期主线：编码端从「写得快」转到「自己验证、自己编排」——Cursor 让 agent 打开桌面应用自测，微软把中心调度器拆掉，AWS 之外的框架层在补记忆与工具边界；图像端第一次出现「直出可编辑文件」这类交付级能力。

## 一、编码与代理

### Cursor Computer Use（10-23）
官方在 X 宣布智能体可以操控整台电脑，不再局限于浏览器。演示里 agent 驱动 iOS 模拟器，跑自己刚写好的功能并点击核对。任务需要时自动启用，也可以在提示词里 @ 提及主动调用，更新 Cursor 即可。
未公布的部分同样重要：支持的操作系统、权限模型、套餐限额与计费都还没写进 changelog。自助托管机型（Self-Hosted Machines）的文档要求 macOS 授予辅助功能与屏幕录制两项权限，且默认关闭、只能由管理员显式开启。
官网：https://cursor.com

### Claude Code 2.1.310（10-26）
本周 2.1.303–2.1.310 共八个版本，2.1.309 一次性修掉十余处沙箱与权限绕过：macOS/Linux 上沙箱命令会先在沙箱外跑 shell 启动文件、符号链接可绕过 denyWrite glob、沙箱内命令能改 `--mcp-config`、重定向与复合命令的权限判定可被绕过。2.1.310 再补一条钩子放行漏洞。
另新增 `claude_code.safety_event` 遥测事件，记录每次被权限规则、自动模式、安全检查、钩子或沙箱拦下的工具调用。依赖 deny 规则的团队应先升到 2.1.310，再复查规则本身。

### Codex CLI 0.164.0（10-25）
功能版：`/presets` 提供十个编号槽位存常用提示与斜杠命令，键盘菜单一键召回；`/model` 与 `/permissions` 支持内联传参；Kitty/Sixel 终端可在完整转录里预览图像；企业 MCP 支持 Codex 账号授权登录；远程 Bash 与 zsh 快照会话做凭据打码。沙箱侧加固了大小写变体元数据路径与可替换符号链接。
官网：https://github.com/openai/codex

### Microsoft Agensh（10-24，MIT）
微软研究院开源的多智能体编码框架，最大特点是没有中心调度器。每个 worker 自行认领子任务，通过 Gitea 共享工作区、Mattermost 消息通道与共享上下文同步，代码直接合进同一个 Git 仓库。
官方口径：ProgramBench 最难 5 题、GPT-5.6-sol high、6 小时预算、断网条件下，1 个 agent 到 128 个的通过率从 19.31% 升到 28.78%；pandoc 任务上 1,024 个 agent 六小时内从 33.89% 升到 55.06%。仓库另给出 GPT-6.1-sol 下 pandoc 从 56.19% 到 79.59%（32 个 agent）。
仓库：https://github.com/microsoft/Agensh

### GenAICode（10-24，开源）
从独立编码 CLI 转型成轻量封装层，把 Claude Code 等模型嵌进网页应用与浏览器游戏。自带 Vite 插件处理打包、热更新与开发服务器配置，React/Vue/Svelte/原生 JS 都能接；统一多家 provider 接口，内置重试与限流管理，换 provider 不改代码。
对前端团队的意义：不用自建 agent 基建，也能在应用里加实时生成与调试能力。

### Agent Relay（10-25，开源）
解决开发者在 Codex 桌面端、Claude 终端与自定义 IDE 之间手工复制粘贴会话的问题。不同环境的 agent 可以互读会话历史、发起异步查询、来回传递任务上下文。
仓库：https://github.com/willwashburn/agent-relay

### Corgi（10-25，开源）
为多 agent 并行工作流做的终端复用器。统一仪表盘 + 资源追踪，F1 一键跳到有新输出的 agent；用本地小模型对操作树、HTTP 链接与跨 agent 上下文做语义摘要，缓解同时跑多个 agent 时的认知过载。

### ToolForge v0.2.2（10-26，Rust + Tauri 2）
开源桌面工具箱，插件化架构整合开发调试、数据转换、文件处理与系统管理。本版新增 MCP 与 CLI 支持，并引入插件级权限管理，让 agent 能受控调用工具而不必交出整机权限。

## 二、技能与插件

### claude-plugins-official（10-25）
Anthropic 官方维护的 Claude Code 插件目录，已收录 315 个插件。一个插件就是一个文件夹，内含斜杠命令、子 agent、技能与 MCP 服务；GitHub、Figma、Notion、Stripe、Supabase、Vercel 均在列，`/plugin install` 一条命令装好。
官方 README 第一句就是提醒：装之前先确认你信得过它。
仓库：https://github.com/anthropics/claude-plugins-official

### Claude 公益插件（10-26）
Anthropic 与约 30 家非营利机构共建的 workflow 包，覆盖筹款与运营场景。已认证非营利组织的 Team 与 Enterprise 席位自动安装，不额外收费。
官网：https://claude.com

### T3 Code iOS 2.1.0（10-25）
移动端正式支持折叠双屏布局，并加入离线消息排队机制。手机上可直接看代码 diff、走引导式讲解、派发 webhook 任务。

## 三、图像与视频

### Canva Craft（10-22）
Canva Research 从零训练的首个图像模型，也是 Canva 第一个自研基础模型。两阶段架构：先由规划模型把提示词写成构图方案（元素、空间关系、层级、文字位置），再由渲染模型出图，最高 2K、30 多种画幅。
训练数据以 Canva 素材库数百万份人类设计模板为主，而非照片，因此文字更可读、改图可只动局部。DesignArena 首发第四，Elo 次日回落到 1330；人物与人像、风景两类拿到第一。API 模型名 `craft_v1_2k`，单次约 50–60 秒。
官网：https://www.canva.com/newsroom/news/canva-craft/

### Ideogram Vector 1.0（10-22）
主要厂商里第一个直接输出可编辑 SVG 的模型，不再走「先生成 PNG 再描摹」的老路。文本生矢量带可选参考图，图生矢量直接上传 JPEG/PNG/WebP（≤50MB）换回形状；支持雕刻、波普、平涂、线稿等风格，可在 Illustrator 与 Figma 里逐形状编辑。
定价：文本生矢量 low/medium/high 为 $0.13/$0.16/$0.20，带参考图的高质量 $0.32；图生矢量 $0.10。两个已知短板：复杂图暂不按图层分组，字母密集的正文排版仍需手工调字距。
官网：https://ideogram.ai

### Seedance 2.5 4K（10-23）
火山引擎面向影视的版本，原生 4K 输出加 10-bit 色深，强化微表情、细微动作与纹理细节。工作流上的改变更实际：先用 480P 出草稿验分镜，定了再生成 4K 正片。
目前仅对部分企业客户内测，无公开定价、无 API 时间表。BytePlus 以短片《Otter is Nobody 2》作为首发案例。

### FLUX 3 Max 图生视频（10-26）
Fal 与 Black Forest Labs 合作上线，基于 FLUX 3 Video 架构的图像条件视频模型。720p 输出、可选 1080p 超分与音频合成，10 秒片约 11 秒出，迭代场景延迟改善明显。
注：10-20 期推的是 FLUX 3 Max 图像模型，这次是视频侧。

### LTX Studio VFX 套件（10-26）
面向影视与广告后期的专业工具组：Alpha Gen 不用绿幕就能抽干净软遮罩，Refine 与 Restore 做素材修复，SDR→HDR 管线直出 16-bit EXR；支持 8K 分块处理，并提供面向工作室的开放权重微调。

### 即梦短剧工作室（10-26）
把剧本、美术设定、分镜、后期与成片重制放进同一套流程。自研剧本模型 Dream 可解析 10 万字长篇，Anycook 负责角色与场景设计，DreamShot 支持画布、故事板与 3D 导演台预演；后期可对单个片段重生成、分离人声与背景音。

### Hi3D V1.0（10-26，开源）
前身 Sparc3D，本次放出全部源码与权重。有效稀疏网格分辨率到 1536³，专为制造流程设计，直打 3D 打印的切片成功率官方称约 90%。

### Viggle JST-2（10-26）
社交平台 TopTop 上线基于该世界模型的多人 3D 互动玩法 Slap Showdown：玩家用 2D 照片 30 秒生成可操控 3D 化身，物理与动作由统一时空架构生成，官方称单场景推理成本低于 1 美分。

## 四、音频与语音

### Ollama TTS / Phonon（10-24）
Ollama 首次支持语音合成，首发模型是 Gradium 造的 Phonon 系列小模型，目前仅 macOS，Windows 与 Linux 在路上。`ollama run phonon "..."` 即可出声，`--voice` 切换音色。
关键改进是把它接在 chat 模型后面：输出边生成边朗读，第一句结束就开始播放，不用等整段。走 OpenAI 兼容的 `/v1/audio/speech` 端点，已有代码几乎不用改。许可分层：Phonon 本体 Apache 2.0，40M 小版本为 CC BY-NC 4.0（限非商用）。
官网：https://ollama.com

### Kitten-TTS 2（10-22，开源）
KittenML 放出全球首个 1.58 位（三值化）文本转语音模型，纯 CPU 即可实时推理，支持不足 5 秒参考音频的零样本克隆与 20 多种语言。端侧配音与离线朗读的门槛被拉到很低。

### Hurston-1（10-25，开源）
Destined AI 的开源 TTS，专门做主流系统会抹平的口音：美国南方英语，以及尼日利亚、西非、东非、南部非洲多种英语变体。声音用自然语言描述（性别、年龄、口音、风格、语速）生成，不做真人克隆。
独有的一点是 phone mode：默认 24kHz，开启后切到 300–3400Hz 电话频带、重采样到 8kHz 并编成 G.711，直接对接 SIP 与 Twilio。训练集约 10 小时电话音质语音、250 位贡献者。

### VoxCPM2（10-24，开源）
OpenBMB 的端到端扩散自回归 TTS，直接生成连续语音表示、绕开离散分词器，支持 30 种语言与 48kHz 输出。用自然语言描述即可设计新音色，无需参考音频；基于 MiniCPM-4 骨干，2B 参数对本地部署友好，RTX 4090 上 RTF 约 0.3（Nano-vLLM 加速后约 0.13），带 OpenAI 兼容 API。

## 五、框架与基建

### Google Agent Compute Engine（10-22）
Google Cloud 在 AGNTCon + MCPCon 发布，为每个 agent 分配一台硬件隔离的 microVM，走 Cloud Hypervisor 边界、独立客户内核与 root 权限。核心设计是**沙箱内不存凭据**：microVM 没有标准网卡与直连 VPC，流量经 virtio-vsock 到 Agent Gateway，策略校验后才注入真实凭据，每次会话带 SPIFFE 工作负载身份。
空闲时自动挂起释放资源，恢复含文件与内存状态；20 万 agent 压测下暂停/恢复不到 500ms，靠写时复制内存共享在单机塞更多 agent。最初支撑 Gemini、Antigravity 与内部评测，后续开放给开发者。Kubernetes 侧的对应物 Agent Substrate 已在 GKE 开源。
博客：https://cloud.google.com/blog

### Google Cloud Data Agent Kit GA（10-25）
面向编码 agent 的数据工具包正式可用，支持 Claude Code、Codex、Cursor、VS Code 兼容编辑器与 Antigravity。设计上把三件事分开：开源 skills 提供流程建议，MCP 工具负责实时访问，IAM 决定 agent 到底能读写哪些资源。GA 新增 BigQuery Graph、Bigtable、Serverless Spark、Iceberg 与数据管道支持，对 Google Cloud 用户不额外收费。

### WebMCP 商用落地（10-26）
Cloudflare 与 Commerce.com 把 WebMCP 铺到近 10 万个店铺域名：站点不再让 agent 靠看页面猜按钮，而是直接声明 `search_products`、`add_to_cart` 这类可调用工具。桥接在边缘交付，访问仍留在商家站点，凭据不外流，购物车可由 agent 更新、结账仍归人。
注意边界：WebMCP 仍是 W3C 社区组草案，Chrome 149 起在 origin trial，WebKit 六月已正式反对（安全、隐私、API 设计三点）。

### ThinkingBox-Training（10-24，微软 × HuggingFace 开源）
agent 强化学习工具链。核心观点是「至少通过一次」（pass@20）会掩盖生产环境的不稳定，于是改用真实后端数据库的确定性终态校验做 0/1 奖励，并在训练池上做 off-policy 相对难度筛选。GRPO 训练后 Qwen 系列有提升。

### Cadence Maestro（10-26）
EDA 厂商 Cadence 的芯片设计 AI 模型系列：让 agent 先理解设计目标、拆解工作，再操作 EDA 工具并分析结果，工具产出的评估结果回流训练。可选 Cadence 云、公有云或自有数据中心部署，气隙环境可用。官方初步测试称相较通用基础模型，设计结果质量最多改善 30%，token 效率最高 5 倍。部分模型基于英伟达 Nemotron 开放权重并集成 OpenShell。首批 Q4 开放给特定客户。

## 六、国内

### 腾讯 Hy-Nomas（10-23 发布 / 10-26 开源）
混元视觉生成团队的交互式视频世界模型，Apache 2.0，权重已上 Hugging Face。不是「生成一条看完就结束的视频」，而是分段自回归：每段结束时重新输入文本或给一条相机轨迹，下一段沿新设定继续，改风格、改动作、改场景在多轮里累积完成。
长程一致性靠 lifelong KV cache 维持；约 8B 参数，输出 1280×704 / 24fps；经 INT8 量化、滑动窗口历史与 CPU offload，单张 RTX 4090 可本地推理，还能用自有视频做 LoRA 微调。技术报告尚未发布。
官网：https://hy-nomas.hy.tencent.com
仓库：https://github.com/Tencent-Hunyuan/Hy-Nomas

### 腾讯 Hy-Memory（10-26，开源）
30B 参数的记忆模型，思路是把记忆拆成快慢两套：一套应付当下对话，一套存长期。目标是让会自我迭代的 Agent 别聊着聊着忘了自己是谁。

### 腾讯 Hy-SimulMT（10-26，开源）
中英语音到语音实时同传模型，开源，支持音色克隆，响应约 3 秒。实测延迟低于六位持证 CATTI 同传专家，将服务 11 月深圳 APEC 会议。

### 讯飞星火 X2.6（10-26，开源）
全国产算力训练的端云一体模型，同步开源 4B 端侧版本，可直接塞进本地设备。端云协同路由准确率官方称 96.1%。

### 南北阁 Nanbeige4.3-33B（10-26，Apache 2.0）
BOSS 直聘旗下团队产物：先造 33B 教师模型再蒸馏 3B（3B 尚未放出）。开放权重，52 万 token 上下文，Terminal-Bench 2.1 得 80.9、DeepSWE 65.5，定位 30B 档 agentic 模型。

### 小米 HachimoDock（10-26）
小米技术委孵化的开源桌面 AI 硬件，自制成本约 150 元。ESP32-P4 主控 + 2.8 英寸屏，语音意图可拆成任务派发给电脑端的 Codex、WorkBuddy 等 agent，多台设备之间能互相接话。源码、物料清单与装配教程全部公开，允许个人非商业复刻。

### 达摩院 RynnUnify（10-26，Apache 2.0）
16B 统一具身大脑，用交错式视频-语言推理同时支撑空间推理、物理预测与长时域规划，是具身大模型往「统一大脑」架构走的代表工作。

## 七、企业与模型侧

### Oracle Fusion Claw（10-26）
Oracle AI World 上发布的受治理 agent 平台，覆盖供应链预测、航运、餐饮运营与医疗等场景，强调在既有治理控制内推理、计算、执行。现场给的例子是一家航运公司靠它省下 5.8 万美元运输成本。同步宣布四年 10 亿美元伙伴生态投入。

### Atos Genesis Intelligence（10-26）
面向受监管行业的 agent 平台，部署选项包括主权云、本地与气隙环境；配套 Atos Codex 平台把运营数据与 AI 推理接到具体动作，并保留人工审批环节。客户成效尚未经第三方验证。

### Kimi K3.1 Pro（10-24）
月之暗面 K3 系列首个正式版：3 万亿参数、100 万上下文，官方称迄今最强，在代码、3D 创作、金融研究与长程 Agent 上提升最明显，Terminal-Bench 4.0 得 65.7%（Claude Opus 5.5 为 66.4%）。同步推出 Highspeed 版，智能水平相同、速度约 2–3 倍、价格 2 倍。开放权重版主动移除了网络攻防相关能力，完整权重计划 11 月 4 日前发布。
10-26 官方为限流与额度消耗过快致歉，全档位会员补月度额度 25%。

### GPT-6.1 Terra（10-26 美西 / 10-27 北京）
OpenAI 面向电脑操作场景的快速低价模型，输入 $1 / 输出 $5 每百万 token，是 GPT-5.6 Terra 与 GPT-6.1 Sol 的一半、GPT-6 Astra 的十分之一。约 105 万 token 上下文，最大输出 12.8 万，支持文本与图像输入。
官方数据：Agents' Last Exam 上比 GPT-5.6 Terra 高约 15 个百分点而成本约三分之一；低推理强度错误率从 53.6% 降到 16.7%；Terminal-Bench 准确率从 21.5% 升到 50.3%。已进入 ChatGPT Work、Codex 与 API（`gpt-6.1-terra`），同日上 Amazon Bedrock。
