## 本期速览

这五天的两条主线都不在「模型又变强了」上。

**第一条：Agent 开始被关进操作系统级的笼子。** 微软把 MXC 转正——一个 JSON 声明文件、网络、桌面的边界，由操作系统执行，Agent 自己改不了；Anthropic 在误提交假线索给警方后，把全部内部评测的实时联网关掉；Satya Nadella 同步发文要求企业假定模型已被攻破。同期爆出的是能力的另一面：能操作浏览器的 Agent，读一个被污染的 README 就可能拿到你机器上的一切。

**第二条：编码工具的战场从「写得快」转到「一口气跑几个」。** Claude Code 把 Projects 的等待名单清空，Pro/Max 全量给并行任务线程；Codex 与 OpenCode 同一周都补上托管 Git worktree；Cursor 则把「人在外面、Agent 在家跑」这件事做成手机上的一个入口。三家的答案不同，问题同一个：一个人到底能同时看住几个 Agent。

另有一条安静的线：**决策模型开始下沉成标准件**。微软、Cloudflare、Liquid AI 三周内接连落子，llama.cpp 也补上了对应端点——「把链路里只需要一次判断的节点单独剥出来」正在从技巧变成默认架构。

## 一、编码与代理

### 1. Claude Code Projects：清空等待名单，Pro/Max 全量开放

**发布日期：2026-10-12｜类型：编码 Agent / 产品开放**

Anthropic 一次性取消了 Claude Code Projects 的等待名单，**所有 Pro 与 Max 订阅者即刻可用**。Project 是一个长期存在的对话：Claude 在其中统筹开发工作，把每个任务拆成**各自的线程并行推进**——多个改动、测试、重构可以同时进行而不是排队。

**注意**：这是开放权限而非新功能，口径上属「已发布能力的全量灰度」。它和 Cursor 的 Projects、Google 的 Jules 是同一件事的三种做法：把编码 Agent 从「一次会话」变成「常驻的协作者」。对专业团队的实际差别在上下文连续性——跨会话不丢，才谈得上长期项目。

### 2. Cursor iOS 遥控本地 Agent（10-06，本期补录）

**发布日期：2026-10-06｜类型：编码 Agent / 远程控制**

Cursor 的 iOS 应用现在能**列出并回复正在你自己电脑上跑的 Agent**。配对三步：装 App 登录 → 电脑自动出现在列表 → 桌面端批准配对。之后能看到 Agent 状态、当前任务与实时 transcript，可以插话、批 diff、回答问题。**Agent 不搬家，代码不出本机。**

**注意**：代价写在同一份 changelog 里——**电脑必须保持开机联网**（设置里有「保持电脑唤醒」，要求接通电源、合盖无效）；**企业版组织默认关闭**，管理员要在 Org settings → Security and identity → Remote control 手动开；目前**只有 iOS**。它与 Claude Code 的 Remote Control 是同一设计（后者会把会话记录存在 Anthropic 服务器上，Cursor 未说明）。这是本期最贴近日常体验的一条。

### 3. 阿里 Qoder Fast 模式：响应快 150%，Token 降 27%

**发布日期：2026-10-12｜类型：编码与办公 Agent 平台**

Qoder 上线 Fast 模式，中国版与国际版**所有用户可直接启用**。官方口径：生成速度提升超 **150%**，单次交互 Token 消耗减少约 **27%**，平均响应时间从性能模式的 **8 秒缩到 3 秒**。三层优化分别是——模型层接高吞吐低延迟模型 + 智能路由（推理效率 +12%）、Agent 运行框架层重构上下文加载与工具调用（执行效率 +28%）、网络层压缩全链路等待（端到端 -15%）。

**注意**：官方给的是自测数据。它的产品线已从主平台扩到 Qoder IDE、CLI、JetBrains 插件与数字员工 QoderWake。对高频重复任务（日报、补代码、修缺陷）值得试，复杂推理仍建议切高档位。

### 4. 智谱 ZCode 上线 GLM-5.3-Highspeed：490 tokens/s

**发布日期：2026-10-12｜类型：高速推理模型**

智谱在 ZCode 平台上线 **GLM-5.3-Highspeed**，已在 ZCode 3.15.1 灰度，订阅用户随机开放。网友实测最高生成速度 **490 tokens/s**，**100 万 token 上下文**、最大生成约 128K token，支持 low / high / max 三档思考强度。对比前代 GLM-5.3-FlashX 的最高 200 tokens/s，提升明显。

**注意**：速度本身对长文档写作与长任务有实用价值，但**灰度 + 随机开放**意味着暂时无法稳定复现。

### 5. 编码 CLI 齐上 Git worktree：Codex 0.162 与 OpenCode 2.0.27

**发布日期：2026-10-08（Codex）/ 2026-10-12（OpenCode）｜类型：编码 Agent CLI**

同一周两个终端 Agent 给出同一个答案：**隔离靠 Git worktree**。

- **Codex CLI 0.162.0**（10-08）：在受信任项目中**自己创建与列出托管 worktree**；Command Center 可用 `p` 固定任务，让一个任务的改动不串到另一个；`/copy` 与 Ctrl+Insert 导航复制 transcript；自定义模型提供方可配实时网页访问与远端压缩；apply_patch 保留 CRLF；opt-in 的 Code Mode 排序工具搜索。0.162.1（10-09）修 TUI 崩溃与后台服务配置不匹配的启动问题。
- **OpenCode 2.0.27**（10-12）：Code Mode 可创建/列出/删除 worktree，**删除需编辑审批**；`opencode pair --remote` 首次会警告将暴露你的 server 并要求确认（`--yes` 跳过）；Chrome / Edge 可安装 OpenCode Web App（含代理认证后）；Code Mode 的 fetch 不再能读 `file://`。前一版 2.0.26（10-08）加了 Vertex 的 Google Cloud 凭据与更快的会话快照。

**注意**：**升级路径要看清**——OpenCode 1.x 与 2.x 双线并存，v1.19.0（10-11）提供 `opencode upgrade --major`，升级后不再自动更新。GitHub Copilot 在 VS Code 1.141 里也跟上：Agents 窗口可网格并排看多个会话，并新增 worktree 占用清理入口。

### 6. JetBrains Mellum2.1：12B 编码模型开源

**发布日期：2026-10-08｜类型：编码模型 / 开源（Apache-2.0）**

JetBrains 放出 **Mellum2.1**，12B MoE，专为编码 Agent 设计。后训练用**真实编码环境里的强化学习**：模型自己翻仓库、改文件、再回头验证改动。权重在 Hugging Face，Apache-2.0。

**注意**：适合拿一个有失败测试的仓库跑对照——诊断、出补丁、自查结果，和现用模型比质量与延迟。JetBrains 的模型线此前存在感不强，这条值得记一笔。

### 7. Anthropic 开源 11 个岗位插件（knowledge-work-plugins）

**发布日期：2026-10-10｜类型：办公 Agent 插件 / 开源（Apache-2.0）**

Anthropic 开源了**自己内部在用**的插件脚手架：11 个面向具体岗位的插件包，覆盖生产力、销售、客服、产品、市场、法务、财务、数据、企业搜索、生物研究，外加一个**用来造新插件的插件**。每个包装好技能（skills）、斜杠命令（commands）与 MCP 连接器。销售接 HubSpot / Clay / ZoomInfo，财务接 Snowflake / Databricks / BigQuery，法务接 Box / Egnyte。

**架构才是重点**：全部是 markdown + JSON，**没有一行代码、没有构建步骤、没有基础设施**。装法两条命令：

```
claude plugin marketplace add anthropics/knowledge-work-plugins
claude plugin install sales@knowledge-work-plugins
```

**注意**：发布后数日仓库即冲到约 2.9 万星。它解决的不是模型能力，而是「每个员工各写各的提示词、结果忽好忽坏」——把工作流变成可复用资产。**约束是 MCP server 的覆盖面**：你的公司用了一个没有 MCP server 的工具，就得自己写或等。另外这些插件会直连 CRM 与数据仓库，上生产前要过一遍权限审查。

### 8. Claude Managed Agents 支持「动态工作流」（10-09，本期补录）

**发布日期：2026-10-09｜类型：Agent 平台能力（beta）**

Claude Platform release notes 新增：Managed Agents 的 agent 可以**自己写一个 workflow**——一段分阶段跑多个 agent 并合并结果的程序，服务器在后台把它当作一次 workflow run 执行（需 `managed-agents-2026-04-01` beta header）。开启方式是把 agent 的 `multiagent` 设为 `{"type": "multiagent_20261001", "workflows": {"type": "enabled"}}`，并用 `workflow_run.*` 事件跟踪。

**注意**：官方口径只说「分片很多的活」（例如审阅数百份文档）。第三方转述称单次最多并行 **1,000 个子 agent**。Managed Agents 仍为 beta，**暂不支持零数据保留与 HIPAA**——敏感数据场景先不要用。

### 9. Google Cloud Gemini agent：常驻云端的通用工作 Agent

**发布日期：2026-10-08｜类型：企业级 Agent 平台**

Gemini at Work 2026 的主角。定位是「**一个通用的工作智能体**」：问答、做知识工作、生成图像与媒体、写并运行代码，全部在一个提示框与一个 API 内。架构原则四条值得记——统一智能体（对话 / 自主执行 / 生成代码同一界面，可派任务、排定时、响应事件）、无处不在的访问（Web、iOS/Android、Windows/macOS、CLI、Workspace、Microsoft 365、Slack，也可做无界面 headless agent）、**持久执行**（跑在云端，关掉笔记本任务继续）、**模型选择可插拔**（当前在 Gemini 家族与 Anthropic Claude 之间编排，官方称多模型路由能提升难题准确率、降低简单任务成本）。

**注意**：同批发布的还有 gemini 内联进 Workspace（Gmail / Drive / Docs / Slides / Sheets / Chat / Calendar 共享同一套记忆与技能），以及智能体身份与策略治理、Smart Routing 与实时支出上限。这是本期体量最大的一条工具发布，但落地要看企业侧的权限梳理。

### 10. Chrome Relay：让编码 Agent 借用你日常的 Chrome

**发布日期：2026-10-10｜类型：编码 Agent 配套 / 开源（MIT）**

一个命令行工具，让编码 Agent **在你日常用的 Chrome 里、带着你真实的登录态**、在后台标签页干活。省掉的正是最烦的那一步：为 Agent 单独准备一份干净浏览器再重新登录一遍。

**注意**：正因为带真实登录态，它的**风险面等于你的浏览器**——用在可信站点与可信任务上，别让它拿着你的银行会话自己点。

### 11. Talorys：个人 Agent 跑在你自己的 Cloudflare 账号里

**发布日期：2026-10-10｜类型：个人 Agent / 自托管（MIT）**

一个跑在**你自己的 Cloudflare 账号**里的个人 AI 助手，README 列的能力是聊天、记忆、任务、笔记与定时提醒，一条命令装好。作者把「服务器成本」与「数据主权」两件事同时解决了——用的是 Cloudflare 免费额度，数据落在你自己的账户里。

**注意**：项目很新（10-10 建仓，24 小时内 440 星）。适合想自己留一份对话与记忆、又不想维护服务器的人当周末项目。

## 二、图像与视频

### 12. Qwen-Image-2.1-Turbo：8 步出图，官方加速版开源

**发布日期：2026-10-09｜类型：图像生成与编辑 / 开源（Qwen Research License）**

阿里通义把 **Qwen-Image-2.1** 的加速检查点开出来了：**同一套 7B 视觉生成架构 + Qwen3-VL 8B 文本编码器**，去噪步数从基座默认的约 **40 步压到 8 步**。采样调度（8 步 SIGMAS）**直接写进 checkpoint**，加载即生效，不能靠 `num_inference_steps` 覆盖。默认 CFG=1，靠**前缀 KV 缓存**复用文本与参考图上下文。

能力与基座一致：文生图与图像编辑合一、单张最高约 2K（2048×2048 / 2752×1536）、最多 **10 张参考图**、圈选/涂抹/独立掩码局部编辑、**原生透明 RGBA 输出**（64 通道 RGBA VAE，不需要额外的透明处理通道）。权重在 Hugging Face 与魔搭；托管 API 上阿里云 Model Studio，**国内百炼 Turbo 定价 0.1 元/张**（Pro 为 0.25 元/张）。

**注意**：官方**没给质量对照表**，8 步相对 40 步在小字、密排文字与多参考图一致性上保留了几成，要自己实测。**授权要看清**：Qwen Research License，商用自托管需单独向阿里确认。社区量化版已出（基座约 11GB GGUF / 24GB INT8）。

### 13. Grok Imagine Video 1.5 Lite：低至每秒 2 美分

**发布日期：2026-10-08｜类型：视频生成 / API**

xAI 把 `grok-imagine-video-1.5-lite` 加进 Grok Imagine API，**输出定价每秒 $0.02（480p）/ $0.03（720p）/ $0.14（1080p）**，图像或视频输入另计。官方视频概览说它做「文生视频与图生视频，带口型同步语音，每秒单价最低，靠 720p 上采到 1080p」，片段长 **1 到 15 秒**，限流 10 请求/秒，支持批处理。Elon Musk 称 Grok bot 会自动使用该模型。

**注意**：**它砍掉的是控制力而非清晰度**——不支持参考图、音色参考与固定关键帧，那些仍属完整版 Video 1.5（$0.08 / $0.14 / $0.25 每秒）。Artificial Analysis 把 Lite 排在文生视频榜第 17，**高于 Veo 3.1 而价格约为其三分之一**（第三方口径）。它把「试概念」这一档的成本压到了可以随手试。

### 14. Magnific One：先定艺术指导，再出图

**发布日期：2026-10-08｜类型：商业图像生成**

Magnific（原 Freepik）的图像生成产品，核心主张是**在生成之前先定艺术指导**——模型读懂提示词、风格与参考后就定下视觉方向，而不是先出图再挑。两种模式：**Draft** 一条提示词返回 **8 到 16 个方向**（积分成本约等于一次生成），**Final** 出 2K 或 4K 成品、最多 **5 张参考图**。定价：2K High 每张 180 积分、4K Max 1,000 积分，年付起 $14.50/月。

**同批上线的 Brand Kit 更实用**：给一个网站、一份品牌手册 PDF、几张图或一段文字，agent 自动抽出 logo、配色、字体、图像风格与语调，人工复核后保存为长期规则；Final 模式生成时直接参与构图，生成后**再对照规则自查偏差**并标出问题。另有 Auto Layers（拆成可编辑图层）、Designer（矢量级改文字/配色）与 Figma / Photoshop 插件。

**注意**：VentureBeat 称其底层是 **GPT-Image-2**（Magnific 产品市场负责人说法），但该公司的书面 FAQ 写「没有训练任何东西」，两种说法**尚未对齐**。官方称不使用用户提示词、图像与 Brand Kit 训练模型。

### 15. Noiz AI Helix World：声场随镜头转的实时世界模型

**发布日期：2026-10-12（论文 09-29）｜类型：交互式世界模型 / 预览版**

Noiz AI 与香港科技大学（HKUST）联合发布。给一张起始图，用 **WASD 走动、方向键转头**，可选文字提示——**画面与立体声一起更新，声场随视角转动**。多数交互式世界模型只出无声画，它把声音做成了原生输出：一次生成约 **1.3 秒**，新的按键或提示从下一段生效。

性能（官方自报）：单张 **NVIDIA H800** 上 768×512 / 24fps，稳态实时率 **0.77**（含音视频解码）；训练数据从 4,100 小时原始素材过滤到 **3,000 小时 / 210 万片段**，要求真立体声与相机位姿。建于开源音画模型 **LTX-2.3** 之上，加 6 自由度镜头与键盘动作控制，再蒸馏成少步因果学生模型。基准 HelixBench（团队自建，1,015 例）上**空间声学一致性 41.8**，对比 EchoWM 的 12.7。

**注意**：**所有分数都是作者自报，无人独立复现**。画质上它略逊于最好的无声模型（WBench 导航 79.9 vs 82.0），**静音时人更偏好 EchoWM**；实时率是数据中心卡的数字，论文没报消费级 GPU。预览版权重 70GB 显存起（推荐 80GB）。demo 开在 helixworld.org。

## 四、文档、写作与办公

### 17. Claude Dashboards 与 Claude Motion：无代码仪表盘与动画

**发布日期：2026-10-08｜类型：办公与创意产出**

**Claude Dashboards**（付费计划 beta）：接业务数据平台与 CRM，用自然语言查询搭**实时仪表盘与分析**，不需要写代码。**Claude Motion**（Team / Enterprise beta）：把提示词变成**可编辑动画并导出为 MP4**——官方特别说明它是**用代码把你自己提供的文字、图表与图片动起来，不调用视频生成模型**，所以不产生幻觉画面。**Runway 是发布伙伴**，任何 Claude Motion 做的动画都能导出到 Runway 再加生成素材与剪辑。

## 六、框架与基建

### 28. 阿里 QwenGyre：超长程 Agent 的在线 RL 框架

**发布日期：2026-10-12｜类型：Agent 训练框架 / 开源**

面向**超长程 Agent 任务**的在线强化学习框架（论文 `arXiv:2609.33848v1`，QwenGyre: An Elastic Reinforcement Learning Framework for Training xLong-Horizon Agents）。解决的问题很具体：Agent 一次执行可能持续数小时、与环境交互数百轮、累计百万级 token，传统 RL 里「等一轮 rollout 跑完」会把 GPU 空着，而复杂分支又产生大量冗余数据。

两个核心模块：**弹性调度器**（不把 GPU 固定切成推理池与训练池，而是实时监控未完成推理量，在不打断在跑任务的前提下把空闲 GPU 动态转给训练；支持流式训练，新节点可无缝接入正在进行的批次，在跑任务的进度、状态与缓存整体搬走，不重头算）；**轨迹处理器**（用 Token-in-Token-out 记录每段输出的真实上下文，按共享前缀组织成**轨迹树**，只把被选中的路径展开为训练样本，共享前缀只算一次损失；**超时但部分完成的任务用 Partial Scoring 给分**，不让半成品变成废数据）。整个框架是**黑盒兼容**的——不改现有 Agent 运行环境，靠代理记录模型调用与工具响应。

官方数据：NL2RepoBench 上每次 rollout 约 70 万 token，48 步训练后**通过率从 52.5% 提升到 58.5%**；相同 GPU 预算下相对 Async 实现 **1.78×** 端到端加速（相对 colocate 最高 1.85×）；在 Qwen3.6-122B 上跨 NL2RepoBench / DeepSWE / TerminalBench 三类任务均获提速。

**注意**：**开源范围与可复现性待观察**——长程在线 RL 牵涉模型服务、环境沙箱、分布式调度、缓存迁移与 trainer 协同，只放框架名不够降低复现门槛。另外 **Partial Scoring 的奖励函数设计直接决定训练天花板**：打分有漏洞，模型会学着刷分而不是完成任务。1.78× 是特定任务规模与基线下的数字，不能外推。

### 29. CopilotKit Open Intelligent UI：开源版 ChatGPT Intelligent UI

**发布日期：2026-10-09｜类型：生成式 UI 框架 / 开源（MIT）**

OpenAI 本周把 Intelligent UI 带给 ChatGPT（回答由图表、地图、可交互小应用组成）后，CopilotKit 放出开源替代：**同样的体验搬进你自己的产品**。Agent 会自己决定这次回答用一个事实（文本）、一个趋势（图表）还是一个流程（可交互图示），生成式代码跑在**隔离 iframe** 里、只能从白名单 CDN 载入库，任何生成界面都能**下载为独立 HTML**。支持用你自己的设计系统与组件，也支持 Google 的 A2UI 生成式 UI 规范。

技术栈：CopilotKit 的 Open Generative UI + LangChain Deep Agents 做后端，AG-UI 做 Agent 与前端之间的开放协议——**换 Agent 框架（Mastra、Google ADK、Microsoft Agent Framework）不用动 UI**。

**注意**：**默认配置仍然依赖 OpenAI**——回答默认走 OpenAI 的 `chat-latest`，挑选视觉形式要第二个模型 **Jev（TypeSafe）**，需要两把 key；**Jev 失败时整个回答失败**，不会静默回退。仓库并非全新（由 3 月的 Open Generative UI 改名而来，约 1,700 星含旧名期间）。README 也注明 demo 数字是示意、地图路线未验证。CEO 称支持 web / 移动 / Slack，README 只描述了 web 与可选 MCP server，**口径不一致**。

### 30. 微软 MXC 正式可用：把 Agent 关进操作系统沙箱（10-07，本期补录）

**发布日期：2026-10-07｜类型：Agent 安全基建 / 开源**

**Microsoft Execution Containers（MXC）** 从 Build 2026 的预览 SDK 转为正式可用（Windows 11，Windows 365 支持同步 GA）。本质是**策略驱动的执行层**：开发者用一个 **JSON schema** 声明 workload 需要的文件、网络目标、进程与 UI 权限，MXC 把它映射到四种隔离后端——**进程容器**（Windows 用 AppContainer、macOS 用 Seatbelt、Linux 用 Bubblewrap，三平台通用）、**会话容器**（Windows 11，独立账号与独立桌面/剪贴板/输入）、**WSL 容器**、**MicroVM**（实验性，硬件级隔离）。核心保证是 **policy 保持在 agent workload 控制之外**——「agent 或生成的代码无法给自己授予额外权限」。

Windows 上另有 **Learning 模式**：进程容器会记录 workload 试图访问过什么（JSON 活动报告），让你先看清再收紧策略，而不是靠猜。三个模式分别是 Enforcement / Learning / Permissive。

**注意**：**已经支持的**有 OpenAI Codex、GitHub Copilot、OpenClaw、Replit、LM Studio、Unsloth AI，NVIDIA 集成 OpenShell；**宣布支持但未交付**的包括 Anthropic Claude Code、Box、Egnyte、Manus、Perplexity、Raycast。企业最需要的两块——**Intune 集中管理与 Entra 区分 agent 与用户身份——都还是「即将到来」**。微软自己的措辞也很克制：容器「**旨在阻止**」而非保证。多种后端的**安全强度并不相同**，共享一套策略格式不等于同等保证。接入前先问供应商一句「支持 MXC 吗」，本期六个主流 Agent 已经支持。
