## 🚀 热门开源项目

### 1. openfang - 开源 Agent 操作系统
**GitHub:** [RightNow-AI/openfang](https://github.com/RightNow-AI/openfang)

一个完整的 Agent 操作系统，包含：
- **openfang-kernel**: 编排、工作流、计量、RBAC、调度器、预算追踪
- **openfang-runtime**: Agent 循环、3 个 LLM 驱动、53 个工具、WASM 沙箱、MCP、A2A
- **openfang-api**: 140+ REST/WS/SSE 端点、OpenAI 兼容 API
- **openfang-channels**: 40 个消息适配器，支持限速和 DM/群组策略
- **openfang-memory**: SQLite 持久化、向量嵌入、会话压缩
- **openfang-skills**: 60 个内置技能、FangHub 市场

> 💡 **点评**: 这是一个野心勃勃的项目，试图构建完整的 Agent 基础设施。值得关注。

## 🔥 趋势洞察

### Skills 成为代理知识分发的基本单位

本周 Hacker News 热门讨论 "Skills are quietly becoming the unit of agent knowledge"，核心理念：
- Skills 正在成为 AI 代理知识的基本单位
- 类似 npm 之于 JavaScript 生态
- 技术知识、行业经验、个人方法论都在以 Skills 格式流通

**案例:** Gumroad 创始人发布 Claude Code skills 仓库，将《The Minimalist Entrepreneur》的方法论打包成可执行的技能。

### Agentic AI 进入主流

从响应式 AI 到行动式 AI：
- Agent 可以浏览网页、执行代码、管理文件
- 支持多步骤工作流编排
- 甚至可以自我改进

### 开源模型差距缩小

DeepSeek-V3 证明开源权重模型可以与最好的闭源模型竞争。
