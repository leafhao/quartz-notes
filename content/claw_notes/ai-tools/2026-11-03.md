### Factory Droid 1.0 —— 把工具调用改成「写一段程序」
- 发布：2026-10-31，Factory 称这是 Droid harness 迄今最大的一次更新。
- 机制：**程序化工具调用成为默认**，模型写一段程序去跑工具，一次请求可驱动数百次工具调用。基础提示词从 20,887 token 压到 **13,055**（降 37%），前置工具定义从 11 个减到 **2 个**。
- 成绩（厂商自测）：Terminal-Bench 4 上配 Claude Opus 5.5 通过率 **65.2%**，每个通过任务 **$4.73**；配 GPT-6.1 Sol 为 57.6%，**$0.79**。官方也承认最差项是 GPT-6.1 Sol 上比 Codex 慢 10%。
- 其他：提示缓存命中 98% 输入、488ms 首屏、有界自主（bounded autonomy）。
- 形态：macOS / Windows 桌面、终端 TUI、Node SDK `@factory/droid-sdk`，可用自己的 API Key。付费 $20/月起。
- 官网：https://factory.ai/ ｜ 文档：https://docs.factory.ai/

### GitHub Copilot Fusion 转正 —— 选的不再是模型，是努力程度
- 发布：2026-11-02 前后转 GA（10-28 Universe 上首次公布）。
- 变化：模型选择器里挑的是一套**自动路由与编排系统**，由 Project HydraFusion 的多模型编排加 Copilot 自动选模的微调策略合并而成。
- 官方指标：Artificial Analysis Coding Agent Index 上 Fusion Max 得 **60**，与 Opus 5.5 Max 加持的 Claude Code 相差 2 分内；平均每任务 API 成本约一半、token 约一半、耗时少约 40%。

### Claude Messages API 消息线程（公测）—— 长会话不再重发全文
- 发布：2026-11-02，beta header `message-threads-2026-08-12`。
- 机制：首轮带完整对话并开线程，之后每轮只发新消息 + 上一条回复的 ID；线程加密存内存、不落盘，**最后一次请求后 5 分钟过期**（过期返回 404，需重发完整对话）。
- 数据：50 万–100 万 token 的请求首 token 延迟中位数降约 **35%**；长会话单请求体量中位数从 **800KB 降到 1.8KB**。该能力对多数 Claude Code 用户已默认开启。
- 边界：**token 用量没减少**（模型每轮仍读完整上下文），省的是传输与预填充；不支持 ZDR 与 HIPAA；批处理接口不支持；线程中途不能改系统提示词和工具。
- 链接：https://claude.com/resources/articles/message-threads

### Gemini API Computer Use 正式可用
- 发布：2026-10-30，Gemini API 更新日志；Interactions API 与 GenerateContent API 同时转 GA。最早 2026-06-24 以公测形态出现。

### 阿里云 Memory 服务升级 —— 记忆变成可接进任意 Agent 的一层
- 发布：2026-11-02，百炼 Agent Studio 的核心服务之一。
- 能力：从对话实时提关键信息，按规则存成记忆与**用户画像**；后续会话按身份与问题检索并塞进上下文，减少重复发问；偏好变了先确认再更新。
- 接入：API（写入、查看、语义检索）、**MCP、CLI**，可直接接 **Codex、DeepSeek Harness、Claude Code、OpenClaw**；控制台可自定义记忆规则、画像字段、调试检索与追踪变更。
- 自报评测：HaluMem-medium 上记忆提取召回/准确/F1 与问答四项最高；PersonaMem-v2 总分 **56.82**，在所列 8 个系统中第一，9 个维度中 7 项最高。无独立验证。
- 链接：https://help.aliyun.com/zh/model-studio/

### NVIDIA PixelUMM —— 不要 VAE 也不要 ViT，直接在像素上统一理解与生成
- 发布：2026-11-01 前后公开（NVIDIA 与滑铁卢大学）。
- 做法：图像切空间 patch、视频切时空 tubelet，理解与生成共用同一套表示，只经一层线性投影就进多模态主干；主干是 Mixture-of-Transformers（理解与生成各一套参数、共享注意力），文本自回归，图像与视频用像素空间 flow matching。
- 意义：省掉双流表示（ViT + VAE）带来的长视觉上下文，也绕开 3D VAE 的时间维难题；全部开源。
- 链接：https://nv-tlabs.github.io/PixelUMM ｜ 代码：https://github.com/nv-tlabs/PixelUMM

- 链接：https://huggingface.co/unsloth/Mistral-Large-4-1T-A52B-GGUF ｜ 指南：https://unsloth.ai/docs/models/mistral-large-4

- 发布：2026-10-29。基于 **MiniMax H3 后训练**，不是从零训练的新架构；用投影分布匹配蒸馏（PDMD）把 50 步去噪压到 **6 步**。

- 许可证要看清：沿用 MiniMax H3 社区许可，**不含欧盟、英国、韩国、美国**；年收入超 2000 万美元需书面许可；禁止用输出训练其他模型。模型卡没有 benchmark。

### Hume Audio Decision API —— 把音频变成可提问的接口
- 发布：2026-11-02，开放申请（候补名单）。

- 数据：官方称用超过 **1000 万**条人类听觉判断训练，与人类评审团判断的一致率 **70.7%**；一次调用可替代此前 10 个以上模型。未公布标准价格。
- 边界：返回的是对声音表达的判断，不是对当事人内心状态的诊断。
- 链接：https://www.hume.ai/
