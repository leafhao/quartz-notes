# AI 工具推荐 2026-11-17

> 搜索窗口：2026-11-12 → 2026-11-17（5 天，承接上期）。主线是**「技能」成为新的交付单位**——Google、NVIDIA、腾讯在 24 小时内各自发布技能工具链；另一条线是国产模型把单价继续往地板打，阿里与腾讯同日上新。

## 编码与代理

- **Claude Projects 主动式协调者**（11-14）— Projects 里的协调者从「等你问」改成「主动报」：可以直接在主对话里问各线程进度，也可以预设条件（「只在完成或受阻时通知我」）。新增 `/btw` 单开一条线程处理临时插进来的问题、不动主线；`/fork` 从当前线程分叉试两种方案；线程可生成只读分享链接（访问过本地电脑的线程不可分享）；最近成果文件集中显示缩略图。官方提醒多线程会更快烧配额。
  https://www.anthropic.com/news
- **Claude HTML-in-Canvas**（11-16）— 桌面版 Canvas 现在能直接渲染 HTML/CSS/JS，且保留文本可选中、可复制、可被读屏软件读取。演示是「融化文字」效果但字符仍能逐字选中。底层走隔离 iframe，沙箱限制外部网络与系统资源；Chrome / Edge 157 起支持，Safari 与 Firefox 还没有。要按名字点名才触发。
  https://www.anthropic.com/news
- **Claude 自托管 Managed Agents**（11-12，私有 Beta）— 整个 Managed Agents 服务（不只是沙箱）可以跑在企业自有云或机房，agent、会话与会话历史都存在内部；服务器把模型请求转给自选供应商（默认 Anthropic）；凭据不进 agent 工作区，由中间层按需注入；每步可记录并导出到自有监控。需向 Anthropic 客户团队申请。
  https://platform.claude.com/docs/en/release-notes/overview
- **OpenCode 2.3.0**（11-13）— 子代理改为默认后台运行，父会话可继续并发接活。TypeScript 仓库已 22.6 万星。
  https://opencode.ai
- **Codex 0.169.0**（11-13）— 新增常驻侧边会话标签页，并支持跨旧任务检索，同时开几条线时不用来回翻。
  https://github.com/openai/codex
- **Cloudflare Kitesurf 开源**（11-13，Apache 2.0）— 八月上线的 Agent 专用无状态浏览器引擎正式开源：跑在 Workers 上，不启 Chromium 容器，自己解析 HTML、算 CSS、执行页面 JS、出截图；说 CDP 协议，Puppeteer / Playwright 直接连。官方八月口径：截图 CPU 380ms vs 878ms、内存 57.8MiB vs 271MiB，但墙钟慢 1.7—1.8 倍。不能放视频、不跑 WebGL、不处理机器人挑战握手。自托管要 Workers 付费计划。
  https://blog.cloudflare.com/kitesurf-open-source/
- **Coral v1.8**（11-13 发版，11-16 上 Show HN，Apache 2.0，Rust）— Agent 不再逐个调工具，而是写一段 TypeScript 程序，在无网络、无凭据的 V8 隔离区里跑；程序里的每次调用被网关拦下，按 Allow / Ask / Block 逐次判定，通过后才补凭据转发。跑通的程序可存成自定义工具，下次一步调用。官方自报 34 个任务上 token 降 37%、成本降 31%。客户端只要支持 MCP 就能接（Claude Code、Codex、Cursor、VS Code）。
  https://github.com/withcoral/coral

## 技能与插件

- **Google Stitch Skills**（11-16 开源，Apache 2.0）— 把 Stitch 的 UI 设计能力打包成 Agent 技能，三个插件：stitch-design（文生界面、代码转设计、抽 DESIGN.md）、stitch-build（React / React Native / shadcn 出码）、stitch-utilities（把模糊需求改写成设计级提示词、按 `.stitch/SITE.md` 逐页建站）。走 Agent Skills 开放标准，Codex / Claude Code / Cursor / Gemini CLI / Antigravity 都能装，OpenCode 需手工拷。前提是先配好 Stitch MCP。已约 9,500 星；README 明确「非 Google 官方支持产品」。
  https://github.com/google-labs-code/stitch-skills
- **NVIDIA SkillEvaluator 0.9**（11-16）— 回答「这个技能到底有没有用」：先跑不需要 API key 的确定性质量门，再做语义重叠检测（防止两个技能干同一件事），最后对比「有技能 / 无技能」两次运行看行为是否真的变了；0.9 新增预算上限与版本 diff。可接 GitHub / GitLab CI，把坏技能拦在 PR 阶段。Apache 2.0，约 2,100 星。
- **腾讯 LoopForge**（11-16 开源，MIT，Go）— 自托管工作台，团队通过 Agent 交付而不是一个人开终端：向 Main Bot 描述任务，它开 Docker 沙箱、拉仓库、分派角色、提 PR；跑通的流程可存成带脚本与人工签核的 SOP。支持 CodeBuddy、Codex、Claude Code、OpenCode、Cursor CLI、Antigravity、Kimi Code。要点是审批发生在运行中而不是结束时。约 2,100 星，13 个版本。
- **PaperOrchestra**（11-17 登上 GitHub 热榜第 11）— Google Research 的多智能体论文写作框架，1,499 星、当日 +313。属研究工具，不是成品应用。

## 文档与办公

- **Gemini Notebook 生成交互网站**（11-17）— 在 Notebook 对话框里输入 `make me a site` 加描述，就能把笔记本里的资料变成可交互站点：备考用的可点元素周期表、历史时间轴，探索数据的仪表盘，或列任务与截止日的项目跟踪器。生成后可新标签页打开或分享。网页版全球 18 岁以上用户陆续开放（含 Workspace 订阅者），移动端后续支持。
  https://blog.google/products/gemini/
- **Gemini 技能可读文件并分享**（11-16）— 自定义指令现在能直接引用 Drive、Photos 或最大 100MB 的上传文件，也能分享给别人用。
- **Google Gems 今日起退役**（11-17）— Gems 开始分批下线，原本能做的大部分事已由 Skills 承接。用惯 Gems 的人需要迁移。
- **OpenAI 医疗 computer-use Agent**（11-16）— computer-use 能力开进 ChatGPT for Healthcare、ChatGPT for Clinicians 与 API，可配置哪些应用与动作可用、加审批步骤、留审计日志；处理病历需走 BAA 与安全留存设置。官方自评 325 个 GPT-6 Astra 病历收件箱任务中 99% 临床安全，1% 含「未经签核就动手」；HealthAdminBench 上 Astra 94.3%、GPT-6 Luna 91.8% 但每任务 8.5 美分。CVS 称一条生产 Agent 周末清掉了积压数月的单据。
  https://openai.com/news

## 框架与基建

- **llama.cpp v1.0.0**（11-13）— 三年半滚动构建号之后第一个正式版，ggml 同步 1.0.0。核心承诺是语义化版本：破坏 API/ABI 才跳大版本，下游应用（Ollama、LM Studio 等都嵌它）终于能当稳定依赖用。同版删掉 35 个废弃函数、`llama.h` 清场；新增 FP8 KV 缓存（`-ctk/-ctv f8_e4m3`）、MoE 专家缓存（`moe_cache_size` + CPU 回退）、OpenAI 兼容的 `/v1/audio/speech` 端点；llama-server 补掉 CORS、DNS rebinding、SSRF 几个洞，并把 MCP 工具调用改成断连即取消。支持 150+ 架构。
  https://huggingface.co/blog/llama-cpp-1-0
- **vLLM 0.34.0**（11-17）— Model Runner V2 成为唯一 GPU runner，V1 移除；多数模型默认拿到更大的 KV 缓存。
  https://github.com/vllm-project/vllm
- **SOV-Transcribe-1**（11-12，Salesforce，Apache 2.0）— Salesforce 首个开源语音模型，26.6B 总参 / 4.6B 激活，Whisper large-v3 编码器 + Gemma 4 26B-A4B 解码器。AA-WER 2.28%，开源非流式转写第一、总榜第七；比同激活量的 Nemotron 3.5 Transcribe（2.81%）和 24B 的 Voxtral Small（2.77%）都低。可用自然语言指令控制逐字稿还是清洗稿，支持术语与上下文提示，单段最长 30 分钟，7 种语言。BF16 权重约 53GB，非流式，不适合实时对话。指标为厂商自报，两套测试集未公开。
  https://huggingface.co/blog/salesforce-sovereign-intelligence/sov-transcribe-1
- **Perplexity Frontier Research**（11-16）— 立项做能自主做研究的 AI 系统，投入 1 万+ GPU，承诺论文、模型与数据公开。
  https://www.perplexity.ai/hub/blog
- **AWS Bedrock Agentic Retrieve**（11-16）— 知识库与 AgentCore memory 合并成一次 `AgenticRetrieveStream` 调用：同时取会话历史、抽事实、返长期记忆。参考实现是多用户助手，每人只见有权限的文档，记忆彼此隔离。
  https://aws.amazon.com/blogs/aws/
- **NVIDIA DGX Spark HPC 开发套件**（11-16，SC26）— 四台 DGX Spark 桌面机连成环形集群，每台与两个邻居直连，面向高校与研究者；配套 HPC SDK 安装 playbook 待发。
  https://blogs.nvidia.com

## 图像与视频

- **LongCat-Video-Avatar 1.6**（11-15，美团 LongCat，MIT 开源权重）— 音频驱动数字人模型换代：口型、面部与肢体动作、长视频一致性都比 1.5 好，官方称可做到 10 分钟以上。输入音频 / 文本 / 图像，输出视频，支持单人与多人对话场景。权重在 Hugging Face，仓库 11-13 建、README 标注 11-15 发布。
  https://huggingface.co/meituan-longcat/LongCat-Video-Avatar-1.6
- **Seedance 2.5 4K API 全面开放**（11-16）— 火山引擎结束邀请制，4K 生成向全体开发者与企业开放。至此 2.5 家族（旗舰 4K / flash 720P）双梯度齐全，4K 从「能不能用」变成按量买。
  https://www.volcengine.com
- **华为 CloudRobo-WM1.2**（11-16，昇腾原生）— 华为云首个具身世界模型，开源交付的不是单独权重，而是模型 + 训练框架 + 仿真验证 + 云边端部署的整套链路。RoboTwin 2.0 与 LiberoPro 2.0 两个仿真基准第一。技术上用 PPA 多模态世界表征推演物体后续变化、DualAct 直接出动作、跨本体语义保真让单臂/双臂/轮式共用一套认知模型，支持四档弹性推理。官方自己提示：仿真分数不等于真机可用，长尾工况与时延仍待打磨。

## 音频与音乐

- **Suno Bridge**（11-13，Beta）— 独立 Mac 应用，和 Ableton Live 12 并排跑，用 Live 的循环标记圈定小节，写一句话就让 Suno 按当前速度、调性、和声与律动生成器乐或人声分轨，直接落到时间轴。生成的是普通音频片段，能继续 warp、切片、过效果链。限制很硬：仅 macOS、仅 Live 12、必须 Premier（$30/月）、每次生成 10 credits；打开工程会把 Ableton 项目与音频上传到 Suno 做上下文分析（上传音频过版权过滤，命中不摄取）；生成内容不进 Suno 网页库，只在 Bridge 的 Downloads 里。
  https://suno.com/blog/introducing-bridge
