## 一、代码生成工具

### Cursor Origin：Cursor 开始自己托管代码（8-17）

Cursor 在 changelog 里宣布 **Origin** —— 自家的代码托管服务，今天起在所有付费计划上滚动开放 early beta。首批能力是「为 agent 规模设计」的基础件：repos、pull requests、code browsing、GitHub 同步，agent-native 特性稍后上线。新建 repo 后有独立的 Codebase tab，URL 形如 `cursor.com/codebase/<你的 codebase 名>`，可以用 CLI clone 或 push 本地项目，也能直接把 GitHub 仓库接进来。

同期 changelog 里还有 Builds（新环境默认启用，可手动触发、可让 agent 调试失败的 build、可配置 stale 阈值）和 8-3 的 Google Workspace 插件（让 coding agent 直接读写 Gmail / Drive / Calendar）。

来源：[Cursor Changelog](https://cursor.com/changelog)

> 值得关注的点：Cursor 从 IDE 往上游走到代码托管，这是在跟 GitHub 抢 agent 时代的入口位置。对个人开发者短期意义不大，但如果你已经在用 Cursor 的 cloud agent，Origin 能省掉一层 GitHub 往返。

### Codex 8 月更新：分页 thread history + sub-agent + 音频输入

Codex 的 8 月发布加了实验性的**分页 thread history（带 sub-agent 支持和 memories）**、音频输入，以及扩展的 `/import` 命令 —— 能把 Cursor 和 Claude Code 的设置、MCP servers、plugins、sessions、project 级 memories 一起迁过来。OpenAI 明显预期开发者会在几家 coding assistant 之间来回切，想把迁移成本压到几分钟。

同一篇还统计了各家的模型开放度：Copilot 的 picker 覆盖 3 家厂商 7 个模型（github.com 从 2026-04-14 起支持给 Claude 和 Codex agent 选模型）；Devin Pro 打包 OpenAI + Claude + Gemini 加自研 SWE 1.7；Antigravity 免费档覆盖 Gemini / Claude / gpt-oss-120b；Kiro 是「前沿 Anthropic 模型 + 开源权重 Qwen3 Coder Next + DeepSeek v3.2」的组合。封闭一端是 Cursor 的 Composer 2（只在自家 IDE，无外部 API）和 Claude Code（只跑 Claude）。

## 二、开发者工具 / MCP 生态（本期最高价值品类）

### TrueForge：开源 agent harness，对标 Claude Managed Agents（8-19）

TrueFoundry 发布 **TrueForge** —— 开源的 agent harness，让企业团队在不被单一厂商锁死的前提下构建、部署、调试、治理生产级 AI agent。核心卖点：可基于**任意模型或任意 MCP server** 搭建，宣称把 agent 总运营成本降低 50%，VentureBeat 的报道标题给的数字是任务完成成本比 Claude Managed Agents 便宜 **30~75%**。

论证逻辑值得一看：TrueFoundry 的说法是 GLM-5.2 这类开源模型正在以极低成本快速追平前沿闭源模型，但多数托管 agent 平台仍把企业锁在某一家的模型、基建和定价里。TrueFoundry 今年 6 月还收购了英国 MLOps 老牌厂商 Seldon AI（Seldon Core 用于生产模型 serving），策略上是把传统 ML、LLM、tools、agents 放到同一套部署和治理层下面。

来源：[HPCwire/AIwire](https://www.hpcwire.com/aiwire/2026/08/19/truefoundry-debuts-trueforge-for-building-and-managing-ai-agents) · [VentureBeat](https://venturebeat.com/orchestration/truefoundrys-open-source-ai-agent-harness-trueforge-boasts-30-75-cheaper-task-completion-than-claude-managed-agents)

### Nutanix 开源 NCP 的 MCP server（8-20）

Nutanix 宣布 **Nutanix Cloud Platform 的 MCP server**，开源实现 MCP 规范，让 AI agent 和开发者工具通过 Nutanix Prism v4 API 与 NCP 交互。对开发者的实际价值是「把系统蓝图前置喂给 coding assistant」，之后可以直接生成可上平台跑的脚本 —— Python / Go / Java / JavaScript / PowerShell / curl 或任何 REST+JSON 兼容形式，也能通过单一界面配置精确的安全权限。

来源：[IntelligentCIO](https://www.intelligentcio.com/me/2026/08/20/nutanix-puts-agentic-ai-into-action-for-enterprises)

### Observe by Snowflake：MCP server 重构版 + 新 CLI 双双 GA（8-14）

Snowflake 宣布重新设计的 **Observe MCP server** 和**全新 Observe CLI** 正式 GA（各集群滚动上线，eu-2 和 ca-1 稍后）。设计上的关键决定：**CLI 与 MCP 完全对等** —— MCP server 暴露给 agent 的每一个操作，都有对应的 CLI 命令。面向的是想把自己的 agent 接到 Observe、或者干脆绕过 UI 直接操作平台的工程师。

来源：[Snowflake Blog](https://www.snowflake.com/en/blog/observe-mcp-server-cli-ai-agents-telemetry)

> 这个「MCP 与 CLI 严格 parity」的做法挺聪明 —— 同一套能力人和 agent 都能用，不用维护两套语义。做内部工具时可以借鉴。

### Revid：单个 prompt 出完整短片，全流程开放给 agent（8-14）

Revid 把能力从短片段扩展到完整叙事 —— 一个 prompt 打通剧本、分镜、配音、剪辑、发布。平台已累积 24 万+ 视频、1.4 万+ 用户、68 国 32 语言，400+ 创作者的作品破 10 万播放。整条 pipeline 通过 **Revid MCP server + 公开 API + CLI** 开放给 AI agent，agent 可以直接下单制作并监控到完成。还在扩充「agent skills」目录 —— 把常用工作流打包成任何 MCP 兼容助手都能直接跑的指令。

来源：[Newsfile](https://www.newsfilecorp.com/release/309329/Revid-Now-Generates-Complete-Short-Films-from-a-Single-Prompt-Handling-Script-Scenes-Voices-Editing-and-Publishing)

### ⚠️ 反面配套阅读：MCP server 正在成为企业密钥泄露面（8-17）

The Hacker News 的这篇讲 MCP server 如何暴露企业机密。跟上面几条一起读比较有意思：MCP 生态在一周内新增了这么多企业系统接入点，同期安全侧就出现了对应的告警。自建 MCP server 时值得先看一眼。

## 三、AI Agent 框架

### Google ADK 发布 zero-trust-agents 开源安全参考实现（8-18）

Google 的 Agent Development Kit 团队发布了名为 **zero-trust-agents** 的开源安全参考 —— 一个完整可跑的示例，演示如何构建「碰到线上数据库也不会立刻变成负债」的自主 agent。基于 2025 年 4 月开源的 ADK 和 Gemini 模型，核心是一个能发起退款、写数据库、执行动态生成 Python 代码的「客服与退货 agent」，重点在它展示的安全架构。

背景数据值得记一下：**prompt injection 已经爬到 OWASP LLM 应用漏洞榜首**，研究显示在受控环境下注入攻击成功率高达 **84%**。文章的判断很直接 —— LangChain、CrewAI、AutoGen、LlamaIndex、Semantic Kernel 都提供了让 LLM 调工具的编排机制，但**没有一个原生阻止被操纵的模型在人来得及干预前执行危险动作**。行业惯常建议是外挂一个独立的「agent control plane」做策略执行，而 Google 这个 demo 的特别之处是把这套逻辑直接嵌进了参考实现里。

来源：[The University Network](https://www.tun.com/home/google-releases-zero-trust-ai-agent-security-blueprint-on-adk)

> 如果你要自己搭 agent 跑本地任务（比如让 agent 动 Obsidian vault 或飞书表格），这个参考实现的权限模型比"在 system prompt 里写规则"靠谱得多。文章专门有一节论证「为什么 system prompt 规则不够」。

这是阿里今年 HappyHorse（多模态模型）、HappyOyster（世界模型）之后的第三步，背景是阿里要在五年内把云和 AI 收入做到年 1000 亿美元（五倍增长）的目标。

来源：[Music Business Worldwide](https://www.musicbusinessworldwide.com/alibaba-launches-ai-song-generator-happyshrimp-1-0-in-beta-with-chinas-taihe-music-signed-up-for-artist-co-creation) · [Briefs.co](https://www.briefs.co/news/alibaba-s-new-ai-music-tool-turns-text-into-full-songs)

## 五、国产 AI 工具

本期国产查询命中中关村在线（搜狐转载）的 20 款编程工具全盘点（8-14），信息密度最高的几条：

### Kimi Code（月之暗面）

CLI + VS Code 插件两种形态，当前默认 **K2.7 Code** 模型，也可切到 **K3**。K3 的榜单成绩：Arena.ai 的 Frontend Code Arena **1679 分排名第一**，超过 Claude Fable 5 和 GPT-5.6 Sol；SWE Marathon 长周期任务 **42.0 分第一**；Terminal Bench **88.3 分**，距第一名仅差 0.5 分。

功能层面：`/goal` 目标驱动模式（定义目标后 AI 持续推进）、Sub-agents（拆独立上下文并行）、Agent Swarm（批量任务多 agent 并行）、长任务后台运行、**HighSpeed 模式出码速度是标准模式的 5~6 倍**。团队能力：Skills 封装团队规范、Hooks 在关键节点自动执行脚本、MCP 连外部工具、Plugins 打包整套配置。

**国内直连**，订阅制 ¥49/月起，用 K3 需 ¥99/月档；K3 API 缓存命中输入 2 元/百万 token，编程场景缓存命中率超 90%。

> 对你这台 Mac mini 最实用的一条 —— 国内直连 + ¥49/月 + Skills/Hooks/MCP 概念和 Hermes 高度同构，迁移心智成本低。K3 的 Frontend Code Arena 第一和 SWE Marathon 第一如果站得住，性价比明显优于绕代理用 Claude Code。

### Qoder CN（阿里云，原通义灵码）

通义灵码已于 **2026-05-20 正式更名为 Qoder CN**，含三个产品：Qoder Desktop（IDE + JetBrains 插件 + CLI）、QoderWork 桌面助理、QoderWake 数字员工。支持 **Kimi / 通义千问 / GLM / DeepSeek / MiniMax 多模型切换**，有 Quest 自主模式、Subagent 和 MCP 支持，Credits 计费。适合需要多模型选择、深度用阿里云生态的开发者。

### TRAE Work（字节跳动）

AI 办公平台，Work / Code / Design 三种模式，桌面端 + 移动端 + 网页端多端协同，**基础功能免费**。Code 模式支持编码、调试和 Git 工作流，中文优化好，新手门槛低。定位是「不想折腾网络、预算有限」的学生和初学者。

GitHub 上的开源项目（原「带货剪手」），上传一张商品图，AI 自动提炼卖点 + 写种草脚本 + 锁定商品原图不变形。值得记的是它 2026.08 确认支持的视频模型清单，相当于一份国产视频模型的现状表：
