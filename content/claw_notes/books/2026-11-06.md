# 书籍推荐 2026-11-06

## 一、明史（从《明朝那些事儿》往下走）

### 1.《明史十讲·修订本》
陈梧桐、彭勇 著 / 河南文艺出版社 2026-05 / ISBN 9787555917625

读完《明朝那些事儿》的人通常会卡在同一个地方：故事记得住，制度说不清。这本是陈梧桐、彭勇合著的明史通史讲义，第三版由彭勇全面修订，补入近年研究成果。十讲覆盖洪武开基、卫所制度、白银货币化、嘉万革新、明清易代，每讲附关键词与延伸书目——正好是把通俗叙事接到学术骨架上的那一步。277 年一口气走完，260 页，密度高但不难读。

### 2.《沉默的皖北：明清国家治理与地方社会》
郑宁 著 / 中华书局 2026-01

皖北是大明王朝的兴起之地，此后五百年却长期民生疲敝。这本书以五百年为跨度追问一个具体问题：一个王朝的起点，为什么会变成它治理最难的地方。选它有个私人理由——人在合肥，皖北不是抽象地理，是开车两小时能到的现实。区域社会史里少见的、把长时段和具体地方咬合起来的写法。

### 3.《根本重地：明代的南京》
方骏 著 / 徐蔚 译 / 社会科学文献出版社 2026-01

永乐迁都之后，南京是不是一个空壳政府？方骏用明代南京各官署编纂的「部门志」这类冷门史料反驳了这个通行印象：南京保留了与北京几乎对称的文官、武官、宦官机构，是南方财政与军事的支点，也是官员的「调节阀」与「培养皿」。制度史里最见功力的一类题目——不看诏令看账本，不看中枢看陪都。

### 4.《晚明大变局》
樊树志 著 / 中华书局 2026-08 新版

樊树志九十岁，中华书局把他的晚明研究做成面向大众的通识本。核心论点很硬：「三千年未有之大变局」常被归到晚清，但真正的转向可能早在晚明已经发生——海禁松动、白银流入、江南市镇兴起、讲学结社、西学东渐。从六个侧面把晚明放回 15 世纪末地理大发现的世界进程里看。想理解「中国近代从哪里开始」，这是比断代史更锋利的一刀。

## 二、博物学与自然观察（从《植物的战斗》往外走）

### 5.《春天存留》
沈书枝 著 / 译林出版社 2026-08 / ISBN 9787575314237

沈书枝是安徽南陵人，南大古代文学硕士。这本书半部是自然观察记，半部是古诗博物志：她因为观鸟重新看见北京城的公园，又把「拆桐花烂漫」这类诗句当成地图，去追一枚桐花的来历、去试柏子香的做法。130 多张亲摄照片，全书彩印。

选它的理由不是文笔，是路径——你读《植物的战斗》是被知识吸引，读这本是被「怎么在日常生活里保留一点观察能力」吸引。对上班的人来说后者更难，也更有用。

### 6.《蕨类观察手册》
王云涯 著 / 商务印书馆 2026-07 / ISBN 978-7-100-26520-1

中国本土常见石松类和蕨类 416 种，野外实拍 3000 余张，每物种 7 张多角度图并标注识别特征。中科院植物所张宪春审订。豆瓣开分 9.8。

工具书的价值在于把「看」变成「认得出」：独创的「矩阵观察法」从整体到局部到显微，给初学者一条固定路径。家在合肥、常爬大蜀山，皖中低山正是蕨类密集的地方——这本是那种能直接带出门的书。

### 7.《自然之子：旷野林间的童年漫游》
约翰·利斯特-凯 著 / 肖舒 译 / 译林出版社·天际线 2026-09 / ISBN 9787575312882

英国博物学家利斯特-凯回望自己的童年：观察黑水鸡的蛋、在阁楼养鸽子、解救被猎人下套的狗獾。2018 年温赖特自然写作奖入围作品。

博物学写作里最动人的一类，不是「我知道什么」，而是「我是怎么开始想知道的」。如果你对《植物的战斗》那种知识密度已经满足，这本给的是另一件东西：好奇心的起源。

## 三、古典诗词（《昨夜星辰》读完之后）

### 8.《杜诗三百首》（简体本）
江弱水 评注 / 中华书局 2026-05 / ISBN 978-7-101-17368-0

江弱水二十年杜诗研究的成果，选杜甫各体诗三百首，占全部杜诗约五分之一。立足中国古典诗学，以西方现代诗学为参照系评析——不是注释串讲，是真正在谈诗怎么成立。简体横排，学术性与可读性兼顾。

江弱水是安徽青阳人，这个巧合不重要，重要的是他写诗评的方式：不把杜甫供起来，而是拆开看他每一处手艺。

### 9.《唐魂宋魄半句诗》（全二册）
马未都 著 / 北京大学出版社 2026-04 / ISBN 9787301373507

选唐宋五代 100 位作者，每人一首，从「传世半句」切入还原完整诗篇与创作现场。比如「人生七十古来稀」常被当祝词用，原是杜甫安史之乱后借酒浇愁的悲慨。

和《昨夜星辰》同一个路数——通俗、以人带诗、不考据。区别是马未都更狠一点：他专挑那些被用滥了的句子，把语境还回去。适合碎片时间。

## 四、社会心理学（《影响力》之后该往哪走）

### 10.《社交大脑》
特雷西·卡米莱里、萨曼莎·罗基、罗宾·邓巴 著 / 刘俊杰 译 / 中译出版社 2026-07 / ISBN 9787500185987

邓巴本人参与写作。核心是「邓巴数」：一个人能维系的有意义社交关系上限约 150 人，超过这个规模，沟通变难、小团体自然形成、「我们」与「他们」的区分取代整体认同。书里给了大量组织案例——戈尔把工厂限制在 150 人左右，宁可新建单元也不让单个组织膨胀。

书架上的《社会性动物》躺了很久没动。这本比它轻，也比它具体：不是讲群体心理的一般原理，是回答「为什么团队过了某个规模就不对劲」。

### 11.《麻烦别人的艺术》
海蒂·格兰特 著 / 戴思琪 译 / 机械工业出版社 2026-03 / ISBN 9787111805441

核心结论反直觉：人们愿意帮忙的概率远高于我们的估计，恰当的「麻烦」反而拉近距离。机制拆得很细——内群体认同、积极身份认同、效能感反馈，让施助者获得价值感，求助就从负担变成联结。

《影响力》讲的是别人怎么影响你，这本讲的是你怎么合理地请人帮忙。对习惯自己硬扛的人是本对症的书。
