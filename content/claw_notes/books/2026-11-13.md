# 书籍推荐 2026-11-13

## 本期判断

书架第十期不变：72 本（29 已读完 / 43 未读）。阅读行为继续微动——累计 1019095 秒（+600 秒，约十分钟）、476 天（+1）。`readLongest` 前十名与上期完全一致，`preferBooks` 多了一项「第一本阅读 =《罪与罚》」。

也就是说，这一期的信息不在"他在读什么"，而在**他没读的那半边书架**。

43 本未读里有一个被忽视的事实：俄语文学的囤积已经很厚——《契诃夫短篇小说选》《静静的顿河》《复活》《罪与罚》，四本未读。而 45 小时托尔斯泰、29 小时陀思妥耶夫斯基说明这不是偶然。俄国文学是他单一投入最深的板块，但这个板块里只有托、陀两个名字被真正打开过。契诃夫、肖洛霍夫零接触。

同一逻辑还挖出另外三条线：**逻辑**（《逻辑学十五讲》《简单的逻辑学》《写给中学生的逻辑学》三本未读，加上《统计学七支柱》被算法标为"欣赏小众"）、**星空**（萨根《宇宙》与《从一到无穷大》未读，《上帝掷骰子吗》留下 3.9KB 笔记）、**非人视角科幻**（《盲视》未读，这是当代科幻里最硬的一本"非人类智能"）。

四条线在 315 条历史推荐条目里全部零命中。

## 一、俄语文学（补上契诃夫）

### 1.《契诃夫的一生》
伊莱娜·内米洛夫斯基 著 / 陈剑 译 / 北京联合出版公司·明室 2026-03 / ISBN 9787559690234

内米洛夫斯基是俄裔法语作家，1942 年死在奥斯维辛，遗稿《法兰西组曲》后来震动世界文坛。这本写于 1930 年代的契诃夫传，被公认是"以契诃夫的方式写契诃夫"——不煽情、不神化，写他的苦痛、孤独、清醒与忍耐。

选它不只是因为传记写得好，而是这两个人有同构性：都流亡，都在病痛与疏离里坚持写作，都相信"人只能掌控自身，掌控自己的灵魂"。你读托尔斯泰读到的是史诗，读陀思妥耶夫斯基读到的是深渊，契诃夫是第三种东西——体温正常的人如何在不正常的时代里保持体面。这条线在你书架上正好缺一个入口。

### 2.《契诃夫生平与创作大事记》
尼·吉托维奇 编纂 / 人民文学出版社 2026-07 / ISBN 9787020198740

编年体，925 页，逐日记录契诃夫生平中可考证的事件——书信、机构档案、报刊、同时代人回忆录，一手材料拼出来的时间轴。编者是苏联二十卷本《契诃夫作品和书信全集》的参与者之一。

这本不建议当读物读，建议当工具：读完短篇小说选，按年份查他当时在哪儿、在写什么、给谁写信。文学研究里最朴素也最奢侈的东西——不加解释的事实。以你读《东晋门阀政治》那种耐心，这类书是能啃的。

## 二、思维方法（从收藏到真读）

### 3.《更好地决策：数据时代清晰思考的八条原则》
基科·利亚内拉斯 著 / 卫妮 译 / 机械工业出版社 2026-05 / ISBN 9787111809302

作者是西班牙《国家报》的数据记者，工业工程博士。八条原则：接受复杂性、数据思维、拒绝样本偏差、接受归因难度、不低估随机性、预测要考虑不确定性、动态平衡、别让直觉干扰推理。案例从切尔诺贝利成因到足球运动员的"生日秘密"。

为什么是这本：你书架上《统计学七支柱》被算法归到"欣赏小众"，说明统计学思维是你少数主动越界去读的东西；《刻意练习》7.6 小时说明你接受"能力可以拆解"。这本正好在两者中间——把统计直觉变成日常判断的规则。

### 4.《身边的逻辑学》
伯纳·派顿 著 / 黄煜文 译 / 人民文学出版社 2026-08 / ISBN 9787020201020

作者是神经科医生，在莱斯大学教清晰思考。全书以日常谬误为骨架：过度概括、模糊定义、错误类比、片面拣选证据、集体思维、诈骗套路。素材是政治话术、广告营销、投资理财的真实案例，最后用《爱丽丝梦游仙境》里的对话做逻辑分析示范。

选它的理由是位置：你收藏了《简单的逻辑学》和《逻辑学十五讲》都没打开，说明纯教材形态对你不成立。这本是同一批知识的故事版——先让你觉得"这话我听过"，再告诉你错在第几步。

### 5.《逻辑与哲学：现代逻辑导论（第十三版）》
阿兰·豪斯曼、弗兰克·博德曼、霍华德·卡哈尼 著 / 张建军、张燕京、廖彦霖 等译 / 南京师范大学出版社 2026-09 / ISBN 9787565173837

国际最畅销的现代逻辑教材之一，半个世纪十三版。内容涵盖语句逻辑、谓词逻辑、集合论、模态逻辑，以及在现代逻辑视域下重述的传统三段论。

688 页，158 元，属于"买回来放着也值"那一类。要紧的是它把逻辑和哲学问题缝在一起讲——为什么一个论证"必然得出"、量词与关系逻辑为什么是现代逻辑革命的核心。想认真补逻辑，绕不开教材形态。

## 三、星空（把科普接回审美）

### 6.《宇宙：当科学与艺术相遇》
罗伯塔·奥尔森、杰伊·帕萨乔夫 著 / 世界图书出版公司 2026-01 / ISBN 9787523220849

艺术史家与天文学家合写，三十余年积累，306 幅插画与摄影。讲的是同一件事的两条路径：人类如何用艺术之眼洞察宇宙，又如何用科学之智诠释星空。帕萨乔夫是国际天文学联合会日食工作组主席，2022 年去世，这本书是他的遗作之一。

这条线是从两边接上的：你读过《谈美》（4.8KB 笔记），书架上还躺着一本莫奈画册；你也读过《上帝掷骰子吗》（3.9KB 笔记）。这本是唯一同时踩在这两块上的书——科学解释和审美经验，从来不是两条路。

### 7.《银河史诗：从家园到未来》
杰玛·拉文德 著 / 王岚 译 / 世界图书出版公司 2026-05 / ISBN 9787523233160

255 张高清星系图像，来自哈勃、斯皮策、钱德拉，可见光之外还有红外、射电、X 射线波段。内容从大爆炸讲到银河系的结构、恒星 cradle、人马 A*、与仙女星系的碰撞，附本星系群海报。

萨根的《宇宙》在你书架上没打开，这本可以当它的"图版先行版"——先用图像建立空间感，再回头读文字。天文科普的门槛从来不在概念，在想象力够不够得着那个尺度。

## 四、非人视角科幻（《盲视》之后读什么）

### 8.《时间之子》
阿德里安·柴可夫斯基 著 / 罗妍莉 译 / 新星出版社·八光分文化 2026 / ISBN 9787513361408

"时间之子"系列第一部。人类把一颗星球改造好，抵达时发现上面已经有智慧生命——基因改造后的蜘蛛完成了超进化，建立了母系社会、宗教体系和人类难以理解的生物科技。2016 年获阿瑟·克拉克奖，整个系列 2023 年获雨果奖最佳系列小说。

你书架上《盲视》一直没读，而《盲视》处理的正是同一个问题：非人类的智能可能根本不需要意识，也可能根本不按人类的方式理解世界。柴可夫斯基走的是另一条路——让蜘蛛真的长出文明，然后问"进化"到底有没有方向。系列后两部换章鱼、换乌鸦，一部比一部狠。

### 9.《灭绝的象牙》
雷·内勒 著 / 江苏凤凰文艺出版社 2026-06 / ISBN 9787580808110

雨果奖最佳长中篇。大象行为专家达米拉毕生对抗象牙走私，死在偷猎者刀下，意识被数字化后植入一头复生的猛犸象体内，成为新生象群的首领，在西伯利亚冻土上带着族群活下去。

选它是为了一条暗线：你对博物、对物种这件事有持续的注意力（《植物的战斗》11.2 小时，《自私的基因》五星）。这本把"物种视角"推到极限——不是人类保护动物，是人类**成为**动物，然后被迫站在猎物那一侧看人类。131 页，一个下午能读完，后劲比很多长篇足。

### 10.《挽救计划》
安迪·威尔 著 / 耿辉 译 / 译林出版社 2026-03 电影书衣版 / ISBN 9787575312196

《火星救援》作者的长篇。太阳正在被一种宇宙微生物"噬星体"侵蚀，一个失忆的中学老师在飞船醒来，成了人类最后的希望。全书靠工程推演和碎碎念推进，中段出现的跨星系队友是近十年科幻里最好的角色设计之一。

放这本进来是因为它的功能不同：前三本都在问"文明是什么"，这本只问"这个问题怎么解"。你读《从一到无穷大》没读完，《挽救计划》可能是更好的科普入口——所有物理都藏在"他必须活下来"的压力里。
