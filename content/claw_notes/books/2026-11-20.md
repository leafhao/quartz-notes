# 书籍推荐 2026-11-20

## 本期判断

书架第十一期完全静止：72 本（29 已读完 / 43 未读），累计 1019095 秒、476 天，`readLongest` 前十、`preferBooks`、`preferAuthor` 全部与上期逐字相同。上一期我就写过一句预判——"若下期仍无结构变化，将转为以未读藏书与笔记体量为主轴"。这期就是那个下期。

于是换了一个更彻底的问法：**过去十期推荐覆盖了几十条线，但哪些方向是一次都没碰过的？**

把 262 条历史推荐条目全部抽出来做关键词交叉，四个方向零命中：**中国当代文学**（刘震云、余华、李娟三个人名一次都没出现过）、**先秦史**（翦商、殷周、商周、甲骨全为 0）、**清史**（乾隆、清代全为 0，而明史 11-06 刚推满一期）、**系统思维这个具体品类**（只推过《更好地决策》一本，偏数据决策而非系统论）。

这四条线不是凭空找的，它们全都对应书架上真实躺着的未读书：《一句顶一万句》《我胆小如鼠》《我的阿勒泰》三本中国当代文学，《翦商》一本先秦史，《饥饿的盛世：乾隆时代的得与失》一本清史，《系统之美》一本系统论。

一个人把书加进书架却不打开，说明他有兴趣但缺一个入口。这期就补这四个入口，另加一条莎学线（《莎士比亚全集》11 册未读，零覆盖）。

## 一、中国当代文学（空了两年的一条线）

### 1.《咸的玩笑》
刘震云 著 / 人民文学出版社 2026-01 / ISBN 9787020197620

《一日三秋》之后隔了四年的长篇，简体版半年发行过百万册。主人公杜太白是延津的中学老师，醉酒打架丢了工作，转去做小城红白事主持人，又因一次"不检点"被拍照上网，成了过街老鼠。他从体面教师一路掉到菜市场卖萝卜，中间没有戏剧性的坠落，只有日常的磨。

扉页上一句话："世界各地，不同的街道上，街上走着的每个人，内心都有伤痕。"刘震云自己在采访里说，他前几本写的是人的 A 面和 B 面，这本想写被日子盖住的 C 面和 D 面。

你书架上《一句顶一万句》一直没打开——那本讲的是"找个说得着的人有多难"，这本讲的是"说不出口的话怎么咽下去"。同一片延津，同一种钝痛。如果要给这条线挑一个入口，这本比《一句顶一万句》更好进：它更短、更近、更不留情面。

### 2.《阿勒泰的角落》
李娟 著 / 花城出版社 2026-02 新版 / ISBN 9787574908147

李娟的成名作，2026 年花城推出"李娟非虚构经典系列"重排版，32 开、328 页。写的是她年轻时跟着家人进北疆深山牧场，在喀吾图、巴拉尔茨、沙依横布拉克几个"角落"撑起半流动的裁缝店和杂货铺，跟着牧民逐水草迁徙。

李娟的好，不在于写了边疆，而在于她写穷日子的时候从不卖惨也不升华。一尾在简陋炉灶边奇迹般活着的金鱼，一个来店里补鞋子的人，一场二十公分厚的雪——她的句子没有形容词的重量，但读完之后你会觉得那天下午的光线变了。

你书架上《我的阿勒泰》没读，这本是同一片牧场的另一组切片，而且更早、更野。如果剧集让你对阿勒泰有过一点好奇，文字版比影像更值得进。

### 3.《卢克明的偷偷一笑》
余华 著 / 新星出版社·新经典文化 2026-01 / ISBN 9787513362573

"混蛋列传"系列第一部，余华第一次写喜剧。家装公司老板卢克明从银行柜台认识妻子开始，靠一场"思想解放"的玩笑把日子过成了生意，再靠生意爬进权色交易的圈子，最后在经济下行里被自己的透支反噬。

说句实话：这本书豆瓣差评很多，一屏一屏刷不完，主要骂它油腻、写性写得难看。但澎湃的书评给了另一个角度——"混蛋列传"第一部，作家本来就是要塑造一个油腻中年混蛋，读者厌恶得这么整齐，某种程度算成功。余华仍然是当下少数敢正面撞社会现实的作家。

放进来的理由不是它好，是它跟你书架上那本《我胆小如鼠》构成一组：一本写暴力如何压在弱者身上，一本写欲望如何从内部烂掉。两本都是余华写"人怎么坏掉"，只是方向相反。

## 二、先秦史（《翦商》之前的那一段）

### 4.《先秦史》
沈长云 著 / 山西人民出版社 2026-09 / ISBN 9787203144113

635 页的先秦断代史，从夏、商、西周讲到春秋战国的兼并，涵盖政权更迭、制度演进、民族关系与社会变迁。作者 1944 年生，师从赵光贤攻商周史，曾任中国先秦史学会副理事长，主持过国家社科基金重点项目"中国古代国家的起源与形成研究"。特点是考古出土材料与传世文献互证。

为什么现在推这本：你书架上《翦商》躺着没读，而《翦商》是一部"观点书"——李硕用考古材料重述商周之变，锋利、有想象力，但它预设你已经知道商周的基本脉络。这本《先秦史》正好是那个底座：先有骨架，再读颠覆。

你读中古史（《东晋门阀政治》21.5 小时）的耐心是够的，缺的只是往前挪一千年。

## 三、清史（明史推完之后该往哪走）

### 5.《乾隆传》
白新良 著 / 中华书局 2026-01 / ISBN 9787101174656 / 41.7 万字

中华书局"中华帝王传记"丛书之一，布面精装。作者是南开清史名家、国家清史编纂工程编写者之一，为写这本把《清高宗实录》完整翻过十遍以上，另辑了 150 万字的乾隆朝人物资料长编。全书用《清实录》、宫廷档案、奏折等一手材料，从 12 岁被康熙看中写到 85 岁内禅，附乾隆年表。

选它的直接原因：你书架上有一本张宏杰的《饥饿的盛世：乾隆时代的得与失》，也是写乾隆，但那是通俗历史写作，观点先行。白新良这本是学院派的定本，正好可以对照着读——同一个皇帝，一个当故事讲，一个当档案查。两本一起读，你会看到"盛世"这个词是怎么被两套写法分别处理的。

11-06 那期推了一整组明史，清史一直空着。这是最自然的接续点。

## 四、系统思维（把《系统之美》读下去）

### 6.《读懂系统思维》（上下册）
陆俊华 著 / 人民日报出版社 2026-08 / ISBN 9787511593634 / 571 页

五部分：系统思想的发展史、系统思维方法、系统思维与哲学/科学/历史思维的贯通、对复杂系统的认识、系统方法与应用途徑。作者长期研究系统科学，本书的特点是把系统论放回思想史里讲，而不是直接给工具箱。

你书架上梅多斯的《系统之美》没读完，问题很可能不在你——那本书是"操作手册"，一上来就是存量流量、反馈回路、杠杆点，缺少"为什么人类需要这样想"的铺垫。这本从思想史切入，先讲系统观念怎么从哲学和科学里长出来，再谈方法。

571 页确实厚。但当参考书用也行，第五章和第二章单独成立。

### 7.《涌现思维：看懂复杂商业世界》
王珞 著 / 机械工业出版社 2026-04 / ISBN 9787111807490

用复杂系统理论解释"规模—复杂性—涌现—不确定性"这条链条：系统小的时候线性描述还凑合，规模一大、互动一密，因果关系就模糊了，系统行为被涌现现象接管。案例覆盖硅谷创新、平台经济、金融网络、人工智能。

跟上一本的分工很清楚：陆俊华那本是"系统思维是什么"，这本是"系统一旦复杂起来会怎么背叛你的预测"。你读《影响力》用了 10.8 小时，读《刻意练习》7.6 小时——你对"人的行为有规律但规律会失效"这件事一直有兴趣。涌现就是那个失效点。

## 五、诗与莎（两本都对应书架上的未读）

### 8.《飞鸟集》
泰戈尔 著 / 郑振铎 译 / 三乖 绘 / 国文出版社 2026-11 / ISBN 9787512525412 / 323 页

郑振铎译本，325 则无题短章，配绘者三乖的插画。这版把"最渺小的存在里藏着最辽阔的真理"做成了图文互译——画不是给诗配图，是用图像重新解释那些句子。

你书架上有一本泰戈尔英文诗集（《飞鸟集》英文版）没打开，还有鲁迅的《野草》。这两本放在一起很有意思：一个是"让生如夏花之璀璨"，一个是"绝望之为虚妄，正与希望相同"，同一时代两种极端的短句美学。

11-06 推过一组古典诗词（《杜诗三百首》《唐魂宋魄半句诗》），外国诗一直空着。这本轻，一个晚上能翻完，适合放在床头。

### 9.《莎士比亚在分裂的美国》
詹姆斯·夏皮罗 著 / 李欣祯 译 / 广西师范大学出版社 2026 / ISBN 9787559885121

2026 年是莎士比亚逝世 410 周年。夏皮罗是哥伦比亚大学教授、美国人文与科学院院士，他挑了美国历史上八个标志性年份，用八部莎剧加一部电影，讲美国人怎么借莎剧吵架：1849 年《麦克白》演出直接引发贫富阶层的街头冲突；2017 年纽约中央公园《裘力斯·凯撒》因影射特朗普引来左右两派互骂；《奥赛罗》的选角风波、《驯悍记》里的父权与女性主义之争。

这本书真正回答的问题不是"莎士比亚多伟大"，而是"为什么一个 16 世纪的英国人可以成为任何立场都能征用的武器"。经典之所以是经典，恰恰因为它能被反复误读。

你书架上《莎士比亚全集》11 册躺着没读——那套书太重，从剧本进很难。从这本进容易得多：先看别人怎么用莎剧，再回头读莎剧，动机就成立了。
