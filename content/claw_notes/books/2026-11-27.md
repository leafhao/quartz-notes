## 一、思想与制度

### 1.《〈王安石集〉导读》
张富祥 著 / 中华书局 2026-08 / ISBN 9787101178630 / 精装 558 页

王安石在官方史书里的形象叠了八百年：南宋高宗为父兄亡国卸责，把祸根推给他；元修《宋史》照抄宋代国史，直指他是北宋亡国元凶；清初陈景云改编《宋史》，干脆把他编进《奸臣传》。"拗相公"和"变法失败者"这两个标签就是这么一层层糊上去的。

张富祥是山东大学做宋代文献的老学者，这本书不正面反驳标签，只是让读者直接读王安石自己的文字。全书分"概说"与"选读"：前面六万字讲生平、从政、学术，以变法贯穿；后面从《临川文集》精选二百二十篇，按原集体例分十辑。值得注意的是取舍——原集里诗占一半篇幅，这本一律不选，选的全是书疏、奏状、札子、表、论议、杂著。刻意不选诗，就是拒绝把王安石"文学化"。

概说第二节的标题也值得玩味："王安石变法的成功与失败"，成功在前。他区分的其实是两件事：变法措施本身的实效，和变法在政治斗争中的结局。

你的主线一直在制度史上：《东晋门阀政治》读了 21 小时排第三，《中国历代政治得失》留了 3.2KB 笔记。唐代、魏晋、明史都推过了，**宋代是唯一还空着的一段**。而王安石恰好是这个缺口里最硬的一块——他谈的不是"宋朝发生了什么"，是"一个王朝如何设计自己的财政、军事与官僚机器"。

### 2.《经济思想简史》
约瑟夫·R. 卡马罗萨诺 著 / 李井奎、何斌锋 译 / 格致出版社 2026-06 / ISBN 9787543237919

从古希腊罗马的哲学思辨讲到中世纪经院学者的道德追问，再到重商主义、重农学派、斯密、李嘉图、马克思、马歇尔、凯恩斯，把经济学从道德哲学的一个分支走向独立社会科学的过程讲清楚。242 页，不堆百科条目，只抓各学派的核心贡献与关键转折。

这本书的长处是始终把理论放回时代里：工业革命的贫困问题催生了什么，大萧条又逼出了什么反思。

你的经济类阅读一直是"实用侧"——《小岛经济学》《纳瓦尔宝典》，还有《工作前 5 年，决定一生的财富》那篇 5.2KB 的笔记，你自己写的结论是要把理财当技能学。但那一路都是"我该怎么做"，缺一本"这门学科是怎么想事情的"。11-06 推过行为金融，是决策心理；这本是思想史，另一条腿。

## 二、音乐

### 3.《音乐的理性与社会基础》
马克斯·韦伯 著 / 喻辉、赵去非 译 / 苏州大学出版社 2026-03

韦伯这本是音乐社会学的开山之作，中译首次成书。他问的问题很韦伯：为什么只有西方发展出了和声—调性体系？答案不在天赋，在理性化——音程怎么划分、音阶怎么构建、调性原则怎么确立，每一步都是一次数学化。书里还讨论乐音体系与音律的理性化，以及现代音乐与其乐器之间技术、经济和社会的关联：钢琴的机械结构、管弦乐团的编制，都是社会条件塑造出来的。

你书架上《社会学的基本概念》没打开，韦伯这个名字一直停在"想读"那一格。从《新教伦理》进太重，从这本进反而轻——它只有两百多页，而且话题是你熟的（音乐），陌生的是视角（社会学）。

更妙的是它跨了两条线：韦伯的社会理论，和你书架上那本没读的《音乐入门：丰子恺音乐五讲》。

### 4.《耳中的世界：音乐在文化中的诞生》
拉蒙·安德烈斯 著 / 刘海娜、李雪 译 / 中信出版集团 2026-02

西班牙作家写的音乐文明史。从人类与声音的初次相遇开始，经两河流域、印度、埃及、希腊、罗马、以色列，一直到中国，最后落到现代西方。他不从乐理讲，而是拿医学、数学、天文学、神话与信仰当棱镜，看音乐在各文明里如何同时是知识，又是愉悦。

和上一本正好配成一对：韦伯问"西方为什么特殊"，安德烈斯问"所有文明都怎么对待声音"。一本是解剖，一本是漫游。

你 10-16 那期我推过《你喜欢肖邦吗》，那是从演奏和唱片进去的。这两本是从"音乐是什么"进去的，角度完全不同，不冲突。

## 三、荒诞与疾病

### 5.《我本软弱，但我已尽我所能：加缪生命笔记选》
阿尔贝·加缪 著 / 言思行 译 / 上海文艺出版社 2026-02 / ISBN 9787532194742

从 1935 年 5 月到 1959 年底，四分之一世纪，加缪在只为自己写的九册笔记里观察世界。原始笔记约四十万字，这本从中辑出五万余字格言与散文段落，124 页，一掌可握。

里面没有哲学体系，只有面对疾病、孤独、贫穷时的真实挣扎，以及他对母亲、朋友、阳光和大海的温柔记录。"不屈服：这句话包含了一切。"

你书架上《鼠疫》和《西西弗神话》都躺着没读，《局外人》却是 2022 年就读完的。这说明加缪的入口是开的，只是那两本太重——一本是寓言体长篇，一本是哲学随笔，都需要整块时间。这本笔记恰好是碎片形态：晚上翻十页就能停下来，适合当入口，也适合当回程。

我自己更看重它的一点：加缪 1930 年代得过肺结核，一辈子带着这个病写作。他谈身体、谈限度、谈"在隆冬里发现身上有一个不可战胜的夏天"，都不是修辞。

### 6.《中国防疫的近代转型》
陈小卡、徐劲 编著 / 商务印书馆 2026-09 / ISBN 9787100265997

鸦片战争前，中国自有一套行之有效的传统公共卫生与防疫办法；战后，西方的公共卫生理念进来，两套东西在具体疫情里互相摩擦，最后长出了近代的防疫体系与卫生行政。这本书做的就是把这个转型的曲折过程用史实摆出来：检疫、隔离、清洁运动、防疫机构怎么一个个落地。

作者陈小卡长期管中山大学医学博物馆，做过西方医学传入中国的研究，材料是实的，不是观念史的空转。

接《鼠疫》读最合适。加缪写的是瘟疫中的伦理处境，这本写的是瘟疫中的制度反应——同一件事的两种写法，一本问"人该怎么办"，一本问"国家能怎么办"。你读《动物庄园》时的结论是"决定社会面貌的是公民认知与生产力水平"，这本正好给那个判断补一段制度细节。

### 7.《中国医史》
王吉民、伍连德 著 / 李汉平 译 / 上海三联书店 2026-01 / ISBN 9787542688934 / 精装 785 页

1932 年首印，第一部系统向西方阐释中国医学成就的英文著作，王吉民与伍连德合著。这版是上卷中译，汉英对照，从伏羲讲到民国。

伍连德这个名字值得一提：1910 年东北鼠疫，他主持防疫，是中国现代公共卫生的起点人物。所以这本书不只是医史，也是"中国人如何用自己的语言向世界说明自己的医学"的一次尝试。目录里有意思的条目很多——"疾病的哲学"、"脉学的原理"、"道教与佛教对医学的影响"、"医学学校与国家考试"、"新旧力量之间的斗争"。

785 页，不用一次读完，当工具书翻。它和上一本互为表里：一本讲观念与制度怎么变，一本讲这些观念本身长什么样。

## 四、语言与戏剧

### 8.《夜晚的语言学家：发现汉语的 100 个秘密》
陈笠 著 / 海峡书局（新经典）2026-08 / ISBN 9787556717064

作者是南京大学中文系本科、香港中文大学广告学硕士，以"笠翁夜话"为名在网上写汉语知识，这是成书。一百个日常语言现象，拆成短章：龙为什么翻案成 Loong 不叫 dragon、"骑"字为什么取消了 jì 的读音、骰子为什么不读 shǎizi、"苹果"的"苹"为什么不能组词、"的""地""得"到底怎么分、汉语语法是不是真的简单。

豆瓣 9.6，但分数不是重点。重点是它用的形式：古人随笔爱以"夜话"为题，围炉夜谈，没有学院派的架子。这类书的价值不在知识量，在于让你重新对每天在用的东西起疑。

你的阅读里语言这个维度一直是 0——271 条历史条目，"语言学""汉语""修辞""文字"全部零命中。而你其实对"表达"很敏感：《一句顶一万句》讲的就是"说不说得着"。这本可以从另一头补：说不着，有时候是语言本身的问题。

### 9.《莎士比亚戏剧来源与创新》
李伟昉 著 / 商务印书馆 2026-05 / ISBN 9787100257411 / 精装 458 页

一个反常识的事实：莎士比亚几乎没有原创情节。他的剧本绝大多数都有可考的素材来源——编年史、旧剧本、意大利小说集、普鲁塔克传记。这本书做的事就是把"源"和"流"一条条对上：某个故事从哪儿来，他改了什么，为什么这么改。

李伟昉是河南大学莎士比亚与跨文化研究中心主任、中国外国文学学会莎士比亚研究分会副会长，这本书是他的老本行，学术密度高，但写法是"点石成金"的路子，不是版本考据。

你书架上《莎士比亚全集》十一册一直没打开。上次我推《莎士比亚在分裂的美国》是想给一个"为什么读"的理由，这次给的是"怎么读"的方法：知道一个故事原本长什么样，再看他怎么改，读剧本就从"看不懂台词"变成了"看他做选择"。这是最省力的入口。
